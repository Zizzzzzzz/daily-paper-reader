## 摘要
具有长上下文窗口的大语言模型可以直接根据完整的学术、技术和政策文档回答复杂问题，但输入整个文档通常成本高昂、速度缓慢，且可能在增加不必要的数据泄露风险的同时降低回答质量。本文针对在长文档上回答多个异构问题的常见场景，在这种场景下，由于文档结构的多样性和查询与分块（query-chunk）之间微弱的语义相似性，固定位置启发式方法和标准的检索增强生成（RAG）可能会失效，而后者通常需要针对特定任务和领域对嵌入检索器进行微调。我们提出了选择性注意力引导提取（SAGE），这是一种无需训练、即插即用的上下文压缩框架。它利用轻量级本地大语言模型执行单次预填充，并将语言模型的注意力信号转换为可配置粒度的查询相关性热图。SAGE 进一步引入了差分注意力策略，以更好地隔离与问题相关的证据，然后在用户定义的 Token 预算下选择得分最高的单元，并仅将这些缩减后的上下文转发给下游大语言模型进行答案生成。SAGE 在多个长文档问答基准测试中超越了传统的压缩技术，特别是在仅使用 10% 上下文预算的情况下，在 QuALITY-hard 上获得了前四名的成绩。这实现了 90% 的 Token 削减，同时保持了具有竞争力的准确率，且无需模型微调或复杂的校准。

## Abstract
Large language models with long context windows can answer complex questions directly from full-length academic, technical, and policy documents, but passing entire documents is often costly, slow, and can degrade answer quality while increasing the risk of unnecessary data leakage. This paper targets the common setting of answering many heterogeneous questions over long document(s), where fixed position heuristics and standard retrieval-augmented generation (RAG) can fail due to document structure variability and weak query-chunk semantic similarity, which often requires task- and domain-specific tuning of embedding retrievers. We propose {Selective Attention-Guided Extraction} (\ourmethod), a training-free, plug-and-play context reduction framework that uses a lightweight local LLM to perform a single prefilling pass and convert language model attention signals into a query-specific relevance heatmap at configurable granularities. \ourmethod\ further introduces \emph{differential attention} strategies to better isolate question-relevant evidence, then selects the top-scoring units under a user-defined token budget and forwards only this reduced context to a downstream LLM for answer generation. \ourmethod\ surpasses traditional reduction techniques across multiple long-document QA benchmarks, notably securing a top-4 rank on QuALITY-hard while constrained to a 10\% context budget. This enables a 90\% reduction in tokens with competitive accuracy, without the need for model fine-tuning or complex calibration.

论文针对长文档问答（Long-context QA）中存在的三个核心痛点：
*   **效率与成本：** 直接将长文档输入 LLM 会导致极高的 Token 成本和推理延迟。
*   **质量下降：** 长上下文中充斥着大量无关信息，容易分散模型注意力（Lost in the Middle 现象），导致回答准确度下降。

    *   **固定位置启发式：** 无法应对结构多变的文档。
    *   **标准 RAG：** 依赖嵌入向量（Embedding）的语义相似度，在处理缺乏关键词匹配、证据分散或语义关联较弱的复杂推理问题时效果不佳。

**SAGE 的核心动机：** 探索是否可以直接利用 LLM 内部的**注意力信号（Attention Signals）**作为更精准的查询相关性指标，从而在严格的 Token 预算下提取最关键的上下文。

### 2. 方法论：核心思想与技术流程
SAGE 是一种**无需训练、即插即用**的上下文缩减框架，其核心流程如下：

1.  **分块注意力计算（Chunked Attention）：**
    *   使用轻量级本地 LLM（如 Llama-3.2-1B）对文档进行分块预填充。
    *   计算查询（Query）对文档每个 Token 的注意力权重，并进行**块长度归一化**，消除因分块大小不同导致的注意力分值偏差。
    *   利用 **KV-Cache 重用**技术，确保同一文档在处理多个问题时无需重复编码。

2.  **差异化注意力（Differential Attention）：**
    *   **核心创新：** 发现某些 Token（如页眉、格式符）无论问题是什么都会获得高注意力。
    *   **技术细节：** 引入一个“对比查询”（如固定指令或语义最远的问题），将目标问题的注意力图减去对比查询的注意力图，从而抵消结构性噪声，突出查询特有的证据。

3.  **单元窗口选择与预算控制：**
    *   根据用户设定的 Token 预算（如仅保留原文档的 10%），在注意力热图上滑动窗口，贪婪地选择平均得分最高的连续文本块。
    *   将选中的片段按原文档顺序拼接，交给下游高性能 LLM（如 Gemini 或 GPT）生成最终答案。

*   **高效性：** SAGE 在仅使用 **10% Token 预算**的情况下，在 QuALITY-hard 榜单上排名第四，证明了 90% 的上下文压缩是可行的。
*   **优于 RAG：** 在所有测试数据集中，SAGE 在相同预算下的表现均优于基于 Embedding 的 RAG，尤其是在需要跨段落整合信息的复杂问题上。
*   **模型规模效应：** 即使是 1B 的极小模型产生的注意力信号也优于强检索器；随着本地模型增大，提取精度进一步提升。
*   **模态通用性：** SAGE 可以无缝扩展到表格行选择任务，准确率接近全量输入。

### 7. 优点（亮点）
*   **无需微调：** 直接利用现成模型的内在能力，部署成本极低。
*   **抗噪能力强：** 差异化注意力机制有效地解决了 LLM 容易被文档结构（如页眉页脚）误导的问题。
*   **预算精确可控：** 相比 RAG 难以控制检索块重叠后的实际 Token 数，SAGE 允许用户定义严格的压缩率。
*   **隐私友好：** 可以在本地完成上下文缩减，仅将关键信息发送至云端 API。

### 8. 不足与局限
*   **重复实体的歧义：** 在包含大量重复实体（如多个邮编、多个日期）的文档中，仅靠注意力可能无法完美区分目标实体，存在精度波动的风险。
*   **预填充开销：** 虽然避免了解码成本，但仍需对长文档进行完整的预填充计算，对于极长文档（如百万级 Token），本地显存仍是挑战。
*   **对比查询的选择：** 差异化效果依赖于对比查询的质量，虽然“最远问题”效果好，但在单次查询场景下可能难以找到合适的对比项。
