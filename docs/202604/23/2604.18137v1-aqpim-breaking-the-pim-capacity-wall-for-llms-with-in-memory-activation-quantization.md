## 摘要
存内计算（PIM）架构为数据密集型机器学习中的内存瓶颈提供了极具前景的解决方案，但往往忽略了激活值内存占用不断增加的挑战。传统的 PIM 方法难以应对基于 Transformer 的模型在长上下文场景下产生的海量 KV 缓存，这些缓存经常超出 PIM 有限的内存容量，而稀疏注意力等技术可能与 PIM 对数据局部性的需求相冲突。现有的 PIM 方法和量化方法通常不足以或不适合利用激活值的独特特征。本研究发现，针对 PIM 专门优化的激活量化有机会提升带宽和计算效率。我们探索了基于聚类的矢量量化方法，这些方法与激活特征以及 PIM 的内部带宽能力高度契合。在此基础上，我们提出了 AQPIM，这是一种基于乘积量化（PQ）的新型 PIM 感知激活量化框架，并针对现代大语言模型（LLMs）进行了优化。通过直接在内存中执行量化，AQPIM 利用了 PIM 的高内部带宽，并实现了在压缩数据上的直接计算，显著降低了注意力计算的内存占用和计算开销。AQPIM 通过引入多项算法优化解决了 PQ 的精度挑战。评估结果表明，AQPIM 实现了显著的性能提升，大幅减少了占解码延迟 90% 至 98.5% 的 GPU-CPU 通信，且相比最先进的（SOTA）PIM 方法实现了 3.4 倍的加速。

## Abstract
Processing-in-Memory (PIM) architectures offer a promising solution to the memory bottlenecks in data-intensive machine learning, yet often overlook the growing challenge of activation memory footprint. Conventional PIM approaches struggle with massive KV cache sizes generated in long-context scenarios by Transformer-based models, frequently exceeding PIM's limited memory capacity, while techniques like sparse attention can conflict with PIM's need for data locality. Existing PIM approaches and quantization methods are often insufficient or poorly suited for leveraging the unique characteristics of activations. This work identifies an opportunity for PIM-specialized activation quantization to enhance bandwidth and compute efficiency.   We explore clustering-based vector quantization approaches, which align well with activation characteristics and PIM's internal bandwidth capabilities. Building on this, we introduce AQPIM, a novel PIM-aware activation quantization framework based on Product Quantization (PQ), optimizing it for modern Large Language Models (LLMs). By performing quantization directly within memory, AQPIM leverages PIM's high internal bandwidth and enables direct computation on compressed data, significantly reducing both memory footprint and computational overhead for attention computation. AQPIM addresses PQ's accuracy challenges by introducing several algorithmic optimizations. Evaluations demonstrate that AQPIM achieves significant performance improvements, drastically reducing of GPU-CPU communication that can account for 90$\sim$98.5\% of decoding latency, together with 3.4$\times$ speedup over a SOTA PIM approach.

*   **核心挑战**：
    *   **容量墙（Capacity Wall）**：存内计算（PIM）虽然带宽极高，但受限于芯片面积，其内存容量有限，难以容纳长文本产生的数百GB KV缓存。
    *   **量化困境**：在 PIM 中实现传统量化（如 INT8/FP8）需要额外的硬件逻辑（如缩放因子处理），这会显著增加面积开销，降低内存密度。

*   **整体含义**：本文提出 AQPIM 框架，旨在通过“存内激活量化”技术，利用 PIM 巨大的内部带宽进行在线聚类，从而在不增加复杂硬件逻辑的前提下，大幅压缩 KV Cache 并提升推理效率。

### 2. 方法论：核心思想与关键技术
AQPIM 的核心思想是**软硬协同设计**，将复杂的矩阵乘法转化为高效的存内查表操作。
*   **核心思想**：采用**乘积量化（Product Quantization, PQ）**。将高维向量拆分为子向量，通过聚类生成质心（Centroids），仅存储质心索引。
*   **关键技术细节**：
    *   **在线加权聚类（Importance-Weighted Clustering）**：在预填充（Prefilling）阶段，利用 PIM 闲置带宽进行在线聚类。根据注意力分数对 Token 加权，确保重要 Token 的量化误差最小。
    *   **通道排序优化（Channel Sorting）**：在离线阶段根据通道相关性重新排列，使子向量内部更具凝聚力，提升量化精度。
    *   **直接压缩计算（Direct Computation）**：在解码阶段，Query 与 Codebook 预计算偏置，通过索引直接在压缩数据上进行查表和求和，**无需解量化**，仅需现有的 FP16 MAC 单元。
    *   **页面感知窗口聚类（Page-aware Windowed Clustering）**：算法确保查找表（Lookup Table）驻留在单个 DRAM 行（Row Buffer）内。
    *   **硬件支持（Intra-Row Indirection）**：在 Bank 层面增加极小的间接寻址逻辑，将随机逻辑访问转化为可预测的行缓存命中，消除随机访问延迟。

### 6. 主要结论与发现
*   **性能提升**：AQPIM 显著减少了 GPU 与 CPU 之间的通信（该通信通常占解码延迟的 90% 以上）。相比 SOTA PIM 方案（AttAcc!），实现了 **3.4 倍** 的加速。

### 7. 优点（亮点）
*   **高效利用带宽**：巧妙地将 PIM 内部巨大的“闲置带宽”转化为在线聚类的动力，解决了 PQ 算法在传统架构上难以在线运行的痛点。
*   **极低硬件代价**：通过算法约束（页面感知）配合微小的硬件修改（行内间接寻址），避免了在 PIM 中添加复杂的整数运算单元。
*   **无需解量化计算**：直接在压缩索引上进行查表求和，这种设计思路极大地简化了数据流。

### 8. 不足与局限
*   **硬件依赖性**：该方案高度依赖于特定的 HBM-PIM 架构修改，在现有的商用通用 GPU 上无法直接部署。
*   **预填充开销**：虽然聚类过程被隐藏在预填充计算之后，但对于极短的预填充任务，聚类迭代可能会引入额外的延迟。
*   **任务覆盖**：实验主要集中在长文本推理，对于多模态模型或其他非 Transformer 架构的适用性尚未探讨。
*   **软件栈复杂性**：在线聚类和存内查表需要编译器和驱动程序的深度支持，论文对软件栈的实现细节描述相对较少。
