## 摘要
视觉-语言-动作（VLA）模型尽管在短程任务中表现强劲，但在长程操纵任务中却存在系统性失效。我们表明，在当前的反应式执行设置下，仅靠延长上下文长度无法解决这一失效问题；相反，它源于执行循环中反复出现的三个缺陷：记忆鸿沟（memory gap）、验证鸿沟（verification gap）和恢复鸿沟（recovery gap）。我们提出了 HELM，这是一个与模型无关的框架，通过三个组件解决这些缺陷：情景记忆模块（EMM），通过 CLIP 索引的关键帧检索关键任务历史；学习型状态验证器（SV），根据观察、动作、子目标和基于记忆的上下文在执行前预测动作失败；以及控制框架控制器（HC），执行回滚和重新规划。SV 是核心的学习贡献：它始终优于基于规则的可行性检查和集成不确定性基准，且其有效性关键取决于对情景记忆的访问。在 LIBERO-LONG 数据集上，HELM 将任务成功率比 OpenVLA 提高了 23.1 个百分点（从 58.4% 提升至 81.5%），而将上下文窗口延长至 H=32 仅带来 5.4 个百分点的提升，且同等预算下的 LoRA 适配仍比 HELM 低 12.2 个百分点。HELM 还提高了在 CALVIN 上的长程表现，并显著提升了受控扰动下的恢复成功率。消融实验和机制分析分离了各组件的贡献，我们发布了 LIBERO-Recovery，作为一种用于评估长程操纵中故障恢复的扰动注入协议。

## Abstract
Vision-Language-Action (VLA) models fail systematically on long-horizon manipulation tasks despite strong short-horizon performance. We show that this failure is not resolved by extending context length alone in the current reactive execution setting; instead, it stems from three recurring execution-loop deficiencies: the memory gap, the verification gap, and the recovery gap. We present HELM, a model-agnostic framework that addresses these deficiencies with three components: an Episodic Memory Module (EMM) that retrieves key task history via CLIP-indexed keyframes, a learned State Verifier (SV) that predicts action failure before execution from observation, action, subgoal, and memory-conditioned context, and a Harness Controller (HC) that performs rollback and replanning. The SV is the core learning contribution: it consistently outperforms rule-based feasibility checks and ensemble uncertainty baselines, and its effectiveness depends critically on access to episodic memory. On LIBERO-LONG, HELM improves task success rate by 23.1 percentage points over OpenVLA (58.4% to 81.5%), while extending the context window to H=32 yields only a 5.4-point gain and same-budget LoRA adaptation remains 12.2 points below HELM. HELM also improves long-horizon performance on CALVIN and substantially boosts recovery success under controlled perturbations. Ablations and mechanism analyses isolate the contribution of each component, and we release LIBERO-Recovery as a perturbation-injection protocol for evaluating failure recovery in long-horizon manipulation.

### 1. 论文的核心问题与整体含义
*   **研究动机**：现有的视觉-语言-动作（VLA）模型（如 OpenVLA, Octo）在短程任务中表现优异，但在长程（Long-horizon）任务中表现极差。
*   **核心发现**：研究者发现，长程任务的失败并非单纯因为上下文窗口（Context Window）不够长，而是源于执行循环中的三个结构性缺陷：
    1.  **记忆鸿沟 (Memory Gap)**：固定窗口丢弃了已完成子目标的证据，导致模型重复执行已完成的动作。
    2.  **验证鸿沟 (Verification Gap)**：模型反应式地生成动作，缺乏执行前的可行性检查，导致错误动作静默执行并累积。
    3.  **恢复鸿沟 (Recovery Gap)**：一旦发生错误，模型无法检测并继续在错误状态下运行，引发连锁失败。
*   **整体含义**：论文旨在通过引入一个增强型的执行框架 HELM，在不改变 VLA 模型骨干的前提下，通过外部记忆和验证机制解决长程操控的鲁棒性问题。

### 2. 论文提出的方法论
HELM 框架由三个核心组件组成，形成“检索-提议-验证-执行/恢复”的闭环：
*   **情景记忆模块 (EMM)**：
    *   使用 CLIP 嵌入作为索引，维护一个关键帧存储库。
    *   在子目标完成、检测到失败或每隔 20 步时写入记忆。
    *   通过余弦相似度检索最相关的历史状态，并将其序列化为文本注入 VLA 的语言输入中。
*   **状态验证器 (SV) —— 核心贡献**：
    *   这是一个轻量级的 MLP 模型，输入当前观察、提议动作、当前子目标和检索到的记忆上下文。
    *   **核心思想**：在动作执行前预测失败概率 $p_{fail}$。它不仅检查物理可行性，还结合记忆判断动作在逻辑上是否必要。
*   **控制框架控制器 (HC)**：
    *   管理子目标堆栈。如果 SV 预测失败，HC 会触发恢复机制。
    *   **回滚 (Rollback)**：检索最近的成功检查点，引导机器人返回安全状态并重新规划。
    *   **前向恢复 (Forward Recovery)**：在无法回滚的环境中，生成补救计划。

### 7. 优点（亮点）
*   **模型无关性**：HELM 作为一个“外挂”框架，可以适配任何 VLA 模型（如 OpenVLA 或 Octo），无需重新训练昂贵的基座模型。
*   **预执行验证**：不同于事后反思（Post-hoc reflection），SV 在错误发生前拦截，极大地保护了硬件安全并减少了错误累积。
*   **新评估协议**：提出的 LIBERO-Recovery 为机器人社区提供了一个标准化的故障恢复测试方法。

### 8. 不足与局限
*   **数据依赖性**：SV 的训练仍需要针对特定环境收集约 5 万步的 rollout 数据，这限制了其在全新环境中的零样本（Zero-shot）部署能力。
*   **回滚假设**：回滚机制假设动作是可逆的，虽然提出了前向恢复变体，但在某些不可逆的物理破坏场景下效果会打折扣。
*   **仿真与现实的差距**：所有实验均在仿真环境（LIBERO, CALVIN）中完成，尚未在真实机器人上验证 SV 对视觉噪声和传感器漂移的泛化能力。
*   **子目标分解**：依赖 VLA 自身的分解能力，若初始任务分解错误，HELM 无法完全纠正。
