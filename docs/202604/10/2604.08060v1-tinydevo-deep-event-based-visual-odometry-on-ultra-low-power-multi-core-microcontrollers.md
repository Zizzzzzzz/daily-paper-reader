## 摘要
嵌入式视觉中的一项关键任务是视觉里程计（VO），它通过视觉传感器估计相机运动，是许多嵌入式功耗受限系统（从自主机器人到增强现实和虚拟现实可穿戴设备）的核心组件。最新一类 VO 系统将深度学习模型与受生物启发的事件相机相结合，这类相机对运动模糊和光照条件具有鲁棒性。然而，最先进的（SoA）基于事件的 VO 算法需要大量的内存和计算资源。例如，领先的方法 DEVO 每帧需要 733 MB 内存和 1550 亿次乘加（MAC）运算。我们提出了 TinyDEVO，这是一种专为资源受限的微控制器单元（MCU）设计的基于事件的 VO 深度学习模型。我们将 TinyDEVO 部署在超低功耗（ULP）的 9 核 RISC-V 微控制器上，实现了约 1.2 帧/秒的吞吐量，平均功耗仅为 86 mW。得益于我们的神经网络架构优化和超参数调优，与 DEVO 相比，TinyDEVO 将内存占用减少了 11.5 倍（降至 63.8 MB），每帧运算量减少了 29.7 倍（降至每帧 52 亿次 MAC），同时在三个最先进的数据集上保持了 27 cm 的平均轨迹误差，即仅比 DEVO 高出 19 cm。我们的工作首次证明了在超低功耗设备上运行基于事件的 VO 流水线的可行性。

## Abstract
A key task in embedded vision is visual odometry (VO), which estimates camera motion from visual sensors, and it is a core component in many embedded power-constrained systems, from autonomous robots to augmented and virtual reality wearable devices. The newest class of VO systems combines deep learning models with bio-inspired event-based cameras, which are robust to motion blur and lighting conditions. However, state-of-the-art (SoA) event-based VO algorithms require significant memory and computation. For example, the leading approach DEVO requires 733 MB of memory and 155 billion multiply-accumulate (MAC) operations per frame. We present TinyDEVO, an event-based VO deep learning model designed for resource-constrained microcontroller units (MCUs). We deploy TinyDEVO on an ultra-low-power (ULP) 9-core RISC-V-based MCU, achieving a throughput of approximately 1.2 frames per second with an average power consumption of only 86 mW. Thanks to our neural network architectural optimizations and hyperparameter tuning, TinyDEVO reduces the memory footprint by 11.5x (to 63.8 MB) and the number of operations per frame by 29.7x (to 5.2 billion MACs per frame) compared to DEVO, while maintaining an average trajectory error of 27 cm, i.e., only 19 cm higher than DEVO, on three state-of-the-art datasets. Our work demonstrates, for the first time, the feasibility of an event-based VO pipeline on ultra-low-power devices.

### 2. 论文提出的方法论
TinyDEVO 的核心思想是对 DEVO 的四个阶段（Patchifier、Correlation、Update、Bundle Adjustment）进行系统性的轻量化改造：
*   **架构优化（Model Reduction）**：
    *   **通道缩减**：大幅减少匹配特征（MF）和上下文特征（CF）的通道数（如从 128/384 降至 64/96）。
    *   **模块剪枝**：移除了 Patchifier 中的旁路连接（Bypass）；在 Update 块中移除了金字塔特征（PYR）和门控循环单元（GRU），并用更简单的归一化+全连接层替代。
    *   **算子替换**：针对 MCU 难以处理的 Softmax 聚合（SA）进行了评估，虽然 SA 耗时，但在保持精度方面至关重要。
*   **超参数调优（Patch Graph Optimization）**：
    *   通过调整补丁数量（$N_{patches}$）、移除窗口（$R_w$）和补丁寿命（$PLT$），优化补丁图（Patch Graph）中的边数（$N_{edges}$）。边数直接决定了 Update 块的推理次数。
*   **混合精度部署**：
    *   将深度学习块（Patchifier, Update）量化为 **int8**，将几何计算块（Correlation, Bundle Adjustment）保持为 **FP16/BF16**，以平衡精度与 MCU 的硬件加速能力。

*   **Benchmark**：以原始的 **DEVO** 模型作为深度学习基准。
*   **对比方法**：

### 5. 实验数量与充分性
*   **实验规模**：

    *   **超参数帕累托优化**：对 $N_{edges}$ 进行了大规模扫描，通过几何“拐点”法确定了最佳平衡点。
*   **充分性评价**：实验设计非常充分且客观。作者不仅在多个数据集上验证了泛化性，还通过 Umeyama 对齐等标准手段确保了 VO 评估的公平性。同时，对比了不同输入分辨率对性能的影响。

### 6. 论文的主要结论与发现
*   **性能飞跃**：TinyDEVO 相比 DEVO，内存占用减少了 **11.5 倍**（63.8 MB），计算量减少了 **29.7 倍**（5.2 GMAC/帧）。
*   **精度损失可控**：在三个数据集上的平均 ATE 仅比 DEVO 高出约 19 cm，在 RPG 数据集上甚至优于传统的几何方法 EVO。
*   **端到端部署**：在 GAP9 MCU 上实现了 **1.2 FPS** 的吞吐量，平均功耗仅为 **86 mW**（含外部 RAM），每帧能耗 79 mJ。
*   **关键发现**：时间卷积（TC）和 Softmax 聚合（SA）对事件驱动 VO 的精度至关重要，移除它们会导致误差剧增，而 GRU 和 PYR 的移除对精度影响较小。

### 7. 优点（亮点）
*   **首次实现**：填补了超低功耗 MCU 无法运行深度学习事件 VO 的空白。
*   **软硬件协同**：不仅优化了算法，还针对 GAP9 的硬件特性（如 NE16 加速器、L1/L2/L3 存储层级）进行了深度适配。
*   **帕累托最优分析**：通过严谨的实验找到了精度与资源消耗之间的最佳平衡点，而非盲目压缩。

### 8. 不足与局限
*   **实时性尚存差距**：1.2 FPS 对于高速运动的机器人（如纳米无人机）来说仍然偏慢，属于“软实时”，距离真正的硬实时（通常需 >20 FPS）还有优化空间。
*   **内存依赖**：虽然峰值内存大幅降低，但仍需 64 MB 左右，这超出了大多数 MCU 的片上 SRAM（GAP9 仅 1.5 MB），必须依赖外部 HyperRAM，这增加了系统复杂性和部分功耗。
*   **场景限制**：实验主要集中在室内和特定轨迹，对于极端动态或超大规模室外场景的鲁棒性尚待进一步验证。
