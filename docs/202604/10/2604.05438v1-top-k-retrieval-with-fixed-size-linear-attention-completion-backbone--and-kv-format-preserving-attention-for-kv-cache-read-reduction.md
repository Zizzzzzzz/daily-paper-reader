## 摘要
长上下文生成日益受到解码阶段键值（KV）缓存传输流量的限制，尤其是当 KV 缓存被卸载到 GPU 显存之外时。查询感知检索（如 Top-K 选择）通过仅加载 KV 对的子集来减少此类流量，但当注意力权重分散在未检索到的标记（tokens）上时，对该子集进行 Softmax 重新归一化会引入偏差。我们提出了一种检索-补全注意力模块，该模块保持骨干网络权重和 KV 缓存格式不变。对于每个查询，我们计算针对 sink/tail 锚点以及查询相关的 Top-K 检索标记的精确注意力，并利用预填充阶段计算的固定大小特征图摘要来估计剩余中间区域的分子和分母。我们在未归一化域中将精确贡献与估计贡献相加，并进行单次归一化，从而在不增加额外注意力端 KV 读取的情况下，恢复缺失的 Softmax 权重。在长上下文基准测试中，该方法在相同的等效标记读取预算下优于仅采用选择策略的 Top-K 方法，且在具有高熵注意力头的场景中提升最为显著。

## Abstract
Long-context generation is increasingly limited by decode-time key-value (KV) cache traffic, particularly when KV is offloaded beyond GPU memory. Query-aware retrieval (e.g., Top-K selection) reduces this traffic by loading only a subset of KV pairs, but renormalizing the softmax over the subset introduces bias when attention mass is spread over unretrieved tokens. We propose a retrieval-completion attention module that keeps backbone weights and the KV-cache format unchanged. For each query, we compute exact attention over sink/tail anchors and the query-dependent retrieved Top-K tokens, and estimate the remaining mid-region numerator and denominator using a fixed-size feature-map summary computed at prefill time. We add the exact and estimated contributions in the unnormalized domain and apply a single normalization, recovering the missing softmax mass without additional attention-side KV reads. Across long-context benchmarks, the proposed method improves over selection-only Top-K at matched token-equivalent read budgets, with the largest gains in high-entropy heads.

#### 1. 核心问题与整体含义
在长上下文大语言模型（LLM）的推理过程中，**KV Cache（键值缓存）的内存流量**成为了主要的性能瓶颈。当上下文极长时，KV Cache 往往需要卸载（Offload）到 GPU 显存之外（如 CPU 内存或 SSD），导致解码时的读取延迟极高。
*   **研究动机**：现有的 Top-K 检索方法虽然能减少 KV 读取量，但仅对检索到的子集进行 Softmax 重新归一化，会忽略未检索 Token 的注意力权重（Mass），从而引入严重的数学偏差，导致模型在注意力分布较分散（高熵）时表现崩溃。
*   **核心目标**：在不改变原始模型权重和 KV 缓存格式的前提下，通过一种“检索+补全”的机制，恢复缺失的注意力权重，降低 KV 读取开销。

#### 2. 方法论
论文提出了一种**检索-补全（Retrieval-Completion）注意力模块**，其核心思想是将注意力计算分为“精确计算”和“线性估计”两部分：
*   **分区策略**：将预填充（Prefill）序列分为三部分：
    1.  **锚点（Anchors）**：包括开头的 Sink Tokens 和末尾的 Tail Tokens，始终进行精确读取。
    2.  **Top-K 检索区**：从中间区域（Mid-region）根据查询动态检索权重最大的 K 个 Token。
    3.  **剩余区域**：未被检索到的中间区域 Token。
*   **线性补全（Linear Completion）**：
    *   在 Prefill 阶段，利用线性注意力的思想，预先计算中间区域的**固定大小特征图摘要（Summary Cache）**。
    *   使用学习到的正向特征映射（Feature Maps, $\phi$）来近似 Softmax 核函数。
*   **减法补全与单次归一化**：
    *   **减法操作**：在解码时，从预存的摘要中减去已被 Top-K 检索到的 Token 的特征贡献，确保补全项仅针对“未检索部分”。
    *   **合并逻辑**：在**未归一化域（Unnormalized Domain）**将精确项（锚点+Top-K）的分子/分母与补全项的估计分子/分母相加。
    *   **最终步骤**：执行单次归一化。这种方法在不增加额外 KV 读取的情况下，近似恢复了完整的 Softmax 概率分布。

*   **数据集与 Benchmark**：

    *   **BABILong**：测试长上下文推理能力的“大海捞针”式任务（QA1–QA5）。
*   **实验场景**：测试了 4k、8k、16k 的上下文长度。
*   **对比方法**：
    *   **Baseline**：全量注意力（Full Attention）、仅锚点（Sink+Tail）、仅 Top-K 检索（带子集归一化）。

*   **骨干模型**：Llama-3.2-1B-Instruct 和 Qwen3-1.7B。

#### 4. 资源与算力

*   **训练细节**：
    *   骨干模型保持冻结（Frozen）。
    *   仅针对每个注意力头训练轻量级的 MLP 特征映射（$\phi$）。
    *   训练数据来自 FineWeb、arXiv 摘要和 BIGPATENT 等长文本语料库。

#### 5. 实验数量与充分性
*   **实验规模**：论文在两个主流模型上进行了多长度（4k/8k/16k）和多预算（1% 到 5% 的读取比例）的详尽扫码实验。
*   **分析深度**：除了准确率对比，论文还深入分析了**注意力熵（Entropy）与性能增益的关系**，并提供了内核近似诊断图（Log-Log Scatter）。
*   **公平性**：采用了“等效标记读取预算（Token-equivalent budget）”协议，将补全缓存的读取开销也折算进总预算中，确保了对比的客观性。

#### 6. 主要结论与发现
*   **性能提升**：在相同的 KV 读取预算下，该方法显著优于纯 Top-K 检索，尤其是在 Llama 模型上。
*   **熵值相关性**：补全机制的增益主要集中在**高熵注意力头**。在这些头中，注意力分布弥散，Top-K 容易遗漏关键权重，而补全项能有效修复偏差。
*   **效率优势**：在 16k 上下文下，该方法能以约 1.8 倍更少的检索量达到与纯 Top-K 相当的精度。
*   **模型差异**：Qwen3 等模型本身对 Top-K 较不敏感（注意力更稀疏），因此补全带来的增益相对较小。

#### 7. 优点
*   **架构兼容性**：不需要重新训练大模型，不改变 KV Cache 的存储格式，易于集成到现有的推理框架（如 vLLM）中。
*   **数学严谨性**：通过未归一化域的合并，从理论上解决了 Top-K 检索导致的归一化偏差问题。
*   **灵活性**：补全模块与具体的检索算法（如 ANNS）解耦，可以作为现有稀疏注意力方案的增强插件。

#### 8. 不足与局限
*   **计算开销**：虽然减少了 I/O，但增加了特征映射的计算量（$\phi$ 的重计算）。在计算受限（Compute-bound）而非 I/O 受限的场景下，优势不明显。
*   **模型依赖性**：特征映射需要针对特定模型进行蒸馏训练，且不同模型的提升空间差异较大。
*   **小预算限制**：在极低预算下，由于补全缓存本身需要一次性读取开销，可能导致无法分配足够的预算给 Top-K 检索。
