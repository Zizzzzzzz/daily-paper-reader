## 摘要
随着大语言模型（LLMs）扩展到支持超过一百万 token 的上下文窗口，键值（KV）缓存的线性增长带来了严重的显存容量和带宽瓶颈，限制了长上下文推理的效率。现有的压缩方法通常根据局部显著性指标对 token 进行优先级排序，以实现预填充计算与解码内存的解耦。然而，这些方法往往依赖于特定层的局部显著性快照，从而系统性地丢弃了那些在整个网络深度中充当全局信息枢纽、但在选定的剪枝层中暂时处于休眠状态的 token。为了解决这一局限性，我们提出了 StructKV，这是一个结构感知的 KV 缓存压缩框架，它引入了三项核心创新：第一，全局入度中心性（Global In-Degree Centrality），通过聚合整个网络深度的注意力模式来识别全局信息枢纽；第二，动态枢轴检测（Dynamic Pivot Detection），利用信息论指标自适应地定位压缩的最佳层；最后，结构化传播与解耦（Structural Propagation and Decoupling），将计算预算与内存存储预算分离。在 LongBench 和 RULER 基准测试上的实验结果表明，StructKV 有效地保留了长程依赖关系和检索鲁棒性。

## Abstract
As Large Language Models (LLMs) scale to support context windows exceeding one million tokens, the linear growth of Key-Value (KV) cache imposes severe memory capacity and bandwidth bottlenecks, constraining the efficiency of long-context inference. Existing compression approaches typically prioritize tokens based on local saliency metrics to decouple prefill computation from decoding memory. However, these methods often rely on local saliency snapshots at a specific layer, thereby systematically discarding tokens that act as global information hubs across the network depth but appear temporarily dormant at the specific layer selected for pruning. To address this limitation, we propose StructKV, a structure-aware KV cache compression framework that introduces three core innovations: First, Global In-Degree Centrality aggregates attention patterns across the network depth to identify global information hubs. Second, Dynamic Pivot Detection utilizes information-theoretic metrics to adaptively locate the optimal layer for compression. Finally, Structural Propagation and Decoupling separates the computational budget from the memory storage budget. Experimental results on the LongBench and RULER benchmarks demonstrate that StructKV effectively preserves long-range dependencies and retrieval robustness.

*   **现有局限性**：目前的压缩方法（如 SnapKV、FastKV）主要依赖“局部显著性”（Local Saliency），即根据特定某一层的注意力分数快照来决定保留哪些 token。
*   **研究动机**：作者发现这种“近视”的方法存在风险——某些 token 在特定层可能表现得“休眠”（注意力权重低），但在整个网络深度中却充当着全局信息枢纽的作用。一旦被误删，会导致长程依赖丢失。StructKV 的目标是识别并保留上下文的“结构化骨架”。

### 2. 方法论：核心思想与关键技术
StructKV 引入了三个核心创新模块：
*   **全局入度中心性累积（Global In-Degree Centrality）**：不再依赖单层快照，而是通过递归累加从输入层到“枢轴层”（Pivot Layer）的所有注意力分数，并引入衰减因子 $\lambda$。这类似于图论中的中心性指标，用于识别在多层中持续贡献语义流的 token。
*   **动态枢轴检测（Dynamic Pivot Detection）**：放弃了固定层剪枝的硬编码方式。该模块在线监控注意力熵（Entropy）、稀疏度（Sparsity）和方差（Variance）的梯度变化，自动捕捉模型从“广泛探索”转向“聚焦提取”的相位转换点（L*），从而自适应地决定何时开始压缩。
*   **结构化传播与解耦（Structural Propagation & Decoupling）**：
    *   **计算与存储分离**：在预填充阶段保留较多 token（$R_{struct}$）以维持计算精度，而在解码阶段存储较少 KV 缓存（$R_{KV}$）以节省显存。
    *   **位置对齐**：通过重新排列 Position ID 确保旋转位置嵌入（RoPE）在压缩后的序列中依然有效。

*   **评估模型**：涵盖了不同架构和规模的模型，包括 LLaMA-3.1-8B-Instruct、Ministral-8B-Instruct 以及 Qwen-2.5 全系列（7B、14B、32B）。
*   **基准测试（Benchmarks）**：

### 5. 实验数量与充分性
*   **实验规模**：实验设计非常充分。除了在多个主流模型上进行主任务对比外，还进行了：
    *   **消融实验**：验证了衰减因子 $\lambda$ 的敏感性、动态枢轴检测的准确性。
    *   **解耦分析**：证明了分离计算预算和存储预算对准确率恢复的巨大贡献（提升达 13.8%）。
    *   **深度适配性**：展示了在不同深度的 Qwen 模型上，自动检测到的枢轴层如何随模型深度增加而向后推移。
*   **客观性**：通过在不同厂商（Meta, Mistral, Alibaba）的模型上验证，证明了方法的通用性。

### 6. 主要结论与发现
*   **性能领先**：在 10% KV 缓存预算下，StructKV 在 LongBench 上的平均得分显著优于 FastKV 和 GemFilter。
*   **长文本鲁棒性**：在 128K 长度的 RULER 测试中，StructKV 表现出极强的韧性，而依赖局部快照的方法在超长距离下会出现性能骤降。
*   **动态性至关重要**：实验发现，随着模型变大变深，最佳压缩层会从第 12 层（7B 模型）推移到第 28 层（32B 模型），证明了动态检测的必要性。

### 7. 优点（亮点）
*   **全局视角**：通过累积注意力分数，有效防止了“重要但暂时休眠”的 token 被误删。
*   **自适应能力**：动态枢轴检测解决了不同模型需要手动调参压缩层的问题，具有极强的工程实用性。
*   **解耦策略**：巧妙地平衡了预填充阶段的计算精度与生成阶段的显存占用。

### 8. 不足与局限
*   **验证长度上限**：受限于计算资源，实验最高只验证到 128K token，尚未在百万级（1M+）真实场景下验证稳定性。
*   **架构覆盖**：目前主要针对标准稠密 Transformer 架构，对于混合专家模型（MoE）或非注意力架构（如 SSM/Mamba）的适用性尚待研究。
*   **硬件依赖**：虽然开销极低，但在显存带宽极度受限的边缘设备上，额外的向量运算可能仍有优化空间。
