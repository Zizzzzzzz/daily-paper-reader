## 摘要
视频大语言模型（Video-LLMs）在视频理解方面表现卓越，但在自回归生成过程中面临高推理延迟。投机解码（SD）通过采用“草稿-验证”范式来缓解这一问题，然而现有方法受限于僵化的精确匹配规则，严重限制了加速潜力。为了填补这一空白，我们提出了 LVSpec，这是首个专为 Video-LLMs 设计的无需训练的松散投机解码框架。基于生成过程是由大量视觉无关填充词（允许松散验证）中的稀疏视觉相关锚点（要求严格验证）所主导的洞察，LVSpec 采用了一种轻量级的视觉相关 Token 识别方案来准确识别后者。为了进一步最大化接受率，我们还增加了一个位置偏移容忍机制，有效挽救了位置不匹配但语义等价的 Token。实验表明，LVSpec 实现了高保真度和高速度：在保留超过 99.8% 目标性能的同时，将 Qwen2.5-VL-32B 的推理速度提升了 2.70 倍，将 LLaVA-OneVision-72B 提升了 2.94 倍。值得注意的是，与针对 Video-LLMs 的最先进（SOTA）无需训练的投机解码方法相比，它将平均接受长度和加速比分别提高了 136% 和 35%。

## Abstract
Video Large Language Models (Video-LLMs) excel in video understanding but suffer from high inference latency during autoregressive generation. Speculative Decoding (SD) mitigates this by applying a draft-and-verify paradigm, yet existing methods are constrained by rigid exact-match rules, severely limiting the acceleration potential. To bridge this gap, we propose LVSpec, the first training-free loosely SD framework tailored for Video-LLMs. Grounded in the insight that generation is governed by sparse visual-relevant anchors (mandating strictness) amidst abundant visual-irrelevant fillers (permitting loose verification), LVSpec employs a lightweight visual-relevant token identification scheme to accurately pinpoint the former. To further maximize acceptance, we augment this with a position-shift tolerant mechanism that effectively salvages positionally mismatched but semantically equivalent tokens. Experiments demonstrate that LVSpec achieves high fidelity and speed: it preserves >99.8 of target performance while accelerating Qwen2.5-VL-32B by 2.70x and LLaVA-OneVision-72B by 2.94x. Notably, it boosts the mean accepted length and speedup ratio by 136% and 35% compared to SOTA training-free SD methods for Video-LLMs.

### 1. 论文的核心问题与整体含义
视频大语言模型（Video-LLMs）在处理长视频时，由于自回归生成的特性，推理延迟极高。现有的**投机解码（Speculative Decoding, SD）**技术虽然能通过“小模型起草-大模型验证”来加速，但存在一个核心瓶颈：**严格精确匹配规则**。即草稿模型生成的 Token 必须与目标模型完全一致才能被接受。

论文指出，在视频理解任务中，并非所有 Token 都同等重要。生成内容由少数**视觉相关锚点**（如具体的物体、动作描述）和大量**视觉无关填充词**（如连词、标点、语法助词）组成。传统的严格验证会因填充词的微小差异而拒绝整个序列，限制了加速潜力。

### 2. 论文提出的方法论：LVSpec
LVSpec 是首个专为 Video-LLMs 设计的**无需训练（Training-free）**的松散投机解码框架。其核心流程包括：

*   **视觉相关 Token 识别（Visual-Relevant Identification）**：
    *   在解码每一步，计算文本 Token 的隐藏状态与视觉特征隐藏状态之间的**余弦相似度**。
    *   为了提高区分度，采用 **Top-N 均值策略**：仅计算文本 Token 与最相关的 N 个视觉 Token 的相似度均值，从而精准识别出承载视觉信息的“锚点”Token。
*   **视觉语义引导的松散验证（Visual-Semantic Guided Verification）**：
    *   设定阈值 $\lambda$，将相似度较低的 Token 视为“视觉无关填充词”。
    *   **策略**：对视觉相关 Token 执行严格匹配（确保不产生事实幻觉）；对视觉无关 Token 执行松散验证（即使字面不一致也予以接受）。
*   **位置偏移容忍机制（Position-Shift Tolerant, PST）**：
    *   针对草稿模型因多加了一个词（如 "the"）或描述顺序微调导致的位置错位，只要目标模型预测的 Token 出现在草稿序列的近邻范围内，即视为匹配成功，进一步提升接受长度。
