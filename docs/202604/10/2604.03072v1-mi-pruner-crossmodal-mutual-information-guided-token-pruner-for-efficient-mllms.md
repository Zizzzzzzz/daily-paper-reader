## 摘要
对于多模态大语言模型（MLLMs），视觉信息相对于文本而言较为稀疏。因此，针对高效推理的视觉剪枝研究应运而生。目前的方法通常根据视觉编码器或 LLM 解码器中的注意力分数来衡量 Token 的重要性，进而保留高注意力分数的视觉 Token 并剪除其余部分。在本文中，我们提出了一种不同且更精准的方法。我们不依赖于特定机制的信号，而是在视觉和文本特征交互之前，直接计算两者之间的互信息（MI）。这使我们能够在特征层面显式地衡量跨模态依赖性。我们的 MI-Pruner 简单、高效且具有非侵入性，无需访问内部注意力图或修改模型架构。实验结果表明，我们的方法在极低延迟的情况下优于以往基于注意力的剪枝方法。

## Abstract
For multimodal large language models (MLLMs), visual information is relatively sparse compared with text. As a result, research on visual pruning emerges for efficient inference. Current approaches typically measure token importance based on the attention scores in the visual encoder or in the LLM decoder, then select visual tokens with high attention scores while pruning others. In this paper, we pursue a different and more surgical approach. Instead of relying on mechanism-specific signals, we directly compute Mutual Information (MI) between visual and textual features themselves, prior to their interaction. This allows us to explicitly measure crossmodal dependency at the feature levels. Our MI-Pruner is simple, efficient and non-intrusive, requiring no access to internal attention maps or architectural modifications. Experimental results demonstrate that our approach outperforms previous attention-based pruning methods with minimal latency.

### 论文总结：MI-Pruner —— 跨模态互信息引导的高效 MLLM 视觉 Token 剪枝器

#### 1. 核心问题与整体含义（研究动机和背景）
随着多模态大语言模型（MLLM）规模的扩大，高分辨率图像输入的视觉 Token 数量剧增，导致自注意力机制的计算开销呈平方级增长。现有的视觉 Token 剪枝方法主要依赖于视觉编码器或 LLM 解码器内部的**注意力分数（Attention Scores）**。
然而，作者指出基于注意力的剪枝存在以下缺陷：
*   **解释性不足与偏差**：注意力分数受位置偏差、注意力汇聚（Attention Sinks）和多头多样性影响，并不完全等同于信息重要性。
*   **实现瓶颈**：提取内部注意力矩阵会增加内存开销，且与 FlashAttention 等加速算子不兼容。
*   **研究动机**：回归信息论本质，直接通过计算视觉与文本特征之间的**互信息（Mutual Information, MI）**来衡量 Token 的相关性，实现一种简单、高效且模型无关的剪枝方案。

#### 2. 方法论：核心思想与技术细节
MI-Pruner 的核心思想是在**投影空间（Projection Space）**中，通过最大化跨模态互信息来识别并保留与查询（Query）最相关的视觉 Token。

*   **核心流程**：
    1.  **特征提取与归一化**：提取投影后的视觉嵌入 $V$ 和文本嵌入 $T$，并映射到单位超球面上。
    2.  **分布构建**：基于玻尔兹曼分布计算视觉-文本（跨模态）和视觉-视觉（模态内）的相似度矩阵，通过 Softmax 转化为条件概率分布 $p(t_j|v_i)$ 和 $p(v_j|v_i)$。
    3.  **互信息量化**：利用**点向互信息（PMI）**衡量 Token 级的相关性。
        *   **跨模态相关性 ($S_{cross}$)**：衡量视觉 Token 与文本查询的语义对齐程度。
        *   **模态内冗余 ($S_{self}$)**：衡量视觉 Token 之间的结构重复性。
    4.  **贪婪搜索与剪枝**：定义评分函数 $S_i = \lambda S_{cross} - (1-\lambda) S_{self}$。通过贪婪搜索算法，在满足预算 $N_{keep}$ 的前提下，选择边际增益最大的 Token 集合。
*   **关键技术**：采用**最大化聚合（Maximal Aggregation）**而非全局平均，以捕捉最显著的语义对齐信号（“核心词”），从而提高对噪声的鲁棒性。

*   **数据集与场景**：

*   **Benchmark 与模型**：

*   **对比方法**：

*   **算力表现**：论文重点分析了推理延迟。MI-Pruner 在 LLaVA-1.5-7B 上，保留 64 个 Token 时的延迟约为 **77ms**，显著低于 SparseVLM (93ms) 和 VisPruner (89ms)。
*   **训练时长**：由于该方法是**训练无关（Training-free）**的插件式模块，因此不需要额外的训练时长。

#### 5. 实验数量与充分性
*   **实验规模**：作者在 10 多个主流基准测试集上进行了广泛实验，涵盖了从 2B 到 30B 不同参数规模的模型。
*   **消融实验**：针对聚合策略（Max vs. Avg）、平衡因子 $\lambda$、温度系数 $\tau$ 以及归一化方式（Softmax vs. MinMax）进行了详细讨论。
*   **客观性与公平性**：实验对比了多种 SOTA 方法，并提供了可视化结果（如剪枝热力图）来验证其捕获查询相关区域的能力。实验设计考虑了闭口问答（Yes/No）和开口推理等多种任务，评估较为全面。

#### 6. 主要结论与发现
*   **性能领先**：MI-Pruner 在多个基准测试中达到了 SOTA 性能，尤其在极高剪枝率（如仅保留 32 或 64 个 Token）下，性能下降远小于基于注意力的方法。
*   **幻觉抑制**：在 POPE 评测中，MI-Pruner 能够更好地保持 Yes/No 分布的平衡，减少了因误删关键物体 Token 而导致的幻觉。
*   **高效性**：由于不需要处理复杂的注意力矩阵，MI-Pruner 的推理速度极快，且内存占用更低。
*   **模型无关性**：成功应用于最新的 Qwen3VL 系列模型，证明了其在动态分辨率和新型架构下的泛化能力。

#### 7. 优点
*   **理论严谨**：将 Token 剪枝建模为子模态函数最大化问题，具有坚实的信息论基础。
*   **非侵入性**：作为“手术刀”式的插件，无需修改模型内部架构，不依赖特定层的注意力图，易于部署。
*   **查询感知**：相比于纯视觉剪枝，MI-Pruner 能够根据用户 Prompt 动态调整保留区域，解释性更强。

#### 8. 不足与局限
*   **先验假设**：模型假设视觉 Token 的先验概率是均匀分布的（即每个 patch 出现概率相等），这在实际摄影构图中可能不成立（如中心区域通常更重要）。
*   **条件独立性假设**：为了计算简便，假设了视觉 Token 间的条件独立性，这在处理需要多个 patch 共同表达的复杂语义时可能存在偏差。
*   **文本剪枝缺失**：目前仅针对视觉 Token 进行压缩，未涉及长文本 Prompt 的压缩，而长文本在某些场景下也是计算瓶颈。
