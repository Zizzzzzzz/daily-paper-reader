## 摘要
大语言视觉模型（LVLMs）由于语言解码器需要处理海量的视觉 token，面临着极高的推理成本。现有的剪枝方法往往会导致显著的性能下降，因为视觉 token 的不可逆移除会引起隐藏状态的分布偏移，使其偏离预训练时的全 token 模式。为了解决这一问题，我们提出了表示一致性剪枝器（RCP），这是一个将累积视觉 token 剪枝与延迟修复机制相结合的新颖框架。具体而言，我们引入了一个交叉注意力剪枝器，利用大语言模型（LLM）的内在注意力作为基准来预测累积掩码，从而确保跨层 token 缩减的一致性和单调性。为了补偿由此产生的信息损失，我们设计了一个名为 DRA 的延迟修复适配器，它能够缓存被剪枝 token 的精华，并专门对答案生成 token 应用基于 FiLM 的调制。我们采用修复损失来使剪枝后的表示在一阶和二阶统计量上与全 token 教师模型保持一致。RCP 非常高效，因为它仅训练轻量级的插件模块，同时允许在推理时进行物理 token 丢弃。在 LVLM 基准测试上的广泛实验表明，RCP 在仅有轻微平均准确度下降的情况下，可移除高达 88.9% 的视觉 token 并减少高达 85.7% 的 FLOPs，且在多个常用基准测试中优于先前无需微调原始模型的方法。

## Abstract
Large Vision-Language Models (LVLMs) suffer from prohibitive inference costs due to the massive number of visual tokens processed by the language decoder. Existing pruning methods often lead to significant performance degradation because the irreversible removal of visual tokens causes a distribution shift in the hidden states that deviates from the pre-trained full-token regime. To address this, we propose Representation Consistency Pruner, which we refer to as RCP, as a novel framework that integrates cumulative visual token pruning with a delayed repair mechanism. Specifically, we introduce a cross-attention pruner that leverages the intrinsic attention of the LLM as a baseline to predict cumulative masks, ensuring consistent and monotonic token reduction across layers. To compensate for the resulting information loss, we design a delayed repair adapter denoted as DRA, which caches the essence of pruned tokens and applies FiLM-based modulation specifically to the answer generation tokens. We employ a repair loss to match the first and second-order statistics of the pruned representations with a full-token teacher. RCP is highly efficient because it trains only lightweight plug-in modules while allowing for physical token discarding at inference. Extensive experiments on LVLM benchmarks demonstrate that RCP removes up to 88.9\% of visual tokens and reduces FLOPs by up to 85.7\% with only a marginal average accuracy drop, and outperforms prior methods that avoid fine-tuning the original model on several widely used benchmarks.

*   **核心问题**：LVLM 在处理高分辨率图像时会产生大量视觉标记（Visual Tokens），导致语言解码阶段的计算开销和内存占用（如 KV Cache）巨大。
*   **研究动机**：现有的剪枝方法虽然能减少标记数量，但往往会导致严重的性能下降。作者发现，**分布偏移（Distribution Shift）**是主因——即不可逆地移除标记会改变后续层的隐藏状态分布，这种偏差随层深增加而累积（Representation Drift），最终破坏模型的推理能力。
*   **整体含义**：RCP 旨在通过维持剪枝前后表示的一致性，在不微调原始模型参数的前提下，实现极高比例的标记压缩。

### 2. 方法论：核心思想与关键技术
RCP 框架由两个核心组件组成，采用交错插入解码器层的方式工作：
*   **残差交叉注意力剪枝器 (Residual Cross-Attention Pruner)**：
    *   **核心思想**：结合 LLM 固有的注意力权重（作为基准）与可学习的查询（Query）来预测标记重要性。
    *   **技术细节**：通过 Gumbel-Sigmoid 生成离散掩码，并采用**累积掩码机制**（$\tilde{m}^{(\ell)} = \tilde{m}^{(\ell-1)} \odot m^{(\ell)}$），确保被丢弃的标记不会在深层重新出现，维持单调递减。
*   **延迟修复适配器 (Delayed Repair Adapter, DRA)**：
    *   **核心思想**：在深层对被剪枝的信息进行补偿。
    *   **技术细节**：缓存被剪枝标记的语义精华（特征均值）和位置信息（掩码嵌入），利用 **FiLM (Feature-wise Linear Modulation)** 调制技术，动态调整答案生成阶段的隐藏状态。
*   **分布对齐损失 (Repair Loss)**：
    *   使用 **W2 距离（Wasserstein-2 distance）** 的变体，通过匹配剪枝模型（学生）与全标记模型（教师）隐藏状态的一阶（均值）和二阶（方差）统计量，强制实现表示一致性。

### 6. 主要结论与发现
*   **高效压缩**：RCP 在保留仅 64 个标记（压缩率 88.9%）的情况下，FLOPs 减少了 **85.7%**，而平均准确率下降极小（约 5%）。
*   **分布对齐的重要性**：实验证明，仅匹配均值（一阶统计量）效果不如同时匹配均值和方差（二阶统计量），证明了完整分布修复的必要性。
*   **位置敏感性**：在解码器的早期阶段进行剪枝，并在接近输出的深层进行修复，能获得最佳的性能平衡。

### 7. 优点（亮点）
*   **无需微调主模型**：保持 LVLM 骨干参数冻结，仅训练轻量级插件，极大地降低了部署成本。
*   **解决分布偏移**：通过 DRA 和修复损失显式处理了剪枝带来的“表示漂移”问题，这是相比于其他单纯 Top-K 剪枝方法的显著优势。
*   **推理友好**：支持物理上的标记丢弃，能直接减少 KV Cache 负担，提升实际推理速度。

### 8. 不足与局限
*   **任务特定训练**：虽然训练开销小，但仍需在特定数据集（如 VQAv2）上进行一轮参数优化，并非完全的“即插即用”（Plug-and-play）。
