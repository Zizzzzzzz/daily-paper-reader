## 摘要
多模态大语言模型（MLLM）在文档理解和密集场景感知等细粒度任务中需要高分辨率视觉输入。然而，当前的全局分辨率缩放范式不加区分地将大量视觉冗余 token 注入具有二次复杂度的自注意力机制中，在忽略空间稀疏性和查询意图的同时，严重制约了推理吞吐量。为解决这一问题，我们提出了 Q-Zoom，这是一个以高效的“由粗到细”方式运行的查询感知自适应高分辨率感知框架。首先，当粗粒度全局特征足够时，轻量级动态门控网络（Dynamic Gating Network）会安全地跳过高分辨率处理。其次，对于需要细粒度感知的查询，自蒸馏区域建议网络（SD-RPN）直接从中间特征空间精确地定位与任务相关的感兴趣区域（RoI）。为了高效优化这些模块，门控网络使用一致性感知生成策略来推导确定性的路由标签，而 SD-RPN 则采用完全自监督的蒸馏范式。随后，通过连续时空对齐方案和针对性微调，将密集的局部 RoI 与粗粒度的全局布局无缝融合。大量实验表明，Q-Zoom 建立了领先的帕累托前沿。以 Qwen2.5-VL-7B 作为主要实验平台，Q-Zoom 在文档与 OCR 基准测试中将推理速度提升了 2.52 倍，在高分辨率场景下提升了 4.39 倍，同时达到了与基线相当的峰值准确率。此外，当配置为最大感知保真度时，Q-Zoom 在上述基准测试中分别超过基线峰值性能 1.1% 和 8.1%。这些显著的改进可以无缝迁移到 Qwen3-VL、LLaVA 以及新兴的基于强化学习（RL）的“带图思考”模型中。项目主页见 https://yuhengsss.github.io/Q-Zoom/。

## Abstract
MLLMs require high-resolution visual inputs for fine-grained tasks like document understanding and dense scene perception. However, current global resolution scaling paradigms indiscriminately flood the quadratic self-attention mechanism with visually redundant tokens, severely bottlenecking inference throughput while ignoring spatial sparsity and query intent. To overcome this, we propose Q-Zoom, a query-aware adaptive high-resolution perception framework that operates in an efficient coarse-to-fine manner. First, a lightweight Dynamic Gating Network safely bypasses high-resolution processing when coarse global features suffice. Second, for queries demanding fine-grained perception, a Self-Distilled Region Proposal Network (SD-RPN) precisely localizes the task-relevant Region-of-Interest (RoI) directly from intermediate feature spaces. To optimize these modules efficiently, the gating network uses a consistency-aware generation strategy to derive deterministic routing labels, while the SD-RPN employs a fully self-supervised distillation paradigm. A continuous spatio-temporal alignment scheme and targeted fine-tuning then seamlessly fuse the dense local RoI with the coarse global layout. Extensive experiments demonstrate that Q-Zoom establishes a dominant Pareto frontier. Using Qwen2.5-VL-7B as a primary testbed, Q-Zoom accelerates inference by 2.52 times on Document & OCR benchmarks and 4.39 times in High-Resolution scenarios while matching the baseline's peak accuracy. Furthermore, when configured for maximum perceptual fidelity, Q-Zoom surpasses the baseline's peak performance by 1.1% and 8.1% on these respective benchmarks. These robust improvements transfer seamlessly to Qwen3-VL, LLaVA, and emerging RL-based thinking-with-image models. Project page is available at https://yuhengsss.github.io/Q-Zoom/.

#### 1. 核心问题与整体含义（研究动机和背景）
当前的多模态大语言模型（MLLM）在处理文档理解、OCR和密集场景感知等任务时，通常依赖提高输入图像的分辨率。然而，现有的全局缩放范式存在两个严重缺陷：
*   **计算冗余（二次方瓶颈）**：不加区分地增加视觉 token 数量会导致自注意力机制的计算量呈平方级增长，严重降低推理速度。
*   **忽视查询意图与空间稀疏性**：并非所有问题都需要高分辨率（如“图中有什么”），且图像中大部分背景区域对回答特定问题（如“车牌号是多少”）是无用的。
**研究动机**：开发一种“由粗到细”的感知框架，仅在必要时、针对必要的区域进行高分辨率处理，从而在保持精度的同时大幅提升效率。

#### 2. 方法论：核心思想与关键技术
Q-Zoom 提出了一个两阶段的自适应感知流程，直接在模型的中间特征空间操作：
*   **动态门控网络（Dynamic Gating Network）**：
    *   **核心思想**：判断当前查询是否仅靠低分辨率特征即可回答。
    *   **技术细节**：利用中间层的隐藏状态，通过一个轻量级分类头输出概率。
    *   **训练策略**：采用“一致性感知样本生成”，通过对比模型在不同分辨率下的表现自动生成标签（若低分辨率错而高分辨率对，则标记为需要细化），无需人工标注。
*   **自蒸馏区域建议网络（SD-RPN）**：
    *   **核心思想**：在需要细化时，精准定位与任务相关的感兴趣区域（RoI）。
    *   **技术细节**：复用模型中间层的交叉注意力图，通过“自蒸馏”范式训练。它会过滤掉无意义的“汇聚 token”（sink tokens），并使用三态标签（前景、背景、忽略区）来生成高质量的伪标签。
*   **时空对齐与针对性微调（Post-SFT）**：
    *   **核心思想**：解决局部高清 RoI 与全局粗略布局之间的空间错位。
    *   **技术细节**：引入连续时空位置编码（基于 MRoPE），通过插值将 RoI 坐标映射回原图。随后通过挖掘“硬样本”（即基准模型对但加入 RoI 后反而错的样本）进行针对性微调，教模型如何融合双流信息。

#### 3. 实验设计
*   **数据集/场景**：
    *   **文档与 OCR**：DocVQA, InfoVQA, ChartQA, OCRBench, TextVQA。
    *   **高分辨率与视觉中心任务**：V*, MME-RealWorld, HR-Bench (4K/8K)。
    *   **通用能力**：MMStar, MME。
*   **Benchmark 与对比方法**：
    *   **基准模型**：LLaVA-1.5 (7B/13B), Qwen2.5-VL (3B/7B), Qwen3-VL (4B)。
    *   **对比范式**：无训练启发式方法（如 ViCrop）、基于强化学习的方法（如 Thyme, DeepEyes）、以及直接缩放方法（S²）。

#### 4. 资源与算力
*   **硬件**：实验主要在单张 **NVIDIA RTX A6000 GPU** 上进行。
*   **训练细节**：
    *   使用 AdamW 优化器，学习率在 $1\times10^{-4}$ 到 $1\times10^{-6}$ 之间。
    *   训练周期仅为 1 个 epoch，表现出极高的训练效率。
    *   SD-RPN 训练使用了约 185K 样本，Post-SFT 仅需约 7K 硬样本。

#### 5. 实验数量与充分性
*   **实验规模**：论文涵盖了从 3B 到 13B 不同规模的多个模型家族，并在 10 多个主流基准测试上进行了验证。
*   **消融实验**：非常充分。作者详细探讨了：
    1.  核心组件（RPN, SFT, Gate）的各自贡献。
    2.  中间层深度（B）和 RPN 层数（R）的影响。
    3.  伪标签生成的阈值敏感度。
    4.  数据规模对性能的提升曲线。
*   **客观性**：通过与最新的 RL 驱动模型（如 Thyme）对比吞吐量和精度，证明了其在帕累托前沿（Pareto Frontier）上的优越性，实验设计公平且具有说服力。

#### 6. 主要结论与发现
*   **效率飞跃**：在 Qwen2.5-VL-7B 上，Q-Zoom 在文档任务中实现 **2.52倍** 加速，在高分辨率任务中实现 **4.39倍** 加速。
*   **精度提升**：在限制视觉 token 数量的情况下，Q-Zoom 的表现超过了使用 4 倍 token 数量的暴力缩放基准。在最高感知配置下，精度比基线提升了 **1.1% - 8.1%**。
*   **通用性**：该框架可作为插件应用于 RL 训练的“思考型”模型（如 ZwZ-Qwen），并能进一步提升其性能。

#### 7. 优点
*   **查询感知**：避免了对简单问题的过度计算，实现了真正的按需分配资源。
*   **无需人工标注**：通过自蒸馏和一致性检查，完全利用模型自身能力生成训练信号。
*   **单次预填充（Single Prefilling Pass）**：相比于需要多次推理或长链思考（CoT）的方法，Q-Zoom 在中间层直接决策，极大地降低了延迟。
*   **即插即用**：对现有 MLLM 架构改动极小，易于迁移。

#### 8. 不足与局限
*   **架构依赖**：对于不支持位置编码动态插值或缺乏中间层视觉定位能力的旧模型（如 LLaVA-1.5），性能提升主要来自 RoI 提取，而无法完美解决空间对齐问题。
*   **级联误差风险**：如果第一阶段的门控网络误判（将复杂问题视为简单），或者 SD-RPN 漏掉了关键区域，模型将无法通过后续步骤挽回错误。
*   **极端小目标**：虽然提升显著，但在极度密集的场景下，单 RoI 策略可能不足以覆盖所有关键细节（未来可能需要多 RoI 支持）。
