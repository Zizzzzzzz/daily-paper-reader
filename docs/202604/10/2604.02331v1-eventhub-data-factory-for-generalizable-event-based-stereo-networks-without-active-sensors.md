## 摘要
我们提出了 EventHub，这是一种用于训练深度事件立体网络的新型框架。该框架无需依赖昂贵的主动传感器获取真值标注，而是利用标准的彩色图像。通过这些图像，我们利用最先进的新视角合成技术推导出代理标注和代理事件；或者在图像已与事件数据配对的情况下，直接推导出代理标注。利用我们数据工厂生成的训练集，我们将 RGB 领域先进的立体匹配模型重新用于处理事件数据，从而获得了具有前所未有泛化能力的全新事件立体模型。在广泛使用的事件立体数据集上的实验证明了 EventHub 的有效性，并展示了相同的数据蒸馏机制如何提高 RGB 立体基础模型在夜间场景等挑战性条件下的准确性。

## Abstract
We propose EventHub, a novel framework for training deep-event stereo networks without ground truth annotations from costly active sensors, relying instead on standard color images. From these images, we derive either proxy annotations and proxy events through state-of-the-art novel view synthesis techniques, or simply proxy annotations when images are already paired with event data. Using the training set generated by our data factory, we repurpose state-of-the-art stereo models from RGB literature to process event data, obtaining new event stereo models with unprecedented generalization capabilities. Experiments on widely used event stereo datasets support the effectiveness of EventHub and show how the same data distillation mechanism can improve the accuracy of RGB stereo foundation models in challenging conditions such as nighttime scenes.

*   **核心问题**：事件相机（Event Camera）在高速运动和高动态范围场景下具有显著优势，但其**立体匹配（Stereo Matching）**网络的发展受限于高质量标注数据的匮乏。

#### 2. 方法论：核心思想与关键技术
EventHub 的核心思想是通过**跨模态蒸馏**和**新视角合成（NVS）**，将 RGB 领域的成熟知识迁移到事件领域。主要包含两个路径：

*   **路径 A：基于新视角合成的合成数据生成**
    *   利用单目 RGB 序列，通过 COLMAP 恢复位姿，使用改进的 **SVRaster**（一种辐射场渲染技术）重建场景。
    *   **虚拟轨迹构建**：设计局部（Local）和全局（Global）虚拟相机轨迹，模拟相机运动。
    *   **运动自适应渲染**：利用 ESIM 模拟器从渲染的 RGB 帧中生成代理事件流，同时渲染高精度的深度图作为代理标注。
    *   **关键公式/细节**：引入了基于深度图和位姿计算的光流场 $F$，动态调整渲染时间步长 $\Delta\tau$ 以避免伪影；设计了基于体素大小的置信度度量 $C_{Vsize}$ 来过滤噪声标注。
*   **路径 B：跨模态立体匹配蒸馏**
    *   在已有的 RGB-Event 混合立体数据集中，直接利用预训练的 RGB 立体基础模型（如 FoundationStereo）处理 RGB 图像对，生成初始深度。
    *   通过相机外参将 RGB 坐标系下的深度重投影到事件相机坐标系，实现对真实事件数据的自动标注。
*   **模型重用（Repurposing）**：将 RGB 立体网络（如 FoundationStereo, StereoAnywhere）的输入层适配为事件张量（Tencode 编码），直接继承 RGB 预训练权重进行微调。

#### 6. 主要结论与发现
*   **泛化能力飞跃**：使用 EventHub 训练的模型在跨域测试（M3ED/MVSEC）中显著优于直接用 LiDAR 监督的模型，误差降低最高达 50%。

*   **双向促进**：训练好的事件立体网络可以反过来为夜间 RGB 图像提供高质量深度标注，显著提升 RGB 模型在极端环境下的表现。

#### 7. 优点
*   **低成本高效率**：彻底摆脱了对 LiDAR 的依赖，使得任何拥有 RGB 相机的人都能生成训练数据。
*   **高质量标注**：利用 NVS 技术生成的标注是稠密且亚像素准确的，解决了 LiDAR 标注空洞的问题。
*   **即插即用**：提出的重用策略证明了 RGB 领域的基础模型（Foundation Models）可以无缝迁移至事件领域。

*   **静态场景限制**：目前基于 NVS 的数据生成主要针对静态场景，对于包含大量动态物体的复杂场景，其模拟真实感可能受限。

*   **模拟器差距**：ESIM 生成的代理事件与真实传感器捕获的事件之间仍存在一定的“模态鸿沟”（Sim-to-Real Gap）。
