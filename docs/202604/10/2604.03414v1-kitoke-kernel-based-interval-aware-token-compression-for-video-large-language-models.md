## 摘要
视频大语言模型 (Video LLMs) 在视频理解任务上表现出色，但由于视觉 Token 数量庞大，面临着高昂的推理成本。我们提出了 KiToke，这是一种无需训练且与查询无关的 Token 压缩方法，它在减少时空冗余的同时保留了关键视觉信息。我们的方法利用基于核的冗余度量从全局角度估计 Token 的多样性，实现了在极端 Token 预算下依然有效的内容自适应选择，并进一步引入了轻量级的时序区间构建与区间感知 Token 合并，以保持时序连贯性。与以往依赖局部或片段级启发式方法的研究不同，KiToke 显式地捕捉了整个视频的全局冗余，从而实现了更高效的 Token 利用。在多个视频理解基准测试和 Video LLM 骨干网络上的广泛实验表明，KiToke 一致优于现有的无需训练的压缩方法，尤其是在保留率低至 1% 的激进情况下，性能提升尤为显著。

## Abstract
Video Large Language Models (Video LLMs) achieve strong performance on video understanding tasks but suffer from high inference costs due to the large number of visual tokens. We propose KiToke, a training-free, query-agnostic token compression approach that reduces spatiotemporal redundancy while preserving critical visual information. Our method estimates token diversity globally using a kernel-based redundancy measure, enabling content-adaptive selection that remains effective under extreme token budgets, and further introduces a lightweight temporal interval construction with interval-aware token merging to maintain temporal coherence. Unlike prior methods that rely on local or segment-level heuristics, KiToke explicitly captures global redundancy across an entire video, leading to more efficient token utilization. Extensive experiments on multiple video understanding benchmarks and Video LLM backbones demonstrate that KiToke consistently outperforms existing training-free compression methods, with particularly large gains at aggressive retention ratios down to 1%.

### 1. 核心问题与整体含义（研究动机和背景）
视频大语言模型（Video LLMs）在处理长视频时，会产生海量的视觉 Token（令牌），这导致 Transformer 架构的推理成本（计算量和显存占用）呈平方级增长。现有的压缩方法主要存在两个痛点：
*   **时空冗余处理不足：** 视频中存在大量重复背景或缓慢运动，现有方法多采用局部启发式策略，难以捕捉跨越长时段的全局冗余。
*   **极端预算下的性能崩溃：** 当 Token 保留率极低（如 1%）时，现有方法往往会丢失关键信息或破坏视频的时序连贯性。
**KiToke** 的研究动机在于提出一种**无需训练（Training-free）**、**与查询无关（Query-agnostic）**的压缩方案，通过全局多样性估计和内容自适应的时间区间划分，在极低预算下保留视频的核心语义。

### 2. 方法论：核心思想与关键技术
KiToke 主要由三个核心模块组成：

*   **基于核的多样性估计（Kernel-based Diversity Estimation）：**
    *   **核心思想：** 将 Token 压缩视为全局多样性最大化问题。
    *   **技术细节：** 使用高斯核函数（Gaussian Kernel）计算每个 Token 与视频中所有其他 Token 的相似度，通过核密度估计（KDE）计算每个 Token 的密度得分。密度越高，代表冗余度越高。
    *   **公式逻辑：** 多样性得分定义为密度的倒数。采用**枢轴采样（Pivotal Sampling）**而非简单的 Top-K 选择，以确保在冗余组中也能保留代表性样本，提高视觉覆盖率。
*   **内容自适应的时间区间构建（Temporal Interval Construction）：**
    *   **核心思想：** 识别视频中的语义转折点，避免跨场景合并 Token。
    *   **技术细节：** 结合“位置差异”和“最佳匹配差异”来衡量帧间变化。通过计算当前变化量相对于局部时序动态的偏差（绝对偏差和相对偏差），精准捕捉突发的场景切换或动作变化，从而构建不等长的时间区间。
*   **区间感知 Token 合并（Interval-aware Token Merging）：**
    *   **核心思想：** 将未选中的 Token 聚合到保留的 Token 中，减少信息损失。
    *   **技术细节：** 在每个时间区间内，根据余弦相似度将未选中 Token 分配给最相似的保留 Token，并利用多样性得分进行加权平均合并，确保独特的视觉特征在聚合后仍具影响力。

*   **算力开销：** 论文强调了 KiToke 的高效性。在 LLaVA-OneVision 上，10% 保留率下实现了 **6.8x** 的首字延迟（Prefill Time）加速；在 1% 保留率下实现了 **12.5x** 的加速。
*   **训练时长：** 由于是 **无需训练（Training-free）** 的方法，该方案不需要额外的训练算力，直接在推理阶段即插即用。

### 5. 实验数量与充分性
*   **实验规模：** 论文在 3 个骨干模型、4 个大型基准测试上进行了详尽测试，涵盖了从 25% 到 1% 的多种保留率梯度。

### 6. 主要结论与发现
*   **全局视角至关重要：** 显式捕捉全视频范围内的冗余（而非局部片段）能显著提升 Token 利用率。
*   **极端压缩的可行性：** KiToke 在仅保留 1% Token 的情况下，依然能保持 LLaVA-OneVision 约 90% 的原始性能，远超同类方法。
*   **时序一致性：** 内容自适应的区间划分能有效防止语义模糊，是保持长视频推理能力的关键。
*   **通用性：** 该方法在不同 Tokenizer（如 Qwen3 的多分辨率 Token）和不同模型架构上均表现出良好的泛化能力。

### 7. 优点（亮点）
*   **极高的压缩效率：** 首次证明了在 1% 这种极低保留率下，视频 LLM 仍能完成复杂的理解任务。
*   **算法优雅且高效：** 结合了统计学中的核密度估计和枢轴采样，理论支撑扎实，且计算开销极低（Prefill 阶段仅需约 12-13ms 额外开销）。
*   **内容自适应：** 能够根据视频动态自动调整压缩策略，而非使用固定的步长或比例。

### 8. 不足与局限
*   **对特定架构的依赖：** 虽然具有通用性，但在 LLaVA-Video 和 Qwen3-VL 等具有复杂时序编码（如换行符 Token 或特定位置编码）的模型上，性能下降幅度比 LLaVA-OneVision 略大，说明压缩策略与模型原生时序设计的耦合仍有优化空间。
*   **查询无关的局限：** 作为一个与查询无关的方法，它无法根据用户具体问题（如“视频中穿红衣服的人在哪？”）定向保留 Token。如果关键信息在视觉上不显著（密度不高），可能会被误删。
*   **超参数敏感度：** 虽然消融实验显示 $\alpha$ 相对稳健，但在处理风格迥异的视频流时，可能仍需微调时间区间的阈值以达到最优效果。
