## 摘要
奇异值分解 (SVD) 已成为减轻视觉语言模型 (VLM) 计算负担的重要技术，而 VLM 在图像描述和视觉问答等任务中发挥着核心作用。尽管此前的多项研究已提出高效的 SVD 变体以实现低秩运算，但我们发现在实践中，在模型执行期间实现显著的延迟降低仍然具有挑战性。为了解决这一局限性，我们引入了一种新的计算模式，并以更细的粒度应用 SVD，从而在执行延迟方面实现了真实且可衡量的改进。此外，考虑到权重元素在相对重要性上存在差异，我们在 SVD 过程中自适应地为每个元素分配相对重要性，以更好地保持准确性，随后通过对权重和激活同时进行量化来扩展该框架，从而构建出高效的 VLM。总的来说，我们提出了加权 SVD (WSVD)，该方法在保持准确性的同时实现了超过 1.8 倍的解码加速，优于其他方法。我们在以下地址开源了代码：https://github.com/SAI-Lab-NYU/WSVD。

## Abstract
Singular Value Decomposition (SVD) has become an important technique for reducing the computational burden of Vision Language Models (VLMs), which play a central role in tasks such as image captioning and visual question answering. Although multiple prior works have proposed efficient SVD variants to enable low-rank operations, we find that in practice it remains difficult to achieve substantial latency reduction during model execution. To address this limitation, we introduce a new computational pattern and apply SVD at a finer granularity, enabling real and measurable improvements in execution latency. Furthermore, recognizing that weight elements differ in their relative importance, we adaptively allocate relative importance to each element during SVD process to better preserve accuracy, then extend this framework with quantization applied to both weights and activations, resulting in a highly efficient VLM. Collectively, we introduce~\textit{Weighted SVD} (WSVD), which outperforms other approaches by achieving over $1.8\times$ decoding speedup while preserving accuracy. We open source our code at: \href{https://github.com/SAI-Lab-NYU/WSVD}{\texttt{https://github.com/SAI-Lab-NYU/WSVD}

#### 1. 核心问题与整体含义（研究动机和背景）
视觉语言模型（VLMs）在图像描述、视觉问答等任务中表现卓越，但其巨大的计算需求和自回归生成过程中的内存带宽瓶颈限制了其实际部署。
*   **现有技术的局限性**：虽然奇异值分解（SVD）常用于模型压缩，但作者发现，在 VLM 的实际执行中，传统的 SVD 低秩分解往往无法降低延迟，甚至可能因重构 KV 向量时引入的多次内存访问而增加延迟。
*   **核心目标**：提出一种新的计算模式，通过细粒度的 SVD 处理和系统级优化，在显著降低 VLM 推理延迟的同时，通过加权机制和量化技术保持模型精度。

#### 2. 论文提出的方法论
WSVD 框架由三个关键组件组成：
*   **细粒度逐头 SVD（Per-head SVD）**：
    *   **核心思想**：不再对整个 Q/K/V 权重矩阵进行整体 SVD，而是针对每个注意力头（Attention Head）独立进行 SVD。
    *   **技术细节**：这种设计避免了在解码阶段重复加载大型共享潜变量，每个头只需加载其对应的低秩潜变量。公式上，将 $W_{Kh}$ 分解为 $A_{Kh} B_{Kh}$，使得内存占用和计算成本从全矩阵的级别降低到头级别，显著减少了 I/O 开销。
*   **加权局部微调（Weighted Local Finetuning）**：
    *   **核心思想**：并非所有权重都同等重要。利用 **Fisher 信息矩阵（FIM）** 来评估每个权重元素对损失函数的影响。
    *   **流程**：计算梯度平方的期望作为重要性得分，在 SVD 截断后，通过局部微调优化低秩矩阵，优先保护那些对精度敏感的“超级权重”。
*   **局部量化感知训练（Local QAT）**：
    *   在低秩模型基础上应用 W8A8/W8A4 量化。引入正交旋转矩阵（如 Hadamard 矩阵）来平滑激活值中的离群点（Outliers），并通过局部 QAT 进一步补偿量化带来的精度损失。
*   **系统级算子融合（Fused Kernel）**：
    *   使用 Triton 语言开发了定制化内核，将低秩重构过程直接集成到 **Flash Decoding** 流水中。这样中间重构的 K、V 向量无需写回显存（VRAM），直接在片上（On-chip）完成计算，极大提升了吞吐量。
