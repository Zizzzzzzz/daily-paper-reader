## 摘要
大语言模型（LLM）的推理服务范式正迅速向复杂的多智能体工作流转变，其中专业化智能体在海量共享上下文上进行协作。虽然低秩自适应（LoRA）能够让这些专业化智能体高效地共存于单个基座模型上，但它在推理服务过程中引入了关键的内存占用瓶颈。具体而言，独特的 LoRA 激活导致不同智能体之间的键值（KV）缓存产生分歧，使得传统的针对共享上下文的前缀缓存（prefix caching）失效。这迫使系统维护冗余的 KV 缓存，迅速使 GPU 显存饱和并降低吞吐量。为了应对这一挑战，我们推出了 ForkKV，这是一个针对多 LoRA 智能体工作流的推理服务系统，其核心借鉴了操作系统中一种新颖的内存管理范式：带有写时拷贝（CoW）的 fork。通过利用 LoRA 的结构特性，ForkKV 将 KV 缓存物理地解耦为一个海量的共享组件（类似于父进程的内存页）和轻量级的智能体特定组件（子进程的内存页）。为了支持这一机制，我们提出了一种 DualRadixTree 架构，允许新 fork 的智能体继承海量共享缓存，并对其轻量级的唯一缓存应用 CoW 语义。此外，为了保证高效执行，我们设计了 ResidualAttention，这是一种专门的算子内核，可直接在片上 SRAM 中重构解耦的 KV 缓存。在多种语言模型和不同任务的实际数据集上进行的全面评估表明，ForkKV 的吞吐量达到了最先进的多 LoRA 推理服务系统的 3.0 倍，且对生成质量的影响微乎其微。

## Abstract
The serving paradigm of large language models (LLMs) is rapidly shifting towards complex multi-agent workflows where specialized agents collaborate over massive shared contexts. While Low-Rank Adaptation (LoRA) enables the efficient co-hosting of these specialized agents on a single base model, it introduces a critical memory footprint bottleneck during serving. Specifically, unique LoRA activations cause Key-Value (KV) cache divergence across agents, rendering traditional prefix caching ineffective for shared contexts. This forces redundant KV cache maintenance, rapidly saturating GPU capacity and degrading throughput.   To address this challenge, we introduce ForkKV, a serving system for multi-LoRA agent workflows centered around a novel memory management paradigm in OS: fork with copy-on-write (CoW). By exploiting the structural properties of LoRA, ForkKV physically decouples the KV cache into a massive shared component (analogous to the parent process's memory pages) and lightweight agent-specific components (the child process's pages). To support this mechanism, we propose a DualRadixTree architecture that allows newly forked agents to inherit the massive shared cache and apply CoW semantics for their lightweight unique cache. Furthermore, to guarantee efficient execution, we design ResidualAttention, a specialized kernel that reconstructs the disaggregated KV cache directly within on-chip SRAM. Comprehensive evaluations across diverse language models and practical datasets of different tasks demonstrate that ForkKV achieves up to 3.0x the throughput of state-of-the-art multi-LoRA serving systems with a negligible impact on generation quality.

### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）应用从简单对话转向复杂的多智能体工作流（如 ReAct、MapReduce），系统通常需要在单个基座模型上同时挂载多个专门化的 LoRA 适配器。
*   **核心矛盾**：虽然 LoRA 权重很小，但不同适配器产生的激活值不同，导致即使输入完全相同的上下文，其生成的 KV Cache 也会产生分歧。
*   **瓶颈**：这使得传统的高效优化手段“前缀缓存（Prefix Caching）”失效。系统不得不为每个智能体维护一份完整的、冗余的 KV Cache，导致显存迅速耗尽，严重限制了并发处理能力和系统吞吐量。

### 2. 方法论：核心思想与关键技术
ForkKV 借鉴了操作系统中进程创建的 **fork** 与 **写时拷贝（Copy-on-Write, CoW）** 机制，提出了一种**解耦式 KV 缓存（Disaggregated KV Cache）**架构。

*   **核心思想**：将 KV Cache 物理拆分为两部分：
    1.  **bCache (Base Cache)**：由基座模型权重生成的、体积巨大的共享部分。
    2.  **rCache (Residual Cache)**：由 LoRA 适配器生成的、体积微小的残差部分。
*   **关键技术细节**：
    *   **DualRadixTree（双基数树）**：使用两棵树分别管理内存。Base 树按 Token ID 索引实现全局共享；Residual 树按 `(Token ID, Agent ID)` 索引管理智能体特有的状态。
    *   **Fork 语义与 CoW**：新智能体启动时，逻辑上“fork”父进程空间，继承共享的 bCache，仅在需要写入特有激活值时为 rCache 分配空间。
    *   **ResidualAttention 内核**：为了避免在显存（HBM）中重构完整 KV Cache 带来的开销，设计了自定义 Triton 内核。它在片上 SRAM 中实时重构 Key，并利用**矩阵结合律**将 Attention 计算拆分为 Base 和 Residual 两部分并行处理，最后融合输出。
    *   **延迟 RoPE（Deferred RoPE）**：由于 rCache 维度较低无法直接应用旋转位置编码，ForkKV 将 RoPE 操作延迟到 ResidualAttention 内核内部，在低秩矩阵上采样后再进行投影。

### 7. 优点（亮点）
*   **跨学科借鉴**：巧妙地将 OS 的内存管理思想（Fork/CoW）引入 LLM 推理系统，解决了多 LoRA 场景下的结构性冗余问题。

*   **实用性强**：直接集成在 SGLang 框架中，对长上下文和复杂智能体流的优化效果立竿见影。

### 8. 不足与局限
*   **计算开销**：在显存非常充裕（低负载）的情况下，由于 ResidualAttention 需要额外的片上重构计算，其性能可能略低于原生内核（论文提到可通过动态切换策略缓解）。

*   **精度风险**：虽然在测试集上表现良好，但在极深层网络或对数值精度极其敏感的任务（如复杂数学证明）中，累积的近似误差是否会放大仍需进一步验证。
