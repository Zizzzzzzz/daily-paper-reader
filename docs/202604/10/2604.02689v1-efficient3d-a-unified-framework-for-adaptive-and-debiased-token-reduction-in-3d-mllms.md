## 摘要
近期多模态大语言模型（MLLMs）的进展已将推理能力扩展到 3D 领域，实现了细粒度的空间理解。然而，3D MLLM 庞大的模型规模和输入特征的高维度带来了显著的推理开销，限制了其在资源受限平台上的实际部署。为克服这一限制，本文提出了 Efficient3D，这是一个用于视觉 Token 剪枝的统一框架，在保持竞争力的准确性的同时加速了 3D MLLM。该框架引入了一个去偏视觉 Token 重要性估计器（DVTIE）模块，该模块在注意力聚合过程中考虑了浅层初始层的影响，从而为视觉 Token 生成更可靠的重要性预测。此外，本文还开发了一种自适应 Token 再平衡（ATR）策略，根据场景复杂度动态调整剪枝强度，从而保留语义完整性并维持跨层的平衡注意力。二者结合实现了上下文感知的 Token 缩减，在降低计算量的同时保留了核心语义。在 ScanRefer、Multi3DRefer、Scan2Cap、ScanQA 和 SQA3D 等五个具有代表性的 3D 视觉与语言基准测试上进行的全面实验表明，与未剪枝的基线模型相比，Efficient3D 取得了更优越的性能，在 Scan2Cap 数据集上的 CIDEr 指标提升了 2.57%。因此，Efficient3D 为 3D MLLM 的高效推理提供了一种可扩展且有效的解决方案。代码已发布于：https://github.com/sol924/Efficient3D。

## Abstract
Recent advances in Multimodal Large Language Models (MLLMs) have expanded reasoning capabilities into 3D domains, enabling fine-grained spatial understanding. However, the substantial size of 3D MLLMs and the high dimensionality of input features introduce considerable inference overhead, which limits practical deployment on resource constrained platforms. To overcome this limitation, this paper presents Efficient3D, a unified framework for visual token pruning that accelerates 3D MLLMs while maintaining competitive accuracy. The proposed framework introduces a Debiased Visual Token Importance Estimator (DVTIE) module, which considers the influence of shallow initial layers during attention aggregation, thereby producing more reliable importance predictions for visual tokens. In addition, an Adaptive Token Rebalancing (ATR) strategy is developed to dynamically adjust pruning strength based on scene complexity, preserving semantic completeness and maintaining balanced attention across layers. Together, they enable context-aware token reduction that maintains essential semantics with lower computation. Comprehensive experiments conducted on five representative 3D vision and language benchmarks, including ScanRefer, Multi3DRefer, Scan2Cap, ScanQA, and SQA3D, demonstrate that Efficient3D achieves superior performance compared with unpruned baselines, with a +2.57% CIDEr improvement on the Scan2Cap dataset. Therefore, Efficient3D provides a scalable and effective solution for efficient inference in 3D MLLMs. The code is released at: https://github.com/sol924/Efficient3D

3D 多模态大语言模型（3D MLLMs）虽然在空间理解和推理方面取得了显著进展，但面临严重的**推理开销问题**。由于 3D 数据的高维度和模型规模的庞大，在资源受限的设备上部署极具挑战。
*   **现有技术的局限：** 现有的视觉 Token 剪枝方法（如 Fast3D）通常采用全局注意力平均来估计 Token 重要性，但这会导致深层的剪枝决策被浅层初始层的注意力模式所误导（浅层往往过度关注视觉 Token）。
*   **场景复杂性差异：** 多数方法使用固定剪枝率，忽略了不同 3D 场景的语义复杂度差异（简单场景物体少，复杂场景物体多且关联复杂），导致过度剪枝或效率不足。

### 2. 方法论：核心思想与关键技术
Efficient3D 提出了一个统一框架，包含两个核心组件：
*   **去偏视觉 Token 重要性估计器 (DVTIE)：**
    *   **核心思想：** 训练一个轻量级网络来预测 Token 重要性，但在生成监督信号时，**剔除浅层初始层**（前 $K$ 层）的注意力图，以消除初始层对视觉 Token 的偏见。
    *   **技术细节：** 引入了**动态混合补偿注意力 Transformer (DHCT)** 层，结合了空间自注意力和跨模态注意力。它利用低秩关联（Low-rank association）来捕捉高阶跨模态语义，并使用多源注意力（自注意力、提示词注意力、描述词注意力）作为联合训练目标。
*   **自适应 Token 重平衡 (ATR) 策略：**
    *   **核心思想：** 放弃固定剪枝率，根据场景复杂度动态调整。
    *   **技术细节：** 引入“影子因子”（Shadow factor）来缩放注意力分数，防止 Token 减少导致的分布偏移。通过逐层累积调整后的注意力，当累积值达到 DVTIE 预测的目标阈值时即执行剪枝，从而在复杂场景保留更多 Token，简单场景剔除更多冗余。

### 6. 主要结论与发现
*   **性能超越基线：** 在 90% 的极高剪枝率下，Efficient3D 在多个任务上依然保持甚至超过了未剪枝基线的性能（例如 Scan2Cap 的 CIDEr 提升了 2.57%）。

*   **去偏的重要性：** 实验证明剔除前两层注意力能显著提升 Token 重要性预测的准确性，避免误删关键语义 Token。

### 7. 优点
*   **自适应性强：** ATR 策略解决了固定剪枝率无法应对多变场景的问题，使模型在处理复杂指令时更具鲁棒性。
*   **即插即用：** 尽管 DVTIE 需要训练，但主模型（3D MLLM）保持冻结，这使得该框架易于扩展到其他预训练模型。
*   **精度不降反升：** 通过精准剔除冗余噪声 Token，模型能更聚焦于关键物体，在某些任务上实现了性能的“反向优化”。

### 8. 不足与局限
*   **额外组件开销：** 虽然推理时主模型变快了，但引入 DVTIE 估计器增加了额外的参数量和前向计算步骤（尽管相对较小）。
*   **依赖物体级 Token：** 该方法基于物体中心（Object-centric）的范式（如 Chat-Scene 的 300 个物体 Token），对于直接处理大规模原始点云（Dense tokens）的 3D MLLM 泛化效果尚未在文中深入探讨。
*   **训练依赖：** 相比于完全 Training-free 的方法，DVTIE 仍需在特定数据集上进行监督训练，存在一定的领域迁移成本。
