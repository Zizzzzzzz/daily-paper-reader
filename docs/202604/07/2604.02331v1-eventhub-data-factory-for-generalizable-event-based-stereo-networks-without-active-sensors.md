## 摘要
我们提出了 EventHub，这是一个用于训练深度事件立体网络的新型框架，它无需来自昂贵主动传感器的真值标注，而是依赖于标准的彩色图像。通过这些图像，我们利用最先进的新视角合成技术推导出代理标注和代理事件，或者在图像已与事件数据配对时仅推导出代理标注。利用我们数据工厂生成的训练集，我们将 RGB 文献中先进的立体模型重新用于处理事件数据，从而获得了具有前所未有泛化能力的全新事件立体模型。在广泛使用的事件立体数据集上进行的实验证明了 EventHub 的有效性，并展示了相同的数据蒸馏机制如何提高 RGB 立体基础模型在夜间场景等挑战性条件下的准确性。

## Abstract
We propose EventHub, a novel framework for training deep-event stereo networks without ground truth annotations from costly active sensors, relying instead on standard color images. From these images, we derive either proxy annotations and proxy events through state-of-the-art novel view synthesis techniques, or simply proxy annotations when images are already paired with event data. Using the training set generated by our data factory, we repurpose state-of-the-art stereo models from RGB literature to process event data, obtaining new event stereo models with unprecedented generalization capabilities. Experiments on widely used event stereo datasets support the effectiveness of EventHub and show how the same data distillation mechanism can improve the accuracy of RGB stereo foundation models in challenging conditions such as nighttime scenes.

### 1. 核心问题与研究动机
*   **核心问题**：如何摆脱对昂贵且有缺陷的主动传感器（如 LiDAR）的依赖，获取高质量、大规模的事件相机立体匹配（Event-based Stereo）训练数据。
*   **研究背景**：
    *   事件相机在高速运动和高动态范围场景下具有优势，但其立体匹配算法的发展受限于标注数据的匮乏。
    *   现有的 LiDAR 标注存在稀疏性、动态物体伪影、重投影误差以及在透明/反射表面失效等问题。
    *   RGB 领域的立体匹配已有海量数据和成熟的基础模型（Foundation Models），但如何将其知识迁移到稀疏的事件流领域仍是挑战。

### 2. 方法论：EventHub 数据工厂
EventHub 提出了两种互补的数据生成路径，旨在利用彩色图像作为“代理”来训练事件网络：

*   **基于新视角合成（NVS）的合成生成**：
    *   **核心思想**：从单目 RGB 序列出发，利用改进的 **SVRaster**（一种高保真辐射场渲染技术）重建场景。
    *   **关键技术**：
        *   **深度正则化**：引入单目深度估计（DepthAnythingV2）和法线一致性损失，提升渲染深度的几何准确性。
        *   **虚拟轨迹构建**：设计局部（物体中心）和全局（室内漫游）虚拟相机轨迹，模拟相机运动。
        *   **运动自适应渲染**：根据像素运动速度动态调整渲染频率，并利用 **ESIM** 模拟器将渲染帧转化为代理事件流。
        *   **体素置信度 ($C_{Vsize}$)**：利用体素大小作为权重，过滤掉渲染深度图中的噪声。
*   **跨模态立体蒸馏**：
    *   **核心思想**：在已配对的 RGB-Event 立体设置中，利用现成的 RGB 立体基础模型（如 FoundationStereo）生成高质量深度图。
    *   **技术细节**：通过相机外参将 RGB 预测的深度重投影到事件相机坐标系，从而为真实事件数据提供“代理真值”。
*   **模型重用（Repurposing）**：
    *   将 RGB 立体基础模型的架构直接迁移到事件领域，使用 **Tencode** 编码将事件流转化为 3 通道张量，并加载预训练的 RGB 权重进行微调。

### 3. 实验设计
*   **数据集**：
    *   **训练集**：NeRF-Stereo、ScanNet++（用于 NVS 生成）、DSEC（用于蒸馏）。
    *   **评估集**：DSEC（域内）、M3ED 和 MVSEC（跨域泛化测试）。
*   **Benchmark 与对比方法**：
    *   **对比模型**：SE-CFF、EMatch 以及作者改造的 E-FoundationStereo 和 E-StereoAnywhere。
    *   **对比方案**：光度损失监督、纯合成数据（SceneFlow）监督、LiDAR 真值监督。
*   **评价指标**：平均绝对误差 (MAE) 和 1/2/3 像素误差率 (1PE/2PE/3PE)。

### 4. 资源与算力
*   **硬件**：使用单张 **NVIDIA A100 GPU**。
*   **训练细节**：
    *   所有模型训练 **10 个 Epoch**。
    *   学习率：事件网络从头训练为 $5 \times 10^{-4}$，RGB 适配模型微调为 $5 \times 10^{-5}$。
    *   Batch Size 为 2。
*   **NVS 耗时**：SVRaster 场景优化约需 20 分钟/场景，渲染速度达 143 FPS。

### 5. 实验数量与充分性
*   **实验规模**：
    *   生成了约 70k 对经过筛选的 NVS 样本和 30k 对蒸馏样本。
    *   进行了 4 种不同数据组合（MIX 1-4）的对比实验。
    *   涵盖了域内测试、跨数据集泛化测试（Day/Night/Indoor 细分场景）。
    *   包含消融实验（深度正则化项、置信度指标、NVS 引擎对比）。
*   **充分性评价**：实验设计非常充分且客观。通过在完全未见过的 M3ED 和 MVSEC 数据集上进行 Zero-shot 测试，有力证明了该方法在泛化性上远超传统的 LiDAR 监督模型。

### 6. 主要结论与发现
*   **泛化性飞跃**：使用 EventHub 生成的代理数据训练的模型，在跨域测试中误差比 LiDAR 监督模型降低了高达 **50%**。
*   **LiDAR 并非完美**：实验发现 LiDAR 标注的稀疏性和噪声实际上限制了模型的上限，而 EventHub 提供的稠密代理标注能让模型学习到更清晰的边界。
*   **闭环增益**：训练好的事件立体模型可以反过来为夜间 RGB 图像提供代理标注，显著提升 RGB 模型在极端光照下的表现。

### 7. 优点与亮点
*   **无需主动传感器**：极大地降低了事件立体匹配的研究门槛，只需普通相机即可生产数据。
*   **高质量 NVS 集成**：首次将先进的辐射场渲染（SVRaster）引入事件数据生成，并解决了深度图噪声问题。
*   **跨模态双向互补**：不仅让事件模型受益于 RGB 知识，还反哺了 RGB 模型在弱光环境下的短板。

### 8. 不足与局限
*   **静态场景限制**：目前的 NVS 流程主要针对静态场景，对于包含大量动态物体的复杂交通场景，代理事件的模拟可能存在偏差。
*   **计算开销**：虽然训练阶段高效，但前期 NVS 场景的重建（每个场景 20 分钟）在处理超大规模场景库时仍有一定时间成本。
*   **模拟器鸿沟**：ESIM 模拟的事件与真实硬件捕获的事件之间仍存在一定的“噪声差异”，尽管泛化性已很强，但仍有优化空间。
