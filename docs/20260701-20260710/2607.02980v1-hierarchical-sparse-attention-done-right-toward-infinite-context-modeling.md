## 摘要
现代大型语言模型（LLMs）向长上下文扩展受限于密集注意力的二次计算成本和较差的长度外推能力。分块稀疏注意力提供了一种有前景的替代方案，但所有现有方法因其不精确的块选择而无法达到全注意力的效果。我们提出层次化地标稀疏注意力（Hierarchical Landmark Sparse Attention, HiLS），这是一种分块稀疏注意力机制，在语言建模（LM）损失下端到端地学习块选择。HiLS 层次化地分解注意力：每个查询与每个检索到的块独立进行注意力计算以提取块特定信息，并根据块检索得分融合输出结果。通过将检索得分纳入前向注意力计算，HiLS 直接利用 LM 损失对其进行优化，实现了端到端的检索学习和原生稀疏训练。实验结果表明，HiLS-Attention 在域内上下文长度上达到了与全注意力相当甚至更优的性能。同时，HiLS-Attention 能以 90% 的检索准确率外推超过训练上下文长度 64 倍以上，远超全注意力。此外，现有的全注意力模型可以通过轻量级继续预训练转换为 HiLS-Attention，在保持域内性能的同时获得超长上下文外推能力。结合其稀疏的 KV 访问和计算，HiLS-Attention 打破了常见的效率-性能权衡，使得长上下文 LLM 在通用长上下文任务上比其全注意力对应模型更高效且更有效。

## Abstract
Scaling modern large language models (LLMs) to long contexts is limited by the quadratic computation cost, and poor length extrapolation of dense attention. Chunk-wise sparse attention offers a promising alternative, but all existing methods fall short of full attention because of their inaccurate chunk selection. We propose Hierarchical Landmark Sparse (HiLS) Attention, a chunk-wise sparse attention mechanism that learns chunk selection end-to-end under the language-modeling (LM) loss. HiLS factorizes attention hierarchically: each query performs attention independently with each retrieved chunk to extract chunk-specific information, and the resulting outputs are fused according to chunk retrieval scores. By incorporating retrieval scores into the forward attention computation, HiLS optimizes them directly with the LM loss, enabling end-to-end retrieval learning and native sparse training. Experimental results show that HiLS-Attention achieves performance comparable to, and in some cases better than, full attention at in-domain context lengths. Meanwhile, HiLS-Attention extrapolates more than $64\times$ the training context length with 90% retrieval accuracy, far beyond full attention. Moreover, existing full-attention models can be converted to HiLS-Attention with lightweight continued pretraining, preserving in-domain performance while acquiring ultra-long-context extrapolation. Together with its sparse KV access and computation, HiLS-Attention breaks the usual efficiency-performance trade-off, enabling long-context LLMs that are both more efficient and more effective on general long-context tasks than their full-attention counterparts.

## 2. 论文提出的方法论

### 2.1 核心思想
- 借鉴 Naive Block Sparse Attention (BSA) 的块质量概念（全注意力下每个块内 token 指数级 logits 之和），但避免计算全注意力。
- 利用 **地标 token（landmark token）** 为每个块生成一个可学习的压缩键 \(k'_c\) 和偏置 \(b'_c\)，通过第一阶泰勒展开近似块质量 \(Z_{i,c}\)（Proposition 3.1）。
- 提出 **层次化 softmax**：将注意力权重分解为 块内归一化权重 × 块间质量估计。从而块检索得分直接参与前向计算，LM 损失可以反向传播到地标 token 的参数，实现端到端学习。

### 2.2 关键技术细节
1. **块质量线性化代理**（Proposition 3.1）：
   \[
   \log\sum_{j\in T_c} e^{s_{i,j}} \approx \frac{q_i^\top k'_c}{\sqrt{d}} + b'_c
   \]
   其中 \(k'_c = \text{Attn}(q'_c, K_c, K_c)\) 是地标查询 \(q'_c\) 对块内键的注意力加权和，\(b'_c = \text{Entropy}(p_j)\) 是块内注意力分布的熵。
2. **层次化因子分解**：
   \[
   w_{i,j} = \frac{e^{s_{i,j}}}{Z_{i,c(j)}} \times \frac{\hat{Z}_{i,c(j)}}{\hat{Z}_i}
   \]
   使用可学习的代理 \(\hat{Z}_{i,c} = e^{\hat{s}_{i,c}}\) 代替真实块质量。
3. **低秩查询校准（Q‑Cal）**：为块级评分引入一个低秩适配器 \(\Delta q_i = W_{\text{up}}W_{\text{down}}h_i\)，使查询更适合评估块级重要性。
4. **GQA 兼容**：在一个 KV 头对应多个查询头的 GQA 场景中，取组内所有查询头中归一化块得分的最大值作为组级得分，保证共享 KV 加载。
5. **位置编码**：使用 HoPE（Hybrid Positional Encoding），仅对训练长度内可旋转的维度施加 RoPE，其余维度用 NoPE 以增强长度外推。
6. **硬件高效内核设计**：将相邻 \(M\) 个查询 token 打包，取它们选中块的并集，一次性加载 KV，提高 Tensor Core 利用率和数据复用（要求 \(M \times G \geq 16\)，不依赖大 GQA 组）。

### 2.3 算法流程简述
1. 对序列进行非重叠分块（块大小 \(S\)）。
2. 每个块末尾插入一个地标 token，根据其隐藏状态计算查询 \(q'_c\)，进而得到块摘要键 \(k'_c\) 和熵 \(b'_c\)。
3. 对于每个查询 token，计算其与所有块摘要的得分 \(\hat{s}_{i,c} = \hat{q}_i^\top k'_c/\sqrt{d} + b'_c\)。
4. 取 top‑K 得分对应的块（加上局部滑动窗口）。
5. 对被选中的块，先进行块内注意力（归一化到该块），再乘以块间质量 \(\hat{Z}_{i,c} = e^{\hat{s}_{i,c}}\)，并在总部分函数 \(\hat{Z}_i\) 下归一化，得到最终注意力权重。

## 8. 不足与局限

- **不支持上下文并行**：论文明确提到 HiLS‑Attention 尚未支持 context parallelism，在大规模长上下文训练时可能遇到分布式效率瓶颈。
