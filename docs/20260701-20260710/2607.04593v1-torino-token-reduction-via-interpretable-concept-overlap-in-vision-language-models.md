## 摘要
视觉-语言模型（VLM）在不同任务中展现出令人印象深刻的能力，但其计算成本主要来自输入到语言模型的大量视觉令牌。现有的令牌减少方法依赖于基于注意力的分数或成对相似性，而没有对每个令牌进行明确的语义表示。我们提出TORINO（通过可解释的概念重叠进行令牌减少），这是一种即插即用的框架，用于在VLM中进行自适应视觉令牌减少，无需对基础模型进行微调。TORINO利用稀疏自编码器（SAE）将视觉令牌投影到可解释的潜在空间中，在该空间中可以通过共享的概念激活来分析令牌关系。具体来说，我们将概念重叠定义为活跃SAE潜在变量之间的一致程度，并利用它来对共享语义内容的令牌进行分组。然后通过剪枝或合并对每组进行减少，提供了一个统一的框架，在去除冗余的同时保留语义上重要的视觉信息。与固定预算方法不同，TORINO根据输入复杂度动态调整减少率，允许不同图像保留不同数量的令牌。在多个视觉-语言基准上的实验表明，TORINO实现了良好的效率-准确性权衡，以最小的性能损失减少了视觉令牌的数量。

## Abstract
Vision-Language Models (VLMs) have demonstrated impressive capabilities across different tasks, but their computational cost is dominated by the large number of visual tokens fed to the language model. Existing token reduction methods rely on attention-based scores or pairwise similarity, without an explicit semantic representation of each token. We introduce TORINO (TOken Reduction via Interpretable coNcept Overlap), a plug-and-play framework for adaptive visual token reduction in VLMs that requires no fine-tuning of the underlying model. TORINO leverages Sparse Autoencoders (SAEs) to project visual tokens into an interpretable latent space where token relationships can be analyzed through shared concept activations. Specifically, we define concept overlap as the degree of agreement between active SAE latents and use it to group tokens that share semantic content. Reduction within each group is then performed by either pruning or merging, providing a unified framework that preserves semantically important visual information while removing redundancy. Unlike fixed-budget approaches, TORINO dynamically adapts the reduction rate to input complexity, allowing different images to retain different numbers of tokens. Experiments across multiple vision-language benchmarks show that TORINO achieves favorable efficiency-accuracy trade-offs, reducing the number of visual tokens with minimal performance loss.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉-语言模型（VLM）中，视觉编码器（如CLIP ViT）输出大量视觉令牌（patch tokens），这些令牌被输入到大型语言模型（LLM），导致注意力计算量随序列长度呈二次增长，成为推理速度和内存占用的主要瓶颈。
- **现有方法的不足**：已有的令牌缩减方法（如基于注意力分数、CLS令牌相似性、原始嵌入距离）均采用代理信号来评估令牌重要性，缺乏对每个令牌所编码概念的显式语义表示。因此，外观不同但语义冗余的令牌可能被错误保留，而共享抽象概念的令牌可能被分开处理。
- **研究动机**：引入可解释性工具（稀疏自编码器，SAE）来获取令牌的显式语义特征，从而指导令牌缩减决策。这是“实用可解释性”（pragmatic interpretability）的一次实践：将原本用于事后分析的可解释性工具，用于指导功能性决策。
- **整体含义**：TORINO是一个即插即用、无需微调的框架，通过SAE将视觉令牌投影到可解释的概念空间，根据共享概念激活进行分组，并在组内进行剪枝或合并，实现内容自适应的动态缩减，达到更优的效率-精度权衡。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：利用预训练的Matryoshka BatchTopK SAE将每个视觉令牌编码为稀疏概念向量，通过定义“概念重叠”（active SAE latents的一致程度）来构建令牌图，按连通分量分组，然后对每组进行缩减（剪枝或合并）。缩减后的令牌数由图像内容动态决定：简单图像形成较少大组，压缩更激进；丰富图像形成较多小组，保留更多令牌。
- **关键技术细节**：
  - **SAE特征提取**：从VLM视觉编码器的中间层（block 22，后MLP残差流）提取令牌嵌入，使用预训练的Matryoshka BatchTopK SAE（ε=64，K=20，ω=65536个概念特征）将其编码为稀疏激活向量。
  - **概念引导的分组**：对每个令牌保留其k个最活跃的概念索引（A_i = argtop_k(z_i)），构建令牌图H，若两个令牌共享至少δ个概念则连边。通过并查集得到连通分量作为概念组。参数(k, δ)控制分组粒度：k=1,δ=1为最大压缩（按argmax分组）；k=2,δ=1更宽松；k=2,δ=2更严格。
  - **Token缩减**：
    - TORINO-P（剪枝）：每组中选择峰值激活分数a(i)=||z_i||_∞最高的令牌作为代表，其余丢弃。
    - TORINO-M（合并）：每组内的令牌通过对数大小缩放平均值合并为虚拟令牌：p_g = (1+log|G_g|)/|G_g| * sum_{i∈G_g} v_i。
  - **固定预算变体**：若需要固定输出长度B，则先截断（保留最大的B组），若组数不足则从池中按峰值激活分数填充。
  - **算法流程**（文字描述）：输入令牌嵌入 → SAE编码获取稀疏激活和峰值分数 → 计算每组top-k概念 → 构建令牌图并分组成连通分量 → 对每组按策略生成主令牌 → 输出长度可变的令牌序列（动态）或固定B个（通过截断+填充）。

## 6. 论文的主要结论与发现

- **性能优势**：在中等压缩水平（~62%~78% reduction）下，TORINO（尤其是合并变体TORINO-M）在相对得分上优于所有基线，取得了最佳效率-精度权衡。例如，在LLaVA-1.5-7B上，~217保留令牌时TORINO-M相对得分98.7%，领先第二名PruneSID约2个百分点。
- **内容自适应性**：每图像保留令牌数随图像复杂度动态变化（图3），复杂图像（如GQA）保留更多令牌，简单图像（如ScienceQA）压缩更激进，无需显式复杂度估计。
- **SAE的必要性**：在~92%压缩率下，移除SAE（使用原始嵌入）导致相对得分下降5.2个百分点（表2），证明SAE概念空间对分组质量至关重要。
- **扩展因子的影响**：大扩展因子（ε=64）在极端压缩时最鲁棒；中等因子（ε=4）在中低压缩时性能最佳。
- **剪枝 vs 合并**：在中低压缩下两者相当，但TORINO-P在高压缩下更优，因为合并后的大组平均操作会模糊细粒度信息。

## 7. 优点：方法或实验设计上的亮点

- **创新性**：首次将SAE的可解释概念用于VLM的令牌缩减，从“信号代理”转向“显式语义表示”，属于“实用可解释性”的典型应用。
- **即插即用**：完全在推理时运行，无需微调基础模型，兼容任意使用相同视觉编码器的VLM。
- **自适应动态预算**：与固定预算方法不同，令牌保留数由图像内容自动决定，无需手动设定或学习复杂度估计器。
- **统一框架**：支持剪枝与合并两种操作，并在同一分组准则下比较其差异。
- **消融实验系统**：深入分析了SAE必要性和扩展因子的影响，验证了设计选择的有效性。
- **实验覆盖全面**：9个基准、2种模型大小、多种压缩率、多种消融，结果可信。

## 8. 不足与局限

- **实验覆盖限制**：
  - 仅在LLaVA-1.5系列上评估，未拓展到其他VLM架构（如Qwen-VL、InstructBLIP），限制了通用性结论。作者在结论中承认这一点，并指出需要为不同视觉骨干训练匹配的SAE。
  - SAE训练仅使用CLS令牌和ImageNet-1K，若在更大规模的patch令牌数据集上训练，可能进一步提升性能（实验中CLS SAE优于空间SAE，但空间SAE训练数据有限，差距可能因数据规模不足而非方法本身）。

- **偏差风险**：
  - 分组参数(k,δ)是全局固定的，不同图像或任务可能需要不同设置，但目前未提供自适应选择机制。
  - 固定预算变体中的截断策略（保留最大组）可能偏向大目标，忽略重要但小面积的概念。
