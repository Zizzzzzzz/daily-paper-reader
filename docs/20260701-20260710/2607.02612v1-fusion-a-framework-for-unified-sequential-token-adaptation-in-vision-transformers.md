## 摘要
视觉Transformer在图像分类中取得了高准确率，但几乎所有图像区域都使用几乎相同的计算量，即使许多区域是冗余或无信息的。最近的适应性推理方法通过选择性压缩令牌或提前终止推理来降低计算成本，但组合这些机制常常导致不稳定的中间表示和准确率下降。我们提出了Fusion，一个统一的适应性推理框架，通过简单的分阶段设计协调令牌合并、提前退出和令牌剪枝：首先合并令牌，然后评估置信度，最后仅对继续推理的样本应用剪枝。这种顺序使得三种机制能够协同工作而非相互竞争。Fusion进一步包含轻量级路由模块，可调整每个输入的压缩强度，并支持在推理时调整准确率-延迟权衡，无需重新训练。在ImageNet-1k上使用DeiT-S，Fusion在可比计算预算下匹配或超越最先进的适应性ViT方法，同时将校准误差降低高达4倍，推理能耗降低48%。在ImageNet-100、CIFAR-100和ImageNette上使用多种ViT骨干网络的实验证明，无需针对数据集调整即可实现一致的迁移性。

## Abstract
Vision Transformers achieve strong image classification accuracy but process all image regions with nearly the same computation, even when many regions are redundant or uninformative. Recent adaptive inference methods reduce this cost by selectively compressing tokens or terminating inference early, but combining these mechanisms often causes unstable intermediate representations and accuracy degradation. We introduce Fusion, a unified adaptive inference framework that coordinates token merging, early exiting, and token pruning through a simple staged design: tokens are merged first, confidence is evaluated next, and pruning is applied only to samples that continue inference. This ordering allows the three mechanisms to operate cooperatively rather than competitively. Fusion further includes lightweight routing modules that adapt compression strength to each input and support inference-time adjustment of the accuracy--latency trade-off without retraining. On ImageNet-1k with DeiT-S, Fusion matches or surpasses state-of-the-art adaptive ViT methods at comparable compute budgets while reducing calibration error by up to $4\times$ and inference energy by $48\%$. Experiments across ImageNet-100, CIFAR-100, and ImageNette with multiple ViT backbones demonstrate consistent transferability without dataset-specific tuning.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：视觉Transformer（ViT）对图像的所有区域（patch token）执行几乎相同的计算量，即使在简单图像中存在大量冗余，导致推理效率低下。
- **已有解决方案**：令牌剪枝（去除不重要令牌）、令牌合并（聚合相似令牌）、提前退出（在浅层置信度高时终止推理）。这些方法通常独立研究和开发。
- **关键挑战**：当将这三种机制组合应用时（即：同时进行剪枝、合并和提前退出），它们会通过共享的中间令牌表示产生相互干扰。例如，在DeiT-S上，**并行组合**导致准确率下降1.62%，第8层的提前退出头准确率从89.4%暴跌至47.6%。
- **本文目标**：提出一个**统一的自适应推理框架Fusion**，通过**顺序分阶段设计**协调三种机制，避免相互干扰，实现稳定高效的联合自适应推理。

## 2. 方法论

### 核心思想
- **顺序执行策略**：先进行令牌合并，然后评估置信度（提前退出），最后仅对继续推理的样本进行令牌剪枝。这种顺序使三种机制**协同**而非竞争。
- **轻量级路由模块**：为每个输入图像动态预测合并比率；支持推理时调整精度-延迟权衡（无需重新训练）。

### 关键技术细节

1. **令牌合并（Merge）**：
   - 在特定层（如块3、5、7）应用。使用一个**单线性投影路由**（d+1个参数）读取CLS令牌表示，预测合并比率 \(m_b \in [0,1]\)。
   - 合并比率通过sigmoid函数得到，并在推理时根据目标计算预算进行缩放：\(\tilde{m}_b = m_b \cdot \frac{1 - \tau_{\text{tgt}}(\theta)}{1 - \tau_{\text{tgt}}(\theta_{\text{ref}})}\)。
   - 采用ToMe的二分匹配方法：将令牌分成两半，匹配最相似的余弦对，合并顶部 \(\lfloor \tilde{m}_b N_b/2 \rfloor\) 对。

2. **提前退出（Early Exit）**：
   - 在特定层（如块8、10）设置辅助分类头。计算置信度 \(c_b = \max_k \hat{p}_b^{(k)}\)。
   - 若 \(c_b \ge \delta_b(\theta)\)（阈值通过验证集设定），则直接返回该层的预测结果。
   - **退出评估发生在合并之后、剪枝之前**，确保置信度评估基于未剪枝的完整表示。

3. **令牌剪枝（Token Pruning）**：
   - 仅在未提前退出的样本上应用。在特定层（如块9、10）使用轻量级评分头，保留重要性最高的 \(\lfloor \tau_b N_b \rfloor\) 个令牌。

4. **训练目标**：
   - 联合训练所有自适应组件，采用**教师蒸馏多目标损失**，包含交叉熵、KL散度、辅助退出头损失、路由损失（合并比率与令牌相似性统计的MSE）、路由多样性惩罚和预算损失。
   - 训练分三个阶段：路由预热 → 退出头预训练 → 联合微调。

5. **推理过程**（算法1）：
   - 输入图像 → patch嵌入 → 逐块处理：
     - 若当前块属于合并层：计算缩放后的合并比率并执行合并。
     - 若当前块属于退出层：计算置信度，若达标则提前返回。
     - 若当前块属于剪枝层：执行剪枝。
   - 若未提前退出，由最终分类器输出。

6. **多配置文件支持**：通过调整退出阈值 \(\delta_b\) 和目标保持比率 \(\tau_{\text{tgt}}\)，在单次检查点上实现多个精度-效率折中点（如BALANCED和POWER_SAVE），无需重新训练。
