## 摘要
最近，视觉 Token 剪枝已被用于处理多模态大语言模型（MLLMs）中大量的视觉 Token。然而，我们观察到，虽然现有的剪枝方法在简单的视觉理解任务上表现可靠，但在有效泛化到复杂的视觉推理任务时却面临困难，这是以往研究中尚未充分探索的关键差距。通过系统性分析，我们将解码过程中的相关视觉信息偏移（RVIS）确定为导致失效的主要原因。为解决这一问题，我们提出了解码阶段偏移感知 Token 剪枝（DSTP），这是一个无需训练的附加框架，使现有的剪枝方法能够在解码阶段将视觉 Token 与不断变化的推理需求相对齐。广泛的实验表明，DSTP 显著缓解了剪枝方法在复杂推理任务中的性能下降，同时在视觉理解基准测试中也持续带来了性能提升。此外，DSTP 在多种最先进的架构上均表现出有效性，突显了其在极低计算开销下的泛化能力和效率。

## Abstract
Recently, visual token pruning has been studied to handle the vast number of visual tokens in Multimodal Large Language Models. However, we observe that while existing pruning methods perform reliably on simple visual understanding, they struggle to effectively generalize to complex visual reasoning tasks, a critical gap underexplored in previous studies. Through a systematic analysis, we identify Relevant Visual Information Shift (RVIS) during decoding as the primary failure driver. To address this, we propose Decoding-stage Shift-aware Token Pruning (DSTP), a training-free add-on framework that enables existing pruning methods to align visual tokens with shifting reasoning requirements during the decoding stage. Extensive experiments demonstrate that DSTP significantly mitigates performance degradation of pruning methods in complex reasoning tasks, while consistently yielding performance gains even across visual understanding benchmarks. Furthermore, DSTP demonstrates effectiveness across diverse state-of-the-art architectures, highlighting its generalizability and efficiency with minimal computational overhead.

### 1. 核心问题与整体含义（研究动机和背景）
*   **背景**：为了降低 MLLM 处理大量视觉 Token 带来的计算和内存开销，现有的研究多采用“视觉 Token 剪枝”技术。
*   **核心问题**：作者发现现有的剪枝方法在简单的视觉理解（如 VQA）中表现良好，但在复杂的**视觉推理（VMR）**任务（如数学、逻辑难题）中性能骤降。
*   **研究动机**：探索为何静态剪枝（在 Prefill 阶段一次性决定保留哪些 Token）无法应对复杂推理。研究发现，推理过程需要模型在不同步骤关注图像的不同区域，这种现象被定义为**相关视觉信息偏移（Relevant Visual Information Shift, RVIS）**。

### 2. 方法论：DSTP 框架
作者提出了**解码阶段偏移感知 Token 剪枝（DSTP）**，这是一个无需训练、即插即用的附加框架。
*   **核心思想**：在解码过程中动态监测模型注意力的变化，一旦发现注意力发生显著偏移，就从之前丢弃的 Token 中“救回”当前相关的部分。
*   **关键技术细节**：
    *   **RISD（RVIS 检测模块）**：在每个解码步骤 $l$，计算当前 Token 对视觉区域的注意力分布与初始（Prefill）分布的余弦相似度。当相似度低于阈值 $\tau$ 时，判定发生了 RVIS。
    *   **CPTS（上下文保留 Token 交换模块）**：一旦触发 RVIS，模型会重新评估所有原始视觉 Token 的重要性，选出当前最相关的 Top-K。为了保持生成的连贯性，它将新选出的 Token 与初始保留的 Token 取并集（Union），形成一个临时的扩展集合，并维持 $L$ 个解码步骤，随后恢复原状以节省开销。

*   **模型架构**：Qwen3-VL-4B/8B, InternVL3.5-8B/14B（包括最新的 Thinking 思考型版本）。
*   **数据集/场景**：
    *   **视觉推理（VMR）**：MathVerse, WeMath, DynaMath, LogicVista, MMMU-Pro。
    *   **视觉理解（VQA）**：ScienceQA (SQA), GQA, TextVQA。
*   **对比方法**：FastV (ECCV'24), DivPrune (CVPR'25), VisionZip (CVPR'25)。
*   **Benchmark**：以原始未剪枝模型（Vanilla）的性能为上限（100%），衡量剪枝方法及其结合 DSTP 后的性能恢复率。

*   **硬件型号**：主要使用 **NVIDIA L40S GPU**。
*   **算力分配**：效率分析（延迟、TPS、显存）在单张 L40S 上完成；大规模基准测试在 4 张 L40S 上并行执行。
*   **训练时长**：由于 DSTP 是**无需训练（Training-free）**的方法，因此不存在训练时长，仅涉及推理阶段的开销。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 8 个主流多模态基准测试，测试了 33.3% 和 22.2% 两种不同的 Token 保留比例。
*   **充分性**：实验设计非常全面。不仅对比了多种剪枝基准，还进行了详细的消融实验（验证 RISD 和 CPTS 的有效性）、超参数敏感性分析（阈值 $\tau$ 和持续时间 $L$）、以及跨模型规模和类型的泛化性验证。
*   **客观性**：通过 TFLOPs 和实际延迟（Latency）双重指标评估效率，证明了 DSTP 在提升精度的同时，计算增量几乎可以忽略不计。

### 6. 主要结论与发现
*   **RVIS 是推理的关键**：在复杂推理中，视觉关注点的偏移是必然且频繁的，而简单理解任务中关注点相对固定。
*   **静态剪枝的局限**：现有方法在 Prefill 阶段丢弃的 Token 往往包含后续推理步骤所需的关键细节，导致模型在推理中后期产生幻觉或失败。
*   **DSTP 的优越性**：DSTP 能显著恢复剪枝带来的性能损失。例如在 MathVerse 上，它能将 FastV 的性能从原始水平的 52.6% 提升至 85.7%，而计算开销（TFLOPs）仅增加不到 1%。

### 7. 优点
*   **理论洞察力强**：首次系统性地识别并量化了解码阶段的视觉信息偏移（RVIS）现象。
*   **高效且通用**：无需重新训练模型，作为插件可提升任何现有剪枝算法的鲁棒性。
*   **平衡性佳**：通过“临时恢复”机制，巧妙地在推理精度和计算效率之间找到了平衡点。

### 8. 不足与局限
*   **层级策略单一**：目前 DSTP 在所有 Transformer 层中应用相同的视觉 Token 集合，未考虑不同层（如浅层提取特征、深层逻辑推理）对视觉信息需求的差异。
*   **超参数固定**：阈值 $\tau$ 和持续时间 $L$ 目前是静态设置的，对于不同难度的问题，动态调整这些参数可能会进一步优化效率。
*   **极端压缩挑战**：在极高的压缩率下（如保留率低于 10%），性能仍存在一定程度的不可逆损失。
