## 摘要
本文对通过 Token 剪枝（一种消除与目标应用无关语言对应的 Token 和嵌入参数的压缩技术）进行适配的最先进多语言大语言模型（LLMs）进行了系统性的基准测试。针对以韩语为中心的自然语言处理（NLP）任务，我们在三种词表配置（原始、英韩 EnKo、英韩中 EnKoZh）下评估了包括 Qwen3、Gemma-3、Llama-3 和 Aya 在内的模型架构。我们使用通用的综合能力、文化素养、指令遵循和机器翻译等既定基准对性能进行了评估。研究结果表明，Token 剪枝通过消除语言混淆显著提高了生成稳定性，并且在机器翻译方面，经常能增强韩语特定任务的性能。尽管指令遵循能力表现出与潜在跨语言表示相关的架构依赖性差异，但词表大小的显著减小证明了 Token 剪枝是内存受限、特定领域部署的一种高效优化策略，尽管其在推理延迟方面的提升较为有限。

## Abstract
This paper presents a systematic benchmark of state-of-the-art multilingual large language models (LLMs) adapted via token pruning - a compression technique that eliminates tokens and embedding parameters corresponding to languages irrelevant to the target application. Focusing on Korean-centric natural language processing (NLP) tasks, we evaluate architectures including Qwen3, Gemma-3, Llama-3, and Aya across three vocabulary configurations: Original, English-Korean (EnKo), and English-Korean-Chinese (EnKoZh). Performance is assessed using established benchmarks for general aptitude, cultural literacy, instruction following, and machine translation. Our findings indicate that token pruning significantly improves generation stability by eliminating language confusion, and in the case of machine translation, frequently enhances performance on Korean-specific tasks. While instruction-following capabilities display architecture-dependent variance linked to latent cross-lingual representations, the significant reduction in vocabulary size validates token pruning as a highly effective optimization strategy for memory-constrained, domain-specific deployments, despite modest gains in inference latency.

#### 1. 论文的核心问题与整体含义（研究动机和背景）
随着大规模多语言大语言模型（LLM）的普及，模型往往面临“多语言诅咒”：为了兼容数百种语言，模型词表（Vocabulary）和嵌入层（Embedding layers）中很大一部分参数被分配给了与特定应用无关的语言。对于专注于韩语（Korean-centric）的任务，这种冗余不仅增加了内存开销，还可能导致“语言混淆”现象，降低生成稳定性。本文旨在探讨通过 **Token 剪枝（Token Pruning）** 技术，在不改变 Transformer 核心架构的前提下，通过精简词表来优化模型在韩语特定任务中的表现和部署效率。

#### 2. 论文提出的方法论
核心思想是实施“语言感知过滤”策略，系统性地切除与目标语言无关的 Token 及其对应的参数。具体流程包括：
*   **语言感知过滤：** 利用 Unicode 编码范围和脚本属性（如 Hangul、Latin、Hanzi）对 Token 进行分类。
*   **词表重构：** 丢弃目标配置（如英韩 EnKo）之外的 Token，并将保留的 Token 映射到新的连续索引空间。
*   **权重重排：** 物理调整嵌入矩阵（Embedding Matrix）和输出投影层（Output Projection Layer）的权重，使其与新索引对齐。
*   **架构保持：** 该过程仅修改输入/输出层，内部 Transformer 块和位置编码保持不变，从而保留模型原有的序列建模能力。

*   **目标模型：** 涵盖了多个主流开源模型家族，包括 Qwen3 (0.6B-14B)、Gemma-3 (270M-12B)、Llama-3.1/3.2 (3B-8B)、Aya-23/Expanse (8B) 等。
*   **词表配置：** 
    1. **Original：** 原始完整多语言词表。
    2. **EnKo：** 仅保留英语和韩语。
    3. **EnKoZh：** 保留英语、韩语和中文。
*   **评估基准（Benchmarks）：**
    *   **通用能力：** KMMLU（综合知识与逻辑）。

#### 5. 实验数量与充分性
实验设计较为充分且具有代表性：
*   **多维度覆盖：** 实验涵盖了从 270M 到 14B 不同参数规模的模型，验证了剪枝在不同体量模型上的普适性。
*   **对比严谨：** 通过 Original、EnKo、EnKoZh 三种配置的对比，深入探讨了跨语言表示（尤其是中文对韩语推理的影响）对模型性能的作用。
*   **客观性：** 使用了多个第三方公认的韩语基准测试集，实验结果通过量化指标（如 COMET 分数、WPR、准确率）呈现，具有较高的客观性。

#### 6. 论文的主要结论与发现
*   **生成稳定性显著提升：** 剪枝消除了无关语言 Token 的干扰，WPR 指标大幅改善（如 Qwen3-4B 从 0.88 提升至 0.99），几乎消除了语言混淆。
*   **翻译性能增强：** 在韩英翻译任务中，剪枝后的模型普遍优于原始模型，表明精简词表有助于正则化输出分布，减少幻觉。
*   **通用能力保持稳定：** 在 KMMLU 等任务中，剪枝后的模型性能波动极小，甚至在小参数模型中因搜索空间缩小而略有提升。
*   **架构依赖性：** Qwen 系列模型在 EnKoZh 配置下表现优于 EnKo，说明其韩语推理能力部分依赖于预训练中形成的中文跨语言对齐。
*   **效率权衡：** 词表规模可缩减约 36%，显著节省显存，但推理延迟的提升非常微小（约 0.89%），因为计算瓶颈主要在 Attention 机制而非嵌入层。

#### 7. 优点
*   **实用性强：** 为资源受限环境下的特定语言模型部署提供了一种低成本、高效率的优化方案。
*   **深入揭示冗余影响：** 证明了多语言模型中的冗余 Token 不仅占用空间，还会通过增加输出噪声损害特定语言的生成质量。
*   **模型覆盖广泛：** 测试了 2025-2026 年间最前沿的开源模型，具有很强的时效性和参考价值。

#### 8. 不足与局限
*   **延迟优化有限：** 实验表明该方法对推理速度的直接提升并不显著，无法解决 Transformer 核心计算的瓶颈。
*   **跨语言依赖解释尚浅：** 虽然观察到 Qwen 对中文 Token 的依赖，但未深入分析这种“潜在跨语言表示”在 Transformer 内部是如何运作的。
*   **任务局限：** 实验主要集中在短文本和标准基准测试，未评估剪枝对长文本处理或极特定专业领域（如法律、医疗）的影响。
