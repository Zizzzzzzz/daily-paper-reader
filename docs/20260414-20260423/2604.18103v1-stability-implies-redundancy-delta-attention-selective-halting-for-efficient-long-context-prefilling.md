## 摘要
在长上下文场景下，预填充（Prefilling）的计算开销构成了大语言模型（LLM）和大多模态模型（LMM）的重大瓶颈。虽然 Token 剪枝可以缩短序列长度，但以往的方法依赖于启发式规则，这破坏了与 FlashAttention 等硬件高效算子的兼容性。在这项工作中，我们观察到 Token 会向“语义固定点”演化，使得进一步的处理变得冗余。为此，我们引入了 Delta 注意力选择性停止（DASH），这是一种无需训练的策略，通过监测自注意力机制的逐层更新动态，来选择性地停止已稳定的 Token。广泛的评估证实，DASH 在语言和视觉基准测试中具有良好的泛化性，在保持模型准确性和硬件效率的同时，显著提升了预填充速度。代码将发布于 https://github.com/verach3n/DASH.git。

## Abstract
Prefilling computational costs pose a significant bottleneck for Large Language Models (LLMs) and Large Multimodal Models (LMMs) in long-context settings. While token pruning reduces sequence length, prior methods rely on heuristics that break compatibility with hardware-efficient kernels like FlashAttention. In this work, we observe that tokens evolve toward \textit{semantic fixing points}, making further processing redundant. To this end, we introduce Delta Attention Selective Halting (DASH), a training-free policy that monitors the layer-wise update dynamics of the self-attention mechanism to selectively halt stabilized tokens. Extensive evaluation confirms that DASH generalizes across language and vision benchmarks, delivering significant prefill speedups while preserving model accuracy and hardware efficiency. Code will be released at https://github.com/verach3n/DASH.git.

在处理长上下文（Long-Context）时，大语言模型（LLM）和大多模态模型（LMM）的**预填充（Prefilling）阶段**面临巨大的计算开销。虽然 Token 剪枝技术可以减少序列长度，但现有方法通常依赖复杂的启发式评分（如累积注意力权重），这需要显式计算完整的注意力矩阵，从而破坏了与 **FlashAttention** 等硬件加速算子的兼容性。
本文的核心动机是观察到 Token 在通过模型深层时会趋向于“**语义固定点**”（Semantic Fixing Points），即在某些层之后，特定 Token 的表示已经稳定，进一步的计算是冗余的。论文旨在提出一种无需训练、硬件友好且能显著加速预填充的策略。

#### 2. 方法论：核心思想与技术细节
论文提出了 **DASH (Delta Attention Selective Halting)** 策略，其核心思想是通过监测 Token 的更新幅度来识别冗余。

*   **核心指标 ($\Delta attn$)**：定义为自注意力子层在残差相加前的输出 $U^{(l)}$ 的 $L_2$ 范数。公式表达为：$\Delta^{(l)}_t = \|U^{(l)}_t\|_2$。该指标衡量了当前层对该 Token 语义表示的贡献程度。
*   **选择性停止策略**：
    1.  **正常处理**：在起始层 $l_s$ 之前，所有 Token 正常参与计算。
    2.  **单次决策 (Single-shot)**：在指定的起始层 $l_s$，计算所有 Token 的 $\Delta attn$ 分数并排序。
    3.  **保留与停止**：根据预设的剪枝比例 $\rho$，保留分数最高的 Top-K 个 Token 作为“活跃集”，其余 Token 在该层之后停止处理（Halt）。
    4.  **后续层复用**：在 $l_s$ 之后的所有预填充层中，仅对活跃集进行计算，被停止的 Token 状态保持不变。
*   **硬件兼容性**：由于 DASH 在 $l_s$ 层之后物理上缩短了序列长度，且不需要在每一层重新计算复杂的注意力权重，因此可以完美兼容 FlashAttention 等高效内核。
