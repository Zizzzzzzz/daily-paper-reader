## 摘要
标准注意力机制的平方级计算复杂度构成了大语言模型在长文本推理中的根本瓶颈。虽然现有的 KV 缓存压缩方法缓解了内存压力，但它们往往会牺牲生成质量，且未能解决浮点运算的高开销问题。本文介绍了 DASH-KV，这是一种创新的加速框架，它通过非对称深度哈希将注意力机制重新表述为近似最近邻搜索。在该范式下，我们设计了一种非对称编码架构，对查询（Query）和键（Key）进行差异化映射，以考虑它们在精度和重用特性上的区别。为了平衡效率和准确性，我们进一步引入了动态混合精度机制，自适应地为关键 Token 保留全精度计算。在 LongBench 上的广泛实验表明，DASH-KV 在性能上与全注意力机制相当，同时显著优于最先进的基准方法，并将推理复杂度从 O(N^2) 降低到线性 O(N)。代码可在 https://github.com/Zhihan-Zh/DASH-KV 获取。

## Abstract
The quadratic computational complexity of the standard attention mechanism constitutes a fundamental bottleneck for large language models in long-context inference. While existing KV cache compression methods alleviate memory pressure, they often sacrifice generation quality and fail to address the high overhead of floating-point arithmetic. This paper introduces DASH-KV, an innovative acceleration framework that reformulates attention as approximate nearest-neighbor search via asymmetric deep hashing. Under this paradigm, we design an asymmetric encoding architecture that differentially maps queries and keys to account for their distinctions in precision and reuse characteristics. To balance efficiency and accuracy, we further introduce a dynamic mixed-precision mechanism that adaptively retains full-precision computation for critical tokens. Extensive experiments on LongBench demonstrate that DASH-KV significantly outperforms state-of-the-art baseline methods while matching the performance of full attention, all while reducing inference complexity from O(N^2) to linear O(N). The code is available at https://github.com/Zhihan-Zh/DASH-KV

大语言模型（LLM）在处理长文本时，标准注意力机制的**平方级计算复杂度**（$O(N^2)$）和 **KV 缓存（KV Cache）带来的巨大内存压力**是核心瓶颈。
*   **现有方法的局限：** 现有的量化压缩（Quantization）往往在极低比特下精度大幅下降；选择性剔除（Eviction）会导致信息永久丢失；且这些方法大多仍基于高开销的浮点运算。
*   **研究动机：** 论文观察到注意力机制中的 Query-Key 匹配本质上是大规模向量检索问题。因此，作者提出将注意力机制重构为基于**非对称深度哈希（Asymmetric Deep Hashing）**的近似最近邻搜索（ANN），旨在将计算复杂度降至线性，并利用位运算（Bitwise operations）替代昂贵的浮点矩阵乘法。

#### 2. 论文提出的方法论：DASH-KV 框架
DASH-KV 的核心思想是将高维浮点相似度计算转换为二进制汉明空间（Hamming Space）中的距离匹配。

*   **非对称哈希架构（Asymmetric Hashing）：**
    *   **Query 编码：** 使用轻量级多层感知机（MLP）动态映射，以捕捉复杂的语义。
    *   **Key 编码：** 使用简单的线性投影，以适应 KV 缓存的高频重用和高效存储。
*   **多维校准策略：**
    *   **跨头共识（Cross-Head Consensus）：** 通过多头注意力的“投票机制”校准哈希距离。
    *   **跨层动量（Cross-Layer Momentum）：** 利用前一层的注意力分布作为先验，增强距离判断的准确性。
*   **动态混合精度注意力机制：**
    *   **高相关 Token：** 保留全精度计算（如 Sink Tokens、相邻 Token）。
    *   **中等相关 Token：** 采用“哈希 + 残差补偿”方案，利用轻量级网络修正量化误差。
    *   **低相关 Token：** 直接掩码（Mask）排除，不参与计算。
*   **三阶段部署（Sandwich Strategy）：** 发现模型中间层对稀疏化更鲁棒，因此在首尾层保留全注意力，中间层应用 DASH-KV。

*   **动态混合精度：** 避免了“一刀切”的压缩，通过残差补偿技术在极低比特下找回了丢失的精度。
