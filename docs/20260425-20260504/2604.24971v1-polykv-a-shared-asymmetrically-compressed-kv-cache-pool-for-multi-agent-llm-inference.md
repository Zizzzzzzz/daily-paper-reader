## 摘要
我们提出了 PolyKV，这是一个多个并发推理智能体共享单个非对称压缩 KV 缓存池的系统。与为每个智能体分配独立 KV 缓存的标准范式不同，PolyKV 仅写入一次压缩缓存，并通过 HuggingFace DynamicCache 对象将其注入到 N 个独立的智能体上下文中。压缩是非对称的：Key 以 int8 (q8_0) 进行量化以保持 softmax 的稳定性，而 Value 则使用 TurboQuant MSE 进行压缩——这包括快速沃尔什-哈达玛变换 (FWHT) 旋转，随后是 3 位 Lloyd-Max 量化，其质心针对 N(0,1) 进行了调整。我们在两种模型规模（SmolLM2-1.7B-Instruct 和 Llama-3-8B-Instruct）、三种上下文长度（600-7,194 个 token）以及多达 15 个并发智能体上进行了评估。PolyKV 在所有配置中实现了稳定的 2.91 倍压缩率。在 15 个智能体共享 4K token 上下文的 Llama-3-8B 上，PolyKV 将 KV 缓存内存从 19.8 GB 减少到 0.45 GB（减少了 97.7%），同时仅保持了 +0.57% 的困惑度（perplexity）退化，且平均 BERTScore F1 为 0.928。PPL 增量不随智能体数量增加而增长，并随着上下文长度的增加而改善，在 1,851 个连贯 token 时反转为 -0.26%。据我们所知，此前尚无工作将单个共享的有损压缩 KV 池与多读取器并发智能体访问相结合。

## Abstract
We present PolyKV, a system in which multiple concurrent inference agents share a single, asymmetrically compressed KV cache pool. Rather than allocating a separate KV cache per agent -- the standard paradigm -- PolyKV writes a compressed cache once and injects it into N independent agent contexts via HuggingFace DynamicCache objects. Compression is asymmetric: Keys are quantized at int8 (q8_0) to preserve softmax stability, while Values are compressed using TurboQuant MSE -- a Fast Walsh-Hadamard Transform (FWHT) rotation followed by 3-bit Lloyd-Max quantization with centroids tuned to N(0,1). We evaluate across two model scales (SmolLM2-1.7B-Instruct and Llama-3-8B-Instruct), three context lengths (600-7,194 tokens), and up to 15 concurrent agents. PolyKV achieves a stable 2.91x compression ratio across all configurations. On Llama-3-8B with 15 agents sharing a 4K-token context, PolyKV reduces KV cache memory from 19.8 GB to 0.45 GB -- a 97.7% reduction -- while maintaining only +0.57% perplexity degradation and a mean BERTScore F1 of 0.928. PPL delta does not grow with agent count and improves as context length increases, inverting to -0.26% at 1,851 coherent tokens. To our knowledge, no prior work combines a single shared, lossy-compressed KV pool with multi-reader concurrent agent access.

#### 1. 核心问题与整体含义（研究动机和背景）
在多智能体（Multi-Agent）大语言模型推理场景中，多个智能体通常需要处理相同的长文档上下文。传统的推理范式为每个智能体分配独立的 KV 缓存（KV Cache），这导致了巨大的显存冗余和计算开销。随着上下文长度和模型规模的增加，KV 缓存成为显存瓶颈。
*   **研究动机**：现有的研究要么关注 KV 缓存压缩（减少单个缓存的大小），要么关注 KV 缓存共享（通过前缀缓存减少冗余），但尚未有系统将**有损压缩**与**多读取器并发共享池**结合起来。
*   **核心目标**：构建一个“一次写入、多次读取”的压缩 KV 池，使 N 个智能体能以极低的显存代价共享同一段上下文。

#### 2. 论文提出的方法论
PolyKV 引入了 **SharedKVPool**（共享池）和 **PooledAgent**（池化智能体）两个核心抽象。

*   **核心思想**：在预填充（Prefill）阶段计算一次 KV 状态，进行非对称压缩后存入共享池。推理时，各智能体直接从池中提取解压后的张量注入各自的 `DynamicCache` 对象。
*   **关键技术细节**：
    *   **非对称压缩方案**：
        *   **Keys (K)**：采用 **int8 (q8_0)** 线性量化。由于 Key 参与 Softmax 计算，对精度敏感，高位宽量化有助于保持注意力机制的稳定性。
        *   **Values (V)**：采用 **TurboQuant MSE (3-bit)** 压缩。首先通过快速沃尔什-哈达玛变换（FWHT）进行旋转，使数据分布趋于正态分布 $N(0, 1)$，然后使用针对该分布优化的 3-bit Lloyd-Max 量化。
    *   **动态注入机制**：通过修改 HuggingFace 的 `DynamicCache`，智能体在生成时直接引用共享池中的数据，避免了为每个智能体复制张量的开销。
    *   **压缩率计算**：K(8-bit) + V(3-bit) 相比于原始的 16-bit 存储，理论压缩比为 $16 / ((8+3)/2) \approx 2.91\times$。

#### 6. 主要结论与发现

*   **即插即用**：基于 HuggingFace 生态开发，无需对模型进行微调（Tuning-free）。
*   **正则化发现**：提出了量化噪声作为正则化工具的有趣假设，并提供了初步的实验支持。
