## 摘要
长上下文推理是大语言模型（LLM）的一项关键能力，支持长文档理解、摘要生成和代码生成等应用。然而，高效的自回归推理依赖于键值（KV）缓存，其内存占用随序列长度线性增长，从而导致严重的内存瓶颈。为了减轻这一开销，KV 缓存剪枝方法在推理过程中丢弃注意力分数较低的缓存标记（tokens）。大多数现有方法在各层之间采用统一的剪枝率，隐含地假设所有层对模型整体性能的贡献是相等的。我们证明了这一假设是次优的，因为不同层对剪枝的敏感度存在显著差异。我们提出了 DepthKV，这是一个层依赖的剪枝框架，它根据各层的敏感度在层间分配固定的全局 KV 预算，而非采用均匀分配。在多个模型和任务中，DepthKV 在相同的全局剪枝率下始终优于均匀剪枝，证明了通过层依赖分配可以更有效地利用 KV 缓存预算。

## Abstract
Long-context reasoning is a critical capability of large language models (LLMs), enabling applications such as long-document understanding, summarization, and code generation. However, efficient autoregressive inference relies on the key-value (KV) cache, whose memory footprint grows linearly with sequence length, leading to a major memory bottleneck. To mitigate this overhead, KV cache pruning methods discard cached tokens with low attention scores during inference. Most existing methods apply a uniform pruning ratio across layers, implicitly assuming that all layers contribute equally to overall model performance. We show that this assumption is suboptimal, as layers differ significantly in their sensitivity to pruning. We propose DepthKV, a layer-dependent pruning framework that allocates a fixed global KV budget across layers based on their sensitivity, rather than using a uniform allocation. Across multiple models and tasks, DepthKV consistently outperforms uniform pruning at the same global pruning ratio, demonstrating more effective utilization of the KV cache budget through layer-dependent allocation.

### 1. 核心问题与整体含义（研究动机）
随着大语言模型（LLM）支持的上下文窗口不断扩大（从128K到数百万token），自回归推理中的 **KV Cache（键值缓存）** 成为了主要的内存瓶颈。现有的后训练（Post-training）剪枝方法（如 H2O、SnapKV 等）通常假设所有 Transformer 层同等重要，并在所有层应用**统一的剪枝比例**。
本文的核心动机在于挑战这一假设。作者发现不同层对剪枝的敏感度显著不同，某些关键层（Content Amplification Layers）的过度剪枝会导致生成内容大幅缩水或质量骤降。因此，研究如何根据层的敏感度**非均匀地分配 KV 预算**，是提升长文本推理效率的关键。

### 2. 方法论：DepthKV 框架
DepthKV 的核心思想是在固定全局内存预算的前提下，将更多的 KV 缓存配额分配给“敏感层”，而对“冗余层”进行更激进的剪枝。

*   **层敏感度评估**：通过层级消融实验（Layer-wise Ablation）发现，中间层通常比起始或结束层更敏感。
*   **指标引导分配 (MGA)**：引入 **InfoNCE** 指标作为层重要性的代理。实验发现，表示鲁棒性（InfoNCE 值较低）的层与性能下降强相关。
*   **分配策略**：
    *   **中间层保护 (MLP)**：直接保留中间核心层不剪枝，其余层均匀剪枝。
    *   **指标引导分配 (MGA)**：根据 InfoNCE 分数动态计算每层的剪枝率 $\rho(l)$，确保全局平均剪枝率达标。
    *   **混合策略 (MLMA)**：结合结构化保护（如保留 2/4/6 个中间层）与指标引导分配。
*   **Token 重要性估计**：在确定了每层的预算后，利用改进的 H2O（Heavy-Hitter Oracle）算法，结合注意力分数和 Value 向量范数（Value-aware）来筛选保留的 Token。

### 6. 主要结论与发现
*   **层重要性非均匀性**：Transformer 层对 KV 剪枝的敏感度存在显著且统计学上可靠的差异。
*   **内容放大效应**：特定层（内容放大层）被剪枝后，模型生成的 YapScore（字数/信息量）会显著下降，这与下游任务性能下降高度正相关。
*   **DepthKV 的优越性**：在所有任务中，层依赖分配（尤其是 MGA 和 MLMA）在相同内存预算下均显著优于均匀剪枝。

### 7. 优点（亮点）
*   **视角新颖**：从“层间分配”而非单纯的“层内 Token 筛选”角度切入，填补了 KV 剪枝研究的空白。
*   **即插即用**：作为一种后训练方法，不需要昂贵的重训练或微调，易于部署。
*   **多维评估**：不仅关注 ROUGE 等硬指标，还通过 YapScore 分析了剪枝对生成行为（如“言之无物”）的影响。

### 8. 不足与局限
*   **非查询感知 (Non-query-aware)**：Token 的重要性是在预填充阶段确定的，无法根据解码过程中的动态查询（Query）实时调整，可能在复杂检索任务中丢失关键信息。
*   **层内头差异忽略**：目前只关注了层级差异，未考虑同一层内不同注意力头（Heads）的功能差异。
*   **超参数依赖**：虽然 MGA 是自动化的，但 MLMA 等策略仍涉及保留层数等超参数的选择，可能需要针对特定模型进行微调。
