## 摘要
边缘 AI 系统上大语言模型（LLM）推理部署的日益增加，要求在有限的内存预算下实现高效执行。一个关键挑战源于键值（KV）缓存，其规模通常会超过可用的设备内存。尽管基于 NVMe 的卸载提供了可扩展的容量，但现有的基于文件的设计严重依赖内核页面缓存，在内存压力下会导致缓存抖动、不可预测的延迟以及高昂的软件开销。我们提出了 DUAL-BLADE，这是一个双路径 KV 驻留框架，可根据运行时内存可用性动态地将 KV 张量分配到页面缓存路径或 NVMe 直连路径。NVMe 直连路径通过将 KV 张量映射到连续的逻辑块地址（LBA）区域来绕过文件系统，从而实现低开销的直接存储访问。DUAL-BLADE 进一步结合了自适应流水线并行技术，使存储 I/O 与 GPU DMA 重叠，从而提高推理吞吐量。我们的评估表明，DUAL-BLADE 显著缓解了 I/O 瓶颈，在不同内存预算下，将预填充和解码延迟分别降低了高达 33.1% 和 42.4%，同时将 SSD 利用率提高了 2.2 倍。

## Abstract
The increasing deployment of Large Language Model (LLM) inference on edge AI systems demands efficient execution under tight memory budgets. A key challenge arises from Key-Value (KV) caches, which often exceed available device memory. Although NVMe-based offloading offers scalable capacity, existing file-based designs rely heavily on the kernel page cache, leading to cache thrashing, unpredictable latency, and high software overhead under memory pressure. We present DUAL-BLADE, a dual-path KV residency framework that dynamically assigns KV tensors to either a page-cache path or an NVMe-direct path based on runtime memory availability. The NVMe-direct path bypasses the filesystem by mapping KV tensors to contiguous logical block address (LBA) regions, enabling low-overhead direct storage access. DUAL-BLADE further incorporates adaptive pipeline parallelism to overlap storage I/O with GPU DMA, improving inference throughput. Our evaluation shows that DUAL-BLADE substantially mitigates I/O bottlenecks, reducing prefill and decode latency by up to 33.1% and 42.4%, respectively, while improving SSD utilization by 2.2x across diverse memory budgets.

### 1. 核心问题与研究动机
*   **背景**：边缘 AI 系统（如本地服务器、嵌入式设备）内存资源有限（通常 8-32GB），而大语言模型（LLM）推理产生的 KV 缓存（KV-Cache）随上下文长度增加而剧增，极易超出 GPU 和主机 DRAM 的容量。
*   **核心问题**：现有的 KV 缓存卸载（Offloading）方案（如 FlexGen）主要依赖操作系统的**内核页缓存（Page Cache）**。在内存受限时，这会导致：
    1.  **缓存抖动（Thrashing）**：解码阶段的自回归访问模式与 LRU 替换算法冲突，导致缓存命中率骤降。
    2.  **软件开销高**：传统文件系统 I/O 栈（VFS、文件系统、块层）引入了显著的延迟。
    3.  **顺序性丢失**：Linux 多队列块层会将原本连续的 KV 流打散，降低了 NVMe SSD 的利用率。

### 2. 方法论：DUAL-BLADE 框架
DUAL-BLADE 提出了三种核心设计来优化 KV 缓存的存储管理：
*   **双路径 KV 驻留（Dual-Path KV Residency）**：
    *   **核心思想**：将 KV 张量动态划分为两组。**Group 1** 留在页缓存路径（利用 DRAM 提速）；**Group 2** 路由至 **NVMe 直连路径**（绕过内核栈）。
    *   **动态预算**：根据运行时可用内存计算页缓存预算 $B_{pc}$，确保 Group 1 能够完全驻留在内存中，从而从根本上避免缓存抖动。
*   **NVMe 直连与顺序 LBA 放置**：
    *   **技术细节**：利用 `io_uring_cmd` 实现内核旁路（Kernel-bypass）。
    *   **LBA 映射**：将 KV 张量映射到 SSD 上连续的逻辑块地址（LBA）。通过维护一个简单的哈希表记录张量 ID 到起始 LBA 的映射，保证了硬件层面的顺序访问，减少了闪存转换层（FTL）的开销。
*   **自适应流水线并行（Adaptive Pipeline Parallelism）**：
    *   **策略选择**：在多线程环境下，动态选择“内重叠（Overlap-Intra）”或“跨重叠（Overlap-Cross）”策略。
    *   **核心逻辑**：通过错开（Staggered Start）存储 I/O 和 GPU DMA 的启动时间，使两者在 PCIe 总线上重叠执行，从而隐藏 I/O 延迟。
