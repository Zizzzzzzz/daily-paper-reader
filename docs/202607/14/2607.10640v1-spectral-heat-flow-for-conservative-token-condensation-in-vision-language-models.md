## 摘要
视觉语言模型（VLM）在推理时成本高昂，因为它们需要处理长序列的视觉token。现有的token剪枝方法在高压缩率下常常因盲目丢弃信息、破坏空间结构或多样性坍塌而导致性能下降。我们提出SpecFlow，一种无需训练的框架，将范式从破坏性剪枝转变为保守性凝聚，严格确保空间覆盖和统计守恒以保证稳定性。将视觉token视为k近邻图中的节点，SpecFlow (i) 通过谱热流计算稳定的重要性场以保持结构连贯性，(ii) 通过自适应空间划分分配预算以保证覆盖，(iii) 将丢弃的信息聚合到核心集汇点中维持统计守恒。该方法即插即用，无需微调，且与FlashAttention兼容。实验证实，我们的SpecFlow在各种任务、VLM架构和剪枝比率下均优于现有最先进方法。值得注意的是，采用SpecFlow的LLaVA-1.5在剪除88.9%视觉token的情况下仍保留95.6%的原始性能，实现了卓越的效率-精度平衡。代码可在 https://github.com/Lzy-dot/SpecFlow 获取。

## Abstract
Vision-Language Models (VLMs) are costly at inference time because they must process long sequences of visual tokens. Existing token pruning methods often degrade under high compression by blindly discarding information, breaking spatial structure or collapsing diversity. We propose SpecFlow, a training-free framework that shifts the paradigm from destructive pruning to conservative condensation, strictly enforcing spatial coverage and statistical conservation to ensure stability. Treating visual tokens as nodes in a $k$NN graph, SpecFlow (i) computes a stable importance field via spectral heat flow to preserve structural coherence, (ii) allocates budgets via adaptive spatial partitioning to guarantee coverage, and (iii) aggregates discarded information into coreset sinks to maintain statistical conservation. The method is plug-and-play, requires no fine-tuning, and is compatible with FlashAttention. Experiments confirm that our SpecFlow outperforms SOTA methods across tasks, VLM architectures, and pruning ratios. Notably, LLaVA-1.5 with SpecFlow retains 95.6\% of original performance despite pruning 88.9\% of visual tokens, offering an exceptional efficiency-accuracy balance. Code is available at https://github.com/Lzy-dot/SpecFlow

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：视觉语言模型（VLM）在推理时，由于需要处理来自视觉编码器的大量视觉 Token（例如，LLaVA-1.5 将一张图片编码为 576 个 token），导致计算成本极高，尤其是在预填充阶段。
- **现有方法局限**：现有的 Token 剪枝方法主要依赖基于注意力分数的 Top-K 选择，在高压缩比下存在两个关键缺陷：
    1.  **空间碎片化**：注意力分数分布“尖刺”且集中，Top-K 选择会破坏物体的空间连贯性，在被保留的 Token 中形成“空洞”。
    2.  **上下文丢失**：倾向于过度保留前景区域而丢弃背景信息，损害依赖于空间关系和场景级语义的任务。
- **研究意义**：提出一种新的范式，从“破坏性剪枝”转向“保守性凝聚”，旨在不破坏空间结构和多样性的前提下，大幅减少视觉 Token 数量，从而在保证精度的同时提升 VLM 的推理效率。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将 Token 剪枝重新定义为 Token 图上的重要性传播问题，采用“保守凝聚”策略，严格保证空间覆盖和统计守恒。
- **关键技术细节**：SpecFlow 框架包含三个核心步骤：
    1.  **HeatFlow: 基于谱热流的重要性扩散**
        - **动机**：不使用不可靠的原始自注意力图，而是构建 k 近邻（kNN）图来反映 Token 之间的语义相似性。
        - **过程**：
            - 从 [CLS] Token 的注意力分布中获取初始重要性信号 e(0)。
            - 计算基于 Token 特征相似度的 kNN 图，并构建行随机转移矩阵 W。
            - 执行热扩散迭代：`e(t+1) = (1 - α)e(0) + αW⊤e(t)`，其中 α 控制传播强度。该过程收敛于一个平衡保真度和图平滑性的唯一固定点，产生一个稳定、区域一致的重要性场。
    2.  **四叉树 Token 剪枝与能量分配**
        - **动机**：保证剪枝后 Token 的空间覆盖，避免 Token 全部集中在高能量区域。
        - **过程**：
            - 将扩散后的能量图 `E` 重塑为 2D 网格。
            - 自适应四叉树划分：根据区域内的能量方差，递归地将高能量变化的区域分割为更细的子区域，将低能量变化的背景区域保持粗粒度。
            - 能量引导的预算分配：根据每个叶子区域的总能量 `M(c)`，按比例分配 Token 保留配额 `qc`，确保保留与能量成比例的 Token 数量。
            - 在每个叶子区域内，选择能量最高的 `qc` 个 Token 保留。这保证了在每个重要区域都有代表性 Token 被保留。
    3.  **汇点 Token (Sink Tokens) 用于信息保守**
        - **动机**：被剪除的 Token 可能包含重要的上下文信息，直接丢弃会导致信息损失。
        - **过程**：不是直接丢弃被剪除的 Token（集合 `Š`），而是将其压缩成极少数的“汇点” Token。
            - **均值汇点 (Mean Sink)**：计算所有被剪除 Token 特征的均值 `umean`，捕获整体上下文。
            - **残差汇点 (Residual Sink)**：选择与均值特征差异最大的一个 Token 作为 `ures`，以促进多样性。
        - 最终的视觉 Token 序列由保留的 Token 和这两个汇点 Token 拼接而成。这确保了被压缩信息的统计守恒。

- **依赖中间表示**：方法需要访问视觉编码器的中间特征和 [CLS] Token 的注意力，对于不暴露内部表示的“黑盒” API 模型可能不适用。
