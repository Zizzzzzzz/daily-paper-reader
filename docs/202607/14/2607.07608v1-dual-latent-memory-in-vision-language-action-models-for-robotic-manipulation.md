## 摘要
主流视觉-语言-动作（VLA）模型主要在马尔可夫假设下根据当前观测预测动作，因此在处理长期、时间依赖的任务时存在困难。现有的记忆增强型VLA要么扩展观测窗口，要么从记忆库中检索历史信息作为辅助策略端上下文。然而，它们将记忆置于VLA推理的原生潜在嵌入空间之外，阻碍了历史经验与多模态推理及动作生成的无缝交织。为此，我们提出了LaMem-VLA，一种原生潜在记忆框架，将历史经验重构为潜在记忆标记，并直接将其与VLA推理交织。其核心包括四个协调组件：（i）管理者，将历史经验组织为互补的短期和长期记忆库；（ii）搜索者，利用多模态认知查询两个记忆库以检索上下文相关证据；（iii）压缩器，将检索到的证据重构为紧凑的短期和长期潜在记忆标记；以及（iv）编织者，将这些记忆标记与当前观测和指令注入到连续的嵌入序列中。通过在相同的连续潜在空间中完全表示、检索和消费历史经验，LaMem-VLA使记忆能够直接参与VLA推理，并在受限上下文下指导动作生成。在SimplerEnv和LIBERO上的大量实验证明了LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

- **研究背景**：主流视觉-语言-动作（VLA）模型基于马尔可夫假设，仅使用当前观测和指令预测动作，缺乏对历史状态、任务进展的感知，导致在长期依赖（long-horizon）的机器人操作任务中表现不佳（即“时间短视偏差”）。
- **现有方法局限**：已有的记忆增强方案要么通过扩展观测窗口（成本随长度增长，且有固定窗口上限），要么将历史证据作为外部辅助上下文（存放在记忆库，在VLA推理后附加到策略端），未能让记忆融入VLA模型的原生连续潜在推理空间，限制了历史经验与多模态感知、动作生成的流畅交织。
- **整体含义**：本文提出将机器人历史经验表示为“上下文原生潜在记忆”（context-native latent memory），在同一连续潜在空间中进行存储、检索和消费，使记忆直接参与VLA的推理和动作生成过程，从而缓解时间短视偏差，提升长时操作能力。

## 2. 方法论

- **核心思想**：构建双尺度潜在记忆（短期视觉记忆 + 长期语义记忆），通过四个协调模块实现记忆的完整闭环：
  1. **Curator（管理者）**：将历史经验组织为两个互补库——**短期记忆库**（存储近期视觉证据，如物体位置、状态变化）和**长期记忆库**（存储动作隐藏状态，体现任务进展和动作连续性）。采用余弦相似度合并冗余相邻单元的策略控制库容量（默认L=16）。
  2. **Seeker（搜索者）**：基于当前多模态认知表示（视觉+指令）构建上下文感知查询，从双库中检索Top-K个相关证据（默认K=8）。
  3. **Condenser（压缩器）**：将检索到的原始证据通过可学习的记忆槽（short-term slots Ls=8, long-term slots Ll=4）和轻量Transformer记忆成形器（memory former），重构为固定长度的**短期潜在记忆令牌**和**长期潜在记忆令牌**，与VLA嵌入空间兼容。
  4. **Weaver（编织者）**：将两种潜在记忆令牌（加上可学习源嵌入）与当前视觉令牌、指令令牌、动作查询令牌拼接为记忆增强的输入序列：  
     `St = [M_short; M_long; Xt; I; Qaction]`。  
     模型进行自注意力后，得到记忆引导的动作表示，再送入扩散动作专家生成动作序列（使用DDIM采样，10步去噪）。

- **技术细节**：使用7B参数的Prismatic VLM作为主干，扩散动作专家约300M参数。动作查询为可学习令牌，动作隐藏状态被写入长期记忆库。检索通过余弦相似度，Top-K操作不经过梯度传播。压缩器中的记忆成形器为两层Transformer，带掩码注意力。

## 6. 主要结论与发现

- LaMem-VLA在**SimplerEnv-Bridge**上平均成功率**73.9%**，超越CogACT（57.3%）和π0（69.2%）等；在**LIBERO**上平均成功率**97.6%**，超越MemoryVLA（96.5%）和CogACT（93.2%）。在长时套件（Long-10, Long-90）上提升尤为显著。
- 双尺度记忆互补：短期记忆提供当前片段视觉证据，长期记忆提供任务进展和动作连续性，两者缺一不可。
- 记忆潜在化注入（latent-native）优于外部策略端条件（policy-side conditioning），因为记忆直接参与自注意力，能更直接影响动作推理。
- 检索单元数K=8为最优，过少或过多均有下降；记忆令牌数Ls=8, Ll=4在性能与效率间取得平衡。

## 7. 优点

- **方法创新性**：首次将机器人历史经验统一表示为VLA推理潜在空间内的原生记忆令牌，实现了记忆与多模态推理的无缝融合，打破传统记忆作为外部辅助的设计范式。
- **双库设计**：短期视觉记忆和长期语义记忆互补，覆盖了不同时间尺度的需求，且通过压缩器输出固定长度令牌，避免上下文膨胀。
- **实验严谨**：消融实验覆盖核心设计（双库、注入方式、检索量、令牌数），验证了每个组件的积极作用。
- **性能显著**：在两大模拟基准上刷新SOTA，特别是在长时任务中提升明显，表明方法有效性。

## 8. 不足与局限

- **模拟环境限制**：所有实验均在模拟器（SimplerEnv, LIBERO）中进行，未在真实机器人平台上验证。真实场景中的噪声、视觉变化、物理交互不确定性可能影响记忆检索和推理效果。作者已说明在扩展真实实验。
- **计算成本**：引入了额外模块（seeker、condenser等），需要8卡H800训练，推理时增加了记忆检索和压缩步骤（但目前未报告详细的推理延迟对比）。对于资源受限场景可能需要优化。
- **记忆容量与检索机制**：默认库容量L=16，检索K=8，对于极长任务（如数百步）可能不足；Top-K检索依赖余弦相似度，对于高度相似或干扰场景可能引入噪声。
- **未讨论泛化性**：模型仅在特定仿真数据集上训练和评测，跨机器人、跨场景的泛化能力未测试。
