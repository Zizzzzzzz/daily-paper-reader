## 摘要
大型视觉语言模型（LVLMs）在视频理解方面取得了显著进展，但由于视觉标记数量庞大且上下文窗口有限，理解长视频仍然具有挑战性。视觉采样通过选择信息丰富的帧子集提供了一种实用的解决方案。然而，现有方法通常要么依赖于相关性感知采样，导致帧选择冗余且时间覆盖不足，要么采用固定的采样策略而不考虑查询类型。在本文中，我们提出了VisualRouter，一个无需训练且即插即用的查询引导视觉采样框架。VisualRouter首先将每个查询分类为全局或局部，然后应用相应的采样策略。对于全局查询，它采用相关性-覆盖混合策略，在保留查询相关视觉证据的同时保持时间覆盖。对于局部查询，它采用事件感知的帧选择策略，执行事件划分、段级帧分配和事件内帧选择，在有限数量的输入帧中共同平衡相关性、覆盖性和多样性。实验表明，VisualRouter在Video-MME、LongVideoBench和MLVU上分别以5.2%、7.7%和11.6%的提升一致地优于均匀采样，使用Qwen2.5-VL-7B，并在相同设置下优于现有的无需训练的视觉采样方法。

## Abstract
Large vision-language models (LVLMs) have achieved significant progress in video understanding, yet understanding long videos remains challenging due to the large number of visual tokens and limited context windows. Visual sampling provides a practical solution by selecting an informative subset of frames. However, existing methods typically either rely on relevance-aware sampling, leading to redundant frame selection and insufficient temporal coverage, or adopt a fixed sampling strategy regardless of query type. In this paper, we propose VisualRouter, a training-free and plug-and-play framework for query-grounded visual sampling. VisualRouter first classifies each query as either global or local and then applies the corresponding sampling strategy. For global queries, it employs a relevance-coverage hybrid strategy that preserves temporal coverage while retaining query-relevant visual evidence. For local queries, it adopts an event-aware frame selection strategy that performs event partitioning, segment-level frame allocation, and intra-event frame selection, jointly balancing relevance, coverage, and diversity with a limited number of input frames. Experiments show that VisualRouter consistently improves multiple LVLMs over uniform sampling, achieving gains of 5.2%, 7.7%, and 11.6% on Video-MME, LongVideoBench, and MLVU with Qwen2.5-VL-7B, and outperforming existing training-free visual sampling methods under the same setting.

### 一、论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：大型视觉语言模型（LVLMs）在处理长视频时面临严峻挑战，核心瓶颈在于视频帧数庞大导致的视觉 token 数量过多，远超模型有限上下文窗口的承载能力。
- **现有解决思路**：视觉采样（Visual Sampling）通过从长视频中筛选出信息量高的帧子集作为模型输入，成为一种低开销、部署灵活的预处理方案，无需重新训练 LVLM 或改动模型架构。
- **现有方法的不足**：
  - **均匀采样**（Uniform Sampling）虽然能保证时间覆盖，但未考虑与查询相关的视觉证据，容易将有限的帧预算浪费在无关或冗余的视频片段上。
  - **相关性感知采样**（如 Top-K、AKS）虽能筛选出与查询相关的帧，但往往存在两个问题：一是当查询缺乏显式视觉锚点（如情节、类型、摘要类问题）时，相关性评估不可靠；二是高相关帧常聚集于同一事件，导致证据冗余、覆盖不全。
  - **多样性感知方法**（如 BOLT、WFS-SB）虽引入多样性目标，但通常与相关性、覆盖性分开优化，难以兼顾。
  - **根本缺陷**：已有方法普遍对所有查询采用固定采样策略，没有根据查询所需的证据类型进行自适应调整。
- **核心观察**：不同查询对视觉证据的需求有本质差异。全局查询需要广泛时间覆盖，而局部查询需要聚焦于少数相关事件段。VisualRouter 正是基于这一观察提出。

### 二、论文提出的方法论

**核心思想**：VisualRouter 是一个免训练、即插即用的查询引导视觉采样框架，通过将查询分为全局与局部两类，分别激活对应的采样分支，实现采样策略与查询证据需求的自适应匹配。

**总体流程**（以图 2 为例）：

1. **视觉评分与特征提取**
   - 视频以 **1 FPS** 均匀降采样，得到候选帧序列 I = {Ii}Ti=1。
   - 使用 **BLIP2-ITM** 计算每帧与查询的语义相关性分数 s_itm（公式 3），并提取 L2 归一化的 BLIP2 语义特征 b̂_i。
   - 使用 **DINOv2** 提取视觉特征 d̂_i，计算相邻帧间的视觉变化分数 s_vis = 1 − ⟨d̂_i, d̂_{i−1}⟩（公式 4），用于捕捉外观突变和镜头切换。

2. **查询门控（Query Gating）**
   - 直接利用 LVLM 自身对每道问题（含候选选项）进行路由判断，不引入额外分类器或训练。
   - **LOCAL**：问题或至少一个选项中包含具体可定位的视觉锚点（如特定人物、物体、场景、可见动作、显示文字、时间线索等）。
   - **GLOBAL**：问题与所有选项均不包含可靠视觉锚点，需要视频级整体上下文才能回答。
   - 设计了专门的 prompt（图 3），明确给出了视觉锚点的定义和判定规则。对 LongVideoBench 数据集，直接全部路由到局部分支（因其问题通常需要定位和整合特定时段的证据）。

3. **全局查询分支：相关性–覆盖混合采样**
   - 将 K 帧预算分为两部分：⌊K/2⌋ 帧通过均匀采样保证时间覆盖；剩余 K − ⌊K/2⌋ 帧从未选候选帧中选取相关性分数最高的帧。
   - 合并两子集后按时间排序；若出现重复帧，则用未选帧中相关性最高者填补空缺。
   - 该策略平衡了全局上下文保留与查询相关证据的获取。

4. **局部查询分支：事件感知采样（算法 1）**
   - **阶段一：事件划分（Event Partitioning）**
     - 对 BLIP2 语义特征计算 **指数移动平均（EMA）** 参考向量 μi（公式 5），并定义语义漂移分数 s_sem = 1 − ⟨b̂_i, μ_{i−1}⟩（公式 6），度量当前帧与之前视频上下文的语义差异。
     - 融合语义漂移与视觉变化信号，经过平滑和鲁棒归一化后得到融合边界分数 p_i = λ_s·s̄_sem + λ_v·s̄_vis（公式 7），其中 λ_s=0.6，λ_v=0.4。
     - 通过局部峰值检测识别事件边界，将视频划分为 M 个连续事件段 C = {Cm}Mm=1。
   - **阶段二：段级帧分配（Segment-Level Frame Allocation）**
     - 对每个事件段 Cm 计算峰值相关性分数 s_max_m 和平均相关性分数 s_mean_m（公式 8、9），结合段长度 ℓm 定义重要性权重 w_m = √(s_max_m · s_mean_m) · √ℓm（公式 10）。
     - 按权重比例分配帧数：k̂_m = K · w_m / Σw_j（公式 11），取整后余数分配给小数部分最大的段，确保 Σk_m = K。
   - **阶段三：事件内帧选择（Intra-Event Frame Selection）**
     - 为避免在同一事件段内选出语义高度相似的冗余帧，采用 **查询感知的 k-DPP（Determinantal Point Process）** 进行选择。
     - 帧质量分 q_i = (s_itm)^γ（γ>1，增强高相关帧权重），语义相似度 A_ij = ⟨b̂_i, b̂_j⟩，构建 DPP 核矩阵 L^(m)_ij = q_i·A_ij·q_j（公式 12）。
     - 在每段内通过**贪心替代最大化 log 行列式**（公式 14）选恰好 k_m 帧，最终合并并按时间排序，得到最终帧集合 T。

### 六、论文的主要结论与发现

1. **显著的性能提升**：VisualRouter 一致性地提升了多种 LVLM 在三个长视频基准上的性能，提升幅度 2.5%–12.2%。以 Qwen2.5-VL-7B、16 帧为例，Video-MME、LongVideoBench、MLVU 分别提升 5.2%、7.7%、11.6%。

3. **长视频和复杂问题收益更大**：在中长视频、OCR 和计数类问题上提升最为明显（OCR 提升 12.95%，计数提升 7.09%），说明自适应采样在证据分布复杂、视觉信息稀疏的场景下尤为有效。
4. **帧预算越紧，优势越明显**：8 帧设置下收益最大（提升 4.6–7.7 个百分点），体现了方法对有限帧预算的高效利用。

6. **所有组件均有贡献**：查询门控、事件划分、相关感知帧分配、k-DPP 事件内选择对最终性能均有正面贡献，缺一不可。

### 七、优点

- **免训练、即插即用**：无需额外训练、无架构修改，可直接作为预处理模块应用于任意 LVLM，部署灵活性强。
- **查询自适应**：首次将查询划分为全局与局部并分别设计采样策略，打破了固定策略的思路局限，更加贴近实际问答的多样化需求。
- **多目标联合优化**：局部分支通过事件级流水线（划分→分配→选择）将相关性、覆盖性、多样性有机结合，而不是割裂优化。
- **方法设计精巧**：利用 EMA 语义漂移和 DINOv2 视觉差异进行事件划分，比单纯相邻帧比较更稳健；利用 k-DPP 在段内联合优化相关性和多样性，理论上优雅且在实践中有明显收益。
- **实验验证全面**：涵盖多模型、多基准、多帧数、多模型规模，并设置充分的消融实验，验证了方法泛化能力和每个组件的必要性。

### 八、不足与局限

- **额外计算开销**：尽管免训练，但 BLIP2-ITM 和 DINOv2 对所有候选帧的特征提取需要额外的推理成本，候选帧数量随视频时长线性增长，对极长视频可能产生较大计算负担。论文未报告此开销的具体量级。
- **1 FPS 采样限制**：以 1 FPS 构建候选帧序列，对于快速动作或短暂事件可能漏掉关键视觉信息，存在信息丢失风险。
- **依赖 BLIP2 相关性质量**：整体性能受限于 BLIP2-ITM 打分的准确性。虽然论文对比了多种打分器，但在复杂语义或跨模态推理问题上，相关性打分的可靠性仍是潜在制约因素。
- **事件划分超参数需人工设定**：λ_s 和 λ_v 的取值（0.6/0.4）固定，峰值检测阈值也需针对不同数据调整，跨数据集泛化时可能需要调参。
- **缺少与训练型方法的直接对比**：训练型方法（如 SeViLA、FFS、Frame-Voyager 等）以不同条件（不同骨干、不同帧数）被引用为参考结果，但未在相同条件下与 VisualRouter 进行公平对比，无法直接判断免训练方法相对于训练型方法的优劣。
