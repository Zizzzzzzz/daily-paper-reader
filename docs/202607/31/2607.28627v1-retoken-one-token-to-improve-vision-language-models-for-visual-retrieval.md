## 摘要
长视觉上下文对视觉-语言模型构成挑战：随着干扰物数量的增加，性能会下降，而且在GPU内存限制下，一次性处理所有token在计算上不可行。我们提出了ReToken，这是一种可学习的嵌入，作为显式检索目标进行训练，从预填充的视觉KV缓存中选择一组稀疏的、与查询相关的视觉token。仅在小型图像问答数据集上训练，ReToken在图像和视频基准测试上均获得了一致的提升：在Visual Haystacks上，它使Qwen3VL-8B提升了13.4个百分点，InternVL3.5提升了12.4个百分点（相对提升超过20%）；在LVBench上，它零样本迁移到长视频，使Qwen3VL-8B获得8.0个百分点的提升。由于其轻量级设计，训练和长视频推理均可在一张H100上完成。代码可在以下网址获取：https://github.com/avaxiao/ReToken

## Abstract
Long visual context poses a challenge for vision-language models: performance degrades as the number of distractors grows, and processing all tokens at once is computationally infeasible under GPU memory constraints. We present ReToken, a single learnable embedding trained as an explicit retrieval target that selects a sparse set of query-relevant visual tokens from a pre-filled visual KV cache. Trained on only a small image-QA dataset, ReToken yields consistent gains across image and video benchmarks: on Visual Haystacks it improves Qwen3VL-8B by 13.4 points and InternVL3.5 by 12.4 points (>20% relative), and on LVBench it transfers zero-shot to long video for an 8.0-point gain with Qwen3VL-8B. Thanks to its lightweight design, both training and long-video inference fit on a single H100. Code is available at: https://github.com/avaxiao/ReToken

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉-语言模型（VLM）在处理长视觉上下文（如图像集合或长视频）时面临两大困境：
  1. **性能退化**：当输入中包含大量与查询无关的干扰物（distractors）时，模型难以定位与问题相关的视觉证据，回答准确率显著下降。
  2. **计算不可行性**：在GPU内存限制下，一次性处理全部视觉token（对于长视频可能达到数万甚至数十万个token）在计算上不可行。
- **关键观察**：作者发现，将长视觉输入处理转化为“检索问题”——即先选出一小部分与查询相关的帧或token，再从这些稀疏上下文中生成答案——是一种有效策略。然而，现有基于注意力（attention）信号的检索机制在VLM中**不可靠**：注意力分数与视觉内容的相关性很弱（如图1a所示），基于注意力的检索器在QAEgo4D Test-MC上平均Recall@1仅为5.1%。
- **核心洞见**：作者发现了一个“不对称性”——**值空间（value space）比查询-键空间（query-key space）携带更强的检索信号**。用精确的目标短语匹配平均视觉值投影（value projections），比传统的查询-键匹配在两个VLM骨干网络上分别带来12.3和5.0个百分点的Recall@1提升（Tab.1）。
- **整体含义**：论文提出通过一个轻量级可学习token——ReToken——来利用值空间的优势，实现高效、精准的视觉检索，从而在不修改VLM的前提下提升长上下文视觉理解能力。

## 2. 论文提出的方法论

### 2.1 核心思想

ReToken是一个**单一可学习嵌入向量** \(X_r \in \mathbb{R}^d\)，被追加到问题（question）token之后，作为**显式的检索目标**进行训练。其核心逻辑是：

> 用ReToken的最终层输出（经过一个轻量投影矩阵）与每个帧的平均值向量（mean value vector）计算余弦相似度，作为该帧与查询的相关性分数，从而选出Top-K个最相关帧。

### 2.2 关键技术细节

- **检索分数计算**：在最终层 \(L_N\)，对第 \(f\) 帧的检索分数为：

  \[
  s_f^{(N)} = \cos\left(W_r X_r^{(N)}, \bar{v}_f^{(N)}\right)
  \]

  其中 \(\bar{v}_f^{(N)}\) 是第 \(f\) 帧所有视觉token在最终层的平均值向量，\(W_r \in \mathbb{R}^{d \times d}\) 是唯一的投影矩阵（可学习），\(X_r^{(N)}\) 是ReToken在最终层的输出。**新增参数仅有两个**：检索token \(X_r\) 和投影矩阵 \(W_r\)。

- **训练损失**：使用**类别平衡的二元交叉熵损失**（class-balanced binary cross-entropy）：

  \[
  \mathcal{L}_{ret} = -\frac{1}{|F^+|}\sum_{f \in F^+} \log \sigma(\tau s_f^{(N)}) - \frac{1}{|F^-|}\sum_{f \in F^-} \log \sigma(-\tau s_f^{(N)})
  \]

  其中 \(F^+\)、\(F^-\) 分别为相关/不相关帧集合，\(\tau\) 是可学习的logit缩放参数。默认情况下VLM被冻结，仅训练ReToken和投影矩阵。

- **部分微调变体**：作者还探索了“仅微调VLM前3层”的变体，此时额外加入生成损失（next-token prediction loss）\(\mathcal{L}_{gen}\)，总损失为 \(\mathcal{L} = \mathcal{L}_{ret} + \lambda \mathcal{L}_{gen}\)。

- **两阶段推理流程**（retrieve-then-answer）：
  1. **视频编码一次**：将视频编码为持久化的KV缓存（短期视频用单次前向，长视频用滑动窗口注意力的分块编码）；
  2. **第一遍检索**：将ReToken追加到问题后，在最终层计算帧级检索分数，选出Top-K帧；
  3. **第二遍作答**：仅加载被选中帧的KV缓存，与问题一起生成答案。

- **长视频特殊处理**：在检索的第一遍前向中，由于早期层的注意力预算有限，ReToken在早期层的注意力被限制在按层内值相似度选出的Top-K₁=256帧内，最终层再精排得到最终Top-K。

## 6. 论文的主要结论与发现

1. **注意力（query-key）空间不适合作为VLM的视觉检索信号**：注意力分数与视觉相关性弱相关，且对检索文本的选择高度敏感。
2. **值空间（value space）是更强的检索信号**：值投影携带实际通过注意力传播的内容，与文本对齐程度更高；用精确目标短语匹配平均值向量，在Qwen3VL-8B上Recall@1达78.0%（vs 65.7% query-key），在InternVL3.5上达83.8%（vs 78.8%）。
3. **ReToken带来显著且一致的增益**：
   - Visual Haystacks上（C=50、K=1）：Qwen3VL-8B从58.6→72.0（+13.4），InternVL3.5从57.3→69.7（+12.4），相对提升超20%；
   - 长视频零样本迁移：LVBench上Qwen3VL-8B从40.6→48.6（+8.0）；
   - 检索精度高：在K=1时，ReToken能保留GT Cache上界的绝大部分准确率（72.0 vs 80.7）。
4. **ReToken在证据局部化、可命名的问题上表现最好**（如关键信息检索+15.4、实体识别+10.5），在证据分散的问题（如摘要）上会伤害性能（-5.2）。
5. **部分微调VLM早期层**能进一步提升图像任务性能（C=50时75.0 vs 72.0），但会降低视频零样本迁移能力（QAEgo4D上60.0→58.0），原因是图像-视频分布差异导致域偏移。
6. **轻量高效**：训练与长视频推理都能在单张H100上完成，每个问题仅增加约0.4秒延迟。

## 7. 优点

1. **洞察深刻且具普适性**：对“值空间 vs 查询-键空间”的系统性诊断具有方法论价值，可能影响后续VLM检索与理解研究的设计选择。
2. **极简设计**：仅一个可学习token + 一个投影矩阵，不修改VLM参数（默认冻结），即插即用，易于复现和集成。
3. **跨模态迁移能力**：仅用多图像QA数据训练，却能零样本迁移到长视频基准，说明学到的是通用的检索能力而非数据集偏置。
4. **实验严谨**：包含大量消融、错误分析、效率测量，并提供了GT Cache上界进行归因分析（如KV缓存被干扰物污染的现象），分析深度较高。
5. **实用性强**：两阶段缓存与检索方案（encode once, retrieve per question）在多问题场景下计算效率高，且训练/推理成本对学术机构友好。

## 8. 不足与局限

1. **训练数据单一**：仅用MIRAGE（多图像QA）数据训练，未在视频数据上训练，限制了其对时间结构（如跨帧推理、时序定位）的建模能力。
2. **帧独立评分**：ReToken对每帧独立打分，无法处理需要跨帧组合信息或时间偏移（如“在我进入房间之前发生了什么”）的查询。
3. **部分场景失效**：在摘要类问题上性能下降（-5.2），因为此类问题需要全局均匀覆盖而非聚焦检索。
4. **两遍推理开销**：额外的检索前向传递增加了延迟（约0.4秒/问题），尽管绝对开销不大，但在实时场景中可能受限。
5. **长视频的早期层注意力限制**：K₁=256帧的启发式设置可能在某些场景下限制检索精度；且该超参未见敏感性分析。
6. **InternVL3.5训练不充分**：仅训练1个epoch导致其在最大上下文规模（C=100）上增益明显低于Qwen3VL-8B，骨干间的公平对比受限。
7. **部分微调的双刃剑效应**：微调早期层在图像任务上更好，但在视频上反而更差，域偏移问题未得到解决。
8. **token级检索未实现**：帧级均值池化会稀释仅占据少量token的证据，论文将此列为未来方向，说明当前方法在细粒度证据上存在局限。
