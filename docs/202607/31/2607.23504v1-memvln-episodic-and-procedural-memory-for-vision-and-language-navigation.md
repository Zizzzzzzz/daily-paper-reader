## 摘要
连续环境中的视觉与语言导航（VLN-CE）要求智能体在低延迟执行动作的同时，维护长期视觉历史以保持轨迹一致性。现有的基于视频的VLN方法通常难以同时满足这两个需求。为解决这些挑战，我们提出了MemVLN，一种新颖的VLN框架，以实时推理效率（14 FPS）实现了最先进的性能。MemVLN利用视觉编码器处理连续观测，并使用大语言模型（LLM）来解释指令和生成动作。我们方法的核心是一种采用金字塔分辨率的情景记忆管理机制。该机制将计算集中在近期感知上，同时保留压缩的长期历史。作为该设计的补充，我们引入了程序记忆，通过紧凑的原子级中层动作词汇表实现快速动作，绕过了自回归解码延迟。在VLN-CE上的实验表明，MemVLN-4B在R2R中比基线Qwen3-VL-4B架构高出5.8%的SR，在RxR中高出9.7%的SR，同时推理延迟实现了7倍的加速。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to maintain long-horizon visual history for trajectory consistency while executing actions with low latency. Existing video-based VLN approaches typically struggle to satisfy both demands simultaneously. To address these challenges, we propose MemVLN, a novel VLN framework that achieves state-of-the-art performance with real-time inference efficiency (14 FPS). MemVLN utilizes a visual encoder to process continuous observations and a Large Language Model (LLM) to interpret instructions and generate actions. Central to our approach is an Episodic Memory management that applies pyramidal resolutions. This mechanism concentrates computation on immediate percepts while retaining compressed long-term history. Complementing to this design, we introduce Procedural Memory for fast action with a compact vocabulary of atomic mid-level actions to bypass auto-regressive decoding latency. Experiments on VLN-CE show that MemVLN-4B surpasses the baseline Qwen3-VL-4B architecture by 5.8\% SR in R2R and 9.7\% SR in RxR, while achieving a 7$\times$ speedup in inference latency.

# MemVLN 论文总结

## 1. 核心问题与整体含义

- **研究背景**：连续环境下的视觉与语言导航（VLN-CE）要求智能体在一个无先验地图的 3D 空间中，依据自然语言指令从起点导航到目标点。与基于离散图的方法不同，VLN-CE 需要智能体将语言指令直接映射到连续的低层动作控制上，因此面临两大核心需求：
  1. **长期视觉历史**：需要维护长时段的历史观测以保证轨迹一致性和避免路径漂移；
  2. **低延迟执行**：需要实时响应环境变化以完成连续控制。
- **现存问题**：已有基于视频的 VLN 方法难以同时满足这两个需求。固定采样少量帧（如 8 帧）会损失时间密度；而采用 token merging / pooling 压缩视觉序列的方法（如 Uni-Navid、StreamVLN 会破坏均匀的 2D 空间网格，与现代 LVLM 的位置编码（M-RoPE）和序列结构（DeepStack）不兼容。
- **论文意义**：提出 MemVLN，用生物启发的“情景记忆 + 程序记忆”机制，同时解决了长期视觉上下文管理与实时推理速度问题，仅使用单目 RGB 输入即达到 VLN-CE 上的 SOTA 性能，并将推理速度提升到 14 FPS。

## 2. 论文提出的方法论

### 2.1 整体架构

- MemVLN 由三部分组成：
  1. **视觉编码器**：处理连续的单目 RGB 观测；
  2. **大型语言模型（LLM）**：以 Qwen3-VL 为骨干，负责指令理解与跨模态决策；
  3. **记忆机制**：包括用于观测管理的情景记忆和用于快速动作的程序记忆。
- 流程：历史帧 → 金字塔分辨率采样 → 视觉编码 → 与指令拼接输入 LLM → 输出单一动作 token → 执行电机控制。

### 2.2 情景记忆（Episodic Memory）：金字塔分辨率

- **动机来自注意力分析**：
  - 最近 4 帧的注意力权重占总视觉注意力 50% 以上；
  - 越近的帧注意力权重显著越高，早期帧几乎被忽略。
- **为什么不采用 token merging**：
  - Token merging 在隐空间中根据语义相似度合并 token，会破坏均匀的空间网格，与 M-RoPE、DeepStack 等现代架构不兼容；
  - 金字塔分辨率在原始像素空间直接下采样，保持严格均匀的空间拓扑，可无缝适配现有骨干。
- **具体策略**：
  - 将历史帧划分为三个时间层：immediate（立即）、short-term（短期）、long-term（长期），由两个时间边界 \(B_{\text{short}}\)、\(B_{\text{long}}\) 分隔；
  - 对距离当前时间步不同的帧采用不同分辨率：\(r_{\text{imm}} > r_{\text{short}} > r_{\text{long}}\)，即近期帧高分辨率、远期帧低分辨率；
  - 分辨率设置使整个长期序列的 token 总量不超过一帧即时帧的 token 数，从而在不增加上下文预算的前提下大幅扩大有效回看窗口；
  - 文中还比较了 U-shaped、descending、ascending 三种金字塔变体，最终 ascending（离当前越近分辨率越高）效果最好。

### 2.3 程序记忆（Procedural Memory）：快速动作

- **延迟分析**：
  - 自回归解码是主要瓶颈：首 token 生成（pre-filling）耗时显著，后续 token 生成随输出长度线性增长；
  - 例如生成 10 个 token 需 360 ms，超过实时控制阈值。
- **快速动作机制**：
  - 将导航动作表示为一个紧凑的原子中层动作 token 词汇表 \(A_{\text{aug}}\)（共 10 个动作）：stop、前移 25/50/75 cm、左转/右转 15°/30°/45°；
  - 从 LLM 原始词表中借用单个 token 来表示这些动作，使整个决策只需**一次前向传播**即可完成，完全绕过自回归逐 token 解码循环；
  - 该设计类似人类的程序性记忆（自动执行的技能），兼顾了动作精细度与实时性。

### 2.4 训练目标与数据

- **目标函数**：对每个时间步 \(t\)，以交叉熵损失最大化在给定视觉特征 \(F_t\) 和指令 \(I\) 下预测正确动作 \(a_t^* \in A_{\text{aug}}\) 的概率：
  \[
  L = -\frac{1}{T} \sum_{t=1}^{T} \log P(a_t^* | F_t, I; \theta)
  \]
- **训练数据**包括：R2R、RxR 及其 EnvDrop 增强版本，ScaleVLN 数据（416K 对），557K 条人类导航轨迹，以及 278K 条 DAgger 算法生成的交互式合成数据。

## 3. 实验设计

- **Benchmark**：
  - R2R-CE（约 5.6K 条英文轨迹，平均长度约 10m）；
  - RxR-CE（约 126K 条多语言指令，平均长度约 15m，更具挑战性）；
  - 均在 Habitat 模拟器中的 Matterport3D 场景下，采用 Val Unseen 划分、90° 水平视场角，评估指标为 NE、OS、SR、SPL。
- **对比方法**：
  - Waypoint-based 方法：CMA、VLN↔BERT、Sim2Sim、GridMM、ETPNav、ScaleVLN；
  - 连续动作控制方法：AG-CMTP、R2R-CMTP、LAW、CM2、WS-MGMap、Seq2Seq、CMA；
  - VLM 方法：NaVILA-8B、Uni-NaVid-7B、StreamVLN-7B。
- **主实验结果**：
  - MemVLN-4B：R2R 上 OS 63.2 / SR 56.6 / SPL 50.0；RxR 上 SR 66.5 / SPL 57.4；
  - MemVLN-8B：R2R 上 OS 65.3 / SR 58.4 / SPL 51.2；RxR 上 SR 66.0 / SPL 57.3；
  - 在仅使用单目 RGB 的条件下，超越了使用全景图、深度、里程计等方式的方法，达到最先进水平；
  - 额外实验表明，仅用 R2R 训练后在 RxR 上零样本测试，SR 达 38.4%，优于 NaVILA 的 34.3%。

## 6. 主要结论与发现

1. MemVLN 通过金字塔分辨率的情景记忆，在不增加 token 预算的前提下有效扩展了视觉历史窗口，显著提升导航成功率与路径效率；
2. 程序记忆将动作空间压缩为原子中层 token，单次前向即可输出动作，在提升推理速度的同时还提高了导航精度（可能是因为避免了长序列生成的不稳定性）；
3. 单一模型、仅用单目 RGB 输入，即可在 R2R-CE 和 RxR-CE 上超越依赖深度、全景图、里程计的传统方法，表现出很强的泛化能力；
4. 训练数据规模与质量很关键，尤其是 DAgger 交互式数据带来的增益最大（RxR 上 OS 提升 4.6%）；R2R 训练的模型可零样本迁移到 RxR 上，且优于现有 VLM 基线。

## 7. 优点

  - 将认知科学中情景记忆与程序记忆的概念引入 VLN-CE，思想新颖且解释性强；

- **可解释性不足**：
