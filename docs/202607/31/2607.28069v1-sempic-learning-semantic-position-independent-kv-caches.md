## 摘要
长上下文检索和智能体工作负载在指令、历史记录和文档顺序不断变化的情况下反复重用相同的文档。前缀缓存无法利用这种重用，而位置无关缓存（PIC）仍然不可靠，因为独立编译的KV状态缺乏其将被使用时的未来上下文。我们的诊断表明，一个学习得到的边界条件化基线在可重用块边界附近显著降低了注意力偏差，但留下了内部和任务级残差，这提示需要对文档表示本身进行适配。我们提出了SemPIC，它训练一个启用LoRA的Writer，通过行为蒸馏编译每层的原生文档KV，同时保留预训练解码器作为不变的Reader。适配仅限于离线缓存构建，保留了标准KV接口和缓存命中解码路径。我们进一步引入了KV梯度检查点，它在不切断通过缓存KV的梯度的情况下减少了峰值训练内存。在三个模型和四个任务上，SemPIC将KV Packet上的平均微F1从0.53提高到0.60，接近完全重计算的0.62。

## Abstract
Long-context retrieval and agentic workloads repeatedly reuse the same documents under changing instructions, histories, and document orders. Prefix caching cannot exploit this reuse, while position-independent caching (PIC) remains unreliable because independently compiled KV states lack the future context in which they will be consumed. Our diagnostics show that a learned boundary-conditioned baseline sharply reduces attention deviation near reusable-block boundaries but leaves interior and task-level residuals, motivating adaptation of the document representation itself. We present \emph{SemPIC}, which trains a LoRA-enabled Writer to compile native per-layer document KVs through behavioral distillation while retaining the pretrained decoder as an unchanged Reader. Adaptation is confined to offline cache construction, preserving the standard KV interface and cache-hit decoding path. We further introduce KV Gradient Checkpointing, which reduces peak training memory without severing gradients through cached KVs. Across three models and four tasks, SemPIC raises mean micro-F1 over KV Packet from 0.53 to 0.60, approaching Full Recompute at 0.62.

# SemPIC：学习语义位置无关的KV缓存

## 1. 核心问题与研究动机

- **核心痛点**：长上下文检索增强生成（RAG）和智能体（agentic）工作负载中，同一份文档会在不同的指令、历史记录和文档顺序下被反复使用。然而，传统前缀缓存（Prefix Caching）仅在重用内容位于相同前缀时才能生效，无法高效复用这些文档。
- **位置无关缓存（PIC）的缺陷**：PIC 允许将文档独立编译为 KV 缓存后按需拼接，但独立编译的 KV 状态仅编码了编译时可见的上下文——当文档在实际请求中被置于新的上下文时，其内容"在语义上是不完整的"，导致质量严重下降。RoPE 重旋转（re-rotation）只能修正位置信息，无法补足缺失的上下文语义。
- **现有方法的局限**：已有 PIC 方法（如 CacheBlend、EPIC、KV Packet、COMB、C²KV）或依赖在线重算、边界条件化、辅助缓存编码器，但都没有回答一个根本问题——**能否在离线状态下学习文档自身的原生 KV 表示，使其被未经修改的解码器在任意未见过的文档组合下直接复用？**
- **设计启发**：作者通过对 KV Packet（边界条件化基线）的诊断分析发现，边界条件化可以大幅降低边界附近的注意力偏离，但文档内部区域的注意力偏离和任务级误差仍然显著，形成"边界-内部不对称"现象。这直接推动了将适配范围从块边界扩展到**整个文档表示**的设计思路。

## 2. 方法论：SemPIC 核心技术

### 2.1 核心思想：Writer–Reader 分离架构

- **SemPIC** 通过 **可训练的 Writer** 和 **不可变的 Reader** 将文档编译与后续消费解耦：
  - **Writer**（文档编译器）：使用预训练解码器参数 θ 加上**可切换的 LoRA 适配器参数 φ**，独立处理每个可复用文档，生成每层原生 KV 缓存：`Kφ(Di) = Wθ,φ(Di) = {Kℓi,φ, Vℓi,φ}Lℓ=1`
  - **Reader**（在线解码器）：使用**冻结的预训练基座模型** Gθ，消费 Writer 产出的 KV 缓存（此时 LoRA 被禁用），进行链接、位置分配和自回归解码。
- 关键设计：**LoRA 仅在离线编译文档时启用**，在线查询预填充、目标 token 计算和推理生成阶段均保持禁用。这一不对称性将全部学习行为隔离在文档编译器内，**不改变存储的 KV 对象格式，也不改动在线解码路径**。

### 2.2 行为蒸馏（Behavioral Distillation）

- 训练目标：让 Reader 在消费独立编译缓存时的输出分布匹配**全量重计算（Full Recompute）**的教师分布。
- 教师分布（全上下文）：`pt^T = pθ(yt | P, D1, S1, ..., Dm, Sm, Q, Y<t)`
- 学生分布（缓存拼接）：`pt^S = pθ(yt | P, R(Kφ(D1), S1, ..., Kφ(Dm), Sm), Q, Y<t)`，其中 R 为链接算子（位置分配 + 因果掩码）。
- 损失函数为温度 τ 缩放的 KL 散度：`LKD = τ² Σᵢ Σᵣ Σₜ DKL(qᵢ,ᵣ,ₜ^T ‖ qᵢ,ᵣ,ₜ^S)`，实验取 τ=1。
- **梯度路径**：梯度经由每一层的 KV 张量回传到 Writer 的 LoRA 参数（公式 9），KV 同时充当"可复用表示"和"可微接口"的双重角色，实现了对文档表示的逐 token 语义级重塑。

### 2.3 KV 梯度检查点（KV Gradient Checkpointing）

- **问题**：Writer 的每一层 KV 都需保留梯度路径，意味着所有层产生 KV 的中间激活都需驻留显存，长文档训练极易 OOM。
- **解决方案**：在每个 Writer 层设置检查点，将层函数视为 `(hℓ+1, Kℓ, Vℓ) = Cℓθ,φ(hℓ)`。前向传播后丢弃层内中间激活，反向传播时重新计算；同时保证重放正确的 LoRA 启用上下文。
- **效果**：在不切断 KV 梯度路径、不改变缓存值和推理路径的前提下，显著降低峰值训练显存。

### 2.4 与边界适配的组合（Joint）

- 为验证文档级适配与边界适配是否互补，作者在 SemPIC 基础上**共同训练共享的 Header/Trailer 边界嵌入**与 LoRA Writer，得到 Joint 变体。训练后推理路径与 SemPIC 相同（无文档重算、无辅助模型）。

## 6. 主要结论与发现

1. **主结果**：SemPIC 在 12 个设置中的 10 个优于 KV Packet，将平均微 F1 从 0.53 提升至 0.60，接近 Full Recompute 的 0.62。在所有 Qwen3 设置中均匹配或超越 KV Packet（4B 平均 +0.10，8B 平均 +0.13）。
2. **Joint 互补性**：边界适配与文档级适配可互补——Joint 在 Llama MuSiQue 上达到 0.38（SemPIC 为 0.28），总体平均 0.61，为所有 learned-cache 方法最佳。
3. **注意力诊断**：SemPIC 在所有 12 个设置中都将 Full-relative 内部注意力误差（Rint）降至 KV Packet 之下（0.564–0.985 vs 0.664–1.257），且 F1 恢复率普遍提高。
4. **跨域迁移**：在 Qwen3-8B 上，SemPIC 将 KV Packet 的 4 任务平均分数在每个训练源下都提升；混合训练是最优训练源（KV Packet 0.51 → SemPIC/Joint 0.57）。
5. **块局部残余**：即使任务表现改善，SemPIC 在块首 token（offset 1）仍存在强烈的注意力集中（T₁ 为 132.5–3248.3 vs offset 2–8 的 0.61–23.49），说明"语义化"与注意力 sink 现象可共存。
6. **训练可行性**：KV 梯度检查点在 FBS=1 时以约 3.4 倍训练时间换取约 24% 峰值显存降低；在 FBS=8 时仅牺牲 8% 时间便降低 56% 显存，且使原先 OOM 的长文档任务可训练。

## 7. 优点与亮点

- **问题定位精准**：通过系统的诊断实验揭示"边界-内部不对称"现象，从经验数据推导出设计需求，研究思路清晰有力。
- **接口优雅**：SemPIC 不改变 KV 存储格式、不引入辅助模型/交叉注意力/额外在线计算，适配全部离线完成；缓存命中路径与标准解码完全一致，实用性强。
- **训练机制新颖**：KV 梯度检查点解决了"逐层 KV 作为可微接口"带来的显存瓶颈，在不牺牲梯度可靠性的前提下扩展可训练上下文长度。
- **理论洞察明确**：明确区分"逐坐标逼近"与"语义缓存"——目标不是重建某个特定张量，而是保持下游预测分布（p^T）在不同组合下的鲁棒性。
- **Joint 组合设计**：展示文档级与边界级适配的互补性，为后续工作提供有价值的组合方向。
- **评估全面**：同时报告质量、效率（FLOPs 与 TTFT 双视角）、注意力诊断、迁移性、局部残余效应、内存-时间权衡，覆盖面广且区分不同层面。

## 8. 不足与局限

- **因果关系未证实**：注意力偏离降低与 F1 提升之间的关系仅为描述性证据，作者明确承认"不建立注意力偏差导致 F1 差距的因果关系"。
- **样本量偏小且无统计检验**：每配置仅 100 个示例，无多次重复运行、无方差/置信区间报告；显存测量仅单次采样，可能遗漏短时分配峰值。
- **跨域迁移结果不稳定**：Qwen3-4B 在 MuSiQue 训练源下 SemPIC 不敌 KV Packet（0.37 vs 0.41）；部分迁移矩阵中某些目标任务分数显著退化（如 Qwen3-8B NIAH 训练源下 SemPIC 在 Biography 仅 0.25，远低于 KV Packet 的 0.53），说明**数据分布漂移下 Writer 的泛化仍然脆弱**。
- **特定模型-任务失败**：Llama-3.1-8B 的 MuSiQue 上 SemPIC（0.28）显著低于 KV Packet（0.37），表明文档级全量适配并非在所有场景下都优于边界适配。
- **注意力 sink 问题未解决**：块首 token 的极端注意力集中（高达 3248 倍于内部平均密度）可能在更大模型或更长上下文下引发未知的行为偏差。
- **训练开销较高**：每个模型-每个任务域需要单独训练一个 LoRA Writer（5 epoch）；FBS=1 时 KV 梯度检查点的训练时间成本接近 3.4 倍，跨 5 个训练源的实验成本相当可观。
- **效率测量边界有限**：FLOPs 为分析估计值，TTFT 为单次同步墙钟测量，均排除 I/O、数据预处理、缓存传输等系统开销，可能无法反映真实部署中的端到端性能；选择性重算 sweep 与 learned-cache 的对比并非严格等预算（FLOPs vs TTFT 分离报告）。
- **评估任务范围有限**：虽然覆盖了 RAG 与多跳 QA，但未涉及代码生成、长文档摘要、多轮对话记忆等常见智能体场景；也未测试更长上下文（超过单文档 4K/8K 级别）和更多文档数量下的表现。
