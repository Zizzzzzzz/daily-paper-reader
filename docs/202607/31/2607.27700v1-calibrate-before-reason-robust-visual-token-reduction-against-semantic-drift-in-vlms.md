## 摘要
大型视觉语言模型（VLMs）由于视觉令牌序列过长而遭受难以承受的推理开销。然而，现有的视觉令牌缩减方法主要通过剪枝或压缩冗余令牌来提高效率，而没有检查所得表示是否与原表示在语义上保持一致。将原始的N令牌视觉序列映射到K令牌可能会丢弃、稀释或错误分配关键视觉线索，引发严重的语义漂移，从而偏离VLM的理解。本文首次将“推理前校准”原则引入视觉令牌缩减，并提出CaRe，一个无需训练的鲁棒框架，在推理前校准紧凑的视觉表示，以保持VLM中的语义保真度。CaRe包含两个互补模块：1）扰动鲁棒校准锚定，它在多方向扰动下识别具有稳定模型侧影响的校准锚点；2）置信门控令牌校准，它从未选中的令牌中提取可靠的校准信号并将其注入锚点。跨多种VLM架构和基准的广泛评估验证了CaRe优于最先进的令牌缩减基线。在剪枝94.4%的视觉令牌时，我们的方法保留了原始全令牌性能的96.4%，相对于未剪枝的原始模型，端到端推理速度提升高达2.30倍。

## Abstract
Large Vision-Language Models (VLMs) suffer from prohibitive inference overhead due to long sequences of visual tokens. However, existing visual token reduction methods mainly improve efficiency by pruning or compressing redundant tokens without examining whether the resulting representation remains semantically consistent with the original representation. Mapping the original N-token visual sequence to K tokens may discard, dilute, or misassign critical visual cues, triggering severe semantic drift that deviates the VLM's understanding. In this paper, we first introduce the principle of 'Calibrate Before Reason' to visual token reduction and propose CaRe, a training-free robust framework that calibrates compact visual representations before reasoning to preserve semantic fidelity in VLMs. CaRe consists of two mutually complementary modules: 1) Perturbation-Robust Calibration Anchoring, which identifies calibration anchors with stable model-side influence under multi-directional perturbations; 2) Confidence-Gated Token Calibration, which extracts reliable calibration signals from unselected tokens and injects them into anchors. Extensive evaluations across diverse VLM architectures and benchmarks verify that CaRe outperforms state-of-the-art token reduction baselines. While pruning 94.4% of visual tokens, our method retains 96.4% of the original full-token performance, delivering up to 2.30 times faster end-to-end inference speed relative to unpruned vanilla models.

# 论文总结：Calibrate Before Reason（推理前校准）

## 1. 论文的核心问题与整体含义

大型视觉语言模型（VLMs）在视觉推理任务中表现优异，但视觉令牌（visual token）序列过长导致推理开销巨大（注意力计算、KV缓存、延迟等）。现有的视觉令牌缩减方法（如令牌剪枝与令牌压缩）虽然提升了效率，但普遍存在一个被忽视的问题：**缩减后的表示是否仍与原始视觉表示在语义上保持一致？**

论文将这种不一致定义为**语义漂移（Semantic Drift）**，具体表现为三类失败模式：
- **删失（discard）**：关键视觉线索被剪枝丢弃；
- **稀释（dilute）**：目标语义因背景语义的混入而被弱化；
- **错配（misassign）**：语义被错误分配到不相关的位置。

为解决这一问题，论文首次将**“推理前校准”（Calibrate Before Reason）**原则引入视觉令牌缩减，提出 **CaRe** 框架——在缩减后、推理前对紧凑视觉表示进行校准，以保留语义保真度。其核心含义在于：令牌缩减不应止步于“减少数量”，而应确保“保留语义的完整性”。

## 2. 论文提出的方法论

### 2.1 核心思想

CaRe 将视觉令牌缩减重新定义为**视觉令牌校准问题**，通过两个互补模块实现：先确定稳定的“锚点”令牌，再从被丢弃令牌中筛选可靠信息并注入锚点，在不增加令牌预算的前提下完成语义校准。

### 2.2 总体流程

CaRe 分为两个阶段：

**阶段一：扰动鲁棒校准锚定（Perturbation-Robust Calibration Anchoring, PRCA）**

目标：从N个视觉令牌中选出K个稳定、多样化的**校准锚点（Calibration Anchors）**。

关键技术细节：
- 在投影器（Projector）之前对每个视觉令牌施加m个方向的对称扰动，并计算响应：
  \[
  C_{x,i} = \frac{\|M(v_i + h u_x) - M(v_i - h u_x)\|_2}{2h}
  \]
- 对每个方向做**方向级鲁棒归一化**（基于中位数与中位数绝对偏差）；
- 计算每个令牌的**扰动鲁棒影响分数**：
  \[
  \psi_i = \mu_i - \lambda \sigma_i
  \]
  其中μ为均值响应，σ为方向标准差，λ惩罚方向性风险（避免仅沿个别方向强响应的不稳定令牌）；
- 在锚点选择中引入**多样性约束**，通过最大化边际相似度差距，防止锚点过度集中于单一显著区域。

**阶段二：置信门控令牌校准（Confidence-Gated Token Calibration, CGTC）**

目标：从剩余（未被选中的）令牌中筛选可靠校准信号，并注入锚点。

包含两个子阶段：
- **Stage Ⅰ（信号资格审定）**：计算每个剩余令牌与锚点的**语义-空间亲和度**（余弦相似度 + 空间位置高斯衰减），基于最佳锚点匹配置信度和分配集中度（熵的逆）进行阈值门控，仅允许高置信度令牌作为校准信号；
- **Stage Ⅱ（锚点校准）**：对合格信号做软分配（soft assignment），按来源可靠性加权聚合为校准信号，注入对应锚点，并在不改变令牌预算的前提下保持原锚点范数以降低分布漂移。

### 2.3 核心公式与流程总结

1. 扰动响应计算 → 2. 方向级归一化 → 3. 影响分数ψi → 4. 多样性引导锚点选集S → 5. 语义-空间亲和度 → 6. 置信度门控（csim + cent）→ 7. 软分配与加权聚合 → 8. 范数归一化注入 → 得到 K 个校准令牌。

1. **CaRe 显著优于现有方法**：在三个模型架构上、不同剪枝率下，CaRe一致超越最先进的剪枝和压缩方法；

4. **模块互补性得到验证**：PRCA和CGTC单独使用均有增益，组合使用时增益最大；

## 8. 不足与局限

- **信息恢复能力有限**：论文自己指出，校准只能“重新分配和精炼”视觉令牌中已有的语义，无法恢复在视觉编码阶段就已丢失的信息。对于弱编码、严重退化或高度模糊的视觉证据，CaRe无能为力；
- **OCR与细粒度文本场景仍是短板**：在TextVQA等依赖OCR的任务上多次出现相对明显的性能退化，说明方法对局部细节、文本线索的保持仍有局限；
- **7B规模模型的局限**：所有实验仅在7B参数的模型上进行，未验证在更大模型上的泛化性；
- **校准参数依赖人工调整**：6个超参数需要通过验证集仔细调节，虽然论文证明对较宽范围鲁棒，但在真正的零样布场景下可能缺少最优参数先验；

- **语义保持指标（CSR）是表示层面而非因果性诊断**：论文承认CSR仅为辅助工具，不代表对答案层性能的因果度量；
- **未提供与强化学习/自适应推理等更前沿范式的对比**：实验对比方法集中在静态剪枝路线，缺少与动态自适应缩减方法的比较。
