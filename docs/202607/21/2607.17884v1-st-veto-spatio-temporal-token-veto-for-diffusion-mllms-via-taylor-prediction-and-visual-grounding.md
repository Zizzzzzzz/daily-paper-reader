## 摘要
视觉语言模型通过思维链提示实现强推理能力，但存在高顺序生成成本、错误累积和有限的自我纠正问题。扩散多模态大语言模型以顺序无关的方式解码令牌，提高了效率并支持迭代细化，但其推理能力及如何增强该能力仍研究不足。我们提出一种无需训练的方法——时空令牌否决，该方法利用每个扩散步骤中观察所有令牌位置的能力。与仅依赖当前步骤置信度不同，ST-Veto通过二阶泰勒预测置信度动态来否决时间上不稳定的令牌，并利用图像注意力质量过滤弱定位令牌，将其替换为更安全的候选令牌。在多个扩散多模态大语言模型和多模态推理基准上，ST-Veto始终优于标准解码策略和先前的视觉语言模型推理方法，在无额外训练或生成成本的情况下，准确率提升高达9%。分析表明，ST-Veto引导生成走向更高置信度、更好定位的路径。

## Abstract
Vision Language Models (VLMs) achieve strong reasoning with Chain-of-Thought (CoT) prompting but incur high sequential-generation cost, error accumulation, and limited self-correction. Diffusion Multimodal Large Language Models (dMLLMs) unmask tokens in an order-agnostic process, improving efficiency and enabling iterative refinement, yet their reasoning and how to enhance it remain underexplored. We propose a training-free method, Spatio-Temporal Token Veto (ST-Veto), which leverages the ability to observe all token positions at each diffusion step. Rather than relying only on current-step confidence, ST-Veto vetoes temporally unstable tokens via second-order Taylor prediction of confidence dynamics and filters weakly grounded tokens using image-attention mass, swapping them with safer candidates. Across multiple dMLLMs and multimodal reasoning benchmarks, ST-Veto consistently outperforms standard decoding policies and prior VLM reasoning methods, improving accuracy by up to 9% with no additional training or generation cost. Analyses show that ST-Veto steers generation toward higher-confidence, better-grounded paths.

### 方法论：核心思想、关键技术细节

#### 核心思想
- **时空令牌否决（ST-Veto）**：在扩散解码的每一步，对当前top-k候选令牌进行时间稳定性（二阶泰勒预测残差）和空间视觉定位（图像注意力质量）双重检查，否决不满足条件的令牌，并替换为同时满足稳定性和定位要求的边界候选令牌。这一“否决-替换”策略引导模型选择更可靠的令牌，作为后续去噪的锚点。

#### 关键技术细节
1. **时间稳定性信号（Taylor Residual）**  
   - 利用局部4步历史置信度（c(t-3) ~ c(t)），通过二阶泰勒展开预测当前步置信度期望值：
     \[
     \hat{c}(t) = c(t-1) + \Delta_{1} + \frac{1}{2}(\Delta_{1} - \Delta_{2})
     \]
     其中 \(\Delta_{1}=c(t-1)-c(t-2)\)，\(\Delta_{2}=c(t-2)-c(t-3)\)。
   - 定义残差 \(e_i = c(t)_i - \hat{c}(t)_i\)，残差显著为负（\(e_i \ll 0\)）表示置信度意外下降，标记为不稳定。

2. **视觉定位信号（Image Attention）**  
   - 选取中间三层（L/3, L/2, 2L/3）的注意力头平均矩阵，计算令牌i对图像令牌区域的注意力占比 \(\rho_i^{(\ell)}\)，再取三层均值得到 \(m_i\)。
   - 低 \(m_i\) 表示该令牌缺乏视觉支撑，标记为弱定位。

3. **否决与替换策略**  
   - **候选集**：当前置信度最高的前k个令牌 \(T_k\)。
   - **稳健统计**：对残差e和视觉信号m分别计算中位数（\(\mu\)）和中位数绝对偏差（\(\sigma\)）。
   - **否决条件**：若 \(e_i < \mu_e - \sigma_e\) 或 \(m_i < \mu_m - \sigma_m\)，则否决该令牌。
   - **安全条件**：需同时满足 \(e_i \ge \mu_e + \sigma_e\) 且 \(m_i \ge \mu_m + \sigma_m\)。
   - **替换候选**：从非top-k中选出安全且置信度接近边界（\(|c_i - c_{(k)}| \le \sigma_c\)）的令牌，用其中最高置信度的令牌替换被否决的令牌；若无足够替换候选，则部分替换。
   - 该过程不强制替换，保证保守性。

#### 算法流程（文字描述）
1. 在扩散步t，模型输出所有掩码位置的置信度 \(c(t)\)。
2. 利用前4步历史计算泰勒残差e和图像注意力m。
3. 根据稳健阈值确定否决集V和替换候选集S。
4. 从S中选取最高置信度的令牌替换V中的令牌。
5. 更新掩码状态，进入下一步t-1。
