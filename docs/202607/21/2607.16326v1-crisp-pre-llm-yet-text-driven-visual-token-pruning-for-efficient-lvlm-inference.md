## 摘要
大型视觉语言模型（LVLMs）通常需要处理成百上千个视觉标记，导致巨大的推理开销。现有的视觉标记剪枝方法要么在LLM之前使用与文本无关的启发式方法，要么在LLM内部进行剪枝，但以效率和嘈杂的跨模态注意力为代价。为了解决这些限制，我们提出了CRISP，一个预LLM但文本驱动的视觉标记剪枝框架，它同时保留了与指令相关的证据和基本的场景上下文。CRISP采用两阶段流水线：第一阶段首先识别与文本对齐的视觉标记，第二阶段通过语义多样性增强上下文完整性。在LLaVA-1.5和LLaVA-NeXT上的大量实验表明，CRISP在激进的剪枝比率下实现了卓越的性能保持，保持了高达99.5%的准确率，同时将推理成本和延迟降低了2倍以上。CRISP为高效LVLM推理提供了一个实用的解决方案，特别是在资源受限的场景中。

## Abstract
Large Vision-Language Models (LVLMs) typically require processing hundreds to thousands of visual tokens, leading to substantial inference overhead. Existing visual token pruning methods either operate before the LLM using text-agnostic heuristics or prune inside the LLM at the cost of efficiency and noisy cross-modal attention. To address these limitations, we propose CRISP, a pre-LLM yet text-driven visual token pruning framework that preserves both instruction-relevant evidence and essential scene context. CRISP works in a two-stage pipeline: Stage 1 first identifies text-aligned visual tokens, and Stage 2 enhances contextual completeness through semantic diversity. Extensive experiments on LLaVA-1.5 and LLaVA-NeXT demonstrate that CRISP achieves superior performance retention under aggressive pruning ratios, maintaining up to 99.5% accuracy while reducing inference cost and latency by more than 2 times. CRISP serves as a practical solution for efficient LVLM inference, especially in resource-constrained scenarios.

## 1. 核心问题与整体含义（研究动机和背景）
大型视觉语言模型（LVLMs）需要处理几百到上千个视觉标记，导致推理开销巨大。现有的视觉标记剪枝方法主要分为两类：
- **预LLM剪枝**：在视觉标记进入大语言模型之前就进行丢弃，通常使用与文本无关的启发式规则（如CLS注意力或特征相似性）。缺点是文本无关，结果不随查询变化，类似“先看后问”，认知负荷高。
- **LLM内部剪枝**：利用LLM内部的跨模态注意力分数来剪枝，是文本驱动的。但早期层剪枝会因位置偏差和注意力分散导致精度下降，深层剪枝则削弱效率收益，且提取注意力会破坏FlashAttention加速，影响推理效率。

因此，论文提出CRISP框架，旨在实现**预LLM但文本驱动**的视觉标记剪枝，同时保留与文本查询相关的关键证据和必要的场景上下文，兼顾效率与精度。

## 2. 方法论：核心思想、关键技术细节
**核心思想**：两阶段流水线，完全在投影器之后、LLM之前进行，无需访问LLM的Transformer块，无需训练。

**第一阶段：关键优先选择（Critical-first Token Selection）**  
- 目标：从全部视觉标记 \(V = \{v_1, ..., v_T\}\) 中选择与查询文本最相关的子集 \(V_{critical}\)。
- 步骤：
  1. **关键词提取**：从查询中去除响应指令，使用轻量级NLP模型（en_core_web_sm）提取名词作为关键词 \(\{w_1, ..., w_N\}\)。
  2. **词级嵌入**：将每个词对应的子词token嵌入平均，得到词级嵌入 \(\{e_1, ..., e_N\}\)。
  3. **跨模态相关度计算**：计算每个视觉标记 \(v_i\) 与每个词嵌入 \(e_j\) 的余弦相似度，得到相关度矩阵 \(S \in \mathbb{R}^{T \times N}\)：  
     \(S_{i,j} = \langle v_i, e_j \rangle / (\|v_i\| \|e_j\|)\)。
  4. **词级配额分配**：根据视觉编码器的CLS注意力，为每个词分配不同的保留预算 \(K_{critical}^{(j)}\)。总预算 \(K_{critical} = \lfloor \alpha K \rfloor\)，其中 \(K\) 为保留总数，\(\alpha\) 为超参数（默认0.3）。配额计算：对每个词，取相关度最高的 \(\lfloor K_{critical}/N \rfloor\) 个标记的CLS注意力之和作为权重，按权重分配预算。
  5. **关键标记选择**：对每个词 \(w_j\)，选择相关度最高的 \(K_{critical}^{(j)}\) 个标记，取并集得到 \(V_{critical}\)。若关键词为空，则回退到CLS注意力选择。

**第二阶段：语义覆盖补全（Semantically-covered Token Completion）**  
- 目标：在 \(V_{critical}\) 基础上，从剩余标记中补充语义多样性的标记，以保留场景上下文。
- 方法：迭代贪心选择。初始化 \(C = V_{critical}\)。每次迭代，对每个剩余标记 \(v_i\)，计算其与当前集合 \(C\) 中所有标记的最大余弦相似度 \(d_i\)，选择 \(d_i\) 最小的标记加入 \(C\)，重复直到总标记数达到 \(K\)。该过程确保新标记与已有标记语义差异大，增加多样性。

## 6. 主要结论与发现
- CRISP在所有剪枝率下均保持极高的性能保留率：在LLaVA-1.5上保留128标记（77.8%剪枝率）时平均保留99.5%的完整性能；在64标记（88.9%剪枝率）时仍达97.7%，远超所有对比方法。
- 在POPE（物体幻觉检测）任务上，CRISP甚至**超越**全标记基线，说明其能更精准地保留与查询对象相关的视觉证据。
- 在LLaVA-NeXT上，320标记下保留96.9%性能，同样领先所有基线。
- 效率方面，CRISP实现近线性的FLOPs和KV-cache减少，解码速度提升2倍以上，端到端评估时间显著缩短。

## 7. 优点
- **训练无关**：无需额外训练或微调，即插即用。
- **预LLM但文本驱动**：克服了传统预LLM方法文本无关的弊端，同时避免进入LLM内部带来的效率损失和注意力噪声。
- **两阶段互补设计**：第一阶段保证查询相关，第二阶段补充场景多样性，有效避免过度聚焦或遗漏上下文。
- **强鲁棒性**：在极低压缩比率（88.9%）下仍保持高精度，且在POPE上超越全标记基线，说明策略对任务敏感。
- **通用性**：在两种不同架构（LLaVA-1.5和LLaVA-NeXT）上均取得一致性优势。

## 8. 不足与局限
- **关键词提取的局限性**：仅使用名词提取，依赖简单NLP模型，对于复杂查询（如抽象关系、动词相关任务）可能无法捕获足够语义，影响第一阶段效果。
- **超参数\(\alpha\)的敏感性**：最佳性能依赖\(\alpha=0.3\)，虽然实验验证了其合理性，但在不同任务或模型上可能需要手动调整。
- **模型规模覆盖不足**：只在7B参数规模上验证，未在更大模型（如13B、34B）或其他视觉编码器上测试，泛化性有待进一步验证。
- **未讨论对视觉编码器的影响**：CRISP在投影器之后立即剪枝，但视觉编码器的输出本身可能已包含冗余，方法是否可与编码器端剪枝结合未探讨。
- **实验基准以VQA为主**：虽然覆盖了9个基准，但缺少如多图像推理、视频理解等更复杂场景，应用边界未明确。
