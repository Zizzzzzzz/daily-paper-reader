## 摘要
近期多模态大语言模型（MLLMs），如 Qwen2.5-VL 和 InternVL3，为高分辨率输入生成大量视觉标记，导致巨大的计算成本。现有的视觉标记剪枝方法要么依赖跨模态注意力且无法在预填充阶段之前剪枝，要么依赖高计算开销的多样性估计。我们观察到，视觉和文本标记的注意力分数均在模态分隔符标记处达到峰值，表明这些分隔符桥接了两种模态。基于这一观察，我们提出 SepPrune，一种高效、无需训练、即插即用的剪枝方法，该方法使用分隔符标记作为统一查询来排序和选择信息丰富的视觉标记。SepPrune 重用 LLM 内置的投影参数，无需架构更改。在 Qwen2.5-VL-7B 上的实验表明，SepPrune 达到了最先进的性能，在移除 80.2% 的视觉标记时保留了原始准确率的 96.3%。

## Abstract
Recent multimodal large language models (MLLMs), such as Qwen2.5-VL and InternVL3, generate large numbers of vision tokens for high-resolution inputs, leading to substantial computational cost. Existing vision token pruning methods either depend on cross-modal attention and cannot prune before the prefill stage, or rely on diversity estimation with high computational overhead. We observe that attention scores from both vision and text tokens peak at modality separator tokens, suggesting that these separators bridge the two modalities. Based on this observation, we propose SepPrune, an efficient, training-free, plug-and-play pruning method that uses the separator token as a unified query to rank and select informative vision tokens. SepPrune reuses the LLM's built-in projection parameters and requires no architectural changes. Experiments on Qwen2.5-VL-7B show that SepPrune achieves state-of-the-art performance, retaining 96.3% of the original accuracy while removing 80.2% of vision tokens.

## 一、论文的核心问题与整体含义

**研究动机**：多模态大语言模型（MLLMs）如 Qwen2.5-VL 和 InternVL3 在处理高分辨率图像/视频时，会生成大量视觉 token（例如 4K/8K 画面），远超文本 token 数量，导致推理阶段计算开销巨大、延迟增加。已有研究表明视觉 token 存在高度冗余，因此剪枝冗余 token 是提升效率的关键方向。

**核心问题**：现有剪枝方法存在两类局限：
- **基于注意力的方法**（如 FastV）：依赖跨模态注意力，必须在 LLM 推理层内计算，无法在预填充（prefill）阶段之前剪枝，且与 FlashAttention 等高效算子不兼容。
- **基于多样性的方法**（如 DivPrune, CDPruner）：通过计算 token 间相似度矩阵（复杂度 O(N²)）来识别冗余，但计算开销本身可能抵消剪枝带来的加速收益。

**整体含义**：作者希望通过一种轻量、无需训练、即插即用的剪枝策略，在不修改 MLLM 架构的前提下，显著减少视觉 token 数量，同时保持模型性能，从而加速推理并降低计算成本。

## 二、论文提出的方法论

### 核心思想
1. **发现现象**：在 LLM 浅层（初始层）中，视觉 token 和文本 token 的注意力分数在 **模态分隔符（Separator token）** 处出现显著峰值（如图 1b 所示），且该现象随着网络深度增加而减弱。进一步消融实验（图 2）表明：移除分隔符对模型性能的损害大于移除同等数量的视觉或文本 token，证明分隔符充当了跨模态的“桥梁”。
2. **核心假设**：分隔符 token 具有全局感知能力，其与视觉 token 的注意力分数可以反映视觉 token 的信息重要性。

### 方法细节（SepPrune）
- **输入序列结构**：  
  \( X_{\text{input}} = [T_{\text{sys}}, S_{\text{left}}, V, S_{\text{right}}, T_{\text{usr}}] \)  
  其中 \( S_{\text{right}} \) 是位于视觉 token 之后的分隔符（因因果注意力掩码，只有该分隔符能访问所有视觉 token）。

- **关键技术**：
  1. **使用分隔符作为统一查询**：以 \( S_{\text{right}} \) 的查询向量 \( Q_{\text{sep}} \) 与所有视觉 token 的键矩阵 \( K_{\text{visual}} \) 计算注意力分数（而非进行完整 N×N 自注意力）。计算复杂度从 O(N²) 降至 O(N)。
  2. **去除位置编码（RoPE）**：在计算注意力分数时，刻意不应用旋转位置编码（RoPE），以避免位置偏差（如倾向于保留底部 token 而剪掉顶部 token），使分数仅反映语义重要性。
  3. **注意力分数计算**：  
     \( \text{Score}_{\text{prune}} = \text{softmax}\left( \frac{Q_{\text{sep}} K_{\text{visual}}^T}{\sqrt{d_k}} \right) \)
  4. **Top-k 选择**：根据分数保留得分最高的 k 个视觉 token，重新拼接为 \( V' \)，与分隔符和文本 token 形成缩短后的序列输入 LLM。

- **方法特点**：  
  - 无需训练，即插即用，不改变 LLM 架构。  
  - 在 LLM 预填充阶段之前完成剪枝，可兼容 FlashAttention 等加速技术。  
  - 复用 LLM 第一层已有的投影参数（Q_proj, K_proj），不增加额外参数。

5. **去除位置编码的必要性**：消融实验验证，去除 RoPE 后性能提升明显（例如 MME 提高 82 分，TextVQA 提高 7.2%）。
