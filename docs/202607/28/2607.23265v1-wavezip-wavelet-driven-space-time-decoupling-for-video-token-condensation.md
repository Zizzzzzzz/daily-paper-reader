## 摘要
现有大型视觉语言模型（LVLMs）在处理长视频理解时，由于视觉标记的二次计算成本而面临挑战。虽然近期的高效方法尝试通过硬剪枝或均匀合并来压缩标记，但它们严格在空间特征域操作，其中鲁棒的结构上下文和判别性语义细节本质上纠缠在一起。本文提出WaveZip，一种联合信号-频率域的高效视频推理框架。基于时间冗余存在于低通近似尺度而空间显著性强烈高频成分相关的洞察，WaveZip利用离散小波变换（DWT）解耦这些信号。在时间上，它使用一维DWT分析查询帧相关性，得到的高频系数进一步通过帧间差异门控，两种信号联合驱动精确的帧级标记预算动态分配。在空间上，二维DWT将特征分解为低频近似和高频细节成分，其中高频系数在查询显著区域内调制以调控空间重建。重要的是，WaveZip无需任务特定训练，可无缝集成到现成LVLMs中提升推理效率。在长视频理解基准上的大量实验表明，WaveZip在极端10倍压缩比下保留了完整性能的99.6%，持续超越最先进方法。

## Abstract
Existing Large Vision-Language Models (LVLMs) struggle with long-form video understanding due to the quadratic computational cost of visual tokens. While recent efficient methods attempt to compress tokens via hard pruning or uniform merging, they operate strictly in the spatial feature domain, where robust structural context and discriminative semantic details are inherently entangled. In this work, we propose WaveZip, a joint signal-frequency-domain framework for efficient video inference. Driven by the insight that temporal redundancy resides in low-pass approximation scales while spatial saliency strongly correlates with high-frequency components, WaveZip leverages Discrete Wavelet Transforms (DWT) to disentangle these signals. Temporally, it employs 1D DWT to analyze query-frame relevance, and the resulting high-frequency coefficients are further gated by inter-frame differences, with both signals jointly driving the dynamic allocation of a precise frame-level token budget. Spatially, a 2D DWT decomposes features into low-frequency approximations and high-frequency detail components, where the high-frequency coefficients are modulated within query-salient regions to regulate spatial reconstruction. Importantly, WaveZip requires no task-specific training and can be seamlessly integrated into off-the-shelf LVLMs to boost inference efficiency. Extensive experiments on long video understanding benchmarks demonstrate that WaveZip retains 99.6% of the full performance under an extreme 10x compression ratio, consistently outperforming state-of-the-art methods.

- **动机**：受频率域分析启发——时间冗余主要存在于低通近似尺度，空间显著性强烈相关于高频分量。因此提出一种基于小波的信号-频率域解耦框架，在压缩时同时保留结构趋势和细粒度细节。
- **整体含义**：WaveZip 是一种无需训练、即插即用的 token 压缩方法，可显著提升 LVLM 的长视频推理效率，在 10 倍压缩下仍保持 99.6% 的完整性能。

## 2. 方法论
### 核心思想
- 利用离散小波变换（DWT）在时间维和空间维分别解耦信号：
  - **时间维**：将帧级相关性序列分解为低频趋势和高频波动，并用帧间视觉变化门控高频系数，得到稳定的帧级 token 预算分配。
  - **空间维**：对每帧特征图进行 2D DWT，分离低频近似（结构）与高频细节（纹理/边缘）；通过查询条件空间显著性图对高频子带进行加权调制，保留任务相关细节，抑制冗余背景。

### 关键技术细节
- **Cross-Modal Scorer**：轻量冻结的跨模态模型（如 BLIP）计算帧级相关性分数 `rt` 和 token 级空间显著性图 `Mt`。
- **Visual Change Estimator (VCE)**：基于相邻帧特征余弦距离计算视觉变化度 `δt`，经 min-max 归一化为门控因子 `γt`；并过滤冗余帧（`δt < τ` 的帧移除）。
- **Wavelet Processor**：
  - **Wavelet Temporal Allocator (WTA)**：对保留帧的相关性序列 `{rm}` 进行 1D DWT（Haar 基），得到近似系数 A 和细节系数 D；用视觉变化门控 `ΓM` 对 D 进行逐元素抑制（`eD = ΓM ⊙ D`），然后 IDWT 得到修正后的相关性序列 `{erm}`。
  - **Wavelet Spatial Modulator (WSM)**：对保留帧特征 `Xm` 进行 2D DWT（db4 基），得到 LL（低频）和 LH/HL/HH（高频）。构建显著性调制门 `Gm = λ·downsample(Mm)`，仅对高频子带进行逐元素相乘（`eX_K = X_K ⊙ Gm`），低频 LL 保持不变，再 IDWT 重建。
- **Token Assigner**：根据修正后的帧相关性 `erm` 分配 token 预算 `nm`（绝对值归一化后四舍五入）。对每帧进行预算引导的双线性插值压缩至 `nm` 个 token，经预训练投影器映射到 LLM 隐空间，按时间顺序拼接。

### 算法流程（文字说明）
1. 输入视频帧和文本查询 → Cross-Modal Scorer 得到帧级分数 rt 和空间显著性图 Mt。
2. VCE 计算帧间变化 δt，生成门控因子 γt，并过滤冗余帧得到保留索引集 M。
3. 对保留帧执行 WTA：1D DWT + 门控调制 + IDWT 修正 rt。
4. 对保留帧特征执行 WSM：2D DWT + 高频子带显著性调制 + IDWT 重建。
5. Token Assigner 按修正后分数分配预算，压缩并投影，输出最终 token 序列 `eZ`。
