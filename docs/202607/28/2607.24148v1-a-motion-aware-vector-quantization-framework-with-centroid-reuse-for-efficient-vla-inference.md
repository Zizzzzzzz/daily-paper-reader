## 摘要
视觉-语言-动作（VLA）模型在具身智能方面展现出巨大潜力，但其在GPU上的高推理延迟限制了实时部署。现有加速器（如Dadu-Corki）虽然提高了效率，但将VLA模型视为全精度工作负载，未能充分利用内存和计算中的大量冗余。本文提出VQVLA，一种算法-硬件协同设计框架，通过利用权重相似性和执行动态性来加速VLA推理。我们首先引入MotionVQ，一种面向运动感知的向量量化方案，根据机器人执行状态动态调整量化精度，在保持任务成功率的同时减少内存访问。然后提出一种基于码本索引表示的融合质心向量化GEMM范式，通过空间聚合和质心时间复用消除冗余乘法。为实现这些优化，我们设计了一种高效支持动态精度选择和质心复用计算的加速器。实验结果表明，VQVLA相比A100 GPU、Dadu-Corki、LUT-DLA、CodeGEMM和ShiftAddLLM分别实现了6.5倍、2.8倍、1.9倍、3.3倍和4.3倍的加速，且精度损失可忽略不计。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong potential for embodied AI, yet their high inference latency on GPUs limits real-time deployment. Existing accelerators, such as Dadu-Corki, improve efficiency but treat VLA models as full-precision workloads, leaving substantial redundancy in both memory and computation underexploited.   In this paper, we propose VQVLA, an algorithm-hardware co-design framework that accelerates VLA inference by exploiting weight similarity and execution dynamics. We first introduce MotionVQ, a motion-aware vector quantization scheme that dynamically adjusts quantization precision based on the robot's execution state, reducing memory access while preserving task success rate. We then propose a merged-centroid vectorized GEMM paradigm that operates on the codebook-index representation, eliminating redundant multiplications through spatial aggregation and temporal reuse of centroids. To realize these optimizations, we design an accelerator that efficiently supports dynamic precision selection and centroid-reuse computation. Experimental results show that VQVLA achieves 6.5x, 2.8x, 1.9x, 3.3x, and 4.3x speedup over the A100 GPU, Dadu-Corki, LUT-DLA, CodeGEMM, and ShiftAddLLM, respectively, with negligible accuracy degradation.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：Vision-Language-Action (VLA) 模型在具身智能任务中表现优异，但其推理延迟较高，尤其在 GPU 上难以满足实时部署需求（如边缘设备、低功耗、高控制频率）。
- **现有局限**：现有加速器（如 Dadu-Corki）虽减少调用次数，但将 VLA 模型视为全精度黑盒，未利用模型内部权重相似性和执行动态性带来的冗余。
- **目标**：通过算法-硬件协同设计，在保证任务成功率的前提下，同时减少内存访问和计算量，加速 VLA 推理。

## 2. 方法论：核心思想与关键技术细节
### 2.1 核心观察
- 机器人执行状态可划分为**执行状态**（靠近目标，动作幅度小，对量化敏感）和**过渡状态**（远离目标，动作幅度大，对量化不敏感）。
- 向量量化（VQ）后，质心访问存在明显的“热点”模式（某些质心被高频使用），可利用空间和时间上的质心复用。

### 2.2 MotionVQ（运动感知向量量化）
- **状态预测**：通过动作三维坐标计算运动幅度 D = sqrt(Ax^2 + Ay^2 + Az^2)，与阈值 T_d 比较。D ≤ T_d 为执行状态，否则为过渡状态。
- **精度自适应**：离线准备两套 VQ 配置：
  - 高精度：VQ[256,2,256]（平均 4.125 比特）
  - 低精度：VQ[128,2,64]（平均 3.125 比特）
- 运行时根据状态动态选择相应码本和索引矩阵，减少内存访问。

### 2.3 Merged-Centroid Vectorized GEMM（融合质心向量化通用矩阵乘）
- **空间合并**：在同一列中，若多个权重向量映射到同一质心，先累加对应的输入，再乘以该质心（利用乘法分配律），减少乘法次数。
- **时间复用**：在不同列中，通过离线选取 Top-k 热质心，运行时在结果缓存中缓存热门质心的乘积，后续遇到相同标签时直接复用，跳过乘法。
- 该范式直接基于码本-索引表示操作，无需反量化步骤。

### 2.4 硬件架构
- 包含**状态预测器**、**矩阵乘法引擎**（含空间合并 PE 阵列、时间复用 PE 阵列、加法树、结果缓存、累加单元）和**索引处理引擎**（多个 IPU 并行构建质心位置表）。
- 加法树采用三阶段流水线（支持 8/4/2 输入归约），每 3 个周期产生 7 个累加结果。
- 时间复用 PE 阵列集成结果缓存和缓存初始化单元，支持热质心预计算。
- 索引处理引擎将同一列中 Cnt>1 的条目归入空间合并表，Cnt=1 的归入时间复用表。
