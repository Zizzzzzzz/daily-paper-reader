## 摘要
现代视觉语言模型（VLM）日益依赖动态或高分辨率视觉编码，从而产生数千个视觉令牌，这大幅增加了下游语言模型的推理成本。现有的令牌缩减方法通过令牌重要性、查询相关性、覆盖度、成对多样性或子集级目标来评估令牌效用。我们的关键见解是通过所选跨度的互补性来审视视觉令牌缩减：不再孤立地或通过成对关系对令牌评分，而是评估其特征中有多少与已保留子集的跨度正交。基于这一视角，我们提出了无需训练且无需查询的贪心正交令牌选择方法（GOTS）。在每一步中，GOTS选择与当前保留跨度正交且残差能量最大的令牌。这一规则恰好最大化候选添加中一步扩大的格拉姆行列式，从而为每个贪心步骤提供精确的局部几何保证，以进行子集扩展。在来自Qwen-VL和InternVL系列的五个高分辨率VLM骨干网络以及十一个多样化的基准测试中，GOTS实现了比最强的评估基线更高的平均性能保持率。一项受控的OCRBench研究表明，在考虑选择开销后，GOTS减少了模型侧的首令牌生成时间。代码已开源：https://github.com/newLLing/GOTS。

## Abstract
Modern vision-language models (VLMs) increasingly rely on dynamic or high-resolution visual encoding, producing thousands of visual tokens that substantially increase downstream language-model inference cost. Existing token-reduction methods assess token utility through token-wise importance, query relevance, coverage, pairwise diversity, or subset-level objectives. Our key insight is to view visual token reduction through selected-span complementarity: instead of scoring a token in isolation or through pairwise relations, we assess how much of its feature is orthogonal to the span of the already retained subset. Based on this perspective, we propose Greedy Orthogonal Token Selection (GOTS), a training-free and query-agnostic method. At each step, GOTS selects the token with the largest residual energy orthogonal to the current retained span. This rule exactly maximizes the one-step augmented Gram determinant among candidate additions, giving each greedy step a precise local geometric guarantee for subset expansion. Across five high-resolution VLM backbones from the Qwen-VL and InternVL families and eleven diverse benchmarks, GOTS achieves higher average performance retention than the strongest evaluated baselines, and a controlled OCRBench study shows that it reduces model-side time-to-first-token after accounting for selection overhead. Code is available at https://github.com/newLLing/GOTS.

### 论文核心问题与整体含义（研究动机和背景）

- **问题**：现代高分辨率视觉语言模型（VLM）为捕获精细信息，动态编码图像，产生数千个视觉 token，导致下游语言模型的自注意力计算成本剧增（预填充延迟和显存占用）。
- **现有方法局限**：已有 token 缩减方法（如 VisionZip、DivPrune、CDPruner、MMTok）多采用**孤立评估**（token 重要性）或**成对关系**（相似性/距离），缺乏对**已选子空间整体互补性**的利用——即使某个 token 与所有已选 token 都不相似，其方向仍可能落在已选子空间内，造成冗余。
- **核心见解**：提出“**所选跨度互补性**”（selected-span complementarity）原则，认为评估 token 效用应衡量其特征中超出已保留子空间的分量，即正交残差。

### 论文提出的方法论

#### 核心思想
- 将视觉 token 缩减建模为**行子集选择问题**：从视觉特征矩阵 \(X \in \mathbb{R}^{N \times d}\) 中选出 \(K\) 行（\(K \ll N\)），使其行空间能最大程度保留原始信息。
- 使用**最大化已选子集的格拉姆行列式**（即体积）作为几何替代目标，该行列式度量子集张成的超立方体体积，既反映特征幅度又反映方向互补性。
- 贪心策略：**每次选择与当前已选子空间正交残差能量最大的 token**，等价于最大化下一步的格拉姆行列式增量。

#### 关键技术细节
- **算法流程**（基于 QRCP 的列主元 QR 分解）：
  1. 初始化：所有 token 的残差向量 \(r_i^{(0)} = x_i\)，候选集 \(U^{(0)} = \{1,\dots,N\}\)，已选集 \(S = \emptyset\)。
  2. 迭代 \(t = 0\) 至 \(K-1\)：
     - 计算候选 token 的残差能量 \(e_i^{(t)} = \|r_i^{(t)}\|_2^2\)。
     - 选择最大残差能量的 token：\(i_t = \arg\max_{i \in U^{(t)}} e_i^{(t)}\)。
     - 若 \(e_{i_t}^{(t)} < \epsilon^2\)（例如 \(10^{-12}\)），提前终止（无数值独立方向）。
     - 归一化残差得到基向量 \(q_t = r_{i_t}^{(t)} / \|r_{i_t}^{(t)}\|_2\)。
     - 对所有剩余候选 token，减去其在 \(q_t\) 上的投影：\(r_j^{(t+1)} = r_j^{(t)} - (r_j^{(t)} q_t^\top) q_t\)。
  3. 将选择的索引按原始顺序排序后输出。
- **几何保证**（Proposition 1）：在精确算术下，每一步选择最大残差能量恰好最大化下一时刻的格拉姆行列式因子，即 \(\det(X_{S \cup \{j\}} X_{S \cup \{j\}}^\top) = \det(X_S X_S^\top) \cdot e_j^{(t)}\)。因此 GOTS 等价于对 \(X^\top\) 进行 QRCP。
- **计算复杂度**：\(O(K N d)\) 时间，\(O(N d + K d)\) 空间，无需构造 \(N \times N\) 相似矩阵。

### 论文的主要结论与发现

1. **性能保持率领先**：在 Qwen2.5-VL-7B 主实验中，GOTS 在 20%、10%、5% 保留率下平均保持率分别为 96.3%、90.9%、82.7%，远优于最强基线 MMTok（90.5%、82.3%、71.6%）。优势随压缩率增大而扩大（+5.8pp → +8.6pp → +11.1pp）。
2. **跨骨干泛化性好**：在四个额外骨干上，GOTS 在所有保留率下的平均保持率均超过 MMTok，5% 时优势为 8.4~11.7pp。
3. **文本密集任务增益显著**：在 OCRBench 和 TextVQA 上提升最大，表明正交选择能保留细粒度文本特征。
4. **推理加速**：在 OCRBench 上，5% 保留率时 LLM 预填充加速 6.87×，考虑选择开销后模型侧 TTFT 降低 31.9%。
5. **消融验证**：默认 GOTS 优于特征空间 NMS、随机/最小残差主元、预归一化；全局均值初始化与空集初始化性能接近。

### 优点

- **无需训练，无需查询**：完全基于视觉特征几何，不依赖文本输入，通用性强。
- **明确的几何保证**：每一步最大化格拉姆行列式增量，提供了局部最优性的理论依据。
- **计算高效**：复杂度 \(O(K N d)\)，无需构建 \(N \times N\) 矩阵，空间开销小。
- **易于集成**：作为后编码器方法，可直接插入现有 VLM，仅需修改 token 索引。
- **实验充分**：跨多模型、多任务、多压缩率的系统评估，消融实验验证设计动机。

### 不足与局限

- **线性假设**：方法基于线性特征空间的正交性，真实 VLM 特征可能包含非线性关系，线性残差不一定完全对应信息互补性。
- **对特征幅度敏感**：残差能量同时反映幅度和方向，实验中去除幅度（预归一化）导致性能下降，但在某些场景下幅度可能误导选择（如噪声 token 具有高范数）。
- **提前终止问题**：当所有残差能量低于阈值时提前停止，可能导致实际保留 token 数少于预算，影响可控性。
- **实验覆盖**：虽覆盖 11 个基准，但主要聚焦 Qwen 和 InternVL 系列，未测试其他架构（如 LLaVA-NeXT、Claude 等）。未与基于学习的方法（如可学习掩码）对比。
- **效率测量范围**：TTFT 仅测量 OCRBench，且未报告多轮对话场景下的加速比。
- **无理论保证下行性能**：贪婪策略无全局最优性保证，实际效果依赖数据特性。
