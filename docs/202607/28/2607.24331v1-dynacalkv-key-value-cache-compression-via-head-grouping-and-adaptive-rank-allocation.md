## 摘要
随着大语言模型（LLM）推理阶段需要处理长上下文窗口，键值（KV）缓存最初似乎可以应对这一挑战，但随着上下文窗口的持续增长，它最终成为了一个重大的瓶颈。低秩压缩最近被研究作为一种有效的减少KV缓存内存同时保持模型性能的方法。然而，现有方法中只有少数对键缓存和值缓存区别对待，尽管它们具有不同的作用。此外，这些方法通常采用固定的注意力头分组，可能无法充分利用注意力头之间的结构相似性。在本文中，我们提出了一种改进的低秩KV缓存压缩框架。对于键缓存，我们基于中心核对齐（CKA）相似性动态分组注意力头，并在参数预算下自适应分配秩预算。对于值缓存，我们采用与ReCalKV相同的方法，通过离线校准优化低秩分解以提高重建质量。在三个指令微调的LLM上的实验结果表明，我们的方法在保持竞争性准确性的同时减少了键缓存的参数数量。我们进一步观察到，所提出的策略对多头注意力（MHA）模型特别有效，而对于分组查询注意力（GQA）模型，尤其是在长上下文设置下，应更谨慎地应用。

## Abstract
As the inference phase of Large Language Models (LLMs) requires handling long context windows, the Key-Value (KV) cache initially appears to address this challenge but eventually becomes a significant bottleneck as the context window continues to grow. Low-rank compression has recently been studied as an effective approach to reduce KV cache memory while maintaining model performance. However, only a few existing methods treat the Key and Value caches differently, despite their distinct roles. Moreover, these methods typically employ fixed attention-head grouping, which may not fully exploit the structural similarity among attention heads. In this paper, we propose an improved low-rank KV cache compression framework. For the Key cache, we dynamically group attention heads based on Centered Kernel Alignment (CKA) similarity and allocate the rank budget adaptively under a parameter budget. For the Value cache, we adopt the same approach as ReCalKV, refining the low-rank decomposition through offline calibration to improve reconstruction quality. Experimental results on three instruction-tuned LLMs show that our method reduces the number of Key cache parameters while maintaining competitive accuracy. We further observe that the proposed strategy is particularly effective for Multi-Head Attention (MHA) models, whereas it should be applied more conservatively to Grouped-Query Attention (GQA) models, especially in long-context settings.

  - 未区分Key缓存和Value缓存的角色差异（Key主要作为注意力索引，Value包含完整信息，两者应有不同压缩策略）；
  - 采用固定的注意力头分组（如每4个头一组），未充分利用头间的结构相似性，导致压缩效率受限。
- **研究动机**：提出动态分组和自适应秩分配策略，在保持模型精度的前提下进一步减少Key缓存的参数，并分析不同注意力架构（MHA vs. GQA）下的适用性。
- **整体含义**：DynaCalKV是一个改进的低秩KV缓存压缩框架，通过CKA相似性动态聚类Key头，并贪心调整秩满足参数预算；Value缓存沿用ReCalKV的离线校准方法。实验表明对MHA模型效果显著，对GQA模型需谨慎使用。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **Key缓存**：基于CKA相似性动态分组，再根据组的能量（奇异值平方和）初始化秩，最后通过贪心算法调整秩以满足参数预算（总参数不超过ReCalKV的固定分组方案）。
- **Value缓存**：不分组，对整个投影矩阵做低秩SVD，然后通过校准数据最小化重构误差（交替更新左右因子）。

### 关键技术细节

1. **全局秩分配**：采用Palu的方法，基于Fisher Information分数在层间分配秩预算。
2. **Key压缩（算法1）**：
   - 输入：Key投影矩阵 \( W^{(k)} \)，相似度矩阵 \( S \)，秩预算 \( r \)，候选聚类数 \( K \)。
   - 步骤：
     - 对每个候选 \( K \)，用层次聚类（Agglomerative Clustering）基于CKA相似矩阵 \( S \) 将头聚类成 \( K \) 组，得到 \( \{W_i\} \)。
     - 根据每个组的能量（奇异值平方和）初始化每组秩 \( r_i = \text{round}(r \cdot \text{energy}(W_i)/\text{energy}(W^{(k)})) \)。
     - 贪心调整：在参数约束 \( \sum r_i \alpha_i \leq 4r/h \)（与ReCalKV对比）下，每次选择归一化能量损失最小的组减少1秩，直到满足约束。
     - 对每组做低秩分解 \( W_i \approx L_i R_i \)。
     - 计算重构误差 + 秩利用率惩罚（\( \lambda=1 \)），选最优 \( K \)。
3. **Value压缩**：
   - 直接对 \( W^{(v)} \) 做SVD得到 \( L_v, R_v \)。
   - 利用校准数据 \( X \)，通过闭式解交替更新 \( L_v \) 和 \( R_v \) 以最小化 \( \|L_v R_v X - W^{(v)} X\|_F^2 \)。
4. **动态分组依据**：线性CKA相似度，公式为 \( \text{CKA}(X,Y) = \frac{\|Y^\top X\|_F^2}{\|X^\top X\|_F \|Y^\top Y\|_F} \)，范围0~1。

## 3. 实验设计：数据集、基准、对比方法

## 6. 主要结论与发现

1. **参数减少**：DynaCalKV相比ReCalKV减少Key缓存参数16%–65%，取决于模型架构和头维度。
2. **零样本精度**：整体与ReCalKV保持同一水平，平均差异在-0.81%到+0.44%之间；对MHA模型（SmolLM2）甚至略有提升。
3. **长上下文性能**：
   - Qwen1.5（MHA）几乎无损失（平均-1.02%），在部分任务上有轻微提升。
   - Llama-3.2（GQA）显著下降（平均-8.03），尤其在检索和摘要任务。
4. **架构敏感性**：DynaCalKV对标准MHA模型（多头数多）非常有效；对已采用GQA（Key头少）的模型，在长上下文场景下需谨慎使用。
5. **分组效果**：高头维度（dh=128）导致头间相似度低，形成更多单例组，参数减少有限；低头维度（dh=64）更容易形成大组，参数减少显著。

## 7. 优点

- **创新性**：首次引入动态头分组（基于CKA）和自适应秩分配，克服固定分组的局限。

- **闭环设计**：Value压缩采用校准数据精调，弥补SVD在激活分布上的次优性。
