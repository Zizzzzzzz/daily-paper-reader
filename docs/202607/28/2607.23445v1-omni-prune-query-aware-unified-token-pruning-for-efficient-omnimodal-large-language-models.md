## 摘要
全模态大语言模型（OmniLLMs）正迅速扩展多模态推理能力以覆盖同步音频和视频。然而，由此产生的音视频令牌序列较长，导致推理时预填充延迟高、GPU内存占用大。现有令牌剪枝方法主要针对纯视觉输入设计，既忽视了音频与视频之间的跨模态关联，也忽略了决定内容重要性的用户查询。为填补这一空白，我们提出Omni-Prune，一种无需训练、查询感知的视听令牌剪枝框架，它联合移除两种模态的冗余，同时保留任务相关的跨模态证据。具体而言，Omni-Prune首先将令牌序列划分为位于音频显著性峰值处的自适应时间窗口，然后在结合编码器注意力与文本查询相关性的单一尺度上对音频和视频令牌进行评分，并将相关的音视频令牌配对以共同保留。在每个窗口内，最终采用K-medoids步骤选择少量代表性令牌，增加单独基于评分的选取所遗漏的多样化线索。大量实验表明，Omni-Prune优于现有基线方法，可实现高达3.25倍预填充加速和1.3倍内存减少，同时保留超过99%的完整模型性能。

## Abstract
Omnimodal large language models (OmniLLMs) are rapidly extending multimodal reasoning to cover synchronized audio and video. However, the resulting audio-video token sequences are long, leading to high prefill latency and GPU memory usage at inference time. Existing token pruning methods, designed mainly for vision-only inputs, miss both the cross-modal links between audio and video and the user query that decides which content matters. To bridge this gap, we present Omni-Prune, a training-free, query-aware audio-visual token pruning framework that jointly removes redundancy from both modalities while keeping task-relevant cross-modal evidence. Specifically, Omni-Prune first splits the token sequence into adaptive time windows placed at audio saliency peaks, then scores audio and video tokens on a single scale that combines encoder attention with text-query relevance, and pairs related audio-video tokens so that they are kept together. Within each window, a final K-medoids step then selects a few representative tokens, adding diverse cues that score-based selection alone would miss. Extensive experiments demonstrate that Omni-Prune outperforms established baseline methods, delivering up to 3.25x prefill speedup and 1.3x memory reduction while retaining over 99% of full-model performance.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：全模态大语言模型（OmniLLMs）能同时处理文本、音频和视频，但其海量的音频-视觉令牌序列导致推理时预填充（prefill）延迟高、GPU 内存占用大。
- **背景**：现有令牌剪枝方法主要面向纯视觉输入（如图像、视频），忽略了音频-视频之间的跨模态关联；同时，用户查询（文本）也未被用于指导剪枝决策，导致冗余保留和效率低下。
- **目标**：提出一种**训练无关**、**查询感知**的音频-视觉令牌联合剪枝框架，在保持任务相关跨模态证据的同时，高效移除冗余令牌。

## 2. 方法论
### 核心思想
- 采用**音频锚定的自适应窗口划分**、**统一评分与跨模态配对**、以及**多样性保留的K-medoids聚类**，在不训练的情况下实现协同剪枝。

### 关键技术细节
1. **音频锚定自适应窗口（Audio-Anchor Adaptive Windowing, AAW）**：
   - 将音频令牌序列均匀划分为与视频帧对齐的段，计算每段音频编码器注意力的均值作为能量曲线。
   - 通过平滑和局部峰值检测得到窗口边界，并设置最小间隔`f_min=2`避免碎片化，生成内容自适应的时序窗口。

2. **跨模态关系图（Cross-Modal Relation Map, CMRM）**：
   - **令牌重要性评分**：在每个窗口内，对音频和视频令牌的编码器注意力分数进行**联合归一化**（min-max归一化至[0,1]），并计算每个令牌与用户文本查询的余弦相似度，将两者相加得到复合分数`φ_i`。
   - **候选保留**：根据归一化注意力是否超过窗口均值，或文本相关性是否超过阈值`τ=0.55`，筛选候选令牌，并按`φ_i`排序保留最多`ρ_keep`比例作为初始保留集。
   - **跨模态配对**：计算窗口内音频与视频令牌的余弦相似度矩阵，采用双向贪婪匹配，将相似度超过门限`γ=0.6`的令牌对共同保留，其余预算优先补足少数模态以保持平衡。

3. **多样性保留聚类**：
   - 对未选中的令牌，在每个窗口内按模态分别使用**K-medoids**（而非K-means，因中心点为真实令牌），选取少数代表令牌（`ρ_c=0.1`），最大化嵌入空间覆盖度，补充高评分令牌可能遗漏的细节信息。

### 算法流程（文字说明）
- 输入：视听令牌序列、编码器注意力分数、文本查询嵌入。
- 步骤1：通过音频能量峰值生成自适应窗口。
- 步骤2：在每个窗口中计算复合分数，选出高置信度令牌集`Kw`。
- 步骤3：跨模态配对生成配对集`Pw`。
- 步骤4：全局按分数优先填充预算到`Kw`，然后优先填充`Pw`中的未选中对，最后补充剩余预算（偏好少数模态）。
- 步骤5：对剩余未选令牌执行K-medoids，挑选`ρ_c`比例的代表令牌。
- 输出：二进制掩码`m`，保留选中的音频-视觉令牌及所有文本令牌。
