## 摘要
高效的长上下文推理不仅关乎降低内存成本，还关乎在生成过程中保持有用上下文证据的可用性。然而，现有的压缩方法，如键值（KV）缓存压缩和上下文压缩，通常要么早期决定保留哪些上下文信息，要么依赖外部压缩器。这种设计使得压缩后的上下文难以适应后续推理步骤所需的证据。本文提出了PReM（保留与刷新记忆），一种上下文压缩框架，将长上下文保持为模型内部的分层KV记忆，并学习保留什么以及何时刷新。具体而言，PReM使用专用记忆层进行记忆选择决策，并使用特殊记忆token <m>在生成过程中触发刷新。为训练这种行为，PReM引入了相位分离刷新训练，将记忆选择与记忆条件生成对齐，同时保持刷新间的连续性。在32K token上下文上的实验表明，PReM在16倍和32倍压缩下均优于强基线，同时在答案质量和推理效率之间保持了良好的平衡。

## Abstract
Efficient long-context inference is not only about reducing memory cost, but also about keeping useful contextual evidence accessible as generation proceeds. However, existing compression-oriented approaches, such as key-value (KV) cache compression and context compression, often either make an early decision about which contextual information to keep or rely on an external compressor. Such designs make it difficult to adapt the compressed context to the evidence needed by later reasoning steps. This paper introduces PReM (Preserve and Refresh Memory), a context-compression framework that maintains the long context as the model's internal layer-wise KV memory and learns what to preserve and when to refresh it. Specifically, PReM uses a dedicated memory layer to make memory-selection decisions, and a special memory token <m> to trigger refreshes during generation. To train this behavior, PReM introduces Phase-Separated Refresh Training, aligning memory selection with memory-conditioned generation while preserving continuity across refreshes. Experiments with 32K-token contexts show that PReM outperforms strong baselines under both 16x and 32x compression, while maintaining a favorable balance between answer quality and inference efficiency.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：长上下文推理中，现有压缩方法（KV缓存压缩、上下文压缩）存在两个关键局限：一是**静态证据保留**——早期决定保留哪些信息后整个生成过程不再变更，无法适应多步推理中不同步骤对不同上下文证据的需求；二是**解耦的证据选择**——依赖外部压缩器单独进行压缩，与生成过程脱节，额外增加计算且难以针对当前推理步骤定制证据选择。
- **核心问题**：如何实现一种**动态**的上下文压缩机制，让模型在生成过程中能够自主判断何时需要刷新记忆，并保留当前步骤所需的证据，同时丢弃无关信息。
- **整体含义**：提出PReM框架，将长上下文作为模型内部的逐层KV记忆，通过学习“保留什么”（记忆选择）和“何时刷新”（通过特殊token <m>触发），实现无需外部压缩器的、与生成耦合的动态压缩，从而在降低内存成本的同时保持有用证据的可访问性。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将长上下文压缩视为**记忆保留与刷新**的学习问题。PReM将上下文编码为LLM内部的逐层KV记忆，并维护原始上下文作为刷新来源。使用一个专用**记忆层**（位于中间至后层）负责记忆选择决策，一个特殊**记忆token <m>**作为显式内部刷新信号。
- **关键技术细节**：
  - **上下文记忆**：在生成前将长上下文编码为每层KV状态（Mℓ），后续被压缩后以额外KV形式参与标准注意力计算。
  - **记忆选择与刷新**：以**块粒度**（chunk）进行选择。将N个上下文位置划分为C个连续块（块大小c）。记忆层ℓm额外添加选择查询投影矩阵Wcℓ，将输入隐状态映射为选择查询。对于每个推理步骤s，利用问题（步骤0）或<m>隐状态（后续步骤）作为选择查询，计算每个块的注意力得分aℓ,s,j，取Top-K个块保留其完整token级KV，其余块平均池化为一个代表对。选中的块索引（S_s）被复用到所有层（记忆层以下层临时压缩后由记忆层结果刷新，以上层直接复用索引）。
  - **刷新机制**：当模型生成<m>时，其隐状态触发重新选择，更新后的选择刷新所有层的压缩记忆。
  - **相位分离刷新训练**：将每个步骤拆分为**记忆选择阶段**和**记忆条件生成阶段**，分别做前向传播并设置不同损失。记忆选择阶段只处理query位置（问题或<m>），计算对比损失L_ms（训练记忆层将证据块排到非证据块前面）；生成阶段处理教师强制下的答案片段ys，使用语言建模交叉熵L_ans；同时增加**边界交叉熵**L_bd，连接选择阶段到第一个答案token，以及前一段末尾到下一个<m>，保证分段训练具有与完整自回归相同的token覆盖。总损失为L = (1/N_LM) * Σ(L_ans + L_bd) + λ_ms * (1/T) * Σ L_ms。
- **公式/算法流程**（文字说明）：
  1. 预处理：将长上下文编码为逐层KV记忆Mℓ。
  2. 每个推理步骤s：由query位置（步骤0为问题，后续为<m>）计算块得分aℓm,s,j → 取Top-K → 构建压缩记忆（保留块保持token级，非保留块平均池化） → 刷新所有层的记忆。
  3. 训练时：按目标序列[x, y0, <m>, y1, ..., <m>, y_{T-1}]，每个步骤先对query做选择阶段并计算L_ms，然后对答案段做生成阶段并计算L_ans和L_bd。
  4. 推理时：按上述选择-刷新-生成循环进行自回归解码。

## 6. 主要结论与发现
- PReM在16×和32×压缩下均取得最佳平均EM/F1，在3B/7B上分别比最强基线提升最多10.23/12.55分（32×时）。
