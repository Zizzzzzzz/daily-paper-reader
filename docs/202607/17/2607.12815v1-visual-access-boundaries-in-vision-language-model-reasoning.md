## 摘要
思维链（CoT）提示被广泛用作视觉-语言模型（VLM）的测试时扩展策略，但目前尚不清楚VLM生成更长推理轨迹时扩展的是什么。我们探究CoT是否需要持续访问图像标记，还是主要依赖于前向传播中早期已提供的视觉信息。我们引入视觉访问扫描，这是一种因果干预方法，沿着层深度和生成时间掩盖从生成令牌查询到图像令牌密钥的注意力，并将视觉访问边界（VAB）定义为保持任务准确性的最小访问区域。在Qwen2.5-VL和InternVL3的六种模型配置中，无CoT直接回答和CoT提示均表现出有限的VAB。在Qwen2.5-VL-32B以及14B和38B规模的InternVL3中，当CoT与无CoT全访问目标进行评估时，其VAB层与无CoT边界最多相差两层，尽管生成了更长的序列。这表明CoT并非主要通过延长推理轨迹中的直接图像令牌访问来提升性能，而是通过扩展基于图像派生隐藏状态信息的语言侧计算。我们进一步表明，CoT的收益受限于感知读出。当查询的视觉属性可被模型可靠读出时，CoT有效；当该读出不可靠时则无效。一个符号属性预测显示，一旦将真实属性作为文本提供，CoT可以改善计数；而一个单目标探测与解码检查表明，困难属性可以从隐藏状态线性恢复，但模型自身难以输出。这些分析共同将瓶颈置于读出而非计数。

## Abstract
Chain-of-Thought (CoT) prompting is widely used as a test-time scaling strategy for Vision-Language Models (VLMs), but it remains unclear what is extended when VLMs generate longer reasoning traces. We ask whether CoT requires continued access to image tokens, or whether it mainly operates over visual information already made available earlier in the forward pass. We introduce Visual Access Sweep, a causal intervention that masks attention from generated-token queries to image-token keys along layer depth and generation time, and define the Visual Access Boundary (VAB) as the minimal access region that preserves task accuracy. Across six model configurations from Qwen2.5-VL and InternVL3, both no-CoT direct answering and CoT prompting exhibit finite VABs. In Qwen2.5-VL-32B and InternVL3 at 14B and 38B scales, when CoT is evaluated against the no-CoT full-access target, its VAB layer differs from the no-CoT boundary by at most two layers, despite substantially longer generations. This suggests that CoT does not primarily improve performance by prolonging direct image-token access throughout the reasoning trace, but by extending language-side computation over image-derived hidden-state information. We further show that CoT gains are constrained by perceptual readout. CoT helps when the queried visual attribute can be reliably read out by the model, but not when that readout is unreliable. A symbolic-attribute oracle shows that CoT can improve counting once ground-truth attributes are supplied as text, while a single-object probe-vs-decode check shows that hard attributes can be linearly recoverable from hidden states yet difficult for the model itself to output. Together, these analyses place the bottleneck at readout rather than counting.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：在视觉-语言模型（VLM）中，思维链（Chain-of-Thought, CoT）提示通过生成更长的推理轨迹来提升性能时，到底扩展了什么？是**持续直接访问图像令牌（image tokens）**，还是主要利用**早期已经传播到隐藏状态中的视觉信息**进行语言侧计算？
- **研究背景**：已有观察表明VLM生成过程中对图像令牌的注意力会衰减，但注意力大小不能证明必要性（低注意力可能意味着不再需要，也可能意味着访问失败）。现有研究主要通过增强视觉注意力来改善性能，但缺乏对“何时继续直接访问图像令牌是功能上必要的”这一因果性问题的理解。
- **意义**：为CoT的测试时扩展机制提供因果解释，并揭示其瓶颈所在，从而指导VLM推理效率优化和主动感知方法的设计。

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想：Visual Access Scop (Visual Access Sweep) 与 Visual Access Boundary (VAB)
- **因果干预**：通过遮罩（mask）沿**层深度**和**生成时间**两个轴向上，从生成令牌查询（generated-token queries）到图像令牌键（image-token keys）的直接注意力，从而测试直接图像令牌访问的必要性。
- **操作定义**：对于一个给定的层数截断 `ℓ_cutoff` 和时间截断 `t_cutoff`，只允许在 `ℓ ≤ ℓ_cutoff` 且 `t ≤ t_cutoff` 的矩形区域内保留注意连接，其余区域将注意力分数设为 `-∞`（即对应 softmax 权重为0）。
- **VAB定义**：在给定容差 `ϵ`（默认0.05）下，能够保持任务准确率不低于全访问基线（`A_full`）的最小访问区域 `(ℓ*, τ*)`，其中 `τ = min(t_cutoff, T_gen)`（有效令牌窗）。
- **三个对比标准**：
  - 直接边界 `ℓ*_D`：Direct 全访问 vs Direct 干预。
  - CoT自身最大边界 `ℓ*_CoT`：CoT全访问 vs CoT干预。
  - 直接锚定CoT边界 `ℓ*_DA`：Direct全访问 vs CoT干预（用于控制Direct和CoT天花板差异）。
- **两种层移量**：`Δℓ*_own = ℓ*_CoT - ℓ*_D` 和 `Δℓ*_DA = ℓ*_DA - ℓ*_D`。

### 控制实验
- **晚层查询文本块**：额外遮罩晚层中查询文本令牌到图像令牌的注意力，排除通过文本路径的间接重新读取。
- **空汇（null-sink）控制**：将移除的图像注意力权重重定向到虚拟的非视觉汇位置，排除注意力质量重新分配的人为效应。

## 6. 论文的主要结论与发现
1. **有限VAB的存在性**：无论是Direct还是CoT，在所有测试的模型中都表现出清晰的有限VAB。性能在遮罩大范围晚层后仍保持，仅在干预到达早层或早令牌时急剧下降。
2. **CoT不扩展直接图像令牌访问**：在大模型（Qwen2.5-VL-32B, InternVL3-14B/38B）上，CoT的VAB层数与Direct边界相差最多2层（直接锚定标准），尽管生成长度增加了约50倍。表明CoT的优势并非来自在整个推理轨迹中延长对图像令牌的直接访问，而是来自基于早期图像派生隐藏状态的语言侧计算。
3. **感知读出决定CoT收益**：在Qwen2.5-VL的三个尺度上，每属性CoT增益（CoT - Direct）与多物体感知读出准确率正相关（3B: ρ=+1.0, 7B: ρ=+1.0, 32B: ρ=+0.5）。当属性可通过符号（oracle）提供时，CoT在所有属性上均恢复增益，包括原先弱的属性（角度、大小）。
4. **瓶颈在读出而非计数**：单物体probe-vs-decode诊断显示，困难属性（角度、位置、大小）可从隐藏状态线性恢复（探测准确率>0.89），但模型自身解码输出准确率很低（0.28-0.38），证明具体视觉信息内部存在但模型无法可靠读出为可用符号。CoT不能修复这一读出缺陷。
5. **选择性CoT路由的实用潜力**：基于属性读出的简单阈值路由策略（读出>0.5时使用CoT，否则Direct）可保留75-87%的全CoT增益，同时节省约50%的输出令牌。

## 7. 优点
- **因果性**：通过主动干预（遮罩注意力）而非观察注意力大小来测试必要性，避免了相关性混淆。
- **双轴扫描**：同时考虑层深度和生成时间，提供更精细的组织图。
- **跨家族与跨规模验证**：从3B到38B，覆盖Qwen2.5-VL和InternVL3两种架构，并包括交叉注意力融合pilot，增强泛化性。
- **瓶颈分析完整**：联合多物体读出预测、oracle bypass、probe-vs-decode三种方法，隔离了“内部编码-模型输出-CoT收益”三个环节，逻辑严谨。
- **控制实验充分**：排除注意力质量重新分布和通过查询文本的间接重新读取等替代解释。
- **实际启示**：提出可操作的CoT路由启发式，兼顾精度和效率。

## 8. 不足与局限
- **任务覆盖有限**：
  - 主要依赖合成属性计数任务和GQA是/否子集，未覆盖需要迭代视觉检查（如“第二个从左边数”）、空间关系推理、或场景理解等更丰富的视觉推理。
  - 角度任务由于准确率接近随机（floor效应），VAB不可定义，限制了该属性上的结论。
- **模型范围**：
  - 仅包括Qwen2.5-VL和InternVL3（prefix-fusion）以及Llama-3.2-Vision（cross-attention）pilot，未测试如构建显式重新感知循环（active perception）的模型（如MemVR, Look-Back, Visual Perception Token）。
  - 同主流架构相比，泛化性需更多验证。
- **机制解释不足**：
  - VAB只标识了一个通道（直接注意力）的冗余性，未解释内部机制——为什么边界出现在该层/时间段？可能是早期把视觉信息绑定到隐藏状态，或晚层通过残差流获得足够信息，或CoT将视觉提取前置。
- **GQA实验缺陷**：
  - CoT在GQA上性能略低于Direct（0.80 vs 0.84），尽管VAB结构仍然存在。论文承认这与近期发现一致（更长推理可能削弱感知基础），但未深入分析为何在真实图像上CoT未重现合成任务中的增益。
- **评估指标**：只使用准确率作为易损性度量，未考虑置信度、推理时间等维度。
- **实操门槛**：多物体读出任务本身需要模型输出属性值，可能受限于模型的格式遵循能力，提取精度影响结果。
