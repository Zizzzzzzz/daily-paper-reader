## 摘要
视觉-语言-动作（VLA）模型在视觉运动策略学习方面取得了令人瞩目的成果，但其本质上是反应式的，将当前观测和语言映射为动作，而缺乏对世界动态的显式前向预测。现有的视觉预见方法能够预测未来的视觉状态，但缺乏明确的运动引导：它们显示目标位置，却未说明如何到达。我们认为，未来特征预测与稀疏点跟踪具有天然的互补性：前者提供目标状态，后者捕捉朝向目标的连续运动路径。我们提出FoMoVLA框架，通过联合学习未来特征预见和稀疏2D点跟踪，以显式的时空监督增强VLA表示，从而优化连续动作策略。FoMoVLA引入紧凑的预见令牌以解码未来特征状态，解码稀疏时间2D点轨迹以建模紧凑的几何运动，并通过轻量化的未来条件交叉注意力模块将两者耦合，使得预期状态与点动力学之间可以实现一致的推理。在LIBERO、RoboCasa GR-1 Tabletop和LIBERO-Plus上的大量实验表明，该方法具有最先进的性能和强大的零样本泛化能力。项目页面见https://liauto-research.github.io/FoMoVLA。

## Abstract
Vision-Language-Action (VLA) models have achieved impressive results in visuomotor policy learning, yet remain fundamentally reactive, mapping current observations and language to actions without explicit forward prediction of world dynamics. Existing visual foresight methods predict future visual states but lack explicit motion guidance: they show where to go but not how to get there. We argue that future feature prediction and sparse point tracking are naturally complementary: the former provides the goal state, while the latter captures the continuous motion path toward it. We propose FoMoVLA, a framework that augments VLA representations with explicit spatio-temporal supervision by jointly learning future feature foresight and sparse 2D point tracking, enhancing the continuous action policy. FoMoVLA introduces compact foresight tokens to decode future feature states, decodes sparse temporal 2D point trajectories to model compact geometric motion, and couples both through a lightweight future-conditioned cross-attention module that enables consistent reasoning between anticipated states and point dynamics. Extensive experiments on LIBERO, RoboCasa GR-1 Tabletop, and LIBERO-Plus demonstrate state-of-the-art performance and strong zero-shot generalization. Project page is available at https://liauto-research.github.io/FoMoVLA.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **现有瓶颈**：视觉-语言-动作（VLA）模型虽然在机器人操作中表现优异，但本质上是**反应式**的，仅依赖当前观测和语言指令直接映射到动作，缺乏对世界动态的前向预测，无法显式建模未来场景演化或长程物体动力学。
- **现有方法不足**：
  - 视觉预见方法（如像素级预测或潜空间预测）能给出未来目标状态，但缺少“如何到达”的连续运动引导。
  - 运动跟踪方法（如光流或点轨迹）能提供密集运动线索，但缺乏未来目标状态的全局语义信息。
- **核心洞察**：未来特征预测（告诉“去哪里”）与稀疏点跟踪（告诉“怎么去”）是天然互补的。只有将两者联合建模并强制一致性，才能为动作生成提供完整的时空指导。
- **解决方案**：提出 **FoMoVLA**，通过联合学习紧凑的未来特征预测和稀疏 2D 点轨迹跟踪，在共享骨干网络内注入显式的时空监督，从而增强 VLA 策略的连续动作生成能力。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 整体架构（图 2）

- 基于 VLM 骨干网络，在训练时增加三个辅助分支，所有分支在推理时丢弃：
  1. **点跟踪分支**：从图像令牌隐藏状态预测 2D 点轨迹（“怎么移动”）。
  2. **未来特征预测分支**：通过紧凑的 `<Foresight>` 令牌解码未来视觉特征（“最终状态在哪里”）。
  3. **未来条件交叉注意力（FCCA）模块**：将未来特征作为条件注入点跟踪分支，确保两者一致性。

### 2.2 关键技术细节

#### （1）点跟踪（Section 3.2）
- **稀疏点选择**：利用 ViT 的 patch 网格（8×8=64 个点），每个图像令牌对应一个查询点。
- **教师监督**：使用冻结的 CoTracker-v3 生成每帧位移目标 \(d^\star \in \mathbb{R}^{N \times T \times 2}\) 和可见性掩码 \(v^\star\)。
- **对齐头**：从图像令牌隐藏状态通过两个 MLP 分别预测位移 \(\hat{d}\) 和可见性 \(\hat{v}\)。
- **损失函数**：
  - 位移回归：\(L_{\text{disp}} = \frac{1}{NT}\sum v^\star_{n,t} \|\hat{d}_{n,t} - d^\star_{n,t}\|^2\)
  - 可见性分类：\(L_{\text{vis}} = \text{BCE}(\hat{v}, v^\star)\)
  - 平滑性正则：\(L_{\text{smooth}}\) 约束二阶时间差分，抑制突变。

#### （2）未来特征预测（Section 3.3）
- **紧凑瓶颈**：在输入序列末尾添加 K=16 个可学习的 `<Foresight>` 令牌，其隐藏状态被训练为编码动作块最后一帧（\(o_{t+T}\)）的视觉特征。
- **EMA 教师**：维护一个动量更新的视觉编码器（\( \mu=0.999\)），对目标帧提取 M=64 个 patch 特征 \(z^\star\)。
- **MAE 解码器**：将 K 个 `<Foresight>` 隐藏状态与 M-K 个可学习掩码令牌拼接，通过轻量 ViT 解码器重建预测 \(\hat{z}\)。
- **损失函数**：余弦相似度 \( L_{\text{foresight}} = 1 - \frac{1}{M}\sum_i \frac{\hat{z}_i \cdot z^\star_i}{\|\hat{z}_i\|\|z^\star_i\|}\)。

#### （3）未来条件交叉注意力（FCCA，Section 3.4）
- 在 VLM 视觉特征提取与位移预测器之间插入零初始化的交叉注意力模块。
- 输入：视觉令牌特征 \(H_{\text{vis}} \in \mathbb{R}^{N \times d}\)，未来令牌特征 \(H_{\text{fut}} \in \mathbb{R}^{K \times d}\)。
- 计算：\(\tilde{H}_{\text{vis}} = H_{\text{vis}} + \text{MHA}(\text{LN}(H_{\text{vis}}), \text{LN}(H_{\text{fut}}), \text{LN}(H_{\text{fut}}))\)。
- 零初始化确保训练开始时为恒等映射，保护预训练特征，随后逐步注入未来信息。

#### （4）训练与推理（Section 3.5）
- **总损失**：\( L = L_{\text{action}} + \lambda_1 L_{\text{foresight}} + \lambda_2 (L_{\text{disp}} + L_{\text{vis}} + \lambda_{\text{smooth}} L_{\text{smooth}}) \)。
  - 流匹配动作头使用动作块预测。
- **推理**：丢弃所有辅助分支，仅保留 `<Foresight>` 令牌（增加 9.4ms 延迟和 0.1GB 显存），性能无额外参数开销。

## 6. 论文的主要结论与发现

1. **联合学习优于单独学习**：未来预测与点跟踪各自独立均能提升性能，但联合训练带来更大增益（LIBERO Long 从 92.0%→94.4%→95.8%）。
2. **FCCA 实现协同**：仅简单组合两目标而不加耦合（FCCA）效果有限；显式以未来条件引导点跟踪在 LIBERO Long 上额外提升 1.8%，且定量跟踪误差下降 25-43%（图6）。

## 8. 不足与局限

- **2D 空间局限**：当前跟踪仅在 2D 图像空间建模，无法捕获场景的 3D 几何结构，对视角剧烈变化或深度变化敏感（实验也显示对 camera/robot state 扰动泛化较弱）。

- **未探讨 3D 集成**：作者自认未来方向是结合 3D 运动预测，当前方法在 3D 场景理解方面缺失。
