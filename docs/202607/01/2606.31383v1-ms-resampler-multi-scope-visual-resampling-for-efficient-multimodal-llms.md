## 摘要
多模态大语言模型（MLLMs）通常采用基于重采样的投影器，将密集的视觉特征转换为用于语言建模的紧凑标记序列。现有大多数重采样器通过全局交叉注意力采用单一、固定的聚合范围，这可能会模糊细粒度的局部证据，并限制在固定标记预算内同时捕获局部细节和全局上下文的能力。在这项工作中，我们提出了MS-Resampler，一种用于MLLMs的多范围视觉重采样框架。MS-Resampler通过将显式的空间范围先验注入重采样注意力中，实例化了多个特定范围的重采样器，使每个分支能够在从局部到全局的特定粒度上聚合视觉信息。然后，这些特定范围重采样器的输出被自适应地融合，以生成用于语言建模的最终视觉表示。在十个公共多模态基准上的大量实验表明，与传统的单一范围重采样器相比，MS-Resampler在引入最小计算开销的同时，持续提升了视觉理解和多模态推理能力。

## Abstract
Multimodal large language models (MLLMs) typically employ resampling-based projectors to transform dense visual features into a compact token sequence for language modeling. Most existing resamplers adopt a single, fixed aggregation scope via global cross-attention, which can blur fine-grained local evidence and limit the ability to capture both local details and global context within a fixed token budget. In this work, we propose MS-Resampler, a multi-scope visual resampling framework for MLLMs. MS-Resampler instantiates multiple scope-specific resamplers by injecting explicit spatial scope priors into the resampling attention, enabling each branch to aggregate visual information at a particular granularity from local to global. The outputs of these scope-specific resamplers are then adaptively fused to produce the final visual representations for language modeling. Extensive experiments on ten public multimodal benchmarks show that MS-Resampler consistently improves visual understanding and multimodal reasoning over conventional single-scope resamplers, while introducing only minimal computational overhead.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：多模态大语言模型（MLLMs）中的视觉投影器（visual projector）负责将视觉编码器输出的密集特征压缩为紧凑的标记序列，以便语言模型处理。现有基于重采样的投影器（例如 BLIP-2 中的 Q-Former）通常对所有查询使用全局交叉注意力，即单一固定的聚合范围。这种设计会模糊细粒度的局部证据（如小文本、小物体、微妙属性），且难以在固定 token 预算下同时捕获局部细节和全局上下文。
- **整体含义**：视觉语义天然具有多空间尺度特性——细粒度概念依赖局部邻域，而组合推理与场景理解需要更广的上下文。现有单范围重采样器本质上存在局部保真度与全局上下文之间的权衡，限制了视觉-语言对齐的质量。论文旨在通过多范围融合的策略突破这一限制，提升紧凑视觉表征的信息密度和语义丰富度。

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- 提出 **MS-Resampler**——一种多范围视觉重采样框架。
- 核心是注入**显式空间范围先验**到交叉注意力中，实例化多个**范围特定重采样器**（scoped resampler），每个分支在从局部到全局的特定粒度上聚合信息，最后通过轻量融合得到紧凑的视觉 token。

#### 关键技术细节
- **Scoped Resampler（范围重采样分支）**：对第 e 个分支，在标准交叉注意力 softmax 前的 logit 中**添加一个空间注意力偏置矩阵** \(B^{(\text{e})}\)：
  \[
  O^{(e)} = \text{Softmax}\left(\frac{Q^{(e)}(K^{(e)})^\top}{\sqrt{c}} + \beta B^{(e)}\right) V^{(e)}
  \]
  其中 \(\beta\) 控制先验强度（\(\beta=0\) 退化为全局重采样）。
- **空间偏置构造**：
  - 将视觉 token 网格划分为 \(M\) 个非重叠区域，每个区域中心作为对应 query 的锚点。
  - 对于分支 e，定义以锚点为中心的 \(k^{(e)}\times k^{(e)}\)窗口。
  - 偏置矩阵元素：窗口内为 0（偏好），窗口外为 -1（抑制），但仍然是软偏置，允许越界注意力。
- **多分支与融合**：
  - 实例化 E 个分支，窗口大小 \(\{k^{(1)},\dots,k^{(E)}\}\) 逐步增大（如 \(\{2,6,14\}\)）。
  - 所有分支共享相同的 query 锚点，输出形状均为 \(M\times c\)。
  - **位置级融合**：对每个 token 索引 i 和通道 j，将 E 个分支的输出组成向量 \(z_{i,j}\in\mathbb{R}^E\)，通过一个共享的两层 MLP（沿专家维度）融合为最终值 \(O_{\text{final},i,j}\)。该 MLP 在所有 i,j 上共享参数，保证位置对齐且轻量。
- **整体流程**：视觉编码器 → 多范围重采样分支（E 个） → 通道级 MLP 融合 → 紧凑视觉 token → 输入 LLM。

### 6. 论文的主要结论与发现

- **主要结论**：MS-Resampler 在几乎所有测试基准上一致优于传统的单范围重采样器以及其他投影器级压缩方法，尤其在 token 预算紧张时（64、36 token）优势更明显。
- **关键发现**：
  1. 显式空间范围先验（偏置）有助于分支专业化，且适中的 \(\beta\) 效果最好。
  2. 多范围组合（局部-中等-全局）优于任何单一窗口大小。
  3. 通道级 MLP 融合（逐通道沿专家维度融合）比平均融合、注意力融合、通道混合 MLP 更优。
  4. 与 LLM 内部 token 压缩方法相比，投影器级的多范围设计能在更少 token（144 vs 192）下达到甚至超越全 token 基线，而内部压缩方法普遍有精度下降。
  5. 方法在不同 LLM 骨干（Vicuna、Qwen2.5）上均有效，具有良好的泛化性。

### 7. 优点

- **方法简洁有效**：通过简单的空间偏置注入实现范围控制，无需复杂架构。
- **轻量**：额外计算开销极小（仅增加少量分支和一个小 MLP），训练和推理速度与同类方法相当。
- **信息丰富**：在固定 token 预算下同时保留局部细节和全局语义，解决了单范围重采样器的根本局限。
- **即插即用**：可替换任意 MLLM 的投影器，适用于不同规模的 LLM（7B、13B、3B）。
- **实验充分**：覆盖 10 个基准、多种对比方法、消融、效率分析，结果可信度高。
