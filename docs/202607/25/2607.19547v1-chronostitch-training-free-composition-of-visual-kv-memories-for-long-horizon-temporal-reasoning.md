## 摘要
长视频问答要求模型随时间保留视觉证据，而无需反复重新处理同一视频。一种实用的方法是将视觉语言模型的内部键值（KV）缓存存储到每个视频片段，并在查询时检索该状态。然而，独立缓存的视频片段无法正确组合：每个片段都从局部旋转位置零开始预填充，因此朴素拼接会碰撞时间相位，并丢失关于什么先发生、事件发生频率或视频中什么变化等问题所需的全局顺序。本文提出了ChronoStitch，一种无训练方法，用于组合独立存储的视觉KV记忆。该方法首先将存储的旋转后键重新基于全局三轴多模态RoPE坐标系，该坐标系保留了时间、高度和宽度结构。我们展示了为什么一维标量重新索引对于视觉标记在几何上不一致，因为它将帧内的空间顺序转换为虚假的时间位移。然后，我们解决了位置修复后残留的内容差距：后续片段最初是在没有关注前面片段的情况下编码的。因此，ChronoStitch选择性地重新计算一小部分高偏差的后片段视觉标记，同时允许它们关注组合后的缓存。在Qwen2.5-VL-3B和TempCompass的时间分割上，ChronoStitch优于朴素组合和仅位置变体，提高了事件排序准确性，同时比完全联合重新预填充快3.3倍。

## Abstract
Long-video question answering requires a model to preserve visual evidence over time without repeatedly reprocessing the same video. A practical approach is to store the vision-language model's internal key-value (KV) cache for each video chunk and retrieve that state at query time. However, independently cached video chunks do not compose correctly: every chunk is prefilled from local rotary position zero, so naive concatenation collides temporal phases and removes the global order required for questions about what happened first, how often events occurred, or what changed across the video. This paper presents ChronoStitch, a training-free method for composing independently stored visual KV memories. The method first re-bases stored post-rotary keys onto a global three-axis multimodal RoPE coordinate system that preserves time, height, and width structure. We show why a one-dimensional scalar re-indexing is geometrically inconsistent for visual tokens because it turns spatial order within a frame into false temporal displacement. We then address the residual content gap left by positional repair: later chunks were originally encoded without attending to earlier chunks. ChronoStitch therefore selectively recomputes a small fraction of high-deviation later-chunk visual tokens while allowing them to attend over the composed cache. On Qwen2.5-VL-3B and the temporal split of TempCompass, ChronoStitch outperforms naive composition and position-only variants, improving event-ordering accuracy while running 3.3x faster than full joint re-prefilling.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：长视频问答（Long-video QA）需要模型长期保留视觉证据，但现有方法要么重复处理整个视频（昂贵），要么使用文本摘要（有损）。一种有前景的方案是存储视频块的键值（KV）缓存，并在查询时检索组合。然而，独立缓存的视频块因局部位置编码归零而无法正确组合：朴素拼接会导致时间相位冲突，丢失全局顺序信息，从而无法回答“哪个事件先发生”、“事件发生频率”或“跨视频变化”等时序问题。
- **背景**：已有工作如KVLink、CacheBlend研究了文本侧的KV缓存复用，ReKV、StreamMem等研究了视频侧的流式KV缓存管理，但缺乏针对独立缓存块在模型原生三轴多模态RoPE（mRoPE）下如何正确组合的系统方法。ChronoStitch首次解决了这一组合问题。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：通过两阶段无训练过程修复独立视频块KV缓存的组合错误：①位置修复：将存储的旋转后键（post-rotary keys）从局部坐标重映射到全局三轴坐标；②内容修复：选择性地重计算少量后块高偏差视觉标记，使其能注意整个组合缓存。
- **关键细节**：
  - **三轴RoPE重基（Three-axis re-basing）**：视觉标记具有三维坐标 \( p = (p_t, p_h, p_w) \)（时间、高度、宽度）。对每个存储的键，计算坐标偏移 \(\Delta_i = (p'_{\sigma(i)} - p_{\sigma(i)}) \theta_i\)，然后直接对旋转后键施加旋转矩阵 \(R(\Delta)\)，无需恢复原始预旋转键。该操作精确重建了层0的联合预填充位置。
  - **一维标量重基的缺陷**：若将视觉标记展平为连续标量位置，同一帧内不同空间位置的标记将获得不同时间索引，导致空间顺序被错误编码为时间位移，几何上不一致。
  - **选择性重计算（Selective recomputation）**：位置修复后，后块内容仍缺失跨块注意力。ChronoStitch使用无监督代理：浅层重计算后，以层1键的变化幅度 \(\delta_t = \|k^{recomp}_t - k^{stored}_t\|^2\) 排序，选择最受影响的前 \(\rho\) 比例（实验中 \(\rho=0.35\)）的后块视觉标记，在完整组合缓存上重新计算所有层，并用新键值替换缓存中原条目。其余标记保持不变。
  - **效率成本**：联合预填充成本 \(C_{joint} \approx V + L(c_a T^2 + c_f T)\)；ChronoStitch成本 \(C_{Chrono} \approx L c_r T + 2(c_a |C| T + c_f |C|) + L(c_a \rho T^2 + c_f \rho T)\)，因 \(\rho < 1\) 且无需重新执行视觉塔（V），理论加速比约为 \(1/\rho\)。

- **无训练**：无需微调或训练，直接操作存储的KV缓存，易于部署。
