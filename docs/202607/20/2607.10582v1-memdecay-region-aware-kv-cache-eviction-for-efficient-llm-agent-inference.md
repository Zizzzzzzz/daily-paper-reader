## 摘要
大型语言模型（LLM）智能体会积累异构上下文，包括系统指令、计划、用户轮次、检索到的文档、工具输出和中间推理，其键值（KV）缓存可能成为主要的内存瓶颈。现有的淘汰策略通常对所有词元应用相同的基于注意力或基于最近性的规则，忽略了智能体编排器已经可用的语义结构。我们提出MemDecay，一种无需训练、面向区域感知的KV缓存淘汰策略。MemDecay为词元分配区域特定的基础优先级和衰减率，在词元获得注意力时刷新保留分数，并在固定缓存预算下淘汰得分最低的页面，同时允许关键区域被固定。我们还提供了一种根据测量的注意力生命周期校准衰减率的程序。我们使用Qwen2.5-1.5B和3B模型在约450和1,700词元上下文中评估MemDecay。在所有设置中，不同区域的注意力生命周期相差一个数量级：系统词元的半衰期范围从148到189个解码步骤，而草稿板词元则为14到16个。固定策略在每个设置中都能以全缓存精度保存系统区域的事实，而没有任何基线能保留超过24个中的13个。随着上下文增长，区域感知的保留仍然有效，而基于最近性的保留则失效。然而，累积注意力的保留在未固定内容上表现更好，消融实验表明注意力分数归一化是当前公式的主要限制。这些结果确立了语义提示结构作为KV缓存管理的稳健信号，同时阐明了应如何将其与基于注意力的重要性相结合。

## Abstract
Large language model (LLM) agents accumulate heterogeneous context, including system instructions, plans, user turns, retrieved documents, tool outputs, and intermediate reasoning, whose key-value (KV) cache can become a major memory bottleneck. Existing eviction policies generally apply the same attention- or recency-based rule to every token, ignoring semantic structure already available to the agent orchestrator.   We introduce MemDecay, a training-free, region-aware KV-cache eviction policy. MemDecay assigns tokens region-specific base priorities and decay rates, refreshes retention scores when tokens receive attention, and evicts the lowest-scoring pages under a fixed cache budget while allowing critical regions to be pinned. We also provide a procedure for calibrating decay rates from measured attention lifetimes.   We evaluate MemDecay at approximately 450 and 1,700 token contexts using Qwen2.5-1.5B and 3B. Across all settings, attention lifetimes differ by an order of magnitude across regions: system-token half-lives range from 148 to 189 decoding steps, compared with 14 to 16 for scratchpad tokens. Pinning preserves system-region facts at full-cache accuracy in every setting, while no baseline preserves more than 13 of 24. Region-aware retention remains effective as context grows, whereas recency-based retention collapses. Accumulated-attention retention performs better on unpinned content, however, and ablations identify attention-score normalization as the main limitation of the current formulation. These results establish semantic prompt structure as a robust signal for KV-cache management while clarifying how it should be combined with attention-based importance.

## 1. 核心问题与整体含义
- **研究动机**：大型语言模型（LLM）作为智能体运行时，会积累包含系统指令、计划、用户轮次、工具输出、检索文档和中间推理的异构上下文。这些上下文对应的键值（KV）缓存随序列长度线性增长，成为主要内存瓶颈，限制了长期推理和服务。
- **现有不足**：现有的KV缓存淘汰策略（如基于累积注意力、注意力汇点+最近窗口等）对所有词元采用统一规则，忽略了智能体编排器已经提供的语义结构（不同区域功能不同，应具有不同的保留寿命）。例如系统指令需持久保留，而草稿板推理内容仅短期有用。
- **核心含义**：将缓存保留策略与提示词语义结构对齐，可实现更高效、更可控的KV缓存管理，支持长期智能体工作负载。

## 2. 方法论
- **核心思想**：MemDecay是一种无需训练的、区域感知的KV缓存淘汰框架。它利用编排器提供的区域标签，为每个区域分配基础优先级和衰减率，并结合注意力重要性计算综合保留分数；在固定缓存预算下，淘汰得分最低的页面，同时允许固定关键区域（如系统指令）。
- **关键技术细节**：
  - **区域标签**：假设编排器输出时附带区域标签（system, plan, user, tool_in, tool_out, retrieval, scratchpad）。标签对应连续提示词跨度。
  - **保留分数**：每个非固定词元 i 在时间 t 的保留分数为：  
    \( s_i(t) = b_{r(i)} \exp(-\lambda_{r(i)} \Delta t_i(t)) + \alpha a_i(t) \)  
    - \( b_r \)：区域 r 的基础优先级（初始值）  
    - \( \lambda_r \)：区域特定的衰减率（控制结构保护衰减速度）  
    - \( \Delta t_i(t) \)：自上次插入或注意力刷新以来的解码步骤数（若注意力超过阈值 τ 则重置）  
    - \( a_i(t) \)：注意力重要性的指数加权移动平均（EWMA），通过每隔 k 步采样注意力计算  
    - α：注意力权重
  - **固定区域**：系统区域永远不被淘汰，确保注意力汇点等稳定解码。
  - **页面级淘汰**：生产系统使用固定大小页面，页面得分为其成员词元分数均值。当缓存超出预算时，非固定页面按升序排序，依次淘汰最低分页面。
  - **衰减率校准**：通过测量区域条件注意力寿命（半衰期）来拟合衰减率，使用加权最小二乘法拟合 log(平均注意力质量) vs 年龄，\( \hat{\lambda}_r \) 作为衰减率。
- **算法流程**（简化）：
  1. 在观察步更新所有缓存词元的注意力 EWMA \( a_i \)
  2. 使用阈值 τ 更新刷新时钟 \( t_i^{ref} \)
  3. 计算非固定词元的保留分数
  4. 计算页面分数
  5. 若缓存大小超过预算，使用最小堆淘汰最低分页面，直至满足预算。

## 6. 主要结论与发现
- **区域生命周期层次稳定**：在所有设置中，区域注意力半衰期相差一个数量级：系统148-189步，草稿板14-16步；检索是移动区域中最长寿的（半衰期48-76步），推翻默认快速衰减假设。
- **固定策略确保系统指令完整保留**：MemDecay在所有设置中都能以全缓存准确率保留系统区域事实（短档24/24，长档21/24），而基线最多保留13/24（Streaming在长档为0/24）。
- **基于最近性的保留随上下文增长崩溃**：Streaming在短档有竞争力，但在长档召回率接近0（0.01-0.13），而MemDecay因其结构先验仍能工作。
- **累积注意力保留在未固定内容上更强**：H2O-style在长档、较大模型上主导未固定内容召回（如3B下50%预算非系统60% vs MemDecay 22%）。
- **MemDecay在未固定内容上的损失机制**：最古老的未固定事实（如第一个用户轮次）因衰减先验被优先淘汰，而注意力项因页面均值稀释和EWMA衰减（ρ=0.9）而无法补偿。消融表明任何测试的注意力权重均无法恢复该损失，指出需要注意力项幅度归一化。

## 7. 优点
- **结构先验的有效性**：明确利用智能体提示的语义结构，使策略可解释且无需训练。实验证明系统固定和区域感知衰减在长上下文中保持有效。
- **无需额外训练**：仅需轻量校准，不修改模型权重。

- **测量协议贡献**：提供了从智能体轨迹估计注意力寿命并校准衰减率的明确步骤。
- **丰富的消融**：通过注意力量级分析揭示了当前公式的根本限制，为后续改进指明方向。

## 8. 不足与局限
- **不可逆性**：基础策略无法恢复已淘汰的词元，当后续上下文使其重新相关时失效（如用户轮次事实被先淘汰后被探测）。论文提出分级扩展可缓解。
- **跨区域信息流**：智能体可能在草稿板中引用工具输出，但两者均快速衰减，导致信息丢失。未提供链接副本的机制。
- **标签依赖性**：假设编排器提供区域标签，当前服务端元数据通道尚在开发中；若需分类器则噪声鲁棒性未测量。
- **粒度粗**：页面内词元混合区域时，页面均值可能掩盖高价值词元（跨边界页面短档35%，长档17%）。区域对齐页面边界可改善，但未实现。
- **工作负载依赖**：区域寿命是工作负载相关的（与[10]和[26]存在矛盾），需要代表性校准数据。
- **规模验证有限**：仅测试1.5B和3B模型、最多1700 tokens，未在更大模型（8B+）或真实长上下文（4k+）上验证；只有8个合成场景，统计力有限；系统、计划、草稿板位置固定，导致这些区域的寿命估计存在位置混淆。
- **注意力采样开销**：当前k=1（每步采样），导致解码变慢（69.8ms vs 26.0ms未评分）。生产部署需增大采样间隔。
