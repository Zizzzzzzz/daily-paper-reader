## 摘要
键值（KV）缓存是长上下文大语言模型（LLM）推理中的主要内存瓶颈。两种主流无训练方法在结构上均存在局限性：令牌选择方法（SnapKV、Ada-KV）从观察窗口评估重要性并驱逐低分令牌，但驱逐是不可逆的——当重要性信号在查询无关复用下退化时，准确率下降11-15个百分点；均匀低秩编码保留每个令牌但在所有位置分配相同秩，浪费预算。我们观察到两种失败有一个共同解决方案：秩应被分配而非驱逐。我们提出VarRate，一种无训练KV编解码器，根据每个令牌的查询显著性为其分配可变的低秩预算，保持每个令牌具有非零秩。类似的自适应秩编解码器仅通过训练实现此分配；VarRate无需训练。由于不丢弃任何令牌，在查询感知选择失效的场景下，其准确率仅下降3.5-5.5个百分点。在LongBench（16个任务）上匹配20%预算时，VarRate在Llama-3.1-8B和Qwen2.5-7B上均保持在未压缩模型的0.8个百分点内。平均而言，它是匹配内存下最强的压缩器。在两个模型上均显著优于其均匀秩的消融版本。针对专为查询无关复用设计的KVzip方法，VarRate在四种设置中的三种上准确率相当，总体相差在1个百分点内，而预填充开销仅为KVzip的约八分之一。

## Abstract
The key-value (KV) cache is the main memory bottleneck in long-context large language model (LLM) inference. Two leading training-free families are both structurally limited: token-selection methods (SnapKV, Ada-KV) score importance from an observation window and evict low-scoring tokens, but eviction is irreversible -- so when the importance signal degrades under query-agnostic reuse, accuracy collapses by 11-15 points; uniform low-rank coding keeps every token but spends equal rank everywhere, wasting budget. We observe that both failures share one cure: rank should be allocated, not evicted. We present VarRate, a training-free KV codec that assigns each token a variable low-rank budget by its query salience, keeping every token at a nonzero rank. Comparable adaptive-rank codecs reach this allocation only through training; VarRate requires none. Because no token is dropped, it degrades by only 3.5-5.5 points where query-aware selection collapses. At a matched 20% budget on LongBench (16 tasks), VarRate stays within 0.8 points of the uncompressed model on both Llama-3.1-8B and Qwen2.5-7B. Averaged over the two, it is the strongest matched-memory compressor. It significantly beats its uniform-rank ablation on both models. Against KVzip, a method purpose-built for query-agnostic reuse, it is accuracy-equivalent in three of four settings and within a point overall, at about one-eighth the prefill overhead.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：长上下文大语言模型（LLM）推理中，KV缓存是主要内存瓶颈。上下文越长，KV缓存对GPU内存的消耗越大。
- **现有无训练方法的缺陷**：
  - **令牌选择法**（如SnapKV、PyramidKV、Ada-KV）：从观察窗口计算重要性得分，然后驱逐低分令牌。重要信号本质上是当前查询的注意力，当缓存被复用（查询无关复用）时，信号过时，且驱逐是不可逆的，导致正确率下降11-15个百分点。
  - **均匀低秩编码**（如Palu、均匀秩消融）：每个令牌保留但分配相同秩，浪费预算在琐碎令牌上，而关键令牌不够。
- **本文动机**：秩应该被**分配**而非驱逐。两种失败同源：对重要信号的反应应该是“粗化”而非“删除”。
- **VarRate**：第一个无需训练的可变速率低秩KV编解码器：根据每个令牌的查询显著性分配可变低秩预算，保持所有令牌非零秩，不丢弃任何令牌。达到同类自适应秩编解码器（需训练）的分配效果。

## 2. 论文提出的方法论

### 核心思想
- 保留每个令牌，但根据其查询显著性（SnapKV注意力得分）通过注水法分配不同的低秩预算（r_min < r_t ≤ R），使得总存储匹配给定预算κ。
- 所有令牌共享一个离线训练的PCA低秩基（残差空间），无需微调。

### 关键技术细节
1. **预处理**：
   - 将post-RoPE的key逆旋转为pre-RoPE，并与value拼接成单一向量z_t ∈ ℝ^D，D = 2Gd_h（G为KV头数，d_h为头维度）。
   - 一个共享基服务所有头。

2. **残差编码**：
   - 保留一些“锚点”令牌（等间距步长Δ）和最近的w个令牌为精确存储（集合E）。
   - 其他令牌（集合C）计算残差 e_t = z_t - 平均锚点值（最近c个锚点的均值）。

3. **共享基（离线训练，无需标签）**：
   - 从少量（6个）未标注的LongBench上下文收集残差，进行SVD得到顶R个右奇异向量V ∈ ℝ^{R×D}。
   - 每个层独立校准。存储为每层一个R×D矩阵（半精度下约134MB，不记入每个序列的缓存预算）。

4. **显著性引导的可变秩分配（注水法）**：
   - 使用SnapKV的注意力得分（观察窗口w_obs）计算每个编码令牌的显著性s_t，经min-max归一化到[0,1]。
   - 分配秩：r_t = clip(r_min + λ·ŝ_t, r_min, R)，其中λ通过注水法迭代调整，使得∑ r_t = B（B = D(κL - n_ref)）。
   - 属性：总存储与均匀秩编解码器相同（内存匹配）；所有令牌至少保留r_min，没有令牌被丢弃。

5. **重建**：
   - 投影系数 c_t = V e_t，然后截断到前r_t个系数（嵌套掩码）。
   - 重建：ẑ_t = 锚点均值 + V^T (mask ⊙ c_t)。
   - 最后将key重新旋转回post-RoPE。

### 复杂度
- 投影通算全秩R一次，然后掩码，无额外算术。
- 在预填充阶段一次性执行，无需重新编码整个上下文。

- **解码速度未加速**：由于重建全尺寸缓存，解码吞吐与未压缩相同；实际加速需融合内核。
- **仅评估7B级模型**：未在更大模型（70B）或不同架构（如Mamba）上验证。
- **极端低预算退化**：在keep-8%时，VarRate在Qwen上崩溃至均匀秩水平，选择方法仍可行。
- **对分布式信息的保留不如量化**：在摘要任务（如GovReport）上，量化（KIVI）优于低秩编码，因为量化保留所有秩但降低精度；VarRate可通过系数量化补偿。
- **与KVzip比较**：虽然大部分细胞统计等价，但在Qwen查询无关复用下显著落后（-5.06点），且整体平均KVzip略好（4细胞均值 -1.18点显著）。VarRate的成本优势显著，但精度上限不如KVzip。
- **查询感知场景优势有限**：在Llama上VarRate并不显著优于选择方法（SnapKV/PyramidKV），仅在Qwen上显著。优势主要来自查询无关复用和均匀秩消融对比。
- **校准依赖性极小**：但校准使用LongBench任务上下文，可能对与LongBench分布差异大的场景需确认。
- **硬件依赖**：长上下文（128K）需要双GPU才能运行未优化重建，未评估融合内核后的端到端延迟。
