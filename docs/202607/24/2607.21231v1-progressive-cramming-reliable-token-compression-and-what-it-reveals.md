## 摘要
Token压缩将序列压缩为学习到的嵌入，并实现近乎完美的重构，但固定的token预算和99%的准确率阈值使得残差误差是反映优化失败还是根本限制尚不清楚。我们引入了渐进式压缩，它逐个增加目标前缀token，仅在固定优化预算内无法再实现重构时停止。渐进轨迹占据嵌入空间中的低维结构。在多项选择基准测试中，即使上下文中包含原始前缀，前置一个压缩嵌入也会导致准确率适度但持续下降，并在生成式评估下几乎完全丧失能力。因果注意力消融干预将这种退化追溯到嵌入在模型早期层中的交互。这些结果将渐进式压缩定位为研究压缩限制的工具，并表明通过脆弱的引导（而非可转移语义）实现的重构完美，对于有意义的压缩并不足够。

## Abstract
Token cramming compresses sequences into learned embeddings with near-perfect reconstruction, but fixed token budgets and 99\% accuracy thresholds leave it unclear whether residual errors reflect optimization failures or fundamental limits. We introduce progressive cramming, which grows the target prefix token-by-token, stopping only when reconstruction is no longer achievable within a fixed optimization budget. Progressive trajectories occupy low-dimensional structure in embedding space. Prepending a crammed embedding causes a moderate but consistent accuracy drop on multiple-choice benchmarks even with the original prefix in context, and collapses capability almost entirely under generative evaluation. Causal attention-knockout interventions trace this degradation to the embedding's interactions in the model's early layers. These results position progressive cramming as a tool for studying compression limits and show that perfect reconstruction - achievable through brittle steering rather than transferable semantics - is insufficient for meaningful compression.

## 论文核心问题与整体含义

- **研究背景与动机**：现有“Token 压缩”（Cramming）工作（Kuratov et al., 2025）表明，单个嵌入可近乎完美地重构最多1568个token，激发了关于Transformer表示潜在容量的探讨。然而，这些工作采用**固定token预算**和**99%准确率阈值**，作者指出剩余的约1%误差并非良性——误差集中在序列开头，导致自回归生成时级联崩溃。核心问题在于：**完美重构到底反映了模型对信息的密集语义编码，还是仅仅利用了Transformer计算中某种脆弱的引导机制？** 理解这一机制对于揭示Transformer如何利用嵌入空间中的信息至关重要。

- **整体含义**：本文揭示了“完美重构”与“语义可转移性”之间的**根本脱节**。优化得到的压缩嵌入可以实现近乎完美的token重构，但它可能通过**注意力捕获（attention sink）**等脆弱方式劫持模型的计算，而非学习到可迁移的语义表示。这意味着仅凭重构准确率不足以评价压缩的“意义”，需要引入下游能力评估。

## 方法论

- **核心思想**：提出**渐进式压缩（Progressive Cramming）**，目标不是一次性压缩固定长度，而是**逐个token地增长目标前缀**，每一步都从上一阶段的热启动嵌入开始优化，仅在当前优化预算内无法达到**100%完美重构**时停止。这建立了明确的成功/失败边界，避免了残差误差的模糊性。

- **关键技术细节**：
    1. **渐进式添加**：从重构第一个token开始，每达到完美重构，就添加下一个token并继续优化，直至无法在预算内收敛。
    2. **低维投影（Low-Dimensional Projection）**：将嵌入约束在一个仿射子空间中（`e = Wz + b`，`z∈Rᵏ`，k≪d），使得优化在低维坐标下进行，提高稳定性和信息增益。该投影可以是逐样本训练的，也可以是全语料共享的（仅在训练时co-adapt，泛化能力差）。
    3. **激活对齐正则化（Activation Alignment）**：可选地添加余弦距离正则项，将压缩嵌入下的隐藏状态拉向无压缩状态，以稳定优化，但对不同模型族效果不同。
    4. **信息增益（Information Gain）**：作为压缩容量的主要度量，定义为压缩前后序列总交叉熵的减少（比特数）。

- **算法流程**（文字说明）：
    - 对于目标序列`x = (x₁, ..., xₙ)`，初始化长度为1的前缀；
    - 优化嵌入`e^(1)`直到完美重构；
    - 扩展到长度`k`，设置`e^(k) ← e^(k-1)`作为热启动，继续优化；
    - 重复直到优化预算耗尽，记录最大完美重构前缀长度。

## 主要结论与发现

1. **渐进轨迹是低维的**：单个样本的优化轨迹在30-100个PCA分量内解释99%方差（嵌入维度2048-4096），但这一低维性是**路径属性**而非解集属性——从相同初始点出发、不同学习率达到的等价解相互远离且方向近似正交。
2. **完美重构不保证下游能力**：将压缩嵌入前置到原始前缀之上，在HellaSwag/ARC上导致**持续但适度**的准确率下降；在生成式评估（5-shot MMLU）中准确率**几乎塌缩为0**，而随机嵌入不影响能力——说明退化是压缩嵌入**主动破坏**模型正常计算所致。
3. **因果定位到早期层**：注意力消融实验揭示，**早期层（而非高注意力集中的后期层）**是下游能力退化的因果原因。后期层虽然吸收大量注意力质量，但消融后对下游无影响，说明注意力集中是**症状而非原因**。
4. **压缩容量受重构器深度和宽度单调约束**：截断预训练模型的前N层并finetune修复后，压缩容量随N和模型宽度单调增长，两者部分可替代——宽度更大的浅层模型可超越深度更大的窄模型。
5. **自回归解码的脆弱性源自数值不匹配**：100%教师强制验证（FlashAttention）与贪婪解码（不同序列长度引起attention tiling顺序变化）之间的数值舍入差异，导致部分token的argmax翻转。使用一致的kernel或引入logit margin可解决。

## 优点

- **方法论创新**：渐进式压缩提供了精确的压缩能力标尺，避免了固定预算下“残差-能力”混淆。
- **因果分析深入**：通过注意力消融直接在模型内部干预，而非仅依赖相关性分析，揭示了注意力集中只是表象。
- **系统消融全面**：对温度、步长、投影维度、激活对齐、前缀长度、模型深度/宽度等进行了详尽的参数扫描，结论可信。
- **跨模型验证**：在Pythia、Llama、SmolLM、Gemma、Qwen等多个族系中重复关键实验，提升了泛化性。
- **实用洞察**：指明了“完美重构”不等于“有用压缩”，对未来的上下文压缩和逆向推理研究有重要警示意义。

## 不足与局限

1. **计算成本高**：渐进式压缩比全压缩约慢2倍（每个样本需多个优化阶段），且**无法批处理**（不同样本达到完美重构的速度不同），限制了大规模应用。
