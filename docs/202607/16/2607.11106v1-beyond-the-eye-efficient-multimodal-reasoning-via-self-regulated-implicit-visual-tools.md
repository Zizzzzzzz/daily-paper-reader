## 摘要
最近的多模态大语言模型（MLLMs）在“用图像思考”（TwI）范式下，通过迭代执行各种视觉工具操作，在细粒度感知任务上取得了显著进展。然而，这种范式严重依赖频繁的外部工具调用和重复的图像重新编码，导致大量计算开销和推理延迟。为解决这些问题，我们提出超越眼睛（BEE），一种以自我调节能力为中心的新型隐式视觉工具范式。BEE直接将视觉工具调用行为纳入训练目标，并鼓励模型发展自我调节的调用机制。这种设计使模型能够自适应地平衡内部知识和隐式工具，避免冗余工具使用，同时大幅降低推理延迟。具体而言，BEE涉及两阶段训练过程：（1）形式化思维链（CoT）监督微调（SFT）。我们构建具有结构化工具槽和混合调用状态的CoT轨迹。此阶段激活模型的隐式工具表示和自适应切换能力。（2）自我调节的奖励驱动对齐。为解决由模糊认知边界导致的冗余工具使用问题，我们首先引入净工具增益（NTG）指标来量化这一现象。基于这一观察，我们进一步提出自我调节的奖励机制。该机制惩罚无效的工具依赖，并鼓励模型进行知识路由，确保仅在模型内部知识不足时才调用隐式工具。BEE在细粒度视觉感知方面取得了最先进的性能，同时在一般推理任务中保持竞争力，并在推理效率上获得了显著提升。

## Abstract
Recent multimodal large language models (MLLMs) have made remarkable progress on fine-grained perception tasks under the "Thinking with Images" (TwI) paradigm by iteratively performing various visual tool operations. However, this paradigm relies heavily on frequent external tool calls and repeated image re-encoding, which leads to substantial computational overhead and inference latency. To address these issues, we propose Beyond the Eye (BEE), a novel implicit visual tool paradigm centered on self-regulated capability. BEE directly incorporates visual tool invocation behaviors into the training objective and encourages the model to develop a self-regulated invocation mechanism. This design enables the model to adaptively balance internal knowledge and implicit tools, avoiding redundant tool usage while substantially reducing inference latency. Specifically, BEE involves a two-stage training process: (1) Formalized Chain-of-Thought (CoT) Supervised Fine-tuning (SFT). We construct CoT trajectories with structured tool slots and mixed invocation states. This stage activates the model's implicit tool representations and adaptive switching capability. (2) Self-regulated Reward-Driven Alignment. To address redundant tool usage caused by ambiguous cognitive boundaries, we first introduce the Net Tool Gain (NTG) metric to quantify this phenomenon. Based on this observation, we further propose a self-regulated reward mechanism. This mechanism penalizes ineffective tool dependency and encourages the model to perform knowledge routing, ensuring that implicit tools are invoked only when the model's internal knowledge is insufficient. BEE achieves state-of-the-art performance in fine-grained visual perception while remaining competitive in general reasoning tasks and achieving substantial gains in inference efficiency.

- **本文目标**：提出 **BEE（Beyond the Eye）**，一种**自我调节的隐式视觉工具（Implicit Visual Tool, IvT）范式**，将工具调用行为内化到模型训练中，使模型能自适应平衡内部知识和隐式工具，避免冗余调用，显著降低延迟。

## 2. 论文方法论：核心思想、关键技术细节

### 2.1 核心思想
BEE 不依赖外部 API，而是将视觉工具操作（如放大、裁剪）编码为离散语义标记（Tool Pad），在推理过程中由模型自回归生成。模型通过一个路由变量 \( g \in \{0,1\} \) 决定是否激活隐式工具，从而在单次前向推理中完成工具增强推理。

### 2.2 两阶段训练框架

#### 阶段一：形式化的 CoT 监督微调（Formalized CoT SFT）
- **目标**：激活模型的隐式工具表示、自适应切换能力和基本推理能力。
- **数据构建**：从 Refocus、Thyme、minio-o3、Visual-CoT 等来源整合 320K 样本。使用预训练的工具语义分词器（Semantic Tool Tokenizer）将真实工具操作后的图像编码为离散标记（Tool Pad），替换原始代码段。同时混合无工具的轨迹，引导模型学会判断何时需要工具。
- **关键步骤**：构造包含“计划→隐式工具→推理→答案”格式的 CoT 轨迹，并加入工具语义对齐的辅助数据进行训练。

#### 阶段二：自我调节的奖励驱动对齐（Self-regulated Reward-driven Alignment）
- **动机**：仅 SFT 无法建立清晰的认知边界。作者提出 **Net Tool Gain (NTG)** 指标量化工具调用的真实边际收益（\( NTG = (|G|-|L|)/|C_{tool}| \)），发现 SFT 模型存在大量冗余工具调用（NTG 仅 6.2%）。
- **自调节奖励（MC-Reward）**：  
  组合奖励 \( R(oi) = r_{acc} + r_{cons} + r_{frmt} + r_{mc} \)。  
  - \( r_{acc} \)：答案准确率（规则匹配 + 语言模型判断）。  
  - \( r_{cons} \)：推理过程与答案一致性。  
  - \( r_{frmt} \)：格式符合性。  
  - \( r_{mc} \)（核心）：根据模型当前能力指标 \( p \)（组内平均准确率）调节工具使用：若 \( p \geq \tau \)（任务较易），使用工具则会受罚；若 \( p < \tau \)（任务困难），鼓励使用工具。具体函数通过余弦门控平滑实现，确保训练稳定。
- **优化算法**：采用 DAPO 进行策略优化，利用上述奖励信号训练。

### 2.3 算法流程（文字说明）
1. 使用 BEE-SFT-320K 对模型进行 SFT 预训练（激活隐式工具和基本路由）。
2. 对每个 RL 批次，模型生成多个轨迹（包含工具/无工具版本），计算复合奖励。
3. 基于奖励计算优势，通过 DAPO 更新模型参数。
4. 重复直到收敛。

### 3.3 实验设置

- 训练后评估：使用 VLMEvalKit 统一框架，答案审核使用 Qwen3-VL-235B 作为裁判。
- 效率评估：单张 NVIDIA H800 GPU，BF16 精度，batch size=1，VLLM 推理（Thyme 除外使用原始 PyTorch）。

## 4. 资源与算力

- **硬件**：单节点（1 Node），NVIDIA H800 GPU（共 8 张，根据超参数配置 SFT 时使用全参数训练，启用 Zero3；RL 时 8 张 GPU，8 rollout per prompt）。
- **训练时间**：
  - SFT 阶段：BEE-7B 约 **4 小时**（320K 数据）。
  - RL 阶段：BEE-7B 约 **49 小时**（55K 数据）。
  - 对比：Thyme 需要 25h SFT + 150h RL，DeepEyesV2 需要 28h SFT + 54h RL，BEE 在计算资源上更高效。
- **推理延迟**：BEE-7B 相比 DeepEyes 实现高达 **86.2% 加速**（8K 分辨率下）。

## 5. 实验数量与充分性

- **全面性**：涵盖 8 个以上基准，包括感知、推理、通用能力、幻觉检测等多维度评估。
- **消融实验**：
  - 隐式工具形式（原始图像、<unk> 标记、纯文本 → 验证工具槽重要性）。
  - 隐式标记长度（4/8/16/36/64 标记，性能稳定）。
  - MC-Reward 对比（BEE-Static vs BEE-MC，NTG 从 6.2% 提升至 66.0%）。
  - 阈值 τ 消融（1/3, 1/2, 2/3, 3/4，最优在 2/3 附近）。
  - Tokenizer 及解耦感知/推理的实验。
- **系统级对比**：内存、吞吐量、延迟、成本（$0.72 / 1K samples，远低于 DeepEyes）。
- **训练动态分析**：工具调用率随训练演变、难度分布变化、奖励曲线。
- **结论**：实验设计客观、公平，消融充分，证据充分支撑声称。

## 6. 主要结论与发现

- **性能领先**：BEE-8B 在感知任务平均准确率 75.3，超过 Qwen3-VL-235B（74.1）和 Kimi-K2.6（71.2），且优于显式工具方法（如 Thyme、DeepEyes）。
- **效率大幅提升**：在 8K 分辨率下推理速度提升 86.2%，成本显著降低。
- **自我调节有效**：MC-Reward 使工具调用更精准，NTG 从 6.2% 升至 66.0%，冗余调用大幅减少。
- **泛化能力**：在未训练的 OOD 任务（如逻辑推理、自动驾驶、医疗）上仍能超越基线，表明隐式工具内化提升通用推理。
- **可部署性**：BEE 可像标准 VLM 一样部署，无需外部沙箱，内存占用低，适合实际应用。

## 7. 优点

- **创新范式**：首次将视觉工具完全内化为隐式表示，消除外部 I/O，实现端到端优化。
- **自调节机制**：通过 MC-Reward 让模型动态评估自身能力边界，按需启用工具，避免浪费。
- **高效训练与推理**：相比现有显式工具方法，训练时间缩短 50% 以上，推理延迟降低一个数量级。
- **数据构建细致**：利用多源数据构造形式化 CoT，并加入工具语义对齐辅助训练，提升隐式表征质量。
- **评估全面客观**：涵盖感知、推理、效率、系统级成本，消融实验设计严密。

## 8. 不足与局限

- **复杂逻辑推理能力有限**：在需要多步严格推理的任务（如 VisuLogic）中表现较弱，常缺少详细步骤。原因可能是训练数据缺乏此类复杂推理样本。
- **多目标场景遗漏**：在包含大量相似物体的图像（如自动驾驶多车辆场景）中，模型可能漏检部分目标。源于缺少密集多目标感知的训练数据。
- **对已有强性能任务提升有限**：在基线已高分（如 OCR、图表）任务上，BEE 收益甚微甚至略有下降，说明隐式工具主要对弱感知任务有效。
- **依赖裁判模型**：答案审核和一致性奖励依赖 Qwen3-VL-235B，引入额外开销，且裁判模型自身存在偏差风险。
- **未探索更大规模模型**：实验仅在 4B、7B、8B 上验证，扩展到更大参数规模的效果未知。
- **工具操作种类有限**：仅支持六类基本操作（缩放、裁剪、旋转等），未涵盖更复杂工具（如目标检测 API）。
