## 摘要
基于因果视觉-语言模型的端到端视觉-语言导航（VLN）能够直接将指令和以自我为中心的观测映射到动作，但标准的行为克隆仅监督下一个动作，并未明确训练策略状态以预测未来的视觉结果。我们首先提出一个诊断性问题：如果在训练和测试时，策略被赋予专家轨迹的未来图像作为特权输入，那么这种额外的视觉证据是否有助于选择当前动作？（专家轨迹的未来图像在实际部署的测试阶段不可用，因此我们仅将此设置用作特权输入诊断。）答案是肯定的；这一合理性检验表明，未来观测可以提供丰富且可行的线索。接着我们提出一个可部署的问题：在推理时不访问未来图像的情况下，我们是否仍然可以通过仅将压缩的未来视觉潜在变量用作训练监督来受益于未来信息？我们提出了未来状态条件VLN（FSC-VLN），该方法添加了一个未来查询标记，并通过一个仅在训练时使用的目标分支（训练后移除），将其隐藏状态与冻结的视觉嵌入对齐至未来$Δ$步。在R2R val-unseen上，FSC-VLN在两种训练数据设置下均比StreamVLN风格基线提高了SR/OSR/SPL，尤其在长视野任务中提升更大；消融实验进一步支持了双查询设计（分离未来查询和动作查询）。

## Abstract
End-to-end vision-language navigation (VLN) with causal vision-language models can map instructions and egocentric observations directly to actions, but standard behavior cloning supervises only the next action and does not explicitly train the policy state to be predictive of future visual outcomes. We first ask a diagnostic question: if the policy is given an expert-trajectory future image as privileged input at training and testing time, is that additional visual evidence useful for choosing the current action? (These expert-trajectory future images are unavailable at test time in real deployment, so we use this setting only as a privileged-input diagnostic.) The answer is yes; this sanity check shows that future observations can provide rich, actionable cues.   We then ask a deployable question: without accessing future images at inference, can we still benefit from future information by using a compressed future visual latent only as training supervision? We propose Future-State-Conditioned VLN (FSC-VLN), which adds a future-query token and aligns its hidden state to a frozen visual embedding $Δ$ steps ahead via a training-only target branch that is removed after training. On R2R val-unseen, FSC-VLN improves SR/OSR/SPL over a StreamVLN-style baseline under two training-data regimes, with larger gains on long-horizon episodes; ablations further support the dual-query design (separating future and action queries).

### 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：在因果视觉-语言模型（VLM）序列中插入两个可学习的查询token（未来查询 qF、动作查询 qA），训练时通过辅助分支将 qF 的隐藏状态与未来 Δ 步观测的冻结视觉嵌入对齐，使得动作生成能隐式利用未来信息；推理时移除辅助分支，仅保留两个查询token。
- **关键技术细节**：
  1. **模型架构**：基于 Qwen2-7B 的因果Transformer，视觉编码器为冻结的 SigLIP（SigLIP-SO400M），输出经 MLP 投影后得到视觉 token。
  2. **未来查询与动作查询**：在上下文序列末尾依次插入 qF、qA（均为可学习参数），随后是动作 token。因果注意力下，qF 可以关注上下文，qA 可以关注 qF 及之前序列。
  3. **未来目标构造**：在训练时，取专家轨迹中当前步之后 Δ=32 步的观测 ot+Δ，经冻结的 SigLIP 和平均池化得到 pooled 嵌入，再通过投影层 g(·) 映射到低维空间，作为 stop-gradient 目标。
  4. **对齐损失**：对 qF 的隐藏状态也经投影层 g(·)，计算两者之间的 L1 损失：Lfuture = ||g(ĥt+Δ) - g(z∗t+Δ)||1。
  5. **总损失**：Ltotal = LLM + λF Lfuture，其中 λF = 0.1。LLM 为标准下一个 token 预测的交叉熵损失。
  6. **训练细节**：冻结 SigLIP 和视觉投影器，仅更新 Qwen2、LM head、qF、qA；随机外观增强仅应用于在线上下文图像，目标图像使用标准预处理。
  7. **推理**：移除目标分支，输入序列仍包含 qF 和 qA，进行单次因果预填充，然后自回归解码动作 token。无需额外前向传播或未来图像生成。
- **算法流程（文字说明）**：
  - 输入：指令 I、当前观测 ot、历史观测 Ht、训练时额外有未来观测 ot+Δ。
  - 编码：冻结 SigLIP 将观测转换为视觉 token。
  - 构造因果序列：Ct（指令+视觉 token）→ qF → qA → 动作 token。
  - 前向：Qwen2 处理完整序列，得到隐藏状态 hF、hA。
  - 损失计算：LLM（动作预测） + Lfuture（对齐）。
  - 反向传播更新参数（除冻结部分）。
  - 推理：仅使用在线上下文 + qF + qA，解码动作。

### 论文的主要结论与发现

1. **特权输入诊断证实未来图像充满信息**：在训练和测试时加入未来图像，SR 从 29.96% 提升至 71.77%（表1），说明未来观测对当前决策有极大帮助。
2. **FSC-VLN 在不增加推理成本下提升性能**：在两种数据设置下，SR/OSR/SPL 均有提升（例如 R2R+RxR 下 SR +1.47%）。
3. **长视野任务获益更大**：分层分析显示，长视野（>10m）下 SR 提升 +2.93~+3.85%，而短视野提升微小。
4. **双查询设计优于单查询**：移除动作查询 qA 后，长视野 SR/SPL 下降，说明分离未来预测与动作生成是有效的。
