## 摘要
开放环境桌面机器人操作要求系统具备语义理解、精确几何位姿估计和高频动作生成能力。尽管端到端视觉-语言-动作（VLA）模型在语义泛化方面表现出色，但它们往往缺乏针对细粒度任务的显式几何约束，且训练成本高昂。为弥合高层语义与底层物理执行之间的鸿沟，我们提出OpenSPM，一种开放环境空间持久记忆框架，由空间位姿记忆和流匹配动作生成模型组成。OpenSPM首先利用语义条件三维感知和卡尔曼滤波来跟踪连续六维位姿，然后从人类示范中提取关键空间位姿，并将其存储为可迁移的、以对象为中心的空间持久记忆条目。推理时，OpenSPM根据自然语言指令检索相关记忆条目，通过SE(3)变换将空间位姿迁移至新场景，并利用轻量级条件流匹配模型生成高频动作块。结合实时本体感觉状态反馈与终端残差校正，该系统有效抑制了轨迹误差累积。在十个LIBERO-GOAL任务上的评估显示，OpenSPM实现了85.6%的成功率和等效控制频率1033.3 Hz，同时仅需极少的推理AI算力。广泛的消融实验表明，结构化空间持久记忆与闭环残差校正在实现可靠的高频机器人操作中起着关键作用。

## Abstract
Open-environment tabletop robotic manipulation requires systems to possess semantic understanding, precise geometric pose estimation, and high-frequency action generation. While end-to-end vision-language-action (VLA) models excel at semantic generalization, they often lack explicit geometric constraints for fine-grained tasks and require costly training. To bridge the gap between high-level semantics and low-level physical execution, we propose OpenSPM, an open environment spatial persistent memory framework consisting of spatial pose memory and flow-matching action generation model. OpenSPM first leverages semantically conditioned 3D perception and Kalman filtering to track continuous 6D poses. It then extracts key spatial poses from human demonstrations, keeping them as transferable, object-centric spatial persistent memory entries. During inference, OpenSPM retrieves relevant memory entries in terms of natural language instructions, transfers the spatial poses to new scenes using SE(3) transformations, and generates high-frequency action chunks via a lightweight conditional flow-matching model. Combined with real-time proprioceptive state feedback and terminal residual correction, the system effectively suppresses trajectory error accumulation. Evaluated on ten LIBERO-GOAL tasks, OpenSPM achieves an 85.6% success rate and an equivalent control frequency of 1033.3 Hz, while requiring minimal inference AI computing power. Extensive ablations illustrate that structured spatial persistent memory and closed-loop residual correction play a crucial role in reliable, high-frequency robotic manipulation.

- 缺乏显式的几何约束，难以处理精细的接触式操作（如抓取、放置、旋转等需要精确对齐的阶段）。

本文旨在桥接高层语义推理与低层物理执行之间的鸿沟，提出一种分解式思路：用高层模型进行语义解析和经验检索，用轻量级低层模型生成受几何约束的局部动作。核心假设是：**关键空间位姿（Key Spatial Pose）** 可以作为中间表示，从演示中提取并跨环境迁移，从而兼顾语义泛化和几何精确性。

## 2. 方法论：核心思想、关键技术细节、算法流程

**核心思想：**  
OpenSPM 构建一个“空间持久记忆”框架，包含两部分：一个**关键空间位姿记忆库**（存储以对象为中心的相对位姿），以及一个**闭环流匹配动作生成模型**（用于在相邻关键位姿之间生成高频动作序列）。关键位姿通过 SE(3) 变换跨场景迁移，保持局部交互几何不变。

**关键技术细节：**

1. **语义条件3D感知与卡尔曼状态估计**：  
   - 利用多视图2D语义分割（基于SAM等模型）+ 3D重建（SAM 3D）得到目标物体的6D位姿。  
   - 将位姿估计视为带噪声的状态空间问题，采用卡尔曼滤波预测和更新连续状态（包括平移、线速度、局部方向误差、角速度）。  
   - 输出经过轻量级平滑处理，获得尺度一致、方向清晰的几何基础。

2. **关键空间位姿记忆库构建**：  
   - 从人类演示中提取关键位姿（基于夹爪状态变化、末端执行器速度/方向变化、以及Qwen3-VL多模态模型的语义判断）。  
   - 每个记忆条目包含：检索键（操作类型、目标物体等）、语言描述、多个关键位姿的**相对位姿**（末端执行器相对于锚定物体的SE(3)）、阶段标签、置信度等。  
   - 相对位姿定义：`ΔT_o→e = (wTo)^{-1} * wTe`，这使得记忆可迁移（定理1证明：若目标物体位姿经历任意刚体变换，则转换后的相对位姿保持不变）。

3. **在线检索与位姿迁移**：  
   - 从语言指令中解析结构化任务元素，通过语义匹配、几何一致性、历史成功率加权选择最佳记忆条目。  
   - 测试场景中，根据新估计的目标物体位姿 `wT'_o` 计算迁移后的世界坐标关键位姿：`wT'_e,j = wT'_o * ΔT_o→e_j`。  
   - 迁移后进行可达性、位姿跳变、最小距离检查。

4. **条件流匹配动作生成**：  
   - 针对相邻关键位姿之间的动作块，训练一个轻量级条件流匹配模型（约24万参数）。  
   - 条件向量包含当前实际夹爪位姿、目标关键位姿、相对位姿误差、片段进度。  
   - 训练时利用线性插值路径学习速度场，损失为MSE。推理时通过ODE积分从噪声生成动作块（长度H=5）。  
   - 模型架构采用条件编码器+共享步态解码器，避免重复编码。

5. **闭环执行与终端残差校正**：  
   - **段间闭环**：每个动作块开始时，使用实时夹爪位姿作为条件，而非规划的理想起始点。  
   - **终端残差校正**：在接近抓取和放置关键节点时，若当前位置与目标关键位姿的残差超过阈值，则重新生成校正动作块，直到误差收敛或达最大迭代次数。

**算法流程（文字说明）：**  
- 离线阶段：从演示中提取关键位姿并存储为记忆条目（相对位姿+标签）。  
- 在线阶段：感知模块估计当前物体位姿 → 解析语言指令 → 检索最佳记忆 → 迁移关键位姿到新场景 → 流匹配模型生成动作块（5步） → 闭环执行（实时状态反馈） → 必要时执行终端残差校正 → 完成操作。
