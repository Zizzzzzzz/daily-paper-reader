## 摘要
视觉标记剪枝通过仅保留视觉标记的子集来减少多模态大语言模型（MLLMs）的推理开销。现有方法通常基于重要性或冗余度来选择标记。然而，我们观察到这些标准在不同输入间会产生稳定的空间偏差，且并不总优于简单的均匀网格采样，这凸显了广泛空间覆盖的价值。受此启发，我们提出了S$^2$Prune，一种无需训练的剪枝方法，它在保持空间覆盖的同时，使标记密度适应局部图像结构。我们首先将图像划分为多个区域，并为每个区域分配至少一个标记以保持覆盖。然后根据拉普拉斯变化分配剩余的标记预算，为结构更丰富的区域分配更多标记。接着，我们利用从第一个解码器块计算得到的早期表示变化（ERC）来选择每个区域内的代表性标记。我们在多种设置和两种MLLM架构上评估了S$^2$Prune。在Qwen2.5-VL-7B-Instruct上，它在所评估的免训练剪枝方法中取得了最高的平均准确率。仅使用原始576个视觉标记中的32个时，它仍保留了全模型性能的79.3%。代码可在https://github.com/yuanyuanjia71-spec/S2Prune获取。

## Abstract
Visual token pruning reduces the inference overhead of multimodal large language models (MLLMs) by retaining only a subset of visual tokens. Existing methods usually select tokens based on importance or redundancy. However, we observe that these criteria produce stable spatial biases across inputs and do not always outperform simple Uniform Grid sampling, highlighting the value of broad spatial coverage. Motivated by this, we propose S$^2$Prune, a training-free pruning method that preserves spatial coverage while adapting token density to local image structure. We first divide the image into regions and assign at least one token to each region to preserve coverage. The remaining token budget is then distributed according to Laplacian variation, giving more tokens to regions with richer structure. We then use Early Representation Change (ERC), computed from the first decoder block, to select representative tokens within each region. We evaluate S$^2$Prune across diverse settings and two MLLM architectures. On Qwen2.5-VL-7B-Instruct, it achieves the highest average accuracy among the evaluated training-free pruning methods. With only 32 of the original 576 visual tokens, it still retains 79.3% of the full-model performance. Code is available at https://github.com/yuanyuanjia71-spec/S2Prune.

## 1. 论文核心问题与整体含义（研究动机与背景）

- **研究背景**：多模态大语言模型（MLLMs）通常将图像编码为大量视觉 token 后与文本 token 一同送入大语言模型处理。高分辨率输入会产生很长的视觉序列，显著增加 prefill 计算量、KV-cache 占用和推理延迟。视觉 token 剪枝旨在保留少量关键视觉 token，同时尽量维持模型性能。
- **现有方法的误区**：已有剪枝方法主要基于 token 重要性（如注意力分数）或冗余度（如相似度合并）做全局 Top-B 选择。但论文发现这些评分标准会在不同输入上产生**稳定的空间位置偏差**（如图像边界偏好、固定行列偏好），且并不总优于简单的均匀网格采样（Uniform Grid）。
- **核心观察**：均匀网格采样通过保持宽泛的空间覆盖带来鲁棒性；但均匀密度忽视了图像的局部结构差异——平滑区域可稀疏表示，而文本、边缘、细纹理等需要更密集的 token。因此，一个好的剪枝策略应在保持空间覆盖的同时，使 token 密度自适应于局部图像结构。
- **整体含义**：论文将视觉 token 剪枝类比为图像编码中的“空间码率分配”问题，提出 S²Prune——一种无需训练、基于空间结构化分配的剪枝框架，验证了“在何处花费 token 预算”与“选择哪些 token”同等重要。

## 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：将 token 剪枝解耦为两级决策：
  1. **空间骨架（Spatial Scaffold）**：决定每个图像区域应分配多少个 token（“在哪花”）。
  2. **局部选择（Local Selection）**：在给定区域预算下，选择哪些 token 作为代表（“选哪些”）。
- **技术细节与公式**：
  - **区域结构复杂度度量**：先将图像转为灰度图，计算四邻域拉普拉斯响应图 \(L\)；每个粗粒度区域 \(R_g\) 的原始结构分数定义为
    \[
    c^{\text{raw}}_g = \mathrm{Var}(L|_{\Omega_g})
    \]
    然后在图像内做 min-max 归一化得到 \(c_g\)。拉普拉斯方差越高，说明区域包含越多边缘、纹理等高频结构。
  - **预算分配**：设区域总数为 \(G\)，每个区域先固定获得 1 个 token（保证覆盖），然后将剩余 \(B - G\) 个 token 按 \(c_g\) 比例分配到各区域，满足 \(1 \le B_g \le |R_g|\) 且 \(\sum_{g=1}^{G} B_g = B\)。若结构分数全为 0，则退化为均匀分配。使用迭代最大余数法处理整数分配与容量上限。
  - **局部单元划分**：每个区域 \(R_g\) 被递归地剖分成 \(B_g\) 个近似等面积的不重叠矩形单元格，保证每个 token 恰好属于一个单元格。
  - **早期表示变化（ERC）**：利用第一个解码器块（Layer 0）的残差更新幅度定义 token 重要性分数：
    \[
    r_i = \| h_i^1 - h_i^0 \|_2
    \]
    在每个单元格内保留 ERC 最大的 token，而不是跨区域做全局比较。这样做可避免重复引入全局评分所伴随的空间偏差。
- **算法流程**（训练无关、无参数）：
  1. 将 24×24 视觉 token 网格划分为 G 个粗区域（如 4×4/5×5/8×8）。
  2. 计算每个区域的拉普拉斯方差并归一化。
  3. 基于区域容量和总预算 B，迭代分配整数区域预算 \(B_g\)。
  4. 每区域递归剖分为 \(B_g\) 个单元格。
  5. 让全部视觉 token 通过解码器 Layer 0，计算每个 token 的 ERC。
  6. 每个单元格保留 ERC 分数最高的 token，共 B 个，并保持原始 token 顺序与 M-RoPE 位置 ID。
  7. 在 Layer 1 之前物理移除未选 token，继续后序推理。

## 6. 主要结论与发现

- 不同 token 评分标准会产生**稳定且各异的空间分配模式**（如 FastV 和 FEATHER no-RoPE 在 B=64 时约 58% 的 token 集中在边界区域），这些模式跨图像和问题保持一致，说明全局评分不仅“选哪些”，更决定“预算花在哪”。
- 简单的**均匀网格采样**在激进剪枝下往往优于复杂评分方法，说明**宽泛空间覆盖**是剪枝鲁棒性的关键因素。
- 但当图像局部结构分布不均衡时，均匀密度会过度表示平滑区域、欠表示细节丰富区域；结构异质性越强，自适应密度带来的增益越大（高异质性组在 B=32 时提升 2.79 个百分点）。
- S²Prune 在 Qwen2.5-VL-7B-Instruct 上：
  - B=128：Acc. 64.0，相对性能 92.1%，为最优；
  - B=64：Acc. 60.6，相对性能 87.0%，为最优；
  - B=32：Acc. 55.9，相对性能 79.3%，比最强基线高 0.9 个百分点，且在 GQA、POPE、MMB_EN 等任务上大幅领先（比最强基线分别高 2.6/3.7/2.2 点），并在 10 个基准中的 6 个上取得最佳。
- 在 LLaVA-OneVision-7B 上同样在所有预算下取得最高平均 Acc. 与 Rel.，说明方法具有跨架构迁移性。
- 效率方面：B=64 时 S²Prune 将 FLOPs 从 8.181T 降至 1.596T（约 5.1× 减少），prefill 延迟从 56.97 ms 降至 28.66 ms（约 2.0× 加速），KV-cache 从 31.50 MB 降至 4.50 MB（约 7.0× 减少）。虽然 GPrune/VisPruner 计算量更低，但 S²Prune 在保持更高准确率的前提下取得更优的权衡。

## 7. 优点

- **问题洞察深刻**：通过大量空间频率图与量化分析，揭示“评分标准决定空间分配”这一常被忽略的维度，并用 Random 与 Uniform Grid 对照实验证明简单覆盖约束的价值。
- **方法设计简洁且训练无关**：拉普拉斯方差与 ERC 均无需任何训练，不引入额外参数，即插即用；两级分配（粗区域预算 + 细粒度局部选择）解耦了“预算位置”与“具体代表”，逻辑清晰。
- **充分验证空间覆盖自适应的必要性**：用“同分配方式 + 不同结构异质性”的分组实验说明均匀密度在高异质性图像上的不足，使动机不只是定性观感，而是有量化支撑。
- **跨架构、多预算、多样本的系统评测**：在 10 个基准上覆盖不同难度与任务类型，跨 3 个预算水平，并在两个模型上验证，结论可靠性较高。
- **空间偏差分析扎实**：不仅展示单一示例，还聚合 1000 个 MMB_EN 样本的频率图，并给出跨预算相关性（Pearson/Spearman 均高），说明空间偏差稳定性是有统计基础的。
- **代码与补充材料完整**：提供了具体算法伪代码、网格敏感性分析、定性可视化等，便于复现。

## 8. 不足与局限

- **模型覆盖范围有限**：仅测试 7B 级别模型（Qwen2.5-VL-7B、LLaVA-OneVision-7B），未在更大规模或不同视觉编码器（如 InternVL、LLaVA-NeXT）上验证；在更大模型上，空间注意力模式与 token 重要性信号的交互可能不同。
- **聚合指标的解释风险**：Acc. 为 10 个基准的平均值，MME 需除以 28 再做平均，这样的归一化可能掩盖个别任务上的显著退化；例如在 TextVQA 等任务上 S²Prune 并不总是第一，个别任务上 FastV 更有优势。
- **边际增益较小**：在 B=128 时平均 Acc. 仅比最强基线高 0.1 点，汇总均值可能让人忽略“在多数任务上优势并不明显”的事实；显著性检验未提供。
- **结构分数仅基于图像底层梯度**：拉普拉斯方差反映的是边缘/纹理等低阶结构，不包含语义信息。对于“语义简单但视觉复杂”或“语义关键但视觉平滑”的区域，该分配可能不够合理。论文虽将区域预算定义为“表示容量”而非“语义相关性”，但这种底层驱动的合理性并非在所有任务中都成立。
- **未报告计算开销细节**：虽然整体免训练且效率表格给出总体 FLOPs/延迟，但拉普拉斯计算、递归区域剖分、ERC 额外的前向层（Layer 0）等操作的单独耗时未列出，应用中的实际加速效果需要进一步量化。
- **测试场景未覆盖生成式/长文本多轮对话**：主实验多为单轮判别/回答类基准，对多图输入、视频输入或长视觉序列下的表现没有讨论。
- **超参数经验化**：粗网格大小（G）需要随预算手动选取（如 32→4×4、64→5×5），论文通过敏感性分析说明影响不大，但仍非自适应确定，缺乏更系统的准则。
- **对比的公平性边界**：所有基线均为免训练方法，但各自原始的 token 预算定义、剪枝层选择存在差异（例如 FastV 从 Layer 2 剪、VisionZip 在视觉层后剪），论文虽尽力统一，但跨方法的“剪枝位置层数”本身可能成为性能差异来源。
