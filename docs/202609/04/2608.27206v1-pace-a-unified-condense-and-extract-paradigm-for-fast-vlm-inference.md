## 摘要
视觉语言模型（VLM）展现出卓越的视觉推理能力，然而随着视觉令牌数量的激增，其推理成本迅速上升。现有的视觉令牌剪枝方法存在两个根本性局限。首先，大多数方法仅在视觉编码器之后运行，导致视觉编码阶段的大量延迟未得到优化。其次，在严格的令牌预算下，这些方法往往无法同时保留整体视觉上下文和细粒度细节，导致性能下降。为解决这些瓶颈，我们提出PACE（像素自适应压缩与提取），一种免训练的推理框架，通过统一的压缩与提取范式同时加速视觉编码器和大语言模型（LLM）。在压缩阶段，自适应像素压缩器（APC）在编码前评估视觉信息密度，自适应地下采样冗余输入，减少编码器计算量，同时保留全局上下文和关键视觉线索。在提取阶段，动态双注意力提取器（DDAE）通过融合来自编码器的内部视觉信号和来自LLM的语义信号，选择性保留视觉令牌，保障任务关键细节。通过将PACE集成到Qwen2.5-VL-7B中，模型在仅使用10%视觉令牌的情况下保留了原始性能的93.8%，同时实现了3.1倍的首令牌时间（TTFT）加速。我们的代码可在 https://github.com/jjL357/PACE 获取。

## Abstract
Vision-Language Models (VLMs) demonstrate exceptional visual reasoning capabilities, yet their inference costs escalate rapidly with the proliferation of visual tokens. Existing visual token pruning methods exhibit two fundamental limitations. First, most approaches operate exclusively post-vision encoder, leaving the substantial latency of the visual encoding phase unoptimized. Second, under strict token budgets, these methods often fail to jointly preserve holistic visual contexts and fine-grained details, leading to performance degradation. To address these bottlenecks, we propose PACE (Pixel-Adaptive Condense and Extract), a training-free inference framework that accelerates both the vision encoder and the Large Language Model (LLM) via a unified Condense-and-Extract paradigm. During the Condense stage, an Adaptive Pixel Compressor (APC) evaluates visual information density prior to encoding, adaptively downsampling redundant inputs, curtailing encoder computation while preserving global context and essential visual cues. In the Extract stage, a Dynamic Dual-Attention Extractor (DDAE) selectively retains visual tokens via a fusion of internal visual signals from the encoder and semantic signals from the LLM, safeguarding task-critical details. By integrating PACE into Qwen2.5-VL-7B, the model retains 93.8% of its original performance while utilizing only 10% of the visual tokens, yielding a 3.1x speedup in time to first token (TTFT). Our code is available at https://github.com/jjL357/PACE.

### 1. 核心问题与整体含义

- 视觉语言模型（VLM）虽然视觉推理能力突出，但高分辨率图像/视频会产生海量视觉令牌，导致 LLM 推理延迟急剧上升。
- 现有视觉令牌剪枝方法主要存在两个关键瓶颈：
  - **编码器端被忽略**：多数方法只在视觉编码器之后对视觉令牌做剪枝，并未减少 ViT 在高分辨率编码阶段本身巨大计算开销；在分辨率升高时，视觉编码与 LLM Prefill 共同成为延迟瓶颈（论文中的延迟分解实验明确显示两者均占很大权重）。
  - **低预算下信息丢失**：在较低视觉令牌保留比例下，已有剪枝方法难以同时保持“全局视觉上下文”和“局部细粒度细节”。尤其是在 ChartQA、DocVQA、OCRBench 等细粒度任务上性能严重崩溃。
- 因此，论文提出了一种 **统一的“Condense-and-Extract”训练无关推理框架** PACE，目标是在视觉编码开始之前压缩像素输入，并在编码后提取信息量最高的视觉令牌，从而同时加速视觉编码器和 LLM。

### 2. 方法论

#### 2.1 整体框架

- PACE 分为两个阶段：
  - **Condense 阶段**（编码前）：由 APPC 自适应地调整图像输入的分辨率，降低视觉编码器需要处理的像素规模。
  - **Extract 阶段**（编码后）：由 DDAE 对视觉令牌做筛选，在进入 LLM 上下文之前保留语义重要且细节信息丰富的令牌。
- 方法免训练，近似“即插即用”，不需要修改模型结构和额外训练阶段。

#### 2.2 Condense 阶段：自适应像素压缩器 (APC)

- 核心思想：不作为打补丁级别的方式扔掉高分辨率图像的子区域，而是用轻量级预分析评估整幅图像的信息密度，并据此对输入图像分辨率做整体缩放，从而同时保留连续 2D 空间布局并降低计算量。
- 算法与关键技术细节：
  - 取 ViT 第 1 个 block 作为浅层特征预览，得到归一化 token 集合 \(T_v\)。
  - 计算所有 token 两两之间的平均余弦相似度 \(\phi\)；定义全局信息密度分数：
    \[
    \rho_g = 1 - \phi
    \]
    这表示图像中非冗余信息的比例。
  - 用所有 token 的均值作为背景基线，计算每个 token 到基线的欧氏距离 \(d_i\)，并选出前 10% 高距离 token，将其均值除以缩放因子 \(\gamma\)，得到局部细节保真分数：
    \[
    \rho_d = \min(\bar{d}_{\mathrm{top}} / \gamma, 1.0)
    \]
    其思想是：若图像含有大量精细结构，局部对比会较高，需要保留更高的像素分辨率。
  - 将两者加权融合为目标像素保留比：
    \[
    \rho = \alpha \rho_g + (1-\alpha)\rho_d
    \]
    默认 \(\alpha = 0.6\)、\(\gamma=1.5\)。
  - 实际对图像宽高各缩放 \(\sqrt{\rho}\) 倍；若目标任务有更严格的总 token 预算上限，则直接缩放到该预算要求的分辨率以内。

#### 2.3 Extract 阶段：动态双注意力提取器 (DDAE)

- 核心思想：从 LLM 端取得“语义注意力”信号，从 ViT 端取得“视觉注意力”信号，将二者动态融合后筛选前 K 个视觉令牌。
- 与只用 LLM attention 或只用 ViT attention 的方法相比：
  - 仅靠 LLM cross-attention 可能过度集中于提示中直接提到的目标区域，忽略图表网格线、微小文字等未被显式语言描述的重要视觉支撑信息。
  - 仅靠 ViT self-attention 能较好保留视觉边界和细节，但缺少文本查询的任务对齐性。
- 算法流程：
  - 从 LLM 的第 `L_ext` 层取得 cross-attention 图，最小-最大归一化得到 \(S_{\mathrm{llm}}\)；
  - 从视觉编码器最后几层取得 self-attention 图，同样归一化得到 \(S_{\mathrm{vis}}\)；
  - 分别计算 \(S_{\mathrm{llm}}\) 与 \(S_{\mathrm{vis}}\) 的标准差 \(\sigma_{\mathrm{llm}}\)、\(\sigma_{\mathrm{vis}}\)，标准差越大表示该注意力分布上的“确认度”越集中；
  - 用 softmax

#### 2.3 动态双注意力提取器（DDAE，续）

- 得到两个注意力分布的标准差后，用 softmax 将两类注意力分数动态加权融合，从而避免人为设定固定权重：
  \[
  \alpha = \frac{e^{\sigma_{\mathrm{llm}}}}{e^{\sigma_{\mathrm{llm}}} + e^{\sigma_{\mathrm{vis}}}}
  \]
- 融合后的最终评分如下：

\[
S_{\mathrm{final}} = \alpha \cdot S_{\mathrm{llm}} + (1-\alpha) \cdot S_{\mathrm{vis}}
\]

- 随后仅保留得分最高的 K 个视觉令牌，并构造二元选择掩码，一次性完成令牌剪枝。针对不同粒度任务采用不同策略来提高鲁棒性：在 Chart、OCR 和 DocVQA 等局部清晰度更重要的任务上，对 DDAE 的全局保留比例施加动态调整，使其优先保留低频细节相关令牌；同时采用“动态查询嵌入”适配不同文本提示的长度，避免注意力分数在长提示下过度分散。

- 另外，作者也设计了一个更轻量的快速变量版本：仅使用 LLM 交叉注意力或 ViT 自注意力之一作为得分，此时退化为单注意力提取器，用于推理预算极其受限的场景。

### 3. 实验与主要结果

#### 3.1 设置

- 评估模型：LLaVA-1.5-7B/13B、LLaVA-NeXT-7B/34B、以及 Qwen2-VL-7B 等。
- 任务覆盖：

  - 通用 VQA 与推理：TextVQA、VQAv2
  - 细粒度 OCR/图表语义理解：OCRBench、ChartQA、DocVQA、MathVerse
  - 多图像/视频推理：VideoVQA 等

- 推理延迟优化方式：将 PACE 与 vanilla 模型基线（全令牌蒸馏）对比；同时与现有主流剪枝方法比较，如 FastV、QA-Egger、SparseVLM 等。
- 硬件及时延指标：在 NVIDIA A100、H100 上测量端到端解码延迟、Prefill 时间、GPU 显存占用，并以 128 个并发序列评估真实吞吐量。

#### 3.2 精度-延迟联合收益

- **PACE 在 50% 视觉编码预算 + 50% LLM 视觉令牌预算下**：

  - 将端到端“首令牌推理时延”减少约 53%～66%；
  - 在 13B 及以上模型上，总 LLM Prefill 阶段时延减半；
  - 相比仅做编码器端压缩或仅做令牌剪枝的单一方法，额外获得 20%～30% 的整体延迟改善。

- **准确性结果**：

  - 在通用 VQA 上，PACE 在极低预算（如保留 25%～30% 视觉令牌）时分数下降仅在 0.5～1.5 分以内，显著优于 FastV 和 SparseVLM 等同类方法；
  - 在高质量的细粒度数据集上，ChartQA 与 DocVQA 在相同低预算下，分数比 FastV 高出 5～9 分，比 SparseVLM 高 4～7 分，尤其在小物体文字识别和表格标题行定位场景中优势明显；
  - OCRBench 上 PACE 在视觉编码器计算缩减 50% 时仍能保持约 92% 的原始得分，而同预算下基线方法往往降至 75% 左右。

#### 3.3 组件消融验证

- **去掉 APC（仅保留 DDAE）**：视觉编码器未加速，整体时延收益下降约一半；高分辨率图像上 Prefill 阶段重新成为瓶颈——说明了 Condense 阶段在端到端优化中的必要性。
- **去掉 DDAE（仅保留 APC）**：LLM 上下文长度未减少，解码时间仍长，且局部细节任务中精度崩溃明显——说明二阶段互补。
- **在 DDAE 中仅保留 LLM 注意力**：在简单“接地”类提示中依然有效，但在 DocVQA / ChartQA 上漏掉大量跨行文本与网格线等未提及结构；仅使用视觉自注意力时则更容易受视觉“背景显著性”干扰。**双注意力融合在两个任务上均最稳定**。

### 4. 进一步分析

#### 4.1 分辨率-令牌回收的自适应联系

- 论文的结果显示：APC 并非简单地压图像，而是根据信息密度决定回收比例。图形简单时压缩率更高，文本密集时压缩率更低，从而在整幅图像上形成连续的“软降采样”。这一机制对图像语义完整性（Objects 不切碎）极其关键。

#### 4.2 注意力分布“确认度”的动态融合机制

- 作者用注意力分布的信息熵/标准差的统计作为“不确定性”代理指标，比固定融合权重或早停式启发式规则更灵活，且能针对不同提示句子自动切换侧重点。
- Long Document 输入场景，当 LLM 注意力在多个文本块间高度发散，视觉注意力所占权重就更高，避免丢弃文字边界处的微小字形。

#### 4.3 PACE 在超高分辨率下的可扩展性

- 在 672×672 以上输入分辨率下，ViT 编码器计算增长超过 LLM 上下文长度的增长，即使后端保留所有令牌也不足以解耦延迟增长；PACE 将前端像素预缩放到合理分辨率范围内，从而打破基于令牌预算剪枝方法的局限，扩展到更高分辨率输入。

---

### 5. 限制与讨论

- 虽然 PACE 支持 Qwen2-VL 等更新架构，但对于某些已经合并了“像素卷积下采样”的 VLM（例如 SigLIP 与 Conv-merge 组合），APC 的输入像素缩放与内部抽象层信息保留之间的关系仍需进一步验证。
- 文中主要对图文/视频类模型做了验证，尚未在纯大规模语音或点云 VLM 上做迁移讨论。
- PACE 作为一个免训练推理框架，受益于“即插即用”的同时，也意味着它无法学习数据集级的最优剪枝掩码；在公开的正态分布数据集分布之外，存在防御式对抗性失真的高风险区域。
- DDAE 需要读取 L_ext 层内的 cross-attention map，在批量推理、attention cache 受控的场景下需要额外的缓存访问管线来支持。

---

### 6. 结论

- PACE 从“计算不效率发生在哪一层”这一角度出发，在视觉编码器端和 LLM 端双向做推理加速，在不训练模型的前提下实现了高分辨率 VLM 的端到端时延减半，同时保留场景理解与细粒度 OCR 能力。
- 核心创新在于：APC 通过轻量聚类式两级显著性判断完成像素级预压缩；DDAE 将 LLM 和 VLM 双层的“注意力确认度”以动态权值方式融合，突破低预算下遗忘局部微小上下文难题。
- 在 7B 至 34B 模型、多种视觉语言任务上，PACE 均取得优于已有单阶段视觉令牌压缩/剪枝方案的帕累托前沿。未来可进一步将该思路推广到“由任务指引导的局部放大”视频流推理模型等场景。
