## 摘要
大型视觉-语言模型（LVLMs）由于其冗长且高度冗余的视觉标记序列而产生了大量的推理成本。基于多样性的剪枝通过基于成对余弦相似度选择标记子集来缓解这一成本。然而，我们发现原始视觉标记之间的相似度强烈集中在正值范围内，限制了它们区分非冗余标记的能力。提高这种分辨率的自然方法是在计算余弦相似度之前对标记特征进行中心化。中心化确实揭示了更丰富的成对结构，但单独使用时却意外地降低了剪枝性能。我们表明，这种明显的矛盾之所以出现，是因为原始几何不仅仅表示成对多样性：它还隐式地偏好全局独特的标记，这些标记往往包含语义信息丰富的内容。中心化能更好地解决子集多样性，但失去了这种有用的逐标记偏好，揭示了多样性和独特性在原始几何中是纠缠在一起的。基于这一分析，我们提出了中心化几何剪枝器（Cen-Prune），它使用中心化余弦相似度来度量子集多样性，同时保留原始空间中的独特性作为互补的逐标记偏好。这种轻量级、即插即用的校正保持底层选择机制不变，并且产生可忽略的计算开销。在多个图像和视频理解基准以及LVLM架构上的大量实验表明，Cen-Prune在现有的基于多样性的剪枝器中提供了稳健的整体性能提升。

## Abstract
Large vision-language models (LVLMs) incur substantial inference costs due to their long and highly redundant visual-token sequences. Diversity-based pruning mitigates this cost by selecting token subsets based on pairwise cosine similarity. We find, however, that similarities between raw visual tokens are strongly concentrated in the positive range, limiting their ability to distinguish non-redundant tokens. A natural way to improve this resolution is to center token features before computing cosine similarity. Centering indeed reveals a substantially richer pairwise structure, yet unexpectedly degrades pruning performance when used alone. We show that this apparent contradiction arises because the raw geometry does more than represent pairwise diversity: it also implicitly favors globally distinctive tokens, which tend to contain semantically informative content. Centering better resolves subset diversity but loses this useful token-wise preference, revealing that diversity and distinctiveness are entangled in the raw geometry. Based on this analysis, we propose the \textbf{Cen}tered Geometry \textbf{Prune}r (Cen-Prune), which measures subset diversity using centered cosine similarity while retaining raw-space distinctiveness as a complementary token-wise preference. This lightweight, plug-and-play correction leaves the underlying selection mechanism unchanged and incurs negligible computational overhead. Extensive experiments across multiple image- and video-understanding benchmarks and LVLM architectures demonstrate that Cen-Prune provides robust improvements in overall performance across existing diversity-based pruners.

- **背景**：大型视觉-语言模型（LVLMs）将图像表示为大量视觉标记（visual tokens），随着高分辨率动态处理和多帧视频输入的引入，视觉标记序列变得非常冗长。由于注意力机制的计算量随序列长度二次增长，视觉标记成为推理延迟和内存消耗的主要来源。
- **问题**：基于多样性的视觉标记剪枝（diversity-based visual token pruning）是降低推理成本的有效方法，其核心依赖于**成对余弦相似度**来度量 token 之间的冗余程度。然而，论文发现**原始视觉标记特征之间的余弦相似度高度集中在正值区间**（平均余弦相似度约 0.37，中位角度约 72°），只有 2.3% 的 token 对具有负余弦相似度。这意味着原始几何空间对"非冗余程度"的区分能力非常有限，大多数 token 看起来彼此相似。
- **关键矛盾**：对特征进行**均值中心化（mean centering）**后，余弦相似度的分布被显著拓宽，出现了大量负相关对（32% 的配对低于 −0.5），表明中心化能够揭示更丰富的残差多样性。然而，直接基于中心化几何进行剪枝反而**降低性能**。论文揭示这一矛盾的原因：原始几何不仅编码了成对多样性，还**隐式包含了对全局独特 token 的偏好**——那些远离平均特征的 token 往往携带更具语义信息的内容。中心化虽然提升了多样性分辨率，却丢失了这种有用的 token 级重要性信号。
- **核心含义**：多样性和独特性在原始几何中是纠缠的，简单地移除共享方向会割裂二者。论文提出 Cen-Prune 将两者解耦并在互补的几何空间中分别建模。

## 2. 论文提出的方法论

### 核心思想
Cen-Prune 将两个互补信号分配到两个互补的几何空间中：
- **子集多样性**：在中心化后的几何中度量（中心化余弦相似度）。
- **Token 独特性（token distinctiveness）**：在原始未中心化的几何中度量，作为软偏好信号融入选择过程。

### 关键技术细节

**（1）中心化几何用于子集多样性**

- 计算图像级均值向量：μ = (1/N)∑ⱼ xⱼ
- 对每个 token 特征中心化：x̄ᵢ = xᵢ − μ
- 在 ℓ2 归一化后的中心化残差上构建相似度矩阵：S̄ᵢⱼ = ⟨x̂̄ᵢ, x̂̄ⱼ⟩
- 中心化移除了共享方向，使选择器能够直接利用残差方向间的角度差异。

**（2）原始空间独特性评分**

- 定义 token i 的独特性分数为其与其余 token 的负平均余弦相似度：gᵢ = −(1/(N−1))∑ⱼ≠ᵢ Sᵢⱼ，其中 Sᵢⱼ 来自原始未中心化特征。
- 该分数与 ∥x̂ᵢ − m∥²（token 与归一化特征均值 m 的距离）单调相关，因此高 gᵢ 意味着该 token 偏离图像的共同特征模式。
- 分数在图像内进行 min–max 归一化（LLaVA 系列）或 z-score + sigmoid 归一化（Qwen2.5-VL），以适配不同 token 数量动态变化的特点。

**（3）与现有选择器的集成**

- **贪心 MMDP（DivPrune/ZOO-Prune）**：距离矩阵改为 Dᵢⱼ = 1 − S̄ᵢⱼ，每次贪心步骤选择：i* = argmaxᵢ∉T g̃ᵢ · minₛ∈T Dᵢₛ，即同时要求残差方向远离已选集合、且 token 本身在原始空间中具有独特性。
- **DPP（CDPruner）**：核矩阵改为 L_Cen = diag(r̃ ⊙ g̃) S̄ diag(r̃ ⊙ g̃)，其中 r̃ 为原始的指令相关性分数，g̃ 为独特性分数，S̄ 为中心化相似度矩阵。
- 底层选择机制和优化流程完全不变，仅替换输入几何并叠加一个软偏好权重。

**（4）针对方差不平衡架构的标准化中心化**

- 对于 Qwen2.5-VL 等架构，部分维度主导了方差（单一维度占中心化方差的 98.9%），直接中心化会导致相似度分布集中在 ±1 两端。
- 先对每张图像的 token 特征进行逐维方差缩放（Y = V·diag(σ)⁻¹），再进行中心化，以构建良态的残差几何。

## 6. 论文的主要结论与发现

1. **原始视觉 token 几何高度集中**：成对余弦相似度集中在正值区间（均值约 0.37，中位角度约 72°），仅 2.3% 为负。现有多样性选择器实际上主要做"去重"，无法构造整体上彼此差异性强的子集。
2. **中心化暴露残差多样性但破坏独特性偏好**：中心化使 32% 的配对余弦相似度低于 −0.5，但纯中心化选择偏好方向独特而残差幅度小的 token，丢失了原始几何中对全局独特、语义重要 token 的隐式偏好。
3. **多样性与独特性可以解耦并互补**：在中心化几何中度量多样性、在原始几何中度量独特性，可以有效兼得两者的优点。
4. **Cen-Prune 提供一致且稳健的改进**：在不同架构、不同压缩率、图像和视频场景下，Cen-Prune 均显著提升现有多样性剪枝器（DivPrune、ZOO-Prune、CDPruner）的性能。例如，LLaVA-1.5-7B 保留 32 token 时，DivPrune 的相对性能从 91.8% 提升至 93.4%；LLaVA-NeXT-7B 保留 320 token 时，CDPruner 从 94.7% 提升至 96.1%；Qwen2.5-VL-7B 保留 10% token 时，DivPrune 从 85.1% 提升至 88.9%。
5. **额外开销可忽略**：与原始剪枝器相比，Cen-Prune 的额外延迟约为 0.1~0.9 毫秒，FLOPs 完全不变。
6. **训练无关、即插即用**：不修改底层选择机制，不引入可学习参数，适配各类主流的基于多样性的剪枝方法。

## 7. 优点

- **问题切入深刻**：通过对原始几何和中心化几何的系统分析，解释了一个直观上反直觉的"中心化反而使剪枝变差"的现象，揭示了多样性与独特性之间的纠缠关系，为多样性剪枝提供了新的分析视角。

- **模型规模覆盖有限**：主要实验集中在 7B 量级，13B 仅作为补充验证；未覆盖更大的 30B/70B 量级模型，不能完全确认在大规模架构上的可扩展性。
- **缺失训练/评估时长信息**：未报告总的 GPU 小时数或推理评估的具体时长，不利于计算成本的全面权衡评估。
- **统计显著性缺失**：大多数结果未报告多次运行的标准差或显著性检验，无法评估结果的稳定性；效率表格中的毫秒级差异可能处于测量噪声范围内。
- **独特性与语义重要性的关联仍是启发式的**：论文承认高独特性不必然意味着语义重要（可能只是离群点），虽然实验显示二者正相关，但缺乏更系统的语义级验证。
- **对 CDPruner 在 Qwen2.5-VL 低压缩率下的改进有限**：在保留 5% token 时，CDPruner + Ours 的相对性能虽然高于 CDPruner，但幅度明显小于 DivPrune 的提升；且个别基准如 MMBench 出现轻微下降。
- **视频场景覆盖较窄**：仅报告了 DivPrune 和 CDPruner 两个基线在视频上的结果，未涵盖 ZOO-Prune、MMTok 等视频场景的对比；视频帧间 token 的独特性和多样性交互机制也未深入分析。
- **标准化中心化的适用性需人工判断**：对于不同架构，论文基于经验分析选择不同的预处理方式（普通中心化 vs. 逐维标准化后中心化）和不同的分数归一化方法（min–max vs. z-score+sigmoid），这在一定程度上依赖分析者对各架构几何特性的判断，而非全自动的统一流程。
