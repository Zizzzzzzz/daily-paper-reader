## 摘要
长上下文压缩对于降低大语言模型推理的成本和延迟至关重要。然而，现有方法可能会割裂重要证据，需要额外的训练或对齐，并且通常依赖目标模型才能实现有效压缩。我们提出了TopoCompress，一种无需训练且与模型无关的框架，通过选择连贯的语义片段来压缩长上下文。TopoCompress首先利用稠密和词法查询相关性以及语义加速对每个片段进行评分。然后，它构建一个混合图，根据语义相似性和序列邻接性连接片段，并在图上传播查询引导的相关性分数。在五个长上下文任务——HotpotQA、2WikiMQA、MuSiQue、Qasper和MultiFieldQA-en上，TopoCompress始终优于强压缩基线。值得注意的是，TopoCompress在使用4倍更小的压缩预算时达到了与最强基线相当的性能，并且比最快基线的压缩时间缩短了1.41倍。

## Abstract
Long-context compression is essential for reducing the cost and latency of large language model inference. However, existing methods can fragment important evidence, require additional training or alignment, and often depend on the target model for effective compression. We introduce TopoCompress, a training-free and model-agnostic framework that compresses long contexts by selecting coherent semantic spans. TopoCompress first scores each span using dense and lexical query relevance together with semantic acceleration. It then constructs a hybrid graph that connects spans based on semantic similarity and sequential adjacency, and propagates the query-guided relevance scores over the graph. Across five long-context tasks-HotpotQA, 2WikiMQA, MuSiQue, Qasper, and MultiFieldQA-en-TopoCompress consistently outperforms strong compression baselines. Notably, TopoCompress achieves performance comparable to the strongest baseline while using a 4x smaller compression budget, and provides a 1.41x smaller compression time over the fastest baseline.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）处理长上下文时面临推理成本高、延迟大、以及“中间信息丢失”等挑战。长上下文压缩旨在从冗长输入中提取最关键的信息，以降低推理开销并提升答案质量。
- **现有方法的三大缺陷**：
  1. **上下文碎片化**：以token为单位做剪枝（如LLMLingua、LongLLMLingua）会破坏词边界、短语、命名实体等完整语义单元（如将“Wilhelm Conrad Röntgen”截断为“Wilhelm Con Röntgen”），扭曲目标模型所见信息，甚至需要后处理恢复。
  2. **依赖目标模型对齐**：压缩器需通过指令微调学习模仿目标模型的信息偏好，引入了额外计算，且压缩器与特定目标模型绑定，缺乏跨模型通用性。
  3. **忽视证据间关系**：perplexity式的重要性评分只刻画局部可预测性，无法建模“证据链”——在HotpotQA、MuSiQue等多跳任务中，一个token可能因局部易预测而被丢弃，却承载着连接跨文档证据的中间信息。
- **总体含义**：本文提出将长上下文压缩从“独立token的修剪”重新定义为“基于图结构的相关性传播与连贯语义片段选择”，首次将图建模引入该任务，实现了免训练、模型无关的有效压缩。

## 2. 论文提出的方法论

### 核心思想
TopoCompress将上下文视为一组语义连贯的片段（span），通过四步完成压缩：片段划分 → 查询相关性打分（附带语义加速） → 混合图上的相关性传播 → 冗余感知的贪心选择。

### 关键流程与公式（文字说明）

1. **语义片段构建**（Semantic Span Construction）  
   将每个文档切分为句子或短段落等连续语义单元，避免token级割裂对实体和短语的破坏。

2. **稠密与词法查询相关性**（Dense & Lexical Query Relevance）  
   使用冻结的bge-m3编码器计算片段与查询的稠密向量余弦相似度（公式1），并用bge-m3输出的词法权重计算查询与片段间的词项匹配得分（公式2）。二者加权融合为查询对齐分数 \( g_i = \mu \hat{r}_i + (1-\mu)\hat{\ell}_i \)（公式3），兼顾语义相关与精确实体/日期匹配。

3. **语义加速**（Semantic Acceleration）  
   对同一文档内的片段序列计算二阶差分 \( a_i = 2e_i - e_{i-1} - e_{i+1} \) 的模长（公式4），刻画语义轨迹发生急剧转折的位置，再以查询对齐为门控得到初始分数 \( s_i = (1 + \lambda \hat{\kappa}_i) g_i \)（公式5）。该机制突出处于语义转折处且与查询相关的片段，避免无关转折被误选。

4. **混合图与相关性传播**（Span Topology & Relevance Propagation）  
   构建加权图：语义边连接k近邻（按嵌入相似度）片段，权重为余弦相似度；序列边连接同一文档内相邻片段，权重为1。边权重矩阵 \( W = \alpha W_{\text{sem}} + \beta W_{\text{seq}} \) 经行归一化后得到转移矩阵P，执行个性化相关传播 \( s^{(m+1)} = (1-\eta)s + \eta P^\top s^{(m)} \)，直到收敛。该步骤使弱匹配查询但处于证据链上的中间片段通过图连接获得重要度。

5. **冗余感知的选择**（Redundancy-Aware Evidence Selection）  
   贪心选择：候选片段得分 = 传播后相关度 − δ × 与已选片段的最大相似度，避免重复信息占用预算。选满预算K后按原始顺序还原，保留可读性。
