## 摘要
KV 缓存量化器通常优化存储空间的重建，尽管注意力机制是通过 logit 读取键（Key），并通过注意力加权读取值（Value）。我们认为，持久的缓存误差应在模型可见的坐标系中进行衡量。对于键，可见对象是模常量偏移后的分数误差；由此产生了 HeadQ，这是一种键侧方法，它在通过校准学习到的查询（Query）基向量中存储低秩残差侧码，并将其作为加性 logit 校正应用。对于值，固定注意力读取产生了一个 $A^2$ 加权的标记失真代理指标。在六个模型中，Fisher/分数空间误差对注意力 KL 散度的预测效果远优于原始键的均方误差（MSE）；同等预算的反例、零空间干预、查询 PCA 控制以及反向符号的 HeadQ 证伪了基于存储 MSE 的替代方案。匹配的 Pythia 检查点将主要异常定位在小模型低熵路由翻转边界。在仅针对键且使用密集值的 WikiText-103 解码实验中，HeadQ 在最强的 2-bit 行上消除了约 84%--94% 的超额困惑度；在辅助的全 KV 2-bit 组合中，HeadQ 结合 $A^2$ 值策略改进了所有六个模型。

## Abstract
KV-cache quantizers usually optimize storage-space reconstruction, even though attention reads keys through logits and values through attention-weighted readout. We argue that persistent cache error should be measured in model-visible coordinates. For keys, the visible object is score error modulo constant shifts; this yields HeadQ, a key-side method that stores a low-rank residual side code in a calibration-learned query basis and applies it as an additive logit correction. For values, fixed-attention readout gives an $A^2$-weighted token-distortion surrogate. Across six models, Fisher/score-space error predicts attention KL far better than raw key MSE; same-budget counterexamples, null-space interventions, query-PCA controls, and wrong-sign HeadQ falsify storage-MSE alternatives. Matched Pythia checkpoints localize the main anomaly to a small-model low-entropy route-flip boundary. In K-only WikiText-103 decode experiments with dense values, HeadQ removes roughly $84$--$94\%$ of the excess perplexity on the strongest 2-bit rows; in an auxiliary full-KV 2-bit composition, HeadQ plus an $A^2$ value policy improves all six models.

随着大语言模型（LLM）上下文长度的增加，KV 缓存（KV-Cache）的存储和带宽压力成为推理瓶颈。现有的量化方法（如 KIVI, KVQuant 等）主要关注**存储空间**的重建误差（如均方误差 MSE），即尽可能让量化后的 $K, V$ 矩阵在数值上接近原始矩阵。
然而，作者指出：**模型并不直接“看到”存储的数值**。
*   **键（Key）**：模型通过查询（Query）与键的点积产生 Logit（分数），且 Softmax 具有平移不变性。
*   **值（Value）**：模型通过注意力权重对值进行加权求和。
因此，传统的 MSE 指标无法准确反映量化对模型行为的影响。论文的核心动机是提出一种在“模型可见坐标系”下衡量和补偿失真的方法。

### 2. 方法论：HeadQ 核心思想与技术细节
HeadQ 的核心是**分数空间校正（Score-Space Correction）**，其主要步骤如下：
*   **模型可见失真定义**：
    *   对于 **Key**：关注 Logit 误差（模常量偏移）。通过 Fisher 信息矩阵推导出，Key 的误差应通过其在 Query 方向上的投影来衡量。
    *   对于 **Value**：关注加权读取误差。推导出应使用 $A^2$（注意力权重的平方）加权的标记失真作为代理指标。
*   **HeadQ 算法流程**：
    1.  **校准阶段**：在离线状态下，收集各层的 Query，通过 PCA 提取每个注意力头的主成分基向量 $U_h$。
    2.  **缓存写入（压缩）**：将 Key 量化为低比特基础格式，同时计算残差 $e_j$。将残差投影到基向量 $U_h$ 上，存储一个极小比特的“侧码”（Side Code）。
    3.  **注意力读取（解压与校正）**：在推理时，利用当前的 Query 与存储的侧码计算一个加性校正项，直接补偿到 Logit 分数上。
*   **Value 侧策略**：采用 $A^2$ 加权分配策略，将更多比特分配给注意力权重高的 Token。
