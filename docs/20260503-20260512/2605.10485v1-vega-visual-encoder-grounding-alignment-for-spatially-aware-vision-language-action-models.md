## 摘要
精确的空间推理是机器人操作的基础，然而当前视觉-语言-动作（VLA）模型的视觉主干网络主要在 2D 图像数据上进行预训练，缺乏显式的 3D 几何监督，导致其表征缺乏准确的空间感知。现有的隐式空间定位方法通过将 VLA 特征与 3D 感知基础模型的特征对齐来部分解决这一问题，但它们依赖于经验性的层搜索，并在 LLM 层级的视觉 token 上进行对齐，此时空间结构已经与语言语义纠缠在一起，限制了泛化能力和几何可解释性。我们提出了 VEGA（视觉编码器定位对齐），这是一个简单而有效的框架，它直接将 VLA 视觉编码器的输出与来自 DINOv2-FiT3D 的空间感知特征相对齐。DINOv2-FiT3D 是一个通过多视图一致的 3D 高斯泼溅（3D Gaussian Splatting）监督进行微调的 DINOv2 模型。通过在视觉编码器输出层级进行对齐，VEGA 在发生任何语言纠缠之前就建立了空间感知定位，提供了一个更具可解释性且更有原则的对齐目标。该对齐通过一个轻量级投影器实现，该投影器与标准动作预测目标一起使用余弦相似度损失进行训练，并在推理时被舍弃，不会引入额外的计算开销。在仿真基准测试和真实世界操作任务上的大量实验表明，VEGA 一贯优于现有的隐式空间定位基准，在 VLA 模型的隐式空间定位方法中树立了新的最先进水平（SOTA）。

## Abstract
Precise spatial reasoning is fundamental to robotic manipulation, yet the visual backbones of current vision-language-action (VLA) models are predominantly pretrained on 2D image data without explicit 3D geometric supervision, resulting in representations that lack accurate spatial awareness. Existing implicit spatial grounding methods partially address this by aligning VLA features with those of 3D-aware foundation models, but they rely on empirical layer search and perform alignment on LLM-level visual tokens where spatial structure has already been entangled with linguistic semantics, limiting both generalizability and geometric interpretability. We propose VEGA (Visual Encoder Grounding Alignment), a simple yet effective framework that directly aligns the output of the VLA's visual encoder with spatially-aware features from DINOv2-FiT3D, a DINOv2 model fine-tuned with multi-view consistent 3D Gaussian Splatting supervision. By performing alignment at the visual encoder output level, VEGA grounds spatial awareness before any linguistic entanglement occurs, offering a more interpretable and principled alignment target. The alignment is implemented via a lightweight projector trained with a cosine similarity loss alongside the standard action prediction objective, and is discarded at inference time, introducing no additional computational overhead. Extensive experiments on simulation benchmark and real-world manipulation tasks demonstrate that VEGA consistently outperforms existing implicit spatial grounding baselines, establishing a new state-of-the-art among implicit spatial grounding methods for VLA models.

#### 1. 核心问题与整体含义（研究动机和背景）
机器人操控任务（如抓取、放置、避障）极度依赖精确的 3D 空间推理。然而，目前的视觉-语言-动作（VLA）模型（如 OpenVLA, RT-2）主要在 2D 图像数据上预训练，缺乏显式的 3D 几何监督。
*   **现有挑战**：现有的“隐式空间定位”方法通常在大型语言模型（LLM）的输入 token 层级进行特征对齐。这导致两个问题：一是空间结构与语言语义在 LLM 层级已经发生纠缠，难以提取纯粹的几何信息；二是需要繁琐的经验性搜索来确定对齐哪一层。
*   **研究目标**：提出一种在视觉编码器输出端直接进行空间对齐的框架，以增强 VLA 模型的 3D 空间感知能力，且不增加推理负担。

#### 2. 方法论
VEGA 的核心思想是**在视觉特征进入 LLM 之前，将其与具备 3D 感知能力的“教师模型”特征进行对齐**。
*   **核心思想**：利用经过 3D 几何监督（3D Gaussian Splatting）微调的视觉模型作为教师，引导 VLA 的视觉主干网络学习空间一致性。
*   **关键技术细节**：
    *   **教师模型**：选用 **DINOv2-FiT3D**。该模型通过多视图一致性蒸馏了 3D 几何属性，能提供密集的、具有空间结构感的 patch 级特征。
    *   **对齐机制**：在 VLA 的 DINOv2 分支输出端添加一个轻量级的 **MLP 投影器**（两层 MLP + GELU）。
    *   **损失函数**：采用余弦相似度损失（Cosine Similarity Loss）来最小化投影后的 VLA 特征与教师模型特征之间的距离。
    *   **联合训练**：总损失函数为 $L_{VEGA} = L_{action} + \lambda L_{align}$，其中 $L_{action}$ 是标准的动作预测损失，$\lambda$ 是平衡系数（实验设定为 0.1）。
*   **算法流程**：训练时，图像同时输入 VLA 视觉编码器和冻结的 FiT3D 编码器；通过投影器对齐特征并反向传播；**推理时，舍弃投影器和教师模型**，模型结构回归原始状态。

#### 7. 优点（亮点）
*   **解耦对齐**：在语言语义介入前进行空间对齐，避免了语义干扰，几何可解释性更强。
*   **零推理开销**：通过训练时的特征蒸馏实现增强，推理时不需要额外的深度传感器或复杂的 3D 基础模型。
*   **架构通用性**：方法简单，易于集成到各种基于 ViT 视觉主干的 VLA 架构中。
*   **数据效率**：在小样本数据下表现出更强的归纳偏置。

#### 8. 不足与局限
*   **教师模型依赖**：VEGA 的效果高度依赖于 DINOv2-FiT3D 的质量，如果任务场景与 FiT3D 的预训练分布（室内场景）差异极大，效果可能受限。
*   **端到端局限**：虽然增强了空间感知，但对于极细微的物体（如细线、透明物体）或工作空间边缘的碰撞预防仍存在失效案例。
*   **任务覆盖**：目前主要集中在短程操控任务，对于长程逻辑推理与空间感知的结合尚待进一步探索。
