## 摘要
基于 Vision Transformer 的前馈三维重建模型可以直接从少量输入图像中估计场景几何和相机位姿，但由于全局注意力层的二次计算开销，将其扩展到包含数百或数千帧的视频输入仍然具有挑战性。最近的 Token 合并方法通过压缩全局注意力层中的 Token 序列来加速这些模型，但它们对查询（query）Token 和键值（key-value）Token 应用统一的缩减，忽略了它们在三维重建中功能上的差异。在这项工作中，我们发现了前馈三维重建模型的一个关键特性：查询 Token 编码了特定视角的几何请求，对压缩较为敏感；而键值 Token 代表共享的场景上下文，能够容忍大幅度的压缩。基于这一见解，我们提出了 Spark3R，这是一个无需训练的加速框架。它通过分配不同的缩减因子，解耦了查询 Token 和键值 Token 的压缩，对查询 Token 应用组内 Token 合并，对键值 Token 应用轻量级 Token 剪枝。此外，Spark3R 跨层自适应地调整键值缩减因子，进一步优化了质量与效率之间的权衡。作为一种无需重新训练的即插即用框架，Spark3R 可以直接集成到多个预训练的前馈三维重建模型中（包括 VGGT、$π^3$ 和 Depth-Anything-3），在 1,000 帧输入下实现了高达 28 倍的加速，同时保持了具有竞争力的重建质量。

## Abstract
Feed-forward 3D reconstruction models based on Vision Transformers can directly estimate scene geometry and camera poses from a small set of input images, but scaling them to video inputs with hundreds or thousands of frames remains challenging due to the quadratic cost of global attention layers. Recent token-merging methods accelerate these models by compressing the token sequence within the global attention layers, but they apply a uniform reduction to query tokens and key-value tokens, ignoring their functionally distinct roles in 3D reconstruction. In this work, we identify a key property of feed-forward 3D reconstruction models: query tokens encode view-specific geometric requests and are sensitive to compression, while key-value tokens represent shared scene context and tolerate aggressive compression. Guided by this insight, we propose Spark3R, a training-free acceleration framework that decouples the compression of query tokens and key-value tokens by assigning distinct reduction factors, with intra-group token merging applied to query tokens and lightweight token pruning to key-value tokens. Additionally, Spark3R adaptively adjusts the key-value reduction factor across layers, further improving the quality-efficiency trade-off. As a plug-and-play framework requiring no retraining, Spark3R integrates directly into multiple pretrained feed-forward 3D reconstruction models, including VGGT, $π^3$, and Depth-Anything-3, and achieves up to $28\times$ speedup on 1,000-frame inputs while maintaining competitive reconstruction quality.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：基于 Vision Transformer (ViT) 的前馈三维重建模型（如 VGGT, $\pi^3$）虽然能直接从图像预测几何和位姿，但其核心的“全局注意力机制”具有**二次方计算复杂度**。这导致模型在处理长视频（数百至上千帧）时，内存和计算开销呈爆炸式增长，难以扩展。
*   **研究动机**：现有的加速方案（如 Token Merging）通常对所有 Token 采用统一的压缩率。作者发现，在 3D 重建任务中，**Query (Q) 和 Key-Value (KV) Token 扮演的角色完全不同**：Q 负责生成特定视角的几何请求（敏感），而 KV 负责提供共享的场景上下文（冗余度高）。忽略这种非对称性限制了加速比和重建质量。

### 2. 方法论：Spark3R 框架
Spark3R 是一个**无需训练、即插即用**的加速框架，其核心思想是“非对称 Token 缩减”：
*   **非对称缩减因子**：为 Q 和 KV 分配不同的缩减比例（$r_Q$ 和 $r_{KV}$），通常 $r_{KV} \gg r_Q$。
*   **组内查询合并 (Intra-Group Query Merging)**：
    *   针对 Q Token，作者发现合并操作具有极强的“时间局部性”（即相邻帧的 Token 更容易合并）。
    *   将视频划分为若干组（如每组 20 帧），仅在组内进行 Token 合并。这不仅保持了重建精度，还将匹配复杂度从 $O(S^2)$ 降低到 $O(S)$。
*   **轻量级键值剪枝 (Lightweight KV Pruning)**：
    *   针对 KV Token，作者发现匹配后的相似度极高（>0.9），因此复杂的“合并（平均）”操作可以简化为直接“剪枝（丢弃）”。
    *   采用简单的“时间步长采样”保留 Token，几乎零计算开销。
*   **层自适应缩减策略 (Layer-Adaptive Schedule)**：
    *   通过离线探测发现，Transformer 的中间层对 KV 压缩更敏感，而浅层和深层则非常鲁棒。
    *   根据敏感度将层分为两类，对不敏感层应用更激进的压缩倍率（如 3 倍于基础缩减因子）。

### 6. 主要结论与发现
*   **极高的加速比**：在 1000 帧输入下，实现了高达 **28 倍** 的加速。

*   **通用性强**：无需任何微调即可直接应用于多种 Transformer 架构的 3D 重建模型。

### 7. 优点（亮点）
*   **非对称视角**：深刻揭示了 Q 和 KV 在 3D 重建中敏感度的本质差异，这是优于以往统一压缩方法的关键。
*   **极低开销**：通过将合并简化为剪枝、将全局匹配简化为组内匹配，使 Token 缩减本身的计算耗时几乎可以忽略。
*   **即插即用**：无需昂贵的重训过程，对工业界和研究者非常友好。

### 8. 不足与局限
*   **性能上限受限于基座**：作为一种加速方案，它无法解决基座模型本身的固有缺陷（如某些极端场景下的失败模式）。
*   **离线探测依赖**：层自适应策略需要针对每个新模型进行一次简单的离线敏感度探测（虽然只需一次且很快）。
*   **应用限制**：主要针对全局注意力机制的模型，对于已经是线性复杂度的架构（如某些纯流式模型）提升可能有限。
