## 摘要
视觉几何 Transformer (VGGT) 是一种用于多种 3D 任务的强大前馈模型，但其交替注意力 (AA) 堆栈的计算量随总令牌数呈二次方增长，使得处理长视频片段的成本非常高。现有的令牌减少加速器通常在 AA 内部运行，导致进入 AA 的 patch 网格未被压缩。我们提出了 PaceVGGT，这是一个预 AA 令牌剪枝框架，在冻结的 VGGT 的第一个 AA 块之前对 DINO patch 令牌进行剪枝。PaceVGGT 训练了一个轻量级的令牌评分器，用于根据 DINO 特征估计每个令牌的重要性。该评分器首先针对未剪枝主干网络的 AA 内部注意力目标进行蒸馏，随后在下游相机、深度和点图损失下进行精调。通过每帧保留预算固定主干网络可见的序列长度，同时利用重要性自适应的合并/剪枝分配，在固定总合并预算下保留高显著性帧的残余内容。此外，特征引导恢复模块负责重建预测头所需的密集空间网格。在 ScanNet-50 和 7-Scenes 数据集上，PaceVGGT 在降低推理延迟的同时，保持了重建质量与延迟之间的最优平衡。在 ScanNet-50 上，当 N=300 时，其延迟比原始 VGGT 降低了 5.1 倍；当 N=1000 时，比 LiteVGGT 降低了 1.47 倍。这些结果表明，预 AA 剪枝是加速冻结的 VGGT 类几何 Transformer 的一条可行路径。

## Abstract
Visual Geometry Transformer (VGGT) is a strong feed-forward model for multiple 3D tasks, but its Alternating-Attention (AA) stack scales quadratically in the total token count, making long clips expensive.   Existing token-reduction accelerators operate inside AA, leaving the patch grid that enters AA uncompressed.   We introduce PaceVGGT, a pre-AA token pruning framework that prunes DINO patch tokens before the first AA block of a frozen VGGT. PaceVGGT trains a lightweight Token Scorer that estimates per-token importance from DINO features. The scorer is first distilled against an AA-internal attention target from the unpruned backbone, then refined under downstream camera, depth, and point-map losses.   A per-frame keep budget fixes the backbone-visible sequence length, while an importance-adaptive merge/prune assignment preserves residual content from high-saliency frames under a fixed total merge budget.   A Feature-guided Restoration module reconstructs the dense spatial grid required by the prediction heads.   On ScanNet-50 and 7-Scenes, PaceVGGT remains on the reconstruction quality--latency frontier while reducing inference latency.   On ScanNet-50, it reduces latency by \(5.1\times\) over unmodified VGGT at \(N=300\) and \(1.47\times\) over LiteVGGT at \(N=1000\).   These results identify pre-AA pruning as a viable acceleration route for frozen VGGT-style geometry transformers.

#### 1. 核心问题与整体含义（研究动机和背景）
Visual Geometry Transformer (VGGT) 是一个强大的 3D 几何基础模型，能够同时预测相机参数、深度图和点图。然而，其核心的**交替注意力（Alternating-Attention, AA）**机制在处理长视频序列时，计算复杂度随 Token（令牌）数量呈二次方增长，导致显存占用极高（如 360 帧需 95GB VRAM）。
**核心问题**在于：现有的加速方案（如 FastVGGT, LiteVGGT）多在 AA 模块内部进行 Token 减少，这意味着模型的前几层仍需处理全量数据。本论文提出 **PaceVGGT**，旨在将剪枝操作提前到进入 AA 模块之前的 **DINO-to-AA 接口处**，从而在整个主干网络中实现计算量的全流程压缩。

#### 2. 方法论：核心思想与关键技术
PaceVGGT 的核心思想是“预处理剪枝 + 几何感知评分 + 特征引导恢复”。

*   **Token Scorer（令牌评分器）**：
    *   使用轻量级深度卷积网络，直接从 DINO 特征图中提取每个 Token 的重要性分数。
    *   **监督信号**：通过蒸馏未剪枝模型的内部注意力权重来训练。评分目标结合了“相机锚定分数”（$S_{cam}$，反映 Token 对位姿估计的贡献）和“跨视图匹配分数”（$S_{global}$，反映 Token 在不同视角间的重复性与显著性）。
*   **重要性自适应剪枝（Token Pruning）**：
    *   将 Token 分为三类：**保留（Keep）**、**合并（Merge）**和**剪枝（Prune）**。
    *   **自适应分配**：根据帧的重要性动态分配“合并”预算。高显著性帧保留更多细节，低显著性帧则更多地进行剪枝。
    *   **合并操作**：将合并类 Token 的特征通过相似度加权聚合到保留类 Token 中，减少信息丢失。
*   **Feature-guided Restoration（特征引导恢复）**：
    *   由于下游任务（如深度图预测）需要密集的空间网格，模型在 AA 模块输出后，利用交叉注意力机制，以原始 DINO 特征为查询（Query），将稀疏的骨干网络输出恢复为高分辨率的密集特征图。

#### 6. 主要结论与发现
*   **加速效果显著**：在 ScanNet-50 (N=300) 上比原始 VGGT 快 **5.1 倍**；在 N=1000 时比 LiteVGGT 快 **1.47 倍**。

#### 7. 优点（亮点）
*   **架构创新**：打破了“在 AA 内部剪枝”的思维定式，通过 Pre-AA 剪枝实现了更彻底的计算节省。
*   **轻量化设计**：新增模块仅占总参数量的不到 1%，且无需重新训练庞大的 VGGT 骨干网络（保持冻结）。
*   **恢复机制**：特征引导恢复模块巧妙地解决了剪枝导致的密集预测困难问题。

#### 8. 不足与局限
*   **场景覆盖**：实验主要集中在室内场景，对于室外大基线（Large-baseline）场景的适用性尚未验证。
