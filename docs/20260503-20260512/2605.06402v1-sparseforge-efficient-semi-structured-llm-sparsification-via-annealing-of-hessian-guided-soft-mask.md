## 摘要
半结构化稀疏性为利用原生硬件支持加速大语言模型（LLM）提供了一条切实可行的路径，但由于强结构耦合，训练后半结构化剪枝往往会导致严重的质量下降。现有方法依赖大规模稀疏重训练来恢复精度，从而导致高昂的计算成本。我们提出了 SparseForge，这是一个训练后框架，它通过直接优化稀疏掩码而非增加重训练 token 的规模来提高恢复效率。SparseForge 将 Hessian 感知的显著性估计与软掩码向硬件可执行结构化稀疏性的渐进退火相结合，实现了稳定且高效的稀疏恢复。在 2:4 稀疏度下的 LLaMA-2-7B 上，SparseForge 仅使用 5B 个重训练 token 就达到了 57.27% 的平均零样本准确率，超过了稠密模型的 56.43% 准确率，并接近了使用 40B 个 token 的最先进方法所取得的 57.52% 的结果。SparseForge 在准确率与效率权衡方面的这种改进在不同模型系列中均表现出一致性。

## Abstract
Semi-structured sparsity provides a practical path to accelerate large language models (LLMs) with native hardware support, but post-training semi-structured pruning often suffers from substantial quality degradation due to strong structural coupling. Existing methods rely on large-scale sparse retraining to recover accuracy, resulting in high computational cost.   We propose SparseForge, a post-training framework that improves recovery efficiency by directly optimizing the sparsity mask rather than scaling up retraining tokens. SparseForge combines Hessian-aware importance estimation with progressive annealing of soft masks into hardware-executable structured sparsity, enabling stable and efficient sparse recovery. On LLaMA-2-7B under 2:4 sparsity, SparseForge achieves 57.27% average zero-shot accuracy with only $\textbf{5B}$ retraining tokens, surpassing the dense model's 56.43% accuracy and approaching the 57.52% result of a state-of-the-art method using $\textbf{40B}$ tokens. Such improvements on the accuracy-efficiency trade-off from SparseForge are shown to be consistent across model families.

### 1. 论文的核心问题与整体含义（研究动机和背景）
论文聚焦于大语言模型（LLM）的**半结构化稀疏化（Semi-structured Sparsification）**，特别是 NVIDIA GPU 原生支持的 **2:4 稀疏模式**。
*   **核心问题**：现有的半结构化剪枝方法面临“精度-效率”的严重权衡。传统的“剪枝后重训练”范式若要恢复精度，通常需要消耗极大的计算资源（如使用 40B tokens 进行长时间训练）；而轻量级的剪枝方法则会导致明显的模型性能下降。
*   **研究动机**：作者认为稀疏恢复的瓶颈在于**掩码（Mask）的质量**而非单纯的重训练规模。在受限的结构化约束下，权重之间存在组内竞争，过早地确定离散的 0/1 掩码会限制优化空间。因此，需要一种更高效的掩码优化机制。

### 2. 论文提出的方法论
SparseForge 提出了一个名为**掩码退火（Mask Annealing）**的框架，核心思想是将掩码视为连续可优化的变量，并经历从“软”到“硬”的转变。
*   **双轨重训练循环（Dual-track Retraining）**：在“加热（Heating）”阶段，同时优化模型权重和连续的软掩码（Soft-mask）。权重通过标准梯度下降更新，而掩码则根据特定的更新规则独立演进。
*   **Hessian 引导的重要性估计**：利用二阶 Hessian 信息（通过 Hutchinson 随机估计器实现）来衡量权重被移除后的损失敏感度。这比单纯的权重绝对值（Magnitude）更能准确反映在组内竞争中哪些权重更重要。
*   **渐进式淬火（Progressive Quenching）**：
    *   引入**二元偏好正则项（Binary-preference Regularizer）**，迫使掩码值向 0 或 1 靠近。
    *   通过**结构化混合因子（$\beta$）**和**温度系数（$T$）**的动态调整，平滑地将连续的软掩码引导至符合硬件要求的 2:4 离散模式，减少最终二值化带来的投影误差。
