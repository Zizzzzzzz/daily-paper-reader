## 摘要
长视频理解对于视频大语言模型（VideoLLMs）而言仍具挑战性，因为密集帧采样会引入海量的视觉 token，而稀疏采样则面临丢失关键时间证据并导致大语言模型（LLM）幻觉的风险。现有的无需训练的 token 削减方法要么将视频等同于静态图像处理，要么依赖于片段级的合并启发式方法，这削弱了细粒度的时空建模并引入了额外的开销。在本文中，我们提出了 EchoPrune，这是一种轻量级且无需训练的 token 剪枝方法，旨在固定 LLM 端视觉 token 预算的情况下提高时间分辨率。我们的核心思想是将冗余的视频 token 解释为时间回声：如果一个 token 可以从前一帧很好地重建，则它仅是一个时间上的冗余回声；否则，它可能捕捉到了新的事件、动作或与查询相关的视觉证据。基于这一见解，EchoPrune 通过以下指标为视觉 token 评分：(i) 查询引导的跨模态相关性，以及 (ii) 时间重建误差（通过连续帧之间的对应匹配和回声匹配来衡量）。所选 token 在抑制可预测冗余的同时，保留了任务相关的线索和时间新颖性，使 VideoLLMs 能够在不增加解码预算的情况下观察更多帧。在 LLaVA-OV、Qwen2.5VL 和 Qwen3VL 上针对六个视频理解基准进行的广泛实验表明，EchoPrune 使 VideoLLMs 能够在相同的 token 预算下处理多达 20 倍的帧数，在 Qwen2.5VL-7B 上实现了性能提升（+8.6%）和推理加速（预填充阶段达 5.6 倍）。

## Abstract
Long-form video understanding remains challenging for Video Large Language Models (VideoLLMs), as the dense frame sampling introduces massive visual tokens while sparse sampling risks missing critical temporal evidence and leading to LLM hallucination. Existing training-free token reduction methods either treat videos equally as static images or rely on segment-level merging heuristics, which weaken fine-grained spatiotemporal modeling and introduce additional overhead. In this paper, we propose EchoPrune, a lightweight and training-free token pruning method that improves temporal resolution under a fixed LLM-side visual token budget. Our core idea is to interpret redundant video tokens as temporal echoes: if a token is well reconstructed from the previous frame, it is merely a temporally redundant echo; otherwise, it may capture new events, motion, or query-relevant visual evidence. Based on this insight, EchoPrune scores visual tokens by (i) query-guided crossmodal relevance and (ii) temporal reconstruction error, measured by correspondence matching and echo matching across consecutive frames. The selected tokens preserve task-relevant cues and temporal novelty while suppressing predictable redundancy, allowing VideoLLMs to observe more frames without increasing the decoding budget. Extensive experiments on LLaVA-OV, Qwen2.5VL, and Qwen3VL across six video understanding benchmarks show that EchoPrune enables VideoLLMs to process up to 20x frames under the same token budget, yielding improved performance (+8.6%) and inference speedup (5.6x for prefilling) on Qwen2.5VL-7B.

### 1. 核心问题与整体含义（研究动机和背景）
视频大语言模型（VideoLLMs）在处理长视频时面临**“采样悖论”**：密集采样会导致视觉 Token 数量爆炸，超出 LLM 的上下文窗口并显著增加计算开销；而稀疏采样（如常用的 32 帧采样）则容易丢失关键的时间细节，导致模型产生幻觉。
现有的 Token 削减方法存在以下局限：
*   **通用性方法**：将视频视为静态图像，忽略了时间维度的冗余。
*   **视频专用方法**：依赖复杂的片段级合并或固定启发式规则，计算开销大且容易破坏时间连续性。
**研究动机**：在不增加 LLM 计算负担（固定 Token 预算）的前提下，通过高效剪枝实现更高的时间分辨率（观察更多帧）。

### 2. 方法论：核心思想与关键技术
EchoPrune 的核心思想是将冗余 Token 解释为**“时间回声（Temporal Echoes）”**。如果当前帧的某个 Token 能被前一帧完美预测，它就是冗余的“回声”；反之，则代表新事件或运动。

该方法基于 **最大边际相关性（MMR）** 框架，通过三个维度对 Token 进行评分：
1.  **查询引导的相关性 ($r$)**：计算视觉 Token 与用户文本查询之间的跨模态相似度，确保保留回答问题所需的关键线索。
2.  **对应匹配 ($\delta_{corr}$)**：直接测量相邻帧相同位置 Token 的持久性，用于捕捉空间运动。
3.  **回声匹配 ($\delta_{echo}$)**：通过空间邻域（或全帧）的线性组合来重建当前 Token。重建误差越大，说明该 Token 包含的新信息越多。

**算法流程**：
*   输入多帧视频 Token 和文本查询。
*   计算每个 Token 的相关性得分和时间重建误差（冗余度）。
*   计算 MMR 综合得分：$S = 相关性 - 重建误差$。
*   执行一次性的 **Top-K 排序**，在投影层（Projection Layer）直接筛选出最重要的 Token 喂给 LLM。

*   **实验规模**：论文在 3 个模型家族、5 种不同参数规模（2B 到 8B）以及 6 个不同侧重点的数据集上进行了测试，实验覆盖面广。

### 6. 主要结论与发现
*   **性能提升**：在相同 Token 预算下，EchoPrune 通过处理更多帧（最高 20 倍），在 Qwen2.5VL-7B 上平均提升了 **8.6%** 的准确率。
*   **长视频优势**：在 LVBench 等极长视频基准上表现尤为突出，证明了其捕捉稀疏分布证据的能力。
*   **效率与效果并存**：相比于需要多层合并的方法，EchoPrune 在投影层的一次性剪枝既保证了速度，又通过时空建模维持了高性能。
*   **跨模态协同**：实验发现纯查询引导或纯视觉引导效果均不如二者结合。

### 7. 优点
*   **轻量且免训练**：作为插件模块，无需对预训练模型进行任何微调，易于部署。
*   **可解释性强**：将冗余建模为“回声”符合直觉，可视化结果显示其能精准保留 OCR 文本、动态物体和查询相关目标。
*   **高压缩比下的鲁棒性**：在仅保留 5%-10% Token 的极端压缩情况下，依然能保持甚至超越原始全量 Token 的性能。

### 8. 不足与局限
*   **位置编码限制**：剪枝后的 Token 序列可能会破坏原始的旋转位置编码（RoPE），论文提到未来需要更精细的 RoPE 设计来进一步提升效果。
*   **模态局限**：目前仅关注视觉冗余，未考虑音频模态对视频理解的引导作用。
*   **ViT 加速缺失**：剪枝发生在投影层，这意味着 Vision Encoder（ViT）部分仍需处理全量图像，未实现端到端的视觉编码加速。
