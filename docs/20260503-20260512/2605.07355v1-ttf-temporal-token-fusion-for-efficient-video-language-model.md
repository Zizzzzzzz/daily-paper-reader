## 摘要
随着视觉标记（token）数量随视频长度增加，视频语言模型（VLM）面临着快速增长的推理成本。例如，在 Qwen3-VL 中，448×448 分辨率下的 32 帧视频已产生超过 8,000 个视觉标记，使得大语言模型（LLM）的预填充（prefill）阶段成为主要的吞吐量瓶颈。现有方法通常依赖于全局相似度或注意力引导的压缩，这往往会抵消其带来的收益。我们提出了时间标记融合（Temporal Token Fusion, TTF），这是一种无需训练、即插即用的 LLM 前置标记压缩框架，旨在利用视频中的结构化时间冗余。TTF 自动选择一个锚帧，然后对后续的每一帧执行局部窗口相似度搜索（例如 3×3），并融合超过阈值的标记。压缩后的序列通过坐标重对齐在预填充和解码阶段保持位置一致性，从而实现与现有 VLM 流水线的无缝集成。在阈值 t=0.70 的 Qwen3-VL-8B 上，TTF 移除了约 67% 的视觉标记，同时保留了 99.5% 的基准准确度，且仅引入了约 0.16 GFLOPs 的匹配开销。总的来说，TTF 为视频理解提供了一种实用且高效的解决方案。代码可在 https://github.com/Cominder/ttf 获取。

## Abstract
Video-language models (VLMs) face rapid inference costs as visual token counts scale with video length. For example, 32 frames at $448{\times}448$ resolution already yield >8,000 visual tokens in Qwen3-VL, making LLM prefill the dominant throughput bottleneck. Existing methods often rely on global similarity or attention-guided compression, incurring offsets to their gains. We propose \textbf{Temporal Token Fusion (TTF)}, a training-free, plug-and-play pre-LLM token compression framework that exploits structured temporal redundancy in video. TTF automatically selects an anchor frame, then for each subsequent frame, performs a local window similarity search (e.g.,$3\times 3$), fusing tokens that exceed a threshold. The compressed sequence maintains positional consistency across both prefill and decoding through coordinate realignment, enabling seamless integration with existing VLM pipelines. On Qwen3-VL-8B with threshold t=0.70, TTF removes about 67\% of visual tokens while retaining 99.5\% of the baseline accuracy and introducing only ${\approx}0.16$\,GFLOPs of matching overhead. Overall, TTF offers a practical, efficient solution for video understanding. The code is available at \href{https://github.com/Cominder/ttf}{https://github.com/Cominder/ttf}

### 1. 核心问题与整体含义（研究动机和背景）
随着视频语言模型（VLM）处理的视频长度增加，视觉标记（Token）数量呈爆炸式增长。例如，Qwen3-VL 在处理 32 帧 448×448 分辨率视频时会产生超过 8,000 个 Token。这导致 LLM 的**预填充（Prefill）阶段**成为严重的推理瓶颈，并显著增加了 KV Cache 的内存占用。
*   **现有挑战**：现有的压缩方法要么在 LLM 内部进行（与高效注意力算子不兼容），要么采用全局相似度匹配（计算开销巨大，甚至超过 LLM 本身）。
*   **核心目标**：开发一种**无需训练、即插即用、计算开销极低**的预处理压缩框架，利用视频在时间维度上的结构化冗余来提高效率。

### 2. 方法论：核心思想与关键技术
TTF 的核心思想是利用自然视频中物体运动相对平滑的特性，通过**局部窗口搜索**来识别并融合冗余 Token。

*   **锚帧选择（Anchor Frame Selection）**：自动选择一帧作为参考（通常是与视频全局平均特征最接近的帧），该帧的所有 Token 均被保留。
*   **局部窗口相似度匹配**：对于非锚帧（源帧）中的每个 Token，不再进行全局搜索，而是在锚帧对应的 $r \times r$（默认 3×3）局部邻域内寻找余弦相似度最高的 Token。
*   **阈值门控与融合**：设定阈值 $t$。如果源 Token 与其最佳匹配锚 Token 的相似度超过 $t$，则认为该 Token 是冗余的，将其融合（丢弃）；否则保留。
*   **坐标重对齐（M-RoPE Alignment）**：为了保持 LLM 对空间和时间的感知，TTF 保留了每个存活 Token 的原始三维坐标（帧索引、行、列），并调整解码阶段的偏移量，确保位置编码（RoPE）的一致性，防止输出重复或崩溃。

### 3. 实验设计
*   **数据集/基准测试**：VideoMME（综合评估）、MVBench（动作理解）、MLVU（多任务长视频）、LongVideoBench（长视频理解）。
*   **基准模型**：Qwen3-VL-2B-Instruct 和 Qwen3-VL-8B-Instruct。
*   **对比方法**：FastVID、VisionZip、HoliTom、VidCom 2 等当前主流的视频 Token 压缩方案。

### 4. 资源与算力
*   **硬件环境**：实验在单张 **NVIDIA A100 40GB GPU** 上完成。
*   **计算开销**：TTF 引入的匹配开销极低，仅为约 **0.16 GFLOPs**（对于 32 帧视频），远低于 LLM 的计算量。
*   **训练时长**：由于该方法是**无需训练（Training-free）**的，因此没有训练时长，直接在推理阶段应用。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 4 个主流视频理解基准测试，针对 2B 和 8B 两种规模的模型进行了测试。
*   **消融实验**：详细探讨了相似度阈值 $t$、锚帧选择策略（首帧、末帧、自动选择）以及局部搜索窗口大小（1x1, 3x3, 5x5）对性能的影响。
*   **充分性评价**：实验设计较为充分，不仅对比了准确率，还详细对比了 LLM 延迟、模型总延迟、吞吐量和显存占用，能够客观反映该方法在实际部署中的优势。

### 6. 主要结论与发现
*   **高效压缩**：在 Qwen3-VL-8B 上，TTF 在 $t=0.70$ 时移除了 **67%** 的视觉 Token，吞吐量提升了 **1.34 倍**。
*   **精度保持**：在大幅压缩的情况下，平均精度保留率高达 **99.5%**。在某些情况下（如 VideoMME），压缩后的模型表现甚至略优于原始模型，这表明 TTF 可能具有一定的“去噪”作用，剔除了无关的背景冗余。
*   **局部搜索的有效性**：3×3 的局部搜索窗口在计算成本和捕捉运动冗余之间达到了最佳平衡。

### 7. 优点
*   **极低开销**：将全局匹配的 $O(FN^2C)$ 复杂度降低为局部匹配的线性复杂度 $O(FNC)$，解决了视频压缩算法本身的计算瓶颈。
*   **即插即用**：不需要对模型进行任何微调，适用于现有的各种 VLM 架构。
*   **位置一致性**：通过精细的坐标对齐处理，解决了 Token 减少后可能导致的位置编码错乱问题。

### 8. 不足与局限
*   **超参数敏感性**：阈值 $t$ 需要手动选择。虽然论文讨论了自适应阈值的可能性，但目前尚未实现自动化。
*   **极端运动场景**：对于运动幅度极大（超过 3×3 窗口覆盖范围）的视频，局部搜索可能会失效，导致冗余识别不准确。
*   **模型覆盖**：实验主要集中在 Qwen3-VL 系列，尚未在其他架构（如基于 MoE 的 VLM）上进行大规模验证。
