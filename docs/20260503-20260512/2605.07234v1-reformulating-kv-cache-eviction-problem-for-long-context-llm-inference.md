## 摘要
大语言模型（LLM）支持长上下文推理，但由于键值（KV）缓存的增长，面临着巨大的内存和运行开销。现有的 KV 缓存逐出方法主要依赖于局部注意力权重，忽略了值表示、输出投影以及多头间交互的影响。在本研究中，我们将 KV 缓存逐出从传统的基于多头权重平均的方法，重新定义为一种感知输出的层级矩阵乘法近似问题。我们提出了 LaProx，这是一种新颖的逐出策略，它显式地建模了注意力图与投影后的值状态之间的乘法交互，从而在考虑多头依赖关系的同时，准确量化 Token 的贡献。基于这一指标，我们提出了首个统一的逐出策略，为 Token 分配全局可比的重要性得分，从而实现全模型范围的选择，而非局部的多头决策。在长上下文基准测试 LongBench 和 Needle-In-A-Haystack 的 19 个数据集上的实验结果表明，我们的方法在仅保留 5% KV 缓存的情况下仍能维持模型性能，并在所有配置下始终优于先前的工作。值得注意的是，在极端压缩场景下，与现有的最先进基准方法相比，我们的方法在保持极低开销的同时，实现了高达 2 倍的准确率损失降低。

## Abstract
Large language models (LLMs) support long-context inference but suffer from substantial memory and runtime overhead due to Key-Value (KV) Cache growth. Existing KV Cache eviction methods primarily rely on local attention weights, neglecting the influence of value representations, output projection, and inter-head interactions. In this work, we reformulate KV Cache eviction from a conventional head-wise, weight-averaging approach into an output-aware, layer-wise matrix multiplication approximation problem. We introduce LaProx, a novel eviction strategy that explicitly models the multiplicative interaction between attention maps and projected value states to accurately quantify token contributions while accounting for inter-head dependencies. Building on this metric, we propose the first unified eviction strategy that assigns globally comparable importance scores to tokens, enabling model-wide selection instead of local, head-wise decisions. Experimental results across 19 datasets on long-context benchmarks LongBench and Needle-In-A-Haystack demonstrate that our approach maintains model performance with only 5\% of the KV cache and consistently outperforms prior works across all configurations. Notably, our method achieves up to 2$\times$ accuracy loss reduction under extreme compression scenarios compared to existing state-of-the-art baselines with minimal overhead.

*   **研究背景**：随着 LLM 上下文长度的增加，KV 缓存的大小线性增长，导致内存占用巨大且推理延迟增加。
*   **核心问题**：现有的 KV 缓存逐出方法（如 H2O, SnapKV 等）主要依赖**局部注意力权重（Attention Weights）**作为重要性指标。
*   **研究动机**：作者发现仅靠注意力权重是不够的，因为它忽略了值表示（Value states）、输出投影矩阵（Output Projection）以及多头注意力（MHA）中头与头之间的相互作用。论文旨在将逐出问题从“局部权重平均”转变为“全局输出感知的矩阵近似”问题。

### 2. 方法论：LaProx 核心思想与技术细节
*   **核心思想**：将 KV 缓存逐出建模为一个**矩阵乘法近似问题**。目标是选择一小部分 Token，使得压缩后的注意力输出尽可能接近原始输出 $A \times (V W_O)$。
*   **关键技术细节**：
    1.  **输出感知指标**：不再只看注意力得分 $A$，而是计算 $A$ 的列范数与投影后值状态 $V W_O$ 的行范数的乘积。公式表示为：$p_i \propto \|A[:, i]\|_2 \|V W_O[i, :]\|_2$。
    2.  **层级分解**：利用矩阵乘法的结合律，将多头注意力的输出分解为各头贡献的加和，从而能够评估每个 Token 对最终层输出的实际贡献。
    3.  **全局逐出策略（Global Selection）**：
        *   **跨头比较**：由于引入了 $W_O$，不同头的得分具有了可比性。
        *   **层级归一化**：为了消除不同层之间量级的差异，对每一层的得分进行归一化，使得模型可以在全局范围内（跨头、跨层）动态分配缓存预算。
*   **算法流程**：计算每个 Token 的 LaProx 得分 -> 层内归一化 -> 全局 Top-K 选择 -> 逐出低分 Token。

*   **充分性评价**：实验设计非常充分且客观。作者不仅对比了最终准确率，还通过余弦相似度分析了注意力输出的近似质量，并可视化了不同模型在不同层/头上的缓存分配模式，证明了其动态分配的有效性。

### 6. 主要结论与发现
*   **性能卓越**：LaProx 在仅保留 **5%** 缓存的情况下，性能依然接近 FullKV，且在所有基准测试中持续优于现有的 SOTA 方法。
*   **极端压缩下的鲁棒性**：在极低预算（如 128 或 256 Token）下，LaProx 的准确率损失比其他方法降低了多达 2 倍。
*   **非均匀分布**：实验发现重要 Token 在层和头之间的分布是高度非均匀且随输入动态变化的，这证明了全局动态分配比固定预算分配更合理。

### 7. 优点
*   **理论严谨**：基于矩阵近似理论（Monte Carlo 矩阵乘法近似），而非纯经验性启发式规则。
*   **全局视角**：打破了传统“按头逐出”的局限，首次实现了模型级的统一缓存管理。
*   **无需训练**：作为一种推理时策略，它不需要任何微调或离线校准，具有很强的通用性。
*   **兼容性强**：能够直接应用于标准 Transformer 架构及其变体（如 MoE 模型）。

### 8. 不足与局限
*   **计算开销**：虽然解码速度提升显著，但在预填充阶段计算 $V W_O$ 和范数会引入微小的额外计算开销（尽管论文称其为 marginal）。
*   **归一化方案**：目前的层级归一化方案相对简单，未来可能存在更复杂的跨层重要性对齐方法。
*   **近似精度**：虽然在 5% 缓存下表现良好，但在极极端压缩（如低于 1%）下，任何基于逐出的方法仍可能面临语义丢失的风险。
