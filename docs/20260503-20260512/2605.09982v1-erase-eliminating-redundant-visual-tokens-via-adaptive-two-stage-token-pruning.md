## 摘要
视觉语言模型（VLM）的最新进展使大语言模型（LLM）能够处理高分辨率图像，显著提升了现实世界的多模态理解能力。然而，这种能力引入了大量的视觉 Token，导致了巨大的计算开销。为了缓解这一问题，研究者们提出了多种视觉 Token 剪枝方法。尽管如此，现有方法主要依赖模型内部学习到的语义特征来捕捉视觉冗余。此外，它们缺乏根据输入图像复杂度调整剪枝策略的自适应机制。在本文中，我们提出了 ERASE，这是一个两阶段视觉 Token 剪枝框架，通过适应图像复杂度的剪枝策略来识别并保留显著 Token。实验结果表明，ERASE 在显著减少视觉 Token 的同时保持了准确率。对于 Qwen2.5-VL-7B，在 85% 的 Token 剪枝率下，ERASE 保留了原始模型 89.46% 的准确率，而此前最好的方法仅保留了 78.1%。我们的代码可在 https://github.com/Tuna-Luna/ERASE 获取。

## Abstract
Recent advancements in Vision-Language Models (VLMs) enable large language models (LLMs) to process high-resolution images, significantly improving real-world multimodal understanding. However, this capability introduces a large number of vision tokens, resulting in substantial computational overhead. To mitigate this issue, various vision token pruning methods have been proposed. Nevertheless, existing approaches predominantly rely on learned semantic features within the model to capture visual redundancy. Moreover, they lack adaptive mechanisms to adjust pruning strategies according to the complexity of the input image. In this paper, we propose ERASE, a two-stage vision token pruning framework that identifies and retains salient tokens through pruning strategies adaptive to image complexity. Experiment results demonstrate that ERASE significantly reduces vision tokens while preserving accuracy. For Qwen2.5-VL-7B, at a token pruning ratio of 85\%, ERASE retains 89.46% of the original model accuracy, whereas the best prior method retains only 78.1%. Our code is available at https://github.com/Tuna-Luna/ERASE.

*   **核心问题**：现代视觉语言模型（VLM）为了提升理解能力，开始支持超高分辨率图像，但这导致视觉 Token 数量随分辨率呈平方级增长（如 4K 图像产生约 16K Token）。这带来了巨大的计算延迟、预填充开销和 KV 缓存内存压力。
*   **研究动机**：现有的剪枝方法存在两个主要缺陷：
    1.  **缺乏自适应性**：通常采用固定的剪枝率或固定的剪枝层，无法根据图像本身的复杂度（如简单的天空背景 vs. 复杂的文档表格）动态调整。

### 2. 方法论：ERASE 框架
ERASE 提出了一个**自适应两阶段**视觉 Token 剪枝框架，核心思想是“先去图像冗余，后去上下文无关冗余”。

*   **第一阶段：图像级自适应剪枝（Stage 1）**
    *   **核心思想**：直接在原始图像空间利用**信息熵（Entropy）**衡量图像复杂度。
    *   **技术细节**：将图像划分为补丁（Patch），计算每个补丁的局部熵。全局图像复杂度定义为所有补丁熵的中位数。
    *   **自适应机制**：利用贝叶斯优化（Bayesian Optimization）预先确定不同复杂度等级对应的剪枝阈值。简单图像（低熵）执行更激进的剪枝，复杂图像（高熵）则保留更多 Token。
*   **第二阶段：上下文感知自适应剪枝（Stage 2）**
    *   **核心思想**：在 LLM 解码器内部，根据文本指令保留相关的视觉 Token。
    *   **技术细节**：利用文本到视觉的交叉注意力分数来评估 Token 重要性。
    *   **双层选择机制**：根据第一阶段计算的熵值，动态决定在 LLM 的哪一层进行剪枝。简单图像在较浅层（Early Layer）剪枝以节省计算；复杂图像在较深层（Mid-to-Late Layer）剪枝以保留细粒度推理能力。
*   **KV 缓存回溯**：一旦在第 $k$ 层确定了要删除的 Token，ERASE 会回溯并删除前 $1 \dots k$ 层中对应的 KV 缓存条目。
