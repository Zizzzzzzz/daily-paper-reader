## 摘要
具身智能既需要长时程推理，也需要实时闭环响应。近期的双系统视觉-语言-动作（VLA）架构将快速反应控制与慢速深思熟虑推理相结合，以平衡推理速度与任务成功率。然而，现有的双过程VLA将快速模块与慢速模块的中间表示紧密耦合，需要端到端联合训练，限制了模块化、可扩展性和灵活的系统切换。在本文中，我们提出环境感知模型选择（EMS），一种通过环境感知模型选择在不同规模的两个完全解耦系统之间切换的自适应VLA推理框架。大规模深思熟虑系统提供全局一致的轨迹规划以确保任务成功，而轻量级反应系统实现高频闭环控制。基于强化学习的切换策略根据实时反馈动态选择调用哪个系统，实现慢速系统的稀疏使用，从而平衡预训练知识利用与运行时效率。与先前的层次化VLA框架相比，我们的设计具有三个关键优势：（1）完全解耦且模块化的双系统架构，支持即插即用的模型替换；（2）自适应、环境感知的切换策略；（3）用于响应式闭环控制的高频推理。我们在仿真和真实环境中广泛评估了EMS。在LIBERO基准测试上，EMS在实现与大规模基线相当的成功率的同时，将有效动作频率提高至93.4 Hz。该框架在真实世界双臂操作任务中进一步展示了强大的可扩展性，在保持稳健性能的同时加速了任务完成。

## Abstract
Embodied intelligence demands both long-horizon reasoning and real-time closed-loop responsiveness. Recent dual-system Vision-Language-Action (VLA) architectures combine fast reactive control with slow deliberative reasoning to balance inference speed and task success rate. However, existing dual-process VLAs tightly couple the fast module to intermediate representations of the slow module, necessitating end-to-end joint training and limiting modularity, extensibility and flexible system switching. In this paper, we propose Environment-aware Model Selection (EMS), an adaptive VLA inference framework that switches between two fully decoupled systems of different scales through environment-aware model selection. The large-scale deliberative system provides globally consistent trajectory planning to ensure task success, while a lightweight reactive system enables high-frequency closed-loop control. A reinforcement-learning-based switching policy dynamically selects which system to invoke based on real-time feedback, enabling sparse use of the slow system and thereby balancing pretrained knowledge utilisation with runtime efficiency. Our design offers three key advantages over prior hierarchical VLA frameworks: (1) a fully decoupled and modular dual-system architecture that supports plug-and-play model replacement; (2) an adaptive, environment-aware switching strategy; (3) high-frequency inference for responsive closed-loop control. We extensively evaluate EMS in both simulation and real-world environments. On the LIBERO benchmark, EMS achieves success rates comparable to the large-scale baseline while increasing the effective action frequency to 93.4 Hz. The framework further demonstrates strong extensibility in real-world dual-arm manipulation tasks, where it accelerates task completion while maintaining robust performance.

- **现有方案的问题**：近期双系统（Dual-system）VLA框架（如DP-VLA、FiS-VLA）虽试图平衡快慢系统，但**快模块与慢模块之间存在紧耦合**——快模块依赖慢模块的中间特征表示，必须端到端联合训练，导致：
  - 模块化程度低，难以独立升级或替换单个模块；
  - 无法灵活地按需切换系统；
  - 跨系统协作灵活性受限。
- **核心研究问题**：如何构建一种双系统VLA框架，使其（i）支持即插即用的模型升级而无需昂贵的联合重训练，且（ii）能根据实时环境反馈自适应地选择适当的计算级别，实现响应式实时闭环控制？

## 二、论文提出的方法论

### 1. 核心思想
论文提出 **EMS（Environment-aware Model Selection，环境感知模型选择）** 框架，其核心是让两个**完全解耦**的策略系统仅在**动作层面**交互，并通过一个轻量级强化学习切换模块，基于实时状态动态决定调用哪个系统。

### 2. 系统组成

- **System 2（深思熟虑系统，慢系统）**：
  - 由大规模预训练VLA模型（实验中采用PI0）实例化；
  - 生成时序连贯的动作块（action chunk），用于全局轨迹规划；
  - 推理频率约10 Hz，注重规划可靠性与全局一致性。
- **System 1（反应系统，快系统）**：
  - 轻量级策略模型（实验中采用BCVILT/ACT），支持独立端到端推理；
  - 实现约100 Hz的高频动作生成；
  - 与System 2共享观测空间（RGB图像+语言指令+机器人状态）。
- **切换模块（Lightweight Switching Module）**：
  - 浅层全连接网络实现，输入仅为机器人状态（不含视觉或语言信息）以保证低开销；
  - 输出二值动作：选择快系统（0）或慢系统（1）。

### 3. 问题建模

将系统选择形式化为一个**动作马尔可夫决策过程（MDP）**：

- **状态**：当前机器人状态 s_t；
- **动作**：离散系统选择动作 â_t ∈ {0, 1}；
- **奖励**：任务成功获得 +r，失败获得 −r，并按时间步均匀分配：

   r_t = R_total / T

- **优化目标**：最大化任务成功率，同时稀疏化对慢系统的调用。

### 4. 执行流程（三步循环）

1. **切换决策**：每个决策边界处，切换模块根据当前状态选择要调用的系统；
2. **策略推理**：被选中的系统基于当前观测生成动作（单步或动作块）；
3. **动作执行**：执行动作序列直到下一决策边界。

### 5. 动作融合（Action Fusion）

为消除切换瞬间的控制不连续，在切换边界执行动作融合：

   a_t = (a_fast_t + a_slow_t) / 2

- 慢→快切换：取慢系统已规划块中的重叠动作与快系统的即时推理动作求平均；
- 快→慢切换：快系统再补做一次推理后取平均。

### 6. 三阶段训练管线

| 阶段 | 训练对象 | 数据来源 | 目标 |
|------|----------|----------|------|
| **Stage I** | System 2 | 示教/遥操作轨迹 D_tele | 最大化 log π_slow(a_t|o_t, l) |
| **Stage II** | System 1 | System 2 生成的成功轨迹（轨迹蒸馏）D_distill | 最大化 log π_fast(a_t|o_t, l) |
| **Stage III** | 切换模块 | 在线（DQN）或离线（IQL）强化学习 | 学习最优切换策略 |

- **在线训练（DQN增强版）** ：采用Double Q-learning降低过估计偏差，Prioritized Experience Replay提高样本效率，Dueling网络架构稳定值估计，NoisyNet实现自适应探索。
- **离线训练（IQL）** ：采用Implicit Q-Learning避免外推误差，通过期望回归学习值函数，结合优势加权行为克隆隐式推导策略，适用于真实场景中无法大量在线交互的情况。

## 六、论文的主要结论与发现

1. **EMS在LIBERO上实现高成功率与高频率兼具**：
