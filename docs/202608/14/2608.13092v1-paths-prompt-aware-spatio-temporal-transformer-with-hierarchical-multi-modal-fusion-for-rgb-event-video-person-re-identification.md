## 摘要
RGB-事件视频行人重识别（RE-VReID）旨在利用互补的RGB视频和事件流，在非重叠摄像头下检索特定行人。然而，现有方法通常将空间和时间建模解耦，限制了它们的交互。此外，全局级别的RGB-事件融合未能充分利用细粒度的判别线索。为解决这些问题，我们提出了Paths，一个用于RE-VReID的统一框架，具有时空建模和层次化多模态融合。具体而言，我们首先设计了一个记忆增强骨干网络（MAB），以维护模态特定的身份原型，实现稳定的模态内表示学习。然后，我们提出了一个提示感知的时空Transformer（PST），在统一的Transformer中联合建模空间和时间线索。最后，我们引入了一个层次化多模态融合模块（HMF），在全局和局部层面整合RGB和事件特征。通过这些模块，我们的框架能够为RE-VReID学习鲁棒且具有判别性的表示。在包括EvReID、MARS和iLIDS-VID在内的三个公开RE-VReID基准上的大量实验证明了我们方法的有效性。代码可在 https://github.com/Reflection0427/Paths 获取。

## Abstract
RGB-Event Video Person Re-Identification (RE-VReID) aims to retrieve specific person across non-overlapping cameras with complementary RGB videos and event streams. However, existing methods often decouple spatial and temporal modeling, which limits their interaction. In addition, global-level RGB-Event fusion fails to fully exploit fine-grained discriminative cues. To address these issues, we propose Paths, a unified framework with spatio-temporal modeling and hierarchical multi-modal fusion for RE-VReID. Specifically, we first design a Memory-Augmented Backbone (MAB) to maintain modality-specific identity prototypes for stable intra-modal representation learning. Then, we propose a Prompt-aware Spatio-temporal Transformer (PST) to jointly model spatial and temporal cues within a unified Transformer. Finally, we introduce a Hierarchical Multi-modal Fusion (HMF) to integrate RGB and event features at global and local levels. With these modules, our framework can learn robust and discriminative representations for RE-VReID. Extensive experiments on three public RE-VReID benchmarks including EvReID, MARS and iLIDS-VID, demonstrate the effectiveness of our proposed method. The code is available at https://github.com/Reflection0427/Paths.

## 1. 核心问题与整体含义

- **任务背景**：视频行人重识别（VReID）在智能监控和多媒体检索中至关重要；RGB 视频存在帧率固定、帧间冗余高等问题，而事件相机能异步捕捉亮度变化，提供对运动敏感的互补信息，因此 RGB-Event 视频行人重识别（RE-VReID）受到关注。
- **现有局限**：
  - 多数方法将空间特征提取与时间建模**解耦成两个独立阶段**，限制了空间语义与时间动态之间的交互。
  - 跨模态融合通常只在**全局/视频级**进行（如时间池化后融合），忽略了 RGB 与事件流之间细粒度的空间错位和模态差异。
- **本文目标**：提出统一框架 **Paths**，在同一个 Transformer 内联合建模空间与时间线索，并在全局和局部层级实现 RGB-Event 融合，从而学习鲁棒、有判别力的身份表示。

## 2. 方法论

- **总体架构**：Paths 由三个核心组件构成：Memory-Augmented Backbone (MAB)、Prompt-aware Spatio-temporal Transformer (PST)、Hierarchical Multi-modal Fusion (HMF)。
- **MAB（记忆增强骨干）**：
  - 使用视觉编码器提取每帧的 class token 和 patch token，并利用时间平均池化获得视频级序列表示。
  - 为每个身份维护**模态特定的原型记忆**，训练前用预训练编码器初始化，训练中通过动量更新当前 batch 的样本中心。
  - 引入**原型对比损失**，使序列表示拉近正确身份原型、远离其他原型，增强跨 batch 监督稳定性。
- **PST（提示感知时空 Transformer）**：
  - 为每帧在每个 Transformer 层引入 G 个可学习**时间提示 token**，与 class/patch token 一起参与自注意力，使时间信息直接参与空间表示学习。
  - **TPS（Temporal Prompt Shuffle）**：通过 reshape、permute、reshape 重组提示 token 的组间结构，促进不同时间跨度信息混合。
  - **BTS（Bidirectional Temporal Shift）**：将提示分成前向/后向两组，分别从上一帧/下一帧平移后再拼接，实现双向跨帧信息传播。
  - 该设计让空间和时间建模在统一骨干中完成，无需额外的时间编码器。
- **HMF（层次化多模态融合）**：
  - **GGF（全局图融合）**：将 RGB/Event 各帧特征作为图节点，对每个查询节点动态选择 Top-K 个模态内和模态间邻居，构造局部图；用多头注意力聚合得到增强节点表示，最后平均生成全局特征。
  - **LTF（局部令牌融合）**：对 patch token 做时间平均池化，以余弦相似度构造代价矩阵，用匈牙利算法求解最优一对一匹配；引入**跨模态对齐损失**促进匹配；再用自适应门控（Sigmoid）融合匹配的 token 对，最后通过可学习 pooling query 聚合得到局部特征。
- **目标函数**：总损失 = 交叉熵损失 + 三元组损失 + λ₁·原型对比损失 + λ₂·跨模态对齐损失。

## 8. 不足与潜在问题
