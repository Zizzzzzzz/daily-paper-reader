## 摘要
鲁棒的机器人控制受益于显式地对状态转换进行建模，但视频生成世界动作模型（WAMs）会带来巨大的部署成本。现有的潜在世界动作模型避免了显式的未来生成，但常常压缩预测表示，或将预测建模与用于动作生成的表示分开。我们提出了 JEPA-WAM，一种构建在预训练 V-JEPA 空间中的潜在世界动作模型，通过共享预测器将潜在转换预测与连续动作生成耦合起来。JEPA-WAM 预测一个空间结构化的当前-未来联合目标，该目标捕获当前与未来观测之间任务共享的视觉时间结构，同时保留密集的补丁级对应关系。通过共享预测器，转换监督直接塑造骨干网络，从中提取用于动作预测的专用表示。相同的设计也可以实例化到预训练的 VLA 策略中，同时保留其原有的感知和动作路径。在 LIBERO-Plus 上，JEPA-WAM 达到了 79.2%，这是没有大规模机器人策略预训练的最佳结果，而其预训练的 $π_{0.5}$ 实例达到了 86.3%，实现了最佳整体性能。在 RoboTwin 2.0 和真实世界双臂操作上的实验进一步证明了在视觉和空间变化下的强泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

- 本文提出 JEPA-WAM，一种构建在预训练 V-JEPA 表示空间中的潜在世界动作模型，通过**共享预测器**将潜在转换预测与连续动作生成耦合，既避免了视频生成的部署开销，又让转换监督直接塑造动作生成所依赖的策略骨干。

## 2. 论文提出的方法论

**核心思想**：在预训练 V-JEPA 2.1 表示空间中构建世界模型——用 V-JEPA 表示当前视觉状态和联合当前-未来转换目标，并用同一个共享预测器同时完成潜在转换预测和动作条件表示提取。

**关键技术细节**：

1. **V-JEPA 表示空间与联合当前-未来目标**：
   - 冻结的 V-JEPA 2.1 编码器对每个相机视角独立编码，生成密集的 patch 级表示（而非全局池化），并按固定相机顺序拼接：$Z_t = \text{Concat}_{v \in V} E_J(O_t^v)$。
   - 训练时，将当前观测 $O_t^v$ 与 $\delta$ 步之后的未来观测 $O_{t+\delta}^v$ 沿时间维堆叠，用冻结的 V-JEPA 联合编码，得到联合目标 $Y_{t,t+\delta}$。由于 V-JEPA 的时间 tubelet 大小为 2，两帧输入产生与单帧相同的空间 token 网格，从而保持 patch 级对应。
   - 联合目标强调两个时间端点之间的**视觉时间关系**（哪些区域稳定、哪些变化、局部物体与空间关系如何演化），而非重构唯一的未来观测。

2. **共享预测器**：
   - 以 Qwen2.5-0.5B 作为共享预测器 $F_\theta$，处理投影后的视觉 token、任务指令和专用动作占位符（action placeholders），输出两路表示：视觉 token 位置的隐藏状态 $Q_t^{wm}$（用于转换预测）和动作占位符输出的专用表示 $C_t$（用于动作生成）。

3. **潜在转换预测**：
   - 轻量预测头 $G_\phi$ 将 $Q_t^{wm}$ 映射回 V-JEPA 空间：$\hat{Y}_{t,t+\delta} = G_\phi(Q_t^{wm})$。
   - 损失为 patch 级余弦距离：$L_{wm} = \frac{1}{BN_{vis}} \sum_{b,n} \left(1 - \cos(\hat{Y}^{(b)}_{t,t+\delta,n}, Y^{(b)}_{t,t+\delta,n})\right)$。

4. **动作生成**：
   - DiT 动作专家基于条件流匹配（conditional flow matching），LIBERO 上使用速度预测目标，RoboTwin 2.0 上使用 x-prediction：$L_{act} = \mathbb{E}_{\epsilon,\tau}\left[\|A_\psi(a_\tau, \tau, s_t, C_t) - (a-\epsilon)\|_2^2\right]$。
   - 总损失：$L = L_{act} + \lambda_{wm} L_{wm}$，其中 $\lambda_{wm} = 0.5$。

5. **部署**：仅需当前观测和语言指令，移除目标分支和预测头，推理开销与普通 VLA 策略相当（85ms/次）。

6. **迁移到预训练 VLA 策略**：向 π0.5 的 VLM 前缀添加 64 个可学习的 future tokens，将其隐藏状态重塑为粗特征图，经轻量投影和双线性上采样后与冻结的 V-JEPA 联合目标做 patch 级对齐；原始感知和动作路径保持不变。

2. **训练资源披露不足**：论文未提供 GPU 型号、总训练耗时、功耗等关键资源信息，也缺少真实世界实验与 RoboTwin 实验的完整训练配置。对于强调“部署高效”的工作而言，训练成本同样是实际落地的重要考量，这一信息的缺失削弱了可复现性和工程参考价值。

3. **真实世界评估规模有限**：5 个任务、每任务 100 条演示、各 10 次 rollout 的规模在同类工作中属于中等偏小，且任务均为桌面级短时程操作（面包/水果/积木/抽屉），未覆盖长时程多阶段、精密装配或动态扰动场景，结论的外推能力有待更大规模、更长时程的真实实验验证。

4. **与大规模预训练方法的比较存在不公平风险**：论文将 π0、π0.5、Being-H0.7 等归类为“有预训练组”，但这些模型使用了数万条跨域演示甚至互联网级数据进行预训练，而 JEPA-WAM 仅使用 LIBERO/RoboTwin 任务内数据。虽然分组报告缓解了这一差异，但直接将 79.2% 与 π0.5 的 84.5% 对比时，读者容易忽略训练数据量级的不对称。论文也未能与同等规模数据预算下使用视频生成式 WAM 的方法做成本-性能联合对比。

5. **对冻结 V-JEPA 特征的依赖**：V-JEPA 2.1 在视觉细节（如小型物体的精确形状与表面纹理）上可能损失高频信息，而机器人操作往往依赖精确几何与接触信息。论文未定量评估 V-JEPA 表示在上述场景中的信息瓶颈，也未提供与自适应微调编码器的对比实验，因此“冻结表示足够支撑精细操作”这一前提仍缺乏直接证据。

6. **与视频生成式 WAM 的对比缺失**：论文在动机上强调视频生成式 WAM 的推理开销问题，但实验部分并未直接对比同数据预算下视频生成式 WAM 的 ID/OOD 性能与推理时延。缺少这一对照，无法量化“潜在世界模型相对显式世界模型在泛化能力上的实际折扣”，削弱了论文对潜在 WAM 范式优势的核心论证。

## 9. 总体评述

JEPA-WAM 的核心贡献在于将联合嵌入预测这一自监督学习范式引入机器人策略的动作条件化过程，并用共享预测器这一简洁而精巧的设计完成了“预测-控制”两条路径的耦合。它既不是对已有潜在 WAM 的简单修补，也不是将 V-JEPA 粗糙地拼接到策略之上，而是重新设计了转换目标的构造方式（联合当前-未来编码）、监督粒度（patch 级）与监督位置（最终隐藏状态），使世界模型信号能够直接塑造动作生成所依赖的表征。这一思路在 LIBERO-Plus、RoboTwin 2.0 和真实世界的多个指标上均带来了显著且一致的提升，且迁移实验表明该方法可以成为预训练 VLA 策略的一种“即插即用”的增强模块。

不过，该工作的局限也与其优势同源：对 V-JEPA 的依赖使得表征上限受制于预训练模型的质量，对语言条件行为差异的建模仍显薄弱，真实世界验证的规模仍不足以完全支撑其泛化主张。未来值得探索的方向包括：将转换目标对指令进行显式条件化、在动作空间中引入更细粒度的物理状态监督（如力/触觉）、以及在更大规模多任务数据上验证方法的可扩展性。
