## 摘要
长视频多模态大语言模型（MLLMs）必须在有限的视觉token预算移除大部分帧证据之前建模时间变化。我们提出了LongVU-TTT，在视觉编码器和LLM之间插入一个带有因果快速权重更新的卷积测试时训练（TTT）重采样器。其分组2D快速权重适应每个视频，并在压缩前对帧特征进行上下文化处理，同时一个混合的均匀与变化感知选择器为下游推理保留显式视觉证据。在受控条件下，TTT-Conv在MLVU上比TTT-MLP最高提升+2.12，比双向Mamba2最高提升+3.04，并且在三个基准测试上均优于基于注意力和固定状态循环的重采样器。分析表明，快速权重表现为时间聚合状态，而非可靠的长期情节记忆：其益处随着证据变得遥远而减弱，这促使显式帧保留。LongVU-TTT在将帧数减少至128个LLM帧之前最多处理512帧，并在五个视频理解基准测试上取得了具有竞争力的性能。

## Abstract
Long-video MLLMs must model temporal change before a limited visual-token budget removes most frame evidence. We introduce LongVU-TTT, which inserts a convolutional Test-Time Training (TTT) resampler with causal fast-weight updates between the vision encoder and the LLM. Its grouped 2D fast weights adapt to each video and contextualize frame features before compression, while a hybrid uniform-and-change-aware selector retains explicit visual evidence for downstream reasoning. Under controlled conditions, TTT-Conv improves over TTT-MLP by up to +2.12 and bidirectional Mamba2 by up to +3.04 on MLVU, and it is stronger than attention- and fixed-state recurrent resamplers across three benchmarks. Analysis shows that the fast weights behave as a temporal aggregation state rather than a reliable long-horizon episodic memory: their benefit attenuates as evidence becomes more distant, motivating explicit frame retention. LongVU-TTT processes up to 512 frames before reducing them to 128 LLM frames and achieves competitive performance across five video understanding benchmarks.

# LongVU-TTT: 面向长视频理解中视觉重采样的因果测试时训练

## 1. 核心问题与研究动机

- **问题背景**：长视频多模态大语言模型（MLLMs）面临的核心矛盾是——视频越长，视觉 token 数量线性增长，而 LLM 的二次复杂度注意力使长序列计算成本过高。为此需要将视觉信息压缩到有限的 token 预算内，但**在压缩之前，必须对视频内的时间变化进行建模**，否则大部分帧证据会在进入 LLM 之前就丢失。
- **现有方法不足**：现有压缩策略（如 token 合并、差分 token 丢弃、DINOv2 冗余帧识别等）大多**直接对原始帧级特征进行压缩，而未先建模帧间变化**，缺乏对“什么变了”的原则性理解。另一方面，循环架构（如 SSM）虽能进行时间传播，但其扁平化序列算子**缺乏 2D 局部邻域交互**，难以补充 ViT 的全局表征。
- **核心研究问题**：能否在投影器（projector）阶段引入一种可适应视频内容的循环算子，既能建模时间变化，又能为压缩提供自然的帧重要性信号？

## 2. 方法论

### 2.1 整体架构

LongVU-TTT 在视觉编码器（ViT）与 LLM 之间插入一个**卷积测试时训练（TTT）重采样器**，其结构如下：

```
视频帧 → ViT 编码器 → TTT-Conv 时间层（快速权重循环） → 空间池化 → 基于重要性的帧选择（512→128） → MLP 投影器 → LLM
```

TTT-Conv 层以残差形式包在 RMSNorm 之后：
**X_out = X + TTT-Conv(RMSNorm(X))**

### 2.2 TTT-Conv 快速权重参数化

- 与先前 TTT 工作中使用 MLP 作为快速权重不同，本文将快速权重参数化为**分组 2D 卷积核**：W₁ ∈ R^(Ng·Dint×d×K×K)（下投影）和 W₂ ∈ R^(C×Dint×K×K)（上投影），直接在帧特征的 2D 空间结构上操作。
- 使用 N_g = 4 个通道组，中间扩展因子为 4，卷积核大小 K = 3。每帧通过线性头产生 key k_t、value v_t、query q_t、每分组学习率 lr_t 和动量系数 m_t。

### 2.3 内循环更新规则

- **自监督对齐目标**：L(k_t, v_t) = −⟨f_W(k_t), v_t⟩，最小化该损失来更新快速权重。
- **因果更新顺序**：第 t 帧的权重状态 W_t 只包含前 t−1 帧的更新，不包含当前帧自身（W_t = W_init + Σ_{i=1}^{t−1} δ_i），即“因果快速权重更新”。
- **并行因果物化**：通过 torch.vmap 和前缀和（prefix-sum）操作，所有帧的权重状态在块内可并行物化，避免真实串行循环，然后逐帧并行应用卷积。
- **跨块状态传递**：块大小为 8 帧，块边界处将最终动量调整增量 p_init 和权重状态传播至下一块，维持整个视频的时间连续性。

### 2.4 显著性驱动的混合帧采样

从 TTT 内部梯度信号中提取两种互补的重要性指标，无需额外的学习评分器：

- **Gradient-Direction Shift（G_t）**：相邻帧快速权重梯度的余弦距离，捕捉**场景级突变**（如镜头切换）；
- **Alignment-Loss Delta（R_t）**：相邻帧对齐损失的正增量，捕捉**场景内的持续变化**（如新物体出现）。
- 两者经 min-max 归一化后加权组合为最终重要性分数：**I_t = α·G_t + (1−α)·R_t**（α=0.4）。
- **混合降采样策略**：先从全部帧中选取 top-k 高重要性帧（Highlight Set），再从剩余帧中均匀抽样补齐至固定预算 N_sel=128。这样既保留显著变化帧，又维持均匀时间覆盖。

### 2.5 系统优化

- **Batch-Tiled ViT 处理**：将 ViT 帧批拆分为 8 个 tile，推迟 ZeRO-3 梯度 reduce-scatter 至最后一个 tile，消除重复节点间通信。
- **异步 CPU 激活卸载**：将 LLM 层的激活通过专用 CUDA 流异步卸载至 CPU 内存，再在后向传播中按需预取，将最大可训练帧数从 64 扩展到 256（4×）。
- 两项优化组合使 256 帧训练在 40GB GPU 上变得可行，无需序列并行机制。

## 6. 主要结论与发现

- **因果 2D 卷积快速权重是有效的时序算子**：TTT-Conv 在三个基准上全面优于 TTT-MLP、双向 Mamba2、Gated DeltaNet、Temporal Transformer，以及双向 Mamba2。在 MLVU 上，比 TTT-MLP 高 +2.12，比双向 Mamba2 高 +3.04。
- **因果更新顺序比非因果更好**：TTT-Conv（因果）比 TTT-Conv（非因果）提高约 4 个点；TTT-MLP 因果比非因果提升 1.0 个点，说明**因果快速权重更新是重要的设计选择**。
- **2D 局部性比 1D 扁平化更优**：TTT-Conv 优于 TTT-MLP（同因果），且打乱网格的控制实验会降低性能，说明 2D 局部邻域结构确实有效。
- **快速权重是“时间聚合器”而非“情节记忆”**：证据扣留实验表明——当省略的证据靠近问题时间戳时（0–25% 和 25–50% 区间），状态传递能显著恢复信息；但超过一半视频长度后，恢复能力衰减至接近无时序层基线（48.66 对比 48.31），而显式证据始终有益（53.11）。这说明**长期情节记忆不能依赖快速权重，必须通过显式帧选择来保留证据**。
- **混合选择策略优于单一信号**：G_t 捕捉场景突变，R_t 捕捉场景内变化，两者加权组合效果最好（71.80 MLVU），优于纯均匀（70.63）或任一单独信号。
- **系统优化有效**：异步 CPU 卸载将最大可训练帧数提升 4×（64→256），batch-tiled ViT 在 64 GPU 上加速 2.23×，且保留 87% 吞吐量缩放效率。

## 7. 优点

- **方法设计巧妙**：
  - 将 TTT 的快速权重从 MLP 推广到分组卷积，在保持参数效率的同时，显式利用 2D 空间局部性，填补了 TTT 文献中缺失的视觉结构先验；
  - 从 TTT 内循环自然产生帧重要性信号，无需额外学习评分器，很好地利用了梯度信号的语义。
- **实验控制严谨**：所有时序算子对比在相同插入位置、相同数据、相同预算下进行，保证了架构比较的公平性；机制消融（静态卷积、逐帧重置、逐块重置、1×1 核、打乱网格）逻辑完整，能清晰归属性能增益来源。
- **诊断实验具有理论价值**：证据扣留实验直接回答了“快速权重是否可替代显式记忆”这一关键问题，有助于理解循环模型的记忆机制边界，也为后续混合架构设计提供指导。
- **系统贡献务实**：batch-tiled ViT + 异步 CPU 卸载是通用优化策略，可与其他序列并行方案组合，有推广价值。

## 8. 不足与局限

- **推理延迟较高**：TTT-Conv 的投影器延迟在 512 帧时为 993ms，比 TTT-MLP（185ms）慢约 5.4 倍，比 Gated DeltaNet（109ms）慢约 9 倍，虽然远快于时间 Transformer（13.7s），但对实时/交互式应用可能有压力。论文承认了这一点，并指出时序丰富化只发生在更昂贵的 LLM 阶段前一次。
- **实验条件与泛化性受限**：
  - 受控实验只用 30% 的混合数据，完整模型的消融验证尚显不足；
  - 消融实验只覆盖 MLVU、LongVideoBench、Video-MME 三个基准，NExT-QA 和 LVBench 未纳入受控研究；
  - 统计显著性未报告（无多次运行方差），无法判断观测差异是随机波动还是系统性差距。
- **数据源单一性**：训练数据仅来自 LLaVA-Video-178K 和 LLaVA-OneVision，基础模型为 LLaVA-Video（Qwen2-7B），结论对于更大模型（如 72B）或不同视觉编码器（如 SigLIP）的迁移性未验证。
- **证据窗口的长期记忆局限**：论文通过诊断实验诚实承认了快速权重状态在远距离证据上的记忆衰减——超过视频一半距离后基本失效。这提示目前的方法可能仍不适用于跨数小时视频的跨场景推理，也说明研究者仍需在长距离记忆机制上继续探索。
- **帧选择策略的代价**：混合选择需要在全视频处理完成后才能执行（需要所有帧的分数），因而是**离线**的，无法直接支持流式推理场景。这与一些在线处理视频的模型不同。
- **超长输入（>512 帧）的扩展性未充分验证**：虽然论文测试了 1024 帧的推理延迟，但训练和性能评估最多只到 512 帧；对更极端长度（如 1 小时以上的视频）的效果未知。
