## 摘要
键值（KV）缓存存储来自过去令牌的信息，是长上下文推理中的主要内存瓶颈。现有的量化方法通过以较低精度的数据类型统一表示KV缓存，并设计量化方案以最小化缓存本身的重建误差来解决这一瓶颈，而未考虑该误差如何通过注意力机制传播。我们证明，在白噪声量化模型下，期望的注意力感知失真可分解为加性的键和值贡献，这些贡献在令牌和通道间可分解。基于变换编码和逆向注水法——这些是信号处理与率失真理论中的经典工具——我们引入了注意力感知变换编码（AATC），该方法在标定集上分配比特以最小化注意力感知失真。在Llama-3.1-8B-Instruct和Qwen-2.5-7B-Instruct上，结合LongBench、RULER、GSM8K、MMLU-Pro和MATH-500的评估，我们的方法在约5.8倍压缩下实现了接近无损的准确率，而每个基线至少在部分设置中性能下降。

## Abstract
The key-value (KV) cache stores information from past tokens and is a major memory bottleneck in long-context inference. Existing quantization methods address this bottleneck by representing the KV cache uniformly with lower-precision data types and designing quantization schemes to minimize reconstruction error in the cache itself, without accounting for how that error propagates through attention mechanisms. We prove that, under a white-noise quantization model, the expected attention-aware distortion decomposes into additive key and value contributions that factor across tokens and channels. Building on transform coding and reverse water-filling, which are classical tools from signal processing and rate-distortion theory, we introduce Attention-Aware Transform Coding (AATC), which allocates bits over a calibration set to minimize attention-aware distortion. On Llama-3.1-8B-Instruct and Qwen-2.5-7B-Instruct, evaluated across LongBench, RULER, GSM8K, MMLU-Pro, and MATH-500, our method achieves near-lossless accuracy at approximately $5.8\times$ compression, whereas each baseline degrades in at least some settings.

## 1. 核心问题与整体含义（研究动机与背景）

长上下文推理中，KV（键值）缓存随着上下文长度线性增长，成为部署大语言模型时的主要内存瓶颈。现有KV缓存量化方法（如 KIVI、KVQuant）的基本思路是：用较低精度统一表示缓存、最小化缓存自身的重建误差，但它们**完全没有考虑量化误差通过注意力机制传播后对最终输出的影响**。

论文从信号处理与率失真理论的经典框架——**变换编码（Transform Coding）** 与**逆向注水（Reverse Water-filling）** 出发，系统地为KV缓存压缩建立了理论视角：

- 证明了在白噪声量化模型下，**注意力输出的期望失真可严格分解为加性的键贡献与值贡献**，且两者在令牌维度和通道维度均可分离；
- 揭示了已有方法中看似独立的维度（token级驱逐、查询感知量化、通道敏感度加权、输出投影感知等）实际上是**同一个失真目标函数的不同侧面**；
- 基于该失真分解，提出了 **AATC（Attention-Aware Transform Coding）**，通过白化变换+注意力感知逆向注水分配比特，在固定比特预算下直接最小化注意力输出失真。

整体含义：这项工作将经典率失真理论引入KV缓存压缩，既显著提升了压缩性能（5.8×压缩下近无损），也为后续研究提供了统一的理论坐标系。

## 2. 方法论

### 2.1 核心思想

最小化注意力输出的期望平方误差（而非KV缓存本身的重建误差），利用定理1将失真分解，并通过变换编码的方式在通道间分配比特预算。

### 2.2 关键公式：注意力感知失真分解（定理1）

\[
D = E[\|o-\hat{o}\|^2] = D_K + D_V + R
\]

其中：

- \(D_K = \sum_{i,c} a_i^2 \|v_iW_O-o\|^2 q_c^2 E[(\delta k_{ic})^2]\) —— 键误差的贡献，受注意力权重 \(a_i^2\)、输出残差 \(\|v_iW_O-o\|^2\) 和查询分量 \(q_c^2\) 的加权；
- \(D_V = \sum_{i,c} a_i^2 E[(\delta v_{ic})^2]\|W_{Oc}\|_F^2\) —— 值误差的贡献，受 \(a_i^2\) 和输出投影行范数 \(\|W_{Oc}\|_F^2\) 的加权；
- \(R\) 为高阶余项，在量化噪声较小时可忽略。

该分解满足：token相关权重与channel相关权重分离，键和值的量化可独立处理。

### 2.3 算法流程（AATC）

**离线标定阶段（每个模型只做一次）：**

1. 对每个层，计算校准激活的输入协方差 \(\Sigma_X\)，做 Cholesky 分解 \(\Sigma_X=LL^\top\)；
2. 对投影矩阵 \(W\)（键或值）做白化 SVD：\(\tilde{W}=L^\top W = USP^\top\)，得到因子分解 \(W=AB\)（其中 \(A=L^{-\top}U\sqrt{S}, B=\sqrt{S}P^\top\)）；
3. 在变换后空间中计算各通道的方差 \(\sigma^2_{\ell,c}\)（与奇异值相关）；
4. 计算键通道权重 \(w^{(K)}_{\ell,c} = \frac{1}{T}\sum_i ((B^K_{\ell,c})^\top q^{(i,\ell,c)})^2\)，值通道权重 \(w^{(V)}_{\ell,c} = \|(B^V W_O)^\top_{\ell,c}\|_F^2\)；
5. 通过**加权逆向注水**在全局（跨所有层）分配键与值各自的比特预算：
   \[
   \min_{\{b_{\ell,c}\}} \sum_{\ell,c} w_{\ell,c}(\sigma_{\ell,c})^2 2^{-2b_{\ell,c}},\quad \text{s.t.}\ \sum b_{\ell,c}\le B
   \]
   得到闭式解：\(b^*_{\ell,c}=\frac{1}{2}\log_2(w_{\ell,c}\sigma^2_{\ell,c}/\lambda)\)（低于水位的通道分配0比特，等效于秩缩减）。

**在线推理阶段：**

6. 新 token 投影到变换空间：\(h^K_t = x_t A_K,\ h^V_t = x_t A_V\)；
7. 用 token 级缩放（基于 99 百分位通道尺度和 token 最大偏移的乘积）进行均匀标量量化；
8. 重构时反变换：\(K_i=\hat{h}^K_i B_K,\ V_i=\hat{h}^V_i B_V\)；
9. 正常计算注意力输出。

### 2.4 关键工程细节

- 键和值使用**独立的比特预算** \(B_K\) 与 \(B_V\)；
- 保留前4个token和最近128个token窗口为全精度（窗口满时每次量化最旧的16个token）；
- 前3层给予保护性比特分配（keys多1比特，values给平均值）；
- GQA设置下按head-group计算token缩放。

## 6. 主要结论与发现

1. **AATC在约5.8×压缩下实现近无损**：在18个结果单元格中（2模型×9项指标），AATC始终在FP16的2σ误差范围内，没有统计显著退化；对比之下，KIVI在Qwen的LongBench上暴跌至0.351，PALU在代码任务上严重退化，KVQuant在RULER长上下文上显著下降。
2. **注意力感知权重的价值在高压缩率下凸显**：在2.5-bit时AATC与var-only差异不大，但在2-bit时var-only在长上下文（16k-32k）下明显退化，而完整AATC保持接近基线水平。这证明 \(q_c^2\) 和 \(W_{Oc}\) 项确实捕捉到了对输出有意义的通道重要性。
3. **模型对压缩的鲁棒性差异显著**：Qwen-2.5-7B比Llama-3.1-8B更难压缩（KIVI在Qwen上严重失效），而AATC在两种模型上都保持稳定，说明其方法泛化性较好。
4. **AATC在极端低比特下仍保持优异性**：在1-bit（约12.4×压缩）时，AATC在LongBench上得分为0.325，而KIVI仅0.202；GSM8K上0.497对0.026，退化方式更温和。
5. **共性发现**：PALU的退化集中在代码补全和检索类任务，证实低秩截断损失了细粒度的token级信息；全局（跨层统一）比特分配相比per-channel分配在LongBench上损失8.6个点，说明逐通道分配的适应性至关重要。

## 7. 优点

1. **理论贡献坚实**：定理1的证明完整、严谨，将量化误差对注意力输出的影响分解为token依赖和通道依赖的显式权重，这是目前KV压缩文献中较为深入的失真分析；
2. **统一视角**：将已有方法的直觉（驱逐、查询感知、敏感度加权、输出投影感知）映射到单一失真分解中，有很强的解释性和启发性；
3. **算法与理论闭环**：从定理1推导出的权重在实验中确实带来了性能提升（尤其在2-bit下），形成从理论到实践的完整链条；
4. **方法优雅、实用**：变换和比特分配全部通过一次离线标定完成，推理时只有矩阵乘法和量化开销；变换是可逆的（正交），不引入额外训练，与现有多头/分组注意力架构兼容；
5. **实验透明度较高**：提供了逐子任务的细粒度结果、比特预算扫掠、消融实验，并在附录中详细说明了每个基线方法的复现设置，可复现性好。

## 8. 不足与局限

1. **理论假设的理想化**：Assumption 1（白噪声、跨token独立）在真实文本中并不严格成立（相邻token的KV表示相关），论文也承认了这一限制，但未给出对相关性鲁棒性的定量刻画或更弱假设下的理论保证；
2. **实现未系统优化**：没有专门CUDA kernel，实际吞吐量/延迟收益未测，与生产部署仍有距离；
3. **模型覆盖范围有限**：仅验证了8B/7B规模的两种模型，对更大规模模型（如70B+）或不同架构（如DeepSeek的MLA）的泛化性未知；
4. **实验设置的公平性存在细微问题**：各方法的压缩率并不完全一致（5.0× vs 5.39× vs 5.91× vs 5.82×）；此外，所有方法均附加了近端token全精度窗口（128个token），这部分开销在短上下文场景中的占比会更大，实际内存节省率在短上下文下会低于标称压缩比；
5. **标定数据的选择影响结果**：消融显示校准集从FineWeb+OpenR1混合改为只用FineWeb时性能下降1.9个点，提示方法对标定数据的分布有一定敏感性，实际应用中需要仔细选择合适的标定语料；
6. **在线自适应能力缺失**：比特分配是离线固定不变的，无法感知推理时实际查询的注意力权重分布变化；论文将token级分配留给未来工作，但静态分配在分布外输入上可能表现不佳。
