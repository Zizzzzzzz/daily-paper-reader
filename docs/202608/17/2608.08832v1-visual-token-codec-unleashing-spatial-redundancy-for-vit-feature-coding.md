## 摘要
大型视觉基础模型的分布式部署通常会将 ViT 骨干网络分割，并在计算节点之间交换中间令牌特征，这使得在带宽和计算约束下进行高效的特征压缩变得至关重要。现有的 ViT 特征编解码器通常将异质的全局令牌和补丁令牌展平为 L x C 伪图像，导致熵模型主要捕获序列轴上的依赖关系，而忽略了原生二维补丁网格结构。在本文中，我们表明 ViT 补丁令牌在原始网格上保留有很强的局部空间相关性。为利用这一结构先验，我们提出视觉令牌编解码器（VTC），一种双路径学习的编解码器，将全局令牌和补丁令牌分离到专用的编码路径中。全局令牌使用轻量级因子化先验进行压缩，而补丁令牌则在补丁令牌网格上使用空间-通道上下文熵模型进行编码。为支持中间层压缩和实际码率适配，VTC 进一步在后续 ViT 块之后加入特征匹配监督，并在单个编解码器内加入可变码率模块。在 DINOv2 和 SAM3 上的实验表明，VTC 在分类、分割和检测任务上始终优于代表性的 ViT 特征编码基线。在达到未压缩特征性能 90% 的情况下，VTC 在这些任务上将码率降低了 15.7 倍至 37.4 倍。我们还针对面向传输和存储的实际部署场景，提供了中间层码率-效用分析。

## Abstract
Distributed deployment of large vision foundation models often partitions a ViT backbone and exchanges intermediate token features between computing nodes, making efficient feature compression critical under bandwidth and computation constraints. Existing ViT feature codecs typically flatten heterogeneous global and patch tokens into an L x C pseudo image, causing entropy models to mainly capture sequence-axis dependencies while overlooking the native two-dimensional patch-grid structure. In this paper, we show that ViT patch tokens retain strong local spatial correlations on the original grid. To exploit this structural prior, we propose the Visual Token Codec (VTC), a dual-path learned codec that separates global and patch tokens into dedicated coding paths. Global tokens are compressed with a lightweight factorized prior, whereas patch tokens are encoded on the patch-token grid using a spatial-channel context entropy model. To support intermediate-layer compression and practical rate adaptation, VTC further incorporates feature-matching supervision after subsequent ViT blocks and variable-rate modules within a single codec. Experiments on DINOv2 and SAM3 show that VTC consistently outperforms representative ViT feature coding baselines on classification, segmentation, and detection tasks. At 90% of uncompressed-feature performance, VTC reduces bitrate by 15.7x-37.4x across these tasks. We further provide intermediate-layer rate-utility analyses for practical transmission- and storage-oriented deployment scenarios.

# 论文总结：Visual Token Codec: Unleashing Spatial Redundancy for ViT Feature Coding

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大型视觉基础模型（如 ViT）在设备端和边缘部署时计算开销巨大，常采用分布式部署，将 ViT 骨干分割到多个计算节点，并通过通信链路交换中间特征。此时，**中间特征的压缩效率**成为系统带宽和延迟的关键瓶颈。
- **现存问题**：现有 ViT 特征编解码器通常将异质的全局令牌（CLS/REG）和补丁令牌（PATCH）展平为 \(L \times C\) 的伪图像，再送入图像编解码器。这种排列只能捕获序列长度（token 序列）上的依赖，**忽略了 patch token 在原始二维网格上的强局部空间相关性**，导致码率冗余严重。
- **核心意义**：论文通过实证滑动窗口皮尔逊相关系数（图 1）证明 patch token 保留着显著的空间局部相关性，并提出应显式利用该结构先验进行特征编码，以大幅降低比特率、提升下游任务保真度。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **总体框架**：将 ViT 骨干分为前缀和后缀，在中间插入编解码器。输入图像经前缀得到中间特征 \(t_n\)，经分析变换 \(f_a\) 得到潜变量 \(\tau_n\)，再分为全局令牌分支 \(\tau_n^{(1d)}\) 和补丁令牌分支 \(\tau_n^{(2d)}\)，分别编码传输，解码后合并经合成变换 \(f_s\) 重建 \(\hat{t}_n\)，供后续 ViT 层和任务头使用。
- **双路径编码（Dual-Path）**：
  - **全局令牌路径**：数量少，携带全局语义。使用轻量级分析/合成变换与**因子化先验**（factorized prior）进行熵编码。通过可学习 CDF 构造概率质量函数，计算码率。
  - **补丁令牌路径**：数量多，位于 \(H \times W\) 二维网格。使用**空间-通道上下文熵模型（SCCTX）**（来自 ELIC）。先由 hyperprior 提供边信息；通道上分组自回归建模通道依赖；空间上采用棋盘格划分，非锚点位置利用已解码邻域预测高斯参数；最终将空间、通道、超先验上下文拼接预测 \(\mu, \sigma\)，实现条件高斯熵建模。
- **特征匹配（Feature Matching）损失**：
  - 传统方法只在压缩层计算 MSE，不能约束量化噪声在后继 ViT 块中的传播。
  - VTC 将重建 tokens 继续前向传播 j 个 ViT 块，在**更深层特征**上计算 patch 和 global 两部分的 MSE，与码率项加权构成率失真损失，显著缓解表示漂移。
- **全局/补丁令牌平衡**：由于全局令牌数量极少，简单 token 数加权会使其被忽略。VTC 在损失中对两类令牌的 MSE 按 1:1 加权，等效提高全局令牌的优化权重，兼顾分类（全局重要）和分割（补丁重要）。
- **可变码率（Variable-Rate）模块**：在单一模型中支持多个码率点。通过 QP 条件嵌入生成调制向量，对编解码特征进行通道级加权，无需训练多套模型。训练时从 65 个对数间隔的 \(\lambda\) 中采样，对应 QP 0–64。

## 6. 主要结论与发现

- **码率大幅下降**：在达到未压缩特征性能 90% 的条件下，VTC 相比 LaMoFC-VTM 的码率降低 **15.7×–37.4×**（分类/分割/检测任务）；其中语义分割收益最大（37.4×），说明二维空间建模对密集预测尤为重要。
- **双路径必要**：消融显示，全 1D 布局忽略空间结构最差；全 2D 填充全局令牌会污染上下文；双路径匹配 token 异质性，获得最佳率失真曲线。
- **特征匹配监督层影响 RD 轨迹**：不同 Input 层但相同 Spv 层的曲线轨迹相似，说明监督层决定编码器保留哪些信息。
- **中间层部署权衡**：
  - 浅层压缩（如 Input=0）可显著降低发送端 FLOPs（~0.6G），但接收端计算高（~87.5G），适合传输导向、任务特定的一次性推理。
  - 深层压缩（如 Input=12）发送端成本高（~88G）但接收端几乎为零，适合存储导向、多任务复用的场景。
  - 在 ADE20K Seg 上，压缩第 9 层并重建最后 4 层（Input=9, Spv=12）是率失真最优配置。
- **骨干规模选择需看指标**：按 bpfp，L 优于 B；按 bpp，B 在 ADE20K 上反而优于 L。推荐跨模型比较使用 bpp。
- **VTC 码率约 0.1 bpp**，远低于 VQFC（~4 bpp）和 VTM（极高编码时间），适合实际存储传输。

## 7. 优点

- **结构先验创新**：首次明确提出利用 ViT patch token 的二维网格空间冗余，并通过滑动窗相关性给出证据，直击现有方法“伪图像展平”的根本问题。
- **双路径自适应设计**：为异质 token 分配不同熵模型，同时具备理论合理性和工程实用性。
- **特征匹配监督**：将压缩误差传播纳入训练目标，有效缓解量化噪声在深层 ViT 中的累积，设计巧妙。
- **面向部署的可变码率与中间层分析**：单模型多码率、发送/接收端 FLOPs 权衡分析，为实际系统（边缘-云、存储）提供可操作参考。
- **实验规范**：多任务、多规模、多协议评估，使用更大测试集并补充 bpp/bpfp 双重指标，结果可信度较高。

## 8. 不足与局限

- **基线覆盖有限**：未与 DT-UFC 等前沿通用特征编码方法直接比较，说服力部分受限。
- **VQFC 对比公平性存疑**：VQFC 原始设计针对固定分辨率，在可变分辨率/多任务场景下不如其他方法，但论文未进行针对性调参或固定分辨率复现。
