## 摘要
视觉-语言-动作（VLA）模型最近在机器人操作中取得了有前景的性能。然而，现有基准主要评估静态操作任务上的泛化能力，很大程度上忽略了动态交互场景。为解决这一差距，我们提出了 ReflexBench，一个用于反应关键型操作的基准。ReflexBench 包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时在同步和异步推理下支持可配置延迟。基于 ReflexBench，我们提出了 ReflexVLA，一种高效的 VLA 模型，专为反应关键型操作设计，无需大规模机器人数据预训练。ReflexVLA 通过潜在未来预测和视觉主干内的多帧时间融合增强了时间推理，同时通过批量视觉编码和 CUDA Graph 重放降低了部署延迟。实验表明，ReflexVLA 持续提高了动态操作性能，同时在标准静态操作基准上保持了有竞争力的准确性，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

### 2. 论文提出的方法论

**整体架构：**
- ReflexVLA 基于一个紧凑的视觉-语言-动作架构 [10]，视觉编码器为 DINOv2 + SigLIP 融合的 ViT 主干（224×224分辨率），语言骨干为 Qwen2.5-0.5B 因果Transformer，通过可学习的动作查询（action queries）产生动作块（action chunk）。

**三大核心设计：**

**(1) 潜在未来预测（Latent Future Prediction）**
- 目的：让策略在训练时学会**预测近未来视觉状态**，从而在动态场景中做出前瞻性决策。
- 关键做法：
  - 不直接预测未来图像（计算昂贵且聚焦于低层外观细节），而是在**语义潜在空间**中预测。
  - 使用**冻结的 DINOv3** 模型编码未来观测，作为稳定的预测目标：`y_{t+i} = ϕ_DINOv3(o_{t+i})`
  - 在输入序列中追加 H 个可学习的未來 token，每个 token 对应动作块中的一个控制步。
  - 将Transformer输出的第 i 个未来 token 经投影头映射到 DINOv3 特征空间：`\hat{y}_{t+i} = f_pred(h_future_i)`
  - 使用**掩码余弦相似度损失**训练：
    - `L_future = Σ_i m_i [1 − cos(ŷ_t+i, y_t+i)] / Σ_i m_i`
  - 总损失为：`L = L_act + λ_future · L_future`（λ_future = 0.05）
- 优势：每个未来步仅用一个token表示，额外序列长度很小，计算和内存开销可忽略。

**(2) 多帧时间融合（Multi-Frame Temporal Fusion）**
- 目的：单帧图像无法捕获运动动态，策略需要历史视觉上下文。
- 关键做法：
  - 在**视觉主干内部**融合多帧信息，而非将多帧图像token直接拼接后送入语言模型（后者会导致序列长度呈 V×T 倍增长，注意力的二次复杂度不可接受）。
  - 对每视角、每个 patch 位置，取 T 帧历史特征构成时间轨迹，先归一化+降维，加上时间位置编码，经**因果多头注意力**（causal MHA）融合：
    - `Δx_{v,p,t} = Up(MHA_causal(z_{v,p,1:T})_t)`
  - 因果掩码确保推理时不会用到未来信息，与在线部署一致。
  - 融合结果加到当前帧的最终层特征上：`\tilde{x}_{v,p,t} = x_final_{v,p,t} + Δx_{v,p,t}`
  - 最终只将**当前帧**的融合特征送入语言模型，视觉token数量与单帧设置完全相同。
- 优势：在不引入语言模型端额外开销的前提下，利用短期运动信息；且实验表明在**中间层特征**（而非最终层）上做融合效果更好，因为中间层保留了更丰富的局部外观与运动信息。

**(3) 推理延迟优化（Inference Latency Optimization）**
- 目的：减少从感知到动作执行的端到端延迟。
- 两项措施：
  - **批量视觉编码**：将 V 个视角 × T 帧历史图像打包为一次批量视觉编码器前向传播，避免 V×T 次独立前向带来的框架开销，并提高GPU利用率。
  - **CUDA Graph 重放**：部署时计算图固定，捕获完整推理流水线（视觉编码→时间融合→多模态投影→语言模型→动作预测）为 CUDA Graph，每次控制周期直接重放图，消除重复的 kernel 调度和运行时分发开销。
- 优势：不改变策略架构和学习目标，纯粹减少部署开销。

**ReflexBench 的延迟感知评估协议：**
- 将模拟器步进与机器人控制解耦，环境动力学独立于策略计算持续演进，避免传统基准“推理时暂停环境”的不真实假设。
- 支持两种推理范式：
  - **同步推理**：模拟器暂停，等待策略推理完成后，机器人闲置指定的延迟时长，再执行预测的动作块。
  - **异步推理**：策略从当前观测推理新动作块的同时，机器人执行上一周期生成的动作块，新动作在下一控制周期生效。
- 延迟可通过**Real-Time Factor (RTF)** 与实际测量策略在真实世界的推理延迟进行换算，将真实延迟注入仿真：
  - `RTF = t_sim / t_wall`

### 6. 主要结论与发现

1. **(Q1) 推理条件显著影响动态任务成功率**：
   - 异步推理在低推理频率下因观测-动作失配而性能较差，但随频率增加最终超过同步推理。
   - 更大的 chunk size + 更短的 action horizon 在异步推理下表现最佳。

2. **(Q2) ReflexVLA 在 ReflexBench 上取得最佳平均性能**：以 **50.4%** 的平均成功率超过所有基线（次优为 PUMA 的 50.2%），且仅需 1B 参数，约为 PUMA 的 1/4。较其主干 VLA-Adapter（30.3%）提升 20.1 个百分点。

3. **(Q3) ReflexVLA 在静态基准上保持竞争力**：LIBERO 平均准确率 **97.2%**，与最佳基线 VLA-Adapter（97.3%）基本持平，证明动态优化设计不损害静态泛化能力。

4. **(Q4) 三个组件均有独立贡献**：
   - 冻结 DINOv3 目标 + 潜在未来预测：36.8% → 62.8%（+26.0）
   - 中间层特征上的多帧时间融合：62.8% → 71.7%（+8.9）
   - 推理延迟优化（批量编码+CUDA Graph）：71.7% → 73.8%（+2.1），且延迟从 125.1ms 降至 65.0ms

5. **(Q5) 真实世界实验中 ReflexVLA 表现优于 SmolVLA，且以 1/4 参数量达到与 PUMA 相当或更好的性能**。

**偏差风险与公平性问题：**
-

- 偏差风险与公平性问题：各基线模型的训练数据来源与训练协议未完全对齐——论文未明确说明 OpenVLA-OFT、π0.5、PUMA、DynamicVLA 等在 ReflexBench 上是否使用了相同的演示数据、相同的数据增强和相同的微调轮数。若某些模型采用官方预训练权重直接推理（而非在反射基准上微调），则其低成功率可能反映的是微调缺失而非模型能力不足，从而给比较结果引入不公平因素。
- 评估的统计信息不完整：虽然给出 3 个种子的平均±标准差，但未报告每次运行的具体成功率、失败模式分类以及跨种子的方差显著性检验，难以判断模型间差异是否具有统计显著性。
- 缺少失败案例分析：论文未定量分析策略在动态任务中失败的原因（如预测滞后、轨迹跟踪偏差、目标丢失、动作执行速度不足等），也缺乏对未来预测质量的直接可视化验证（如预测特征与真实未来特征的相似度随时间的变化）。
- 通用性讨论不足：ReflexVLA 的动态设计是否可推广至更复杂的高维操作任务（如灵巧手操作）或长时程任务未作说明；潜在未来预测在目标部分遮挡、多目标交互场景下是否仍然有效也无实验证据。
- 硬件依赖问题：CUDA Graph 优化依赖固定计算图，若模型支持动态任务切换或自适应计算，可能无法直接复用；且论文未报告不同GPU型号下的加速效果差异。

### 9. 可复现性与开放性

- 论文提供项目网站，并声明将开源代码、基准环境和模型权重，这为社区复现和二次开发提供了良好基础。
- 但当前论文文本中缺少详细的训练超参数表（学习率、batch size、优化器、训练步数、数据增强策略、未来预测权重λ_future的衰减安排等），也缺少环境动力学参数（如传送带速度、物体运动轨迹生成公式）的完整描述，增加了复现摩擦。
- 延迟测量方法（如何在实际硬件上测量端到端延迟、如何将仿真时间与墙钟时间对应）描述过于简略，需要依赖项目仓库的补充文档才能完整复现。

### 10. 总结与展望

**本文的总体定位**：ReflexBench 与 ReflexVLA 共同构成了一套面向反应关键型操作的研究框架——前者为动态场景下的 VLA 评估提供了更真实的延迟感知协议，后者通过潜在未来预测、多帧时间融合和推理延迟优化三方面协同设计，在不大幅增加参数与计算开销的前提下，显著提升了 VLA 模型在动态任务中的表现和部署效率。

**核心贡献回顾**：
1. 率先在 VLA 语境下将“推理延迟”作为显式变量引入基准设计，填补了动态交互+延迟评估的空白。
2. 提出了一种计算代价极小的语义潜在未来预测目标，使策略具备前瞻性而不引入像素级重建负担。
3. 设计了视觉主干内多帧因果融合机制，在不增加语言模型序列长度的前提下捕捉运动动态。
4. 通过系统实验验证了推理条件（模式、频率、chunk size、horizon）对动态任务成功率的强烈影响，并给出了可操作的选取建议。

**未来工作方向**：
- 将潜在未来预测与大规模预训练结合，探索能否在预训练阶段赋予 VLA 通用动态感知能力。
- 引入更先进的动作调度机制（如 RTC）到 ReflexBench 的评估协议中，使基准能匹配业界最新部署实践。
- 扩展任务集到更多真实动态场景（如非刚体操作、人类协作、对抗性环境），以及加入对预测质量本身的可视化与量化评估。
- 探索在多模态信息（如力觉、深度）上的时间融合与预测，进一步提升对物理交互的敏感性。

**总体评价**：这是一篇问题定义清晰、方法设计精巧、实验链条完整的论文。虽然在数据集规模、基线公平性和统计细节上仍有改进空间，但其提出的“延迟感知评估协议”和“视觉主干内多帧因果融合”对未来 VLA 研究具有很强的启发价值。推荐从事机器人学习、VLA 部署和动态操作研究的读者精读，并将 ReflexBench 作为新增的评估标准参考。
