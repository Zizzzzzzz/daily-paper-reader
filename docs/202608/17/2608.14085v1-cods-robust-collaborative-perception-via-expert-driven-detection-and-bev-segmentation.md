## 摘要
协同感知通过多智能体信息交换突破了单视角限制。然而，位姿误差和通信延迟等多源噪声会降低融合特征质量，从而制约感知性能。检测与BEV分割的联合训练提供了一种自然的补救措施，其中分割出的道路区域有助于约束目标分布，而检测边界框有助于恢复模糊的分割边界。为此，我们提出了一种鲁棒的协同感知框架，结合专家驱动的检测与BEV分割（CoDS）。为了解决融合质量的空间不一致性，我们首先引入了协同可靠性图（CoRM）来显式量化特征质量分布。基于CoRM，我们设计了语义混合专家（S-MoE）模块，以针对不一致的特征需求提取差异化特征。最后，为了进一步缓解特征噪声退化，双向任务互补交互（BTCI）通过双向注入细化任务感知特征。在OPV2V和V2V4Real数据集上的大量实验表明，我们的CoDS在两项任务上均超越了现有基线，并在多源噪声下保持稳定的鲁棒性。代码：https://github.com/JinlongW128/CoDS 和 https://openi.pcl.ac.cn/OpenAIDriving/CoDS。

## Abstract
Collaborative perception breaks through single-view limitations via multi-agent information exchange. However, multi-source noise such as pose errors and communication delays degrades fusion feature quality, constraining perception performance. Joint training of detection and BEV segmentation provides a natural remedy, where segmented road regions help constrain target distributions and detection bounding boxes help recover ambiguous segmentation boundaries. To this end, we propose a robust Collaborative perception framework with expert-driven Detection and bev Segmentation (CoDS). To address spatial inconsistency in fusion quality, we first introduce the Collaborative Reliability Map (CoRM) to explicitly quantify feature quality distribution. Based on CoRM, we design the Semantic Mixture-of-Experts (S-MoE) module to extract differentiated features for inconsistent feature demands. Finally, to further mitigate feature noise degradation, the Bidirectional Task Complementary Interaction (BTCI) refines task-aware features through bidirectional injection. Extensive experiments on OPV2V and V2V4Real datasets show that our CoDS surpasses existing baselines on both tasks and maintains stable robustness under multi-source noise. Code: https://github.com/JinlongW128/CoDS and https://openi.pcl.ac.cn/OpenAIDriving/CoDS.

## 1. 核心问题与研究动机

- **背景**：L4/L5 级自动驾驶依赖可靠的环境感知，但单车感知存在视野受限、遮挡和盲区等固有问题。协同感知通过多智能体（CAV）间信息共享突破单视角限制，已成为自动驾驶领域的重要研究方向。
- **核心问题**：协同感知在特征融合过程中面临多源噪声干扰，包括：
  - 传感器测量误差与 GPS/IMU 位姿漂移导致空间对齐偏差；
  - 通信延迟导致不同智能体的 BEV 特征在时间上不一致。
- **关键洞察**：上述噪声导致融合特征在空间上产生不一致的质量分布——对齐良好的区域特征质量高，对齐失败区域则噪声累积、质量退化。现有方法要么只做单任务（检测或分割），要么在多任务场景中缺乏跨任务双向交互，未显式建模和自适应处理这种空间质量不一致性。
- **核心观察**：BEV 语义分割提供的道路区域响应可作为检测的空间先验，约束目标合理分布；3D 检测边界框可精确勾勒目标与道路背景的空间边界，帮助分割恢复模糊边界。两者天然互补。

## 2. 方法论

### 2.1 核心思想

提出 **CoDS**（Collaborative perception with expert-driven Detection and BEV Segmentation）框架，以“融合可靠性”为先验，驱动任务特定特征提取和跨任务交互，联合优化 3D 目标检测与 BEV 语义分割。

### 2.2 三大核心模块

**（1）协同可靠性图（Collaborative Reliability Map, CoRM）**

- **目的**：显式量化协作 BEV 融合特征的空间质量分布。
- **方法**：
  - 将 N 个智能体经位姿变换后的 BEV 特征沿智能体维度堆叠；
  - 计算每个像素位置跨智能体的通道级方差 V(h,w)；
  - 对通道方差向量取 L2 范数得到标量不一致度 φ(h,w)；
  - 通过逆变换 R(h,w) = 1 / (1 + φ(h,w)) ∈ (0,1] 生成像素级可靠性图 R。
- **意义**：高可靠性区域对应多智能体特征一致、对齐良好的区域；低可靠性区域指示错位和噪声污染区域。该显式质量先验用于引导后续专家路由。

**（2）语义混合专家（Semantic Mixture-of-Experts, S-MoE）**

- **目的**：解决检测与分割对特征的需求不一致——检测依赖稀疏前景的精细边界特征，分割依赖全局连续背景的结构特征；同时处理融合质量的空间不均。
- **专家设计**（按语义而非任务划分）：
  - **FG-Expert（前景专家）**：3×3 卷积提取局部边缘 + 5×5 深度可分离卷积编码形状上下文，采用 InstanceNorm 适配稀疏激活；
  - **BG-Expert（背景专家）**：ASPP 空洞空间金字塔池化（rates={1,3,6}）聚合多尺度道路模式，采用 GroupNorm 适配稠密训练；
  - **SH-Expert（共享专家）**：双路径 SE 注意力做全局通道重标定，作为不确定区域的回退选项。
- **路由机制**：
  - 设计可靠性置信生成器 H_conf，拼接 F_coop 与 R 后经并行轻量卷积分支产生前景/背景置信度；
  - 结合语义路由先验 π_det/π_seg 与可学习路由信号 λ_det/λ_seg，通过任务特定可学习标量 α 加权后 Softmax 归一化得到门控图 G_τ；
  - 不同任务对 α 初始值不同（检测 α=0.7 强调语义先验，分割 α=0.45 更依赖学习信号）。

**（3）双向任务互补交互（Bidirectional Task Complementary Interaction, BTCI）**

- **目的**：进一步缓解低可靠区域中任务感知特征受噪声干扰的问题，实现检测与分割的双向互补增强。
- **方法**：
  - 从源特征经全局平均池化和两层全连接网络提取通道描述子，生成通道权重 W；
  - 采用零初始化（W2 的权重和偏置为零），确保初始时从恒等映射开始学习；
  - 从可靠性图 R 计算标量门控 β = mean(R)，统一控制两个方向的交互强度；
  - 通道权重通过乘性残差注入调制目标特征：F_hat = F ⊙ (1 + β·(W − μ))，其中 μ=0.5 为 sigmoid 中点；
  - 对源特征应用梯度停止（stop-gradient）以防跨任务梯度干扰；
  - 两个方向（det2seg 和 seg2det）共享门控 β，但保持独立的 FC 参数。

### 2.3 损失函数

总损失 L = ζ_cls·L_cls + ζ_reg·L_reg + ζ_seg·L_seg，其中 L_cls 为分类焦点损失，L_reg 为回归 smooth-ℓ1 损失，L_seg 由静态和动态语义监督组成，权重分别为 ζ_cls=1.0、ζ_reg=2.0。

## 6. 主要结论与发现

- **性能领先**：CoDS 在 OPV2V 上检测 AP@0.3/0.5/0.7 达到 94.64/94.05/86.88，分别较 AttFuse 提升 4.70/4.64/3.23 点；分割上 Dynamic/Road/Lane IoU 提升 5.27/5.41/7.11 点。在 V2V4Real 上同样全面超越基线，尤其 AP@0.7 改善显著。
- **鲁棒性优势**：随着定位噪声和通信延迟增大，CoDS 在所有指标上始终保持领先，性能下降更平缓。在 500ms 延迟下仍维持 AP@0.5 为 68.89、AP@0.7 为 50.08、Dynamic IoU 为 66.50。
- **联合训练有效性**：相比单任务训练，联合训练在检测和分割上实现双向性能提升，证明互补监督信号的有效性。
- **效率优势**：相比朴素级联模型 NCM，CoDS 参数减少 45.8%、FLOPs 减少 25.5%、推理内存减少 49.7%，同时性能更优。

## 7. 优点

- **创新性突出**：首次将融合可靠性量化（CoRM）与语义混合专家（S-MoE）结合用于协同感知，提出“可靠性感知的专家路由”范式，有效解决融合质量空间不一致问题。
- **任务互补设计合理**：检测与分割的双向交互（BTCI）设计精巧——零初始化保证训练稳定、梯度停止避免跨任务干扰、可靠性门控自适应控制交互强度，兼具效果与鲁棒性。
- **消融实验系统**：增量式消融清晰展示了各模块的独立贡献，逻辑严密。
- **鲁棒性验证充分**：对定位噪声和通信延迟两种典型多源噪声均做了系统评估。
- **效率-性能平衡**：在显著降低计算资源消耗的同时取得更优性能，具备实际部署潜力。
- **多数据集验证**：仿真（OPV2V）与真实世界（V2V4Real）双重验证，实验可信度较高。

## 8. 不足与局限

- **分割真值局限**：V2V4Real 缺乏真实 BEV 分割标注，使用检测 GT 生成动态目标真值属于近似方案，无法全面评估静态类别（Road/Lane）的分割性能在真实世界中的表现。
- **对比公平性存疑**：ICA-V2X 为引用原论文结果，训练配置和环境可能不一致；未与更新的 Transformer 类协同感知方法（如 V2X-ViT、CoAlign 之后的 SOTA）进行对比，基线范围有限。
- **算力硬件限制**：批量大小仅 2，训练配置相对保守；未报告训练时长和收敛曲线，无法判断模型的训练效率。
- **噪声范围有限**：定位噪声最大仅 0.6m/0.6°，通信延迟最大仅 500ms，极端场景下的鲁棒性未充分验证。
- **应用扩展单一**：框架目前仅覆盖 3D 检测与 BEV 分割两项任务，论文自述局限为尚未集成更多任务（如轨迹预测、地图构建等）；多智能体数量上限为 5，大规模车辆场景下的可扩展性未验证。
- **通用性局限**：实验主要基于 AttFuse 的中间融合策略，两种融合范式（如早期/晚期融合、稀疏/稠密特征）下的有效性未得到验证。
