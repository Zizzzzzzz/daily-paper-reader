## 摘要
3D视觉语言模型（3D VLMs）能够对多视图场景进行空间推理，但由于重复观测和大量无信息区域导致显著的令牌冗余，从而带来高昂的计算成本。尽管视觉令牌压缩在加速2D VLMs方面已显示出潜力，但它未能捕捉3D场景的结构化特性，导致空间覆盖不完整和细粒度细节丢失。在本文中，我们提出了HiSC，一种用于3D VLMs中分层空间聚类令牌压缩的免训练框架。HiSC通过利用几何和语义线索联合组织空间聚类令牌，将令牌压缩从令牌级选择提升到聚类级处理。具体来说，我们首先引入了一种基于空间图的合并（SGraM）策略，该策略将跨视图冗余建模为空间连通性，并整合物理一致的区域，在LLM推理之前有效地合并极其相似的冗余令牌。然后，我们在LLM推理中提出了一种基于空间聚类的剪枝（SCluP）范式，该范式在聚类间和聚类内执行分层压缩，在保留对象实例完整性的同时，为重要区域保留细粒度细节。在多样化3D推理基准上的大量实验验证了HiSC的有效性，尤其是在高视觉令牌剪枝率下。此外，HiSC在最小性能下降的情况下实现了超过90%的令牌缩减。代码可在https://github.com/elecreak/HiSC获取。

## Abstract
3D vision-language models (3D VLMs) enable spatial reasoning over multi-view scenes but suffer from substantial token redundancy due to duplicated observations and large uninformative regions, leading to high computational cost. Although visual token compression has shown promise in accelerating 2D VLMs, it fails to capture the structured nature of 3D scenes and leads to incomplete spatial coverage and loss of fine-grained details. In this paper, we propose \textbf{HiSC}, a training-free framework for hierarchical spatial clustering token compression in 3D VLMs. HiSC lifts token compression from token-level selection to cluster-level processing by organizing tokens into spatially grounded clusters using joint geometric and semantic cues. Specifically, we first introduce a \textbf{spatial graph-based merging (SGraM) strategy} that models cross-view redundancy as spatial connectivity and consolidates physically consistent regions, effectively merging extremely similar redundant tokens prior to LLM inference. We then propose a \textbf{spatial clustering-based pruning (SCluP) paradigm} within LLM inference, which performs hierarchical compression across clusters and within clusters, preserving object instance completeness while retaining fine-grained details for important regions. Extensive experiments on diverse 3D reasoning benchmarks show validate the effectiveness of HiSC, particularly under high visual token pruning ratios. Besides, HiSC achieves over 90\% token reduction with minimal performance degradation. Code is accessible at https://github.com/elecreak/HiSC.

# HiSC: 分层空间聚类令牌压缩用于高效3D场景理解 — 论文总结

## 1. 核心问题与研究动机

**核心问题：** 3D视觉语言模型（3D VLMs）在进行多视图3D场景理解时，因以下原因产生严重的视觉令牌冗余和高昂的计算成本：

- **跨视图重复观测**：多视图输入中，同一物理实体被多个视角反复编码；
- **无信息区域**：大面积的空白平面等区域贡献了大量冗余令牌；
- 单个3D场景产生的视觉令牌数量远超过典型2D VLM，长序列显著增加LLM推理开销。

**现有方法的不足：** 已有的面向2D VLM的令牌压缩方法（如FastV、BTP等）主要基于注意力分数、重要性或多样性在1D令牌序列/特征空间中做独立令牌级选择，存在两个关键缺陷：

1. **缺乏空间结构建模**：未利用3D场景的几何结构和空间连通性，导致空间覆盖不完整、细粒度信息丢失；
2. **无法区分布局化重复**：2D冗余主要表现为局部相似性，而3D冗余涉及大面积物理一致区域和跨视图结构重复，需要显式建模空间连通性。

## 2. 方法论：HiSC框架

HiSC是一个**免训练**（training-free）的框架，核心思想为：将令牌压缩从**令牌级选择**提升为**聚类级处理**，利用几何邻近性和语义相似性将令牌组织为空间聚类，在不同层级采用定制化压缩策略。

### 2.1 总览

框架由两个互补模块组成，分段处理冗余：

- **SGraM（Spatial Graph-based Merging，空间图合并）**：在LLM推理**之前**执行，用于消除跨视图和物理一致区域的结构化冗余；
- **SCluP（Spatial Clustering-based Pruning，空间聚类剪枝）**：在LLM推理**内部**执行，用于逐层进行层次化、对象中心的令牌选择。

### 2.2 前置知识（3D VLM令牌构建）

- 多视图RGB图像 + 深度图 + 相机参数 → 每个patch映射到3D坐标；
- 视觉令牌：$v_i = f_{proj}(f_i, p_i)$，其中$f_i$为视觉特征，$p_i$为3D坐标，$f_{proj}$为结合外观与空间信息的投影函数；
- 输入LLM的序列：$X = [T_{prompt}; V; T_{query}]$，其中视觉令牌数$L_v$远大于文本令牌数$L_{text}$，主导计算开销。

### 2.3 SGraM：空间图合并（LLM前）

**动机：** 物理一致区域（如大平面、跨视图重叠区域）的令牌具有**传递性连通**关系——空间上局部相邻且语义一致的令牌构成链式结构，这是特征相似性聚类无法捕捉的。

**核心步骤：**

1. **几何-语义邻接构建**（解耦设计）：
   - 几何邻接：$A^g_{ij} = \mathbb{I}(\|p_i - p_j\|_2 < \tau_{geo})$
   - 语义邻接：$A^s_{ij} = \mathbb{I}(sim(f_i, f_j) > \tau_{sem})$
   - 统一邻接矩阵：$A_{ij} = A^g_{ij} \odot A^s_{ij}$

2. **连通分量提取**：将邻接矩阵视为无向图$G=(V,E)$，提取连通分量$C = \{C_k\}_{k=1}^K$，每个分量对应一个物理一致区域。

3. **聚合压缩**：对每个连通分量的令牌进行特征/坐标平均，生成超级令牌（super-token），实现结构化去冗余。

**设计优势：** 解耦方式保证空间有效性（几何约束）与语义一致性（语义约束）同时满足，避免仅靠全局相似性的跨对象错误合并，且通过图连通性捕捉传递性连接。

### 2.4 SCluP：空间聚类剪枝（LLM内）

**动机：** LLM逐层推理中令牌仍存在冗余，但现有token级方法独立选择，导致空间分布不均、对象覆盖不足。

**核心步骤：**

1. **对象中心空间聚类**：两步分解——
   - 先将令牌划分为$K_{sem}$个粗粒度语义组；
   - 再在每组内基于空间邻接矩阵执行连通分量分析（ConnComp），分离物理上不同的实例。
   - 公式：$C = \bigcup_{m=1}^{K_{sem}} \text{ConnComp}(A^{(m)})$
   - 这种“先语义后空间”的设计避免纯语义的跨空间误合并，以及纯空间的过分割。

2. **层次化聚类剪枝**——
   - **聚类间预算分配**：将总预算$N^{(l)}$分配到各聚类，满足：$n_k \geq 1$（保证每个聚类至少保留1个令牌，防止对象消失），$n_k \propto (I_k)^2$（按聚类重要性的平方加权分配，突出重要区域）；
   - **聚类内令牌选择**：采用重要性+多样性混合策略，定义联合空间-语义距离：
     $$D^{comb}_{ij} = \lambda\|p_i - p_j\|_2 + (1-\lambda)(1 - sim(f_i, f_j))$$
     优先选择与已选令牌在该度量下距离较远的令牌，促进结构多样性。

**整体效果：** 聚类级预算分配保证全局对象覆盖，聚类内选择保证重要区域的细粒度细节，避免token级方法早期过度剪枝重要对象细节、后期不完整区域表示的问题。

## 6. 主要结论与发现

1. **全面超越现有方法**：在三个压缩级别、五个基准上，HiSC均优于所有基线，且差距在极端压缩下尤为显著（Relative Score 92.46%，远高于次优的89.43%）。

2. **高压缩下保持性能**：90%令牌缩减下保持92.46%的原始性能；中等压缩下97.14%，几乎无损。

3. **结构化冗余的可压缩性**：实验表明3D场景中存在大量可直接合并的结构化冗余（SGraM有效验证），去除冗余不仅不损害性能，反而可能缓解注意力稀释。

4. **层次化剪枝优于独立选择**：聚类间分配+聚类内选择的层次化方案，优于纯token级和纯cluster级方法，体现“全局覆盖+局部保真”的权衡价值。

5. **解耦连通性的必要性**：几何与语义联合的解耦邻接设计显著优于任一单独约束或特征耦合方案。

6. **组件互补性**：SGraM与SCluP单独使用均性能下降（尤其仅SGraM相对退化更大），两者结合同时保证“安全去冗余”和“结构化分配”。

## 7. 优点

### 方法设计方面
- **从“选择”到“组织”的范式转变**：将token压缩从1D序列操作提升到3D空间聚类级处理，更契合3D场景的结构本质；
- **解耦几何与语义**：分别用空间连通性和语义一致性构建邻接关系，避免特征空间的歧义性和几何位置的误导；
- **连通分量的传递性**：利用图连通性捕捉物理一致区域的链式传递关系，优于全局相似性聚类；
- **层次化预算管理**：聚类间按重要性平方分配（保证对象覆盖），聚类内重要性+多样性联合选择（保留细节），设计精妙且直观；
- **免训练即插即用**：无需重新训练/微调，直接应用于已发布的3D VLM，实际部署友好。
