## 摘要
事件相机以高时间分辨率异步捕获强度变化，需要新颖的预处理方法以用于下游任务。与静态强度快照不同，事件数据本质上编码了场景动态和物体运动的信息，这意味着从事件中提取的特征可能表现出与基于帧的视觉中无直接对应物的行为。在本文中，我们分析了事件角点检测中使用的两个特征——结构张量的特征值和时空密度值——并表明它们是运动线索。我们假设这些特征与局部几何信息结合，可以增强运动估计任务。为了验证这一点，我们首先从理论上分析运动角点处结构张量的特征值与运动方向之间的关系。然后，我们在合成数据集上设计了受控实验，证实将局部几何特征与特征值和密度值扩展可提供互补的运动信息，并且对纹理和散粒噪声具有鲁棒性。最后，我们将所提出的特征集成到最先进的事件光流网络中，并在真实世界的DSEC基准上进行评估，添加的特征持续提高了准确性，在数据稀缺场景和低容量模型中收益最大。本文代码可在 https://github.com/hesamaraghi/static-in-frames-dynamic-in-events 获取。

## Abstract
Event cameras capture intensity changes asynchronously with high temporal resolution, requiring novel preprocessing methods for downstream tasks. Unlike static intensity snapshots, event data inherently encode information about scene dynamics and object motion, meaning that features derived from events can exhibit behaviors with no direct analogue in frame-based vision. In this paper, we analyze two features used in event-based corner detection---the eigenvalues of the structure tensor and the spatiotemporal density values---and show that they are \emph{motion cues}. We hypothesize that these features, combined with local geometric information, can enhance motion estimation tasks. To validate this, we first theoretically analyze how the eigenvalues of the structure tensor at moving corner points relate to the direction of motion. We then design controlled experiments on a synthetic dataset, confirming that extending local geometric features with eigenvalues and density values provides complementary motion information and is robust to texture and shot noise. Finally, we integrate the proposed features into a state-of-the-art event-based optical flow network and evaluate on the real-world DSEC benchmark, where the added features consistently improve accuracy, with the largest gains in data-scarce scenarios and for lower-capacity models. ## 1. 核心问题与研究动机

- **背景**：事件相机（Event Camera）以异步方式记录逐像素的亮度变化，具有微秒级时间分辨率。与帧相机不同，事件数据是场景动态和物体运动的天然载体，但现有基于事件的特征提取方法大多将事件特征当作静态时空描述子使用（如角点检测），未充分挖掘其中隐式的运动信息。
- **核心问题**：事件角点检测中使用的两个特征——**结构张量（Structure Tensor）的 Harris 特征值（λ₁, λ₂）** 和 **时空密度值（Spatiotemporal Density）**——究竟仅仅是几何/角点线索，还是本身也蕴含着运动方向信息？能否将其显式用作运动线索来提升光流估计等运动估计任务？
- **整体含义**：作者提出了一种“重新思考”视角：**事件中的特征不是静态的，而是动态的**。事件相机独有的特征行为（没有帧视觉中的对应物）应当作为运动提示（motion cues），与局部几何共同提升下游运动估计。

## 2. 方法论

### 2.1 核心思想
把从事件流中计算得到的 Harris 特征值和密度值作为“运动线索”，显式地扩展现有事件表示（如 voxel grid），并与局部几何/空间邻居信息结合，从而帮助网络更精确地估计光流。

### 2.2 特征提取
- 对事件流 `{eᵢ = (xᵢ, yᵢ, tᵢ, pᵢ)}`，采用指数时间衰减核构建密度图：
  ```
  I(rᵢ) = Σ_{j≤i} pⱼ · g(rᵢ - rⱼ) · exp((tⱼ - tᵢ)/τ)
  ```
  其中 `g(·)` 是高斯空间核，`τ` 是时间衰减常数。
- 基于密度图计算空间梯度 `∇I = [Iₓ, I_y]`，再计算结构张量：
  ```
  S_w = w * (∇I∇Iᵀ)
  ```
- 由结构张量得到 Harris 特征值 λ₁, λ₂（闭式解）。

### 2.3 理论分析：特征值→运动方向
- 以三角形平动为例，分析顶点 A 处结构张量的特征值与运动方向的关系。
- 设局部几何矩阵 `V = [n̂₁, n̂₂]`（两条边的单位法向量），将位移向量 u 投影到法向方向上得到 `d = Vᵀu`。
- 理论推导表明：结构张量可分解为 `S_w = V·diag(A₁, A₂)·Vᵀ`，其中 A₁/A₂ 与梯度贡献区域面积成正比。
- 从特征值求得 A₁、A₂（补充材料给出二次方程 `A² − (λ₁+λ₂)A + λ₁λ₂/sin²θ = 0`），即可恢复运动方向：
  ```
  û = V⁻ᵀ [sin(α₁), sin(α₂)]ᵀ
       = V⁻ᵀ [sin(A₁θ/(A₁+A₂)), sin(A₂θ/(A₁+A₂))]ᵀ
  ```
- 由此建立“Harris 特征值 + 局部几何 = 运动方向恢复”的理论桥梁。

### 2.4 集成方法
- **顺序不变 MLP（Toy 模型）**：以事件邻居的相对空间坐标（必要时含相对时间）为基线，可附加密度值和 Harris 特征值，用 DeepSets 式置换不变结构预测光流。
- **IDNet（真实网络）**：将逐事件的密度值和特征值按 temporal bins 进行体素化（voxelize），与事件 voxel 沿通道维度拼接，作为第一层卷积的扩展输入；无需额外编码器或复杂的跨模态融合，保持轻量、即插即用。

## 3. 实验设计与 Benchmark

### 3.1 数据集 / 场景

- **真实世界基准 2：EVIMO2v2**（补充材料，室内场景、物体独立运动），同样比较子集与全量训练场景。

## 6. 主要结论与发现

- **Harris 特征值 + 密度值确实是运动线索**，且需与局部几何信息配合才能有效恢复运动方向；单独使用扩展特征（不含空间坐标）无法学习光流。
- 扩展特征带来的提升**不是模型容量增大所致**（随机/重复特征无效）。
- 密度值和 Harris 特征值提供的信息**优于单纯增加相对时间**，且二者可进一步叠加。
- 对**前景纹理和散粒噪声**具有较强鲁棒性，在挑战条件下依然持续改善光流精度。
- 在真实 DSEC 基准上，扩展特征**一致降低 1-PE/2-PE/3-PE/EPE/AE**；提升幅度在**数据稀缺子集**和**低容量模型**（Tiny IDNet、1/8 分辨率）中更明显，表明该特征在资源受限或数据有限时尤其有价值。
- 轻量即插即用：无需额外编码器，仅增加极少的参数量（IDNet 从 1.427M→1.430M）和推理时间（约 2ms/帧）。

- **理论分析与实验相结合**：先用几何推导建立特征值→运动方向的可解释联系（Algorithm 1），再用合成控制实验和真实基准验证。
