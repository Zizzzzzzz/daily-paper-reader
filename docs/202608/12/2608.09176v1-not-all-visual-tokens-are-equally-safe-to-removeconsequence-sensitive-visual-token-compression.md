## 摘要
视觉语言模型（VLM）的视觉标记压缩在很大程度上依赖于注意力、冗余性和不确定性等标准，以在固定计算预算下最大化平均准确率，这隐式地假设所有错误具有相同的代价。然而，下游任务中错误预测的后果很少是对称的：误读发票金额可能远比误分类背景颜色代价更高。受此启发，我们提出了后果敏感的视觉标记压缩，该方法根据请求的潜在错误代价跨请求分配视觉计算。我们的方法遵循“先校准后分配”的流程，离线估计特定后果的错误预算曲线，并利用从问题或任务信息中获得的后果信号在线应用校准后的标记预算。在一个受控的任务内基准中，高后果和低后果问题来自相同的文档图像，因此仅凭内容无法揭示哪些问题出错代价高昂。在该设置下，我们的方法在相同总标记预算下将高风险错误从0.300降至0.133，而内容驱动的分配器表现不比均匀分配更好。通过测量不同代价比率下错误率随标记预算的变化，我们推导出一个分配前沿：当错误代价相等时，均匀分配是最优的；随着代价差距增大，将标记转移到高后果问题上的收益越来越大。该分配原则在三个密集视觉语言基准、两种预算实现机制（标记删除和分辨率重分配）、两种VLM架构和多种标记选择策略上均能良好泛化。在现实混合工作负载中，后果敏感的分配使代价加权错误降低了38%，同时相较于全分辨率推理延迟降低了约21%。

## Abstract
Visual token compression for vision--language models (VLMs) has largely relied on criteria such as attention, redundancy, and uncertainty to maximize average accuracy under a fixed compute budget, implicitly assuming that all errors carry equal cost. However, the consequence of an incorrect prediction on downstream tasks is rarely symmetric: misreading an invoice amount can be far more costly than misclassifying a background color. Motivated by this, we introduce consequence-sensitive visual token compression, which allocates visual computation across requests according to their potential error costs. Our method follows a calibrate-then-allocate procedure, estimating consequence-specific error-budget curves offline and applying the calibrated token budgets online using consequence signals available from question or task information. On a controlled within-task benchmark, high- and low-consequence questions are drawn from the same document images, so content alone cannot reveal which questions are costly to get wrong. In this setting, our method reduces high-stakes errors from 0.300 to 0.133 under the same total token budget, whereas a content-driven allocator performs no better than uniform allocation. Measuring how error rates change with token budget across different cost ratios, we derive an allocation frontier: uniform allocation is optimal when errors are equally costly, and token transfer toward high-consequence questions becomes increasingly beneficial as the cost gap grows. This allocation principle generalizes well across three dense vision-language benchmarks, two budget realization mechanisms (token deletion and resolution reallocation), two VLM architectures, and multiple token selection strategies. On a realistic mixed workload, consequence-sensitive allocation reduces cost-weighted error by 38% while achieving approximately 21% lower latency than full-resolution inference.

## 1. 核心问题与整体含义（研究动机与背景）

视觉标记（visual token）在现代视觉语言模型（VLM）推理中占据主导计算成本，因此视觉 token 压缩成为高效推理的关键方向。现有工作（如 FastV、SparseVLM、VisionZip 等）基于注意力、冗余性或不确定性等信号来筛选、压缩视觉 token，其统一目标都是在固定计算预算下**最大化平均准确率**。该目标隐含了一个关键假设：**所有预测错误的后果都是对称的、代价相等的**。

然而，在真实下游任务中，错误后果往往高度不对称：例如，在文档理解、图表推理、信息图中，误读一个发票金额、交易编号或医疗数值的后果，远比误分类一个章节标题或装饰属性严重得多。这类后果差异往往在推理前就可用（如问题类型、任务身份、应用工作流），但现有分配策略无法利用这种信号——注意力、冗余性、不确定性仅描述视觉输入特性，而不刻画“答错会付出多大代价”。

本文据此提出一个新视角：与其问“哪些视觉 token 是冗余的”，不如问“**当不同错误的代价不同时，有限的视觉计算预算应如何分配**”。作者将视觉 token 压缩重新形式化为**在严格总 token 预算约束下最小化代价加权错误（Cost-Weighted Error, CWE）**的问题，并提出了后果敏感的视觉 token 压缩方法。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：校准-分配（Calibrate-then-Allocate）

方法分两个阶段（见图 2）：

- **离线校准阶段**：利用验证集上的推理结果，估计**分层级（tier-specific）的误差-预算曲线** $\hat{e}_t(b)$——即每个后果层级的错误率如何随视觉 token 预算变化。然后根据预设的后果代价权重，在固定总预算约束下求解最优分配策略。该反馈循环仅在离线阶段更新，推理时策略固定。
- **在线推理阶段**：每个请求根据问题文本或任务身份快速判定后果层级，将离线校准好的 token 预算直接应用到该请求。在线开销仅为轻量级的层级分配。

### 2.2 问题形式化

样本 $i$ 带有后果权重 $c_i > 0$（回答错误的代价），分配到视觉 token 预算 $b_i$。样本按层级 $t$ 分组，层级 $t$ 有共同权重 $c_t$、规模 $n_t$、误差-预算曲线 $e_t(b)$。给定总预算 $B$，优化目标为：

$$\min_{\{b_t\}} \sum_t n_t c_t e_t(b_t) \quad \text{s.t.} \quad \sum_t n_t b_t \le B, \quad b_t \ge b_{min}$$

在两层级实例中（$n_{hi}=n_{lo}=n$，$c_{hi}=r$，$c_{lo}=1$，$B_{hi}+B_{lo}=608$，即平均每图 304 token），目标等价于最小化：

$$J(B_{hi}) = \frac{r E_{hi}(B_{hi}) + E_{lo}(608 - B_{hi})}{r+1}$$

### 2.3 分配原则：水填充 vs. 离散交换条件

- 经典连续凸情况的**水填充规则**要求代价加权边际误差降低 $c_t |e'_t(b_t)|$ 在所有层级间相等。
- 但本文实测问题**不满足该前提**：预算位于离散的 13 点网格上（导数条件不成立），且误差-预算曲线非凸（如 $E_{hi}$ 的有限差分边际在 32→64→96→128 区间为 −0.043、−0.023、−0.064，非单调）。
- 因此作者采用**基于交换的离散一阶条件**：在网格最优处，从任一层级向另一层级移动一个网格步长都不会降低 $J$。分配器通过**穷举搜索**可行预算对来最小化实测 $J$，并确保每个报告的 argmin 处满足交换条件。

### 2.4 两种预算实现机制

1. **真实 token 删除（True Deletion）**：以全分辨率编码，用固定选择器对 token 排序，删除其余 token（保留原始空间坐标，缩短 embedding 和位置 id）。零掩码替代会导致分布外零向量并破坏生成，故不可用。此机制用于分析，可精确控制选择器。
2. **分辨率重分配（Resolution Reallocation）**：调整图像尺寸使编码器输出近似预算的 token 数，然后走标准生成路径，无需修改模型代码，适用于任意 VLM。实验表明在 Qwen2.5-VL 上该机制优于删除机制，作为部署机制使用。连续分辨率机制的偏差 ≤0.4%。

### 2.5 两轴分配机制图谱

问题类别可在两个正交轴上区分：
- **敏感度差距**：每 token 的边际误差降低是否不同？
- **代价差距**：错误代价是否不同？

| 是否有代价差距 | 无（代价相同） | 有（代价不对称） |
|---|---|---|
| **无敏感度差距**（内容不可代理代价） | 无需分配器 | **后果敏感分配必要**（本文任务内场景） |
| **有敏感度差距**（内容可代理） | 内容驱动分配器可获胜 | 未测试（构成假设而非结论） |

本文测试的机制中，后果敏感分配在“存在代价差距且无敏感度差距可被内容代理”时是必要的。

## 6. 主要结论与发现

1. **后果信息本身有价值**：在任务内受控条件下，高低后果问题的图像分布完全相同、token 敏感度统计上无差异（边际 0.00173 vs. 0.00171，斜率标准误约 2×10⁻⁴），内容驱动的分配器退化为均匀分配且无效（McNemar 4:4, p=1.0），而后果敏感分配将高风险错误从 0.300 降至 0.133（2.25×，McNemar 54:4, p≈3×10⁻¹²）。这一设计隔离证明增益来自代价不对称而非 token 敏感度差异。

2. **未加权准确率不代表优化目标的全部**：cost-aware 的平均错误率（0.488）反而高于 uniform（0.337），低后果层错误率升至 0.843，说明方法确实在优化代价加权目标，而非间接恢复精度最优分配。

3. **分配前沿的特征**：
   - 代价比 r=1（对称代价）时，均匀分配最优
   - r=3 时出现内部最优（448/160 附近）
   - r≥5 时最优解移向网格边界（如 576/32），即应继续向高后果层级转移 token
   - 反向分配（anti）一致性地恶化 CWE，作为方向控制有效

4. **跨数据集泛化**：冻结规则在三个密集文档型基准上保持一致方向，绝对高后果错误降幅随信息密度单调（0.250 / 0.167 / 0.100），盈亏平衡代价比随密度下降（DocVQA 2.8、ChartQA 3.6、InfographicVQA 0.7）。InfographicVQA 甚至在纯准确率（不加权）上就占优。

5. **多机制、多模型、多选择器不变的普适性**：分配增益在分辨率重分配、LLaVA-OneVision、六种 token 选择器上均成立；现有 token 选择方法（FastV、SparseVLM、VisionZip）可作为正交组件与后果敏感分配叠加。

6. **校准与分配规则的可迁移性**：分裂半校准验证中，用一半校准集拟合出的最优分配在另一半上保持方向一致；关键词规则在 DocVQA、ChartQA、InfographicVQA 三个数据集上逐字迁移后均能产生一致的后果敏感效应，说明该机制不依赖特定数据集的过拟合，具备一定的部署鲁棒性。

7. **分配器与视觉 token 选择器正交可组合**：六种 token 选择器（冗余度、随机、显著性、FastV、SparseVLM、VisionZip）上，cost-aware 分配一致优于 uniform 分配，表明后果敏感预算分配解决的是“层级间资源再分配”问题，与“层级内 token 筛选”问题相互独立，二者可叠加使用。论文没有声称后果敏感机制能取代 token 选择器，而是将其定位为一种正交的系统级优化。

## 7. 局限性与未来方向

### 7.1 主要局限性

**（1）后果权重是人为设定而非经验测量。** 实验中 r=1/2/3/5/10/20 均为设计参数，论文没有来自真实业务场景的代价数据（如金融文档误读的实际损失、医疗记录错误的后果评级）。虽然 r 扫描和前沿分析证明了机制对代价比变化的敏感性，但实际部署时需要领域专家重新校准权重。

**（2）后果层级判定规则存在噪声。** 冻结关键词规则的 LLM 法官一致性仅 κ=0.45，表明规则会将部分导航性数字误判为高后果、将部分真实交易性问题漏入低层级。作者认为这会低估效应，但同时也意味着在更精确的后果估计下，增益可能进一步增大或分配边界发生偏移。

**（3）低后果错误率的代价被有意忽略。** 在 r≥3 时，最优分配明显牺牲低后果层（错误率升至 0.843），这是优化目标的必然结果，但也提示该方法适用于后果不对称明确的场景，而非通用精度优化。如果下游对整体准确率也有硬性要求，需要额外约束。

**（4）部分次要设置下统计显著性不足。** ChartQA、LLaVA-7B 与 Qwen2.5-VL-3B 的 r=5 条件下，∆CWE 的置信区间包含零。虽然主设置（DocVQA + Qwen2.5-VL-7B）效应极显著，但跨模型、跨数据集的增益幅度并不均匀。

**（5）任务内场景是理想化构造。** 任务内主实验通过均衡高低后果组的图像分布来隔离后果信息，现实请求的后果层级往往与图像内容相关（如文档类型本身暗示任务类型），此时内容信号与后果信号可能混淆，分配器需要同时处理两者。

### 7.2 未来方向

1. **端到端后果感知训练**：将后果权重纳入 VLM 的微调目标，使模型在生成阶段就直接感知不对称代价，而非仅在 token 预算分配阶段进行后处理。
2. **学习式后果预测器**：用轻量分类器替代冻结关键词规则，利用问题文本、任务身份、应用元数据联合预测后果层级，并显式建模预测置信度。
3. **分层级选择器联合优化**：当前选择器与分配器是级联关系，未来可联合搜索“层级划分 + 预算分配 + 选择器类型”，实现更细粒度的系统级优化。
4. **延迟导向的预算约束**：本文以 token 数为预算约束，实际部署中更关心端到端延迟或显存峰值；可扩展为在延迟 SLO 约束下做代价敏感分配。
5. **更丰富的后果结构**：本文使用二值后果层级（高/低）与标量代价，真实场景可能有多级后果、非对称代价矩阵甚至部分错误不可接受（代价无穷大），需要更一般的分配框架。

---

## 8. 总体评价与启示

本文是一篇定位清晰、设计严谨的实证研究。它的核心贡献不在于提出一种新的视觉 token 选择算法，而在于**重新定义了视觉 token 压缩的优化目标**——从“最小化平均错误率”转向“最小化代价加权错误”，并证明了在后果不对称条件下即便图像内容完全相同、token 敏感度无差异，后果信息本身也足以带来显著的资源分配增益。

方法上最值得肯定的是**任务内设计**：通过构造高低后果层、保持图像分布严格一致，论文有效地排除了内容混杂因素，使因果归因成立。等预算协议、McNemar 配对检验、bootstrap 置信区间、分裂半校准等统计细节也明显高于该领域常规水准。分配原则的离散化处理（交换条件替代水填充）体现了对实际问题非凸、非连续特性的尊重。

与此同时，论文也诚实地暴露了该方向的开放问题：后果权重的来源、层级判定的可靠性、跨架构的增益稳定性。这些局限不削弱核心结论，但决定了该方法能否从研究原型走向实际部署，还取决于领域代价建模的成熟度。

**一句话总结**：当错误的代价不对称时，视觉 token 压缩不应只追求平均准确率最大化，而应根据后果权重重新分配预算；本文用严格的受控实验证明了这一原则的有效性与边界条件。
