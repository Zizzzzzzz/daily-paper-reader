## 摘要
丰富的视觉信息增强了视觉-语言模型（VLM）的感知能力，但海量的视觉令牌却导致推理成本上升。现有的视觉令牌剪枝方法依赖于基于相似性的引导，利用文本-视觉及视觉-视觉令牌之间的成对相关性进行压缩。然而，这些方法仅捕捉局部的层内信号，忽略了VLM中的整体推理过程。本文重新审视VLM推理过程，提出了一种补充相似性引导的高效引导方案。具体而言，我们发现一个关键现象：随着LLM层数的加深，文本令牌通过自注意力不断聚合视觉信息，并逐步将部分视觉内容吸收进文本表示中。为量化该现象，我们从几何表示角度提出跨模态吸收（CMA）指标，用于衡量文本吸收了多少视觉信息，并揭示出更深层中更多视觉令牌可近似由文本子空间解释。基于此，我们提出跨模态残差（CMR）方法，通过Tikhonov正则化最小二乘将视觉令牌投影到文本子空间，并利用重建残差量化无法由文本解释的视觉信息。最终，基于CMR，我们提出SIEVE——一种免训练的视觉令牌压缩方法，它结合CMR、文本注意力相关性和残差空间多样性，以保留任务相关且互补的令牌。在多种VLM架构上的实验验证了SIEVE的有效性。例如，在LLaVA-NeXT-7B上，SIEVE仅保留11.1%的视觉令牌，同时保持了原始平均性能的97.5%，实现了3.62倍的预填充加速、2.49倍的端到端加速以及6.02倍的KV缓存缩减。

## Abstract
Abundant visual information strengthens vision-language model (VLM) perception, yet massive visual tokens raise inference costs. Existing visual token pruning methods rely on similarity-based guidance, which exploits pairwise text-vision and vision-vision token correlations for compression. However, such methods only capture local layer-level signals and overlook the whole inference process in VLM. In this paper, we revisit VLM inference and present a new efficient guidance scheme that complements similarity-based guidance. In particular, we identify a key observation: as LLM layers deepen, text tokens continuously aggregate visual information via self-attention and progressively absorb partial visual content into textual representations. To quantify this phenomenon, we propose Cross Modal Absorption (CMA) from a geometric representation perspective to measure how much visual information is absorbed by text, revealing that more visual tokens in deeper layers can be approximately explained by the text subspace. We accordingly propose Cross Modal Residual (CMR). It projects visual tokens onto the text subspace via Tikhonov regularized least squares and exploits reconstruction residuals to quantify visual information that cannot be explained by text. Finally, based on CMR, we present SIEVE, a training-free visual token compression method that combines CMR, text-attention relevance, and residual-space diversity to retain task-relevant and complementary tokens. Experiments on diverse VLM architectures verify the effectiveness of SIEVE. For instance, on LLaVA-NeXT-7B, SIEVE keeps only $11.1\%$ of visual tokens while preserving $97.5\%$ of the original average performance, achieving $3.62\times$ prefill speedup, $2.49\times$ end-to-end speedup, and a $6.02\times$ KV-cache reduction.

## 二、方法论

### 整体框架：SIEVE
SIEVE是一个**免训练的即插即用**视觉令牌压缩方法，从三个互补视角选择令牌：
1. **CMR（跨模态残差）**：衡量视觉令牌中无法被文本子空间解释的独特视觉信息
2. **文本注意力相关性**：衡量视觉令牌与当前文本上下文的任务相关度
3. **残差空间多样性**：在残差空间中抑制冗余令牌，确保保留的令牌互补

### 关键技术细节

#### 1. 跨模态吸收（CMA）——层级度量
- 定义：CMA = 1 − ||V_c − V̂_c||²_F / ||V_c||²_F，其中V_c为居中后的视觉令牌矩阵，V̂_c为其在文本子空间上的投影。
- 作用：从整体层面度量"文本子空间对视觉表示的解释程度"，揭示跨模态吸收的单调递增趋势。

#### 2. 跨模态残差（CMR）——令牌级度量
**构建步骤**：
- 以文本均值进行居中：t̄ = (1/N_t)ΣT_j，T_c = T − t̄，V_c = V − t̄
- 对每个居中视觉令牌v_{c,i}，通过Tikhonov正则化最小二乘将其重建为文本令牌的线性组合：
  - b_i = argmin ||v_{c,i} − b_iT_c||² + λ||b_i||²
- 正则化系数λ自适应设定：计算文本Gram矩阵G = T_cT_c⊤，按特征值能量比例η确定有效维度k，设λ = σ²_k + ε
- 闭式解：b_i = v_{c,i}T_c⊤(G + λI)⁻¹，v̂_{c,i} = b_iT_c
- **CMR分数**定义为归一化重建残差：CMR_i = ||v_{c,i} − v̂_{c,i}||₂ / ||v_{c,i}||₂
  - 残差越大 → 文本无法解释的独特视觉信息越多 → 保留必要性越高

#### 3. 注意力信号构建
- 计算文本令牌对每个视觉令牌的注意力权重（仅取注意力质量最高的top ρ_h比例的头）
- 与FlashAttention兼容：采用"双重前向"策略，通过辅助值矩阵（标记视觉令牌位置）在不显式物化完整注意力矩阵的情况下提取所需信号。

#### 4. 引导分数整合
- 综合分数：Score_i = a²_i · CMR²_i（乘法融合）
- 乘法融合使令牌需同时具备语义相关性和几何残差信息，避免单一信号主导，同时抑制仅在某一信号上得分异常高的背景/噪声令牌。

#### 5. 残差空间多样性选择
- **残差相似度度量**：在残差空间中用平方余弦相似度 g_ij = (r_i⊤r_j / (||r_i||₂||r_j||₂))² 衡量令牌间冗余——残差空间已去除文本可解释分量，方向更能反映真正的独特视觉信息
- **贪心选择**：迭代选择分数最高的令牌，之后对剩余令牌按相似度打折：Score_j ← Score_j(1 − g_{i*j})，直到选满预算K个令牌。

### 计算效率
- CMR投影有闭式解，无需迭代优化；主要额外开销为残差空间Gram矩阵计算O(N_v²d)，但遵循"一次性评分、多层受益"模式，净加速条件为后续层的序列缩短收益 > 剪枝层的评分开销。

## 六、主要结论与发现

1. **跨模态吸收现象确凿存在**：CMA随层深度单调递增（ρ=+0.99），深层中更多视觉信息可由文本子空间解释；终结层CMA约为随机基线29倍，说明文本子空间解释力远超偶然水平。
2. **SIEVE在不同架构和压缩比下均达到最佳或接近最佳性能**：
   - LLaVA-1.5-7B：保留64个令牌（11.1%）时保持96.0%性能，比最强基线SCOPE高0.6个百分点
   - LLaVA-NeXT-7B：保留320个令牌（11.1%）时保持97.5%性能，比DART/HoloV高1.4/1.3个百分点
   - Qwen2.5-VL-7B：11.1%预算下比FastV高9.2、比HoloV高2.3个百分点
3. **残差空间多样性至关重要**：直接用Top-K选择性能骤降至90.13%（−6.46），说明"选什么"和"选得多样"缺一不可。
4. **注意力与CMR高度互补**：两者所选令牌的平均重叠率仅约11.54%，乘法融合显著优于单独信号和加性融合。
5. **推理效率大幅提升**：以较小额外评分开销换取后续所有层的序列缩短收益，实现数倍加速和KV缓存大幅缩减。

## 七、优点

1. **新颖的观察视角**：首次从跨模态信息吸收的角度审视VLM推理，揭示"视觉信息逐步被文本同化"的动态过程，超越静态的层内相似性分析。
2. **方法设计简洁且优雅**：CMR将高维几何问题转化为Tikhonov正则化最小二乘问题，有闭式解，计算轻量；自适应λ避免手工调参。
3. **三信号互补框架**：CMR（视觉独特性）+ 注意力（任务相关性）+ 残差多样性（互补性）三者形成完整的选择逻辑，且各有不可替代的作用（重叠率仅11.54%证明了互补性）。
4. **免训练、即插即用**：无需任何训练或微调，可直接应用于现有VLM，实用性强。
5. **对FlashAttention友好**：设计了辅助值矩阵的双重前向策略，在流式计算框架下也能获取注意力信号，兼顾效率与兼容性。
6. **理论分析扎实**：附录中对CMA的有效尺度（随机基线上界 vs 理论上界）进行了严格的数学推导，避免了对数值的误读。

## 八、不足与局限

1. **多模态吸收的非均匀性未充分利用**：论文展示了不同令牌的吸收程度具有高度非均匀稀疏结构（少数令牌即使深层仍保持高CMR），但SIEVE在固定层执行统一剪枝策略，未利用不同层的最优剪枝时机差异（如自适应决定在哪些层剪多少）。
2. **实验规模有限**：
   - 仅在7B规模模型上验证，未覆盖更大模型（13B/72B）或更小型高效模型
   - 仅评测图像任务，未覆盖视频理解等长视觉序列场景（虽然附录讨论了理论适用性）
3. **超参数仍需人工设定**：虽然η和H_top的敏感性低、鲁棒性好，但剪枝层选择、令牌预算K等仍需按任务/模型人工配置。
4. **注意力信号与FlashAttention的兼容性代价**：双重前向策略需要额外一次注意力计算（尽管只涉及少量剪枝层），在极长序列下辅助计算本身可能成为瓶颈。
5. **基准覆盖的偏差风险**：8个基准中多数为VQA类任务，对细粒度定位、文档理解、多图推理等场景的覆盖不足。
6. **与SparseVLM的对比可能不完全公平**：SIEVE利用了注意力信号（与SparseVLM同类信息）加上CMR和多样性；但对比方法的实现是否经过同等程度的超参调优未明确说明。
7. **未报告多次运行的方差**：缺乏统计显著性分析，无法确认某些小差距（如0.1~0.3个百分点）是否在噪声范围内。
