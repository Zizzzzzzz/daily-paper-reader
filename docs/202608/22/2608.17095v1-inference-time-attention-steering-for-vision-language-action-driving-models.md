## 摘要
视觉-语言-动作（VLA）驾驶模型将推理阶段与基于扩散的轨迹解码器耦合在一起，但并未提供一种直接的方法，在不重新训练的情况下，在推理时将注意力重新定向到安全关键的交通参与者上。我们在Alpamayo-R1的Qwen3-VL骨干网络上，对检测器定位的交通参与者的视觉token施加了一个有界的加性softmax前注意力偏置。该偏置以故障开放的前置钩子（fail-open forward pre-hook）形式应用，不改变任何权重。在来自Physical AI World Model Synthetic数据集的50个变道场景中，轨迹解码器在偏置幅度上表现出单调的剂量反应，并且在每个测试幅度下，与配对的零偏置对照相比，效果均有所不同。在钳位处，平均位移约为17厘米，横向偏移可达约140厘米。层消融实验表明，动作相关信号位于后期层中，效果随钩住层数的增加而增强（前8层为2.0厘米；全部36层为67.6厘米）。逐调用注入审计解释了为什么因果链文本从不改变。基于掩码的偏置在此服务栈中从未到达推理路径，因此这种不变性是已证实的暴露，而非鲁棒性。被引导的轨迹倾向于朝向被关注的参与者移动，这表明偏置控制的是模型的注视位置，而非编码目标行为。

## Abstract
Vision-language-action (VLA) driving models couple a reasoning stage with a diffusion-based trajectory decoder, but do not give a direct way to redirect attention toward safety-critical actors at inference time without retraining. We studied a bounded additive pre-softmax attention bias on the visual tokens of detector localized traffic actors on Alpamayo-R1's Qwen3-VL backbone. It is applied as a fail open forward pre-hook with no weight changes. On 50 lane-change scenarios from the Physical AI World Model Synthetic dataset. The trajectory decoder shows a monotonic dose response in the bias magnitude, separate from a paired zero bias control at every tested magnitude. It reaches $\approx 17$\,cm mean displacement with lateral shifts up to $\sim 140$\ cm at the clamp. A layer ablation places the action-relevant signal in late layers, where the effect increases with the number of hooked layers (2.0cm for the first 8 layers; 67.6cm for all 36). A per call injection audit explains why the Chain-of-Causation text never changes. The mask based bias never reaches the reasoning pathway in this serving stack, so the invariance is verified exposure, not robustness. Steered trajectories tend to shift toward the attended actor, suggesting the bias governs where the model looks rather than encoding a target behavior.

## 1. 论文的核心问题与整体含义

**研究动机与背景**

- 视觉-语言-动作（VLA）驾驶模型（如 Alpamayo-R1）将推理阶段与基于扩散的轨迹解码器耦合，成为端到端自动驾驶的新范式。此类模型通常基于大语言模型骨干（如 Qwen3-VL），联合处理多摄像头输入、生成自然语言推理链（Chain-of-Causation, CoC）并输出未来轨迹路点。
- 然而，VLA 模型存在结构性局限：一旦部署，其视觉 token 上的注意力分配便由训练固定。若模型对安全关键参与者（如盲区中的并线车辆、人行横道上的行人）注意力不足，现有部署体系下缺乏在推理时无需重训练即可重新定向注意力的机制。对于 10B+ 参数模型，重训练成本极高，且破坏部署模块化。
- 推理时注意力引导在 LLM 领域已有研究（PASTA、InstABoost、SpotLight 等），但此前尚无工作将其应用于 VLA 驾驶模型，也没有研究此类干预在混合架构（语言推理 + 扩散动作解码）中的传播行为。

**整体含义**

- 本研究在 Alpamayo-R1's Qwen3-VL 骨干上，对检测器定位的交通参与者视觉 token 施加**有界加性 pre-softmax 注意力偏置**，以故障开放的前向钩子形式注入，不改变任何权重。
- 核心研究发现：偏置在 50 个变道场景中产生**单调剂量反应**，平均位移约 17 cm，横向偏移最多约 140 cm；效果集中于后期 transformer 层并随层数累积。CoC 文本在所有实验条件下均不变——但逐调用审计证明这只是**暴露不对称**的产物，而非架构鲁棒性。被引导的轨迹倾向于移向被关注参与者的方向，说明偏置控制模型的"注视位置"而非编码目标行为语义。

## 2. 论文提出的方法论

**核心思想**

- 在不修改任何模型权重的前提下，通过向特定视觉 token 的注意力 logits 注入有界偏置，增加模型对检测到的交通参与者的注意力质量，从而影响扩散轨迹解码器的输出。

**关键技术细节**

1. **有界加性 pre-softmax 偏置（Bounded Additive Pre-Softmax Bias）**：
   - 在 Qwen3-VL 的 grouped-query attention 与 per-head QK-Norm 框架下，对目标 token 集合 \( T_A \) 的注意力 logits 添加常量偏置 \( b_j = \min(\lambda, \beta) \)，其中 \( \lambda \) 为幅度控制参数，\( \beta \) 为安全钳位，\( k_{\text{sink}} \) 为保护初始 sink 位置的参数。
   - 公式形式：\( \tilde{z}_{q,j} = z_{q,j} + b_j \)，即 softmax 前的加法偏置。
   - 加法形式与 FlashAttention 兼容；钳位 \( \beta \) 防止过强偏置导致指令过度聚焦而退化生成质量。
   - 命题 1 保证：在 \( 0 < \lambda \leq \beta \) 下，目标 token 上的注意力质量不会低于原始值且随 \( \lambda \) 单调增加（标准 softmax 代数性质的直接推论）。

2. **参与者检测与 token 映射（Actor Detection and Token Mapping）**：
   - 使用 YOLO11-nano 检测器在模型输入分辨率（576×320）的最近上下文帧上运行，通过针孔模型估计距离与横向偏移，选出 5–40 m 纵向范围、±4 m 横向带内的最近车辆作为目标参与者。
   - 通过 Qwen3-VL 的 patch 尺寸与 2×2 空间合并因子（产生 10×18 token 网格）将检测框映射到精确的视觉 token 索引，公式为网格单元算术后加上序列偏移。
   - **逐次验证**：每个 token 索引都对照 tokenizer 的视频 token 区间进行核对，越界即拒绝，防止 resize 管线漂移造成静默失效。

3. **实现与暴露审计（Exposure Audit）**：
   - 通过 `register_forward_pre_hook` 在 Qwen3-VL 自注意力模块上注入偏置，编辑 `attention_mask` 关键字参数（4D 浮点张量，被掩码位置为 −∞，未掩码位置为 0）。
   - 钩子为**故障开放**设计：缺少掩码参数或形状不匹配时原样返回并记录跳过。
   - **关键审计发现**：在部署的服务路径中，CoC 的 prefill 和解码阶段通过融合因果核调用注意力（无显式掩码），注入永远不会触及推理路径；而扩散动作解码器的前向传播携带显式 4D 掩码，因此接受偏置。这定义了干预的"实际暴露范围"。

4. **层选择（Layer Selection）**：可配置钩子安装的子集（全部、最后 k 层、前 k 层、中间 k 层），用于消融实验。

## 3. 实验设计

- **数据集**：50 个变道场景，来自 **PhysicalAI WorldModel-Synthetic Autonomous Driving Scenarios** 数据集（NVIDIA 发布的 Omniverse 渲染多摄像头合成视频）。使用前置广角摄像头，4 帧上下文，0.5 秒步长，分辨率 576×320。
- **场景选择**：按排序程序选取，要求检测到 5–40 m 范围内、±4 m 横向带内的前车，偏好约 20 m 距离，并按数据集的环境排列扩展去重。
- **模型**：Alpamayo-R1-10B（Qwen3-VL 骨干 + 扩散动作头），NF4 量化，36 层 transformer，8 个 KV 头、28 个 query 头，轨迹为 64 个路点 @ 10 Hz（6.4 秒视野）。
- **Benchmark 与对比方法**：本研究不是标准 benchmark 竞赛性质。基线对比为**配对零偏置对照**（即同一随机种子下 head_scale=0 的基线轨迹），并验证其与基线逐位一致（ADE ≡ 0）。没有与其他推理时注意力引导方法进行直接对比——作者明确说明本研究的对象是干预的传播行为而非其效用。
- **关键协议**：**配对种子协议（Paired-seed Protocol）**——基线与引导运行共享相同随机种子和确定性算法配置，任何非零差异均归因于偏置；零偏置门控验证配对精确性。
- **评价指标**：
  - ADE（平均位移误差）：配对基线–引导轨迹间的平均 L2 距离；
  - 最大横向偏移；
  - CoC 精确字符串匹配变化率；
  - Cliff's δ 与 Wilcoxon 符号秩检验（Holm 校正）；
  - 相对于被关注参与者侧面的转移方向分析。

## 6. 论文的主要结论与发现

1. **干预精确实现**：钩子在所有目标列精确添加 +λ（均值为 +4.0），非目标列为 0，零越界事件，且 40 次偏置注意力调用全部发生在扩散动作解码器阶段。
2. **单调剂量-反应**：ADE 从 λ=0.5 时的亚厘米级单调增长至 λ=4 时的均值 ≈17 cm；最大横向偏移均值 ≈38 cm，个别案例最高 ≈140 cm。所有非零条件均与配对零偏置对照高度显著分离（p ≪ 10⁻¹⁰），Cliff's δ=1.0。
3. **采样器噪声地板比效应大 30 倍**：交叉种子的基线间平均距离为 3.23 m，而偏置效应平均 0.107 m——非配对比较必然淹没效应，配对协议是必要条件，也说明效应可检测但量级远小于采样随机性。
4. **后期层主导**：first_8 层几乎惰性（ADE 2.0 cm），last_4 即达 11.5 cm，last_8 为 16.7 cm，全部 36 层为 67.6 cm；横向位移相应达到 205.5 cm。效果随钩住层数大致单调累积。
5. **轨迹几何**：偏差在滚动前期（约前 2 秒）近似为零，随后超线性增长，最大横向偏移出现在预测视野末端——扩散解码器将扰动的视觉条件整合在整条路点序列上，而非单步响应。
6. **朝向偏移倾向**：在参与者保持在自车前方的时间步长内，被引导轨迹倾向移向参与者所在侧；作者将其解释为偏置调节视觉显著性（"模型看哪里"）而非编码目标行为（"该做什么"）。
7. **CoC 不变性 = 暴露不对称，而非鲁棒性**：推理路径从未被偏置触及（融合因果核不带显式掩码），因此 CoC 文本不变是"已验证的未暴露"；在 T=1.0 温度下依然不变完全是暴露问题而非确定性解码的假象。

## 7. 优点

1. **严谨的实验协议设计**：配对种子协议让厘米级效应从数米量级的扩散采样器噪声中分离出来，零偏置门控（ADE≡0）验证配对精确性，这是本方法最突出的方法论亮点。
2. **暴露审计（exposure audit）的引入**：逐调用追踪偏置实际到达的前向通道，直接纠正了"CoC 不变=鲁棒性"的误导性解读，为复合多模态架构上的干预研究设立了可复现的报告标准。
3. **诚实且克制的主张边界**：明确声明不对"更好驾驶"做效用声明；主动披露 Cliff's δ=1.0 是构造性结果的局限性；承认方向分析只是定性观察；明确指出匹配对照缺失意味着不能主张参与者特异性。
4. **工程实现的小巧与稳健**：故障开放钩子、钳位防抑制、sink 保护、逐次 token 映射验证——细节设计考虑周全，且所有机制都是轻量、模块化、可替换的。
5. **清晰的层级定位与实用旋钮**：层消融表明偏置幅度 λ 和层子集 L 是两个独立的调节旋钮，后者能在固定 λ 时提供更细粒度的控制。
6. **对安全 VLA 设计有双重启示**：一方面风险模块可通过偏置调节规划而不干扰可解释推理链（且可审计证明推理轨迹未被操纵）；另一方面 CoC 文本不能作为轨迹级干预的监控信号——这一负结果同样重要。

## 8. 不足与局限

1. **合成环境局限**：所有数据均为 Omniverse 渲染的合成视频，无记录的自车状态（ego state），自车历史为合成的匀速直线模型。虽有基线 CoC 连贯性和零偏置门控两道保障，但**合成到真实的迁移完全未测试**，真实日志中更复杂的参与者几何形状是否保持剂量反应仍是开放问题。
2. **开环评估**：轨迹作为单次前向传播的预测进行评估，未在 Bench2Drive 等基准上做闭环评估，无法判断位移在真实闭环中的语义好坏。
3. **单模型单任务**：仅在 Alpamayo-R1-10B 上验证了变道场景；对行人、十字路口、多参与者场景以及 VLA 架构的泛化只是假设而非已验证事实。
4. **语言路径暴露未建立**：推理路径从未被实际扰动，因此该路径对注意力扰动的敏感性既未证实也未证伪，是最重要的后续工作。
5. **方向解释的定性与不完整**：toward-actor 倾向依赖"参与者保持在自车前方"的常速模型假设，部分逐时间步的方向信号会翻转；缺少更丰富的反事实设计。
6. **缺失匹配对照干预**：零偏置对照能证明"轨迹对偏置有响应"，但不能证明"对参与者本身有响应"。固定偏置 token 数量而改变其描绘内容（平移/镜像框、背景区域、第二辆车、散点 token 集）的对照实验是作者自认为最重要的缺失实验——没有它就不能主张参与者特异性。
7. **样本量有限**：层消融仅基于 5 个场景，虽然规律清晰，但统计稳定性有限；50 个主实验场景也仅覆盖合成变道情形。
