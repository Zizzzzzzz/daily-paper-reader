## 摘要
RS-LVLM推进了地球观测图像的多模态理解，但其性能从根本上受限于高分辨率处理，因为视觉令牌数量随线性输入分辨率呈二次方增长，而重要的视觉证据本质上是稀疏的，并在扩展的序列中逐渐被稀释。现有的令牌剪枝方法大多依赖于尺度无关的分辨率策略和孤立的显著性线索，限制了任务对齐的粒度自适应和整体证据保留。为解决这一问题，我们提出了尺度自适应与地理空间证据调制令牌剪枝（SA-GEM），这是一个即插即用框架，统一了任务自适应令牌粒度分配与整体地理空间令牌重要性调制。具体而言，一个轻量级路由器根据查询相关的令牌粒度选择分辨率，而一个令牌重要性调制器则联合建模任务相关性、空间结构和局部冗余，以保留整体地理空间证据。我们表明，更高的分辨率并非普遍有益，一旦达到足够的粒度，令牌质量比令牌数量更重要。跨多个基准的实验表明，SA-GEM在准确性和效率上均比现有剪枝方法取得了一致的提升。在XLRS-Bench上，它以2.4倍的总推理加速在准确率上超过GeoLLaVA-8K达2.3%。

## Abstract
RS-LVLMs have advanced multimodal understanding of Earth observation imagery, yet their performance is fundamentally constrained by high-resolution processing, as visual token counts grow quadratically with linear input resolution while important visual evidence is inherently sparse and increasingly diluted across the expanded sequence. Existing token pruning methods largely rely on scale-agnostic resolution policies and isolated importance cues, limiting task-aligned granularity adaptation and holistic evidence preservation. To address this, we present Scale-Adaptive and Geospatial Evidence-Modulated Token Pruning (SA-GEM), a plug-and-play framework that unifies task-adaptive token granularity allocation with holistic geospatial token importance modulation. Specifically, a lightweight router selects the resolution based on query-dependent token granularity, while a token importance modulator jointly models task relevance, spatial structure, and local redundancy to preserve holistic geospatial evidence. We show that higher resolution is not universally beneficial and, once sufficient granularity is reached, token quality matters more than token quantity. Experiments across various benchmarks demonstrate that SA-GEM achieves consistent gains in both accuracy and efficiency over existing pruning methods. On XLRS-Bench, it surpasses GeoLLaVA-8K by 2.3% in accuracy with a 2.4 times total inference speedup.

- **现有方法局限**：
  - 已有令牌剪枝方法（如 RFM-DIP、GeoLLaVA-8K、UHR-BAT）多沿用自然图像 LVLM 的剪枝准则，依赖单一重要性线索（任务注意力、视觉注意力或冗余合并），难以保留互补上下文与弱激活但关键的地理证据，甚至可能破坏空间结构与连续性。
  - 现有方法普遍假设“更高分辨率对所有任务都有益”，忽略了不同任务对视觉粒度的差异化需求——全局场景理解偏好低分辨率，而细粒度感知需要高分辨率。
- **核心洞察**：一旦达到足够粒度，令牌质量比令牌数量更重要；高分辨率并非普遍有益。因此需要一种“任务自适应粒度分配 + 整体地理空间证据保留”的统一剪枝框架。

## 2. 方法论：SA-GEM

SA-GEM 是一个即插即用（plug-and-play）框架，包含两个核心组件：

### 2.1 任务自适应粒度路由（Task-Adaptive Granularity Routing）

- 训练一个轻量级 MLP 路由器，将查询文本的嵌入表示映射到四个有序粒度级别：全局（global）、区域（regional）、组合（compositional）、细粒度（fine-grained）。
- 查询表示通过带掩码的均值池化得到：  
  \[
  \bar{q} = \frac{\sum_j m_j q_j}{\sum_j m_j}
  \]
- 路由器通过交叉熵损失离线训练，伪标签由多个基础模型对查询的粒度预测进行多数投票生成（无人工标注）。
- 推理时，路由器选出粒度组，并查表获得对应的输入分辨率 \(R\)、剪枝比例 \(\rho\) 与小波配置 \(\psi\)。

### 2.2 整体地理空间证据调制（Holistic Geospatial Evidence Modulation）

对每个视觉令牌 \(v_i\) 计算重要性分数 \(S_i\)，融合三类互补证据：

- **任务相关语义对齐分数** \(E_i^t\)：
  - 利用视觉编码器最后一层自注意力输出（解耦后的注意力分量 \(A_d\)）与查询表示 \(q\) 的余弦相似度：
    \[
    E_i^t = \cos(a_i, q)
    \]
  - 作用：定位查询相关的目标区域，避免被视觉显著但与任务无关的区域干扰。

- **尺度自适应空间结构分数** \(E_i^s\)：
  - 对图像进行 L 级离散小波变换（DWT），聚合高频子带（LH、HL、HH）的响应，投影到令牌网格上：
    \[
    E^s = \sum_{\ell=1}^L \mathcal{U}_t\left(\sum_{s\in\{LH,HL,HH\}} |I_\ell^s|\right)
    \]
  - 作用：突出边界、地物过渡带和拓扑结构等地理空间关键线索；小波基与分解层级可随分辨率自适应调整。

- **动态局部冗余掩码** \(M_i^d\)：
  - 在空间邻域窗口内计算令牌间的特征差异与空间距离加权成本，得到局部变化分数 \(E_i^d\)。
  - 使用四分位距（IQR）准则识别高度冗余的令牌（例如大片水体、农田、森林），生成二值掩码：
    \[
    M_i^d = \mathbb{I}\left(E_i^d \le Q_1 - 1.5 \cdot \text{IQR}\right)
    \]
  - 作用：自适应抑制同质区域，将令牌预算重新分配给信息更丰富的区域。

### 2.3 分数整合与 Top-K 选择

- 最终重要性分数：
  \[
  S_i = \mathcal{N}\left(E_i^t \cdot E_i^s\right) - M_i^d
  \]
- 其中 \(\mathcal{N}\) 为归一化；乘法耦合任务意图与结构上下文，冗余掩码以减法惩罚冗余令牌。
- 最终使用 Top-K 选择保留 \(K = \lfloor (1-\rho)N\rfloor\) 个令牌，送入 LLM 解码。

- **SA-GEM 的优越性**：
