## 摘要
检索增强生成（RAG）的预填充成本与检索上下文长度成正比，并且在Transformer骨干网络中，KV缓存会随每个生成token的增长而增大。状态空间模型（SSM）在结构上避免了第二种成本；我们消除了第一种成本，将每个查询的预填充从O(L_context)降至O(1)。我们引入了PRECOG（预计算上下文注入），这是一种利用SSM独有属性的检索机制：固定大小、位置无关的循环隐藏状态是模型所读全部内容的完整摘要。PRECOG离线将文档语料库预编码为SSM隐藏状态，并在查询时直接注入最佳匹配状态，完全绕过了上下文中的重新消化。相同的状态注入机制支持SMC（结构化记忆整合）：一种具有认知域聚类的分层持久记忆，可调节的保真度与存储旋钮，以及O(1)会话初始化，将短期情景状态整合为长期语义记忆，并在查询时将两者与检索到的语料库状态融合。我们在TENNs-LLM上演示了该系统，这是一个具有192 KB隐藏状态的12亿参数门控SSM语言模型。PRECOG在回答质量上与上下文RAG相当，将边缘硬件上的预填充延迟从约27秒降至不到6毫秒——约4500倍的加速，跨越了从不可用到交互的阈值。该机制在架构上对于Transformer KV缓存是不可能的，因为后者与位置纠缠且随上下文长度线性增长。

## Abstract
Retrieval-augmented generation (RAG) imposes a prefill cost proportional to retrieved context length, and -- with Transformer backbones -- a KV-cache that grows with each generated token. State-Space Models (SSMs) avoid the second cost by construction; we eliminate the first, collapsing prefill from $O(L_{context})$ to $O(1)$ per query. We introduce PRECOG (Pre-Computed Context Injection), a retrieval mechanism that exploits a property unique to SSMs: the fixed-size, position-agnostic recurrent hidden state is a complete summary of everything the model has read. PRECOG pre-encodes document corpora offline as SSM hidden states and injects the best-matching state directly at query time, bypassing in-context re-ingestion entirely. The same state-injection mechanism enables SMC (Structured Memory Consolidation): a hierarchical persistent memory with cognitive-domain clustering, an adjustable fidelity-vs-storage dial, and $O(1)$ session initialization, which consolidates short-term episodic states into long-term semantic memory and fuses both with retrieved corpus states at query time. We demonstrate the system on TENNs-LLM, a 1.2B-parameter gated-SSM language model with a 192 KB hidden state. PRECOG matches in-context RAG answer quality, reducing prefill latency from $\sim$27 s to $<$6 ms on edge hardware -- a $\sim$4500$\times$ speedup that crosses the threshold from unusable to interactive. The mechanism is architecturally impossible for Transformer KV-caches, which are position-entangled and grow linearly with context length.

### 1. 核心问题与整体含义（研究动机与背景）

- **Transformer 的两大结构性局限**：KV 缓存随上下文长度线性增长，且缓存与绝对位置纠缠（如 RoPE），导致长上下文推理成本高、缓存跨上下文无法复用。
- **边缘部署的痛点**：在带宽受限的边缘硬件上，RAG 需要对检索到的上下文进行逐 token 预填充（prefill）。以 1.2B 模型为例，处理 512-token 块需要约 27 秒，完全无法实现交互式体验。
- **SSM 的独特优势**：状态空间模型将历史上下文压缩为固定大小、位置无关的循环隐藏状态，逐 token 推理内存为 O(1)。已有工作主要将其作为效率改进，但本文将其上升到**架构性算法重构**的高度：利用SSM隐藏状态的可注入性，彻底消除 RAG 上下文的预填充成本。
- **整体含义**：首次证明并实现了"预计算上下文 → 直接注入状态"的 RAG 范式，将预填充从 O(L_context) 降为 O(1)，并扩展出结构化持久记忆机制 SMC；该机制在 Transformer 架构上在原理上不可行。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 PRECOG：预计算上下文注入

- **核心思想**：SSM 的隐藏状态是模型读取内容的完整摘要。将文档块离线编码为隐藏状态，查询时直接注入该状态作为初始条件，使模型"仿佛"已读取该内容，而无需重新逐 token 处理。
- **离线索引阶段**：
  - 知识库分块（默认 512 tokens）；每块经 SSM 前向传播一次，捕获 24 层最终隐藏状态 ¯h(i) ∈ R^{24×4096}，FP16 存储共 192 KB（与块长无关）。
  - 用轻量级句子编码器（all-MiniLM-L12-v2，384 维）生成检索键 k_i = φ(c_i)；键向量存 DRAM 并建 FAISS 索引；完整隐藏状态存闪存，按需加载。
- **查询注入阶段**：
  - 编码查询 → FAISS top-k 检索 → 闪存加载对应状态（192 KB）→ 注入为 SSM 初始状态 → 模型仅处理查询 token。
  - 端到端开销约 6 ms（编码 5 ms + 检索 <1 ms + 状态加载/注入 <1 ms）。
- **理论保证（定理 1）**：SSM 更新映射 Φ(h,x) 仅依赖当前时刻 (h,x)，无显式时间依赖（时间平移不变性）。因此 S(h₀, c ⊕ q) = S(S(h₀, c), q)，即 PRECOG 与 in-context RAG 产生**逐位相同**的状态轨迹（FP16 量化误差有界）。PRECOG 不是近似，而是同一计算的代数重构。
- **为何 Transformer 不成立**：RoPE 使 KV 更新依赖绝对位置，预计算的缓存无法在其他位置复用；重算即重新消化，无预填充节省。

#### 2.2 SMC：结构化记忆整合

- **层次化聚类路由**：对话块编码为状态轨迹后，按 5 个认知域（情感、时间、社交、空间、事实）两级路由（域 → 子簇）；子簇分 Type-A（精确回忆）与 Type-B（稳定压缩）两类。
- **保真度-存储旋钮（K 参数）**：K=N_c（无损逐状态）、K=N_c/k（抽稀）、K=1（仅最终状态，与 PRECOG 状态相同）。
- **语义整合与 O(1) 会话初始化**：每个子簇维护语义状态 s_{m,j}，经指数移动平均（EMA）累积分块状态；会话开始直接注入该语义状态，初始化为 O(1)。
- **联合检索**：查询时并行检索情景记忆与语料库状态，经 softmax 加权融合（式 8）后注入，统一了持久记忆与语料库检索。

### 6. 主要结论与发现

- **质量等价性得到验证**：PRECOG top-1 在 SQuAD 上与 in-context RAG 仅差 0.2 EM / 0.2 F1（58.0/73.4 vs 58.2/73.6），处于 FP16 量化界内，实证确认定理 1。
- **延迟降低约 4,500 倍**：预填充从约 27 s 降至 <6 ms（边缘硬件），TTFT 从约 27 s 降至 585 ms，跨越交互可用性阈值。
- **存储显著压缩**：192 KB 固定状态 vs Llama-3.2-1B KV 缓存 16 MB（L=512），85× 优势；随块长增加优势扩大（L=131K 时 21,845×）。
- **消融发现**：
  - 注入底部 12 层保留 99% F1（72.5 vs 73.4），存储减半；上层注入失效，说明低层负责上下文聚合。
  - top-k 组合在 HotpotQA 上 k=3 最优（+7.5 F1 over top-1），k>3 后检索召回仍增但 F1 退化，暴露线性组合启发式的局限。
  - 块长 <600 tokens 时 PRECOG 与 in-context 相当；超过后差距扩大（≥2400 tokens 时差 15 F1），实证刻画了 SSM 的记忆窗口边界。
- **SMC 聚类可行**：5 个认知域的 inter/intra 距离比均 >1.5（空间域 3.77），且能检测新兴簇。

### 8. 不足与局限

- **实验覆盖有限**：主质量验证仅在 SQuAD 一个数据集上（纯抽取式、单段证据）；未在生成式任务（摘要、对话）、开放域多跳 QA（完整 HotpotQA）、多语言等场景评估。
- **top-k 组合缺乏理论保障**：softmax 加权平均为启发式，k>3 时 F1 退化；无结构性方法确保多状态融合不丢失信息。

- **存储开销较大**：状态级检索比原始文本 RAG 贵约 200×（192 KB vs ~1 KB/块）；仅在存储约束不紧、延迟约束强的场景适用。
- **神经形态部署数字为仿真**：功率数据来自 12nm 仿真（FPGA 仅验证功能），非真实 tape-out 测量；供应商相关细节因保密未披露，外部可复现性受限。
- **SMC 验证深度不足**：聚类验证仅用虚构对话语料（哈利波特），且标签生成依赖 GPT-4o；端到端问答增益未量化，真实对话场景待验证。
- **缺少方差报告**：1,000 题单次采样、无多次运行标准差/置信区间，统计稳健性不明。
