## 摘要
多模态投机解码通过允许轻量级草稿模型提出候选令牌，供更大的目标模型并行验证，从而加速视觉-语言模型。现有方法通常将草稿模型固定于一种视觉接口，例如预定义的视觉令牌预算或静态压缩表示。然而，我们的受控视觉预算分析表明，视觉需求在不同任务和解码阶段之间差异显著，这意味着更多的视觉输入并不总是有益的。实际上，证据不足可能削弱视觉基础，而过多的上下文则增加开销并可能干扰草稿生成。我们提出FOVEA（聚焦按需视觉证据自适应），一种缓存友好的方法，构建可重用的视觉记忆，并为草稿状态动态检索有界子集。累积质量规则决定选择哪些条目以及选择多少。选中的条目被聚合为视觉读出，并通过轻量级门控残差校正与当前草稿隐藏状态融合。该校正并非将视觉令牌插入自回归上下文，而是仅修改传递给语言模型头部的表示。在多个视觉-语言骨干和多模态基准上的实验表明，FOVEA提高了草稿接受率和端到端解码速度，相比自回归解码实现了高达2.13倍加速。这些结果表明，状态条件证据检索是在整个多模态生成过程中重用固定视觉表示的有效替代方案。

## Abstract
Multimodal speculative decoding accelerates vision-language models by allowing a lightweight draft model to propose candidate tokens for parallel verification by a larger target model. Existing methods typically condition the drafter on a fixed visual interface, such as a predefined visual-token budget or a static compressed representation. However, our controlled visual-budget analysis shows that visual demand varies substantially across tasks and decoding stages, which means more visual input is not always beneficial. Actually, insufficient evidence may weaken visual grounding, while excessive context adds overhead and may disrupt drafting. We propose FOVEA (Focused On-demand Visual Evidence Adaptation), a cache-friendly approach that builds a reusable visual memory and dynamically retrieves a bounded subset for a draft state. A cumulative-mass rule determines both how many and which entries are selected. The selected entries are aggregated into a visual readout and fused with the current draft hidden state through a lightweight gated residual correction. Rather than inserting visual tokens into the autoregressive context, the correction modifies only the representation passed to the language-model head. Experiments across multiple vision-language backbones and multimodal benchmarks show that FOVEA improves draft acceptance and end-to-end decoding speed, achieving up to $2.13\times$ speedup over autoregressive decoding. These results demonstrate that state-conditioned evidence retrieval is an effective alternative to reusing a fixed visual representation throughout multimodal generation.

- **核心论点**：单一全局固定视觉接口无法适用于所有解码分支和生成阶段，需要**按当前草稿状态动态检索视觉证据**。
- **额外挑战**：状态相关的视觉选择必须与 KV 缓存复用兼容——动态插入或移除视觉令牌会改变自回归上下文，使历史缓存失效。因此，需要一种在不修改历史上下文的前提下将视觉证据注入当前令牌评分的方法。

## 2. 论文提出的方法论

### 2.1 总体框架

FOVEA（**F**ocused **O**n-demand **V**isual **E**vidence **A**daptation）包含四个核心步骤：视觉记忆构建 → 状态条件检索 → 缓存友好的隐藏状态校正 → 目标模型并行验证。

### 2.2 关键技术细节

**（1）图像专用视觉记忆（Image-specific Visual Memory）**
- 目标模型对输入图像编码后，得到投影视觉令牌序列 $V=\{v_i\}_{i=1}^N$；
- 一次性构建每图视觉记忆：$M_{img}=\{(k_i, u_i, m_i)\}_{i=1}^N$，其中：
  - $k_i = W_K \mathrm{LN}(v_i)$ 为键向量；
  - $u_i = W_U \mathrm{LN}(v_i)$ 为值向量；
  - $m_i \in \{0,1\}$ 为有效位置掩码（区分填充位）；
- 该记忆在整个生成过程中被所有草稿树节点共享，避免重复处理完整视觉序列。

**（2）状态条件 Top-$\tilde{K}_{r,n}$ 视觉证据检索**
- 对每个草稿树节点 $n$，由隐藏状态 $h_n$ 与树深度嵌入 $E_{dep}[\ell_n]$ 构成查询：$q_n = W_Q(\mathrm{LN}(h_n) + E_{dep}[\ell_n])$；
- 对所有有效视觉记忆键计算相似度分数 $s_{n,i}$，归一化后按分数降序排列；
- **累计质量规则**（Cumulative-mass rule）确定动态检索数量：
  $$\tilde{K}^{raw}_{r,n} = \min\{k : \sum_{t=1}^{k} \bar{\alpha}_{n,\pi_n(t)} \geq \rho\}$$
  其中 $\rho = 0.8$（累计质量阈值），$\pi_n(t)$ 为第 $t$ 大分数的索引；最终检索数量为：
  $$\tilde{K}_{r,n} = \min\{|V|, K_{max}, \max(K_{min}, \tilde{K}^{raw}_{r,n})\}$$
  其中 $K_{min}=32$，$K_{max}=256$；
- 对选中条目重新归一化注意力权重，聚合为视觉读出向量 $r_n = \sum_{i \in I_n} \alpha_{n,i} u_i$。
- 关键性质：所有记忆键都会被打分，动态变化的只是**聚合数量**而非打分范围，且该规则不引入可训练参数。

**（3）缓存友好的隐藏向量校正（Cache-Friendly Hidden Correction）**
- 视觉读出**不以上下文令牌形式插入**，而是通过门控残差校正修改当前评分表示：
  - 校正向量：$c_n = f_\theta([h_n; r_n])$（MLP）；
  - 自适应门：$g_n = \sigma(g_\theta([h_n; r_n]))$（标量）；
  - 校正后表示：$\hat{h}_n = \mathrm{RMSNorm}(h_n + g_n c_n)$；
  - 输出分布：$z_n = W_{LM}\hat{h}_n$。
- 草稿令牌序列、注意力掩码、位置标识和**历史 KV 缓存均保持不变**，从而避免缓存重建开销。

**（4）训练目标**
联合四项目标：
- **隐藏状态对齐** $L_{hid}$：匹配校正后草稿隐藏状态与目标隐藏状态（含中间层表示）；
- **分布蒸馏** $L_{KL}$：最小化草稿分布与教师分布（目标模型 softmax logits）之间的 KL 散度；
- **令牌级目标** $L_{tok}$：CE 硬标签监督 + 候选边界裕度损失（teacher-competitor logit gap），使草稿候选集合覆盖目标模型的 Top-$K_c$ 选择；
- 每位置权重按指数衰减 $w_n = \exp(-\frac{n-1}{\gamma_w})$，优先拟合近期令牌。

## 6. 论文的主要结论与发现

- **固定视觉预算的缺陷被证实**：视觉需求随解码状态动态变化且呈非单调关系，"更多视觉输入"并不总是更好；约 39.1% 的状态在固定预算下存在供给错配。
- **FOVEA 全面优于强基线**：
  - 平均加速比：LLaVA-Next-7B 达 1.68×、LLaVA-Next-13B 达 1.66×、Qwen2.5-VL-7B 达 1.60×；相比各自最强基线分别提升 11.3%、13.7%、13.5%；单基准最高达 2.13×（MMT-Bench）；
  - 平均接受长度：3.960 / 3.882 / 3.925，分别超过最强基线 8.1%、6.0%、5.6%；
  - 在所有 27 个骨干—基准组合中均保持高于 1× 的加速比。
- **接受长度与加速比可同时提升**：对比 Vispec 高 τ 但低加速比的现象，证明 FOVEA 额外接受的令牌没有带来不成比例的草稿端开销。
- **动态检索优于任何单一固定预算**：固定 K 的行为随任务变化呈非单调性，FOVEA 的累计质量规则在跨任务上更均衡。
- **缓存友好设计具有可量化收益**：相比"校正+重建缓存"，FOVEA 草稿时间降低 17.1%，加速比从 1.764× 提升至 1.855×，且接受长度几乎不变。

## 7. 优点

- **问题发现扎实**：通过受控视觉预算诊断实验直接验证了"固定视觉接口不最优"这一假设，用数据说话，动机充分；
- **方法设计优雅**：将"选择多少证据"与"选择哪些证据"统一到累计质量规则中，无额外参数；
- **缓存友好的创新点突出**：通过门控残差校正修改**评分表示**而非**上下文内容**，在保持状态条件视觉选择灵活性的同时规避了 KV 缓存失效问题，是一个巧妙的关键设计；
- **检索机制高效**：视觉记忆只构建一次，所有草稿节点共享；打分所有键但仅聚合 Top-$\tilde{K}$，开销可控；
- **训练目标完整**：结合隐藏状态对齐、分布蒸馏和候选边界裕度，直接针对投机解码的验证机制优化草稿分布；
- **实验严谨性较高**：数据去污、消融层次丰富、重复推理报告标准差、对缓存复用效果进行隔离量化。

## 8. 不足与局限

- **训练开销不可忽略**：需为每个目标骨干单独训练草稿模型（约 32 GPU 小时/骨干），且依赖预计算的目标模型伪标签；训练无关方法（Lookahead、PLD）虽效果较弱但零训练成本；
- **推理配置覆盖有限**：仅报告贪婪解码、固定 200 token 上限、树宽 6 / 深度 6 / 40 节点预算的配置；未探索采样温度、beam 搜索等对视觉检索行为的影响；
- **骨干泛化验证不完整**：仅覆盖 LLaVA-Next（Vicuna）和 Qwen2.5-VL 两个家族，未覆盖 MoE 架构、更大规模（如 70B+）或其他视觉编码器；诊断实验更仅使用一个骨干；
- **动态缓存管理的缺失**：虽然 FOVEA 避免改变历史 KV 缓存，但随着生成推进，KV 缓存仍在增长，论文未讨论长序列下的缓存内存管理与压缩策略；
- **公式与参数敏感性分析不足**：ρ、K_min、K_max 等关键超参数仅在主实验中取固定值，未系统分析其敏感性；
- **可视化证据较单薄**：图 5 仅展示一条轨迹的定性注意力变化，缺乏更系统的多样本统计验证；
- **外部有效性局限**：视觉记忆假设单图输入场景；多图推理、视频输入、交错图文等更复杂的多模态输入形态未验证；
- **与 TIGER 等同期工作的对比缺失**：论文提及 TIGER 为并发工作，但未在实验中进行比较。
