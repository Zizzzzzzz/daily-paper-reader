## 摘要
令牌通信（TokenCom）最近成为一种新范式，其中令牌作为通信和计算的统一单元，实现了高效的多模态语义和目标导向传输。在本文中，我们开发了Ada-TokenCom，一种基于大型自回归模型的速率自适应TokenCom框架，该框架将下一令牌预测与算术编码相结合，以在令牌级别实现超低比特率语义通信。我们提出了一种混合重建/生成方案，其中发射机利用预训练的自回归大模型对令牌序列开头的高信息量令牌进行编码和传输，而接收机使用相同模型预测其余部分。此外，我们设计了一种基于Lyapunov的算法，以动态优化源压缩率以及调制和编码方案，适应时变网络条件。仿真结果表明，我们提出的Ada-TokenCom框架优于基于数字和深度联合源信道编码的语义通信基线。

## Abstract
Token Communications (TokenCom) has recently emerged as a new paradigm in which tokens serve as unified units for communication and computation, enabling efficient multimodal semantic and goal-oriented transmission. In this paper, we develop Ada-TokenCom, a rate-adaptive TokenCom framework based on large autoregressive models, which integrates next-token prediction with arithmetic coding to achieve ultra-low bitrate semantic communication at the token level. We propose a mixed reconstruction/generation scheme, where the transmitter encodes and transmits the highly informative tokens at the beginning of the token sequence leveraging a pre-trained autoregressive large model, while the receiver uses an identical model to predict the rest. Moreover, we design a Lyapunov-based algorithm to dynamically optimize both the source compression rate and the modulation and coding scheme, adapting to time-varying network conditions. Simulation results demonstrate that our proposed Ada-TokenCom framework outperforms both digital and deep joint source-channel coding-based semantic communication baselines.

- **背景**：传统语义通信主要基于深度联合源信道编码（DeepJSCC），其学习表示往往与特定模态、任务、数据集或信道条件耦合，泛化能力有限，且难以与现有数字无线系统无缝集成。
- **TokenCom 的出现**：令牌（token）作为通信与计算的统一单元，可将多模态数据统一为令牌序列，利用预训练大模型（GFM/MLLM）的上下文与生成先验进行语义级传输。
- **现有不足**：已有 TokenCom 研究多关注令牌恢复、保护、打包、多址与边缘推理，**速率自适应**方面仍缺乏系统研究——特别是缺乏将自回归（AR）令牌压缩、接收端令牌生成、调制编码方案（MCS）选择以及长期资源约束联合优化的数字 TokenCom 框架。
- **核心问题**：如何在时变无线信道与平均符号开销约束下，利用大模型生成能力实现超低码率、可自适应速率的高效语义通信？
- **整体意义**：本文提出 Ada-TokenCom，将 AR 概率建模与算术编码（AC）结合，并通过混合“重建/生成”机制，把“显式传输信息量大的头部令牌”与“接收端生成尾部令牌”统一起来，为低速率数字语义通信提供了一条新路径。

## 2. 论文提出的方法论

### 2.1 总体架构

- 输入图像经预训练 tokenizer（VQGAN）转换为离散令牌序列 \(s=[s_1,\dots,s_N]\)，并可选附带条件令牌（如类别标签、文本 prompt）。
- 预训练 AR 大模型（如 LlamaGen）按光栅扫描顺序建模联合概率：
  \[
  p(s|s_c)=\prod_{n=1}^N p(s_n|[s]_{1:n-1},s_c)
  \]
- 发送端**只对前 \(n^*\) 个头部令牌**进行算术编码并传输；接收端先用相同 AR 模型进行算术解码恢复头部令牌，再以同样模型**自回归生成剩余的 \(N-n^*\) 个尾部令牌**，最后经 detokenizer 重建图像。

### 2.2 核心机制

- **自信息/熵分析驱动设计**：
  - 实验发现条件自信息沿令牌序列递减，即前序令牌携带更多信息，尾部令牌可基于上下文预测。
  - 条件预测熵在图像中部（主物体区域）明显偏低，说明尾部令牌在已知类标签和头部令牌后具有较大可预测性。
- **算术编码（AC）**：
  - AR 模型输出各位置条件概率分布，AC 据其递归划分子区间并生成二进制码流。
  - 编码长度接近自信息 \(\sum -\log p(s_n|\cdot)\)，实现无损压缩。
- **混合重建/生成**：
  - 头部令牌：AC 解码恢复，保持令牌域精确；
  - 尾部令牌：由接收端 AR 模型条件生成，不占用传输资源；
  - 通过调整 \(n^*\) 即可控制压缩率与重建质量，实现速率-质量折中。

### 2.3 跨层速率自适应

- 无线信道：准静态块衰落瑞利信道，支持 M-QAM 与信道编码，采用 Type-I ARQ。
- PER 近似：基于 waterfall 阈值的简化模型，将 PER 表示为平均 SNR 与包长的函数：
  \[
  \mathrm{PER}_m(L,\bar\gamma)\approx 1-\exp\left(-\frac{\alpha_m\ln L+\beta_m}{\bar\gamma}\right)
  \]
- 优化问题：在每个时隙选择 \( (n^*, m) \)，最大化长时间平均语义质量（如 CLIP 相似度），同时满足平均信道符号预算 \(C_{th}\)。
- Lyapunov 漂移加惩罚：
  - 引入虚拟队列 \(Z_t\) 跟踪预算违规；
  - 每时隙决策：
    \[
    d_t^*=\arg\min_{d_t\in\mathcal D}\{Z_t\bar C_t(d_t,\bar\gamma_t)-\eta A_t(n_t^*)\}
    \]
  - \(\eta\) 平衡“追求语义质量”与“维持资源预算”，在线执行复杂度为 \(O(|\mathcal N||\mathcal M|)\)。

### 3.2 对比方法

## 6. 主要结论与发现

- **超低码率优势明显**：Ada-TokenCom 在 0.0062~0.0468 bpp 范围内即可获得较高 CLIP 相似度（0.923~0.973），码率比传统学习编码器低 90% 以上。
- **语义一致性优先**：在低 CBR 区域，Ada-TokenCom 的 CLIP 比 SwinJSCC 提升约 21%~28%（某些条件下最高 47%），LPIPS 最多降低约 60%，FID 最多降低约 77%。
- **像素级保真度上限**：由于离散 tokenizer 与生成式重建的固有特性，Ada-TokenCom 的 PSNR 低于 SwinJSCC 和学习型压缩方法，说明其更适合以语义/感知质量为目标的低带宽场景。
- **Lyapunov 策略有效**：在线策略可近似达到 long-term oracle 的累计语义质量；在预算约束下会先短暂超用、随后收敛到约束边界，而固定策略要么浪费资源、要么长期违规。
- **代价是计算**：接收端仍需全序列 N 步 AR 推理，解码延迟达约 1 秒（LlamaGen-L + 256 tokens），换取更低的传输开销。

## 7. 优点与亮点

- **方法设计新颖**：将“下一令牌预测 + 算术编码 + 接收端生成”融合，天然利用自回归模型的预测能力进行熵编码，同时支持令牌级截断实现平滑速率控制。
- **跨层优化统一视角**：源压缩（\(n^*\)）与信道保护（MCS）在统一 Lyapunov 框架下联合优化，兼顾长期平均资源约束与时变信道机会主义利用。
- **数字友好、兼容现有协议栈**：采用分离式信源/信道编码，可嵌入现有数字通信系统，而非依赖端到端联合学习。
- **验证充分且直观**：通过自信息热力图、熵分布可视化、不同截断长度重建样例等方式，直观支持“尾部令牌可可靠生成”的核心假设。
- **泛化性较好**：对比多种 AR 模型、不同条件信息、不同 SNRs/CBR 场景，且使用 ImageNet-V2 避免过拟合评估。

## 8. 不足与局限

- **接收端推理延迟大**：AR 全序列解码需要 \(N\) 次顺序前向；文中解码 AR 部分约 908 ms/图，对实时应用不友好。
- **PSNR 低于传统/DeepJSCC 基线**：对像素级保真要求高的任务不适用；生成式重建可能引入“幻觉”或细节失真。
- **条件信息成本未完全纳入**：t2i 场景中 prompt 压缩开销 252 bits 虽小，但单图像令牌载荷相比未必总能忽略；类别标签场景则条件开销极小。
- **实验场景较窄**：仅覆盖单用户点对点图像传输，未包含多用户、视频、点云、多模态任务。
- **公平性局限**：与 SwinJSCC 相比模型规模、训练数据与计算量差异显著，不能完全归因于框架优越性。
- **Lyapunov 参数依赖经验搜索**：\(\eta=10^6\) 是通过网格搜索得到的，缺乏理论指导的自动调参机制。
- **复杂度分析留待优化**：文中承认全前缀重算是为了数值一致性，存在明显优化空间，但尚未给出实际优化后的延迟数据。
