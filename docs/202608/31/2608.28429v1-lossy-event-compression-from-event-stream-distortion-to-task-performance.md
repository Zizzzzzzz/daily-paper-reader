## 摘要
事件相机产生具有微秒级时间分辨率的异步稀疏数据流，但在中高运动场景中，它们每秒可产生多达数亿个事件，带来显著的带宽和存储挑战。因此，有损压缩对于实际部署至关重要，然而现有的事件流失真度量无法可靠地预测压缩引起的任务级性能下降，迫使编解码器优化依赖于昂贵的任务特定评估。为解决这一差距，本文介绍了两种根本不同的事件压缩流水线：i) 基于聚合的流水线，将事件流转换为基于极性的直方图帧，并使用传统图像编解码器JPEG 2000进行压缩；ii) 基于无帧点云的流水线，使用基于八叉树的编解码器G-PCC将事件原生编码为3D点。随后，在统一的任务驱动评估框架内对这两种流水线进行评估，该框架将事件流失真与下游应用性能联系起来，涵盖四个代表性任务：i) 视频重建，ii) 目标检测，iii) 光流估计，以及延迟敏感任务 iv) 在参考相对协议下的异步特征跟踪。在此基础上，据作者所知，首次将五种基于分类的失真度量应用于事件压缩，并与现有事件流度量进行基准比较。实验结果表明，所提出的度量能够可靠地预测不同编码框架下压缩引起的任务性能下降。这表明事件流失真评估可以成为重复任务特定评估的有效替代方案，为未来事件数据编码方案的开发和优化提供直接指导。

## Abstract
Event cameras generate asynchronous, sparse data streams with microsecond temporal resolution, but in moderate-to-high motion scenes they can produce as many as hundreds of millions of events per second, creating significant bandwidth and storage challenges. Lossy compression is therefore essential for practical deployment, yet existing event stream distortion metrics fail to reliably predict compression-induced degradation at the task level, forcing codec optimization to rely on expensive task-specific evaluations. To address this gap, this paper introduces two fundamentally different event compression pipelines: i) an aggregation-based pipeline that converts the event stream into polarity-based histogram frames for compression with the conventional image codec JPEG 2000, and ii) a frame-free point cloud-based pipeline that codes events natively as 3D points using the octree-based codec G-PCC. Both pipelines are then assessed within a unified task-driven evaluation framework that relates event stream distortion to downstream application performance across four representative tasks: i) video reconstruction, ii) object detection, iii) optical flow estimation, and a delay-sensitive task iv) asynchronous feature tracking under a reference-relative protocol. Building on this framework, five classification-based distortion metrics are applied to event compression for the first time, to the best of the authors' knowledge, and benchmarked against existing event stream metrics. Experimental results demonstrate that the proposed metrics reliably predict compression-induced task degradation across different coding frameworks. This demonstrates that event stream distortion assessment can be an efficient alternative to repeated task-specific evaluation, providing direct guidance for the development and optimization of future event data coding solutions.

- **背景**：事件相机以微秒级时间分辨率异步产生稀疏事件流，但在中高运动场景下每秒可产生数亿事件，带来严重带宽和存储压力，因此有损压缩是实际部署的必需环节。
- **问题**：现有事件流失真度量无法可靠预测压缩引起的下游任务性能下降，导致编解码器优化必须依赖昂贵、耗时的任务级评估，限制了编码方案的快速迭代。
- **含义**：本文试图建立事件流失真度量与下游应用性能之间的可靠映射，用低成本的事件级指标替代昂贵的任务级评估，为未来 JPEG XE 等标准制定和编码器优化提供工具。

## 2. 方法论

- **总体思路**：提出两条结构上互补的有损压缩流水线，并在统一的任务驱动评估框架下验证新提出的分类失真度量能否跨编码架构预测任务退化。
- **流水线一：基于聚合的图像编码流水线**
  - 将事件流按极性分离，并在固定时间窗口 Δt 内聚合成“计数直方图帧”（每个像素存储事件数量）。
  - 使用 JPEG 2000（小波变换）对直方图帧进行无损或有损压缩。
  - 解码后通过“逆聚合”将直方图帧还原为事件流：对每个像素的 N 个事件在窗口内均匀分配时间戳。
  - 操作点由 Δt（5–150 ms，取决于数据集）和 JPEG 2000 目标码率（2/1.5/1/0.5/0.25/0.1 bpp 及无损模式）控制。
- **流水线二：基于点云的原生编码流水线**
  - 将事件流按 100 ms 时间块切分，按极性分为两路，映射到以 (x, y, t) 为坐标的 3D 点云。
  - 把三个坐标统一量化为 10-bit 网格，避免时间坐标数值范围过大导致八叉树失衡。
  - 使用 MPEG G-PCC（TMC13）分别压缩正/负极性点云，极性作为流标识而非点属性。
  - 操作点由几何量化尺度 q ∈ {1.0, 0.375, 0.3, 0.2, 0.125, 0.0625, 0.03125} 控制。
- **统一评估框架**：采用参考相对（RR）协议——先在未压缩事件流上运行下游任务得到参考输出，再在压缩解码流上运行任务，比较两者的差异，从而隔离压缩引入的影响。
- **五种分类失真度量**（首次用于事件压缩）：
  - 将原/重建事件流聚合为二值帧（15 ms 窗口），逐像素比较得到混淆矩阵 TP/FP/FN/TN；
  - 计算 **Recall**（事件存活率）、**IoU**（结构保真度）、**Markedness**（受幻觉事件影响的标签可靠性）、**MCC**（类别不平衡下的综合相关系数）、**Cohen’s Kappa**（相对随机基线的一致性）。
  - 这些度量针对事件像素极稀疏导致的类别极端不平衡而设计。

## 3. 实验设计

- **下游任务与数据集/模型**：
  - **视频重建**：ECD 数据集 + HyperE2VID，衡量 PSNR / SSIM；
  - **目标检测**：Gen1 数据集子集 + RVT，采用 COCO 流程的 mAP；
  - **光流估计**：MVSEC 数据集子集 + E-RAFT，衡量端点误差 EPE；
  - **异步特征跟踪**：ECD 数据集 + HASTE，采用特征寿命（feature age）指标，作为延迟敏感任务的压力测试。
- **基准对比度量**：与六种已有事件流失真度量比较——ASTSM、PSNR E2E、VQ_s、VQ_t、Frame PSNR、Frame MSE。
- **编码器对比**：
  - 聚合流水线中比较 JPEG 2000 与 JPEG XL / AVIF 在稀疏直方图帧上的表现；
  - 两种流水线（JPEG 2000 vs G-PCC）进行跨表示形式比较；
  - 每个度量分别在聚合编码器、点云编码器、以及两者合并的操作点集合上计算与任务性能的 SROCC / PLCC。
- **统计方法**：用三次多项式回归（ITU-T P.1401）将失真度量映射为任务性能预测值，再计算 PLCC 和 SROCC，以 0.80 作为可靠预测阈值。

## 6. 主要结论与发现

- 五种分类度量在 SROCC ≥ 0.80 的条件下，对三个主要任务（视频重建、目标检测、光流估计）**在两种编码器单独及合并池上均能可靠预测任务退化**，而六种基准度量无法做到一致可靠。
- 在延迟敏感的异步特征跟踪任务中，新度量仍是 rank 相关性最强的预测器（合并池 SROCC 0.788–0.808），优于所有基准度量，但相关性略低于前三个任务。
- 度量时间窗口是任务相关参数：异步跟踪偏好短窗口（约 3 ms），视频重建偏好中等窗口（约 18–22 ms）；默认 15 ms 在大多数组合下接近最优。
- JPEG 2000 在稀疏直方图帧上显著优于 JPEG XL 和 AVIF，因为小波变换更少产生“幻影事件”，而块变换会污染零像素区域。

## 7. 优点

- **双流水线设计**：聚合式与点云式编码在表示层面根本不同，使度量验证可跨架构推广。
- **首次引入分类度量**：利用混淆矩阵和类不平衡指标（MCC、Kappa 等），针对事件流稀疏性比传统信号度量更本质。
- **统一评估协议**：RR 协议将压缩影响从任务模型固有误差中分离，结论更可靠。
- **低计算成本**：失真度量只依赖事件流本身，可作为率失真优化时的代理目标，避免反复跑任务模型。
- **分析细致**：包括图像编码器对稀疏帧的适用性研究、时间窗口敏感性分析、以及合并池上的稳健性验证。
