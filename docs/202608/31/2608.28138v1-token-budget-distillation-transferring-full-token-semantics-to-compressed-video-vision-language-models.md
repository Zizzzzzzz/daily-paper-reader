## 摘要
适配视频视觉语言模型（VLM）在计算上非常昂贵，因为视频输入会产生大量视觉令牌，使得微调和推理成本都很高。尽管视觉令牌压缩可以减少这种开销，但直接在压缩输入上进行适配通常会导致语义漂移和明显的性能下降。我们提出了令牌预算蒸馏（TBD），一种参数高效的微调框架，用于在固定令牌预算下适配视频VLM。TBD冻结预训练骨干网络，仅更新LoRA适配器，并将基于FlashVID的视觉令牌压缩集成到视频路径中。为了在压缩下保留全令牌语义，TBD采用双路径教师-学生设计，其中全令牌教师提供稳定的监督，压缩学生通过任务损失、答案区域KL蒸馏、真实标签锚定的边际蒸馏以及可靠性感知的知识蒸馏控制进行优化。这种设计使学生能够恢复全令牌模型的语义行为，同时在激进的令牌缩减下保持高效。我们在三个视频VLM骨干网络上评估了TBD，包括LLaVA-Video、LLaVA-OneVision和Qwen3-VL-8B-Instruct，跨越四个视频理解基准。TBD在中等和激进压缩下都始终优于仅压缩的基线。在保留率R=10%的LLaVA-Video上，TBD保留了Vanilla模型平均准确率的97.0%；在R=10%的LLaVA-OneVision上，它达到了58.4的平均分数，并匹配了100.0%的相对准确率。

## Abstract
Adapting video vision-language models (VLMs) is computationally expensive because video inputs produce a large number of visual tokens, making both fine-tuning and inference costly. Although visual token compression can reduce this overhead, direct adaptation on compressed inputs often causes semantic drift and noticeable performance degradation. We present Token-Budget Distillation (TBD), a parameter-efficient fine-tuning framework for adapting video VLMs under a fixed token budget. TBD freezes the pretrained backbone, updates only LoRA adapters, and integrates FlashVID-based visual token compression into the video pathway. To preserve full-token semantics under compression, TBD employs a dual-path teacher-student design, where a full-token teacher provides stable supervision and a compressed student is optimized with task loss, answer-region KL distillation, GT-anchored margin distillation, and reliability-aware KD control. This design enables the student to recover the semantic behavior of the full-token model while remaining efficient under aggressive token reduction. We evaluate TBD on three video VLM backbones, including LLaVA-Video, LLaVA-OneVision, and Qwen3-VL-8B-Instruct, across four video understanding benchmarks. TBD consistently outperforms compression-only baselines under both moderate and aggressive compression. On LLaVA-Video at retention ratio R = 10 percent, TBD preserves 97.0 percent of the Vanilla model's average accuracy; on LLaVA-OneVision at R = 10 percent, it achieves an average score of 58.4 and matches 100.0 percent relative accuracy.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：视频视觉语言模型（Video VLM）在处理视频输入时会产生大量视觉 token，导致微调和推理的计算成本随序列长度呈二次方增长（“token 爆炸”问题）。
- **现有方案的不足**：视觉 token 压缩（如 token 剪枝/合并）虽能降低计算开销，但大多数方法仅将压缩视为推理阶段的即插即用加速模块；当需要在严格 token 预算下进行微调适配时，直接对压缩输入施加任务监督会引发**显著的语义漂移（semantic drift）**。
- **语义漂移的具体表现**：对时空 token 不加区分地合并或丢弃，会将细粒度的前景动作稀释为聚合的背景噪声，导致模型的视觉注意力从精确的判别性动作（如“骑自行车”）漂移到模糊的泛化概念（如“移动物体”），进而造成置信度下降和推理能力显著退化。
- **研究意义**：本文将高效适配问题重新定义为**语义保持问题**，而非单纯的效率问题，为在有限 token 预算下部署视频 VLM 提供了可行方案。

## 2. 方法论（核心思想、关键技术细节与算法流程）

### 2.1 总体框架
- **TBD（Token-Budget Distillation）** 是一个参数高效微调框架，采用**双路径教师-学生（dual-path teacher-student）**架构：
  - **教师分支**：处理全量 token（z_f），关闭压缩和 LoRA，以完全梯度无关（gradient-free）的评估模式运行，作为原完整 token 模型的精确代理，提供稳定监督。
  - **学生分支**：处理压缩后的 token（z_c），冻结骨干网络 Θ，仅更新 LoRA 参数 Φ。
- 适配完成后教师分支被丢弃，仅保留高效的学生模型用于推理。

### 2.2 问题形式化
- 压缩操作：z_c = C(z_f; B)，其中 |z_c| ≤ B ≪ N_f，B 为固定 token 预算。
- 优化目标：Φ* = arg min_Φ Σ L(y; v, q, z_f, z_c; Θ, Φ)，L 联合了标准监督目标与蒸馏约束。
- **LoRA 适配**：W = W₀ + ΔW，ΔW = B_W·A_W，其中 A_W、B_W 为可训练的低秩矩阵，秩 r ≪ min(d, d′)。

### 2.3 可靠性感知的蒸馏模块（三个关键组件）
1. **答案区域 KL 蒸馏（Answer-region KL Distillation）**：
   - 仅在对齐的答案位置（M = min(M_t, M_s)）上计算师生 token 级 KL 散度：L_KL = (1/|Ω|) Σ_{i∈Ω} KL(σ(l_t^i/τ) ∥ σ(l_s^i/τ))·τ²。
   - 核心创新是**可靠性掩码 Ω**：只保留教师既“正确”（最高概率对应 ground-truth）又“自信”（概率超过预设阈值）的位置，过滤噪声蒸馏信号。

2. **GT 锚定边际蒸馏（GT-anchored Margin Distillation）**：
   - 针对语义漂移导致的“边际坍塌”（模型难以区分正确概念与背景噪声）问题，显式定义边际：m_t^i = l_t^i,y_i − l_t^i,n_i，m_s^i = l_s^i,y_i − l_s^i,n_i（n_i 为教师视角的最高分错误 token）。
   - 使用 Huber 损失惩罚师生边际偏差：L_margin = (1/|Ω|) Σ Huber(m_s^i, m_t^i)，迫使压缩学生模仿教师的决策边界间距。

3. **可靠性感知的知识蒸馏控制（Reliability-aware KD Control）**：
   - 总损失：L = λ_ce·L_CE + λ̂_kd(t)·L_KD，其中 L_KD = L_KL + λ_m·L_margin。
   - λ̂_kd(t) 采用**线性 warmup 调度**，并相对于 L_CE 的大小进行**严格封顶（capping）**，防止训练早期过度正则化。

### 2.4 算法流程（文字描述）
1. 教师分支前向：提取全量 token，关闭压缩与 LoRA，生成教师 logits（无梯度）。
2. 学生分支前向：FlashVID 压缩 token，启用 LoRA，生成学生 logits（有梯度）。
3. 可靠性掩码构建：对齐答案位置，筛选教师正确且自信的 token 位置构成 Ω。
4. 计算任务损失（CE）、KL 对齐损失、边际损失，合并为蒸馏损失。
5. 动态加权（warmup + CE 相对封顶）后反向传播更新 LoRA 参数。

## 7. 优点

- **问题定义新颖**：将 token 压缩下的适配重新框定为“语义保持”问题，识别并形式化了“语义漂移”病理（空间稀释→认知模糊），超越了简单的效率优化视角。
- **方法设计务实**：冻结骨干 + 仅更新 LoRA，兼容训练无关的压缩前端（FlashVID），梯度只流经压缩表示，学习容量全部用于表征修复，无需重新训练压缩模块。
- **蒸馏机制精巧**：可靠性掩码（教师正确且自信才蒸馏）、GT 锚定边际（防止边际坍塌）、动态 KD 权重（warmup + 封顶），三管齐下且具有清晰的物理解释。
- **评估全面且深入**：不满足于宏观精度，还提供了 logit 分布、决策边界、注意力图三层机制分析，证据链完整。
- **通用性强**：在 LLaVA 家族和 Qwen3-VL 上均有效，且对压缩模块选择不敏感（多种前端均可搭配）。

## 8. 不足与局限

- **训练成本未充分解决**：蒸馏过程需要执行全 token 教师前向，训练阶段内存与时间开销仍然很高，与“高效适配”的目标存在一定张力。
- **性能上限受限于压缩前端**：学生的最终性能被所选训练无关压缩模块的不可逆信息损失所约束（表 3 显示不同压缩前端差距明显）。
- **实验覆盖有限**：仅使用单一训练数据集（LLaVA-Video-178K）；未测试其他视频指令数据集或更多样的压缩率（如 R=5%、R=50%）。
- **机制分析样本量偏小**：logit 分析和决策边界分析分别仅采样 100/200 个样本，注意力可视化仅展示单个实例，缺乏大规模统计分析支撑。
- **效率数据缺失**：未报告 FLOPs、延迟、显存占用、训练时间等量化效率指标，削弱了“效率-精度权衡”论证的量化基础。
- **应用场景局限**：主要针对多项选择式问答基准；对于开放式生成、长视频密集描述等任务的适用性尚未验证。
