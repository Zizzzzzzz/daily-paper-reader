## 摘要
键值（KV）缓存已成为长上下文大语言模型推理中的主要内存和带宽瓶颈，使得超低位量化日益重要。然而，现有的基于旋转的INT2方法在完整注意力读出之前优化缓存统计量或代理误差，尽管模型最终受到通过注意力和输出投影$W_O$传播的误差影响。为解决这一不匹配问题，我们提出\textit{OptR}，一种输出感知的旋转方法，最小化$W_O$之后的注意力输出误差。OptR将$W_O$后的注意力输出误差分解为键和值引发的项，并通过完整的INT2量化和注意力路径学习每头正交校正。OptR进一步应用注意力等价的键重参数化，在不改变softmax分布的情况下减少大的通道偏移。在三个模型和五个推理与编码基准上，OptR consistently改善了QuaRot和OSCAR，并增强了长上下文检索，同时保持了分页KV缓存格式且推理开销可忽略不计。

## Abstract
The key-value (KV) cache has become a major memory and bandwidth bottleneck in long-context large language model inference, making ultra-low-bit quantization increasingly important. However, existing rotation-based INT2 methods optimize cache statistics or proxy errors before the complete attention readout, even though the model is ultimately affected by the error propagated through attention and the output projection $W_O$. To address this mismatch, we propose \textit{OptR}, an output-aware rotation method that minimizes post-$W_O$ attention-output error. OptR decomposes the post-$W_O$ attention-output error into key- and value-induced terms and learns per-head orthogonal corrections through the full INT2 quantization and attention path. OptR further applies an attention-equivalent key reparameterization to reduce large channel-wise offsets without changing the softmax distribution. Across three models and five reasoning and coding benchmarks, OptR consistently improves both QuaRot and OSCAR and strengthens long-context retrieval, while preserving the paged KV-cache format with negligible inference overhead.

- **研究背景**：随着大语言模型（LLM）规模与上下文长度的不断增长，KV 缓存成为长上下文推理阶段的主要内存和带宽瓶颈。在自回归解码时，每一层需要存储并反复读取全部历史 token 的键和值，缓存占用随上下文长度、批大小和模型深度线性增长。
- **INT2 量化的动机**：INT2 KV 缓存仅需 BF16 的 1/8 存储、INT4 的 1/2，能够在相同内存预算下支持更长上下文或更大批次。然而 INT2 只有 4 个量化电平，量化组中少数离群值会显著扩大表示范围，导致大部分值的舍入误差增大，而激进截断又会引入离群值本身的大误差。
- **现有方法的局限**：旋转式量化（如 QuaRot、OSCAR）是当前主流路线——通过正交矩阵将极端通道值分散到各维度以提高可量化性，且不改变张量形状、保持分页缓存兼容性。但现有方法要么使用固定变换，要么基于缓存统计或“完整注意力读出之前”的代理误差来选择旋转矩阵，**没有直接衡量最终传给后续层的注意力输出误差**。
- **核心矛盾**：KV 量化误差经过注意力加权读出和输出投影 $W_O$ 后进入残差流并向后传播，最终影响模型预测。因此“最佳重建缓存”的旋转未必是最佳保持 $W_O$ 后输出的旋转，量化目标与真实推理目标存在失配。
- **论文意义**：提出 OptR（Output-aware Rotation），直接以 $W_O$ 后的注意力输出误差为优化目标，在输出空间中校准旋转矩阵，弥补了代理目标与真实推理目标之间的鸿沟，为超低位 KV 缓存量化提供了新方向。

## 2. 论文提出的方法论

### 2.1 核心思想

OptR 的核心思想是：**将旋转的选择从“缓存重建度量”转向“输出空间度量”**，即最小化 INT2 量化后经完整注意力路径和输出投影 $W_O$ 后产生的实际输出误差。具体包含两大技术：

1. **注意力等价的键重参数化（attention-equivalent key reparameterization）**：在旋转和量化之前，先从每个键中减去逐通道校准均值 $\mu$。由于所有键同时减去同一向量，每个查询的所有 logit 都加上一个相同的与 token 无关的常量，从而不改变 softmax 概率分布。该操作压缩了 INT2 的动态范围，缓解离群值造成的量化误差。仅对键执行此操作，因为平移值会改变注意力输出。
2. **逐头正交校正（per-head orthogonal corrections）**：为每个 KV 头学习独立的正交校正旋转，通过完整的 INT2 量化—注意力—输出投影路径最小化 $W_O$ 后误差。

### 2.2 误差分解（公式 8）

将 $W_O$ 后的注意力输出总误差 $\Delta y_{t,j}^\ell$ 分解为两项：

$$\Delta y_{t,j}^\ell = \underbrace{\left(\sum_{s \le t} \Delta p_{t,s}^{\ell,j,h} \, v_{s,h}^\ell\right)(W_{O,j}^\ell)^\top}_{\text{key-induced output error}} + \underbrace{\left(\sum_{s \le t} \hat{p}_{t,s}^{\ell,j,h} \, \Delta v_{s,h}^\ell\right)(W_{O,j}^\ell)^\top}_{\text{value-induced output error}}$$

- **键引发误差**：键量化误差改变注意力分数 $\Delta a$，进而扰动 softmax 分布 $\Delta p$，最终影响注意力加权输出——其效应取决于查询向量和注意力图，而非仅 $\|\Delta k\|_2$。
- **值引发误差**：值量化误差 $\Delta v$ 在注意力权重加权聚合和 $W_O$ 投影后直接进入输出。

该分解解释了为什么“原始缓存重建”只是代理目标：重建误差 $\|K-\hat{K}\|_F^2 + \|V-\hat{V}\|_F^2$ 与模型实际观察到的输出误差 $\|\delta y_K + \delta y_V\|_2^2$ 可能偏好不同的旋转方向。

### 2.3 分阶段校准流程

- **键旋转先行**：由于量化后的键决定注意力分布，OptR 先固定值为 BF16，最小化键损失的组合目标：

$$L_K(R_K; D) = \mathbb{E}_{(t,j)\in D}\left[ D_{\mathrm{KL}}\left(p_t \| p_t^K(R_K)\right) + \lambda_K \frac{\|e_K(t,j; R_K)\|_2^2}{d_{\mathrm{model}}} \right]$$

  KL 散度项保持注意力分布，第二项衡量键引发注意力变化导致的 $W_O$ 后输出误差。

- **值旋转后行**：选定键旋转后，在此基础上优化值旋转，最小化值引发输出误差：

$$L_V(R_V; D) = \mathbb{E}_{(t,j)\in D}\left[ \frac{\|e_V(t,j; R_V)\|_2^2}{d_{\mathrm{model}}} \right]$$

### 2.4 正交参数化与 INT2 感知优化

- 每个 KV 头学习无约束矩阵 $A$，构造反对称生成器 $S = A - A^\top$，校正旋转为 $R = R^0 \exp(S)$——由于反对称矩阵的矩阵指数必为正交矩阵，旋转在优化全程保持正交性。
- 校准过程贯穿完整 INT2 量化路径：旋转、截断、分组、INT2 舍入、反量化、逆旋转，使用直通估计器（STE）近似不可微分舍入操作的梯度。
- 模型权重全程冻结，仅优化旋转生成器参数；校准得到的旋转在推理时固定使用。

### 2.5 推理部署实现

- 结合 $(k-\mu)R_K = kR_K - \mu R_K$ 预计算旋转均值，将键中心化融入缓存写入核（单次 launch 完成旋转、中心化、截断、量化、打包）。
- 值侧旋转及其逆旋转分别吸收进 $W_V$ 和 $W_O$，避免额外值旋转核。
- 在 GQA 下，查询核按对应 KV 头的旋转矩阵旋转查询。推理实现与主论文中“反旋转”公式等价。
- 方法不依赖特定旋转初始化，可叠加在 QuaRot（Hadamard 固定旋转）或 OSCAR（协方差感知自适应旋转）之上。

- **误差分析证实有效性**：OptR 同时降低 $W_O$ 后即时输出误差和跨层传播的残差流误差（例如 Qwen3-4B-GPQA 上输出 MSE 从 0.83 降到 0.23），且降低发生在大多数层和 KV 头而非少数极端位置。
- **目标选择的关键性**：消融显示 post-WO 输出误差目标（70.67%）优于缓存重建（65.33%）和 pre-WO 注意力读出目标（62.67%），直接证明输出空间优化的必要性。
- **效率与兼容性**：OptR 保持 INT2 管线的分页缓存格式和推理效率，推理开销可忽略，适合实际部署。

## 8. 缺点与潜在风险

- **离线校准成本**：每模型需要 6–11 分钟的单 GPU 校准时间（不含 GPU 轨迹收集），且校准数据固定来自 GPQA 解码轨迹，对域外任务（如代码生成）的泛化能力缺乏专门验证。
- **校准数据域偏差**：所有模型的校准数据均来自同一个 GPQA 提示池，虽然优化与留出子集不相交，但评测基准中包含 GPQA-Diamond，存在一定的域重叠风险；对代码基准（MBPP+、LiveCodeBench）和数学基准（AIME24/25）的效果可能受益于推理类校准数据的间接泛化，但论文未做交叉域校准实验。
- **长上下文评估单一**：仅使用 RULER-NIAH 一种长上下文任务，缺少多跳检索、长文档 QA、摘要等更丰富的长上下文评测，结论的普适性有限。
- **TurboQuant 对比较弱**：TurboQuant 仅单次运行且无方差报告，由于 vLLM 实现慢，可能未能充分代表该方法的真实性能，对比公平性稍显不足。
- **INT2 极端量化的固有局限**：即便 OptR 大幅提升，Phi4-14B 的恢复度仍相对较低（例如 AIME24 上 OSCAR+OptR 仅从 9.33% 到 27.33%，BF16 为 48.67%），说明超低位量化在部分模型上仍有不可忽略的性能损失。
- **复杂度与可解释性**：针对每个头的正交校正矩阵缺乏直观解释，旋转矩阵可解释性较差；若未来出现比 INT2 更低的量化位宽，该框架的扩展性尚未验证。

## 9. 复现要点与关键细节

- **核心公式**：误差分解式（式 8），键旋转损失 $L_K$（含 KL 散度 + $\lambda_K = 1.0$ 的归一化输出误差），值旋转损失 $L_V$。
- **正交参数化**：$R = R^0 \exp(A - A^\top)$，逐头学习无约束生成器矩阵 $A$，自动保证旋转正交性。
- **INT2 量化路径**：完整包含旋转 → 中心化（仅键）→ 截断（键 0.96 / 值 0.92）→ 分组（组大小 128）→ 舍入 → 反量化 → 逆旋转，舍入梯度用 STE。
- **训练配置**：Adam，学习率 0.02，每层每头 80 步，校准数据来自 30K-token GPQA 解码轨迹。
- **推理融合**：键中心化吸收进缓存写入核（$(k-\mu)R_K$ 预计算）；值旋转吸收进 $W_V$，逆旋转吸收进 $W_O$；GQA 下查询核按对应 KV 头旋转查询。
- **缓存成本**：INT2 + 64 sink + 256 recent 保留 BF16，有效 2.32 BPE。

## 10. 局限性再讨论（结合主观批判）

从学术批判角度看，OptR 本质上是**在"量化误差最小化"与"任务性能保持"之间引入了一个更贴近真实损失面的代理目标**，但它并未改变 INT2 量化本身的表示能力极限。在 4-bit 精度下，代理目标与真实目标的差距或许可以忽略；但在 2-bit 下，仅靠旋转优化仍难以完全弥合量化信息的根本性丢失——这解释了 Phi4-14B 上恢复度偏低的现象。此外，逐头独立学习旋转矩阵引入了大量额外参数（每层每头一个 $d_k \times d_k$ 矩阵），虽然校准后无需存储全部参数，但"以参数换精度"的策略在面对更大模型（如 70B+）或更长上下文（如 1M）时，校准轨迹收集与优化的算力成本会显著上升，论文未对此做出充足的扩展性论证。

## 11. 个人评价与定位

OptR 是一篇**方法动机清晰、理论推导扎实、工程落地完整**的 KV 量化论文。其最核心的贡献不在于创造新的量化格式，而在于识别出"旋转选择应在输出空间而非缓存空间进行"这一关键视角，并用公式化的误差分解与实验验证支撑了该论断。相比 QuaRot 和 OSCAR 这类"量化友好性"导向的方法，OptR 是"推理正确性"导向的量化方法，在方法论层面具有较好的启发意义。若后续工作能补充跨域校准、更多长上下文基准和更大模型的扩展实验，该工作将具备更强的说服力。

**总体评分**：8/10（方法论新颖性高、实验较充分、工程实现完整；扣分项为校准域偏差、长上下文评估单一和 TurboQuant 对比强度不足）。

## 12. 关键术语表

| 术语 | 含义 |
|---|---|
| INT2 KV 缓存 | 将键值缓存量化为 2-bit，每个元素仅 4 个量化电平 |
| 旋转量化 | 通过正交矩阵变换将离群通道值分散到各维度，提高可量化性 |
| OptR | Output-aware Rotation，输出感知的旋转校准方法 |
| key reparameterization | 键中心化：所有键减去逐通道均值，不改变注意力分布但缩小动态范围 |
| per-head orthogonal corrections | 为每个 KV 头学习独立的正交旋转矩阵 |
| $W_O$ 后输出误差 | 注意力输出经输出投影矩阵后的误差，OptR 的直接优化目标 |
| Key-induced error | 键量化导致注意力分布扰动，进而引起的输出误差 |
| Value-induced error | 值量化直接导致的注意力加权读出误差 |
| STE | Straight-Through Estimator，直通估计器，用于近似舍入的梯度 |
| BPE | Bits Per Element，每元素有效平均缓存位宽 |
| GQA | Grouped Query Attention，分组查询注意力 |
| sink/recent tokens | 保留在 BF16 精度的关键首尾 token（64 sink + 256 recent） |
| QuaRot / OSCAR | 现有旋转式 KV 量化方法，OptR 可叠加于其上 |

## 13. 参考文献要点

论文方法主要建立在以下工作之上：
- **QuaRot**：使用 Hadamard 旋转的固定旋转 KV 量化方法，OptR 以其为固定基旋转。
- **OSCAR**：通过协方差感知的自适应旋转做 KV 量化，OptR 可在此基础上进一步优化。
- **TurboQuant**：基于向量量化的 KV 缓存压缩方法，作为对比基线。
- **RULER-NIAH**：长上下文大海捞针检索基准，用于评估长上下文鲁棒性。

上述工作的核心工具（正交旋转、Hadamard 变换、协方差校准、NIAH 检索）被 OptR 以不同方式组合、扩展和重构，形成新的输出空间优化框架。

---

**总结**：OptR 解决了 INT2 KV 缓存量化中"旋转矩阵优化目标与真实推理目标失配"的关键问题，通过键中心化重参数化 + 逐头正交校正 + 输出空间误差驱动的分阶段校准，在 Qwen3 系列和 Phi4 模型上显著提升了 INT2 KV 缓存下的推理准确率与长上下文鲁棒性，同时保持了极低的推理开销。该方法为超低位 KV 量化提供了新的方法论视角，但在校准域泛化、长上下文评估多样性和更大规模模型的扩展性方面仍有进一步探索空间。
