## 摘要
多模态大语言模型（MLLM）用于手术场景理解时，通常会将数百个密集的视觉标记注入语言模型，导致推理成本高昂，并且生成答案的空间可追踪性有限。我们提出Slot2Text，一种双模式手术MLLM，用一组紧凑的区域（编码为槽位潜变量）替代视觉输入的密集表示。Slot2Text不依赖于视觉编码器与语言的对比对齐，而是将自监督视觉特征分组为几个区域——槽位，这些槽位作为带区域标签的视觉标记供语言模型使用。Slot2Text-Fast使用槽位前缀回答手术问题。Slot2Text-Reason还识别并定位与推理相关的区域，将语言输出与相应的槽位标记、掩码或区域关联起来。在多个视觉问答和视觉定位基准上的实验表明，Slot2Text-Fast以较低的成本与最先进的基线方法竞争，平均总标记消耗减少91.8%，视觉前缀从1,295个标记减少到47个（减少96.4%）。Slot2Text-Reason以额外的标记和延迟换取明确的区域身份、位置和可追踪的空间证据。这些结果确立了紧凑的槽位潜变量作为手术MLLM的高效默认视觉接口，在需要更高空间可追踪性时调用基于推理的定位。

## Abstract
Multimodal large language models (MLLM) for surgical scene understanding typically inject hundreds of dense visual tokens into a language model, leading to costly inference and limited spatial traceability for generated answers. We present Slot2Text, a dual-mode surgical MLLM that replaces dense representations of visual input with a compact set of regions encoded as slot latents. Instead of relying on contrastive alignment of the visual encoder with language, Slot2Text groups self-supervised vision features into a few regions--slots that are consumed by the language model as area-labeled visual tokens. Slot2Text-Fast uses the slot prefix to answer surgical questions. Slot2Text-Reason also identifies and locates areas relevant for reasoning, linking language outputs to corresponding slot tokens, masks or regions. Experiments on multiple visual question answering and visual grounding benchmarks show that Slot2Text-Fast is competitive with state-of-the-art baseline at a much lower cost, reducing the average total token consumption by a 91.8\% and the visual prefix from 1,295 to 47 tokens (a 96.4\% reduction). Slot2Text-Reason trades additional tokens and latency for explicit area identities, locations, and traceable spatial evidence. These results establish compact slot latents as an efficient default visual interface for surgical MLLMs, with grounded reasoning invoked when greater spatial traceability is required.

## 二、方法论：核心思想与关键技术

### 1. 总体框架

Slot2Text 的整体流程为：**冻结 DINOv3 编码器处理图像 → 槽位注意力（Slot Attention）分组为 K 个区域 → 几何增强的融合模块 → VL 桥投影到 LLM 输入空间 → 语言模型生成回答**。系统架构包含两种运行模式：

- **Slot2Text-Fast**：直接基于 slot 前缀回答，不生成中间推理文本。
- **Slot2Text-Reason（R）**：额外生成区域 ID、掩码、bounding box 等结构化定位输出，提供可追踪的空间证据。

### 2. 对象中心视觉分词器（Object-Centric Visual Tokenizer）

- 图像输入编码：使用冻结的 **DINOv3 ViT-B/16**（分辨率 224×224），得到 $N = h \times w$ 个 patch 嵌入。
- **Slot Attention 预训练**：从 9 个初始化查询开始，经过 3 次迭代注意力更新，得到 K 个 slot 潜变量和软分配掩码 $A \in \mathbb{R}^{K \times h \times w}$。
- 通过**特征重建损失**（自监督，无需人工分割标注）训练：
  \[\hat{x}_j = \sum_{i=1}^{K} A_{ij} D(s_i)_j,\quad L_{slot} = \frac{1}{N}\sum_{j=1}^{N}\|\hat{x}_j - x_j\|_2^2\]
- 预训练完成后，冻结特征适配器和槽位注意力模块。

### 3. 几何增强区域令牌

为使每个 slot 保留更完整的 DINOv3 外观信息，模型实施掩码加权池化：
\[p_i = \frac{\sum_j A_{ij} x_j}{\sum_j A_{ij} + \epsilon}\]
同时计算掩码质量 $m_i$ 和归一化质心 $(c_x^i, c_y^i)$ 用于排序。由有序槽位融合模块组合所有成分：
\[z_i = F_\theta([s_i; p_i; c_x^i; c_y^i; m_i]),\quad v_i = P_\phi(z_i)\]
最终以 `[area-1:, v1, area-2:, v2, ...]` 的带标签形式进入 LLM。每个文本标签（如 "area-1"）构成语言模型与连续区域之间的**离散语言线索**。

### 4. 直接回答与区域接地推理

- **Slot2Text-Fast**：把紧凑区域集视作标准 MLLM 中密集视觉标记的替代物，直接基于前缀和问题回答。
- **Slot2Text-Reason**：添加结构化定位监督。目标区域通过最大化 IoU 选择：
  \[i^\star = \arg\max_i \text{IoU}(A_i^h, T)\]
  训练时附加多轮辅助问答（掩码 QA、区域 ID QA、框坐标 QA），使 LLM 学会在目标描述、区域标识和显式坐标之间转换。
- 掩码输出采用两种形式：**压缩语义描述符**（基于 Text4Seg 风格的 run-length 编码）和**非压缩语义描述符**。

### 5. 多阶段视觉指令调优

| 阶段 | 训练内容 | 冻结部分 |
|------|---------|---------|
| Stage 1：VL 桥对齐（8 epochs） | 仅训练融合模块、槽位投影器、视觉投影层、图像边界嵌入 | DINOv3、Slot Attention、LLM |
| Stage 2：混合推理指令调优（4 epochs） | VL 桥 + Llama 3.2 1B 的 rank-128 LoRA | DINOv3、Slot Attention |
| Stage 3：渐进式推理加速 | 依次微调为：Reason-Compress（压缩掩码）→ Reason-Localization（紧凑坐标）→ Fast（无推理痕迹） | 逐步精简输出格式 |

该方法**不依赖 CLIP 式对比图文预训练**，而是通过自监督特征 + 下游桥接学习视觉-语言映射，这是与主流 MLLM 范式的关键差异。

## 六、主要结论与发现

1. **压缩效率显著**：Slot2Text-Fast 将视觉前缀从 1,295 减至 47 个 token（减少 96.4%），平均总 token 消耗减少 **91.8%**，同时吞吐量从 3.59 提至 4.62 samples/s，峰值 GPU 内存从 6.55 GiB 降至 2.66 GiB。
2. **性能与 SOTA 竞争**：在接地 QA 上，Slot2Text-Reason 平均 AP@50 达 91.61、mIoU 达 82.42，优于 TokenPacker 与 Slot-MLLM；Slot2Text-R-L 平均 F-score 达 40.04，为所有压缩方法中最高。
3. **区域级监督的价值**：显式区域监督在区域条件生成（Region-Based QA）上尤其有效，Slot2Text-R-C 在 EndoVis 上区域级 BLEU-4 和 CIDEr 分别超过 EndoChat 2.55 和 0.29 分。
4. **可控的权衡谱系**：从 Fast → R-L → R-C → R，模型依次用 token 开销换取更丰富的空间解释，形成"效率-可解释性"的可调光谱。
5. **紧凑槽位潜变量可作为手术 MLLM 的默认视觉接口**：在高效回答与按需接地推理之间可灵活切换。

## 七、方法优点

1. **开创性的"压缩+可追溯"双目标设计**：不仅减少 token，还保留了每个 token 对应的空间掩码、质心和框，实现了"回答可溯源到图像区域"。
2. **无需对比预训练**：不依赖 CLIP 式图像-文本对比对齐，规避了通用预训练数据中手术概念不足的问题；自监督槽位预训练 + 下游桥接的方式更契合手术领域。
3. **渐进式推理加速课程**：先学非压缩语义描述符，再逐步压缩为更紧凑的格式，这一课程式训练策略有较强的启发意义。
4. **几何增强与排序机制**：在槽位中融合外观池化、质心、掩码质量等几何信息，并利用质心排序加速训练收敛，技术细节设计合理。
5. **多阶段训练解耦清晰**：将视觉-语言对齐、指令调优、推理加速分离，各阶段目标明确，便于诊断与复用。
6. **效率报告完整**：同时报告 token 数、吞吐量、内存三项指标，并给出多次运行的波动区间，评估方式规范。

## 八、不足与局限

1. **固定槽位预算**：每次推理使用固定 K=9 的槽位数，无法根据图像复杂度自适应增减；论文指出未来可用自适应槽位分配或 MoE 路由解决。
2. **快速/推理模式需预先选定**：不能在同一次推理中动态切换模式，限制了实际部署的灵活性。
3. **槽位模块冻结**：视觉编码器和 Slot Attention 在整个指令调优阶段被冻结，可能限制任务自适应能力，并延长对齐时间。
4. **无限制视觉 QA 性能不足**：在 CoPESD 等数据集的开放视觉 QA 上低于 EndoChat（如 CoPESD 上 BLEU-4：45.90 vs 46.94），压缩带来的信息损失在开放式问答中体现更明显。
