## 摘要
最近在语音大语言模型方面的进展展示了其在理解复杂音频任务方面的显著能力。尽管取得了这些进展，但其长上下文推理仍因高昂的KV缓存内存需求而严重受限。现有的以文本为中心的压缩方法在此面临困境，常常破坏语音连续性或丢弃关键语义线索。为解决这一问题，我们提出了VoxZip，一种无需训练、两阶段的语义锚定KV缓存压缩框架。第一阶段利用自动语音识别（ASR）转写作为显式语义锚点，进行时间对齐、压缩和融合音频令牌，在显著减少初始KV缓存的同时提升令牌信息密度。为进一步提高压缩比，第二阶段采用基于时间衰减累积注意力的动态过滤策略，以驱逐非必要令牌并缓解早期令牌偏差。在Qwen3-Omni上跨越六个不同音频基准的全面评估展示了我们方法的优越性。VoxZip在长音频推理中表现出色，并在短时任务上持续保持高保真感知。值得注意的是，在长上下文场景下即使面对激进的20倍KV缓存压缩，它仍能维持未压缩基线性能的90%以上。此外，在4倍压缩比下，VoxZip带来了1.9倍的推理吞吐量提升以及3.3倍的峰值内存开销降低。代码和模型将在https://github.com/MM-Speech/VoxZip 提供。

## Abstract
Recent advancements in Speech Large Language Models have demonstrated remarkable capabilities in understanding complex audio tasks. Despite this progress, their long-context inference remains severely bottlenecked by prohibitive KV cache memory demands. Existing text-centric compression methods struggle here, often disrupting speech continuity or discarding crucial semantic cues. To address this, we propose VoxZip, a train-free, two-stage semantic-anchored KV cache compression framework. The first stage uses automatic speech recognition (ASR) transcriptions as explicit semantic anchors to temporally align, compress, and fuse audio tokens, significantly reducing the initial KV cache while elevating token information density. To further improve the compression ratio, the second stage employs a dynamic filtering strategy based on temporally decayed accumulated attention to evict non-essential tokens while mitigating early-token bias. Comprehensive evaluations on Qwen3-Omni across six diverse audio benchmarks demonstrate the superiority of our approach. VoxZip excels in long-audio reasoning and consistently maintains high-fidelity perception on short-form tasks. Notably, it sustains over 90\% of the uncompressed baseline performance even under an aggressive 20x KV cache compression in long-context scenarios. Furthermore, at a 4x compression ratio, VoxZip yields a 1.9x increase in inference throughput alongside a 3.3x reduction in peak memory overhead. Code and models will be available at https://github.com/MM-Speech/VoxZip.

- **核心问题**：长上下文 SLLM 推理受制于 **KV 缓存内存瓶颈**——在预填充和自回归解码阶段累积的 KV 缓存随序列长度线性增长，造成高昂的内存开销与推理延迟。
- **已有方法的不足**：文本模态的 KV 压缩方法（如 StreamingLLM、SnapKV、PyramidKV、ChunkKV）直接迁移到音频域效果不佳，原因在于：
  - 音频信号存在**强时间冗余**和**低信息密度**，注意力分数分布弥散（attention dilution），缺乏文本那样的显著显著性；
  - 仅依赖注意力分数的驱逐机制难以定位关键语义锚点，易导致语义漂移或幻觉；
  - 文本中心方法可能破坏语音连续性或丢失关键副语言线索。
- **核心洞察**：如图 1 所示，音频 token 的注意力分布与文本存在显著的模态异质性——文本区域注意力矩阵高度显著，而原始音频 token 注意力被严重稀释。因此需要一种模态感知的、以语义为锚的压缩策略。

## 2. 方法论：VoxZip

- **总体思路**：提出 **VoxZip**，一种**无需训练（train-free）的两阶段语义锚定 KV 缓存压缩框架**。其核心理念是通过语义锚点重塑音频 token 的信息密度。

### 第一阶段：语义锚定音频压缩（预填充阶段）

该阶段以 ASR 转录文本为显式语义锚点，对对应声学区间进行时间对齐、压缩与融合，包含三个步骤：

1. **时间对齐的嵌入切分**：
   - 使用 Whisper-Turbo ASR 模型生成带时间戳的转录，仅保留置信度 > 0.3 的片段，形成有效语义集合 S = {S₁, ..., Sₙ}；
   - 在**连续音频潜空间**中直接切分（而非物理截断波形），通过时间映射公式将绝对时间映射到离散音频 token 索引：
     - `idx_start = ⌊L_a · τ_start / τ_total⌋`
     - `idx_end = ⌊L_a · τ_end / τ_total⌋`
   - 切分出语义音频区间 E_A,s 与背景音频区间 E_A,bg。

2. **语义锚定压缩与融合**：
   - 将每个语义区间的 L_a 个声学特征均匀划分为 L_t 组（与文本 token 数对齐）；
   - 对每组执行**逐元素平均池化**：`ẽ_a,j = (1/|G_ij|) Σ e_a,k`；
   - 将池化后的声学表示与对齐的文本嵌入做**逐元素相加**构建语义锚点：`e_f,j = ẽ_a,j + e_t,j`；
   - 该操作将音频语义区间压缩至原长的约 **0.25×**，在保留副语言线索的同时与核心文本语义紧密对齐。

3. **背景保留与序列拼接**：
   - 保留未转写或低置信度区间（背景声学区间）的原始特征以维持全局环境声感知；
   - 按原始时间顺序拼接融合语义区间与背景区间，形成最终压缩输入序列 E_comp。

### 第二阶段：时间衰减的 KV 缓存驱逐（解码阶段）

- **问题**：传统累积注意力分数评分存在**早期 token 累积偏差**——早期 token 经历更多累积步骤，天然获得更高分数，导致驱逐机制持续保留它们。
- **解决方法**：引入**时间衰减机制**，按层独立维护时间衰减累积分数向量：
  - `A⁽ᵗ⁾ = γ · [A⁽ᵗ⁻¹⁾, 0] + Softmax(q_t K_tᵀ / √d)`
  - 其中 γ ∈ (0,1) 为衰减系数（经验值设为 0.95），显式惩罚陈旧的音频状态。
- **驱逐策略**：将缓存分为三部分——无条件保留的注意力汇点窗口（T=4 个 token）、最近的 M 个 token（动态分配 20% 预算）以及基于衰减累积分数选出的 Top-N 重要历史 token：
  - `I_hist = Top_N(A⁽ᵗ⁾[T:-M])`
  - 通过拼接操作更新 KV 缓存。

## 6. 主要结论与发现

- **语义锚定有效**：以 ASR 转录为锚点压缩音频区间，可显著提升 token 信息密度，将原本弥

散的音频表示重塑为语义密集的锚定表征，从而在低预算下保持甚至超越完整 KV 的性能。

- **时间衰减有效**：引入按层独立维护的时间衰减累积分数可有效缓解早期 token 累积偏差，γ=0.95 时在 5% 极端预算下仍保持 91% 以上的性能保留率，而 γ=1.00（即不使用衰减）时性能显著下降，验证了该机制的必要性。
- **融合策略的互补性**：Stage-1 中“文本嵌入 + 池化音频嵌入”的全融合（T+A Full）在语义类基准上最优，而音频单独表示更利于非语义任务（如说话人识别），表明语义锚定应保留音频与文本的双通道信息，而非简单地以文本替代音频。
- **压缩比的强鲁棒性**：从 25% 压缩到 5% 预算（即 4× 到 20× 压缩），VoxZip 的性能衰减平缓，在长上下文基准上始终优于所有基线在更高预算下的表现，说明其压缩能力在极端约束下依然可靠。
- **效率红利显著**：结合语义压缩与 KV 驱逐，可在 64K 上下文下实现峰值内存降低 3.34×、吞吐提升 1.93×、预填充延迟加速 1.74×，且这些收益已包含 ASR 辅助模块的额外开销。
- **模态异质性的关键启示**：直接迁移文本模态的 KV 压缩方法无法解决音频注意力稀释问题，必须结合模态特有的语义结构（如语音转录）进行锚定与重塑，这为未来多模态 KV 压缩研究提供了重要方向。

## 7. 局限性与未来方向

- **单一骨干验证**：所有实验仅在 Qwen3-Omni 系列（30B）上进行，VoxZip 对其他 SLLM 架构（如 SALMONN、Qwen-Audio 等）的迁移性尚未验证。
- **ASR 依赖与误差传播**：当前框架强依赖 Whisper-Turbo 的转录质量与时间戳精度，对低资源语言、强噪声环境或副语言信息丰富的语音场景仍可能存在误差传播风险。
- **闭源基线缺失**：SpeechPrune 作为当前最有竞争力的音频 KV 压缩方法，因闭源未能纳入公平对比，削弱了与 SOTA 直接比较的完整说服力。
- **动态压缩策略不足**：当前以固定压缩比（25%/15%/10%/5%）控制缓存预算，尚未实现根据任务难度或序列内容自适应调整压缩率的动态机制。
- **多模态协同未探索**：VoxZip 当前仅处理音频模态的 KV 压缩，对视频等其他模态与音频联合输入的协同压缩尚未涉及。
- **统计稳健性信息缺失**：论文未报告多次独立运行的标准差、置信区间等统计显著性指标，难以评估结果在随机性下的稳定性。
