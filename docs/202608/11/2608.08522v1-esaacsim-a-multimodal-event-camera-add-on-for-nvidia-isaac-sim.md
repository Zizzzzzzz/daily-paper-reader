## 摘要
基于事件的视觉正在成为机器人学中越来越重要的感知范式，然而其应用仍然受到传感器可用性以及缺乏面向现代机器人平台的集成仿真工具的限制。本文介绍了EsaacSim，一个用于NVIDIA Isaac Sim的多模态事件相机插件，它支持对可配置事件相机进行在线仿真，并生成灰度与Bayer RGGB事件。该框架支持多种事件相机分辨率，并通过原生ROS2接口提供同步的RGB、APS、事件、深度和IMU输出。一种运动引导的帧间隔合成策略进一步提高了有效时间分辨率，同时保持与Isaac Sim渲染管线的兼容性。实验评估展示了在代表性机器人场景中的同步多模态仿真，以及五种事件相机分辨率下、有效事件率从240Hz到960Hz的高效在线性能。事件流生成对于灰度事件需要6.98-27.28毫秒，对于Bayer RGGB事件需要7.58-29.16毫秒，同时在NVIDIA RTX 4060 GPU上仅使用不到400MB的额外GPU内存。这些结果表明，EsaacSim能够支持用于机器人研究和合成数据生成的在线多模态事件相机仿真。我们发布了该仿真器的早期版本，并报告其当前的架构和性能。

## Abstract
Event-based vision is becoming an increasingly important sensing paradigm for robotics, yet its adoption remains limited by sensor availability and the lack of integrated simulation tools for modern robotics platforms. This paper presents EsaacSim, a multimodal event camera add-on for NVIDIA Isaac Sim that enables online simulation of configurable event cameras with grayscale and Bayer RGGB event generation. The framework supports multiple event camera resolutions and provides synchronized RGB, APS, event, depth, and IMU outputs through native ROS2 interfaces. A motion-guided frame-gap synthesis strategy further increases the effective temporal resolution while preserving compatibility with the Isaac Sim rendering pipeline. Experimental evaluation demonstrates synchronized multimodal simulation across representative robotic scenes and efficient online performance over five event camera resolutions at effective event rates from 240 to 960Hz. Event stream generation requires 6.98--27.28ms for grayscale events and 7.58--29.16ms for Bayer RGGB events while using less than 400MB of additional GPU memory on an NVIDIA RTX~4060 GPU. These results show that EsaacSim enables supports online multimodal event-camera simulation for robotics research and synthetic data generation. We release an early version of the simulator and report its current architecture and performance.

- **论文目标**：提出 **EsaacSim**，一个面向 NVIDIA Isaac Sim 的多模态事件相机插件，支持在线、可配置的灰度（grayscale）与 Bayer RGGB 事件仿真，并通过原生 ROS 2 接口同步输出 RGB、APS、事件、深度与 IMU 数据，推动机器人多模态感知研究与合成数据生成。

## 2. 论文提出的方法论

### 2.1 核心思想
- 不替换 Isaac Sim 原生的 RTX 相机渲染管线，而是“挂接”到已有相机的渲染输出上，将其转换为异步事件流。
- 采用分层架构，将场景渲染、事件生成与数据发布解耦，便于独立演进与扩展。

### 2.2 系统架构
- **原生 Isaac Sim 层**：负责场景表示、物理仿真（PhysX）、渲染与相机图像生成。
- **EsaacSim 扩展层**：负责相机原语发现、运行时配置、GPU 图像缓冲获取、可视化与 ROS 2 通信。
- **事件生成后端**：基于帧的 log-intensity 模型，将灰度或 Bayer 图像转换为异步事件。
- **输出接口层**：通过 ROS 2 发布 RGB、APS、事件、深度与 IMU 数据。

### 2.3 事件生成模型
- 采用标准事件相机模型：若像素的 log 强度变化超过对比度阈值，则产生正/负事件。
- 强度计算：
  - 对 HDR 图像 \(I_k\) 转换为标量强度 \(S_k\)（灰度/加权亮度/Bayer RGGB 采样）。
  - 计算对数强度 \(L_k(x,y)=\log(S_k(x,y)+1)\)。
- 事件生成条件：
  - \(\Delta L_k(x,y) = L_k(x,y) - L_{ref}(x,y)\)
  - 当 \(\Delta L \ge C_{ON}\) 产生 ON 事件，当 \(\Delta L \le -C_{OFF}\) 产生 OFF 事件，随后更新参考强度 \(L_{ref}\)。
- **Bayer RGGB 支持**：直接根据虚拟 RGGB 马赛克对 R、G1、G2、B 通道分别独立应用同一 log-intensity 模型，保留真实 Bayer 事件相机的色彩空间采样模式。

### 2.4 运动引导的帧间隙合成（Motion-Guided Frame-Gap Synthesis）
- 为了提高有效时间分辨率，不必提高 Isaac Sim 渲染频率，而是利用渲染器提供的密集运动向量（motion vectors）。
- 给定两帧渲染图像 \(I_{k-1}\)、\(I_k\) 以及运动场 \(v(x,y)\)，用后向扭曲（backward warping）合成中间帧：
  \[
  I_{k,n}(x,y)=I_k(x-\alpha u(x,y), y-\alpha v(x,y))
  \]
  其中 \(\alpha=n/N\)，\(n=1,\ldots,N-1\)，插值因子 \(N\) 对应 8/16/32 倍，有效事件率可达 240/480/960 Hz（假设渲染频率 30 Hz）。
- 若运动向量不可用，则回退为线性图像插值。
- 合成帧时间戳为 \(t_{k,n}=t_{k-1}+\frac{n}{N}(t_k-t_{k-1})\)。

### 2.5 可配置传感器模型
- 支持配置参数包括：空间分辨率（DVS128、DAVIS240、ATIS、DAVIS346、GenX320）、对比度阈值 \(C_{ON}/C_{OFF}\)、像素级阈值失配、不应期（refractory period）、延迟（latency）、时间戳量化、散粒噪声、漏电流噪声、强度模式（灰度/亮度/Bayer RGGB）。

### 2.6 ROS 2 输出接口
- 提供三种事件消息形式：`Event`（单事件）、`EventPacket`（批处理）、`PackedEventPacket`（结构体数组打包，降低高频率事件流序列化开销）。
- 同时提供 APS 灰度/Bayer 图像、深度图像、IMU 数据，并与事件流时间戳对齐，适用于 RGB-event、depth-event、视觉惯性等多模态算法。

## 7. 优点

- **面向机器人集成**：与 Isaac Sim 原生渲染管线兼容，支持 ROS 2 原生接口，易于与现有机器人工作流（RViz2、rosbag2 等）集成。
- **多模态同步输出**：RGB、APS、事件、深度、IMU 同步生成，对多模态感知研究价值高。
- **传感器可配置性**：支持阈值、阈值失配、不应期、延迟、噪声等丰富参数，可模拟不同型号事件相机的特征。
- **Bayer RGGB 支持**：保留真实 Bayer 事件相机的色彩采样结构，比一般灰度事件仿真更贴近实际硬件。
- **性能友好**：在消费级 GPU 上即可在线运行，显存开销低，便于推广。
- **创新设计**：运动引导帧间隙合成利用渲染运动向量提高时间分辨率，是一种高效且与渲染管线解耦的方案。
- **架构清晰**：分层设计（原生 Isaac Sim 层 / 扩展层 / 事件生成后端 / 输出接口）使各模块可独立演进。
