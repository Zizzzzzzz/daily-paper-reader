## 摘要
高效Transformer研究常以并非所有令牌都需要同等计算量这一主张来激励令牌剪枝与自适应计算。我们通过SEWN对这一主张进行了端到端测试，SEWN是一种双流Transformer，通过学习的门控将令牌路由至轻量级或全容量处理。在我们的实验中，相对于参数匹配的基线，路由仅引入可忽略的精度变化，而门的令牌重要性信号关键取决于其学习方式。静态词典种子先验在BoolQ上未能通过反事实忠实性测试，而完全上下文化的门在两个评估任务上均实现了高度显著的分离（p<10^-10），且不改变任务精度。

## Abstract
Efficient-transformer research often motivates token pruning and adaptive computation with the claim that not all tokens require equal computational effort. We test this claim end to end using SEWN, a two-stream Transformer that routes tokens through either lightweight or full-capacity processing using a learned gate. Across our experiments, routing introduces negligible accuracy change relative to parameter-matched baselines, while the gate's token-importance signal depends critically on how it is learned. A static lexicon-seeded prior fails a counterfactual faithfulness test on BoolQ, whereas a fully contextual gate achieves highly significant separation ($p<10^{-10}$) on both evaluated tasks without changing task accuracy.

## 1. 论文的核心问题与整体含义（研究动机和背景）

高效Transformer研究长期以来基于一个核心假设：**并非所有输入 token 都需同等计算量**——虚词、模板化内容可被廉价处理，而承载语义的关键 token 才需要全模型容量。这一假设驱动了 token 剪枝、token 合并、深度自适应计算等大量工作，并隐含着两个通常被捆绑在一起的主张：

1. **效率主张**：跳过或廉价处理“不重要的”token 可以在精度损失很小的情况下节省计算量。
2. **可解释性主张**：用于决定 token 重要性的信号，本身可以当作模型行为的人可读解释。

本文旨在**严格、分离、诚实地**检验这两个主张，为此提出了 **SEWN（Stream-Efficient Word Network）** ——一种显式路由决策的双流 Transformer 架构。论文的定位不是提出新的 SOTA 高效架构（作者明确承认 DistilBERT 在同等参数预算下精度更高），而是一篇方法论与机制性的实证研究：它通过端到端实验、反事实忠实性测试、控制消融和跨任务泛化分析，检验路由机制在效率和可解释性两个维度上的真实表现。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想

SEWN 采用**双流处理**设计，用一个可学习的门控（gate）为每个 token 分配处理路径：

- **轻量级功能词流（function-word stream）**：2 层、256 维，接收由门控值缩放的 token 嵌入，处理全序列（保持上下文）。
- **内容流（content stream）**：4 层、768 维，直接移植自 bert-base-uncased 权重，接收按（输入嵌入 × 门控值）缩放的 token 嵌入，专注于高重要性 token。
- **层级交叉注意力融合模块**：将两个流的表示融合后送入分类头。

### 2.2 门控设计的两种变体

| 变体 | 设计 | 关键特征 |
|---|---|---|
| **静态先验门控** | MLP 上下文分数 + 每词汇表 id 偏置项（初始化自手工构建的封闭类/功能词词典，经子词扩展后含 269 个 token id） | 体现语言学直觉：限定词、介词、助动词承载信息量低于实词 |
| **上下文门控** | 相同 MLP，**无词典偏置** | 门控完全从训练信号中学习 token 优先级 |

门控输出一个 [0,1] 标量，解释为“路由到廉价流的概率”。

### 2.3 三个核心架构变体

- **SEWN-core（基础）**：上述双流重加权结构，但两个流仍处理所有 token，不节省 FLOPs。
- **SEWN-sparse（计算主张落地）**：在进入昂贵内容流之前进行**硬 top-k 选择**（始终包含 [CLS] token），仅被选中的 k 个 token 进入内容流；功能流仍处理全序列。融合机制重构为：k 长度的内容表示通过一个交叉注意力块**查询**全长功能表示，恢复必要上下文，同时避免了昂贵流中的 O(n²) 注意力。这实现了真实的计算节省。
- **SEWN-lean**：移除功能流和融合模块，保留单个内容流，门控作为唯一的 per-token 机制（门控值变为 1−g 加权的输入缩放）。
- **SEWN-random-topk**（仅消融）：与 SEWN-sparse 架构完全一致，但每次前向随机抽取 k 个 token 进入内容流，用于隔离“硬选择瓶颈”与“学习排名”各自的作用。

### 2.4 反事实忠实性协议

对于验证子样本（n=200），计算各方法的 per-token 重要性分数，然后通过 [MASK] 替换 top-20%、bottom-20% 以及五个随机 20% 的 token，测量模型对原始预测 softmax 置信度的下降幅度。**严格忠实标准**要求满足单调排序 **top > random > bottom**（显著性 p < 0.05，配对 t 检验）：

- top-k masking 导致的置信度下降 > random-k 的下降（综合充分性/完整性）
- random-k 下降 > bottom-k 的下降（验证主动 token 过滤，而非未校准的扰动）

### 2.5 蒸馏修复机制

对于 SEWN-lean 在 BoolQ 上忠实性失败的问题，使用 KL 散度 logit 蒸馏 + 显式 MSE 匹配教师的 per-token 门控分数：

$$L = L_{task} + \alpha \cdot L_{logit\text{-}KD} + \beta \cdot L_{gate\text{-}MSE}，\quad \alpha = 1.0，\beta = 2.0$$

## 6. 主要结论与发现

### 6.1 经得起检验的主张（4 条）

1. **手工语言先验会静默地降低学习的重要性信号可靠性**，且不伴随精度变化：静态词典先验在 BoolQ 上完全失败（p=0.48，不可与随机区分），而上下文门控在两个任务上均通过（p<10⁻¹⁰），精度仅相差约 0.3 分。
2. **硬 top-k 选择是真实且稳健的计算收益**：SEWN-sparse 较 BERT-base 加速 5.2–8.7 倍，较 DistilBERT 加速 2.6–4.4 倍，跨越所有测试数据集；在数据量和序列长度约 3 倍变化的 PubMedQA 上依然成立（6.36 倍 vs. BoolQ 的 6.14 倍）。
3. **门控的忠实性取决于选择标准是否为稳定的内容决定函数，而非硬瓶颈本身**：随机选择（机制相同的瓶颈）p=0.45，完全消解了忠实性；冻结注意力的非学习排名能通过测试，但需额外完整前向，实际更慢于未剪枝的 BERT-base。
4. **MoD 路由器具有真实信号但达不到严格排序标准**：MoD 的 top-vs-random（p=1.3×10⁻⁶）和 top-vs-bottom（p=1.7×10⁻⁴）都显著，但 bottom-drop 略高于 random-drop，违反 top>random>bottom 严格标准，故判定 FAIL。

### 6.2 被推翻的主张（4 条）

1. **路由能显著提升任务精度**：在 BoolQ 上，SEWN 最优变体也不及简单的内容-only 消融（69.68），且与均匀 50/50

提升无关：SEWN 的精度并没有因路由而获得显著优势。事实上，在 BoolQ 上，SEWN 最优变体也不及简单的内容-only 消融（69.68），且与均匀 50/50 门控（SEWN-no-gate）相比没有系统性增益。

2. **重要性分数可以作为直接、可迁移的解释**：反事实实验表明，SEWN 的上下文门控在多数任务上通过严格忠实性测试，但解释力随数据集和骨干剧烈波动；在 RACE 上完全失效，在 RoBERTa/BoolQ 上出现无法复现的结果。因此“路由分数 = 可靠解释”的泛化主张被推翻。

3. **token 重要性在稠密基线上是不可获取的**：作者原预期只有显式路由模型才能产生内容敏感的重要性信号。但实验发现，冻结 BERT-base 的注意力到 CLS 的分数（SEWN-attn-topk）也能通过部分忠实性测试，说明结构无关的信号在稠密基线中已经存在，路由机制并非唯一来源。

4. **手工语言先验必然有帮助**：静态先验（功能词偏置）不仅没有提升忠实性，反而抑制了可学习门控的表现（BoolQ 失败），说明“语言直觉先验”在自动路由场景中是不必要的、甚至有害的负担。

### 6.3 数据集与任务维度的模式

- **忠实性容易达成的场景**：BoolQ、PubMedQA、Winogrande（单一强线索，如实体、否定词、对比词）。
- **忠实性困难或失效的场景**：RACE（长文本多跳推理，需要全段综合而非局部 token 删除）、IMDB（情感关键词分散，但门控仍通过）、SWAG（上下文依赖强，但门控通过）。
- **RACE 的全面崩溃**：所有变体（包括 BERT-base 本身）在 RACE-middle 上精度都低于随机选择（~25%），表明该配置下 3 epoch / 低学习率的训练协议不足以让模型学到有效表示，而非路由机制本身的缺陷。

### 6.4 可解释性与效率的权衡

SEWN-sparse 展示了“训练时用门控分数做硬选择、推理时通过 FLOPs 节省”的可行性，但这种效率收益与可解释性收益并不绑定：随机 top-k 同样能获得相同的加速（因为计算图相同），却完全没有忠实性。因此，**效率来自架构（稀疏计算），忠实性来自学习到的排名**——二者是独立维度，必须分别评估。

## 7. 已知局限与开放问题

### 7.1 论文明确承认的局限

- **忠实性测试规模有限**：n=200、单一掩码比例（20%）、未做多重比较校正；作者承认更彻底的解释评估需要更大样本和更多扰动模式。
- **未解决的泛化问题**：静态先验、上下文门控、硬 top-k 在不同骨干、任务、训练配置上的表现极不一致（RoBERTa 上无法复现 BoolQ 的结论），说明当前路由机制的迁移能力尚未被理解。
- **RACE 上的失败**：无法区分是训练不足还是架构不匹配，降低了该数据集作为忠实性基准的可信度。
- **未对比大规模模型**：所有实验在 BERT-base 规模完成，结论是否能推广到 1B+ 参数模型（如 Llama、T5-XXL）未知。
- **效率测量口径**：FLOPs 节省基于固定序列长度（512）的估算，未覆盖动态批处理、显存、内存带宽等真实工程开销；MoD 的延迟测量也只是单卡 GPU 上的相对值。

### 7.2 开放问题

1. 如何设计门控信号，使其在长文本、多跳推理（如 RACE/HotpotQA）中保持逐 token 可归因性？
2. 路由机制与知识蒸馏能否解耦？本文的 gate-MSE 修复有效但仅用于单一失败案例，缺乏通用理论。
3. 静态先验的失败是否意味着所有语言先验都应被摒弃？还是说需要更精细的、位置/句法感知的先验？
4. 学习排名的忠实性是否随模型规模单调提升？本文的负面结果显示规模与骨干的影响可能是非单调的，亟需更大规模的实验。

## 8. 对后续研究的启示

本论文的最大价值在于方法论上的“拆解”：它将“稀疏计算”与“可解释性和重要性解释”从历史上纠缠的假设中分离，并给出了可复用的评估协议（反事实掩码 + 严格排序标准 + 随机对照）。未来工作可借鉴：

- **评估范式**：任何声称“路由/剪枝提供可解释性”的工作，都应报出 top/random/bottom 的完整掩码曲线，而非仅展示 top-k 归因图。
- **架构设计**：SEWN-sparse 的“廉价流处理上下文 + 稀疏昂贵流 + 交叉注意力融合”结构，可被改造为更高效的 MoE 或多令牌预测框架。
- **训练信号**：显式 gate-MSE 蒸馏（β=2.0）提供了一种将教师重要性分数迁移到学生路由器的简单实例，可推广到用户定义的关键性目标。
- **负面结果的价值**：RACE 的崩溃、BoolQ/RoBERTa 的不可复制性提醒后续研究，路由可解释性宣言必须先限定任务域和训练配置。

## 9. 总体评价

本文是一项**严谨、有原则、敢于自我否定**的实证研究。它没有追求 SOTA 精度，而是回答了“效率与可解释性两个承诺各自成立到什么程度”这一关键问题。其主要贡献不是一个新的高效架构，而是一套可复用的**反事实忠实性协议**，以及大量诚实的负面结果——例如“手工先验有害”“随机瓶颈与学习瓶颈不可混淆”“冻结注意力也能获得部分忠实性”。缺点是任务域和模型规模有限，且某些关键结论（如 RACE）受训练配置混淆，导致部分证据链不闭环。但作为一篇方法论论文，其分离双主张、构建严格检验标准的思路，对 token 级高效 NLP 研究的未来工作具有很高的参考价值。
