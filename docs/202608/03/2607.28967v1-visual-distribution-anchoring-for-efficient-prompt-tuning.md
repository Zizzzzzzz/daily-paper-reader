## 摘要
提示调优以少量可训练参数适应视觉-语言模型，但现有方法在效率与适应性之间存在权衡：静态文本提示可能过拟合源类别，图像条件提示增加逐实例计算，多模态调优则修改视觉分支。我们提出VDA（视觉分布锚定），一种无需训练的target适配框架，通过离线从无标签目标池估计的类级视觉原型来增强冻结的语义分类器。我们首先探究原型能否从类名合成。文本到质心映射器能重建保留的源原型，但在数据集偏移下失败，因为类名指定语义身份而非目标域外观。Oracle分析证实真实目标原型具有高度判别性。因此，VDA利用冻结的语义和域模板分类器将无标签目标图像划分为类相关组。置信度排序的图像特征形成归一化原型，并通过一个全局权重与语义分类器融合。适配无需目标标签、目标侧优化、统一类先验假设、迭代细化或测试查询访问，并产生固定可缓存的分类器。受控实验表明，类特定划分驱动性能提升，且视觉局部伪标签错误即使类别不正确也可能仍然有用。在十次ImageNet到目标迁移中，相同的冻结设计分别将zero-shot CLIP、TCP和MaPLe提升3.22、3.39和3.35个百分点，在每种设置下改善十个目标中的九个。其视觉校正进一步将无泄漏的PromptKD提升2.79个百分点，补充了zero-shot、源提示、多模态提示和目标蒸馏分类器。

## Abstract
Prompt tuning adapts vision--language models with few trainable parameters, but existing approaches trade off efficiency and adaptation: static textual prompts can overfit source classes, image-conditioned prompts add per-instance computation, and multimodal tuning modifies the visual branch. We propose VDA (Visual Distribution Anchoring), a training-free target adaptation framework that augments a frozen semantic classifier with class-level visual prototypes estimated offline from an unlabeled target pool. We first ask whether prototypes can be synthesized from class names. A text-to-centroid mapper reconstructs held-out source prototypes but fails under dataset shift because class names specify semantic identity, not target-domain appearance. An oracle analysis confirms that true target prototypes are highly discriminative. VDA therefore uses frozen semantic and domain-template classifiers to partition unlabeled target images into class-correlated groups. Confidence-ranked image features form normalized prototypes, fused with the semantic classifier using one global weight. Adaptation requires no target labels, target-side optimization, uniform class-prior assumption, iterative refinement, or test-query access, and yields a fixed, cacheable classifier. Controlled experiments show that class-specific partitioning drives gains and that visually local pseudo-label errors can remain useful despite being class-incorrect. Across ten ImageNet-to-target transfers, the same frozen design improves zero-shot CLIP, TCP, and MaPLe by 3.22, 3.39, and 3.35 points, respectively, improving nine of ten targets in every setting. Its visual correction further improves leakage-free PromptKD by 2.79 points, complementing zero-shot, source-prompted, multimodal-prompted, and target-distilled classifiers.

## 1. 核心问题与整体含义（研究动机与背景）

### 研究背景

- 视觉-语言模型（如 CLIP）通过将图像表示与类名构建的文本分类器进行比较，实现零样本识别。
- 提示学习（Prompt Learning）利用有限的标注源数据改进这些分类器，但现有方法面临一个**效率—适应性权衡**：
  - **静态文本提示**（如 CoOp）：成本低，但容易过拟合源分布。
  - **图像条件提示**（如 CoCoOp）：适应性强，但逐实例计算成本高。
  - **多模态方法**（如 MaPLe）：同时修改语言和视觉提示路径，但改动较大。

### 核心问题

- 源训练的分类器可能保留了目标类别的"语义身份"，却无法捕捉该类别在新域中"视觉上如何表现"。例如，"森林"这一名称无法说明它在高空卫星图像中的外观。
- 一个自然想法是直接从类名预测视觉类原型，但研究表明：**源域原型的准确重建并不能迁移到目标域**——类名指定了语义身份，却没有指定目标域中的视觉实例化方式。

### 论文提出的解决思路

- 通过离线从**无标注目标池**中估计类级视觉原型，并将其与冻结的语义分类器融合。
- 该方法无需训练、无需目标标签、无需优化，产生一个固定的、可缓存的分类器。

## 2. 方法论：VDA（Visual Distribution Anchoring）

### 核心思想

- 使用冻结的语义分类器和固定的域模板分类器，对无标注目标图像进行**硬划分**，形成类相关分组。
- 在每个分组内，按置信度排序保留最多 K 张图像，其归一化均值构成目标视觉原型。
- 通过**一个全局融合权重**，将视觉原型分数与语义分类器分数融合。

### 技术流程（六步）

1. **图像编码**：用冻结的 CLIP 图像编码器对所有无标注目标图像编码并归一化：
   \( v_i = \text{norm}(f_V(x_i)) \)

2. **域感知分配**：构建域模板分类器（如"a true-color overhead satellite image of a {class}"），将语义分数与域模板分数平均：
   \[
   a_{ic} = \frac{1}{2}(s_{sem}(x_i,c) + s_D(x_i,c))
   \]
   每个图像通过 argmax 硬分配到一个预测类 \( \hat{c}_i = \arg\max_c a_{ic} \)。

3. **有上限的伪支持选择**：在每个预测类内，按 softmax 置信度排序，保留最多 K 张图像（K=32）。

4. **目标视觉原型估计**：对每个支持的类，计算所选图像归一化特征的均值并再次归一化：
   \[
   \hat{\mu}_c = \text{norm}\left(\frac{1}{|S_c|}\sum_{i\in S_c} v_i\right)
   \]

5. **语义—视觉融合**：最终分数为：
   \[
   s_{VDA}(x,c) = (1-\lambda_c)s_{sem}(x,c) + \lambda_c s_{vis}(x,c)
   \]
   其中 \( \lambda = 0.2 \) 为全局融合权重，无支持图像的类别保留纯语义分类器。

6. **共享空间简化**：当语义分类器与视觉原型共享同一 CLIP 特征空间时，融合退化为固定类向量的线性组合，可在推理前缓存：
   \[
   \bar{w}_c = (1-\lambda)w_c^{sem} + \lambda \hat{\mu}_c
   \]

### 关键设计原则

- **硬划分而非软分配**：避免均匀类先验假设和熵崩溃问题。
- **K 是上限而非均衡约束**：允许类别间支持数不均衡。
- **一次性适应**：不做迭代伪标签细化，避免强化初始错误。
- **不需要**：目标标签、目标侧梯度优化、验证集早停、统一类先验、测试查询访问。

## 6. 主要结论与发现

### 核心结果

- VDA 将主要语义分类器（TCP）从 65.82% 提升至 69.21%（+3.39 点），10 个数据集中改善 9 个（Food101 基本不变，-0.12）。
- 在匹配协议下，VDA 超过 ZLaP 1.53 点（8/10 数据集更高），超过无先验 InMaP 复现 2.98 点（9/10 更高）。
- 同一套冻结设计提升零样本 CLIP 3.22 点、MaPLe 3.35 点、无泄漏 PromptKD 2.79 点，每种设置均为 9/10 改善。

### 关键机制发现

1. **类名无法独力预测目标域原型**：文本到质心的映射器在源域内重建精度很高（0.930 余弦），但目标域中心化对齐很弱（0.387），跨域迁移失败。
2. **真实目标原型高度判别**：Oracle 分析显示，真实验证 16-shot 质心分类可达 66.16%（基线 49.91%）。
3. **硬划分是主要驱动力**：通用目标质心、随机目标分配、打乱原型都无效；类特定硬划分贡献了大部分性能提升。
4. **置信度排序贡献较小但存在**：类内随机采样 53.23% → 置信度排序 54.92%，且在 EuroSAT 和 UCF101 上效果显著，但在 Aircraft 上统计上不显著。
5. **视觉局部的伪标签错误仍然有用**：Aircraft 上错误支持样本与真实类的视觉相似度在错误对中处于第 88.7 百分位，且显著富集正确的飞机家族（17.1% vs 1.25%）和制造商（38.4% vs 7.98%）。
6. **软分配失败**：平衡 Sinkhorn 分配产生高熵分配（0.949–0.994），迭代细化后效果更差。

## 7. 优点

### 方法设计的亮点

- **极简高效**：无需训练、无梯度更新、无迭代细化，单次前向适应即可完成。
- **即插即用**：不修改任何提示学习器的内部架构，作为 logit 级修正与多种分类器兼容。
- **固定可缓存分类器**：共享特征空间下融合退化为一次性向量组合，推理成本与普通 CLIP 相同。
- **清晰的实验隔离**：对方法内部各组件（硬划分、置信度排序、域模板、融合）逐一归因，证明"类别对应"而非"通用域统计"是改进来源。
- **严谨的协议匹配**：区分匹配协议与非匹配协议的基线结果，避免误导性对比。

### 实验设计的优点

- 对 InMaP 的匹配复现做了明确说明，并如实报告了协议差异。
- PromptKD 实验特意采用"无泄漏"协议（最后一步检查点而非最佳验证检查点），防测试集泄漏。
- 消融实验充分揭示了解释机制（错误的伪标签为何有用），具有学术价值。

## 8. 不足与局限

### 方法本身的局限

- **依赖无标注目标图像**：VDA 并非严格的 source-only 或 name-only 方法，如果目标池有偏、过小或时间不匹配，性能可能下降。
- **需要人工域描述**：域模板分类器依赖手动指定的域描述，当部署域未知、异质或难以描述时，模板选择可能需要额外人工。
- **固定在 CLIP ViT-B/16 特征空间**：所有原型在 OpenAI CLIP ViT-B/16 空间中估计，虽然语义分类器可替换，但没有验证其他骨干（如 ViT-L/14、SigLIP 等）的泛化性。
- **无法覆盖无支持类**：如果某个类别没有分配到图像，VDA 保留语义分类器，但其他类别的视觉校正可能仍会改变决策边界，且无法恢复完全无支撑的类别。
- **全局固定融合权重**：单一权重 λ 稳定但未必最优，论文承认无法充分利用异常高质量的原型；类相关权重尝试未成功，留作未来工作。

### 实验覆盖的局限

- **超参选择非完全无偏**：K 和 λ 在 5 个开发集上选择，其余 5 个数据集已经看过早期配置的结果，作者已坦率声明。
- **InMaP 对比**：官方配置因协议不同被分离报告，匹配复现是"无细化"的前置 Free 版本，可能没有充分发挥 InMaP 的潜力。
- **MaPLe/PromptKD 是 logit 级附件**，推理时可能需要额外的原始 CLIP 分数流，与纯单一骨干推理成本不等价。
- **Food101 几乎是唯一的负例**：在多个设置下 VDA 对 Food101 无提升或有轻微下降，说明某些域中语义分类器已足够好，视觉修正可能引入噪声，论文对此未做深入解释。

## 总结

VDA 提出了一种简单、免训练、无需标签的目标域适配机制：用冻结分类器对无标注目标池进行硬划分，以置信度排序提取类级视觉原型，并以全局权重与语义分类器融合。方法在十个跨域数据集上一致性地提升了多种基线（零样本/源提示/多模态提示/蒸馏分类器），具有清晰的机制分析和严谨的协议管理。尽管存在对无标签池和人工域描述的依赖、仅在单一骨干空间验证、以及超参选择非完全无偏等局限，其"语义保持类别身份 + 视觉纠正域外观"的设计理念为提示调优提供了有意义的补充方向。
