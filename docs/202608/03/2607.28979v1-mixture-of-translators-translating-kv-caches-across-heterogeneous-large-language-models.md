## 摘要
异构大语言模型（LLM）系统日益依赖共享上下文、检索到的证据和多智能体对话历史，然而其内部键值（KV）缓存仍然是模型特定的，无法跨架构重用。因此，每个模型都必须为相同上下文重复预填充或存储缓存，限制了多模型推理和长上下文生成的可扩展性。我们提出了翻译器混合（MoT）——一个缓存翻译框架，它可将源LLM的上下文KV缓存映射到目标LLM的缓存空间。与依赖单一投影路径或全局共享潜在空间的先前方法不同，翻译器混合使用多个翻译器模块来捕获多样的源-目标映射。为了进一步减少残差翻译误差，我们引入了上下文校正损失，将重放的目标轨迹与原生目标轨迹对齐。我们揭示了缓存翻译中两种相互竞争的失败模式：早期注入造成的传播翻译偏移和晚期注入造成的最后状态偏移。MoT通过翻译器混合和目标侧校正来解决这些问题。在Qwen2.5、GPT-2和OPT模型之间的同构和异构翻译中，翻译器混合保持了下游问答性能，包括Qwen2.5-7B规模的翻译：平均封闭集问答准确率为51.0%，平均抽取式问答F1为0.43。在实际案例研究中，翻译器混合实现了多智能体推理的保质量内存重用，并在长上下文缓存增强生成中保留了96.3%的直接上下文质量，展示了跨异构LLM的可扩展KV缓存重用。

## Abstract
Heterogeneous Large Language Model (LLM) systems increasingly rely on shared contexts, retrieved evidence, and multi-agent dialogue histories, yet their internal key-value (KV) caches remain model-specific and cannot be reused across architectures. Consequently, each model must repeatedly prefill or store caches for the same context, limiting the scalability of multi-model reasoning and long-context generation. We propose Mixture-of-Translators(MoT), a cache translation framework that maps context KV caches from a source LLM into the cache space of a target LLM. Unlike prior approaches that depend on a single projection path or global shared latent space, MoT uses multiple translator modules to capture diverse source--target mappings. To further reduce residual translation error, we introduce a Context Correction Loss that aligns the replayed target trajectory with the native target trajectory. We reveal two competing failure modes in cache translation: propagated translation shift from early injection and last-state shift from late injection. MoT addresses them through translator mixtures and target-side correction. Across homogeneous and heterogeneous translations among Qwen2.5, GPT-2, and OPT models, MoT preserves downstream QA performance, including Qwen2.5-7B-scale translation with 51.0% average closed-set QA accuracy and 0.43 average extractive QA F1. In practical case studies, MoT enables quality-preserving memory reuse for multi-agent reasoning and retains 96.3% of direct-context quality in long-context cache-augmented generation, demonstrating scalable KV cache reuse across heterogeneous LLMs.

### 二、论文方法论

#### 1. 核心思想

- 将源模型上下文缓存 `KV_Src,Ctx` 映射到目标缓存空间 `dKV_Tgt,Ctx`，使目标模型可直接使用翻译后的缓存完成后续预填充与生成。
- 不同于单一路径投影（C2C）或全局共享潜在空间（LSC），MoT 使用**多个翻译器模块**在**token 级别**进行混合路由，以捕获异构模型中多样化的源-目标缓存对应关系。

#### 2. 关键理论分析：两种竞争性误差

- **传播错误（Propagation Error）**：翻译注入层越早，翻译产生的偏移经残差网络向上传播，形成累积误差。理论证明（命题 2.3）传播后的最终状态偏移随注入层位置呈指数衰减，即注入越早、残差越严重。
- **校正赤字错误（Correction Deficit Error）**：翻译注入层越晚，留下供上层网络校正偏移的层数越少。理论上（命题 2.4）校正赤字系数在上层不足时趋于 1（即无法校正）。
- **联合优化目标**：需同时最小化翻译偏移 `||s_T||` 与最终状态偏移 `||s_L||`，两者缺一不可。

#### 3. MoT 架构

- **多个骨干翻译器**：每个翻译器采用基于交叉注意力的递归翻译结构（源自 LSC 但无共享潜在空间），将源缓存槽归一化、投影、跨层扫描融合后输出目标缓存块。
- **Token 级门控路由**：对每个 token，通过门控函数生成各翻译器得分，选取 Top-K 个翻译器并按归一化权重加权组合，使不同 token 可采用不同的翻译器组合（公式 5）。
- **理论优势（命题 3.2）**：最优 MoT 的翻译偏移不大于最优单翻译器，且在 token 级路由能实现单翻译器不可表示的映射时严格优于单翻译器。

#### 4. 上下文校正损失（Context Correction Loss）

- 让经翻译缓存重放的目标模型隐状态轨迹 `ĥ^Tgt_ℓ` 对齐原生预填充轨迹 `h^Tgt_ℓ`（公式 6）。
- 实现时采用 KV 层面的启发式（公式 14），通过比较重放与原生 KV 缓存来近似对齐，直接降低最终状态偏移 `||s_L||`。
- 理论保证（命题 C.1）：当末层 K/V 投影堆叠矩阵满列秩时，减小末层 KV 匹配误差等价于减小 `||s_L||` 的上界。

#### 5. 整体流水线（五阶段）

1. 上下文预填充（源模型计算源 KV 缓存并选定翻译通道）
2. KV 翻译（MoT 将源缓存映射到目标缓存空间）
3. 上下文重放（用翻译后的缓存重建目标侧缓存，配合校正损失）
4. 提示预填充（目标模型基于重建缓存处理查询）
5. 补全输出（生成最终回答）

#### 6. 其他工程细节

- **通道映射**：默认采用深度比映射（Depth-Ratio Mapping），仅使用连续通道窗口，并通过验证损失选择最优通道集。
- **稀疏重放**：提出 Top-S 源引导稀疏注意力，根据源模型注意力图选取重要 token 位置进行目标侧注意，将重放成本从 O(N²) 降为 O(N·S)（上下文长度为 N）。
- **MoT-h 变体**：受 HCache 启发，翻译中间激活而非 KV 张量，由目标模型自身的 K/V 投影恢复缓存，降低峰值内存与传输开销，但翻译容量略降。

### 七、优点

- **理论驱动**：对翻译注入位置的影响给出了形式化分析（指数衰减与校正赤字），并以统一的竞争性误差框架指导模型设计，方法有坚实的理论基础。
- **架构创新**：Token 级多翻译器混合（Top-K gating）突破了单一路径/单翻译器的表达能力瓶颈；新增 Context Correction Loss 直接针对残差误差，两者互补。
- **双重收益**：同时面向内存重用（多智能体 offload）和存储重用（长上下文 CAG），提供了实际可落地的系统价值。
- **丰富实验**：覆盖同构/异构、多种模型家族、参数规模扩展、多智能体与长上下文两大应用场景，且包含详细的消融与可扩展性分析。
- **诚实分析**：对校正赤字改善有限等局限性有自我剖析，附录中对失败情况（如 DialoGPT 层映射不规律）也有清晰的说明。

### 八、不足与局限

- **校正赤字未根本解决**：MoT 对 `d_T:L` 校正赤字系数改善有限，主要靠降低 `||s_T||` 和正交偏移 `β_T:L` 改善结果，并未提升目标模型自身的校正能力。
- **通道映射依赖深度比假设**：当模型在指令微调、训练分布或表示组织上差异较大时（如 DialoGPT 案例），深度比映射可能失效，需要更自适应的通道选择方法。
- **跨 tokenizer 问题未解决**：源与目标模型若使用不同 tokenizer，缓存位置无法直接对应，MoT 尚未支持跨 tokenization 的缓存翻译。
- **性能仍远低于 Native**：以 GPT-2 homogeneous 为例，MoT 的 42.0% 平均准确率低于 Native 的 35.0%（原文表 5 中 MoT 为 42.0%，但 NewsQA F1 仅 0.01，显示翻译质量仍有明显损失）；KV cache 翻译本质上是高维表示的近似重建，信息丢失不可避免。
- **额外峰值内存开销**：MoT 因多翻译器引入额外峰值内存（如 Qwen2.5-7B→0.5B 时为 16.62 GiB vs Native 15.25 GiB），尽管作者解释为大模型翻译中边际成本较小。
- **实验范围有限**：任务集中于 QA（闭集+抽取式），未覆盖开放式生成、推理链、多语言等更广泛的下游任务；且未涉及跨 tokenizer 的架构异构场景。
- **训练成本随模型池增长**：虽然 MoT 避免了 LSC 的二次方训练复杂度，但每增加一个目标模型仍需训练相应翻译器，规模化部署时的训练开销仍需考虑。
- **潜在安全影响**：更高效的自动智能体系统可能加速部署，带来监督、问责和人类判断的角色问题（作者已坦承这一更广泛影响）。
