## 摘要
KV缓存压缩对于高效的长上下文推理至关重要。现有的驱逐方法会永久丢弃未选中的令牌，从而移除它们对注意力的总体贡献。基于合并的替代方案保留了更多信息，但可能扰动本应保持精确的保留键和值。我们观察到，缓存驱逐所遗漏的信息可以表示为softmax注意力分子和分母中的残差统计量。基于这一观察，我们提出了ResKV，它将固定的KV预算划分为一个精确的主缓存和一个紧凑的残差缓存，用于重建被忽略令牌的贡献。ResKV让主缓存令牌和残差条目参与相同的softmax归一化，因此残差条目既恢复注意力分子和分母的质量，而不是作为事后修正。构建时的验证代理确定每层和每个KV头的残差分配，而解码时的动态门控调整单个查询的残差贡献。在LongBench和RULER上的全面评估，涵盖查询感知和查询无关设置、多种骨干网络、缓存预算和代表性压缩基线，表明在相同保留KV预算下取得了广泛改进，同时保持了压缩解码的实际效率，包括峰值内存使用和长上下文解码吞吐量。

## Abstract
KV cache compression is essential for efficient long-context inference. Existing eviction methods permanently discard unselected tokens and consequently remove their aggregate contribution to attention. Merging-based alternatives preserve more information but can perturb retained keys and values that should remain exact. We observe that the information omitted by cache eviction can be formulated as residual statistics in both the numerator and denominator of softmax attention. Based on this observation, we propose ResKV, which divides a fixed KV budget into an exact main cache and a compact residual cache that reconstructs the contribution of omitted tokens. ResKV lets main-cache tokens and residual entries participate in the same softmax normalization, so residual entries restore both attention numerator and denominator mass rather than acting as a post-hoc correction. A construction-time validation proxy determines residual allocation for each layer and KV head, while a decode-time dynamic gate adjusts residual contributions for individual queries. Comprehensive evaluations on LongBench and RULER, covering query-aware and query-agnostic settings, multiple backbones, cache budgets, and representative compression baselines, demonstrate broad improvements under the same retained KV budget while preserving the practical efficiency of compressed decoding, including peak memory usage and long-context decode throughput.

## 1. 核心问题与整体含义

- **背景与动机**：长上下文大语言模型（LLM）依赖KV缓存避免自回归生成时重复计算历史键值，但KV缓存随上下文长度线性增长，成为推理内存和带宽的主要瓶颈。KV缓存压缩需在"保留足够历史信息"与"有限缓存槽位"之间取得平衡。
- **现有方法的缺陷**：
  - **驱逐（Eviction）类方法**（如H2O、SnapKV等）将缓存压缩视为二元决策：保留的令牌原样保留，被驱逐的令牌连同其注意力贡献和softmax归一化质量被彻底移除。在注意力分布较为弥散时，大量低分令牌的聚合贡献不容忽视，硬驱逐会带来显著的输出偏差。
  - **合并（Merging）类方法**（如CaM、KVMerger等）虽将被驱逐状态聚合回保留条目，但会扰动本应精确的保留键/值，在需要精准检索的任务中破坏"精确记忆"。
- **核心科学问题**：如何在固定的KV缓存预算内，既保留高优先级令牌的精确表示，又重建被驱逐令牌在注意力计算中的聚合贡献？

## 2. 方法论：ResKV

### 2.1 核心思想

- **关键观察**：将softmax注意力写成分子–分母形式后，缓存驱逐所丢失的信息可精确表述为被驱逐集合上的两个未归一化softmax统计量：分母中的权重和 Z_E(q)，以及分子中的加权值求和 N_E(q)。ResKV将这些"遗漏的信息"视为可重建的残差统计量，而非彻底删除或折叠进保留令牌。
- **总体架构**：在固定总预算 b = m + r 下，将缓存划分为：
  - **主缓存（Main Cache）**：m个槽位，保存精选择的高优先级令牌，键值保持精确不变；
  - **残差缓存（Residual Cache）**：r个槽位，用紧凑的聚类摘要表示被驱逐令牌的结构化信息。

### 2.2 残差缓存构造

- 对每个残差组 C_j（由被驱逐令牌聚类而成），存储三个量：
  - 代表性键 \bar{k}_j（组内键均值）
  - 代表性值 \bar{v}_j（组内值均值）
  - 组内令牌计数 c_j
- 聚类目标是最小化组内键的平方距离，通过若干次 Lloyd 迭代求解（初始中心选取被驱逐令牌中得分最高的那些）。
- 若组内令牌对某查询的logit相似，则其聚合统计量可近似为 c_j e^{\bar{a}_j(q)} 和 c_j e^{\bar{a}_j(q)} \bar{v}_j，其中计数 c_j 恢复被省略的softmax质量。

### 2.3 共享Softmax残差解码

- ResKV的核心解码公式：
  - 主缓存logit：a_p = ⟨q, k_p⟩/√d
  - 残差条目logit：\bar{a}_j = ⟨q, \bar{k}_j⟩/√d + log c_j + log g(q)
  - 输出：\hat{o}(q) = (Σ_{p∈M} e^{a_p} v_p + Σ_{j∈R} e^{\bar{a}_j} \bar{v}_j) / (Σ_{p∈M} e^{a_p} + Σ_{j∈R} e^{\bar{a}_j})
- 残差条目与主缓存令牌参与**同一个softmax归一化**，同时恢复注意力分子和分母质量，而非作为事后输出修正。
- 硬驱逐是 r=0 的特例。

### 2.4 自适应残差控制

- **构建时验证代理（Validation Proxy）**：将观测窗口分为拟合部分（选出主缓存）和验证部分（评估重建误差）。在候选残差预算集合 {0, 0.05, 0.10, 0.15, 0.20} 中，为每层、每个KV头独立选择能最小化验证集上注意力输出重建误差的残差预算；仅当残差优于纯主缓存一定相对边际（δ=0.01）时才启用，否则回退到 r=0。
- **解码时动态门控（Dynamic Gate）**：根据主缓存注意力的最大注意力权重 p_max^M 衡量主缓存注意力的尖锐程度。主缓存注意力越集中（p_max大），残差logit被下调权重越多（避免残差稀释精确检索峰值）；主缓存注意力越弥散，残差保留更多质量以恢复遗漏的聚合贡献。门控值为 g(q) = max(g_min, sigmoid((τ − p_max^M)/T_g))。

### 2.5 理论保障

- 推导证明了硬驱逐的输出误差可分解为主/残差分子分母项的解析形式（式25），残余条目近似误差在组内logit差有界时有上界（附录A.2），验证了残差条目在组内键相似时成为精确KV令牌、组大小为1时退化为精确令牌的理论性质。

## 3. 实验设计

### 3.1 数据集与基准

- **LongBench**：16个真实长上下文理解任务，覆盖单文档QA、多文档QA、摘要、少样本学习、合成检索和代码补全。
- **RULER**：13个受控长上下文任务，覆盖检索和聚合行为（如Variable Tracking、FWE、单键/多键检索等），在4K和32K两种上下文长度下评估。

### 3.2 模型骨干

- LLaMA-3.1-8B-Instruct
- Qwen-2.5-7B-Instruct
- 两者均使用分组查询注意力（GQA），ResKV按KV头粒度构造残差条目。

### 3.3 对比方法

- **H2O**：累积注意力质量高的令牌保留方法
- **SnapKV**：基于观测窗口的令牌重要性估计
- **TOVA**：基于最近注意力评分的令牌选择
- **AdaKV**：跨注意力头的自适应预算分配
- **CaM**：合并方法（将被驱逐状态合并进保留条目）
- 另外与全缓存（Full Cache）作为上界对比。

### 3.4 设置

- 压缩率 ρ ∈ {0.6, 0.7, 0.8, 0.9}，对应保留 40%/30%/20%/10% 的KV槽位。

- 对于每组对比，ResKV使用与基线相同的评分/分配策略，将相同的总预算划分为主缓存+残差缓存。

## 6. 主要结论与发现

1. **ResKV在相同保留KV预算下全面优于基线**：LongBench上32/32配置提升（平均+1.02分），RULER上63/64配置提升（平均+3.38分）。在紧预算下收益更大：10%和20%保留KV时分别平均提升+3.47和+3.66分。
2. **查询无关设置下收益最大**：RULER查询无关场景下平均提升4.54分（vs 查询感知的2.22分），说明ResKV在实际部署场景（压缩时不知未来查询）中尤其有效。
3. **残差条目对分布式证据任务帮助显著**：任务级别增益集中在代码补全（RepoBench-P、LCC）、Passage Retrieval、TREC、Variable Tracking、FWE等需要跨上下文散布证据的任务上。
4. **效率几乎无损**：峰值内存与压缩基线基本重叠（压缩过程不会导致额外显著内存占用），解码吞吐率略低于SnapKV但远高于全缓存，且在全缓存OOM的128K上下文长度下仍能维持稳定解码。
5. **被驱逐令牌存在可聚类的键空间结构**：PCA投影显示被驱逐键具有清晰的几何结构而非随机噪声，验证了残差条目可表示性的基础。
6. **三个设计组件均贡献显著**：移除验证代理降低S1和VT各4.00和7.04分；移除动态门控降低4.80和4.48分；移除共享softmax降低RepoBench-P 3.00分。

## 7. 优点

- **理论创新性强**：将驱逐信息损失形式化为softmax分子分母的残差统计量，为KV缓存压缩提供了新的可计算视角，推导严格且易于理解。
- **设计简洁而完备**：主缓存+残差缓存结构直观，共享softmax方案既恢复了注意力分母（归一化质量）又恢复分子（值贡献），比纯输出修正方法更本质。
- **免训练、即插即用**：ResKV无需训练，可叠加在现有压缩方法之上（使用基线的评分策略），实用性强。
- **双尺度自适应**：构建时验证代理（按层/按头分配残差预算）+ 解码时动态门控（按查询调节残差权重）在不同粒度上优化残差的使用，设计精细。
- **实验覆盖面广**：多骨干、多基准、多压缩率、多基线、两种构建设置以及效率与消融分析，实验证据链完整。
- **与FlashAttention-2兼容**：通过log-sum-exp统计量合并主残差分支，保持了系统级兼容性。

## 8. 不足与局限

- **模型覆盖面有限**：仅评估了LLaMA-3.1-8B和Qwen-2.5-7B两个指令微调模型，未覆盖更大规模（如70B+）、MoE架构、非GQA模型或编码器-解码器架构。
- **基准覆盖有限**：虽使用LongBench和RULER，但未在更长上下文（如128K-1M）或其他基准（如∞Bench、BABILong）上评估任务精度。
- **无统计显著性报告**：所有结果单次运行，无方差或置信区间，无法判断增量是否在统计上显著（不过跨64个配置的一致提升缓解了该担忧）。
- **残差条目基于均值键值**：均值摘要表达力有限，对组内logit变化大（键分布不均匀）的组近似误差可能较大；文中误差界依赖于组内logit差有上界的假设。
- **解码吞吐有额外开销**：残差分支的键-查询相似度和动态门控计算带来每步额外计算，虽优于全缓存但逊于SnapKV，在高吞吐服务场景中可能成为瓶颈。
- **一次性构建、不动态更新**：残差条目在prefill后一次性构造，不随生成过程更新；对于生成长度远大于上下文的任务，可能需要轻量级残差刷新机制（文中列为未来工作）。
- **超参数较多且敏感**：候选残差预算网格、验证窗口大小（128个观测查询）、Lloyd迭代次数、δ、τ、T_g、g_min等超参数需要调优，虽然论文用了统一默认值，但跨不同模型/任务的最优值可能有变化。
- **压缩置信度不足**：未讨论压缩处理阶段的耗时、内存占用以及残差条目对显存碎片的影响；图中显示峰值内存与基线"基本重叠"但未给出精确数值。
