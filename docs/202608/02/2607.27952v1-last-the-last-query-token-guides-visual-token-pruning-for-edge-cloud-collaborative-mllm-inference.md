## 摘要
多模态基础模型正在将边缘-云视觉智能从特定任务的特征流水线重塑为基于令牌的接口，其中边缘设备将视觉输入编码为令牌，供通用云MLLM使用。然而，密集的视觉令牌序列增加了云侧推理成本。现有剪枝方法主要针对集中式推理：视觉驱动方法可在云执行前运行，但通常与查询无关，而查询引导的方法往往依赖于目标MLLM的内部状态，无法在传输前确定令牌相关性。紧凑的引导模型提供了一种替代方案，但现有设计可能需要昂贵的注意力聚合或辅助生成。我们提出LAST，一种无需训练的框架，用于边缘-云协作MLLM推理中依赖查询的视觉令牌剪枝。LAST使用紧凑的边缘侧VLM作为引导代理，并从最后查询令牌对视觉令牌的注意力中导出轻量级重要性信号。在因果注意力下，最后查询令牌可以关注完整的视觉序列和整个查询上下文，从而在无需访问云模型、自回归生成或对多个查询位置进行昂贵聚合的情况下实现查询感知剪枝。随后，LAST在固定令牌预算下保留一组多样化的查询相关视觉令牌。我们在11个多模态基准上，针对不同引导策略的剪枝方法，在多种令牌预算下评估了LAST。实验表明，LAST持续达到最强性能，在仅保留12.5%视觉令牌的同时保持了全令牌准确率的95.4%，并且具有低边缘侧选择开销和减少的云侧计算。

## Abstract
Multimodal foundation models are reshaping edge-cloud visual intelligence from task-specific feature pipelines into token-based interfaces, where edge devices encode visual inputs into tokens for a general-purpose cloud MLLM. However, dense visual-token sequences increase cloud-side inference costs. Existing pruning methods mainly target centralized inference: vision-driven methods can operate before cloud execution but are typically query-agnostic, whereas query-guided methods often rely on internal states of the target MLLM and cannot determine token relevance before transmission. Compact guidance models offer an alternative, but existing designs may require costly attention aggregation or auxiliary generation. We propose LAST, a training-free framework for query-dependent visual token pruning in edge-cloud collaborative MLLM inference. LAST uses a compact edge-side VLM as a guidance proxy and derives a lightweight importance signal from the last query token's attention to visual tokens. Under causal attention, the last query token can attend to the full visual sequence and the entire query context, enabling query-aware pruning without cloud-model access, autoregressive generation, or costly aggregation over multiple query positions. LAST then retains a diverse set of query-relevant visual tokens under a fixed token budget. We evaluate LAST on 11 multimodal benchmarks under multiple token budgets against pruning methods with different guidance strategies. Experiments show that LAST consistently achieves the strongest performance, preserving 95.4% of the full-token accuracy while retaining only 12.5% of the visual tokens, with low edge-side selection overhead and reduced cloud-side computation.

## 1. 核心问题与研究动机

- **背景演进**：多模态基础模型将边缘-云视觉智能从"任务特定的特征流水线"重塑为"基于令牌（token）的统一接口"——边缘设备将视觉输入编码为视觉令牌，传输给云端通用多模态大语言模型（MLLM）进行推理。
- **核心矛盾**：视觉编码器通常保留稠密的补丁级表示，产生大量视觉令牌。这些令牌中很多是视觉冗余的，或与当前查询（query）弱相关，导致：
  - 多模态上下文过长；
  - 云侧计算显著增加；
  - 传输开销增大。
- **关键问题**：在边缘-云协作设定下，视觉令牌剪枝必须在**云模型看到完整序列之前**、在**边缘侧**完成选择，这与传统集中式推理中的剪枝有本质区别：
  - **视觉驱动方法**（如 VisionZip、VisPruner）：可在云执行前运行，但查询无关，可能丢弃视觉上不显眼但对回答至关重要区域。
  - **查询引导方法**（如 FastV、SparseVLM）：依赖目标 MLLM 的内部状态，无法在传输前得到相关性信号。
  - **紧凑引导模型**（如 SGP、IF-Prune）：提供了一种可能路径，但往往需要昂贵的注意力聚合、自回归生成或重复视觉编码，增加了边缘侧开销。
- **研究问题**：能否在边缘侧使用一个轻量信号，同时捕获完整的图像-查询上下文，从而实现查询感知的视觉相关性估计？

## 2. 方法论：LAST

### 2.1 核心思想

- **基本设定**：边缘部署一个紧凑的引导模型 \(M_e\)（小规模VLM），云端部署一个更强的目标模型 \(M_c\)，二者共享同一视觉编码器 \(E\) 的参数与视觉令牌布局，但使用各自的连接器（connector）\(\phi_e\) 和 \(\phi_c\)。这保证边缘选出的令牌可被云模型直接消费，无需特征对齐或重新编码。
- **关键观察**：在**因果注意力**掩码下，序列中**最后一个查询令牌**可以关注：
  - 完整的视觉前缀（全部视觉令牌）；
  - 整个先前的查询文本上下文。
  
  因此，该位置对视觉令牌的注意力分布，天然是一个"查询条件化的"相关性信号——涵盖了完整的图像-查询上下文，却只需读取一个查询位置的注意力行。

### 2.2 技术流程

1. **视觉编码**：图像 \(I\) 由共享视觉编码器 \(E\) 产生 \(N\) 个视觉令牌 \(X = [x_1, \dots, x_N]\)。
2. **边缘侧预填充**：边缘模型将视觉令牌投影到其嵌入空间（\(H_e = \phi_e(X)\)），按标准模板组装多模态输入 \(Z_e = P_e(H_e, Q)\)，做**一次无解码（decoding-free）的预填充前向传播**。
3. **注意力打分**：在最后一层/所有层和所有注意力头上，取出最后一个查询位置 \(p^\star\) 对每个视觉令牌位置的注意力权重，求和得到原始分数：
   \[
   s_i = \sum_{\ell=1}^{L} \sum_{h=1}^{H} A^{(\ell,h)}[p^\star, p_i], \quad i \in [N]
   \]
   再归一化为相关性分布 \(\tilde{w} \in \mathbb{R}^N_{\ge 0}\)。
4. **令牌选择**：采用**重要性加权贪心 k-center 选择**，在固定预算 \(K = \lceil \rho N \rceil\) 下平衡查询相关性与视觉多样性：
   - 初始化：选相关性最大的令牌作为首个选中点；
   - 迭代：每次选择使"查询相关性 × 到已选集的最小距离"最大的未选令牌：
     \[
     j_t = \arg\max_{i \notin S_{t-1}} \tilde{w}_i \cdot \delta_i^{(t-1)},\quad \delta_i^{(t-1)} = \min_{j \in S_{t-1}} (1 - \bar{x}_i^\top \bar{x}_j)
     \]
   - 该目标函数抑制两类令牌：与查询无关的、与已选特征冗余的。
5. **传输与云侧推理**：选中令牌恢复原始顺序后仅传输 \(X_S\)，云模型直接用其原生连接器 \(\phi_c(X_S)\) 生成最终回答。
6. **复杂度与开销**：
   - 注意力聚合只需 \(O(LHN)\) 次操作（对比所有查询位置聚合需要 \(O(LHMN)\)）；
   - 选择过程通过增量更新 \(\delta\)，为 \(O(KNd_v)\)，无需构造 \(N\times N\) 距离矩阵；
   - 整个过程**无需训练**，所有参数冻结。

## 6. 主要结论与发现

1. **性能**：LAST 在所有 3 个保留预算下均取得最佳平均准确率。保留 62.5%、37.5%、12.5% 时分别保留全量令牌性能的 **99.3%、99.0%、95.4%**，且与最优竞争对手的差距随预算缩减而扩大（相对性能提升 1.1 / 1.5 / 2.4 个百分点）。
2. **查询相关的必要性**：在 12.5% 保留下，最优查询无关方法平均分仅 57.8，而查询相关方法（SGP / LAST）达到 69.9 / 71.4，说明查询条件化信号对极端剪枝至关重要。
3. **局部化信息场景优势**：LAST 在需要定位密集视觉输入中局部信息的任务上优势明显（如 ChartQA 上超出 SGP 8.6 分、DocVQA 2.8 分、MM-Vet 2.6 分）。
4. **效率**：LAST 的注意力聚合仅需 2.51 ms（比 FastV 低 36.8%，远低于 SparseVLM）；在 12.5% 保留下同时取得最高准确率和最低边缘延迟。
5. **泛化性**：在 LLaVA-1.5-7B/13B 上同样表现最佳，保留 32/576 令牌时可保持 90.2% 相对性能。
6. **消融结论**：
   - "最后查询令牌"作为注意力来源优于 First/Middle，与 All Mean（甚至 All Mean + Answer）接近且开销更小；
   - 重要性加权 k-center 选择明显优于直接 Top-k（ChartQA 提升 4.7 分，MME 提升 39 分），证明"相关性 + 多样性"联合建模的价值。

## 7. 优点

- **方法设计层面**：
  - **训练无关**：全流程无需训练或微调，所有模型参数冻结，部署成本低；
  - **轻量高效**：只需一次无解码预填充，无需自回归生成、无需所有查询位置聚合、无需重复视觉编码；注意力聚合仅 \(O(LHN)\)；
  - **查询感知 + 多样性兼顾**：利用最后一个查询令牌的因果注意力特性获得精简查询条件化信号，再通过加权 k-center 平衡相关性与覆盖率；
  - **即插即用**：通过共享视觉编码器 + 独立连接器的设计，使边缘选择的令牌可被云端直接消费，无需对齐或重编码；
  - **无需云端内部状态**：选择过程在传输前完成，不依赖目标云 MLLM 的内部注意力，适合真实边缘-云协议。
- **实验层面**：
  - 覆盖 11 个基准、3 个预算、多个方法类别，评估维度全面；
  - 展示了效率数据（延迟、FLOPs）而不只报告准确率；
  - 提供了跨模型泛化验证和定性可视化，支撑结论的稳健性；
  - 消融实验清晰隔离了"注意力来源"和"选择策略"两个关键设计决策的贡献。
