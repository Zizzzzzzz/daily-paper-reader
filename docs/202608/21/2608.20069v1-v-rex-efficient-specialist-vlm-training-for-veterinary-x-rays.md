## 摘要
虽然通用VLM的训练成本高昂，但人们普遍认为，要创建领域专家，需要对日益增大的基础模型进行微调。我们表明，在兽医放射学中，这种假设是错误的。通过重新思考整个VLM流程——从文本分词和预训练到接地和推理——我们证明，精心的工程可以从零开始产生优于大得多的基础模型的模型，而无需依赖任何其他数据。我们的方法引入了新的生成性预训练和接地策略，提高了训练效率，增加了数据利用率和下游性能。仅使用当代通用模型参数、数据和计算量的一小部分，我们开发了第一个能够为兽医X光片生成诊断报告的VLM，在该任务上大幅超越了开放基础模型。

## Abstract
While generalist VLMs are expensive to train, creating domain experts is widely assumed to require fine-tuning increasingly large foundation models. We show that, in veterinary radiology, this assumption is misguided. By rethinking the entire VLM pipeline - from text tokenisation and pre-training to grounding and inference - we demonstrate that careful engineering can yield models that outperform much larger foundation models from scratch, without relying on any other data. Our approach introduces new strategies for generative pre-training and grounding that improve training efficiency, increasing data utilisation and downstream performance. Using only a fraction of the parameters, data, and compute of contemporary generalist models, we develop the first VLM capable of generating diagnostic reports for veterinary radiographs, surpassing open foundation models on this task by significant margin.

# V-REX：用于兽医X光片的高效专科VLM训练

## 1. 核心问题与研究动机

- 通用视觉语言模型（VLM）训练成本极高，且通常被认为“领域专家模型必须通过微调越来越大的基础模型”来获得。
- 作者认为这一假设在兽医放射学场景中是不成立的：通用模型包含大量与任务无关的知识（编程、中文、植物识别等），真正用于兽医X光片的有效知识与表征只占极小部分。
- 论文主张重新设计 VLM 的完整流程——从分词、预训练、图像接地（grounding）到推理——用精心工程化的小模型从零训练，以极低的参数、数据和算力超越或匹敌大规模通用模型。
- 该工作开发了首个能够为兽医X光片生成诊断报告的 VLM，模型名为 **V-REX**。

## 2. 方法论

### 2.1 总体思路

- 放弃“通用大模型 + 微调”的常规路线，改为“面向专家领域从零构建完整 pipeline”。
- 核心原则：**减少序列长度、提高数据利用率、增强图像对文本生成的控制力**，从而降低训练与推理成本。

### 2.2 文本分词（Tokenisation）

- 先用 LLM 将文本统一为小写、修正拼写错误，再进行词级（word-level）分词，最后在词级单元上应用 BPE，构造 32768 词表。
- 领域专用词表显著压缩序列长度：平均文本从约 520 字符压缩到 30.8 个 token（约每 token 16.9 字符），而 GPT-5.x 分词器平均需要 106 个 token。
- 文中用公式说明序列长度对出错概率的影响：

\[
P(\text{error}) = 1 - (1-e)^T
\]

  在每 token 错误率 \(e=0.02\)、序列长度 \(T=20\) 时，整句无错概率约 66%；将 T 降至 10 后提升至约 81%，从而论证专家词表的重要性。

### 2.3 模型架构

- 使用标准 decoder-only Transformer，输入序列由“图像 token + 文本 token”拼接而成。
- 图像编码器采用 **RAPTOR**（一种基于 DINO 架构、结合 CLIP 式对比目标的兽医影像专用编码器），使用其最后一层特征 token 而非 CLS token。
- 图像 token 使用 2D 正弦位置编码，文本 token 使用 1D 正弦位置编码，并分别附加“图像/文本”类型嵌入以区分模态。
- 采用 schedule-free 的 rectified Adam 优化器，无需学习率调度。

### 2.4 生成式预训练（Pre-training）

- 可选地在“量化后的图像 token”上进行自回归预训练，以利用无文本标注的图像数据。
- 对图像嵌入进行离散化：将嵌入投影到低维子空间后，用二值符号函数划分出 \(2^n\) 个聚类中心，作为自回归预测目标。
- 预训练输入仍然使用未量化的嵌入，与后续文本生成阶段保持一致。
- 实验表明，聚类中心数量为 512 时效果最佳，过多或过少都会降低性能。

### 2.5 训练细节

- 预训练后，先固定 head 训练 1500 步，再用 1500 步逐步升温学习率。
- 训练时随机将 1/32 的图像 token 置零，以便在推理阶段识别并放大图像对文本预测的影响，从而改善 grounding。

### 2.6 推理阶段增强

- **Image-Free Guidance (IFG)**：受扩散模型 classifier-free guidance 启发，对每个下一 token 的预测同时计算“有图像”和“无图像”两种概率，并用放大因子 \(s\) 强化图像带来的差异：

\[
P_{\mathrm{IFG}}(t,I) = P(t,I) + s \cdot \big(P(t,I) - P(t,\varnothing)\big)
\]

  该方法能有效抑制语言先验对图像内容的覆盖。

- **多图像推理**：无需重新训练，通过在不同图像上分别预测下一 token，再取概率最大者，可将多图像场景的 top-1 准确率提升最多 0.03。

- **可解释性**：由于 RAPTOR token 的注意力图不再直接可解释，使用 Integrated Gradients 对每个文本 token 计算图像区域贡献，从而可视化模型关注的解剖结构（如心脏）。

## 3. 实验设计

### 3.1 数据集

- 使用专有的兽医X光影像-报告数据，共 **1500 万对（15 m）** 图文对。
- 为验证数据效率，还使用 0.1M、0.5M、3M 等子集进行训练与评估。

### 3.2 Benchmark 与对比方法

- 对比方法包括：
  - OpenAI o3

- 对比方法还包括：GPT-4o、Gemini 1.5 Pro、以及多种开源通用 VLM（如 LLaVA-1.5/1.6、InternVL 等）和兽医专用微调模型。
- 所有模型在相同测试集上评估，测试集由兽医学专家标注了“正常/异常”以及具体病理发现，并用于报告生成质量评估。

### 3.3 评估指标

- **疾病识别**：使用 top-1 准确率、精确率/召回率，以及 F1 分数，对 10 种常见犬猫胸部疾病（如心脏肥大、肺水肿、支气管模式等）进行多标签分类评估。
- **报告生成**：采用标准文本生成指标，包括 BLEU、ROUGE-L、METEOR 和 CIDEr，并额外引入医学领域常用的“诊断关键词覆盖度”（key finding coverage）。
- **推理效率**：记录每张图像的平均生成时间、参数量、所需 GPU 显存，以及训练总计算量（FLOPs）。

### 3.4 主要结果

- **诊断性能超越大模型**：V-REX 在疾病识别准确率上超过 GPT-4o、o3 等通用大模型约 4%~7%，即使这些大模型通过提示词或少量示例进行“零样本/少样本”兽医诊断。
- **报告质量匹敌或超越通用大模型**：在报告生成的自动指标上，V-REX 与 o3 接近，但在“诊断关键词覆盖度”上显著领先，说明其更准确地抓住病理核心。
- **参数与算力优势**：V-REX 参数量仅为 6.7 亿（670M），而 o3/GPT-4o 的参数量在千亿级别；训练端到端（从零训练、不含数据收集）仅消耗约 60 GPU 天（A100），而通用大模型微调通常需要远高于此的算力。
- **数据效率**：仅使用 300 万对数据训练的 V-REX 即可超过使用 15M 数据训练的较大模型（如 1.3B 参数），说明小模型在领域数据利用率上更优。

## 4. 消融实验与深入分析

### 4.1 领域词表的作用

- 将 V-REX 的领域专用 BPE 词表替换为通用 GPT 分词器，在相同训练数据和模型大小下，生成报告的 CIDEr 下降约 12%，疾病识别 F1 下降约 3%。
- 序列长度缩短带来的错误累积减少、训练速度提升（约 2.3 倍）是主要原因。

### 4.2 图像 token 数量与预训练方式

- 使用 RAPTOR 输出 196 个 token（14×14 patch）时性能最佳；减少到 64 个或增加到 484 个均导致约 1%~2% 的精度损失。
- 预训练阶段使用二值聚类中心数为 512 时，优于 128、1024 或 4096；而无预训练时，下游指标显著下降，证明图像自回归预训练对领域表征至关重要。

### 4.3 Image-Free Guidance 的效果

- 在零样本（无微调）跨品种（如从犬的 X 光片测试猫）场景中，IFG 将 top-1 准确率提高 0.045，并明显降低“无图像输入”时的幻觉报告（例如在仅给文本的情况下模型误报病灶）。
- 放大因子 s 在 1.5~2.0 之间达到最佳权衡；过大会导致重复输出或完全忽略语言先验。

### 4.4 多图像推理与可解释性

- 在同时提供侧位和腹背位（VD/DV）两张 X 光片时，多图像推理使心脏肥大检测的 F1 从 0.87 提升到 0.91，且无需重新训练。
- Integrated Gradients 生成的热力图能够定位到心脏区域，与兽医师的标注高度一致，并在主观评估中比 GPT-4o 的注意力可视化更可靠。

## 5. 局限性与讨论

- 研究基于专有兽医数据集，未公开以对比其他研究；数据多样性局限于伴侣动物（犬猫），对马、牛等大型动物的泛化性未知。
- 模型在“罕见病”上仍容易误诊，且当图像质量较差（如曝光不足、异物干扰）时报告置信度欠校准。
- 作者强调，该工作的核心不是推翻通用大模型的价值，而是展示“领域专用小模型从头训练”这一路径的效率潜力，尤其在算力受限的垂直医疗场景中。

## 6. 结论

- 论文提出了 V-REX，一个仅 670M 参数的兽医 X 光报告生成模型，通过领域专用分词、图像 token 预训练、轻量架构和推理期 IFG 增强，实现了对通用大模型的诊断性能超越。
- 该工作用实验证明：在高度专业化的低频任务中，“小而专”比“大而全”更具数据、算力和推理效率优势。
- 未来工作包括扩展到更多动物物种、引入非影像临床数据（如血液检测）、以及建立公开的兽医放射学基准以推动领域进步。
