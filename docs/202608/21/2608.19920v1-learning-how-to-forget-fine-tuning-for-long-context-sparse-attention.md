## 摘要
许多先前的工作通过稀疏注意力解决了键值（KV）缓存选择与压缩问题，以便在没有过多硬件预算的情况下实现Transformer语言模型的长上下文推理。我们提出了一种对稀疏注意力模型进行微调的新方法。该方法适用于任意KV缓存策略，在适中的硬件预算（例如，单个具有40 GB内存的Nvidia A100 GPU）下运行，并允许模型与策略协同适应，其性能通常优于使用精确注意力（序列并行）训练的模型。我们还提供了H2O稀疏注意力（我们实验中的领先策略）的高效实现，并配有专用的缩放点积注意力内核支持。KeysAndValues（https://github.com/awslabs/keys_values）是一个用于长上下文推理和微调的新型开源库，为本文讨论的所有方法提供了易于使用且高性能的代码。

## Abstract
A lot of prior work addressed key-value (KV) cache selection and compression by sparse attention to enable long-context inference for transformer language models without excessive hardware budgets. We provide a new method for fine-tuning models with sparse attention. It works for any KV cache policy, runs on a moderate hardware budget (e.g., a single Nvidia A100 GPU with 40 GB RAM), and allows the model to co-adapt with the policy, often outperforming models trained with exact attention (sequence parallelism). We also provide an efficient implementation of H2O sparse attention (the leading policy in our experiments) with dedicated scaled dot product attention kernel support. KeysAndValues (https://github.com/awslabs/keys_values), a new open source library for long-context inference and fine-tuning, provides easy-to-use and performant code for all methods discussed here.

## 1. 论文的核心问题与整体含义

- **背景**：现代大语言模型需要处理极长上下文（如工具调用、链式推理、多轮对话），但标准 Transformer 的注意力机制在计算和内存上随上下文长度快速增长，尤其是 KV 缓存的存储开销成为瓶颈。
- **核心问题**：现有稀疏注意力方法能在推理时通过固定大小的 KV 缓存和逐出策略降低内存，但这些策略通常在训练/微调阶段不可见，导致模型与推理阶段的缓存策略不匹配。与此同时，主流长上下文微调依赖序列并行或上下文并行，需要大量 GPU，且无法让模型针对具体的 KV 缓存策略进行协同优化。
- **整体含义**：论文提出一种新的微调方法，使模型在训练时就直接采用与推理时相同的稀疏注意力策略，实现“模型与缓存策略共同适应”。该方法硬件要求低（单张 A100 40GB 即可），适用于任意 KV 缓存策略，并在多个长上下文基准上通常优于用精确注意力（序列并行）训练的模型。

## 2. 论文提出的方法论

- **总体框架**：在微调过程中，模型按推理时的稀疏注意力方式运行，即使用固定大小的 KV 缓存，并按指定策略进行逐出（eviction），从而在训练阶段就模拟推理时的信息丢失模式。
- **核心技术思路**：
  - **避免对缓存策略求导**：前向过程中记录所有缓存逐出决策（replay log），反向传播时重放这些决策，而不是对策略本身微分，从而支持任意策略。
  - **嵌套激活检查点**：将序列分为 chunk，再组合为 cell；外层按层（layer）循环，内层按 cell 循环，配合 CPU offloading，使 GPU 内存需求与上下文长度基本无关。
  - **线性 KV 缓存递推与 delta 编码**：相邻 chunk 的 KV 缓存仅相差少量被覆盖的位置，可利用 `scatter/gather` 表达递推关系，并用 delta（被覆盖前的旧 KV 向量）代替完整缓存存入计算图，大幅减少反向传播中的驻留内存。
  - **autograd saved tensors hooks**：通过 pack/unpack hooks 将 delta 编码集成到 PyTorch 自动求导中，使实现与具体缓存策略无关。
- **对 H2O 的改进**：
  - 提出归一化 H2O 分数，避免长驻缓存条目因累积得分占优；
  - 支持按 batch 位置独立决策，而非原文中所有 batch 共用同一决策；
  - 提供 Triton 代码，在 FlashInfer SDPA 内核旁返回求和注意力权重，解决 H2O 实现速度慢的问题。

- 当前稀疏注意力未被主流推理库广泛采用，主要原因是 SDPA 内核缺乏对求和注意力权重、隐式因果掩码等支持；论文给出相应的内核扩展建议。
