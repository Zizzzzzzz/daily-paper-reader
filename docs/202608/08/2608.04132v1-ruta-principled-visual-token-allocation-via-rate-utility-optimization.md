## 摘要
高分辨率图像和长视频为视觉-语言模型提供了丰富的多模态推理和细粒度感知上下文，但由此产生的长视觉令牌序列使得大语言模型侧的计算和内存成本高昂。现有的视觉令牌缩减器通常以规定速率运行，而近期方法则通过特定于方法的学习阈值或重要性预测器来适应不同输入的令牌数量。我们提出了RUTA，一种原则性的率-效用令牌分配方法，通过联合学习保留哪些令牌以及为每个图像-查询对分配多少令牌，在进入大语言模型之前进行缩减。RUTA构建了查询条件化的候选令牌，并预测每个候选令牌的保留概率。在训练期间，这些概率参数化独立的伯努利门控，而它们的总和为每个图像-查询对提供可微的训练时令牌数量估计。保留的令牌作为锚点，根据语义亲和性和空间邻近性从非保留令牌中聚合信息。RUTA通过惩罚性的率-效用目标进行优化，该目标平衡下游任务损失与预期令牌使用量。在五个基准测试中取平均值，并相对于每个骨干网络的全令牌基线进行测量，RUTA在LLaVA-NeXT-7B和Qwen3-VL-8B上分别仅使用2.0%和4.2%的视觉令牌，同时保持了88.2%和94.4%的任务性能。

## Abstract
High-resolution images and long videos provide vision-language models with rich context for multimodal reasoning and fine-grained perception, but the resulting long visual token sequences make large language model-side computation and memory costly. Existing visual token reducers often operate at prescribed rates, while recent methods adapt token counts across inputs using method-specific learned thresholds or importance predictors. We introduce RUTA, a principled Rate-Utility Token Allocation method that performs pre-LLM reduction by jointly learning which tokens to retain and how many to allocate to each image-query pair. RUTA constructs query-conditioned candidate tokens and predicts a retention probability for each candidate. During training, these probabilities parameterize independent Bernoulli gates, while their sum provides a differentiable training-time estimate of the token count for each pair. Retained tokens serve as anchors that aggregate information from non-retained tokens according to semantic affinity and spatial proximity. RUTA is optimized with a penalized rate-utility objective that balances downstream task loss against expected token usage. Averaged across five benchmarks and measured relative to each backbone's full-token baseline, RUTA uses only $2.0\%$ and $4.2\%$ of visual tokens while preserving $88.2\%$ and $94.4\%$ of task performance on LLaVA-NeXT-7B and Qwen3-VL-8B, respectively.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：高分辨率图像和长视频为视觉-语言模型（VLM）提供了丰富的上下文信息，显著提升了多模态推理和细粒度感知能力。然而，这些输入导致视觉令牌序列急剧增长，使得大语言模型（LLM）侧的计算和内存开销成为规模化多模态推理的核心瓶颈。
- **核心问题**：视觉证据在图像/视频中分布不均匀——回答某个查询可能只需一小块区域，而大量区域冗余或无关。因此，"保留哪些令牌"和"为每个图像-查询对分配多少令牌"是两个关键决策。
- **现有方法的不足**：
  - 多数缩减器依赖**外部指定的固定预算**（如固定保留比例或层间计划），无法适应不同查询的证据需求——简单查询被过度分配，复杂查询则证据不足。
  - 近期自适应方法虽能动态调整令牌数，但速率控制机制依赖**特定方法的目标和约束**，缺乏统一的原则性框架。
- **本文贡献**：受率失真理论启发，首次将视觉令牌缩减形式化为**率-效用优化（Rate-Utility Optimization）**问题，通过共享惩罚项联合学习保留内容与分配数量，在预-LLM阶段实现查询自适应的令牌分配。

## 2. 论文提出的方法论

### 2.1 核心思想
RUTA 将视觉令牌缩减分解为两个组件：
- **查询条件化候选构造器 $g_\phi$**：将编码器分辨率集中在查询相关区域。
- **率控压缩器 $h_\varphi$**：预测每个候选令牌的保留概率，据此选择锚点并将非锚点信息聚合进锚点。

整体目标为率-效用最优化：
$$\min_\theta \; \mathbb{E}\left[\ell_{\text{task}}\left(\text{LLM}(q, f_\theta(x,q)), y\right) + \lambda_{\text{rate}} \hat{R}_\theta(x,q)\right]$$

其中 $\lambda_{\text{rate}}$ 控制率-效用权衡点。

### 2.2 查询条件化候选令牌构造
- **短语解析**：从查询中提取名词短语和属性（如"oven below the stove burner"），去除问句模板等非视觉词。
- **定位器**：使用 Grounding DINO（仅更新其 grounding 头）对每个短语预测边界框和置信度，以置信度阈值 $\delta=0.5$ 筛选后取所有框的**最小外接矩形**作为感兴趣区域（RoI）。
- **编码**：将 RoI 裁剪并缩放至基础输入分辨率，通过视觉编码器生成候选令牌序列 $Z$（$N_c$ 个，数量与原始 $N$ 相当）。候选构造本身不减少令牌数，而是将分辨率重新分配到查询相关内容上。

### 2.3 率控压缩
- **保留概率预测**：两层查询条件化 MLP 为每个候选令牌预测保留概率 $\rho_i = \text{sigmoid}(s_\varphi(z_i, q)/\tau)$，其中 $\tau=0.7$ 为温度。
- **伯努利门控与率估计**：训练时独立采样 $\xi_i \sim \text{Bernoulli}(\rho_i)$，期望保留数为各概率之和 $\hat{R}_\varphi = \sum_i \rho_i$——即可微的训练时令牌率估计，无需预设预算。
- **直通估计器（STE）**：$\tilde{\xi}_i = \rho_i + \text{sg}(\xi_i - \rho_i)$，前向用离散采样，反向梯度可传播。
- **推理时选择**：默认使用自适应 top-K，$K = \text{clip}(\text{round}(\hat{R}_\varphi), 1, N_c)$，取概率最高的 $K$ 个候选为锚点。
- **锚点聚合**：非锚点不直接丢弃，而是根据**语义亲和性 + 空间邻近性**加权合并到锚点中：
  - 语义亲和：查询/键投影后的点积相似度，尺度 $\sigma_{sa}=0.07$。
  - 空间邻近：基于归一化空间位置的 RBF 核，带宽 $\sigma_{sp}^2=0.04$，权重 $\lambda_{sp}=1.0$。
  - 每个非锚点归一化权重后，用值投影将信息残差更新至锚点：$\tilde{z}_i = \tilde{\xi}_i \cdot \text{LN}(z_i + \beta \Delta z_i)$，$\beta=4.0$。

### 2.4 联合优化
- 训练目标为小批量平均的任务损失 + $\lambda_{rate}$ 加权的期望令牌数惩罚。
- 相比固定每样本预算，该目标允许不同输入在相同全局率压力下获得不同令牌数。

## 6. 论文的主要结论与发现

1. **原则性框架有效**：将视觉令牌缩减形式化为率-效用优化，以可微期望令牌数作为率估计，允许不同样本获得不同令牌数，是可行且有效的。
2. **显著效率优势**：在匹配的低令牌率下，RUTA 在五个基准上平均准确率均居首位——仅用 2.0%（LLaVA-NeXT）和 4.2%（Qwen3-VL）的视觉令牌，分别保持 88.2% 和 94.4% 的任务性能。
3. **查询条件化定位是关键**：定位器选择实验显示，无论使用何种定位器（DINO/OWLv2/Qwen2-VL），均优于随机区域和全图基线，说明收益源于"查询条件化定位"本身。
4. **自适应率分配优于固定预算**：固定率 vs 自适应率的对比表明，率变化本身不够，必须将容量分配给真正有需求的样本。
5. **语义+空间合并优于单一策略**：语义路由贡献最大，空间邻近提供互补结构，两者结合最佳。
6. **优势集中在低-中率区间**：令牌预算放大后优势收窄，说明查询条件化候选构造在容量稀缺时最有价值——这恰好是实际部署最关心的场景。

## 7. 优点

- **理论框架清晰**：从率失真理论出发，为"率-效用"权衡提供了统一且可微的目标函数，摆脱了固定预算和特定方法约束。
- **端到端可微训练**：伯努利门控 + STE + 期望率估计使离散选择与连续优化无缝衔接，无需强化学习。
- **方法设计完整**：将"定位哪里"（候选构造）、"选哪些"（锚点选择）、"选多少"（率分配）、"如何压缩信息"（锚点聚合）四要素统一在一个可训练框架内。
- **聚合机制保留了非锚点信息**：相比直接剪枝，基于语义+空间的注意力式合并减少了信息丢失。
- **推理时无额外开销**：推理仅需一次自适应 top-K 选择，不引入随机性，部署友好。
- **实验全面**：主实验 + 率-效用曲线 + 多组消融 + 可视化，证据链较完整；且覆盖两个不同架构的骨干，增强了泛化可信度。
- **诚实披露局限**：作者明确讨论了三方面局限性，且消融中出现"未严格率匹配"时如实说明。

## 8. 不足与局限

### 实验覆盖方面
- **基准范围有限**：仅覆盖单图像 VQA 类任务，未涉及视频理解、多图像场景、图文检索等更广泛的 VLM 应用。
- **骨干覆盖有限**：仅测试 LLaVA-NeXT-7B 和 Qwen3-VL-8B，未覆盖更大模型（如 34B/72B）或其他架构家族。
- **消融范围有限**：关键消融仅在单一数据集和单一骨干上进行，跨数据集/骨干的稳定性未验证。

### 偏差风险
- **定位器依赖**：Grounding DINO 的定位质量直接影响上限，若相关目标未被识别（小物体、抽象概念），性能可能显著下降。
- **训练数据未详述**：各数据集上的微调划分、数据量、类别分布等信息不完整。
- **单包围盒策略**：多个分离区域合并为一个外接框时，可能覆盖过多无关区域，稀释分辨率收益。作者承认"当区域间隔很远时，裁剪可能覆盖大部分图像"。

### 应用限制
- **需要重新训练**：RUTA 针对特定 VLM 和任务数据集优化，迁移到新骨干/新域需要额外训练，不像训练无关方法那样即插即用。
- **率只是粗略代理**：令牌数不反映局部化与编码开销、KV-cache 内存、硬件吞吐等指标，实际加速可能与令牌减少不成正比。
- **可扩展性存疑**：$\lambda_{rate}$ 的合适值因骨干而异（文中为 LLaVA 用 0.02、Qwen 用 $2\times10^{-5}$），调参成本可能较高。
