## 摘要
近期三维视觉语言模型（3D VLMs）通过将2D视觉特征投影到世界坐标来构建几何感知令牌，从而实现对3D问答等任务的空间推理。然而，这种设计为每个场景生成数千个令牌，导致巨大的计算和内存开销。尽管令牌压缩在2D VLMs中已被广泛研究，现有方法依赖语义相关性或基于注意力的选择，忽视了3D令牌的结构化空间特性。此外，仅靠空间邻近性无法解决3D表示中的冗余，因为在空间聚合后对象级令牌不平衡仍然存在。为解决这一问题，我们提出3DZip，一种三阶段令牌压缩框架：首先应用粗体素化去除点级冗余，然后通过行列式点过程基于特征空间多样性选择锚定令牌，最后在空间约束下合并剩余令牌以保持几何连贯性。在三个3D问答基准上的实验表明，3DZip始终优于现有压缩方法，仅使用128个令牌即可保留原始性能的94.7%，同时实现1.92倍的推理加速。

## Abstract
Recent 3D vision-language models (3D VLMs) construct geometry aware tokens by projecting 2D visual features into world coordinates, enabling spatial reasoning for tasks such as 3D question answering. However, this design generates thousands of tokens per scene, resulting in substantial computational and memory overhead. While token compression has been extensively studied in 2D VLMs, existing approaches rely on semantic relevance or attention-based selection that overlook the structured spatial nature of 3D tokens. Moreover, redundancy in 3D representations cannot be resolved by spatial proximity alone, as object-level token imbalance persists even after spatial aggregation. To address this, we propose 3DZip, a three-stage token compression framework that first applies coarse voxelization to remove point-level redundancy, then selects anchor tokens based on feature-space diversity via a Determinantal Point Process, and finally merges remaining tokens under spatial constraints to preserve geometric coherence. Experiments on three 3D question answering benchmarks demonstrate that 3DZip consistently outperforms existing compression methods, retaining 94.7% of the original performance with only 128 tokens, achieving a $1.92\times$ faster inference speed.

## 2. 论文提出的方法论

### 2.1 核心思想

将3D表示中的冗余分解为三个互补层面，并制定对应策略：
- **点级冗余**：同一物理表面被多视角重复观测 → 粗体素化去除
- **对象级冗余**：同一物体的多个表面区域对应多个令牌 → 特征多样性锚点选择
- **几何一致性**：压缩后需保持3D结构关系 → 空间约束令牌合并

### 2.2 三阶段框架（Algorithm 1）

**Stage 1：粗体素化（Coarse Voxelization）**
- 将3D空间划分为尺寸为 δ 的轴对齐体素，统计占据体素。
- 对每个体素内的令牌特征和坐标做平均池化：
  - \( f_k = \frac{1}{|G_k|} \sum_{v_i \in G_k} f_i \)
  - \( p_k = \frac{1}{|G_k|} \sum_{v_i \in G_k} p_i \)
- 得到显著缩减的令牌集 \( V_{vox} \)。

**Stage 2：特征多样性引导的锚点选择（Feature-Diversity Guided Anchor Selection）**
- 对体素令牌特征进行 L2 归一化：\( \hat{f}_k = f_k / \|f_k\|_2 \)
- 构建余弦相似度核：\( L_{kl} = \hat{f}_k^\top \hat{f}_l \)
- 使用行列式点过程（Determinantal Point Process, DPP）选择 K 个锚点，最大化 \( \det(L_A) \)，从而鼓励特征空间多样性。
- 采用基于 Cholesky 分解的快速贪心近似算法（标准方法），每次选择残差分数最大的令牌并更新。

**Stage 3：空间约束的令牌合并（Spatially-Constrained Token Merging）**
- 对每个非锚点令牌，在特征空间找到最近的锚点：\( a^*(j) = \arg\min_{a \in A} (1 - \hat{f}_j^\top \hat{f}_a) \)
- 引入网格距离约束：将坐标量化为网格索引，计算网格空间距离 \( d_g(j,a) \)，仅当 \( d_g(j,a) \leq \tau_g \) 时才允许合并。
- 超过空间阈值的令牌被丢弃（视为空间孤立、无补充上下文价值的观测）。
- 锚点特征更新为自身与分配令牌的均值，锚点位置保持不变。
- 最终得到压缩令牌集 \( V' \)，输入 LLM 进行推理。

### 2.3 关键超参数
- 体素尺寸 δ = 0.2 m
- 空间约束阈值 τ_g = 5（网格空间）

## 6. 论文的主要结论与发现

1. **投影式3D VLM存在两类冗余**：点级冗余（多视角重叠观测）和对象级冗余（同一物体多表面令牌），且空间聚合不能解决对象级不平衡。
2. **特征多样性优于空间多样性**：在DPP中，特征空间距离始终优于空间（XYZ）距离（64令牌时 52.8 vs. 50.1 EM），因为特征多样性更有效地平衡了对象级令牌分配（特征DPP覆盖 70% vs. 空间DPP覆盖 51%）。
3. **三步互补有效**：体素化去除点级冗余、DPP选择语义多样锚点、空间约束合并补充上下文并保持几何一致性，三阶段缺一不可。
4. **性能优异**：3DZip 以 128 令牌保留原始性能的 94.7%（Rel.），以 64 和 32 令牌分别保留 92.3% 和 88.9%，在所有预算下均优于现有压缩方法。
5. **效率显著**：推理延迟从 342ms 降至 178ms（1.92× 加速），FLOPs 减少 90.2%，KV cache 减少 86.0%。
6. **类别级洞察**：空间需求最高的类别（对象定位、空间理解）中，3DZip 改善最明显；而注意力量化的方法（FastV/SparseVLM）在对象状态识别中表现较好，因其对特定文本查询聚焦有效。

## 8. 不足与局限

- **小物体信息损失**：粗体素化可能合并不同物体或背景，削弱精细尺度的物体线索。补充分析显示，在细小物体（bottom 10% 尺寸）和细粒度细节子集上，3DZip 低于无体素化变体（EM 19.5 vs. 21.6），小物体纯度仅为 0.070（全量压缩时），表明 Stage 1 存在潜在的信息破坏风险。
- **超参数固定、缺乏场景适应性**：δ 和 τ_g 在所有场景中固定，未随场景复杂度（密度、大小）自适应调整。场景规模分析显示，小场景偏好更小的 δ 和更紧的 τ_g，大场景则相反；固定设置虽总体最优，但非各场景最优。

- **对比范围有限**：主要与训练无关的压缩方法比较，未与经过特定训练/微调的压缩模块对比；也未考虑结合 FlashAttention 等已有加速手段后的叠加效果。
