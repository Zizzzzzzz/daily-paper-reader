## 摘要
事件相机产生稀疏且异步的事件流，为高效感知提供丰富的时空信息。近期基于事件的模型通过直接建模异步事件而无需密集帧重建，展现了强大的性能。然而，识别其预测背后的事件级证据对于提高模型透明度和可靠性至关重要。直接从点云适配点级显著性方法可提供细粒度归因，但忽略了事件特有的时空结构。为解决这一局限，我们提出体素引导的全局事件排序（VGER），一种用于基于点的事件云网络的免训练归因框架。VGER结合事件级梯度证据与任务感知的体素扰动证据，将区域贡献转化为事件级归因分数，同时保持细粒度分辨率。此外，VGER引入统一的事件排序策略，其中排名靠前的事件预期对预测至关重要，而排名靠后的事件预期对预测影响有限。我们在三个基于事件的基准上评估VGER，使用PointNet、PointNet++和EventMamba。在九种数据集-骨干网络组合下，VGER在高层级和低层级删除性能上均持续优于点级显著性基线。

## Abstract
Event cameras produce sparse and asynchronous event streams that provide rich spatio-temporal information for efficient perception. Recent advances in event-based models have demonstrated strong performance by directly modeling asynchronous events without dense frame reconstruction. However, identifying the event-level evidence behind their predictions is crucial for improving model transparency and reliability. Directly adapting point-level saliency methods from point clouds provides fine-grained attribution but overlooks event-specific spatio-temporal structures. To address this limitation, we propose Voxel-Guided Global Event Ranking (VGER), a training-free attribution framework for point-based event cloud networks. VGER combines event-level gradient evidence with task-aware voxel perturbation evidence, transferring regional contribution into event-level attribution scores while preserving fine-grained resolution. Furthermore, VGER introduces a unified event ranking strategy, where high-ranked events are expected to be prediction-critical and low-ranked events are expected to have limited influence on predictions. We evaluate VGER on three event-based benchmarks with PointNet, PointNet++, and EventMamba. Across nine dataset-backbone settings, VGER consistently improves both high-tail and low-tail deletion performance over point-level saliency baselines.

## 1. 核心问题与整体含义（研究动机与背景）

事件相机是一种仿生视觉传感器，输出稀疏、异步的事件流，具有高时间分辨率、低延迟和高动态范围等优势。近年来，基于点的事件云网络（point-based event cloud networks）——如将原始事件表示为时空点集并采用 PointNet、PointNet++、EventMamba 等点云架构处理——在事件分类等任务上取得了良好性能。然而，随着这些模型日益复杂，其预测由大量异步事件之间的复杂交互决定，导致难以理解哪些事件为模型决策提供了关键证据，这阻碍了模型透明性和可靠性的提升。

现有归因方法存在一个核心矛盾——**粒度困境**（granularity dilemma）：

- **点级显著性方法**（如从点云直接迁移的 PCS）虽能提供细粒度的事件级重要性区分，但忽略了事件特有的**局部时空结构**——事件语义往往来自相关事件组构成的运动模式和物体边界，而非孤立事件。
- **区域扰动方法**（如体素级扰动）能提供任务感知的区域整体证据，但将同一体素内所有事件赋予相同分数，牺牲了事件级的分辨率。

因此，论文提出 **VGER（Voxel-Guided Global Event Ranking）**——一个无需训练的归因框架，旨在**同时兼顾细粒度事件级分辨率和区域时空结构感知**，为事件云网络提供全局事件排序，用于识别预测关键事件和可安全移除的事件。

## 2. 方法论：核心思想、技术细节与算法流程

VGER 的核心思想是：将**事件级梯度证据**（细粒度敏感性）与**任务感知的体素扰动证据**（区域结构贡献）进行融合，并引入结构排序项进行全局排序。整个框架分为四个阶段：

### 2.1 事件级梯度证据（Event-Level Gradient Evidence）
- 对每个事件的时空坐标 z = (x, y, t) 进行鲁棒归一化，防止时间坐标因数值范围过大而主导分数。
- 提出**各向异性度量矩阵** Aρ = diag(1, 1, ρ)，其中 ρ = ωt/ωs 控制时间位移与空间位移的相对权重，以区分时间与空间位移对归因的影响。
- 将点云显著性方法 PCS（Point Cloud Saliency）适配到事件域，定义各向异性中心收缩路径 ¯z(τ) = exp(−τAρ)¯z，并给出事件级 PCS 分数：

  S_pcs(ei) = −(∇¯zi L, Aρ ¯zi / (rρi + ε)) · (rρi)^(1+α)

  该分数衡量事件沿各向异性时空收缩方向被抑制时任务损失的一阶变化量，保留每个事件的独立分数。

### 2.2 任务感知体素证据（Task-Aware Voxel Evidence）
- 将归一化事件域划分为 Gs × Gs × Gt 个体素（在各向异性变换坐标下进行），对每个被占用体素 Vj，将其中的事件移向流中心（保持数量、极性、时间顺序），计算任务损失变化：

  ΔL(Vj) = L(fθ(Ẽ(j)), y) − L(fθ(E), y)

- 将该体素级损失变化广播至每个构成事件：S_vox(ei) = ΔL(V(ei))，实现**区域证据到事件级精度**的转移。

### 2.3 结构排序项（Structural Ranking Term）
- 先将梯度与体素证据加权融合为基准分数：S_base = βp·Norm(S_pcs) + βv·Norm(S_vox)。
- 引入**局部上下文排序**：
  - 体素内排序 ρV：同一体素内事件按基准分数的相对排名；
  - 时间箱内排序 ρT：同一时间段内事件的相对排名；
  - 体素占用度 D(Vj)：衡量体素内事件密度，其稀疏性 1−D 也作为结构信息。
- 最终结构分数为各成分的加权组合：

  S_struct = wb·S_base + wc·ρV + wt·ρT + wr·(1−D) − wd·D

  结构项在不替换梯度与体素信号的前提下细化了全局事件排序——体素内排名保持区域内的细粒度区分，时间排名引入时间上下文，占用度反映事件的空间分布特征。

### 2.4 全局事件排序（VGER Score）
- 最终 VGER 分数融合三路证据：

  S_VGER(ei) = λv·Norm(S_vox) + λp·Norm(S_pcs) + λr·Norm(S_struct)

- 对完整事件流执行全局排序：π = argsort S_VGER(ei)。该统一排序同时用于**高尾评估**（删除排名靠前的事件应导致预测显著下降）和**低尾评估**（删除排名靠后的事件应对预测影响有限）。

## 6. 主要结论与发现

1. **VGER 在所有九种设置下同时改善高尾和低尾删除性能**：相比 PCS-xyt，高尾 AUC 全部下降、低尾 AUC 全部上升，宏平均高尾 AUC 降低 0.0532、低尾 AUC 提升 0.0470，双尾间距从 PCS-xyt 的 0.0566 扩大至 0.1568。
2. **体素证据是高尾（决策关键事件定位）的主要来源**，消融实验表明添加体素通道后，删除高排名事件导致准确率更早、更深地下降。
3. **结构融合改善了低尾（可安全移除事件识别）表现**，完整融合在大多数删除比例下保持了最高的低尾准确率。
4. **VGER 对多种骨干有效**：无论 PointNet 的全局池化、PointNet++ 的层次几何特征，还是 EventMamba 的长时间依赖建模，VGER 均优于点级基线。
5. **统一排序同时服务于"解释"与"压缩"**：高尾事件为决策关键事件（删除会破坏预测），低尾事件为可移除事件（删除可保持准确率），一个排序同时支撑两种应用需求。

## 7. 优点

- **创新性强**：VGER 是首个专门为基于点的事件云网络设计的归因框架，填补了事件级归因的空白。
- **巧妙解决粒度困境**：通过"体素证据广播到事件 + 结构排序"的策略，同时获得区域结构感知和事件级分辨率，而不是在两者之间折中。
- **免训练与通用性**：无需训练或修改模型参数，适用于多种基于点的骨干网络，架构无关。
- **方法论严谨**：
  - 引入各向异性时空度量，显式区分空间位移与时间位移的贡献；
  - 保留 PCS 的数学可解释性（沿收缩路径的一阶损失变化）；
  - 体素扰动任务感知性强，直接测量区域对预测的有限任务效应；
  - 结构排序项在保留原始证据的同时细化了局部排序，设计逻辑清晰。
- **评估协议更全面**：提出双尾评估视角，既验证排名头部的事件确实关键，也验证排名尾部的事件确实可移除，比单一删除曲线更严格。
- **提供了可视化案例**：展示了高尾删除和低尾（错误修正）删除的实际效果，增强了结果的可信度。
