## 摘要
现代视觉语言模型（VLM）将高分辨率图像转换为长序列的视觉词元。每个词元都经过语言解码器并持久存在于其提示KV缓存中，推高了推理成本并促使进行激进的视觉压缩。现有的基于评分的方法为每个词元分配独立的显著性分数并保留Top-K词元。然而，文本查询消耗的是来自视觉群体的集体性、带符号的注意力消息，而非孤立补丁。因此，相同大小的Top-K集合可能反复覆盖某一显著区域，遗漏稀疏但互补的证据，并丢弃由被移除群体携带的信息。为此，我们将忠实的视觉压缩表述为为解码器消息构建紧凑的锚点集，并引入我们无需训练的基于真实消息锚点集剪枝（GMC）方法，该方法在查询锚定、外观和坐标感知证据之间联合分配支持，然后在物理压缩和原生注意力恢复之前，将丢弃的状态迁移到其原始多模态位置上的选定代表中。这将忠实压缩分解为两个耦合组件，包括选择覆盖所需消息模式的载体，以及在这些载体上实现带符号的群体消息。我们进一步推导了将它们的误差与带符号消息失真、视觉创新和候选边际稳定性联系起来的界限。在多个VLM家族和多样化基准上的实验展示了强劲性能，其中GMC-H2在Qwen2.5-VL-7B上以80.2%更少的视觉词元保留了97.78%的完整相对平均能力，而GMC-L16达到100.36%。受控干预实验证实，集体支持和群体实现共同驱动了这些增益。

## Abstract
Modern vision language models (VLMs) turn high-resolution images into long sequences of visual tokens. Every token traverses the language decoder and persists in its prompt KV cache, inflating inference cost and motivating aggressive visual compression. Existing score-based methods assign each token an independent importance score and retain the Top-K. However, text queries consume collective, signed attention messages from the visual population, not isolated patches. Consequently, equally sized Top-K sets can repeatedly cover one salient region, omit sparse but complementary evidence and discard information carried by the removed population. We therefore formulate faithful visual compression as constructing a compact coreset for decoder messages, and introduce our training-free Grounded Message Coreset Pruning (GMC) which jointly allocates support across query-grounded, appearance, and coordinate-aware evidence, then transports discarded states into selected representatives at their original multimodal positions before physical compaction and native attention resume. This decomposes faithful compression into two coupled components, including selecting carriers that cover the required message modes and realizing the signed population message on those carriers. We further derive bounds connecting their errors to signed-message distortion, visual innovation, and candidate-margin stability. Experiments across multiple VLM families and diverse benchmarks demonstrate strong performance, with GMC-H2 retaining 97.78% Full-relative mean capability on Qwen2.5-VL-7B using 80.2% fewer visual tokens, while GMC-L16 reaches 100.36%. Controlled interventions verify that collective support and population realization jointly drive these gains.

## 1. 核心问题与整体含义

- **背景问题**：现代视觉语言模型（VLM）为了理解高分辨率图像，会把图像切分为大量视觉 token（例如 Qwen2.5-VL-7B 在 1008² 分辨率下产生 1296 个视觉 token）。这些 token 全部通过语言解码器，并一直保留在 prompt 的 KV cache 中，因此视觉 token 越多，推理代价越高。

- **现有方法的缺陷**：
  - 主流压缩方法都是“独立评分 + Top-K 保留”，例如根据注意力分数、特征范数或敏感度给每个 token 打分，再保留最高分的 K 个 token。
  - 然而文本查询实际上消费的是**视觉群体共同产生的“集体性、带符号的注意力消息”**，而不是一个个孤立 patch 的独立重要性。
  - 因此等量的 Top-K 集合可能反复覆盖同一个显著区域，遗漏稀疏但互补的证据（比如图表中的数值、坐标轴刻度、关系端点等），并完全丢失被删除 token 所携带的信息。

- **核心主张**：视觉压缩不应被简化为“每个 token 有多重要”，而应被理解为**为解码器消息构建一个紧凑的、有真实语义锚定的锚点集（grounded message coreset）**。支持分配（在哪里保留证据）与消息实现（保留的代表向量应携带什么信息）是两个相互耦合、不可分割的部分。

- **整体含义**：论文试图在压缩率很高的情况下仍保持 VLM 的输出保真度，强调消息层面的群体覆盖与带符号实现，而不是孤立 token 的重要性排序。

## 2. 方法论

### 2.1 核心思想

论文提出 **GMC（Grounded Message Coreset Pruning）**，一种**无需训练**的视觉 token 压缩框架，包含两个耦合部分：

1. **支持分配（Support Allocation）**：在多个证据“客户端”（client）上联合分配有限的 K 个载体位置，使它们能互补地覆盖查询所需的证据模式。
2. **消息实现（Message Realization）**：将未选中的视觉状态“迁移”到选中的代表 token 上，同时保留原始多模态位置，再恢复原生紧凑注意力，从而在代表 token 上重新实现被下游消费的带符号群体消息。

### 2.2 具体技术要点

- **边界消息几何（Boundary Message Geometry）**：
  - 在解码器第 p 层之前，利用原生 RMS 归一化、M-RoPE 位置编码和因果注意力计算 Q/K/V。
  - 使用原生视觉列注意力切片 `A_h`，而不是单独对视觉 token 重归一化的注意力，从而保留与文本 token 的竞争关系。
  - 为了降维，使用固定秩的随机正交探针（rank-r=4）投影每个头的 value，并加入一个“注意力质量同质坐标” `σ_{c,h}`，以保证支持分配时把注意力质量和 value 坐标放在同一尺度上。

- **三类“客户端”证据**：
  - **查询锚定客户端（Query-Grounded Clients）**：来自原生注意力中已与文本查询交互的视觉注意力消息，代表当前提示已经访问到的证据。
  - **外观客户端（Appearance Clients）**：基于归一化边界特征的高斯核相似度，用于保留尚未被 prompt 激活但视觉上重要的内容。
  - **空间客户端（Spatial Clients）**：基于原始图像网格坐标的径向地标核，用于防止支持集合坍缩到单一显著区域，并保留空间关系与分布式证据。

- **互补覆盖的贪心求解**：
  - 将支持分配建模为带权重的最大设施覆盖问题：
    `F(S)=Σ_m max_{i∈S} C_{mi}`。
  - 由于该目标函数是归一化、单调且子模的，贪心批次选择（batch greedy）具有近似保证。已完成覆盖的客户端不会重复吸引新 token，因此冗余高分区会迅速失去边际价值。

- **群体迁移（Population Transport）**：
  - 每个被丢弃 token 被分配到同图内、语义最相似且空间贴近的代表 token 上。
  - 使用带符号余弦相似度 + 空间距离门控项进行分配，避免跨图像分配。
  - 对每个簇计算加权质心，并用消息能量作为权重；在 RMS 归一化恢复后写入代表 token 的状态。
  - 在 RMS 恢复之前，迁移操作对任意线性映射都精确保持一阶矩（带符号总体消息），因此能保存方向相反的相互抵消信息。

- **物理压缩与位置保持**：
  - 删除所有未选中的视觉位置，只保留 K 个代表 token，且每个代表 token 保持原始的多模态位置 ID。
  - 后续解码器层从第 p 层开始以紧凑序列继续运行，不改变模型原生接口、因果顺序和坐标系统。

- **误差与理论保证**：
  - 给出子模覆盖的批式贪心近似系数 `c_B`。
  - 将覆盖误差、迁移误差、RMS 恢复误差、紧凑注意力质量不匹配、视觉创新（VIE）和候选边际稳定性（candidate margin stability）以可审计的界限联系起来。
  - 核心命题：非负覆盖目标决定“载体放在哪里”，迁移与原生紧凑注意力决定“带符号消息是什么”；二者不可互相替代，误差以加法形式进入最终消息误差界。

## 3. 实验设计

### 3.1 使用的模型与基准

- **主模型**：Qwen2.5-VL-7B-Instruct（1008² 分辨率，1296 个视觉 token）。
- **迁移模型**：LLaVA-1.5-7B（576 个视觉 token）。
- **压缩边界**：GMC-H2（第 2 层前压缩）、GMC-L16（第 16 层前压缩）、GMC-H1（第 1 层前压缩，长文档场景）。
- **基准任务**：
  - 通用能力：TextVQA、ChartQA、MME、POPE、MMBench、GQA。
  - 幻觉与忠实性：POPE、AMBER、HallusionBench、CHAIR（CHAIRs/CHAIRi）。
  - 长文档：DocVQA（ANLS，最多 15,876 个视觉 token）。

### 3.2 对比方法

- FastV、DivPrune、VisionZip、CDPruner、MMTok、HAWK、FitPrune、SparseVLM、ApET、VLM-Pruner 等近期压缩/剪枝方法。
- 对比设置包括：固定最终 token 数（K=128/256/512 等）、固定 token 层工作量（equal token-layer work）、相同路径下的支持选择器对比（Random、Uniform-head attention、Norm+diversity、Feature k-center、HAWK-style）、全绝对分数表等。

### 3.3 消融与机制实验

- **History × Population 双因素析因**：验证历史视图（historical views）和群体迁移（population transport）对消息实现的影响。
- **Selector × Recovery 析因**：组合不同支持选择器和不同恢复方式（hard deletion、uniform merging、grounded transport）。
- **消息通路实验**：开关 current message、historical views、population weighting 的 2³ 析因设计。
- **组件边际效应**：分别移除 message、appearance、spatial、transport 组件，观察性能变化。
- **位置干预**：对比“保留原始位置”和“重新打包为连续位置”，验证 M-RoPE 坐标的重要性。
- **探针与参数敏感性**：探针秩、种子、群体权重、空间分配门控、批大小等参数扫描。
- **机制诊断**：覆盖饱和率（grounded/appearance/spatial）、VIE（视觉创新误差）、有害翻转率、候选逻辑误差与翻转的 AUROC、无翻转证书（no-flip certificate）等。

### 3.4 主要结果

- Qwen2.5-VL-7B 上：
  - GMC-H2 在 K=256 时保留 Full 相对平均能力 **97.78%**，且减少 **80.2%** 视觉 token；
  - GMC-L16 在 K=256 时达到 **100.36%**，K=128 时仍有 **99.11%**。
- LLaVA-1.5-7B 上：
  - GMC-L16 在 K=64/128 时保持约 99.68%/99.59% 的六任务平均保留率。
- 幻觉与忠实性任务上，GMC 在 POPE、AMBER、HallusionBench、CHAIR 上均优于 VisionZip 和 MMTok，且在低预算下多项差异通过 Holm 校正。
- DocVQA 长文档场景下，GMC-H1 保留 98.87% ANLS，带来 1.258× 端到端加速，并减少 73.94% 的 prompt-KV。
- 等量 token-layer work 对比中，GMC-H2 在更小最终 token 数下仍优于 MMTok 和 VisionZip。

## 6. 主要结论与发现

- 视觉 token 压缩应该从“独立 token 重要性排序”转向“消息级锚点集构建与群体实现”。
- GMC 只需在解码器某一层前一次性构建支持集合与迁移映射，即可在大幅压缩 token 的情况下保留 VLM 的绝大多数能力：
  - 80.2% token 减少时仍可达到接近甚至超过 Full 的平均能力（GMC-L16 为 100.36%）。
- 支持分配（query-grounded + appearance + spatial）决定证据载体位置；群体迁移决定载体所携带的带符号消息；两者缺一不可，且误差可独立审计。
- 保留原始多模态位置对下游空间推理与解码器行为非常重要；重新打包位置会导致显著性能下降。
- 剪枝边界越早（H2），计算节省越大但保真度越低；越晚（L16），保真度越高但压缩带来的计算节省越少。两者构成“质量-工作”曲线的不同工作点。
- GMC 无需训练即可迁移到不同 VLM 架构（Qwen2.5-VL 和 LLaVA-1.5），说明消息级覆盖思想具有一定通用性。

## 7. 优点

- **问题视角新颖**：清晰指出现有 Top-K 独立评分方法与“VLM 实际消费集体带符号消息”之间的错配，提出“消息锚点集”这一更高层次的压缩范式。
- **方法无需训练、即插即用**：只访问边界层原生 Q/K/V 和注意力切片，不改模型参数，不引入额外模型，工程可落地性较强。
- **理论和实践结合紧密**：给出子模覆盖近似界、覆盖到状态失真再到消息误差的链式推导、候选边际稳定性不等式，使压缩保真度可审计。
- **实验设计全面且公平**：多种基准、多种预算、两种架构、固定 K 与固定 work 双重视角、严格配对统计方法，结论可信度较高。
- **消融设计精细**：通过析因实验把“支持选择”和“消息实现”两个耦合组件分离开，实证验证各自贡献及交互效应。

## 8. 不足与局限

- **计算资源细节不够透明**：
  - 未报告完整训练/推理总 GPU 小时数、GPU 数量、能耗等；只给出了单次推理的组件时延，不利于完整复现算力成本评估。
- **生成设置较单一**：
  - 使用贪心解码、batch size 1，没有验证更高 batch 或采样解码下的表现。
- **基准覆盖仍有偏向**：
  - 通用任务集中缺少更强细粒度感知（如 OCR 大图、密集文字、复杂图表推理）的独立深度评测；DocVQA 只作为长文档场景单测。
- **压缩边界依赖人工选择**：
  - H1/H2/L16 是由用户指定的边界层，论文没有提出自动选择最优边界的准则；不同任务/模型可能需要不同边界。
- **固定配置的泛化风险**：
  - 方法中包含多个冻结超参数（温度、批大小、历史视图数、空间地标数等），论文虽做了敏感性分析，但未完全覆盖所有跨域迁移情形。
- **理论界限的常数依赖实际状态**：
  - 消息传播和候选边际界中的 Lipschitz 常数、局部放大系数等依赖具体模型状态，实际中只能通过后验测量，难以在压缩前直接预言最坏情况。
- **长文档缓存实现略为特殊**：
  - 缓存式执行中，前缀层保留未压缩的 selected dense K/V，后缀层使用压缩状态；这种混合方式在真实部署中可能引入额外的 cache 语义复杂度。
