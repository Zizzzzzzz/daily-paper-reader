## 摘要
长时程事件驱动的动作理解仍未得到充分探索，因为现有数据集大多包含短时修剪片段，而采集带有密集时间标注的原生事件流成本高昂。我们提出了Event ActivityNet，一个从人工标注的未修剪ActivityNet视频派生的大规模模拟事件基准。该基准包含3,263个视频、200个动作类别和106.94小时的数据，并提供匹配的5-bin和9-bin事件体素表示、时间动作标注以及带时间戳的标题。该基准支持标注片段动作识别、辅助事件-语言对齐以及因果在线时间动作定位。我们直接从非插值源视频的已解码帧顺序生成事件体素，保留每个视频的合理标称或平均帧率元数据以进行近似时间映射，并使用动作中心重建LPIPS作为保留可重建内容的软诊断。我们为自适应事件帧、提示-标题对齐以及仅事件、仅RGB和RGB-事件定位建立了基线。在渐进式嵌套尺度训练协议下，识别Top-1准确率从52.25提升至66.42，而在线时间定位的平均mAP从21.7提升至29.0。此外，分阶段的Event ActivityNet预训练后接原生事件微调，在多种监督预算下均 consistently 优于仅目标训练和从头联合训练。Event ActivityNet为长时程事件建模提供了可扩展基准，尽管原生相机评估对于面向部署的结论仍然至关重要。

## Abstract
Long-horizon event-based action understanding remains underexplored because existing datasets largely comprise short, trimmed clips, while collecting native event streams with dense temporal annotations is costly. We introduce Event ActivityNet, a large-scale simulated-event benchmark derived from human-annotated, untrimmed ActivityNet videos. It comprises 3,263 videos, 200 action classes, and 106.94 hours, with matched 5-bin and 9-bin event-voxel representations, temporal action annotations, and timestamped captions. The benchmark supports annotated-segment action recognition, auxiliary event-language alignment, and causal online temporal action localization. We generate event voxels directly from non-interpolated source videos in decoded frame order, retain per-video rational nominal or average frame-rate metadata for approximate time mapping, and use action-center reconstruction LPIPS as a soft diagnostic of retained reconstructable content. We establish baselines for adaptive event framing, prompt-caption alignment, and event-only, RGB-only, and RGB-event localization. Under a progressive nested-scale training protocol, recognition Top-1 accuracy increases from 52.25 to 66.42, while online temporal localization average mAP improves from 21.7 to 29.0. Moreover, staged Event ActivityNet pretraining followed by native-event fine-tuning consistently outperforms target-only and joint-from-scratch training across multiple supervision budgets. Event ActivityNet provides a scalable benchmark for long-horizon event modeling, although native-camera evaluation remains essential for deployment-oriented conclusions.

## 2. 方法论

- **总体路线**：不采集原生事件流，而是从 ActivityNet 的 RGB 视频直接生成离散事件体素（Event Voxel），复用已有的人类标注，避免 LLM 生成指令语料。
- **核心思想**：以“原始帧率 + 直接视频到体素转换”替代“高帧率插值 + 连续事件流存储”，降低资源需求，同时保留帧间运动信息。
- **关键技术细节**：
  - 使用定制 GPU 实现 V2V（Video-to-Voxel）管线，FFmpeg 解码为灰度帧，不做缩放、裁剪、帧率转换或中间 240Hz 插值。
  - 相邻帧对数亮度差经固定对比度阈值（c⁺ = c⁻ = 0.2）累积为带极性（Polarity）的符号切片；每个体素由 B 个连续帧间转换组成，B∈{5,9}，即 5-bin 与 9-bin 表示。
  - 保留每视频的标称/平均帧率元数据，用于近似帧到秒映射；不保留帧内展示时间戳（PTS）。
  - 使用 HyperE2VID 对动作中心窗口进行重建，并用 LPIPS 评估重建帧与源帧的感知距离，作为“可重建内容保留度”的软诊断阈值（δ=0.30），但不剔除任何视频。
- **下游任务定义**：
  - 标注片段动作识别：基于 v1.3 动作实例与标签，不把视频整体分配单一标签。
  - 因果在线 TAL：在任意时刻 t 仅使用观测前缀，不允许访问未来或事后修正。
  - 标题-动作对齐：用 tIoU 将 ActivityNet Captions 与动作实例匹配，η=0.1 为阈值，得到弱监督信号。
- **参考模型**：
  - 自适应事件帧 AEF-Split&Merge（AEF-SM）：根据活动率和对数空间直方图的 Jensen–Shannon 散度自适应切分/合并窗口。
  - 事件-文本对比对齐：冻结文本编码器，结合类提示与匹配标题训练事件编码器；也测试了正样本 Smooth-ℓ1 变体。
  - RGB-事件因果融合：基于 SimOn 和 MATR，采用事件查询 + RGB 键值的因果交叉注意力（CA），以及两种拼接方式（C1 下采样事件、C2 复制 RGB 特征）。

## 6. 主要结论与发现

- 渐进式嵌套尺度训练有效：识别 Top-1 从 52.25% 提升到 66.42%，Top-5 到 73.41%；在线 TAL 平均 mAP 从 21.7 提升到 29.0，mAP@30 从 32.9 到 46.3。
- 5-bin 与 9-bin 在识别上几乎无差（差距≤0.21），但 9-bin 在在线 TAL 上略有优势（mAP@30 最大提升 1.8），说明体素分组会影响时间定位度量。
- 基于 Event ActivityNet 的分阶段预训练+原生数据微调一致优于目标-only 和联合从头训练，在小监督比例（10%）下增益最大（Top-1 提升 2.61~7.65 点）。
- RGB-事件因果交叉注意力（CA）优于 RGB-only 和 event-only，表明 RGB 提供外观上下文、事件提供补充运动线索。
- 自适应事件活动检测（AEF-SM）和标题-提示对比对齐均带来积极且稳健的增益；字幕监督在去除低重叠样本（η=0.3）时效果最好（57.65 Top-1）。

## 7. 优点

- **规模与范围**：首个面向未修剪、长时程事件动作理解的模拟事件基准，规模达 3,263 视频 / 200 类 / 106.94 小时。
- **复用人类标注**：不加 LLM 生成指令，继承 ActivityNet 的动作标签和 Captions 描述，并派生标题-动作对齐，保证语义来源可信。
- **受控的双表示**：匹配的 5-bin 和 9-bin HDF5 表示，便于研究时间离散化对下游任务的影响。
- **质量与完整性审计**：使用 HyperE2VID + LPIPS 进行重建感知诊断，并包含 HDF5 可读性、张量/索引一致性、时序元数据、分片 SHA256 校验等完整性机制。
- **协议清晰**：固定 train/val 划分、固定最终检查点汇报、多次运行均值±标准差，匹配模态比较，可复现性强。
- **技术方法简洁有效**：AEF-SM 轻量自适应分帧、事件-文本对比对齐、因果 RGB-事件融合设计清晰，且与现有公开模型（ExACT、SimOn、MATR）良好衔接。

## 8. 不足与局限

- **模拟事件与真实传感器的差距**：不包含原生传感器噪声、异步微秒时间戳、高动态范围测量等物理特性，不能直接等价于真实事件相机数据。
- **时间映射近似性**：基于标称/平均帧率将秒级边界映射到帧索引，对变帧率（VFR）视频可能有误差；且不保存帧内 PTS。
- **诊断覆盖面有限**：LPIPS 只检查动作中心窗口的可重建性，不验证完整时间边界、背景到动作转换、事件统计真实性。
- **分布偏移与选择偏差**：为覆盖全部 200 类和时长分层，并依据字幕触发词/首帧亮度做运动/光照富集，导致子集与 ActivityNet 源分布存在偏移（如 Pearson 相关 r=0.64），可能偏向描述明显运动/光照的视频。
- **数据规模负担**：5-bin 和 9-bin 两个发布各约 5 TB，总存储需求大，可能限制可访问性。
- **部署导向结论受限**：作者明确说明，面向实际部署仍必须采用原生事件相机评估，模拟事件基准不能替代。
