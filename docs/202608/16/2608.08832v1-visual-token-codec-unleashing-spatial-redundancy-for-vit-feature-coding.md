## 摘要
大型视觉基础模型的分布式部署通常会将ViT骨干网络分割，并在计算节点之间交换中间标记特征，这使得在带宽和计算约束下实现高效特征压缩变得至关重要。现有的ViT特征编解码器通常将异构的全局标记和块标记展平为L×C的伪图像，导致熵模型主要捕获序列轴上的依赖关系，而忽略了原生的二维块网格结构。在本文中，我们表明ViT块标记在原始网格上保留了很强的局部空间相关性。为利用这一结构先验，我们提出了视觉标记编解码器（VTC），一种双路径学习编解码器，将全局标记和块标记分离到专用的编码路径中。全局标记通过轻量级因子化先验进行压缩，而块标记则在块标记网格上使用空间-通道上下文熵模型进行编码。为了支持中间层压缩和实际的速率自适应，VTC进一步在后续ViT块之后引入特征匹配监督，并在单一编解码器内引入可变速率模块。在DINOv2和SAM3上的实验表明，VTC在分类、分割和检测任务上持续优于代表性的ViT特征编码基线。在未压缩特征性能的90%水平下，VTC在这些任务上将比特率降低了15.7倍至37.4倍。我们还提供了面向实际传输和存储部署场景的中间层速率-效用分析。

## Abstract
Distributed deployment of large vision foundation models often partitions a ViT backbone and exchanges intermediate token features between computing nodes, making efficient feature compression critical under bandwidth and computation constraints. Existing ViT feature codecs typically flatten heterogeneous global and patch tokens into an L x C pseudo image, causing entropy models to mainly capture sequence-axis dependencies while overlooking the native two-dimensional patch-grid structure. In this paper, we show that ViT patch tokens retain strong local spatial correlations on the original grid. To exploit this structural prior, we propose the Visual Token Codec (VTC), a dual-path learned codec that separates global and patch tokens into dedicated coding paths. Global tokens are compressed with a lightweight factorized prior, whereas patch tokens are encoded on the patch-token grid using a spatial-channel context entropy model. To support intermediate-layer compression and practical rate adaptation, VTC further incorporates feature-matching supervision after subsequent ViT blocks and variable-rate modules within a single codec. Experiments on DINOv2 and SAM3 show that VTC consistently outperforms representative ViT feature coding baselines on classification, segmentation, and detection tasks. At 90% of uncompressed-feature performance, VTC reduces bitrate by 15.7x-37.4x across these tasks. We further provide intermediate-layer rate-utility analyses for practical transmission- and storage-oriented deployment scenarios.

# 论文总结：Visual Token Codec: Unleashing Spatial Redundancy for ViT Feature Coding

## 1. 核心问题与研究动机

论文关注**大视觉基础模型（如 ViT）在分布式部署中的中间层特征压缩问题**。在实际系统中，常将 ViT 骨干分割为前缀（sender）和后缀（receiver），中间层 token 特征需要跨节点传输或存储。由于 ViT 特征维度高、数据量大，在带宽和计算受限场景下，高效的特征压缩编码成为关键瓶颈。

现有 ViT 特征编码方法（如 LaMoFC、VQFC、DT-UFC 等）通常将**全局 token（CLS/REG）和 patch token 展平成 L×C 的“伪图像”**，再交给图像/视频编解码器处理。这种序列化布局使熵模型主要沿 token 长度方向建模依赖，却忽略了 patch token 在原始二维网格（H×W）上天然存在的强局部空间相关性。作者通过滑动窗口 Pearson 相关分析证明，patch token 在二维网格上具有显著的空间冗余，而展平处理完全丢失了这一结构先验，导致压缩效率不足。

此外，现有研究缺乏对**中间层特征编码的系统分析**：传输导向场景倾向于压缩浅层特征以降低端侧计算，存储导向场景则倾向于压缩深层特征以提高可复用性，但如何选择压缩层以平衡码率、计算和下游效用仍不清楚。

## 2. 方法论：VTC 框架

论文提出 **Visual Token Codec (VTC)**，一种双路径学习型编解码器，核心思想是**根据 ViT token 的异构结构分别设计编码路径**，显式利用 patch token 的二维空间冗余。

### 2.1 整体框架

- 将 ViT 划分为前缀（prefix）和后缀（suffix），在指定层插入编解码器。
- 中间特征 \( t_n \) 首先经过变换 \( f_a(\cdot) \) 得到潜在表征 \( \tau_n \)，再按 token 类型拆分：
  - 全局 token（CLS/REG）→ 1D 路径；
  - patch token → 2D 网格路径。
- 解码后合并，再经 \( f_s(\cdot) \) 映射回原始 token 空间，输入后续 ViT 块。

### 2.2 全局 token 编码

- 使用轻量级分析/合成变换和一个**因子化先验熵模型**。
- 对量化潜在变量 \( \hat{e} \) 用累积分布函数（CDF）构造概率质量函数（PMF）并计算码率：
  \[
  R(\hat{e}) = -\log_2 p(\hat{e})
  \]

### 2.3 patch token 编码

- patch token 被重塑为原始 H×W 网格，使用 **SCCTX（Spatial-Channel Context）熵模型**（源自 ELIC）结合超先验。
- 超先验通过 hyper encoder/decoder 生成条件高斯参数。
- 潜在变量 \( y \) 沿通道分成 K 组，组内采用**棋盘格空间上下文**，组间采用**通道自回归**，预测均值/方差参数：
  \[
  \Theta_k = g_{ep}(\Phi_{sp,k}, \Phi_{ch,k}, \Phi_{hp})
  \]
- 量化采用残差量化：\( \hat{y} = round(y - \mu) + \mu \)。

### 2.4 率失真优化与特征匹配损失

- 基础失真为压缩层特征 MSE，但容易导致量化误差在后续 ViT 块中传播放大。
- 提出**特征匹配损失**：将重构 token 输入后续 j 个冻结 ViT 块，与未压缩特征在深层计算 MSE：
  \[
  L_D = \| t^{(2d)}_{n+j} - \hat{t}^{(2d)}_{n+j} \|^2 + \| t^{(1d)}_{n+j} - \hat{t}^{(1d)}_{n+j} \|^2
  \]
- 总目标：
  \[
  L = L_D + \lambda \cdot (R(\hat{e}) + R(\hat{z}) + R(\hat{y}))
  \]
- 对全局 token 的 MSE 采用 1:1 加权（而非按 token 数量加权），以保证全局语义 token 的重建精度。

### 2.5 可变速率模型

- 使用 QP 条件调制模块库（VBR Module Bank），单一模型支持多个码率点。
- QP 经 embedding 生成 4 个调制向量，对特征进行通道级缩放，调整信息量。

## 6. 主要结论与发现

1. **空间冗余是 ViT 特征编码的关键**。利用 patch token 的二维网格结构进行熵建模，可以大幅提升压缩效率。
2. **VTC 在任务特定设置下显著优于现有基线**：在达到 90% 未压缩特征性能时，比特率降低 15.7×–37.4×（SAM3 InsSeg 15.7×，DINOv2 SemSeg 37.4×）。
3. **多任务兼容编码可行**：单一码流可同时支持分割和重建任务，且在语义分割上保持优势，但重建质量（LPIPS）仍有提升空间。
4. **中间层选择存在权衡**：浅层压缩降低发送端计算但增大码率和接收端负载；深层压缩可生成可复用表示但 RD 效率不一定最优。最佳 RD 操作点为 Input=9, Spv=12（DINOv2-B）。
5. **特征匹配监督层决定信息保留倾向**：相同 Input 层但不同 Spv 层时 RD 曲线走势相似，说明监督层比压缩层更直接影响编码器保留的内容。
6. **骨干规模并非越大越好**：在 bpp 指标下 DINOv2-B 在 ADE20K 上的编码效率优于 DINOv2-L，建议跨模型比较使用 bpp 而非 bpfp。
7. **双路径设计优于单路径**：全局 token 与 patch token 分开编码比全部展平 1D 或 2D 伪图像都更高效，因为避免了 token 类型统计不匹配和填充污染。

## 7. 优点

- **问题洞察深刻**：通过相关性分析揭示 ViT patch token 的二维结构先验，切中现有方法的要害。
- **方法设计清晰有效**：双路径架构简单、可解释性强，与 token 的语义差异高度契合；特征匹配监督从“表征保真”转向“任务效用”，更符合 feature coding 的目标。
- **工程实用性高**：支持可变码率、中间层压缩、多任务兼容，可服务于真实分布式推理和特征存储场景。
- **实验分析细致**：从任务、骨干规模、中间层选择、消融、延迟等多个角度全面评估，给出了实际部署指导（如浅层/深层权衡、bpp vs bpfp 的指标选择）。
- **评测严谨性**：使用更大规模测试集、适当报告 BD 指标、区分 task-specific 与 multi-task 两种协议，提升了结论可信度。

## 8. 不足与局限

- **对比基线有限**：未与 DT-UFC、跨架构特征编码等较新的学习型方法直接比较，无法全面体现 SOTA 优势；VTM 基线的极高编码耗时也使“相对增益”部分来自基线本身的低效。
- **骨干覆盖范围窄**：仅验证了 DINOv2 和 SAM3 两类 ViT 变体，未涉及 SigLIP、CLIP、LLaMA-VLM 等其他主流视觉基础模型，通用性尚待证明。
- **重建任务性能不足**：在主观重建（Rec）上 VTC 与未压缩特征仍有明显 LPIPS 差距，表明面向任务的特征编码在像素级保真方面存在天然瓶颈。
- **中间层分析只在单一任务（ADE20K Seg）下进行**，检测、分类等任务下的压缩层选择可能不同，结论外推需谨慎。
- **资源信息不完整**：缺少模型参数量、训练时间、内存占用等关键信息，难以判断实际部署成本。
- **潜在偏见风险**：可变速率模型使用 QP 采样的训练策略，可能对不同码率点的性能均衡有影响，但未提供各 QP 下的详细曲线；双路径中 1:1 失真权重为经验选择，未对权重敏感性进行系统消融。
- **未来工作提示**：论文未解决熵解码速度、重建友好目标、以及跨更大模型家族的验证问题，这些都是实际落地时需要关注的方向。
