## 摘要
视觉语言模型（VLM）中的视觉输入通常被编码为比文本长得多的token序列，这使得视觉token成为高效推理的主要瓶颈。近来许多方法通过对token重要性进行评分并在单次传递中剪除低分token来解决这一瓶颈。然而，一次性评分是不够的，因为token与提示相关的有用性取决于已保留的证据。受这一见解的启发，我们引入了DIVE（动态迭代视觉证据构建），这是一个无需训练的框架，将视觉token剪除重新构建为动态证据构建。DIVE反复选择具有最高残差条件分数的剩余token，更新视觉和提示残差以扣除已解释的证据，并重新评估剩余token。这种选择-更新-再评估的过程构建了一个互补的、与提示相关的证据保留集。在八个图像理解基准上的实验表明，DIVE在不同token预算下始终能保持性能。在视觉token减少88.9%的情况下，DIVE保留了未压缩模型平均性能的98.2%。代码可在https://github.com/Zhong-Chenchen/DIVE.git获取。

## Abstract
Visual inputs in vision-language models (VLMs) are often encoded into substantially longer token sequences than text, making visual tokens a major bottleneck for efficient inference. Abundant recent methods address this bottleneck by scoring token importance and pruning low-scoring tokens in a single pass. However, one-shot scoring is insufficient because a token's prompt-relevant usefulness depends on the evidence already retained. Motivated by this insight, we introduce DIVE (Dynamic Iterative Visual Evidence Construction), a training-free framework that recasts visual-token pruning as dynamic evidence construction. DIVE repeatedly selects the remaining token with the highest residual-conditioned score, updates the visual and prompt residuals to discount the evidence already explained, and re-evaluates the remaining tokens. This select-update-re-evaluate process builds a retained set of complementary, prompt-relevant evidence. Experiments across eight image-understanding benchmarks show that DIVE consistently preserves performance across token budgets. With an 88.9% reduction in visual tokens, DIVE retains 98.2% of the uncompressed model's average performance. Code is available at https://github.com/Zhong-Chenchen/DIVE.git.

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉语言模型（VLMs）在编码视觉输入时，产生的视觉 token 数量远超文本 token。例如在常见的 LLaVA 编码设置下，一张图片产生 576 个视觉 token，而文本提示往往不足 10 个 token。这种数量失衡导致视觉序列成为 VLM 推理效率（prefill 延迟、注意力计算、KV 缓存占用）的主要瓶颈。
- **核心问题**：如何在缩短视觉序列的同时，不丢失回答提示所必需的视觉证据。
- **已有方法的不足**：现有视觉 token 剪枝方法大多遵循"静态 Top-k 剪枝"范式，即为每个 token 分配一个固定的重要性分数，然后一次性选出分数最高的 k 个 token。然而，token 的"有用性"并非孤立存在，而是取决于当前已经保留了哪些 token——一旦某个显著对象已被充分表征，继续保留该区域的其他高分 token 只会带来冗余信息，剩余预算应分配给尚未覆盖的区域或互补的上下文细节。
- **核心见解**：一个视觉 token 的价值不仅取决于其独立的相关性，还取决于它相对于当前保留集的"残余状态"（即尚未被现有证据解释的部分）。
- **解决思路**：提出 **DIVE（Dynamic Iterative Visual Evidence Construction）**，一个无需训练的框架，将视觉 token 剪枝重新定义为动态证据构建过程，通过"选择—更新—再评估"的迭代机制，构建一个互补的、与提示相关的证据保留集。

## 2. 论文提出的方法论

- **总体框架**：DIVE 将静态的一次性 Top-k 选择，改为迭代式的动态选择。每一步在当前状态下选出得分最高的候选 token，更新视觉和文本残差以"扣除"已解释的证据，再重新评估剩余候选 token。系统架构如图 2 所示，算法伪代码见 Algorithm 1。
- **核心状态设计**：
  - 从同一多模态序列的隐藏状态中提取视觉表示 \( X \in \mathbb{R}^{N \times d} \) 和有效提示位置的文本表示 \( Q \in \mathbb{R}^{M \times d} \)，二者共享同一表示空间，可通过内积直接比较。
  - 在每一轮迭代中，维护动态演化的视觉残差状态 \( X^{(t)} \) 和查询残差状态 \( Q^{(t)} \)。视觉残差 \( x_i^{(t)} \) 追踪候选 token i 中尚未被覆盖的证据；查询残差 \( q_m^{(t)} \) 追踪尚未被满足的提示方向。更新仅用于引导选择，最终的原始视觉表示保持不变用于后续推理。
- **Prompt-conditioned 打分公式**：
  \[
  g_t(i) = \exp\left(\lambda \phi_i^{(t)}\right) \| x_i^{(t)} \|_2^2
  \]
  - 残差能量项 \( \| x_i^{(t)} \|_2^2 \)：衡量候选 token 在先前选择后剩余的视觉证据量。
  - 提示对齐权重 \( \phi_i^{(t)} \)：衡量候选与当前未解析查询状态的对齐程度（取候选与所有查询状态的正向对齐值中最大的三个的平均值，再在候选集合上归一化）。
  - 系数 \( \lambda \) 控制提示条件的强度，默认 \( \lambda = 1.5 \)。
- **选择时反馈更新**：
  - 选出 token \( s_t \) 后，将其当前视觉残差归一化得到方向 \( u_t \)，作为本轮新覆盖的视觉证据方向。
  - 定义单向反馈算子 \( F_{u_t}(z) = [\langle z, u_t \rangle]_+ u_t \)，即只提取与选中证据正对齐的分量。
  - 对视觉和查询残差同时应用耦合的一侧更新：
    \[
    x_i^{(t+1)} = x_i^{(t)} - \eta F_{u_t}(x_i^{(t)}), \quad
    q_m^{(t+1)} = q_m^{(t)} - \eta F_{u_t}(q_m^{(t)})
    \]
  - 视觉更新抑制已被覆盖的证据；查询更新扣除已被部分满足的提示方向。反馈强度默认 \( \eta = 0.8 \)。
- **迭代选择流程**：从空集开始，每轮计算所有未选中候选的得分，选择得分最高者加入保留集，更新残差状态后重新评估，直到达到预算 K。最后将选中的 token 恢复到原始空间-时间顺序，使用原始表示传给冻结的 VLM 推理。
- **理论性质**：论文证明该更新具有单调的单侧残差衰减性质：对于 \( 0 < \eta < 2 \)，更新后残差能量不增；仅与选中方向正对齐的分量被抑制，正交和负对齐分量保持不变。选择过程本身近似于按残差范数排序，并用提示对齐调制，具备一定的贪婪最优性直觉，但不提供全局集合函数优化的保证。
- **计算复杂度**：总选择成本为 \( O(MNd + K((N+M)d + MN)) \)，其中 N 为视觉 token 数，M 为提示 token 数，K 为保留 token 数，d 为嵌入维度。

## 6. 论文的主要结论与发现

- **主实验结论**：在 LLaVA-1.5-7B 上，DIVE 在保留 192/128/64 个视觉 token 时分别维持 100.3%/99.9%/98.2% 的未压缩性能，在三个预算上都取得了最高的平均表现；仅用 64 个 token 时在 8 个基准中的 7 个上排名第一。
- **跨骨干可迁移性**：在 LLaVA-1.5-13B、LLaVA-NeXT-7B/13B 的 9 个设置中，DIVE 都取得了最高的相对平均性能；在 Qwen2-VL-7B 上以两种压缩率均居首。
- **视频理解有效性**：在 LLaVA-OV-7B 上保留 15% 视觉 token 时仍保持 98.4% 的性能；在 Qwen2-VL-7B 视频任务上保留 15% 时保持 98.0%，显著优于对比方法。
- **效率-性能平衡**：在 POPE 上将视觉 token 从 576 减至 64 时，DIVE 的 prefill 加速 2.26×，端到端总时间加速 1.68×，同时 F1 仅下降 0.2 个点；在性能-延迟曲线中，DIVE 始终处于上包络线，性能退化更平缓。
- **机制验证**：随着反馈更新次数从 0 增加到 16，正确回答似然度和 MME 分数显著上升，16 次后趋于饱和；反馈更新降低了保留集内 token 的平均最大余弦相似度（即降低了冗余度）；完整更新的 prefill 开销增加 30.7%，但端到端延迟仅增加 1.8%，说明迭代更新的成本在完整推理过程中被有效摊薄。
- **消融结论**：去除语言引导或视觉中心打分均导致性能下降；完全冻结分数不更新（No Update）时，平均性能骤降至 61.97%（LLaVA-1.5-7B, 64-token 设置），显著证明了动态残差反馈的必要性。

## 7. 优点

- **方法创新性强**：将视觉 token 剪枝从静态单次打分重新定义为动态迭代的证据构建过程，明确建模了"token 的有用性依赖于已保留证据"这一关键特性，填补了现有方法的空白。
- **无需训练、即插即用**：DIVE 不需要重新训练或修改底层 VLM 架构，只需访问中间隐藏状态，可直接应用于冻结模型，兼容性强、部署成本低。
- **耦合的单侧残差更新设计精巧**：同时更新视觉和文本残差，将"已解释的视觉证据"和"已被满足的提示方向"一起扣除；top-h 对齐取平均抑制了弱相关文本 token 的干扰；单向更新（仅抑制正对齐分量）避免了过度抑制。
- **超参数固定、稳定性好**：全部实验使用同一组超参数（λ=1.5、η=0.8、h=3），不针对具体骨干或数据集微调；参数敏感性测试显示性能波动小（96.06%–97.20%）。
- **实验广泛且系统**：覆盖 8 个图像基准、2 个视频基准、4 个模型家族（含 7B/13B 两个规模）、多种压缩率、多个高效对比方法，验证了方法的通用性。
- **效率分析客观深入**：不仅报告了 token 减少的理论收益，还实测了端到端延迟、prefill 时间、GPU 内存、KV 缓存大小和性能-延迟曲线，证明了实际可用性。
- **理论保障**：提供了残差更新的单调性证明，从数学上说明了更新不会增加残差能量，保证了迭代过程的稳定性。

## 8. 不足与局限

- **需要模型内部访问权**：论文在 Limitations 中明确承认，DIVE 操作于中间视觉 token 表示，要求访问模型内部状态，因此目前仅适用于开源权重的模型（open-weight MLLMs）。无法直接应用于仅提供 API 的黑盒系统，限制了方法的适用场景。
- **依赖架构冗余度**：DIVE 的收益取决于底层视觉编码器是否产生可剪除的冗余。如果模型视觉编码器本身已输出紧凑表示，则进一步的剪枝空间有限，可能需要更保守的压缩策略。
- **实验于 2026-2027 年的模型/基准上完成**：论文发表时间设定在 2026-2027 年，实验基于当时的 LLaVA-1.5、LLaVA-NeXT、LLaVA-OV、Qwen2-VL 系列模型；未涉及更新一代的 VLM（如 LLaVA-OneVision 之外更前沿的模型），对新架构的泛化尚未验证。
- **单侧更新可能丢失信息**：在 η=0.8 的保守设置下，正对齐方向上 20% 的分量仍保留，这避免了过度抑制，但也意味着部分已覆盖证据可能在下一次选择时仍然参与竞争，形成轻微冗余。
- **近似最优而非全局最优**：基于残差范数的启发式打分和贪心交替选择，虽然实验效果良好，但论文明确指出不提供对下游目标的全局集合函数优化或近似保证，理论上仍是一个启发式方法。
- **选择阶段额外延迟**：迭代选择本身增加了 prefill 阶段的额外计算开销，虽然端到端延迟增幅较小，但在极短输入/极短生成场景下，选择开销占比可能上升。
- **未报告统计显著性**：实验虽然覆盖众多设置，但未报告多次运行的方差或统计显著性检验，基准评估的随机性可能对绝对分数差造成一定影响。
