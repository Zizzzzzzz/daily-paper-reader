## 摘要
3D视觉语言模型（3D VLMs）能够对多视图场景进行空间推理，但由于重复观测和大量无信息区域的存在，产生了显著的标记冗余，导致计算成本高昂。尽管视觉标记压缩在加速2D VLMs方面已显示出潜力，但它无法捕捉3D场景的结构化特性，导致空间覆盖不完整和细粒度细节丢失。在本文中，我们提出了HiSC，一种用于3D VLMs中分层空间聚类标记压缩的无训练框架。HiSC通过利用几何和语义线索的联合，将标记组织为空间聚类的簇，将标记压缩从标记级选择提升到簇级处理。具体而言，我们首先引入了一种基于空间图的合并（SGraM）策略，将跨视图冗余建模为空间连通性，并整合物理一致区域，在LLM推理之前有效地合并极其相似的冗余标记。然后，我们在LLM推理过程中提出了一种基于空间聚类的剪枝（SCluP）范式，在簇间和簇内进行分层压缩，在保留对象实例完整性的同时，为重要区域保留细粒度细节。在多种3D推理基准上的广泛实验验证了HiSC的有效性，特别是在高视觉标记剪枝率下。此外，HiSC实现了超过90%的标记减少，同时性能下降极小。代码可在https://github.com/elecreak/HiSC获取。

## Abstract
3D vision-language models (3D VLMs) enable spatial reasoning over multi-view scenes but suffer from substantial token redundancy due to duplicated observations and large uninformative regions, leading to high computational cost. Although visual token compression has shown promise in accelerating 2D VLMs, it fails to capture the structured nature of 3D scenes and leads to incomplete spatial coverage and loss of fine-grained details. In this paper, we propose \textbf{HiSC}, a training-free framework for hierarchical spatial clustering token compression in 3D VLMs. HiSC lifts token compression from token-level selection to cluster-level processing by organizing tokens into spatially grounded clusters using joint geometric and semantic cues. Specifically, we first introduce a \textbf{spatial graph-based merging (SGraM) strategy} that models cross-view redundancy as spatial connectivity and consolidates physically consistent regions, effectively merging extremely similar redundant tokens prior to LLM inference. We then propose a \textbf{spatial clustering-based pruning (SCluP) paradigm} within LLM inference, which performs hierarchical compression across clusters and within clusters, preserving object instance completeness while retaining fine-grained details for important regions. Extensive experiments on diverse 3D reasoning benchmarks show validate the effectiveness of HiSC, particularly under high visual token pruning ratios. Besides, HiSC achieves over 90\% token reduction with minimal performance degradation. Code is accessible at https://github.com/elecreak/HiSC.

## 1. 论文的核心问题与整体含义

- **研究背景**：3D视觉语言模型（3D VLMs）通过多视图RGB-D输入实现空间推理，在3D场景理解与具身智能中展现潜力。然而，多视图设置会产生大量视觉标记，单个场景往往产生数千个token，远超2D VLMs，导致推理成本极高。
- **核心问题**：3D场景中的标记冗余具有结构化特征，具体表现为两类：
  - **跨视图重复观测**：多个视角反复编码同一物理实体，产生近似重复的token。
  - **大面积无信息区域**：如空白平面表面，贡献大量冗余token。
- **现有方法的不足**：2D视觉token压缩方法（如基于注意力、多样性或敏感度的剪枝）直接对1D token序列进行独立选择，未利用3D场景的空间连通性和几何一致性，导致：(1) 空间覆盖不完整，关键物体可能被完全丢弃；(2) 重要性引导的选择会过度聚焦于少数区域，丢失上下文细节与重要物体的表示保真度。
- **核心思想**：将token压缩从**token级选择**提升为**簇级处理**——通过联合几何邻近性与语义相似性，将token组织为空间聚类簇，在多个层次上执行定制化压缩策略。

## 2. 方法论：核心思想与关键技术细节

**整体框架**：HiSC是一个无训练（training-free）框架，由两个互补模块组成：

### 2.1 空间图合并（SGraM）——LLM推理前

- **目标**：在LLM推理前消除跨视图冗余和物理一致区域中的重复token。
- **几何-语义邻接**：将几何邻近性和语义相似性解耦，分别定义两个邻接矩阵：
  - 几何邻接：`Ageo_ij = I(||p_i - p_j||_2 < τ_geo)`，基于3D坐标间的欧氏距离。
  - 语义邻接：`Asem_ij = I(cosine_sim(f_i, f_j) > τ_sem)`，基于特征间的余弦相似度。
  - 统一邻接：`A_ij = Ageo_ij ⊙ Asem_ij`，只有同时满足空间相邻且语义一致的token之间才建立边。
- **连通组件提取**：将邻接矩阵A视为无向图G = (V, E)，提取连通分量，每个分量对应场景中一个物理一致的空间连通区域。这种设计利用连通性的传递性，能捕捉大范围空间变化但局部结构一致的表面，同时避免跨区域的错误合并。
- **聚合**：每个连通分量的token通过特征和位置平均等简单聚合方式合并为代表性超token。

### 2.2 空间聚类剪枝（SCluP）——LLM推理过程中

- **目标**：在LLM多层推理中执行层次化token压缩，兼顾对象级覆盖与局部细节保留。
- **对象中心空间聚类**：采用两步分解：
  - 先将token划分成语义分组；
  - 再在每个语义组内应用空间连通性分离物理上不同的实例。
  - 最终簇：`C = ∪_m ConnComp(A^(m))`，确保每个簇对应3D空间中物理连通且语义一致的区域。
- **分层簇级剪枝**：
  - **簇级预算分配**：为每个簇分配token数量`n_k`，满足`n_k ≥ 1`且`n_k ∝ (I_k)²`，其中`I_k`为簇的重要性分数。约束`n_k ≥ 1`保证每个簇都保留至少一个token，防止对象完全消失；二次方加权则重点关照重要区域。
  - **簇内token选择**：采用重要性选择与多样性采样相结合的混合策略。定义联合空间-语义距离：`D_comb_ij = λ||p_i - p_j||_2 + (1-λ)[1 - cos(f_i, f_j)]`，优先选择与已选token在几何和语义上距离较远的token，促进结构多样性。

## 6. 主要结论与发现

1. **HiSC在所有压缩档位下一致优于现有方法**：在轻压缩和中压缩下几乎无损（相对分数98.87%和97.14%），在极端压缩（~10% token）下仍保持92.46%的相对性能，远超所有基线。
2. **结构化冗余去除可缓解注意力稀释**：适当的冗余合并反而提升了模型在部分任务上的表现（如Medium压缩下ScanQA CIDEr达到100.78，超过未压缩基线）。
3. **解耦的几何-语义连通性是关键**：仅用语义或仅用几何的邻接构建都会导致显著性能下降，而3D感知特征的纠缠式表示也不如解耦方案可靠。
4. **分层簇级剪枝优于纯token级或纯簇级剪枝**：token级剪枝产生碎片化表示，簇级剪枝可能整体删除低重要性簇导致覆盖不足，分层方案兼顾两者。
5. **SGraM和SCluP互补**：合并减少冗余使预算分配更有效，剪枝提供适应性选择；两者缺一不可。

## 7. 优点
