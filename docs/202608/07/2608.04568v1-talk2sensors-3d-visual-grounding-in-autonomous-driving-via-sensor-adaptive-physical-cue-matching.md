## 摘要
作为具身智能的关键能力，3D视觉定位（3DVG）主要在室内场景中借助RGB-D或点云输入进行研究，而现有的室外扩展大多仅依赖单目图像。这两种设置均未能充分满足真实世界的室外感知需求——在此类场景中，异构传感器捕获互补但各异的物理属性，例如视觉纹理、3D几何和物体运动学，这些属性对于实现灵活且鲁棒的查询自适应定位必不可少，但尚未被充分利用。为弥补这一差距，我们引入了Talk2Sensors，这是首个基于相机、激光雷达和4D毫米波雷达的多传感器3D视觉定位数据集。它包含8,682条语言指令和20,558个被引用对象，并配有与传感器特定物理线索明确对齐的多样化提示。此外，我们提出了TSFormer，一种基于Transformer的统一框架，用于自动驾驶中的语言引导3D视觉定位。TSFormer采用从粗到细的属性感知融合策略：语言路由属性采样器首先通过使用查询级语言线索调制传感器采样权重来执行粗粒度的文本条件特征检索，而随后的稀疏保持模态仲裁器模块则进行细粒度的模态仲裁和文本引导细化，以确定精确的引用空间位置。这种设计能够根据每个提示的语义需求动态路由外观、几何和运动线索，防止密集模态淹没稀疏但关键的传感器信号。大量实验表明，TSFormer在多个基准上达到了最先进的性能：在Talk2Sensors上比最强基线提高了8.05 mAP，并在单目Mono3DRefer基准上实现了53.05%的Acc@0.5。

## Abstract
As a key capability for embodied intelligence, 3D visual grounding (3DVG) has been predominantly studied in indoor scenes with RGB-D or point-cloud inputs, while existing outdoor extensions largely rely on monocular images alone. Both settings fall short of real-world outdoor perception, where heterogeneous sensors capture complementary yet distinct physical properties, such as visual texture, 3D geometry, and object kinematics, that are indispensable for flexible and robust query-adaptive grounding but remain under-exploited. To bridge this gap, we introduce Talk2Sensors, the first multi-sensor 3D visual grounding dataset built upon camera, LiDAR, and 4D radar. It contains 8,682 language instructions and 20,558 referred objects, with diverse prompts explicitly aligned with sensor-specific physical cues. Furthermore, we propose TSFormer, a unified Transformer-based framework for language-guided 3D visual grounding in autonomous driving. TSFormer adopts a coarse-to-fine property-aware fusion strategy: the Language-Routed Property Sampler first performs coarse text-conditioned feature retrieval by modulating sensor sampling weights with query-level linguistic cues, while the subsequent Sparse-Preserving Modality Arbiter module conducts fine-grained modality arbitration and text-guided refinement to determine the precise referred spatial location. This design enables dynamic routing of appearance, geometry, and motion cues according to the semantic requirements of each prompt, preventing dense modalities from overwhelming sparse but critical sensor signals. Extensive experiments demonstrate that TSFormer achieves state-of-the-art performance across multiple benchmarks: it improves over the strongest baseline by 8.05 mAP on Talk2Sensors, and transfers to the monocular Mono3DRefer benchmark with 53.05\% Acc@0.5.

### 二、🔬 方法论：TSFormer框架

#### 2.1 整体架构

TSFormer是一个端到端、统一的多传感器Transformer架构，其核心设计哲学是：**语言查询应决定“哪个传感器”的信息最重要**。给定一个驾驶场景和自然语言指令，相机、LiDAR、雷达分别经过各自的骨干网络提取单模态特征，随后经过两个核心模块的协同处理，最终用共享的Transformer解码器预测被引用物体的3D边界框。

**核心架构流程**：

```
多模态输入(相机/LiDAR/雷达) → 单模态骨干网络 → 
  Language-Routed Property Sampler (LRPS) [粗粒度检索] → 
    Sparse-Preserving Modality Arbiter (SPMA) [细粒度仲裁] → 
      Grounding Decoder → 3D预测框
```

#### 2.2 模块一：Language-Routed Property Sampler (LRPS) —— 语言路由属性采样器

**解决的问题**：传统多传感器融合依赖刚性且需标定的几何投影（如投影到BEV空间），面对相机、LiDAR、雷达密度差异悬殊时鲁棒性差，且无法根据查询内容选择“应该看哪个传感器”。

**核心思想**：将采样过程重构为**查询驱动的统一空间检索**——用语言语义调节各传感器的采样权重，先做粗粒度的文本条件特征提取。

**关键技术细节**：
- 将CLIP全局文本特征通过模态特定投影（φ_m）注入各传感器语义空间；
- 计算文本特征与物体查询（Q）之间的**通道级点积相似度**，生成查询级文本-传感器相似度图 D_m；
- 通过可学习的温度参数 τ_m，经Sigmoid将相似度转化为有界调制因子 G_m；
- 该调制因子被广播到可变形注意力权重中，在Softmax归一化**之前**进行调制，使采样权重朝向文本相关区域偏移；
- 同时用语言调制后的偏移量更新采样位置，通过多尺度可变形注意力聚合特征。

**效果**：LRPS使采样过程显式语言感知——查询“红色车辆”时，模型自动增强对相机纹理特征的采样；查询“5米/秒前行”时，增强对雷达运动线索的检索。

#### 2.3 模块二：Sparse-Preserving Modality Arbiter (SPMA) —— 稀疏保持模态仲裁器

**解决的问题**：粗采样后仍存在背景响应与模态冗余；信息密集的相机特征容易在融合中淹没稀疏但关键的雷达信号（即运动/速度信息）。

**核心思想**：用语言语义预测**样本级模态门控**，做细粒度的模态仲裁与文本细化，精准确定目标的空间位置。

**关键技术细节**：
- 将文本Token序列汇总为全局语义向量，经门控网络（线性层+非线性激活+层归一化+输出投影）预测各模态权重 α = [α_cam, α_lidar, α_radar]；
- 可选**Top-K稀疏路由**：将门控对数经过Top-K掩码（默认K=2），强制稀疏化，防止所有模态无差别参与；
- 各传感器采样特征按门控权重加权求和，得到融合传感器特征 F_s；
- 以融合特征为查询（Q），文本Token为键值（K/V），通过多头交叉注意力做最终的文本引导细化；
- 经过残差连接和层归一化，输出最终的仲裁特征 F_SPMA。

**效果**：实现了“语义驱动的传感器仲裁”——强调与文本需求一致的模态，同时通过软门控与稀疏化保护雷达的稀疏信号不被相机密集特征淹没。

#### 2.4 解码器与训练目标

- **DETR式集合预测解码器**：900个物体查询，6层解码器，迭代细化查询表示；
- **预测头**：输出二元引用置信度（区分“是否是被引用的物体”）和7维3D边界框（中心坐标、尺寸、偏航角）；不预测语义类别，语义完全由语言查询传达；
- **训练损失**：采用匈牙利算法进行二分匹配，结合**引用置信度交叉熵损失 + L1边界框回归损失 + 3D GIoU损失**；解码器各中间层均施加辅助监督以加速收敛。

**充分性评估**：实验设计相当充分，主客观证据相结合，且从多个角度（性能、鲁棒性、效率、泛化性、可解释性）形成完整闭环。模块级消融公平性较好（仅替换对应组件，其他条件固定）。不过，**所有实验均为单次运行的确定性结果，未报告方差/多次种子重复实验**，统计显著性未做检验，这是量化严谨性上的一处可改进空间。

### 六、📝 主要结论与发现

1. **多传感器物理线索是户外3DVG的上限提升关键**：单传感器中LiDAR几何信息表现最佳（46.182 mAP），相机（10.100）和雷达（1.463）单独使用远弱；但**正确设计的多传感器融合能进一步突破**——TSFormer三传感器融合（51.000）持续优于任意单一或双传感器组合。

2. **朴素融合适得其反**：FUTR3D将三传感器信息无差别叠加后（42.949 mAP）反而低于其LiDAR单传感器水平，直观说明密集相机特征对稀疏雷达信号的“淹没”效应确实是实际存在的严重问题。

3. **语言引导的动态路由是解决方案**：TSFormer最大的性能增益出现在雷达涉及提示——Radar Only +8.03、Camera+Radar +8.16、Camera+LiDAR+Radar +10.83，正好是单一模态不足、需要正确属性路由的关键场景。

4. **设计具备良好的模块化与泛化性**：LRPS和SPMA可独立提升性能且互补；TSFormer无需任务特定微调即可无缝迁移到Mono3DRefer，并超越专为该基准设计的模型。

### 七、✅ 方法亮点与优势

1. **开创性数据集设计**：第一个严格将语言提示与传感器特定物理属性（外观/几何/运动）显式对齐的室外多传感器数据集，且从源头上通过“量化可视化+禁止主观描述+三专家审核”确保数据质量，阻断了大模型的模板化生成与主观臆测问题。

2. **巧妙的问题拆解**：将语言引导的传感器融合解耦为“粗粒度采样路由”与“细粒度模态仲裁”两步，粗到细的架构更符合人类认知规律，且两个模块可独立实验验证、互补组合。

3. **规避标定依赖**：LRPS在统一的查询空间内完成跨传感器检索，绕开了传统方法中繁琐且脆弱的几何投影对齐，天然支持任意传感器子集输入。

4. **稀疏保护机制设计精妙**：软门控+Top-K稀疏路由的组合既实现了语义驱动的模态选择，又有效防止信息密集模态（相机）主导训练信号，是方法的核心创新点。

5. **实验的科学性与可视化深度**：属性感知热力图（图10）直观展示了不同模态对颜色、距离、运动等属性的响应差异；采样响应可视化（图11）直接验证了语言调制对采样分布的影响。

### 八、⚠️ 不足与局限

1. **传感器配置的覆盖面有限**：数据集基于View-of-Delft单一来源，场景集中在荷兰城市道路环境，未覆盖中国/美国等不同交通规则与道路形态，也未涵盖夜间、雨天、雪天等极端条件。论文虽在结论中说明将向恶劣天气扩展，但当前版本尚未实现。

2. **雷达的主导性被削弱**：虽然引入了4D雷达，但数据显示雷达单独使用时性能极低（1.463 mAP），主要作为LiDAR的补充信息存在。论文对“雷达在高遮蔽场景中的独特价值”的论证不足——实验均在理想天气下进行，雷达的天气鲁棒性优势未得到充分展示。

3. **统计严格性不足**：所有实验结果均为单次运行，未报告多次实验的标准差，也未进行统计显著性检验，结论的稳健性缺少量化证据。

4. **提示生成过程存在潜在偏差**：虽然由人类标注者编写提示，但提示内容受限于VoD场景中出现的物体与状态分布；某些物理属性（如雷达RCS、穿透性）在真实应用中极为有用，但可能难以通过自然语言有效表达，导致这类属性在数据中的代表性不足。

5. **应用限制**：方法在推理阶段仍需同时获取相机、LiDAR和雷达数据，对传感器硬件要求高；FPS约9.2，仅勉强达到实时阈值，在更复杂场景或高分辨率输入下实时性预算可能会吃紧。

6. **物体类别覆盖有限**：数据集关注行人和车辆等动态道路参与者，对道路基础设施（交通标志、护栏）、静态障碍物等类别未覆盖，这限制了模型在完整场景理解中的适用性。
