## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当规范指令被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测揭示其根本原因在于架构而非语义理解的缺乏。具体而言，我们证明当前的VLA模型在内部成功保留了正确的任务身份。失败实际上源于动态视觉观察与文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构性瓶颈，我们提出了接地语义重绑定（GSR），一种优雅的干预方法，通过将独立提取的任务语义与原生视觉特征显式融合，从零训练一个完全重新初始化的动作专家，从而绕开不稳定的联合路由。这种有针对性的干预仅使用规范示范即可显著恢复释义不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6个百分点。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进模型的PRIDE分数推至新纪录70.4，在指令生成能力上优于最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义接地，从而绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：视觉-语言-动作（VLA）模型在机器人操控任务中表现出色，但其成功高度依赖于标准基准测试中使用的刚性、规范化的语言模板。当面对语义等价的改写指令（paraphrased instructions）时，现有VLA模型性能显著下降，缺乏释义不变性（paraphrastic invariance）。
- **核心问题**：论文通过系统探测，颠覆了“性能下降源于模型语义理解不足”的直觉，指出**根本原因在于架构性缺陷**：动态视觉观察与文本指令的**联合编码（joint encoding）** 引入了系统性特征偏移，导致下游动作策略无法将保留的语义正确转化为控制命令。换言之，模型“听懂了”但“做不对”。
- **整体含义**：论文证明了可以通过**优雅的结构设计**而非暴力的数据扩展来解决这一鲁棒性问题，为VLA模型的指令泛化提供了新范式，并展示了轻量级模型通过合理架构设计即可媲美大规模预训练模型的可能性。

### 2. 方法论：Grounded Semantic Re-binding (GSR)

- **核心思想**：绕开不稳定的视觉-文本联合路由，将任务语义的提取与视觉场景建模解耦，并在动作生成阶段重新融合。
- **核心技术细节**：
    1.  **独立语义提取**：使用**冻结的T5-large编码器**接收真实任务指令，提取纯任务语义特征。T5不接收任何图像或机器人状态信息，确保语义的稳定性。
    2.  **视觉与文本解耦**：将模型原生VLM的文本输入替换为固定中性提示词（如“执行任务”），使其不再提供任务相关措辞，仅负责处理视觉场景。这防止了动态视觉与文本的联合编码干扰任务语义。
    3.  **动作专家重训**：**完全重新初始化并从头训练**动作专家（action expert），使其从训练初期就学习如何将T5语义、视觉特征与机器人状态正确映射为动作。
    4.  **架构感知注入**：根据模型架构，将投影后的T5语义特征注入到其核心多模态融合阶段：
        - **VLA-Adapter**：T5特征作为侧路K/V源提供给独立的Bridge-Attention策略。
        - **SmolVLA**：T5特征注入到SmolVLM的原生语言槽位，在视觉-语言深度融合前进行接地。
        - **π0.5**：保留其鲁棒的原生指令（PaliGemma），同时T5作为补充语义源，在PaliGemma任务token位置接地。
- **公式/流程**：关键公式为语义保留度R = (Δ_wrong - Δ_para) / (Δ_wrong + Δ_para)；诊断干预通过替换单层特征来计算动作恢复率。核心流程为：冻结T5提取语义 → 投影注入 → 在融合点与视觉特征交互 → 重新初始化的动作专家生成动作。

### 6. 主要结论与发现

- **根因确认**：VLA模型在指令改写时的失败源于架构机制，而非语义理解。任务语义被正确编码，但下游动作政策无法稳定利用。
- **联合编码是瓶颈**：动态视觉与文本的联合编码会放大措辞引起的特征偏移，而独立语义提取能有效规避这一问题。

- **深入的机理分析**：通过层间干预、特征距离度量、子空间分析等诊断手段，提供了清晰的因果链证据，直指问题根源。

- **架构感知的通用性**：提出的GSR是方法论而非固定补丁，能适配不同信息流的模型，体现了较强的普适性。

### 8. 不足与局限

- **大型动作专家训练问题**：GSR需要重新初始化动作专家，对于像π0.5这样参数庞大的专家，在标准训练计划下会导致规范指令成功率暂时下降（从96%降至91%），需要延长训练步数来解决，这增加了训练成本。
- **原生解耦架构的可扩展性瓶颈**：ParaVLA框架在扩大视觉基础模型（如DINOv2）规模时，未能表现出像VLM那样的大规模扩展能力，导致其性能提升受限。**解决这一扩展性瓶颈是未来重要方向**。
- **对原生语言路径的依赖**：GSR的指导原则取决于对原生路径鲁棒性的先验判断。若原生路径本身鲁棒（如π0.5），则GSR作为补充；若不可靠，则需中性化。但如冲突测试所示，SmolVLA即便中性化后，在处理双路径时也面临相互干扰的风险。
- **实验覆盖有限**：真实机器人实验规模较小，且仅在6个任务上进行，涉及抓取和堆叠，未覆盖更复杂的操作类型，成功率也偏低。此外，域外（OOD）任务在真实机器人上成功率较低（如task 3、5、6），表明存在进一步挑战。
- **诊断方法的局限性**：语义词空间（wording subspace）的估计需要配对的规范-改写指令对，这在实际应用中可能不易获得。该方法主要用于诊断而非训练。
