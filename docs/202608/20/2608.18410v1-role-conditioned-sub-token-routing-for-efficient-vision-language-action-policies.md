## 摘要
视觉-语言-行动(VLA)模型处理长多模态令牌序列，使得推理在内存和计算方面都代价高昂。现有效率方法主要减少视觉令牌，但激进的令牌剪枝变得脆弱，因为移除一个令牌会丢弃其整个表示。子令牌压缩提供了一种互补的替代方案，通过保留更多令牌同时减少其值宽度。然而，直接将子令牌压缩应用于VLA策略效果较差，因为对于感知、语言理解和控制重要的信息在多模态表示中的分布不同。我们引入了角色条件子令牌路由(RoleSub)，它学习如何压缩保留令牌的值表示。在视觉令牌减少之后，RoleSub将每个保留的值表示在正交空间中划分为组，并使用轻量级路由器确定应保留哪些组。路由决策以令牌表示、学习的潜在角色表示和语言上下文为条件。同一机制也可应用于语言值，允许压缩视觉和语言表示而无需移除额外令牌。我们在四个LIBERO套件上评估了OpenVLA-OFT-7B上的RoleSub。在匹配的视觉KV预算下，RoleSub在36个设置中的33个中优于经过训练的仅令牌控制，在激进压缩下增益最大。结合视觉和语言压缩，总KV降至原始的9.2%–11.3%，同时在大多数任务上保持强大的控制性能。这些结果表明，减少保留令牌内的表示为令牌剪枝提供了有效补充，用于激进VLA压缩。

## Abstract
Vision-Language-Action (VLA) models process long multimodal token sequences, making inference expensive in both memory and computation. Existing efficiency methods mainly reduce visual tokens, but aggressive token pruning becomes fragile because removing a token discards its entire representation. Sub-token compression provides a complementary alternative by retaining more tokens while reducing their value width. However, directly applying sub-token compression to VLA policies is less effective because information important for perception, language understanding, and control is distributed differently across the multimodal representation.   We introduce Role-Conditioned Sub-Token Routing (RoleSub), which learns how to compress the value representations of retained tokens. After visual token reduction, RoleSub partitions each retained value representation into groups in an orthogonal space and uses a lightweight router to determine which groups should be preserved. The routing decision is conditioned on the token representation, a learned latent role representation, and language context. The same mechanism can also be applied to language values, allowing visual and language representations to be compressed without removing additional tokens.   We evaluate RoleSub on OpenVLA-OFT-7B across the four LIBERO suites. At matched visual-KV budgets, RoleSub outperforms a trained token-only control in 33 of 36 settings, with the largest gains under aggressive compression. Combining visual and language compression reduces total KV to 9.2--11.3% of the original while retaining strong control performance on most tasks. These results show that reducing the representation within retained tokens provides an effective complement to token pruning for aggressive VLA compression.

## 2. 论文提出的方法论

### 核心思想
- **RoleSub（Role-Conditioned Sub-Token Routing）**：在视觉令牌减少之后，对每个保留令牌的值向量进行正交空间分解并分组，再用一个轻量路由器决定保留哪些值组。路由决策同时依赖：
  - 令牌自身的隐藏表示；
  - 可学习的**潜在角色表示**（latent role representation）；
  - 语言上下文（语言令牌的聚合表示）。
- 同一机制也可用于压缩语言令牌的值表示。这样可以在不删除令牌的前提下，同时压缩视觉和语言表示。

### 关键技术与流程（文字说明）
1. **令牌级减少**：对指定类型令牌（如视觉）用重要性评分选择保留子集（例如 QK-based 选择）。令牌保留率 r_m 控制保留数量，不限制具体剪枝规则，可兼容不同方法。
2. **正交值空间分解**：
   - 对每层使用固定正交矩阵 R^(ℓ)（正交性保证无损变换）；
   - 值向量 v_i^(ℓ) 变换为 z_i^(ℓ) = R^(ℓ)^T v_i^(ℓ)；
   - z_i 被切分为 S 个非重叠组，每个组 ds 维；
   - 路由器选择保留 Ki 组（0/1 掩码），再通过 M 掩码和 R 逆变换回原始值空间。
   - 若全部保留则无损；信息损失仅来自组选择。组不预定义语义，结构由控制目标学习。
3. **潜在角色表示**：
   - 轻量级角色估计网络 f_role 输出 softmax 向量 a_i^(ℓ) ∈ R^C（C 为潜在角色分量数，实验中 C=6）；
   - 角色分量不预设含义，与策略联合学习。
4. **角色条件值路由**：
   - 路由分数 = 令牌状态得分 γ_token + α_role·γ_role + α_lang·γ_lang；
   - γ_token 由令牌隐藏状态映射到 S 组；
   - γ_role = W_role·a_i（潜角色到组得分的投影）；
   - γ_lang 由语言令牌池化后经 f_lang 得到；
   - 取 Top-Ki 组保留，训练时用直通估计器（straight-through estimator）处理离散选择。
5. **令牌类型相关预算**：
   - 各令牌类型（vis/lang/prop/act）可有不同平均保留组数 Km；
   - 基于潜角色 a_i 在同类令牌间做软分配，允许单个令牌保留不同组数，但平均保持 Km。
6. **训练方式**：
   - 预训练 VLA 骨干冻结；
   - 联合训练 LoRA 适配器、路由函数和角色估计器；
   - 损失函数为动作预测的 L1 损失（动作分块的平均误差）。

## 3. 实验设计

- **模型**：OpenVLA-OFT-7B（基于 OpenVLA，Llama-2-7B + SigLIP/DINOv2 视觉编码器），每个控制步预测 8 个动作，多模态前缀含 512 个视觉令牌（双相机）+ 语言 + 本体感觉 + 动作上下文令牌。
- **数据集 / Benchmark**：四个 LIBERO 套件（Spatial、Object、Goal、LIBERO-10），每套 10 个任务，每任务 50 次评估试次。训练使用 no-op 过滤后的 LIBERO RLDS 数据。
- **视觉压缩配置**：
  - 视觉令牌保留数 8 / 16 / 32（对应 rvis = 0.015625 / 0.03125 / 0.0625）；
  - 值组预算 Kvis ∈ {1, 2, 4}，总组数 S=16，每组 256 维，dv=4096；
  - 语言/本体/动作值默认不压缩（在视觉主实验中）。
- **对比方法**：
  1. **Uncompressed VLA**：官方密集策略；
  2. **Training-free token-only pruning**：无训练的视觉令牌剪枝（直接应用）；
  3. **Matched-budget trained token-only pruning**：使用与 RoleSub 相同的 LoRA 训练流程但无子令牌路由，按相同视觉-KV 预算保留更多/更少的完整令牌（控制变量，分离“适应”与“路由”的收益）；
  4. **Plain sub-token routing**：训练过的普通子令牌路由（R=I、无潜角色、所有令牌均匀 K），用于分离 RoleSub 新增结构的贡献。

## 6. 论文的主要结论与发现

1. **RoleSub 优于匹配预算的纯令牌剪枝**：在所有 36 个视觉-KV 设置中 33 个优于 trained token-only，最大增益出现在激进压缩（如 8 个视觉令牌、Kvis=1）和长时程任务（LIBERO-10）上。
2. **训练无关的纯令牌剪枝在激进压缩下失效**：Kvis=1 对应的 12 个操作点中有 10 个成功率为 0，说明仅靠增加剪枝比例不可行。
3. **令牌保留与值宽度保留作用不同**：
   - 移除语言令牌会急剧损害性能（保留 53% 语言令牌时成功率约 40%）；
   - 但保留所有语言令牌并压缩其值表示到 1/16 组，独立应用时几乎无损（表 3）。
4. **组合压缩可将总 KV 降至 9.2%–11.3%**：同时保留视觉和语言值压缩后，大多数任务（Goal、Object、Spatial）仍保持强性能。
5. **视觉与语言压缩存在耦合**：LIBERO-10 上，语言压缩单独无害，但与强视觉压缩组合时损失显著（10个点以上）；增加语言值预算能显著弥补性能，表明策略在某一模态信息受限时会更多依赖另一模态。

## 7. 优点

- **方法创新性强**：提出“值内压缩”作为令牌级剪枝的互补维度，引入正交空间分解 + 潜在角色 + 语言条件路由，使压缩结构可学习而非依赖固定语义分组。
- **实验对照严谨**：通过“匹配预算的 trained token-only”控制训练适应效应；通过 plain sub-token routing 消融角色条件模块；通过独立语言压缩实验揭示令牌删除与值删除的差异。
- **发现具有普适启示**：语言令牌位置重要但值宽度冗余的结论，可能对多模态模型效率优化有参考意义。
- **压缩比可观**：总 KV 降到 ~10% 的同时在许多任务保持近乎密集性能，说明方法实用潜力大。
- **不假设预定义语义角色**：潜角色学习灵活，可在 VLA 控制目标下自动发现路由结构。
