## 摘要
随着Transformer架构的广泛成功，令牌正成为一种新的基本信息处理单元。这一趋势在多模态大语言模型（MLLMs）中尤为明显，其中视觉和文本信息都被表示为令牌并进行处理。随着MLLMs的快速部署，令牌的高效传输变得越来越重要。本文研究如何在保持多模态理解性能的同时，减少与MLLMs交互过程中的数据传输量。为解决这一问题，我们提出了一种针对MLLMs的令牌通信框架。在所提出的框架中，一个神经编解码器被集成到视觉分词器中，以控制传输的比特数。在接收端，解码后的潜在表示通过两条路径处理。解码器将图像重建为重建先验，而适配器将潜在表示转换为视觉令牌，并将其注入视觉分词器的中间层。为了使注入的令牌适用于MLLMs，我们进一步设计了一种两阶段的视觉-语言语义对齐训练方案。适配器首先通过蒸馏损失进行预热，然后通过对齐损失与文本语义对齐。还通过特征级线性调制引入了一种自适应适配器，使一个适配器能够支持多种编解码器速率。在各种MLLM基准上的大量仿真表明，在传输数据量相同的情况下，所提出的方案在任务性能上优于其他针对MLLMs的图像处理方案。

## Abstract
With the broad success of the Transformer architecture, token is becoming a new basic information processing unit. This trend is especially evident in multimodal large language models (MLLMs), where both visual and textual information are represented and processed as tokens. With the rapid deployment of MLLMs, the efficient transmission of tokens has become increasingly important. This paper investigates how to reduce the amount of transmitted data during interactions with MLLMs while preserving their multimodal understanding performance. To address this problem, we propose a token communication framework tailored to MLLMs. In the proposed framework, a neural codec is integrated into the vision tokenizer to control the number of transmitted bits. At the receiver, the decoded latents are processed through two paths. The decoder reconstructs image as a reconstruction prior, while the adapter converts latents into visual tokens and injects them into an intermediate layer of the vision tokenizer. To make the injected tokens suitable for MLLMs, we further design a two-stage visual-language semantic alignment training scheme. The adapter is first warmed up by a distillation loss and then aligned with textual semantics through an alignment loss. An adaptive adapter is also introduced through feature-wise linear modulation, allowing one adapter to support multiple codec rates. Extensive simulations on various MLLM benchmarks show that, under the same amount of transmitted data, the proposed scheme achieves better task performance than other image processing schemes for MLLMs.

### 2. 方法论：核心思想、关键技术细节与流程

#### (1) 核心思想
将图像神经网络编解码器与 MLLM 的视觉分词器结合，将压缩通道嵌入视觉信息处理流程中——即把整个链路视为一个"扩大了的视觉分词器"，信道将其拆分为发射端与接收端两部分，发射端输出视觉分词器的中间特征，编解码器控制传输比特数。

#### (2) 框架信息处理流程（图 2）
- **发射端**：输入图像 x 经 DL 编码器 Enc(·) 进行非线性分析变换，得到压缩导向潜变量 y，随后经量化、熵编码（AE）变为比特流，经信道传输。
- **接收端**：
  - 比特流经算术解码（AD）与反量化恢复潜变量 ŷ；
  - **路径一（重建先验）**：解码器 Dec(·) 将 ŷ 重建为像素域图像 x̂，输入视觉分词器，经 patchification 与嵌入投影得到重建视觉令牌，再经前 n−1 个 Transformer 块处理；
  - **路径二（适配器）**：适配器 Apt(·) 将 ŷ 转换为视觉令牌 T^apt_vis，注入到第 n 个 Transformer 块之前，与重建分支令牌按 T_vis = V_{n:N_V}(T^{rec,n−1}_vis + αT^apt_vis) 相加融合；
  - 融合后的视觉令牌与文本令牌拼接，由 LLM 进行自回归的下一令牌预测。
- **关键公式**：
  - 编码：y = Enc(x; q, θ_enc)
  - 重建：x̂ = Dec(ŷ; q, θ_dec)
  - 适配器输出：T^apt_vis = Apt(ŷ; q, θ_apt)
  - 传输压缩率：bpp = B/(H×W)；信道带宽比：CBR = N_ch/(C×H×W)
  - 优化目标：max PMLLM(Θ)，约束 bpp ≤ R 或 CBR ≤ ρ，SNR = γ

#### (3) 适配器架构（图 3）
- **Patchification**：将压缩潜变量 ŷ 的 2D 空间网格视为 patch，经 Reshape + Linear 映射至视觉分词器隐藏维度 D，得到令牌序列 T^pat_vis。
- **FiLM 模块（QP 自适应）**：通过可学习的 QP 嵌入表 + SiLU + Linear，生成缩放参数 α_q 与偏移参数 β_q，对令牌序列做特征级线性调制：T^FiLM_vis = T^pat_vis ⊙ (1_L(1_D + α_q)) + 1_L β_q。固定 QP 的适配器可跳过此模块。
- **Vision Transformer 块**：包含可学习的绝对位置编码、RoPE 旋转位置编码、多头注意力与 FFN，输出最终适配器令牌。
- **QP 自适应**：训练时随机采样 QP，使单个适配器支持多码率；推理时只需提供当前 QP 索引。

#### (4) 两阶段训练方案（图 4 与 Algorithm 1）
- **阶段一：蒸馏预热**：
  - 用原始图像经冻结视觉分词器前 n−1 块得到的中间特征 T^{ori,n−1}_vis 作为蒸馏目标；
  - 损失：L_distill = (1/|B|) Σ ∥T^{fuse,n−1}_vis,i − sg(T^{ori,n−1}_vis,i)∥²
  - 使适配器注入的令牌能补偿压缩造成的中间层信息损失。
- **阶段二：语义对齐**：
  - 融合令牌经视觉分词器剩余 Transformer 块后，用可学习查询经注意力池化聚合为视觉语义特征 v_i；
  - 文本语义特征来自预先构建的文本嵌入表（由类名 × 文本模板 → 冻结文本编码器 → EOS 嵌入 → 归一化平均池化得到）；
  - 采用 SigLIP 损失：L_SigLIP = −(1/|B|) Σ_i Σ_j log σ(z_ij(τ v_i u_jᵀ + b))，其中同类别图像-文本对为正对；
  - 总损失：L_stage2 = L_distill + λ_align · L_SigLIP，防止适配器参数漂移；
  - 训练期间冻结神经编解码器、视觉分词器与文本编码器，仅优化适配器和注意力池化头。
- **训练细节**：λ_align 采用 ramp-up 调度；SigLIP 参数 τ=10、b=−10 初始化；适配器输出注入第三块，注入强度 α=0.1。

### 6. 主要结论与发现

1. **A-ImageTC 性能优势显著**：在相同 BPP 下，所提方案在绝大多数 benchmark 和码率点优于重建方案与 Bridge，尤其在低码率区域优势明显；

3. **QP 自适应适配器有效**：经 FiLM 训练的单适配器性能可与各 QP 专用适配器相媲美，甚至略有优势；固定 QP 适配器在码率偏移时性能显著下降；
4. **语义对齐是关键**：移除 SigLIP 损失模型无法收敛；用 CE 替代 SigLIP 在全部 benchmark 上均有明显下降；
5. **VQ 方案可互补**：将 VQ 编解码器融入 A-ImageTC 框架可进一步提升性能，验证了适配器设计的普适性；
6. **无线传输下保持优势**：在 Rayleigh 衰落信道下，A-ImageTC 在不同 SNR 下均优于基线；但分离式数字传输在低 SNR 下仍存在性能悬崖效应；
7. **复杂度开销小**：自适应适配器增加约 2M 参数，计算量几乎不变，接收端处理时间影响可忽略。

### 7. 优点

- **任务定制化设计**：针对 MLLM 而非人类感知或单一机器任务设计编码方案，贴合 MLLM 多模态理解的实际需求；
- **轻量高效**：仅需训练一个小型适配器（单个 Transformer 块 + FiLM）和注意力池化头，冻结 LLM 与视觉分词器，避免了涉及 LLM 的端到端重训练，训练成本低；
- **无需改动编解码器结构**：框架可兼容多种神经编解码器（DCVC-RT、ELIC、VQ 类），灵活性强；
- **巧妙利用重建先验**：保留了像素域重建路径以提供细节信息，与语义化的适配器令牌互补，兼顾细节保留与语义保持；
- **QP 自适应创新**：通过 FiLM 将 QP 信息注入适配器，实现单适配器多码率支持，避免为每个码率训练单独的适配器，显著降低存储与部署成本；
- **有效的训练设计**：两阶段训练（蒸馏预热 + SigLIP 对齐）既稳定了令牌注入，又实现了视觉-语言语义对齐；采用文本嵌入表准备 + 注意力池化提取视觉语义，处理细致合理；
- **实验全面且分析深入**：覆盖多种 MLLM、多种编解码器、无线信道仿真、多维度消融，并对反直觉现象（如 32B 在 COCO Caption 上 CIDEr 低于 8B）进行了合理的定性解释。

### 8. 不足与局限

- **依赖类别标签**：文本嵌入表的构建需要训练数据集的类别名称与文本模板，这限制了适配器训练向无标签或开放域数据的推广；
- **受限于 L 类数据集**：语义对齐基于类粒度进行，对类内差异大、语义丰富的图像（如自然场景）对齐粒度可能不够精细；
- **COCO Caption 结果的解释困境**：32B 模型在 A-ImageTC 下 CIDEr 超越原始图像输入，作者解释为"更详细的描述不一定得分更高"，但这同时提示该指标可能不能完全反映真实视觉理解质量；
- **无线传输实验单一**：仅用 MME 一个 benchmark 验证无线场景，结论的普适性有待加强；
- **分离式数字传输的固有局限**：低 SNR 下性能急剧下降的"悬崖效应"仍然存在，论文未探索更鲁棒的联合信源信道编码方案；
