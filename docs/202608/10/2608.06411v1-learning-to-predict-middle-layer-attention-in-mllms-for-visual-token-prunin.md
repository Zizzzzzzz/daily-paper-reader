## 摘要
多模态大语言模型（MLLMs）在多种视觉-语言任务中表现出色，但其效率受到处理大量视觉token成本的限制。视觉token剪枝可以降低这一成本，但需要准确的token重要性估计。近期研究表明，来自语言模型中间层的文本到视觉注意力可以有效指导视觉token剪枝，通常使用预定义中间层的注意力来选择要保留的视觉token。因此存在两个问题。首先，我们的分析显示，其注意力对问题最敏感的层在不同样本间差异很大，使得固定层成为次优选择。其次，获取适当中间层的注意力需要将大量视觉token经过多个语言模型层处理，此时已经耗费了相当多的计算量。为解决这两个问题，我们提出了中层注意力预测（MAP），该方法使用问题对比教师选择（Question Contrastive Teacher Selection）通过对比原始和参考问题下的注意力来识别特定样本的教师层，并将选定层的注意力蒸馏到一个轻量级预测器中，该预测器从多模态输入特征估计视觉token重要性。在推理时，MAP将预测的重要性分数与多样性标准相结合，在第一个语言模型层之前剪枝视觉token。因此，MAP在剪枝时无需注意力图，并保持与现有推理加速技术的兼容性。在LLaVA-NeXT-7B的十个基准测试上，MAP仅使用5.56%的视觉token便保留了未剪枝模型97.5%的性能，实现了3.09倍的端到端加速。

## Abstract
Multimodal large language models (MLLMs) achieve strong performance across diverse vision-language tasks, but their efficiency is limited by the cost of processing numerous visual tokens. Visual token pruning can reduce this cost, but requires accurate token importance estimates. Recent studies have demonstrated that text-to-vision attention from middle language model layers can effectively guide visual token pruning, typically using attention from a predefined middle layer to select the visual tokens to retain. Two problems therefore remain. First, our analysis shows that the layer whose attention is most responsive to the question varies substantially across samples, making a fixed layer suboptimal. Second, obtaining attention from the appropriate middle layer requires processing numerous visual tokens through several language model layers, by which point considerable computation has already been spent. To address both problems, we propose Middle-layer Attention Prediction (MAP), which uses Question Contrastive Teacher Selection to identify a sample-specific teacher layer by contrasting attention under the original and reference questions, and distills attention from the selected layer into a lightweight predictor that estimates visual token importance from multi-modal input features. During inference, MAP combines the predicted importance scores with a diversity criterion to prune visual tokens before the first language model layer. Thus, MAP requires no attention maps for pruning and remains compatible with existing inference acceleration techniques. Across ten benchmarks on LLaVA-NeXT-7B, MAP retains 97.5% of the unpruned model performance with only 5.56% of the visual tokens, yielding a 3.09x end-to-end speedup.

- **研究意义**：本文旨在同时解决上述两个问题，在不牺牲性能的前提下显著提升 MLLM 推理效率，并保持与现有注意力加速内核（如 FlashAttention）的兼容性。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架
论文提出 **MAP（Middle-layer Attention Prediction，中层注意力预测）**，其核心思路是：在**离线训练阶段**，为每个训练样本自适应地选择最优教师层，并将该层的注意力分布蒸馏到一个**轻量级预测器**中；在**推理阶段**，该预测器直接从 LLM 处理之前的视觉和文本嵌入中预测视觉 token 的重要性，无需实际计算 LLM 的注意力图。

### 2.2 关键技术一：QCTS（Question Contrastive Teacher Selection，问题对比教师选择）
- **目的**：为每个样本动态地选择最能响应输入问题的教师层。
- **具体做法**：
  - 对同一图像，分别输入**原始问题**和**通用参考问题**（"What is shown in this image?"），提取每个 LLM 层的文本到视觉注意力分布。
  - 在每个层计算两个注意力分布的 Jensen-Shannon 散度（JS divergence）。JS 散度越大，说明该层的注意力被当前问题"重定向"的程度越高，即该层对问题越敏感。
  - 选择 JS 散度最大的层作为该样本的教师层：`l* = arg max_l D_JS(p_l || p_ref_l)`。
- **合理性**：参考问题不指向任何特定对象、属性或区域，提供了通用视觉注意力的基线，因此对比可以有效地量化问题对注意力的引导作用。

### 2.3 关键技术二：跨模态注意力蒸馏（Cross-Modal Attention Distillation）
- **预测器结构**：轻量级预测器包含两个模态特定的 MLP（`f_T` 和 `f_V`），分别变换文本和视觉表示，再通过 `W_Q` 和 `W_K` 投影为查询和键。在计算注意力分数前应用 RoPE 保留位置信息。预测的注意力分布通过 softmax 计算。
- **训练目标**：用 KL 散度最小化预测分布与教师分布之间的差异。训练时冻结原始 MLLM 的所有参数。

### 2.4 推理时的多样性感知剪枝（Inference-Time Token Pruning）
- 将预测的注意力分数作为视觉 token 的重要性分数。
- 先保留注意力分数最高的 K0 个 token 作为初始集合，剩余为候选集合。
- 采用**贪心迭代**策略，逐步从候选集中选择 token 加入保留集，选择标准为：
  `arg max_i [ 预测重要性分数 × 特征正交残差范数 ]`
- 维护一个由已选视觉嵌入构建的**正交基**，新的 token 在保留高重要性的同时，还需与现有子空间正交（即与已选 token 的特征互补），从而兼顾**问题相关性**和**特征多样性**。
- 剪枝在第一个 LLM 层之前完成，推理时无需任何注意力图，因此可以兼容 FlashAttention 等优化内核。

## 6. 主要结论与发现

- **中层注意力的有效性**：文本到视觉注意力在中间层对问题相关视觉证据的定位能力最强，早期层存在位置偏差，后期层区分度减弱。
- **最优层不固定**：不同样本、不同基准上，提供最强剪枝指导的层差异显著，固定中间层策略次优。
- **QCTS 的有效性**：通过问题对比选择的教师层在定位质量和剪枝效果上均优于单一固定层，接近 ROI-Max 上界。
- **MAP 的整体效果**：
  - 在 LLaVA-NeXT-7B 十个基准上，仅保留 5.56% 视觉 token（160/2880），保持 97.5% 的未剪枝性能，优于所有现有方法。
  - 在 Qwen2.5-VL-7B 上，保留 128 tokens（10%）时，相对性能 95.2%，显著优于基线（VisionZip 87.5%），优势大幅领先。
  - 在不同保留比例下均取得最佳的平均相对性能，且压缩越激进，优势越明显。
- **蒸馏的可行性**：轻量级预测器可以有效地从样本特定教师层中学习注意力分布，在 LLM 处理前准确估计 token 重要性，避免了推理时获取注意力图的开销。
- **多样性的价值**：特征多样性准则在 token 预算充裕时增益有限，但在高压缩比下能有效保留互补特征，显著提升性能。

## 7. 优点

- **问题发现深入**：通过严谨的实证分析揭示了两层被忽视的问题——最优层随样本变化、以及获取中间层注意力的固有成本，为指导后续研究提供了重要证据。
- **方案设计巧妙**：
  - QCTS 利用对比学习思想，在不依赖标注的情况下为每个样本自适应选择教师层，无需额外的标注信息。
  - 将"昂贵的中间层注意力"蒸馏为"廉价的预 LLM 预测"，从根本上绕开了效率困境，设计优雅。
- **工程实用性强**：推理时无需注意力图，与 FlashAttention 等优化内核兼容，实际部署价值高。
- **实验扎实全面**：覆盖模型范围广（3 个骨干）、基准数量多（10+）、压缩比例跨度大（从 22.2% 到 5.56%），充分验证了方法的鲁棒性。
- **结果优异**：在多种设置下均显著优于现有方法，特别是在高压缩比下保持性能的能力突出。

## 8. 不足与局限

- **训练阶段仍有较高成本**：离线训练需要为每个样本运行完整的 MLLM 前向传播（含原始问题和参考问题各一次），还需要存储和计算所有层的注意力分布，数据准备过程的开销不容忽视。
- **参考问题的选择敏感**：QCTS 依赖固定的通用参考问题（"What is shown in this image?"），该问题的措辞可能对某些领域（如医疗、科学图表）产生不同的注意力基线，其通用性未经验证。
- **分析范围有限**：层分析实验仅基于 GQA 数据集和 LLaVA 系列模型，对于其他模型架构（如 Qwen2.5-VL 的更深层）中注意力的层间特性未做深入分析。
- **预测器存在信息瓶颈**：预 LLM 的表示是否在所有情况下都能充分编码回答问题所需的细粒度视觉语义，存在不确定性（论文未单独分析预测器与真实注意力的吻合度）。
- **多样性选择的计算开销**：贪心正交化过程在 token 数量多时可能引入额外的选择延迟，论文未提供该过程的单独耗时分解。
- **缺少更长上下文和视频任务验证**：当前实验集中在静态图像的任务上，未验证在视频理解等更长序列场景中的有效性。
- **未报告训练细节**：训练数据的规模、来源、与评测基准的关系（是否存在数据泄漏风险）等重要信息未披露。
