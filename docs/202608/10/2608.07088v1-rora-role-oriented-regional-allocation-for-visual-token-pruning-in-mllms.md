## 摘要
多模态大语言模型（MLLMs）将图像编码为长视觉令牌序列，导致预填充和KV缓存存储成本高昂。现有的免训练剪枝方法根据重要性、多样性或空间覆盖度选择令牌，但将保留的令牌视为可互换的，并未显式跟踪哪些与对象相关的区域已被覆盖。我们提出RoRA，一个免训练框架，将视觉令牌剪枝视为面向角色的区域证据分配。给定固定预算，RoRA将令牌划分为受保护语义核心、互补上下文和细粒度细节。它首先通过位置先验和提示校准的对象先验校准文本条件注意力，然后从高置信度锚点构建注意力锚定区域（AARs），作为已覆盖对象支持的轻量级代理。上下文主要在AARs之外探索，而一个小的AAR引导预算恢复局部细节；成对相似性仅用于上下文阶段的冗余过滤。在匹配预算下，RoRA在LLaVA和Qwen-VL系列中持续优于强免训练基线，即使在激进剪枝比例下也能保留大部分未剪枝准确率，例如在LLaVA-1.5上以88.9%的剪枝比例保持96.5%的完整性能，并在Qwen3-VL上以75-90%的剪枝比例相比D2Pruner提升约5%。在66.7%剪枝比例下，RoRA仅需0.7毫秒进行令牌选择，并将端到端推理时间减少24.6%，对应在NVIDIA H800上相比未剪枝推理实现1.33倍加速。

## Abstract
Multimodal large language models (MLLMs) encode images as long visual token sequences, making prefilling and KV-cache storage expensive. Existing training-free pruning methods select tokens by importance, diversity, or spatial coverage, but treat retained tokens as interchangeable and do not explicitly track which object-related regions are already covered. We present RoRA, a training-free framework that casts visual token pruning as role-oriented regional evidence allocation. Given a fixed budget, RoRA partitions tokens into a protected semantic core, complementary context, and fine-grained detail. It first calibrates text-conditioned attention with a positional prior and a prompt-calibrated object prior, then builds Attention-Anchored Regions (AARs) from high-confidence anchors as lightweight proxies for covered object support. Context is explored mainly outside AARs, while a small AAR-guided budget restores local detail; pairwise similarity is used only for context-stage redundancy filtering. Under matched budgets, RoRA consistently outperforms strong training-free baselines across LLaVA and Qwen-VL families, retaining most of the unpruned accuracy even at aggressive pruning ratios, e.g., 96.5% of full performance at 88.9% pruning on LLaVA-1.5, and improving over D2Pruner by about 5% on Qwen3-VL at 75-90% pruning. At a 66.7% pruning ratio, RoRA requires only 0.7 ms for token selection and reduces end-to-end inference time by 24.6%, corresponding to a 1.33x speedup over unpruned inference on an NVIDIA H800.

## 1. 核心问题与研究动机

- **背景问题**：多模态大语言模型（MLLMs）将图像编码为长序列视觉令牌，高分辨率图像、多图输入和视频可产生数百至数千个令牌，导致 LLM 层的预填充（prefill）开销、KV 缓存大小和推理延迟显著增加。
- **现有方法的不足**：
  - **注意力偏置问题**：FastV 等基于原始文本条件注意力的方法受位置偏置影响，令牌集中于图像边缘等系统性热点，而非真正的语义区域。
  - **语义角色缺失**：现有方法（如 DART 的多样性选择、HoloV 的 crop-wise 配额分配）虽改善了空间覆盖，却未显式区分保留令牌的语义角色，导致预算可能被分配到高方差但任务无关区域（如观众、纹理丰富的边缘）。
  - **结构感知不足**：D2Pruner 通过去偏注意力加全对相似度图建模冗余，但全图成对计算昂贵且缺乏结构感知，未显式追踪哪些对象区域已被覆盖。
- **核心论点**：回答多模态查询通常需要三种互补的视觉证据——**核心对象**（锁定查询目标）、**互补上下文**（场景、次要对象、关系）、**细粒度细节**（文字、边界、小物体）。现有方法用单一同质标准或忽略对象覆盖的 crop 配额进行分配，无法刻意保留全部三种证据。
- **研究目标**：提出一种免训练、即插即用的视觉令牌剪枝框架，在固定保留预算下实现角色感知的区域证据分配，兼顾精度与效率。

## 2. 方法论：RoRA 框架

### 2.1 核心思想

RoRA 将视觉令牌剪枝形式化为**角色导向的区域证据分配**问题，将保留令牌预算显式分解为三个不相交的角色集合：

```
S = P ∪̇ C ∪̇ D ，  Kp + Kc + Kd = K
```

- **P（语义核心）**：保护查询所需的主要对象证据；
- **C（互补上下文）**：覆盖核心外部的次要对象、空间关系和场景背景；
- **D（细粒度细节）**：恢复文字、小型物体、边界和局部纹理等细节。

### 2.2 关键技术细节与流程

#### 阶段一：对象校准的注意力与核心保护

- **位置先验校准**：从 GQA 训练集中采样 1,000 张无标注图像，用通用提示（“Please describe the image.”）估计模型的位置偏置先验 `b_i`；用对象检查提示（“List all visible objects in the image.”）获得弱对象感知先验 `o_i`。
- **校准分数**：

  ```
  r_i = Norm(a_i / (b_i + ε))
  p_i = Norm(r_i + λ_obj · o_i)
  ```

  - 其中 `a_i` 为原始注意力分数，`λ_obj` 为对象先验强度系数（设为较小值，保证样本特异性注意力仍占主导）。
- **语义核心选择**：选取 `p_i` 最高的 `Kp` 个令牌构成保护集 P，这些令牌不再参与后续阶段候选池。

#### 阶段二：注意力锚定区域（AAR）与互补上下文分配

- **AAR 构建**：选取 `Ma` 个高置信度令牌作为空间锚点，在二维令牌网格上以其为中心、半径 `ra` 展开局部邻域，所有锚点邻域的并集构成 AAR：

  ```
  A = TopK_Ma({p_i})
  R_AAR = ∪_{a∈A} N_ra(a)
  ```

- **上下文评分**：AAR 外的令牌获得探索加分，促进预算覆盖未被核心覆盖的空间证据：

  ```
  c_i = Norm(p_i + λ_ctx · I[i ∉ R_AAR])
  ```

- **轻量冗余过滤**：仅在此阶段使用成对相似度，若候选令牌与已保留令牌的余弦相似度超过阈值 `τ_sem` 则跳过，避免重复证据消耗预算：

  ```
  C = Select_{τ_sem, Kc}({c_i | i ∉ P})
  ```

#### 阶段三：AAR 引导的细节修复

- **细节分数**由三部分加权组成加上 AAR 内加分：

  ```
  d_i = ω_a·â_i + ω_m·m̂_i + ω_l·ℓ̂_i + λ_det·η_i
  ```

  - `â_i`：归一化的注意力响应；
  - `m̂_i`：归一化的特征范数 `‖h_i‖₂`；
  - `ℓ̂_i`：归一化的局部对比度，即令牌与其 8 邻域令牌的平均特征差异；
  - `η_i`：AAR 指示器（在 AAR 内为 1，否则为 0）。

- **最终保留集**：从未被分配至核心或上下文的令牌中，选择 `d_i` 最高的 `Kd` 个令牌构成细节集 D，三者并集形成最终保留令牌序列。

#### 算法复杂度

- RoRA 在语义核心固定后仅对剩余候选进行冗余过滤，复杂度为 `O(N + N_t²)`，远低于 D2Pruner 的 `O(N²)` 全图相似度计算，与 HoloV 的 `O(N²/C)` 相当。

## 6. 主要结论与发现

1. **角色分配优于同质标准**：将令牌划分为语义核心/上下文的角色感知分配，显著优于基于单一重要性/多样性准则的分配方式；在 RefCOCO 定位任务上，仅引入语义核心保护即将归一化准确率从 35.44% 提升到 74.44%（K=144）。
2. **AAR 有效改善覆盖**：AAR 引导的上下文探索在定位子集上进一步提升准确率（7/8 个子集提升，无退化）。
3. **细节修复带来稳定而温和的提升**：在 TextVQA/VizWiz 上，加入细节令牌使平均归一化分数从 101.61% 逐步提升至 101.94%，验证了其作为小预算补充模块的设计初衷。
4. **精度-效率优势**：LLaVA-1.5 上 66.7% 剪枝时仅为 0.7ms 选择开销，同时保持 98.4% 的 POPE 性能；LLaVA-NeXT 上 90% 剪枝时在 POPE 上保持 88.01% 的准确率，预填充加速 2.00×。
5. **跨模型泛化**：RoRA 在从 LLaVA（较低分辨率静态令牌）到 Qwen-VL（动态分辨率高令牌数）的各类骨干上均获得最佳或接近最佳的归一化平均性能。

## 7. 方法亮点

- **角色化分配的新视角**：超越“重要性排序”范式，将视觉证据按功能角色显式分层分配，逻辑清晰、动机充分。
- **轻量 AAR 结构建模**：用锚点邻域局部区域近似对象覆盖，免去 D2Pruner 式的全图稠密相似图，计算开销极低。
- **双层先验校准**：同时利用位置先验（消除系统性偏置）和提示校准对象先验（温和引导对象关注），且将对象先验设计为弱正则化项，保留泛化性。
- **不对称预算策略**：AAR 外探索上下文（扩展覆盖）、AAR 内恢复细节（补充局部），区域指导与角色目标对齐。
- **严格公平评估**：固定配置共享，不使用 benchmark 特调；效率数据使用官方开源实现，同一 GPU 环境对比，具有可复现性。

## 8. 不足与局限

- **评估偏差风险**：Qwen2.5-VL 上 FastV/D2Pruner 等基线出现 >100% 的归一化分数，说明某些 benchmark 上剪枝反而提升性能的现象，但论文对这类“超上界”现象缺乏系统解释；RoRA 的优势可能存在任务依赖。
- **细节模块增益有限**：细节修复带来的准确率改进相对温和（≤0.4 个百分点），其必要性需在更广泛基准上验证。
- **校准数据适用性**：位置/对象先验仅从 GQA 图像估计，跨域（如文档图像、医学影像、图表）的泛化能力未验证。
- **应用限制**：在超长视频或多图场景中，AAR 的 2D 网格假设可能失效；与流式生成/批处理场景的集成方式未讨论。
