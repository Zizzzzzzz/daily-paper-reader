## 摘要
视觉-语言-动作（VLA）模型在机器人操作领域日益展现出应用潜力，然而其实际部署仍受限于高昂的推理延迟和不稳定的异步执行。这一挑战在基于流匹配的VLA模型中尤为突出，因为动作解码需要基于VLM上下文进行多次迭代步骤。虽然高效推理方法能提高控制频率，异步方法能减少执行空闲时间，但现有方法往往无法同时实现低延迟推理和精确、时间上一致的异步执行。我们提出了\textbf{FlashVLA}，一个流式动作解码框架，以统一的形式解决这两个挑战。FlashVLA维护一个包含多个不同噪声水平块的流式动作缓冲区，并使用逐块因果注意力对其进行解码。这一设计使FlashVLA能够在每次推理步骤中生成一个可执行的动作块。此外，其逐块自回归形式隐含地保留了动作连续性，使得无需额外未来状态条件即可实现平滑的异步执行。在大量仿真和真实世界实验中，FlashVLA显著提高了推理速度，同时保持了强大的任务性能。在单GPU上可实现$\geq$30\,Hz的控制频率，并在实际部署中实现平滑的异步推理。

## Abstract
Vision-Language-Action (VLA) models are increasingly promising for robotic manipulation, yet their real-world deployment remains bottlenecked by high inference latency and unstable asynchronous execution. This challenge is particularly pronounced in flow-matching-based VLA models, where action decoding requires multiple iterative steps conditioned on the VLM context. While efficient inference methods improve control frequency and asynchronous methods reduce execution idle time, existing approaches often fail to jointly achieve low-latency inference and accurate, temporally consistent asynchronous execution. We introduce \textbf{FlashVLA}, a streaming action decoding framework that addresses both challenges in a unified formulation. FlashVLA maintains a streaming action buffer with multiple chunks at different noise levels and decodes them using chunk-wise causal attention. This design allows FlashVLA to produce one executable action chunk per inference step. Moreover, its chunk-wise autoregressive formulation implicitly preserves action continuity, enabling smooth asynchronous execution without extra future-state conditioning. Across extensive simulated and real-world experiments, FlashVLA substantially improves inference speed while maintaining strong task performance. It can achieve $\geq$30\,Hz control frequency on a single GPU with smooth asynchronous inference in real-world deployment.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 视觉-语言-动作（VLA）模型将视觉观察和语言指令直接映射为机器人动作，已成为端到端机器人操作的主流范式，如π0.5等模型展现出强大的泛化能力。
- 然而，VLA模型实际部署面临两大核心瓶颈：
  - **高推理延迟**：以π0.5为例，动作解码单独消耗了每步推理时间的75%，根源在于每个动作块需要10次顺序去噪步骤（在RTX 4090上测量，双视角输入）。
  - **异步执行不稳定**：同步推理在每个块边界停滞，而异步推理虽能重叠预测与执行，但存在观测陈旧导致的预测-执行时间错配问题（模型预测时基于旧观测，动作到达时机器人已处于模型未见过的状态）。
- **现有方法的不足**：高效推理方法（轻量架构、压缩、token剪枝）只降低单步延迟，仍保留迭代解码循环；异步方法（未来状态条件、动作条件化）只修补错配问题，且补丁成本随前瞻步长增加而增长。两类方法各自为战，无法同时解决延迟和错配问题。
- **核心洞察**：两个失败模式共享同一根源——**流匹配VLA孤立地解码每个动作块**（从纯噪声开始，仅以当前观测为条件，与进行中的块解耦）。这种孤立设计既把全部去噪步骤集中到单次块解码中（延迟成本），又使新块对即将加入的轨迹一无所知（错配成本）。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
将"孤立解码"改为"联合解码"：维护一个包含多个不同噪声水平动作块的流式缓冲区，通过块级因果注意力（chunk-wise causal attention）联合推进所有块的去噪进度，每个推理步骤产出一个可执行动作块，从而同时消除延迟成本和错配成本。

### 关键技术细节

**（1）流式缓冲区与噪声阶梯（§3.1）**

- 维护N个块，固定在阶梯状噪声水平：$B_t = [x^{(1)}_{\tau_1}, x^{(2)}_{\tau_2}, \ldots, x^{(N)}_{\tau_N}]$，其中 $\tau_1 < \tau_2 < \cdots < \tau_N$。
- 噪声水平单调递增的阶梯设计同时对应去噪进度和执行顺序：最干净的块最先执行，纯噪声块最后执行。
- 噪声采样使用带扰动的均匀分布：$\tau_i = 0.001 + 0.999 \cdot \frac{i-1+u_i}{N}$，$u_i \sim \text{Beta}(1.5, 1.0)$。

**（2）块级因果注意力**

- 较嘈杂（较晚）的块可以关注较干净（较早）的块，但反向不允许。
- 信息流在时间上前向传播，不在噪声上后向传播，保证自然的时间因果方向。
- 这一设计带来三个运行属性：
  - **摊销去噪**：每个块经过N个噪声水平的所有N次前向传播，但分布在N个不同推理步中，每步仅一次前向，每步产出一个可执行块。测得的墙钟加速达19.9×（十步到一步的GPU工作量减少9.3×，加上消除内核启动序列化）。
  - **隐式异步条件**：未来块关注近执行块，自动获得即将加入轨迹的条件信息，无需显式未来状态预测器。
  - **块级记忆**：每个高时间步块关注缓冲区中所有更早块，形成短期结构化历史，解释了长时任务上的显著增益。

**（3）流式推理算法（§3.2）**

- **冷启动阶段**：缓冲区初始为空，用N−1个填充块和一个高斯噪声样本初始化，运行N−1次前向填充缓冲区；期间机器人执行安全默认动作（初始关节状态或归一化零动作），保持静止。冷启动开销每幕仅支付一次，在多秒rollout中摊销。
- **稳态流式阶段**：作为队列运行——每步（i）推进所有块一个去噪步，（ii）弹出最干净块执行，（iii）剩余块前移，（iv）尾部追加新的纯噪声块。
- **系统级优化**：CUDA Graph编译（更快调度且异步非阻塞）、线性层打包减少内核启动开销、PyTorch max-autotune编译消除内核气泡。

**（4）多缓冲联合微调（§3.3）**

- 预训练VLA从未见过部分填充的缓冲区或块级因果注意力模式，需要适配。
- 对单一观测$o_t$，冷启动过程暴露N种不同缓冲区配置（j个真实动作块 + N−j个填充块）。
- **打包方案**：将所有N种配置打包进单个训练样本，共享同一观测编码，用注意力掩码隔离各配置。观测编码只计算一次，大幅提升微调效率。
- 联合损失函数（式3）：$L_{joint} = \sum_{j=1}^{N}\sum_{i=1}^{j} \mathbb{E}_{\tau_i,z_i}\left[\left\|v_\theta(x^{(i)}_{\tau_i}, \tau_i | o_t, B^{(j)}_t) - (z_i - a^{(i)})\right\|_2^2\right]$
- 该目标同时覆盖冷启动和稳态行为：模型学习在任何噪声水平、任何有效缓冲区前缀条件下去噪。
- 架构改动：在动作专家中使用FiLM增强多级时间步条件；对SmolVLA额外添加time-MLP和FiLM层。

## 6. 主要结论与发现

1. **联合解码显著加速**：FlashVLA将每步动作解码延迟降低最多20×（GPU工作量减少9.3× + 消除内核启动序列化），端到端每动作加速最高2.43×。
2. **异步连续性无损恢复**：块级因果注意力隐式保留了轨迹连续性，无需显式未来状态预测器。在d=1~4异步延迟下，LIBERO成功率保持97.5-98.3%，始终高于同步π0.5（96.9%）；对照的VLASH在d=4时降至93.1%。
3. **长时任务增益显著**：RoboTwin 2.0长时任务成功率从53.0%提升至89.6%（+36.6点）；LIBERO-Long从92.4%提升至96.2%（+3.8点）。增益随任务horizon增长而增大，验证了块级记忆的作用。
4. **跨架构可迁移**：SmolVLA推理延迟1.95×加速（成功率保持），LingBot-VLA 2.81×加速且成功率提升3.4-4.1点。
5. **真实世界可行**：在RTX A4000上推理延迟67.3 ms（约两个30 Hz控制周期），通过两步异步延迟实现30 Hz平滑控制；任务得分超越所有π0.5配置，完成时间平均加速1.3×。
6. **因果注意力是核心成分**：移除因果掩码导致异步成功率下降约10个百分点，证明流式缓冲区本身不足，因果注意力才是异步连续性的关键。

## 7. 优点

- **即插即用**：作为流匹配VLA的drop-in修改，只需轻量架构改动和一次微调，跨架构泛化验证充分（π0.5、SmolVLA、LingBot-VLA）。

- **仅适用于流匹配VLA**：方法专为流匹配动作专家设计，对扩散模型或其他动作解码架构的适用性未涉及。
- **需要微调而非零样本适配**：依赖多缓冲联合微调，无法直接应用于现成的预训练VLA权重。
