## 摘要
事件相机生成异步、高频的数据流，以比传统相机更低的延迟提供空间稀疏信息。原则上，这些特性应该是控制策略设计的理想选择。然而，该领域的强化学习研究仍然有限，因为现有方法未能充分利用传感器的特性。基于CNN的方法通过将事件聚合为稀疏网格，抵消了传感器的优势，这导致计算成本与传感器分辨率耦合，并使时间信息模糊。同时，现有的生成式基线依赖于轨迹数据的可用性来预训练模型。我们提出了FLEET（通过高效令牌化从事件中学习特征），一种直接处理事件序列的特征提取器。利用随机傅里叶特征和交叉注意力，我们的架构将可变流压缩为固定大小的潜在表示。这将特征提取器骨干网络的推理成本与传感器分辨率解耦，使得无需辅助损失即可进行端到端学习。我们在一个新的高通量基准上验证了FLEET。结果表明，我们基于序列的方法超越了最先进的性能，并对观测频率的变化表现出优越的鲁棒性。

## Abstract
Event cameras generate asynchronous, high-frequency data streams offering spatially sparse information at lower latency than traditional cameras.In principle, these properties should be ideal for the design of control policies.However, reinforcement learning research in this field remains limited as existing approaches fail to fully exploit the sensor's properties.CNN-based methods negate the sensors benefits by aggregating events into sparse grids. This couples compute cost to sensor resolution and blurs the temporal information. Meanwhile, existing generative baselines rely on the availability of trajectory data to pretrain the model. We propose FLEET (Feature Learning from Events via Efficient Tokenization), a feature extractor that processes event sequences directly. Leveraging random Fourier features and cross-attention, our architecture compresses variable streams into fixed-size latent representations. This decouples inference cost of the feature extractor's backbone from the sensor's resolution, enabling end-to-end learning without auxiliary losses. We validate FLEET on a new, high-throughput benchmark. The results demonstrate that our sequence-based approach surpasses SOTA performance and exhibits superior robustness to variations in observation frequencies.

## 论文总结：FLEET——基于事件相机的强化学习令牌化特征提取

### 1. 核心问题与整体含义（研究动机与背景）

事件相机与传统帧式相机截然不同，它以**异步、微秒级延迟**的方式响应像素级亮度变化，输出空间稀疏但时间精度极高的数据流。在原理上，这些属性（低延迟、高动态范围、低带宽）非常契合机器人控制和自动驾驶等时间关键型任务，应当是强化学习（RL）策略学习中的理想传感器。

然而，现有事件相机 + RL 的研究未能充分利用传感​​器的潜力，面临两大核心矛盾：

- **CNN 网格化范式的失配**：主流方法将事件流聚合为稀疏时空张量（如 RVT），这带来双重问题。其一，计算成本与传感器分辨率耦合（分辨率越高，张量越庞大），而非与信息量成正比；其二，聚合过程本身会引入时间模糊，破坏事件数据最宝贵的时间精度，尤其在低控制频率下更严重。
- **生成式预训练的缺陷**：以 eVAE 为代表的两阶段方法依赖离线轨迹数据预训练自编码器，其重建损失逼迫模型编码"视觉保真度"而非"控制相关特征"，导致目标错位。同时，预训练数据分布与部署环境之间的分布偏移也会严重损害模型在真实控制中的表现。

因此，核心问题是：**是否存在一种轻量级、端到端可训练的架构，能够在 RL 循环中直接处理原始事件序列，而不依赖网格聚合或辅助预训练？**

### 2. 论文提出的方法论

#### 2.1 总体思路

FLEET（Feature Learning from Events via Efficient Tokenization）是一种序列化、令牌化的事件处理流水线，直接作用在原始事件序列上，输出固定长度的潜表示，供标准 PPO 智能体使用。核心设计目标是**将特征提取骨干的计算成本与传感器的空间分辨率彻底解耦**。

#### 2.2 关键技术细节

- **事件序列采样（Event Sequence Sampling）**：
  原始事件流长度 D 可变，为保证 JAX 固定形状需求，将事件流等分为 M 个时间箱，每箱随机抽取 1 个事件，得到长度为 M 的固定批次。事件不足时补零并掩码。

- **随机傅里叶特征（Random Fourier Features，RFF）编码**：
  坐标（时间和空间）分别映射为高频特征以克服 MLP 的谱偏置问题。公式为：
  \[
  \text{RFF}(x) = [\sin(\pi x B), \cos(\pi x B)]
  \]
  其中 \(B \sim \mathcal{N}(0, \sigma^2)\)。选取较小的 \(\sigma_{\text{temporal}}\) 与较大的 \(\sigma_{\text{spatial}}\)。

- **时空调制门控（Temporal Gating）**：
  空间 RFF 嵌入被时间 RFF 嵌入经线性投影 + Sigmoid 的门控向量逐元素调制：
  \[
  z_k = \text{RFF}(u_k) \otimes \text{sigmoid}(W_{\text{gate}}\text{RFF}(t_k) + b_{\text{gate}})
  \]

- **交叉注意力压缩（Perceiver-style Cross-Attention）**：
  将嵌入后的事件序列作为 K/V，N 个可学习潜令牌作为 Q，通过多头交叉注意力 + 掩码 softmax，将长序列压缩为固定 N 个令牌。该模块复杂度为 \(O(NM)\)，N 远小于 M，实现维度压缩。

- **骨干与 RL 集成**：
  N 个令牌经三层的 MLP 编码器后，通过全局平均池化成单一特征向量。特征提取器由 Actor 和 Critic 共享，但对 Actor 输入施加**停止梯度（stop-gradient）**，只通过 Critic 的价值函数损失（TD 误差）驱动表征学习，避免 Actor-Critic 目标冲突。

### 6. 主要结论与发现

1. **综合性能**：FLEET 在所有三个环境中全面超越所有事件基线方法。Racing 场景中最佳基线（DMRCNN）仅达到 FLEET 的 27%；FLEET 甚至超过 RGB 变体 50%。
2. **分辨率不变性**：FLEET 在传感器分辨率从 96×64 提升至 384×256 时性能几乎恒定（约 40-47 分），而 CNN 方法虽然部分在中分辨率下略有提升，但计算成本呈二次方增长。
3. **频率鲁棒性**：当控制频率提高（\(\Delta t\) 从 0.1 降至 0.025）时，CNN 基线的性能急剧下降，而 FLEET 保持稳定。这归因于事件序列处理天然保留了时间精度，而网格聚合在高频下变得极度稀疏。
4. **计算解耦**：FLEET 的计算成本固定为 83.28 GFLOPs、4.09 GB VRAM、11.76 ms，完全不随分辨率变化。在 384×256 下，FLEET 仅需 DMRCNN 8% 的算力和 NatureCNN 3% 的算力，执行速度快 300-400 倍。
5. **注意力可解释性**：不同潜令牌自发地专门化——有的聚焦于近距离边界，有的追踪远处动态，有的联合关注对角区域以感知赛道曲率，形成层级感受野。
6. **端到端 vs. 预训练**：训练纯粹由 RL 奖励信号驱动，不需要离线演示或辅助重建损失，成功规避了目标错位和分布偏移问题。

### 7. 优点

- **架构设计优雅**：利用 Perceiver 风格交叉注意力实现序列压缩，\(\mathcal{O}(NM)\) 复杂度远低于自注意力的 \(\mathcal{O}(M^2)\)，在技术思路上简洁且高效。
- **计算成本与分辨率完全解耦**：将特征提取的算力需求从传感器分辨率中解放出来，这对真实世界高分辨率事件相机（如 1MP 传感器）的部署具有重要意义。
- **避免目标错位**：纯端到端 RL 信号驱动，不做重建或对比辅助损失，表征直接对齐控制目标。
- **时间信息零损失**：直接处理事件序列，不做网格化时间分箱，保留了事件相机最重要的时间精度。
- **学术严谨性**：使用 IQM + 95% CI 作为评估指标，同 RL 社区的标准实践一致，统计意义可靠；代码开源，复现门槛低。
- **应用导向的基准构建**：自建高通量 Event-CarEnv 允许快速迭代，填补了事件 RL 领域缺少快速仿真基准的空白。

### 8. 不足与局限

- **仿真到现实的鸿沟**：所有实验均基于仿真环境，事件数据由模拟器（ESIM 风格随机阈值法）生成，与真实事件传感器的噪声特性、时滞、带宽限制存在差异。论文在结论中也承认这是实际部署前必须克服的障碍。
- **计算效率声称存在限定**：FLEET 的 GFLOPs 在最低分辨率下反而高于 DMRCNN（83 vs. 47 GFLOPs），其优势主要体现在推理速度（得益于矩阵乘法的硬件友好性）和高分辨率扩展性。若只关心低分辨率场景，效率优势相对有限。
- **消融实验覆盖不足**：所有消融实验仅在 Racing 一个环境中完成，没有在 Parking 或 IDP 上验证组件的普遍有效性。
- **基线对比公平性存疑**：
  - eVAE 使用随机 rollouts 预训练，其效果差部分源于预训练数据质量，而非表征方法的理论缺陷；
  - LFF-DS 被"修改"为包含 FLEET 的归一化与时间门控，使其无法代表原始方法的完整效果；
  - DMRCNN 的原始论文使用不同的 RL 框架（DeepMDP），此处仅在 PPO 中评估，可能未完全发挥其潜力。
- **固定序列长度与信息丢弃**：在事件非常密集的场景中，随机采样会丢弃大量事件，尽管分层策略缓解了时间盲区，但没有自适应地依据场景信息量调整采样密度。
- **未验证可扩展性**：没有在更高维动作空间或更复杂任务（如多智能体、交互式驾驶）中验证 FLEET 的适用性。
- **实现依赖性能疑问**：论文提到需要固定输入大小以利用 JAX 加速，这限制了模型在事件真正批量异步到达时的处理灵活性，可能削弱事件相机异步特性的优势。
