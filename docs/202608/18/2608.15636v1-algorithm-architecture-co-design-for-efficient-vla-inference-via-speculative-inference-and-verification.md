## 摘要
视觉-语言-动作（VLA）模型在具身人工智能领域展示了卓越的能力，但其高计算成本和受限的预测动作长度阻碍了实时部署。尽管已经引入了专为高效具身AI设计的加速器Dadu-Corki，但它并未利用机器人与其环境之间固有的交互模式，导致预测动作长度相对较短。我们观察到，机器人环境自然地在主动状态（精确动作至关重要）和被动状态（动作对任务成功影响有限）之间交替。这一洞察带来了新的调度机会：在被动状态下进行长动作长度的推测性预测，并在主动状态下进行选择性验证。我们提出了SpecVLA，一种算法-系统协同设计框架，能够自适应地平衡动作长度、推理延迟和任务可靠性。在算法方面，SpecVLA引入了一种状态感知的VLA推理执行范式，并利用差分残差和块级混合精度量化，构建了一种硬件友好的小型验证模型（sVLA）。在系统方面，我们开发了一个异构架构，由GPU和机器人专用硬件模块组成，并设计了推测性数据流，通过并行执行将VLA和sVLA解耦。在LIBERO和ManiSkill基准上对OpenVLA和RDT的全面评估表明，SpecVLA在保持任务成功率的同时显著降低了端到端延迟。通过实现及时验证的长动作长度推测性预测，SpecVLA实现了既高效又可靠的实时机器人操作。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities in the field of embodied AI, but their high computational cost and limited predicted action length hinder real-time deployment. Although Dadu-Corki, a dedicated accelerator for efficient embodied AI, has been introduced, it does not exploit the inherent interaction patterns between the robot and its environment, which results in a relatively short predicted action length. We observe that robotic environments naturally alternate between active states-where precise actions are crucial-and inactive states-where actions have limited impact on task success. This insight enables a new scheduling opportunity: long-action-length speculative prediction in inactive states, paired with selective verification in active states.   We propose SpecVLA, an algorithm-system co-design framework that adaptively balances action length, inference latency, and task reliability. On the algorithm side, SpecVLA introduces a state-aware VLA inference execution paradigm and a hardware-friendly construction of a smaller verification model (sVLA) using differential residuals and block-wise mixed-precision quantization. On the system side, we develop a heterogeneous architecture consisting of a GPU and a robotic-specific hardware module, along with a speculative dataflow that decouples VLA and sVLA through parallel execution. Comprehensive evaluations on OpenVLA and RDT across LIBERO and ManiSkill benchmarks show that SpecVLA reduces end-to-end latency significantly while preserving task success rate. By enabling long-action-length speculative prediction with timely verification, SpecVLA achieves real-time robotic manipulation with both high efficiency and reliability.

## 2. 论文提出的方法论（核心思想、关键技术细节、公式或算法流程）

### 2.1 总体框架：SpecVLA推测-验证执行范式

- **基本流程**：
  - **非活跃状态**：直接用VLA预测长动作序列（如8个动作），跳过验证，直接执行以摊销推理成本。
  - **活跃状态**：VLA推测长序列，但在每个动作执行前调用sVLA生成期望动作（Expected Action），比较预测动作与期望动作的相似度；若差异过大则触发回滚（rollback）并重新调用VLA生成新序列。
- **动作验证指标**：采用**加权L1距离**（weighted L1 distance）。先对每个动作维度做min-max归一化，再对7维动作（3维位置 + 3维旋转 + 1维夹爪）按方差的倒数赋权：
  - 归一化：$$\tilde{A}[k] = \frac{A[k] - A_{low}[k]}{A_{high}[k] - A_{low}[k]}$$
  - 加权L1距离：$$L_1(\tilde{A}, \tilde{A}') = \sum_{k=1}^{7} w[k] \times |\tilde{A}[k] - \tilde{A}'[k]|, \quad w[k] = \frac{1}{\sigma[k]}$$
  - 距离低于阈值 $T_s$ 则接受动作，否则拒绝并回滚。

### 2.2 环境状态预测算法（Algorithm 1）

- **输入**：机械臂状态 $G_s$、物体坐标集合 $\{O_c\}$、机械臂坐标 $G_c$、距离阈值 $T_d$。
- **判定逻辑**：
  1. 计算机械臂与每个物体的欧氏距离 $D_i$；
  2. 若存在物体距离 $\leq T_d$，则计数 $n$ 加1；
  3. 若机械臂处于打开状态（$G_s = -1$）且 $n < 1$，判定为**非活跃状态**；否则判定为**活跃状态**。
- **作用**：动态决定当前周期是否需要对每个预测动作进行sVLA验证。

### 2.3 sVLA的构建：基于差分残差与块级混合精度量化

- **差分残差计算**：$\Delta X_i = X_i - X_{i-1}$（相邻帧特征相减），残差分布更窄（如图3所示），更适合低比特量化。
- **块级量化策略**（硬件友好）：
  - 将残差矩阵划分为固定大小的块；
  - 对每个块求和绝对值，与两个阈值 $T_z$ 和 $T_h$ 比较：
    - 和 $< T_z$：块置为0（0-bit，零块直接删除）；
    - 和 $> T_h$：重要块，采用高精度（8-bit）；
    - 介于两者之间：低精度（4-bit）。
  - 高精度块进一步分解为低比特块和高比特块，统一数据路径，简化硬件控制。
  - 零块被压缩移除，减少计算量。
- **量化与累积**：量化后的残差与权重相乘得到残差输出，再与上一时间步的输出累加，逐层处理。

### 2.4 推测性数据流与异构架构

- **核心问题**：VLA与sVLA之间存在数据依赖（sVLA验证需依赖VLA的预测结果），串行执行会抵消理论加速收益。
- **推测数据流**：让VLA**推测性地提前执行**下一轮预测，无需等待当前sVLA验证结果；若验证通过则提前终止（terminate）当前GPU上的VLA任务，若验证失败则继续完成剩余VLA计算。
- **异构硬件模块**：
  - **GPU**：执行全精度VLA推理。
  - **机器人专用硬件模块**（含三个子模块）：
    - **SIMD PE阵列**：基于块分裂策略统一精度，支持低精度块级矩阵乘法，通过硬连线移位共享块数据，减少缓冲区带宽压力；
    - **状态预测器（State Predictor）**：通过可重构数据路径同时支持**环境状态预测**（欧氏距离）和**动作验证**（加权L1距离），共享减法器组、加法树、比较器等硬件单元；
    - **预处理模块**：将残差生成、块级量化与块标签生成集成在单一流水线中，消除中间数据搬运。

## 7. 优点

- **算法-架构协同设计**：不仅提出了算法层面的推测执行范式，还针对算法设计了专用硬件（可重构状态预测器、块级量化的预处理模块），实现了软硬件深度协同。
- **利用时间冗余的新视角**：不同于现有压缩方法（空间剪枝、层跳过等），通过差分残差和状态感知的推测执行，在保留模型表达能力的同时减少计算，思路新颖。
- **硬件设计上的精巧复用**：环境状态预测和动作验证共用同一距离计算数据路径，通过重构模式减少面积开销，体现了高效的硬件设计理念。
- **验证机制增强鲁棒性**：相比传统的无验证推测（如Spec-VLA），逐动作验证对物理环境的突变（如物体意外位移）更敏感，提升了任务可靠性。
- **大量消融和设计探索**：完整拆解了每个组件对延迟和成功率的贡献，并对四个关键阈值参数和预测长度进行了系统扫描，帮助读者理解系统行为和参数选取依据。

## 8. 不足与局限

- **训练算力信息缺失**：未提供VLA模型的训练资源投入和成本核算，不利于评估系统的完整投入产出比。
- **物理不可逆风险的讨论不够深入**：回滚机制对“完全闭合夹爪”等物理不可逆操作，论文仅说明“多步执行可以恢复”，但并无具体实验验证在真实机器人上的安全边界。
- **模拟与真实部署的差距**：硬件评估依赖模拟器和综合工具，没有在FPGA或ASIC原型上运行真实机器人任务的端到端验证，实验结果可能偏乐观。
- **感知依赖假设**：环境状态预测依赖物体坐标和机械臂坐标等感知信息（此信息来自机器人感知模块），若感知本身存在误差或遮挡，状态预测的准确性可能下降。论文仅在传感器噪声下对模型进行了鲁棒性测试，但未测试感知噪声对状态预测算法的影响。
- **阈值选择策略偏启发式**：采用一维贪心扫描而非全局联合优化，可能存在阈值组合非最优的情况。
- **RDT-PlugCharger任务的代表性有限**：RDT基线在该任务上成功率仅2%，过于极端，无法充分体现性能差异。
- **与真实世界复杂度的差距**：LIBERO和ManiSkill均基于仿真环境，真实场景中的物体形变、光照变化、非结构化干扰等未被充分覆盖。
