## 摘要
真实世界部署的视觉-语言-动作（VLA）模型常常受限于效率与性能的权衡、跨本体泛化和执行平滑性。我们提出NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化计算资源和模块化。为了弥合异构机器人之间的语义差距，我们引入GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束强制执行运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上达到85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人技术实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 核心问题与研究动机

- 论文针对**视觉-语言-动作（VLA）模型在真实机器人部署中面临的三大瓶颈**展开研究：
  1. **效率与性能冲突**：现有单体同步架构采用统一时间分辨率，无法同时兼顾低频率语义推理与高频率电机控制；
  2. **跨本体泛化困难**：不同机器人形态（如灵巧手、夹爪、机械臂）的连续运动学映射到离散 token 需要庞大词表和大规模数据，难以实现统一的动作语义；
  3. **执行不流畅**：异步实时推理与动作块生成之间存在时间错配，容易导致轨迹抖动和边界不连续问题。
- 论文提出 **NebulaVLA**，一种异步双频架构，将快慢认知范式引入 VLA 模型，以系统性地解决上述问题。

## 2. 方法论

### 2.1 核心思想
- 借鉴 Kahneman 的“快慢双系统”认知范式，将 VLA 拆分为两个解耦的子系统：
  - **System 2（慢系统）**：约 10 Hz，负责高层语义规划，基于语言指令和稀疏视觉输入生成抽象动作引导；
  - **System 1（快系统）**：约 20 Hz，负责低层反应式控制，基于引导动作、高频视觉输入和动作历史生成最终执行动作。
- 通过异步双频设计平衡计算效率与控制响应速度，并支持分布式部署。

### 2.2 关键技术细节
- **System 2**：以 Qwen3-VL 为骨干，提取隐藏层特征作为 System 1 的抽象动作引导。
- **System 1**：受 InternVLA-M1 启发，并做了两项优化：
  - 对预训练 DINOv2 进行对比微调，增强视觉-本体感觉对齐；
  - 集成 **Guide Action** 机制，保证轨迹连续性与平滑性。
- **GESTURE-7**：一种基于自然语言的 7 维末端执行器状态表示：
  - 向量形式：`[x, y, z, r, p, w, gesture]`；
  - `x, y, z` 为笛卡尔位置，`r, p, w` 为欧拉角姿态，`gesture` 为自然语言关键词（如 `grasp`、`push`）；
  - 不同机器人执行相同动作时共享同一关键词，从而统一异构平台的动作语义。

### 2.3 Guide Action 机制
- 核心思路借鉴图像外扩（Image Outpainting）：
  - 以动作块末尾未执行的若干动作点（如 a4–a7）作为“引导点”，条件化下一动作块的生成；
  - 在扩散去噪过程中通过二值掩码强制保留已知动作区域，保证块边界无缝衔接。
- 条件概率模型：`pθ(A^t_full | A^t_full, A_prior, τ)`；
- 掩码更新公式：`A^(t-1)_full = M ⊙ A^(t-1)_prior + (1-M) ⊙ A^(t-1)_noisy`；
- 训练时引导点数量从 0 到 3 随机采样，以适配推理延迟变化。

### 2.4 三阶段训练流程
1. **Stage 1（System 2 SFT）**：基于 GESTURE-7 进行监督微调，涵盖空间定位、轨迹预测、推理规划三类任务；
2. **Stage 2（System 2 RL）**：使用 GRPO 强化学习进一步优化轨迹规划能力；
3. **Stage 3（System 1 SFT）**：联合微调 System 2 与 System 1，使用加权流匹配损失，损失仅施加于掩码 M=0 的新生成区域。

## 6. 主要结论与发现

1. **性能领先**：NebulaVLA 在 LIBERO-Plus 上达到 **85.5%** 平均成功率，优于 InternVLA-M1（81.3%）、OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。
2. **效率显著提升**：异频架构将平均单步推理延迟从同频设计的 115 ms 降至 **42 ms**，动作生成加速约 **2.7 倍**。
3. **真实世界有效性**：在 Pick-and-Place 和 Packaging Line Material Feeding 任务上，成功率分别达到 92.08% 和 92.5%，均超过 InternVLA-M1 和同频变体。
4. **训练策略有效**：三阶段训练整体带来 1.7–2.5% 的性能提升；S2 SFT 对 Layout 维度显著改善（+6.2%），S2 RL 进一步提升语言和布局维度的语义耦合性能。
5. **Guide Action 有效**：平均关节 jerk 降低 **25.6%**，其中关节 12、13 分别降低 41.2% 和 45.1%，有效抑制块边界抖动。

## 7. 优点

- **架构设计新颖**：异步双频架构将语义推理与动作控制解耦，既保持了深层语义理解能力，又满足高频实时控制需求，且支持分布式部署。
- **动作表示统一**：GESTURE-7 用自然语言关键词统一异构机器人动作语义，天然支持跨本体泛化，并能与强化学习无缝结合。
- **平滑性内化到生成过程**：Guide Action 将平滑约束嵌入扩散去噪过程，而非依赖后处理平滑，从机制上保证轨迹连续性。
- **训练流程完整**：SFT + RL + 连续动作微调的三阶段流程，既有任务适配又有策略优化，逻辑清晰。
