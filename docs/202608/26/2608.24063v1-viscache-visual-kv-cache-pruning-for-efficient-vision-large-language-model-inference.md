## 摘要
尽管视觉大语言模型（VLLMs）在多模态推理中取得了显著成功，但由于视觉键值（KV）缓存带来的巨大计算和内存开销，其长上下文推断仍然过于昂贵。现有的KV压缩方法通常对视觉令牌和层进行统一剪枝，导致大量信息丢失和性能下降。为了解决这一挑战，我们提出了VisCache，一个即插即用的框架，用于无需训练的由粗到细的视觉KV缓存剪枝，它包含两个协同阶段。首先，一个轻量级VLM通过选择性地转发语义信息丰富的关键帧来过滤时间冗余。其次，我们引入了PruneKV，一种针对VLLMs注意力动态量身定制的外科手术式KV压缩算法。与僵硬的剪枝策略不同，PruneKV采用抛物线式的逐层预算分配，以及一种不对称更新机制，选择性地剪枝键同时融合值，从而保留关键上下文信息。大量实验表明，VisCache显著提高了推断效率，实现了高达2.35倍的加速和显著的内存减少，同时仅保留19-28%的KV缓存即可保持竞争力的性能。VisCache持续优于现有基线，为长上下文VLLM推断建立了效率和性能之间的新Pareto前沿。代码可在 https://github.com/Wlklk/VisCache 获取。

## Abstract
While Vision Large Language Models (VLLMs) have achieved remarkable success in multimodal reasoning, their long-context inference remains prohibitively expensive due to the massive computation and memory overhead of visual Key-Value (KV) caches. Existing KV compression methods often apply uniform pruning across visual tokens and layers, leading to substantial information loss and degraded performance.To address this challenge, we propose \textbf{VisCache}, a plug-and-play framework for coarse-to-fine \textbf{Vis}ual KV \textbf{Cache} pruning without training, which consists of two synergistic stages. First, a lightweight VLM filters temporal redundancy by selectively forwarding semantically informative keyframes. Second, we introduce {PruneKV}, a surgical KV compression algorithm tailored to the attention dynamics of VLLMs. Unlike rigid pruning strategies, PruneKV adopts a parabolic layer-wise budget allocation together with an asymmetric update mechanism that selectively prunes keys while fusing values, thereby preserving critical contextual information. Extensive experiments demonstrate that VisCache substantially improves inference efficiency, achieving up to {2.35$\times$ speedup} and significant memory reduction while maintaining competitive performance with only {19--28\%} KV cache retention. VisCache consistently outperforms existing baselines, establishing a new Pareto frontier between efficiency and performance for long-context VLLM inference. Code is available at https://github.com/Wlklk/VisCache

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 整体架构：粗到细、双阶段压缩

- **阶段一：Prompt-Aware Scout 时序冗余过滤（Coarse Filtering）**
  - 使用轻量级视觉语言模型（默认 CLIP ViT-B/32）作为“侦察模型”；
  - 对视频帧和文本 prompt 分别编码，得到帧嵌入 \(h_f\) 和文本嵌入 \(h_t\)；
  - 采用 **MMR（Maximal Marginal Relevance）** 准则平衡相关性（与 prompt 相关）和多样性（帧间冗余惩罚）：
    \[
    \text{MMR}(f)=\lambda \cdot \text{sim}(h_f,h_t)-(1-\lambda)\max_{f'\in\Omega}\text{sim}(h_f,h_{f'})
    \]
  - 迭代选择 top-k 关键帧，在视频进入 VLLM 前就去除时间冗余。

- **阶段二：PruneKV 层感知视觉 KV 压缩（Fine-Grained Pruning）**
  - **Token 重要性打分**：利用预填充阶段各层注意力分数，对每个视觉 token 聚合其接收到的注意力：
    \[
    s_v=\frac{1}{L}\sum_{l=1}^{L}\sum_{i=1}^{N}A^l_{i,v}
    \]
  - **抛物线式逐层预算分配**：
    - 设截断层 \(h\)（默认 \(h=\frac{3}{4}L\)），超过该层的视觉 KV 全部移除；
    - 对保留层 \(l\in[1,h]\)，预算比例满足：
      \[
      b_l=1-\frac{(l-1)^2}{2(h-1)^2}
      \]
    - 即浅层保留更多 token，深层更激进压缩，并归一化以满足全局保留率约束。
  - **非对称键值更新（Prune Keys, Fuse Values）**：
    - 键是注意力相关性的选择器，重要性低可直接删除；
    - 值携带上下文信息，不能简单丢弃，而是通过相似度加权融合到保留 token 中：
      \[
      \Phi=\text{Softmax}\left(\frac{V_k V_d^\top}{\tau}\right)
      \]
      \[
      V_k^{new}=\mu V_k+(1-\mu)\Phi V_d
      \]
    - 默认 \(\mu=0.7\)、\(\tau=1.0\)。
  - 共享全局 token 排序：各层从同一个全局注意力重要性排序中按各自预算选择 token，保证跨层 token 身份一致性。

- **总体保留率**：
  \[
  RR = p \times q \times \frac{h}{L} \times m
  \]
  其中 \(p\) 为帧过滤比例，\(q\) 为 token 保留比例，\(h/L\) 为层截断比，\(m\) 为层内平均预算。

## 6. 论文的主要结论与发现

- VisCache 仅保留 **19%–28% 的视觉 KV 缓存**即可达到与全量缓存相当甚至更好的平均性能。
- 在 Qwen2.5-VL-3B 上，28% RR 下平均准确率 45.64%，超过全量缓存 44.16%；32B 模型上 28% RR 平均 56.86%，优于全量缓存 57.46% 之外的几乎所有基线。
- 推理效率显著提升：
  - 最高 **2.35× 端到端加速**（DREAM1K 上 19% RR）；
  - FLOPs 降至全量缓存的 **6%–15%**；
  - GPU 显存从 5.57GB 降至 3.68GB，KV cache 显存降至 0.02GB。
- 抛物线预算分配显著优于算术/几何/固定预算；非对称键值融合进一步提升了 VQA 准确率。
- 两阶段设计互补：Scout 解决帧级时间冗余，PruneKV 解决 token 级结构冗余，在低 RR 下优势更明显。
- 共享全局 token 排序优于层独立排序，因为全局排序更稳定且能保持跨层信息一致性。

## 7. 优点

- **无需训练、即插即用**，可直接适用于多种 VLLM 架构。
- **粗到细的双阶段设计**具有清晰解释性：先删冗余帧、再压缩 KV cache。
- **抛物线预算分配**比常用线性/几何衰减更符合视觉信息“浅层细粒度、深层语义化”的分布规律。
- **非对称 KV 更新**（剪键融值）是较新的切入点，能保留被删 token 的上下文信息。
- **共享全局注意力排序**简化了逐层 token 选择的复杂性，同时提升性能。
- 实验覆盖多种基准、多种模型规模、多个保留率、多个消融维度，并报告了实际系统级延迟与显存，工程实用性较强。

## 8. 不足与局限

- **Scout 模型与主模型存在语义对齐偏差**：轻量 VLM（如 CLIP）选出的关键帧可能并不完全等价于主 LLM 认为重要的帧；论文也指出三种失败模式：缺少转场帧、误删歧义帧、保留冗余帧。
- **PruneKV 需要存储预填充阶段所有层的注意力分数**，会引入额外显存/内存开销，论文将其列为明确局限，但未给出该开销的具体数值。
- **缺乏多次运行统计与显著性分析**：除融合强度实验外，多数性能数字未报告方差或多次重复结果。
- **与更激进基线的对比还不够全面**：如未对比部分更新更强的 token merging、低秩分解或系统级 PagedAttention 优化方法。
- **应用限制**：对模型内部注意力质量依赖较强，底层模型若有注意力偏差或安全偏见，压缩过程可能放大这些偏差；在隐私、监控等大规模视频分析场景应用时需额外做公平性与伦理评估。
