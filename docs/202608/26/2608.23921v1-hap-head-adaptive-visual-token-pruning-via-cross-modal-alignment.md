## 摘要
最近的视觉语言模型将高分辨率图像编码为长视觉token序列，导致高昂的预填充成本。为了压缩它们，现有方法通过对所有注意力头均匀平均文本到视觉注意力来对每个视觉token打分，这假设每个头都与查询匹配。然而，我们的实证分析表明，未对齐的头主导了平均值，放大了背景token，淹没了细粒度线索。为了解决这个问题，我们提出了PAQ（提示接地注意力质量），一个量化每个头将提示与图像区域对齐程度的指标。基于PAQ，我们的剪枝分三个阶段进行。给定目标FLOPs预算，我们首先将Transformer层分组，并为每组分配视觉token预算。在每组内，我们通过PAQ加权的softmax将每个头的注意力图聚合为组级矩阵。最后，我们根据该矩阵的幅度对视觉token打分，并保留每组的分配预算。通过用PAQ加权头，我们的方法根据更忠实反映提示相关性的注意力信号对token打分，而不是通过均匀平均稀释它们。在18个基准测试中，我们的方法实现了最先进的权衡。具体来说，在LLaVA-1.5-7B（9个任务）上，仅保留5.6%的token就保留了原始性能的99.1%，超过了最强的基线AutoPrune 4.2个百分点。代码可在https://github.com/baokou-fw2/HAP获取。

## Abstract
Recent Vision-Language Models encode high-resolution images into long visual token sequences, incurring prohibitive prefill costs. To compress them, existing methods score each visual token by averaging text-to-visual attention uniformly across all heads, which assumes every head matches the query. However, our empirical analysis shows that misaligned heads dominate the average, amplifying background tokens and drowning out fine-grained cues.   To address this, we propose PAQ (Prompt-Grounded Attention Quality), a metric quantifying how well each head aligns the prompt with image regions. Built on PAQ, our pruning proceeds in three stages. Given a target FLOPs budget, we first partition the transformer layers into groups and allocate a visual token budget to each. Within each group, we then aggregate per-head attention maps via PAQ-weighted softmax into a group-level matrix. Finally, we score visual tokens by this matrix's magnitude and retain the allocated budget per group. By weighting heads with PAQ, our method scores tokens by attention signals that more faithfully reflect prompt relevance, rather than diluting them through uniform averaging.   Across 18 benchmarks, our method delivers state-of-the-art trade-offs. Specifically, on LLaVA-1.5-7B (9 tasks), retaining only \textbf{5.6\%} tokens preserves \textbf{99.1\%} of the original performance, surpassing the strongest baseline AutoPrune by 4.2 points. Code is available in https://github.com/baokou-fw2/HAP.

- **问题背景**：近年来，视觉语言模型（VLMs）通过集成高分辨率视觉编码器与大型语言模型（LLMs），在 multimodal 推理与理解上取得显著进展。然而，高分辨率编码器会将图像编码为数百至数千个视觉 token，形成长序列，导致自回归预填充（prefill）阶段产生高昂的计算和内存开销，成为实时部署与资源受限环境下的关键瓶颈。
- **现有方法的缺陷**：现有视觉 token 剪枝方法（如 SparseVLM、PDrop、AutoPrune 等）通常利用跨模态注意力统计来排序和剪除视觉 token。但它们共享一个关键简化假设——同一层内所有注意力头对提示相关区域的关注程度相同，因此采用**对所有头均匀平均注意力分数**的策略。
- **核心发现**：论文通过实证分析揭示，注意力头实际上分为三种截然不同的模式：
  - **Sink heads（汇聚头）**：无论文本提示如何，注意力都坍缩到固定区域（如图像背景或边缘）。
  - **Dispersed heads（分散头）**：注意力广泛分布，缺乏明确的提示对应关系。
  - **Optimal heads（最优头）**：注意力集中在随查询变化的与任务相关的区域。
- **均匀平均的危害**：均匀平均会让未对齐的头（sink/dispersed）主导分数，放大背景 token 并淹没来自 optimal heads 的细粒度线索。实验表明，按平均注意力选择的 token 在任务精度和空间定位上均不及按单头最佳对齐选择的 token。
- **研究意义**：本文首次系统揭示了 VLM 跨模态注意力头的异构对齐特性，并据此设计了无需训练的 token 剪枝方法，以更忠实于提示相关性的方式实现视觉 token 压缩，显著降低预填充成本。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
将注意力头异构性视为**可靠性信号**而非**可平均化的噪声**：提出 PAQ（Prompt-Grounded Attention Quality）指标衡量每个注意力头的提示-视觉对齐质量，并以此指导注意力头的加权融合和视觉 token 的剪枝，实现“头自适应”的 token 选择。

### 2.2 PAQ（Prompt-Grounded Attention Quality）指标
- **理论依据**：基于 Theil 不确定系数（uncertainty coefficient），定义为：
  $$PAQ = \frac{I(V; T)}{H(V)}$$
  其中 I(V;T) 衡量视觉分布受文本查询驱动的程度，H(V) 为视觉总熵。该值域为 [0,1]，表示视觉分布被查询解释的比例。
- **计算方式**：完全从固有的注意力统计中计算，无需额外参数。设 α_ji 为第 j 个文本 token 到第 i 个视觉 token 的归一化注意力权重，将其视为软相关性分配 p̂(v_i|t_j)=α_ji，并采用均匀文本先验 p(t_j)=1/N_t，代入上式即可得到 PAQ。
- **对三类头模式的区分能力**：
  - **Sink/Dispersed heads**：注意力权重 α_ji 对文本 token t_j 不变，即 p̂(v_i|t_j) = p̂(v_i)，视觉分布与文本独立，则 I(V;T)=0，PAQ 趋近于零。
  - **Optimal heads**：注意力随查询变化集中于任务相关 token，产生 I(V;T)>0 且 H(V) 低，PAQ 值高。

### 2.3 HAP 框架（三层流程）
给定目标 FLOPs 预算，HAP 分三个阶段进行：

1. **分层组划分与预算分配**：
   - 将 L 个 Transformer 层划分为 M 个连续组，每组 L/M 层。
   - 视觉 token 遵循金字塔结构（越深层 token 越少），组 g 的目标预算为 N_v(g) = V / (1+g)²，其中 V 为初始视觉 token 数。
   - 组数 M 通过闭式 FLOPs 成本函数 F(M) 直接从目标预算推导，无需逐任务调参。

2. **PAQ 加权的软注意力聚合**：
   - **头级聚合**：对每一层 l，计算每个头的 PAQ 分数，经中心化（减去均值）后应用 softmax 得到聚合权重 w_c，加权融合所有头的注意力图，得到层注意力 A_agg^(l)。
   - **组级聚合**：将组内各层视为新的候选集，以各层的聚合注意力图和 PAQ 分数重复上述 PAQ-softmax 过程，融合得到组级注意力矩阵 A_group^(g)。

3. **Token 打分与剪枝**：
   - 利用组级注意力矩阵，对每个视觉 token 计算跨所有文本位置的平均注意力分数 s_i^(g)。
   - 按分数排序，保留每组预算 N_v^(g) 个最高分 token。

### 2.4 效率分析
- 剪枝开销：PAQ 计算和剪枝开销为 O(H·N_t·V·L/M)，远小于未剪枝的注意力成本。
- 与 FlashAttention 兼容：通过“双闪存聚合”扩展，无需物化完整的 O(N²) 注意力矩阵，额外内存仅每层几个 KB，开销 <2%。
- 闭式 FLOPs 公式：总计算成本可表达为组数 m 的确定性函数，无需架构特定的剪枝调度。

## 6. 论文的主要结论与发现

1. **VLM 跨模态注意力头存在系统性异构性**：sink、dispersed、optimal 三种模式在不同层和架构中均稳定出现，均匀注意力聚合会稀释最优信号。
2. **PAQ 能有效区分可靠对齐与虚假模式**：高 PAQ 头具有正确的视觉接地（RefCOCO IoU 相关性 0.67~0.71），低 PAQ 头对应注意力汇聚/分散模式。
3. **HAP 实现 SOTA 精度-效率权衡**：
   - LLaVA-1.5-7B：仅保留 5.6% token（32 个），保持 99.1% 性能，超过最强基线 AutoPrune 4.2 个百分点。
   - InternVL3-8B / Qwen2.5-VL-7B：25% token 保留下达到 99.5%/99.1% 相对分数。
   - DeepSeek-VL2：50% token 保留下达到 103.0% 相对平均值（超过未剪枝版本）。
4. **效率显著**：2.82× 推理加速、KV cache 减少 80%，且 PAQ 开销 <2%。
5. **无需逐任务调参**：唯一用户输入是目标 FLOPs 预算，所有调度均从此确定性地推导。

## 7. 优点：方法与实验设计亮点

## 8. 不足与局限

- **仅覆盖预填充阶段**：方法在预填充阶段剪枝，解码阶段视觉 KV cache 保持不变；虽分析了长生成场景，但对超长输出的内存优化仍有限。
- **PAQ 为注意力代理指标**：基于跨模态注意力的相关性证据而非因果验证，未进行反事实 token 干预实验来建立严格因果关系。
- **应用范围有限**：评估以静态图像和短视频为主，流式或超长多模态场景的头部对齐模式待研究。
- **计算开销未完全消除**：PAQ 虽开销小但在极低 token 保留率下相对占比会上升。
- **重标注基准未覆盖**：MME 等部分基准得分可能受 prompt 细节影响，虽做了提示敏感性分析但未深入探讨评估偏差。
