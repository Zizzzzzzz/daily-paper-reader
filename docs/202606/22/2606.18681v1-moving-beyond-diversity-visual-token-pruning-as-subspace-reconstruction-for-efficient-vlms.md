## 摘要
尽管视觉语言模型（VLM）性能卓越，但由于大量视觉标记的存在，其计算开销显著。虽然多样性最大化已成为标记缩减的主流策略，但现有方法依赖于基于余弦的归一化相似度，忽略了幅度信息，无法准确逼近原始特征表示，导致性能次优，特别是在组合式多技能推理任务上。本文提出SPARE——一种子空间重构方法，将标记剪枝重新表述为列子集选择问题，并显式最小化重构误差。通过迭代选择具有大投影残差的标记，SPARE实现了超越角度多样性的重构驱动剪枝。此外，我们揭示了一个反直觉的“反相关”现象：图像-文本相关度较低的标记反而能更好地保留上下文信息。基于此发现，我们将反相关性作为附加选择标准融入SPARE，以促进上下文感知的标记选择。在多种VLM和基准测试上的广泛实验表明，SPARE consistently取得了最先进性能，尤其在组合任务上提升显著。当应用于LLaVA时，SPARE可在完全无需训练的情况下移除高达94%的视觉标记，同时保留95%的基线性能。

## Abstract
Despite their remarkable performance, Vision Language Models (VLMs) incur substantial computational overhead due to the large number of visual tokens. While diversity maximization has become a dominant strategy for token reduction, existing methods rely on cosine-based normalized similarity that discards magnitude information, failing to faithfully approximate the original feature representation and leading to suboptimal performance, particularly on compositional multi-skill reasoning tasks. In this paper, we introduce SPARE, a subspace reconstruction method that reformulates token pruning as a column subset selection problem and explicitly minimizes reconstruction error. By iteratively selecting tokens with large projection residuals, SPARE performs reconstruction-driven pruning beyond angular diversity. Moreover, we reveal a counterintuitive anti-relevance phenomenon: tokens with lower image-text relevance score can better preserve contextual information. Based on this finding, we incorporate anti-relevance into SPARE as an additional selection criterion to promote context-aware token selection. Extensive experiments across multiple VLMs and benchmarks demonstrate that SPARE consistently achieves state-of-the-art performance, with strong gains on compositional tasks. When applied to LLaVA, SPARE removes up to 94% of visual tokens while retaining 95% of the baseline performance, all in a fully training-free manner.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：视觉语言模型（VLM）在处理高分辨率图像或视频时，会产生数千甚至上万的视觉 token，导致巨大的计算开销和内存消耗（特别是 LLM 的 KV cache）。
- **现有方法局限**：当前主流的 token 剪枝策略以**多样性最大化**为主（如基于余弦归一化相似度选择互不相似的 token），但这类方法丢弃了 token 的幅度信息，无法忠实逼近原始特征表示；在需要多技能组合推理（如识别+OCR+空间推理）的任务上性能显著下降。
- **核心动机**：将 token 剪枝视为**特征子空间的重建问题**而非单纯的离散度最大化，并且发现了一个“反相关”现象：**图像-文本相关度较低的 token 反而包含更多对推理有用的上下文信息**。基于此，本文提出 SPARE 方法，兼顾重构保真度与上下文感知。

## 2. 方法论：核心思想、技术细节与算法流程

### 核心思想
- 将视觉 token 剪枝重新建模为**列子集选择问题（CSSP）**，目标是最小化剪枝后的特征矩阵相对于原始矩阵的 Frobenius 范数重构误差。
- 采用**秩揭示 QR 分解（RRQR）** 的贪心策略：每次选择投影残差（即向量在已选子空间上的分量误差）最大的 token，逐步逼近原始子空间。
- 同时，引入**反相关引导**：基于 CLIP 图像-文本相似度，优先保留相似度低的 token（因其包含互补上下文信息），与重构残差相乘作为选择标准。

### 关键技术细节
1. **重构残差计算**：
   - 对每个候选 token \( x_i \)，残差 \( r_i = \|x_i - \Pi_S x_i\|_2^2 = \|x_i\|_2^2 - \sum_{q \in Q} (x_i^\top q)^2 \)（其中 \( Q \) 为已选 token 的标准正交基）。
2. **反相关分数**：
   - 对每个视觉 token，计算其与所有文本 token 的 CLIP 余弦相似度，取负均值后做 z-score 归一化，再经 softplus 转换得到非负权重 \( \rho_n \)。
3. **联合选择准则**：
   - 每次迭代选择 \( n^* = \arg\max_{n \notin S} (r_n \rho_n) \)，即同时考虑重构重要性和反相关性。
4. **算法流程**（Algorithm 1）：
   - 输入：视觉 token 矩阵 \( X_v \in \mathbb{R}^{N \times d} \)，CLIP 图像/文本嵌入，预算 k。
   - 计算反相关分数。
   - 初始化残差为 token 的 L2 范数平方。
   - 循环 k 次：选择残差×反相关分数最大的 token；通过 Gram-Schmidt 正交化更新基；更新剩余 token 的残差（减去在新基方向上的投影）。
   - 输出选择掩码。
