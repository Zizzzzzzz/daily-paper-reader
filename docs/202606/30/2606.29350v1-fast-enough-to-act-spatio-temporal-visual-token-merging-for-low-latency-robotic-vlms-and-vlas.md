## 摘要
视觉语言模型和视觉语言动作模型赋予了机器人前所未有的能力。然而，视频和高分辨率图像的输入会产生大量视觉标记，导致推理延迟极高，严重阻碍机器人的实时控制。为了突破这一计算瓶颈，我们提出了ST-Merge，一种即插即用、无需训练的框架，它在视觉编码阶段直接高效地融合冗余标记。通过显式构建3D时空坐标，它采用多队列并行匹配和加权聚合机制，实现跨帧冗余标记的高效且几何一致的融合。此外，我们引入了一种合并后位置校正机制，通过动态重新评估视觉标记加权质心的旋转位置编码，有效消除合并引起的空间偏差，从而确保灵巧操作所需的高精度空间感知。在主流的视觉语言模型Qwen2.5-VL的视频问答任务中，ST-Merge实现了2倍的推理加速，仅带来1%的微小精度损失。当部署在π0.5 VLA策略上时，ST-Merge在1024×1024分辨率下实现了8.3倍的加速，并在该高分辨率设置下匹配了基线成功率。在较低分辨率下，它引入了少量精度下降。

## Abstract
Vision-language models and vision-language action models endow the robot with unprecedented capabilities. However, the input of video and high-resolution images yields a massive number of visual tokens, leading to extremely high inference latency and severely hindering the robot's real-time control. To break through this computational bottleneck, we propose ST-Merge, a plug-and-play, training-free framework that efficiently fuses redundant tokens directly during the visual encoding phase. By explicitly constructing 3D spatiotemporal coordinates, it employs a multi-queue parallel matching and weighted aggregation mechanism to achieve efficient and geometrically consistent fusion of redundant tokens across frames. In addition, we introduce a post-merge positional correction mechanism that effectively eliminates spatial deviation caused by merging by dynamically re-evaluating the rotational position code of the weighted centroid of the vision token, thereby ensuring the high-precision spatial awareness required for dexterous operation. In the Video Question Answering task on the mainstream VLM, Qwen2.5-VL, ST-Merge achieves a 2$\times$ inference speedup with only a tiny 1\% loss in precision. When deployed on the $π_{0.5}$ VLA policy, ST-Merge achieves an 8.3$\times$ speedup at 1024 $\times$ 1024 resolution and matches the baseline success rate at this high-resolution setting. At lower resolutions, it introduces a small drop in accuracy.

## 2. 方法核心思想与技术细节

### 核心思想
ST-Merge 是一个**即插即用、无需训练**的框架，在视觉编码器的**浅层全局注意力层**直接对冗余 token 进行**时空融合**，大幅减少后续计算，并引入**合并后位置校正**保证空间精度。

### 关键技术流程（共 5 步）

1. **队列划分（Multi-Queue Partitioning）**  
   - 将视觉 token 分为 1 个锚队列（anchor）和 K-1 个候选队列（candidate），实现 O(n) 的**一对多并行匹配**，避免传统二分图匹配的串行瓶颈。

2. **位置感知距离计算（Position-Aware Distance）**  
   - 为每个 token 构建 3D 时空坐标 \( p_i = (t_i, y_i, x_i) \)（时间、高度、宽度）。  
   - 计算 token 间欧氏距离，并用高斯核生成邻域权重 \( w_{ij} = \exp(-\|p_i - p_j\|^2 / (2\sigma^2)) \)，强制匹配仅发生在邻近帧或空间区域，防止跨区域误匹配。

3. **加权时空匹配（Weighted Spatio-Temporal Matching）**  
   - 结合语义相似度与空间权重：相似度矩阵 \( S'_{ij} = (a_i^\top c_j) \cdot w_{ij} \)。  
   - 对每个锚 token 选择最高分候选 \( b_j^* \) 作为匹配对，按得分降序取 top r 高置信度对进行合并。

4. **token 合并与特征聚合（Token Merging）**  
   - 源 token 特征通过加权平均融合到目标 token：  
     \( v_{b_j^*} \leftarrow (s_{b_j^*} v_{b_j^*} + s_{a_i} v_{a_i}) / (s_{b_j^*} + s_{a_i}) \)，保持特征幅度和空间覆盖。

5. **合并后位置校正（Post-Merge Positional Correction）**  
   - 针对 Qwen2.5-VL 等使用 RoPE 的模型：合并后 token 的旋转位置编码（sin/cos）**不直接继承**任一源 token，而是计算各源 token 加权质心位置对应的 sin/cos 值（按贡献大小加权），并重新归一化以保证 RoPE 旋转不变性。  
   - 该步骤消除合并引起的空间偏差，是保持高精度几何推理的关键。

- **部署差异**：在 VLA（π0.5）的 SigLIP 编码器中不使用 RoPE，故不启用位置校正；同时输入为单帧多视图，不计算时间权重，只做空间匹配。

## 7. 方法的优点

- **即插即用、无需训练**：无需修改模型参数，可直接应用于现有 VLM/VLA 架构。  
- **早期融合降低计算**：在视觉编码器浅层即完成 token 压缩，级联节省后续所有层计算，效率极高。  
- **时空显式建模**：通过 3D 坐标和高斯核权重，强制匹配在时空邻域内进行，避免跨区域误合并。  
- **多队列并行匹配**：O(n) 复杂度，支持大规模 token 快速削减。  
- **后合并位置校正**：针对 RoPE 机制设计，有效维持空间精度，对机器人精细操作至关重要。  
- **高分辨率优势明显**：在高分辨率下冗余信息多，合并效果最好，加速比高达 8.3 倍且零精度损失。
