## 摘要
低光图像增强在输入帧包含缺失结构、饱和噪声和弱局部对比度时严重不适定。事件相机提供高时间分辨率的异步亮度变化观测，但先前的工作通常将体素通道视为无序或静态的特征堆栈进行融合，而不是显式地模拟其窗口内的时间演化，从而削弱了使事件有用的时间证据。我们提出EvLIR，一个从有序事件中学习光照残差的时间残差增强框架，用于低光图像增强。给定一个低光帧及其对齐的事件体素，EvLIR保留事件流的有序时间箱，并引入时间事件残差模块（TERM）以使用轻量级ConvGRU编码短窗口事件动态。由此产生的时间状态被转换为有界光照校正，为Retinex风格的光照估计和后续的可靠性感知图像事件恢复提供空间自适应光度指导。在SDE和SDSD室内/室外基准上，EvLIR在十二个数据集-度量对中的十一个上取得了最佳结果，四个基准上的平均得分为25.63 dB PSNR、28.30 dB PSNR*和0.827 SSIM。

## Abstract
Low-light image enhancement is severely ill-posed when the input frame contains missing structure, saturated noise, and weak local contrast. Event cameras provide asynchronous brightness-change observations with high temporal resolution, but prior works often treat voxel channels as an unordered or static feature stack before fusion, rather than explicitly modeling their within-window temporal evolution, weakening the temporal evidence that makes events useful. We propose EvLIR, a temporal-residual enhancement framework that learns illumination residuals from ordered events for low-light image enhancement. Given a low-light frame and its aligned event voxel, EvLIR preserves the ordered temporal bins of the event stream and introduces a Temporal Event Residual Module (TERM) to encode short-window event dynamics with a lightweight ConvGRU. The resulting temporal state is converted into a bounded illumination correction, which provides spatially adaptive photometric guidance for Retinex-style illumination estimation and subsequent reliability-aware image-event restoration. On SDE and SDSD indoor/outdoor benchmarks, EvLIR achieves the best result on eleven of twelve dataset-metric pairs, with average scores of 25.63~dB PSNR, 28.30~dB PSNR*, and 0.827 SSIM across the four benchmarks.

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 在Retinex风格增强的框架中，**用有序事件来估计光照残差**，而不是将事件作为静态特征简单融合。
- 通过**时序事件残差模块（TERM）** 对事件体素的短窗口动态进行编码，输出有界光照校正，修正由图像分支估计的基测光照图。

### 2.2 关键技术细节
- **有序事件表示**：将32通道的事件体素沿时间轴划分为K个有序时间箱（默认K=8），每个箱包含C/K个通道，保持从早到晚的时序。
- **时序事件残差模块（TERM）**：
  - 每个时间箱先经共享的3×3卷积+LeakyReLU投影。
  - 投影后的序列送入**ConvGRU**进行递归编码，更新门和重置门控制时序状态演进，强化持续亮度变化模式，抑制孤立噪声。
  - 最后一个时间箱的隐状态通过一个残差头（两个3×3卷积+tanh）生成有界光照残差ΔL。
- **光照校正**：将残差ΔL（缩放因子s=0.1）加到图像分支估计的基测光照L₀上，得到校正光照L，权重α=0.1。校正后的光照用于Retinex提亮：Iₘ = Iₗ ⊙ L + Iₗ。
- **可靠性感知图像-事件恢复**：分别提取提亮图像和原始事件体素的特征，拼接并通过1×1卷积对齐；引入SNR图作为空间可靠性先验，低SNR区域更依赖事件特征；最终恢复网络融合所有特征预测正常光图像。

### 2.3 算法流程（文字描述）
1. 输入低光RGB图像Iₗ和对齐的事件体素E（32通道）。
2. 通过光照网络从Iₗ估计基测光照L₀及光照特征。
3. 将E划分为K个有序时间箱[E₁,...,E_K]。
4. TERM逐箱处理：投影→ConvGRU更新隐状态→生成有界残差ΔL = s·tanh(ψ(H_K))。
5. 校正光照L = L₀ + αΔL，并提亮得到Iₘ。
6. 分别提取Iₘ和E的特征，拼接对齐；结合SNR图输入恢复网络，输出最终增强图像Î。

- **有序事件时序建模显著优于无序聚合**：Ordered ConvGRU相比Order-Free Accumulation在SDE-in上PSNR提升0.51 dB，SSIM提升0.0165。

## 7. 优点

- **设计简洁高效**：TERM模块轻量（ConvGRU+小卷积头），计算开销小，单GPU可训练。
- **有界残差设计合理**：将事件动态约束为小幅度修正（α=0.1），避免噪声干扰和光照估计崩溃。
- **实验验证充分**：在真实事件（SDE）和仿真事件（SDSD）上均验证有效性，并提供了细粒度的消融和参数分析。
