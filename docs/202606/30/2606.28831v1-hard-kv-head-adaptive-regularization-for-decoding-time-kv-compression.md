## 摘要
长上下文LLM推理面临一个根本冲突：头自适应压缩算法（例如Top-$p$核采样）通过动态波动内存预算提供卓越的准确性，但现代推理引擎（例如vLLM）要求刚性、静态的内存模式以利用CUDA Graphs和PagedAttention。我们通过HARD-KV解决了这种"静态-动态"不匹配，这是一个统一框架，弥合了动态选择与刚性系统约束之间的差距。HARD-KV引入了级联缓存层次结构，管理token在密集、稀疏和压缩层级中的生命周期。关键地，我们提出了一种Logits校准机制，将多样化的重要性指标归一化为统一的概率空间，从而实现异构头之间一致的Top-$p$预算分配。为弥补效率差距，我们提供了一种系统级解决方案，将碎片化的动态索引重写为与高性能推理引擎兼容的连续物理布局。在数学推理基准（AIME、U-Math）上的大量实验验证了HARD-KV在10k+ token场景中实现了高达2倍于静态基线的吞吐量提升，同时保持高保真生成。代码可在https://github.com/SuDIS-ZJU/HARDInfer获取。

## Abstract
Long-context LLM inference faces a fundamental conflict: head-adaptive compression algorithms (e.g., Top-$p$ nucleus sampling) offer superior accuracy by dynamically fluctuating memory budgets, yet modern inference engines (e.g., vLLM) demand rigid, static memory patterns to leverage CUDA Graphs and PagedAttention. We resolve this ``Static-Dynamic'' mismatch with HARD-KV, a unified framework that that bridges dynamic selection with rigid system constraints. HARD-KV introduces a Cascade Cache hierarchy, managing the token lifecycle across dense, sparse, and condensed tiers. Crucially, we propose a Logits Calibration mechanism that normalizes diverse importance metrics into a unified probability space, enabling consistent Top-$p$ budgeting across heterogeneous heads. To bridge the efficiency gap, we offer a system-level solution, which rewrites fragmented, dynamic indices into contiguous physical layouts compatible with high-performance inference engine. Extensive experiments on math-reasoning benchmarks (AIME, U-Math) verify that HARD-KV achieves up to 2$\times$ throughput improvement over static baselines while maintaining high-fidelity generation in 10k+ token scenarios. Code is available at https://github.com/SuDIS-ZJU/HARDInfer.

## 1. 核心问题与整体含义（研究动机和背景）

长上下文大语言模型（LLM）推理面临一个根本矛盾：**头部自适应的 KV 缓存压缩算法**（如 Top‑p 核采样）通过动态调整每个注意力头的缓存预算，能取得更高的生成精度；然而现代推理引擎（如 vLLM）依赖 **CUDA Graphs 和 PagedAttention** 等静态、固定的内存模式来获得高性能。这种“动态算法 vs 静态系统”的不匹配导致头部自适应压缩在实际部署中难以发挥效率优势。HARD‑KV 旨在统一这一矛盾，在保持动态压缩精度的同时，使内存布局符合系统对规则性和连续性的要求，从而显著提升吞吐量。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
HARD‑KV 提出**级联缓存（Cascade Cache）** 层次结构，将 KV 缓存的生命周期划分为三个层级，并通过**Logits 校准**将不同选择方法的注意力分数归一化到统一的概率空间，实现一致的 Top‑p 预算分配；再通过**系统级索引正则化**将动态、碎片化的索引转换为连续物理布局，从而兼容 CUDA Graphs 等优化。

### 2.2 关键技术细节

- **级联缓存（Cascade Cache）**：三层结构  
  - **第1层 – 密集缓存（Dense Cache）**：保留最近的 token，保证局部注意力完整。  
  - **第2层 – 稀疏缓存（Sparse Cache）**：对移出密集窗口的 token，采用校准后的 Top‑p 选择保留重要键‑值对。  
  - **第3层 – 压缩缓存（Condensed Cache）**：对更早的块进行固定预算的驱逐或合并（eviction/merging）。  
  三层通过自定义的“级联注意力”合并输出（利用 FlashInfer 的组合式 Attention State 代数）。

- **Logits 校准（Logits Calibration）**：  
  不同选择方法（如 SnapKV 的 max‑pooling、R‑KV 的余弦相似度）会改变注意力分数分布，导致相同的 Top‑p 阈值产生截然不同的保留 token 数量（“选择坍缩”）。  
  HARD‑KV 通过温度缩放（temperature scaling）调整变换后的分数，使 Top‑p 选择的概率质量与原始注意力的 Top‑k 集合匹配。  
  具体算法：对于保序变换（如 max‑pool），直接对 logits 施加温度 `z/T`；对于非保序变换，则对变换后的分数 `g(z)/T` 进行 softmax。通过梯度下降或二分搜索求解最优温度，使得 `M_k(S) ≈ M_k(Ŝ)`（Top‑k 的概率质量误差最小）。  
  此外，论文提出了“三步框架”（Gather → Reduce‑Scatter → Sample），将大多数现有选择方法统一到 Top‑p 预算下。

- **系统级索引正则化**：  
  - **重写缓存（Rewrite Cache）**：将选中的 KV 块重写为连续的物理布局。  
  - **稀疏加载（Sparse Loading）**：通过硬件掩码加载，避免重写但增加冗余。  
  - **展平索引（Flatten Index）**：将各层各头的索引展平成一维数组，取最大值或和作为统一块数。  
  针对头部自适应分配（Head‑wise Allocation, HA），论文比较了 HA‑Sparse（稀疏加载）和 HA‑Max（重写为最大块数），实验表明在长序列（>10k）时重写方案能节省大量计算时间。  
  工程实现上，修改了 nano‑vllm 引擎，引入头级块表（Head‑wise Block Table）和部分更新机制，以支持 CUDA Graphs。

### 2.3 主要公式与算法流程（文字说明）
- **Logits 校准优化问题**：给定 Top‑p 阈值，最小化原始注意力 Top‑k 概率质量与校准后注意力 Top‑k 概率质量之差，通过调整温度 T 实现。  
- **温度求解**：可采用梯度下降（Adam）或二分搜索。论文采用首次压缩时求解温度，后续复用。  
- **三步框架**：  
  1. Gather：按分组策略（如量化、相似性）将 KV 缓存聚为子组；  
  2. Reduce‑Scatter：在子组内计算评分并散射到后压缩块；  
  3. Sample：根据 Top‑k 或 Top‑p 筛选最终索引。
