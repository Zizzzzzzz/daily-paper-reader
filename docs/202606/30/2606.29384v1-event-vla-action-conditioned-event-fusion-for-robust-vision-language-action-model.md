## 摘要
视觉-语言-动作（VLA）模型已成为具身智能的重要范式。然而，现有VLA模型通常假设光照良好且稳定的室内环境，而现实世界的具身操作可能涉及光照变化导致的退化RGB观测，这对鲁棒机器人操作提出了关键挑战。为解决这一问题，我们提出Event-VLA，一种事件增强的VLA框架，用于在不同光照条件下实现可泛化的操作。我们将退化可见性下的VLA操作建模为以RGB为中心策略的实际鲁棒性问题，并引入事件流作为一种光照鲁棒、运动敏感的互补观测，以提高跨可见性水平的鲁棒性。具体而言，与直接将事件特征融合到全局语义标记空间的传统多模态融合不同，Event-VLA通过动作查询路由路径注入事件信息。它使用可学习的动作查询从VLA推理过程中提取任务相关语义，并通过门控交叉注意力选择性聚合事件标记，构建事件感知的动作表示。这种设计保留了预训练的RGB-语言语义先验，同时有效利用事件信息进行鲁棒动作预测。仿真和实际部署实验表明，Event-VLA在正常光照下保持强操作性能，并在低光照退化及近黑暗实际场景中提高了成功率。

## Abstract
Vision-Language-Action (VLA) models have become an important paradigm of embodied AI. However, existing VLA models typically assume well-lit and stable indoor settings, while real-world embodied manipulation may involve degraded RGB observations caused by illumination shifts, posing critical challenges for robust robotic manipulation. To address this gap, we propose \textbf{Event-VLA}, an event-enhanced VLA framework for generalizable manipulation across varying illumination conditions. We formulate VLA-based manipulation under degraded visibility as a practical robustness problem for RGB-centric policies, and introduce event streams as an illumination-robust, motion-sensitive complementary observation to improve robustness across visibility levels. Specifically, unlike conventional multimodal fusion that directly merges event features into the global semantic token space, Event-VLA injects event information through an action-query routing pathway. It uses learnable action queries to extract task-relevant semantics from the VLA reasoning process, and selectively aggregates event tokens via gated cross-attention to construct event-aware action representations. This design preserves the pretrained RGB-language semantic priors while effectively leveraging event information for robust action prediction. Experiments in simulation and real-world deployment show that Event-VLA maintains strong manipulation performance under normal lighting and improves success rates under low-light degradation and near-dark real-world settings.

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **设计原则**：语义上下文由预训练 VLA 建模，事件信息应以受控方式注入到动作路径中，而不干扰全局语义标记空间。
- **关键创新**：通过可学习的动作查询（action queries）从 VLA 推理过程中提取任务相关语义，再经门控交叉注意力（gated cross-attention）选择性聚合事件 token，构建事件感知的动作表示。

### 2.2 关键组件与技术细节

#### (1) PREI：物理残差事件集成
- 将异步事件流 `S_{t-H:t}` 压缩为紧凑的物理残差图（三通道）：
  - **瞬时通道** (`E_ins`)：强调最近局部变化，使用短衰减常数。
  - **显著通道** (`E_sal`)：突出局部显著事件活动，用局部平滑背景归一化。
  - **持久通道** (`E_per`)：保留整个窗口内的结构轮廓，基于事件计数。
- 公式核心：每个像素的活动强度通过指数衰减加权，然后经 `tanh` 归一化。
- 参数：时间窗口 H=40ms，衰减常数 τ_ins=3ms，τ_sal=10ms，5x5 高斯平滑核。

#### (2) 事件编码器与特征蒸馏
- 将 PREI 图输入事件编码器 `Φ_e`，输出全局事件 token `g_e` 和空间事件 token `P_e`，投影到 VLA 隐藏维度。
- 使用冻结的视觉教师（DINO 分支）进行特征级蒸馏，对齐事件特征与 RGB 特征空间，提高兼容性。蒸馏损失包括全局余弦相似度和局部 patch 余弦相似度，在 N-ImageNet 和 LIBERO 合成数据上训练。

#### (3) 动作条件事件接口
- **输入构建**：VLA 输入包含 RGB token、语言 token、本体 token、动作占位符和三类可学习查询 token（公共查询 Q_c、动作查询 Q_a、事件查询 Q_e）。事件 token 不参与 VLA 前向。
- **后门控融合**：VLA 隐藏状态 `Z_lm` 与编码后的事件 token `Y_e`（加位置编码）进行交叉注意力，得到 `Z_attn`。然后通过门控：`Γ = sigmoid(f_gate(...))`，融合为 `Z_fused = Norm(Z_lm + Γ ⊙ Z_attn)`。
- **查询引导路由**：利用公共查询和动作查询路由动作相关 token 到动作头；利用公共查询和事件查询路由事件相关 token 到辅助事件头。
- **动作头与事件头**：动作头预测未来动作块 `A_hat`；事件头预测未来 PREI 目标 `E_hat_prei`（仅训练时使用）。

#### (4) 训练目标
- 主损失：动作预测 L1 损失 `L_act`。
- 辅助正则化：未来 PREI 重建损失 `L_evt`（使用内容掩码 M）和梯度一致性损失 `L_deriv`。
- 总损失：`L = L_act + λ_evt L_evt + λ_deriv L_deriv`，λ_evt=0.1，λ_deriv=0.3。辅助损失仅训练时使用，推理时不需事件头。

## 6. 主要结论与发现
- Event-VLA 在**正常光照下**保持与 RGB-only 基线相当的性能（平均成功率 96.5%，与 MM-ACT 96.3% 相近）。
- 在**渐进退化**（尤其 LL-Severe）下，Event-VLA 显著优于所有 RGB-only 基线（95.6% vs. 最佳 RGB 基线 69.6%），且优于其他事件融合方法。
- 事件表示 PREI 优于传统时间表面；动作条件查询路由接口在成功率和延迟权衡上最佳。
- “Ours w/o event”（禁用事件路径）性能与完整模型接近，说明事件接口不破坏预训练的 RGB-语言动作通路。
- 真实世界部署验证：在正常光照下保持竞争力，在低光和近暗下比 π0、OpenVLA-OFT 更稳定（近暗 SR 52.5% vs. 15%/12.5%）。
- 辅助事件预测正则化带来额外增益。

## 7. 优点（亮点）
- **创新的事件-动作接口设计**：不将事件 token 送入 VLA 主干，避免了干扰预训练语义先验，同时通过动作查询有选择地注入运动-物理残差，实现“语义由 VLA，残差由事件”的优雅分离。
- **PREI 表示**：分解事件为瞬时、显著、持久三通道，紧凑且保留物理残差信息，优于单一时间表面。
- **全面系统的消融**：不仅比较事件融合策略，还深入分析表示、查询、正则化等每个设计维度，提供清晰的设计洞察。
- **真实世界验证**：从仿真到真实机器人平台的完整闭环，增加了方法可信度。
- **低延迟**：事件注入仅增加约 2ms 推理延迟，实用性好。

## 8. 不足与局限
- **模拟器依赖**：LIBERO-Cross 使用 RGB-to-event 模拟器生成事件流，未能完全捕捉真实事件相机的噪声特性、触发动力学和校准误差（论文承认此局限）。
- **真实世界评估规模有限**：仅 4 个任务、3 种光照条件，未覆盖多种物体、复杂环境和长时域操作，泛化性尚需更广泛验证。
- **仅针对光照退化**：事件相机的主要优势（高动态范围、低延迟、无运动模糊）未在其他挑战（如高速运动、遮挡）下系统测试。
