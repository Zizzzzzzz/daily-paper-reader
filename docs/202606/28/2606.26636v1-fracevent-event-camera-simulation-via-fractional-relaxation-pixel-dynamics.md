## 摘要
事件相机以微秒级时间分辨率异步报告亮度变化，但由于需要专用传感器、精确同步和任务特定标注，真实事件数据难以大规模收集。因此，事件相机模拟对于基于事件视觉的任务至关重要。大多数实用的模拟器基于对比度阈值事件生成，有些还附加滤波、随机噪声或手动调整的传感器参数。虽然有效，但这种公式通常会简化每个像素生命周期产生的时间结构，这可能会扭曲事件时序并削弱下游迁移。我们提出了FracEvent，一种通过分数松弛电压动力学对像素级生命周期建模的事件模拟器。给定对数强度轨迹，FracEvent驱动一个紧凑的松弛模式堆栈，将其响应组合成电压状态，通过在连续电压轨迹上定位阈值交叉来发出开/关事件，并在保留底层记忆模式的同时更新参考。这种保留的状态将残余电压响应与后续事件时序联系起来。我们通过事件流比较以及图像重建和光流估计的下游迁移来评估FracEvent。在多个数据集上，FracEvent改善了生成事件的时间结构，并比竞争模拟器基线实现了更强的下游迁移结果，显示了其在实际事件相机模拟中的价值。

## Abstract
Event cameras asynchronously report brightness changes with microsecond-level temporal resolution, but real event data remain difficult to collect at scale because specialized sensors, careful synchronization, and task-specific annotations are required. Event-camera simulation is therefore important to event-based vision tasks. Most practical simulators build on contrast-threshold event generation, some with additional filtering, stochastic noise, or hand-tuned sensor parameters. While effective, such formulations often simplify the temporal structure produced by the lifecycle of each pixel, which can distort event timing and weaken downstream transfer. We introduce FracEvent, an event simulator that models this pixel-level lifecycle with fractional-relaxation voltage dynamics. Given a log-intensity trajectory, FracEvent drives a compact stack of relaxation modes, combines their responses into a voltage state, emits ON/OFF events by localizing threshold crossings on the continuous voltage trajectory, and updates the reference while retaining the underlying memory modes. This retained state links residual voltage response to later event timing. We evaluate FracEvent through event-stream comparison and downstream transfer on image reconstruction and optical flow estimation. Across multiple datasets, FracEvent improves the temporal structure of generated events and achieves stronger downstream-transfer results than competing simulator baselines, showing its practical value for event-camera simulation.

### 2. 论文提出的方法论
- **核心思想**：将事件模拟分解为上游亮度轨迹和传感器侧转换两部分。FracEvent专注于传感器侧，利用分数松弛电压记忆模拟像素的积累、触发、参考更新和状态保留。
- **关键技术细节**：
  1. **分数松弛像素动力学**：
     - 定义 `M` 个松弛模式，每个模式对应时间常数 `τ_m`，权重 `w_m` 由分数阶参数 `α` 决定（α=1时为单模式）。
     - 每个模式的状态 `z_m(t)` 遵循一阶松弛方程：`dz_m/dt = (L(t) - z_m)/τ_m`。
     - 像素电压 `v(t)` 为所有模式的加权和：`v(t) = Σ w_m z_m(t)`。
     - 模式时间常数基于帧间隔中点亮度自适应调整（通过参考亮度 `I_ref` 和系数 `β` 控制亮度依赖性）。
  2. **连续时间阈值交叉**：
     - 对每个帧间隔（假设对数亮度线性变化），利用闭式解计算端点电压。
     - 基于端点参考相对电压计数ON/OFF事件数量：`n+ = floor([u(t_end)]+/θ_on)`，`n- = floor([-u(t_end)]+/θ_off)`。
     - 对每个计数电平，在区间内用**二分法**定位精确时间戳（无需密集时间网格）。
     - 若计数超过求解器上限，递归分割区间。
  3. **保留记忆状态更新**：
     - 事件发生后，仅更新参考电压 `r`（按ON/OFF阈值移动），**模式状态 `z_m` 保持不变**，将残余电压响应链接到后续事件。
     - 支持不对称的ON/OFF阈值。
- **算法流程**（文字描述）：
  - 输入帧序列（灰度），转换为对数亮度 `L(t)`。
  - 初始化所有模式状态为 `L(t0)`，参考电压为初始电压。
  - 对每个帧间隔：
    - 设定模式时间常数，定义区间内线性亮度轨迹。
    - 计算端点电压，计算ON/OFF事件计数。
    - 若计数超过容量则递归分割。
    - 对每个有效像素和计数电平，用二分法定位交叉时间戳，生成事件并更新参考电压。
    - 将模式状态携带至下一间隔。
  - 输出按时间戳排序的事件流。

### 7. 优点
- **方法创新**：首次将分数松弛动力学引入事件模拟，显式建模像素级记忆效应，更物理真实。
- **模块化框架**：将传感器侧转换与上游轨迹分离，可灵活搭配不同渲染器/插值器，提高可复用性。
- **连续时间处理**：使用闭式模式更新和二分法定位事件时间戳，避免网格约束，产生更自然的异步事件。
- **实验严谨**：
  - 校准独立于下游任务（仅用事件统计），避免过拟合测试集。
  - 消融实验系统移除关键组件，验证各模块贡献。
  - 基线使用其推荐设置，不因FracEvent参数调整而改变。
  - 多数据集、多任务、全序列评估，提供充分证据。

### 8. 不足与局限
- **无法完全补偿上游轨迹误差**：传感器侧动力学再精确也无法弥补亮度轨迹中的缺失运动、曝光伪影等。未来需与更强的轨迹模型结合。
- **校准依赖性**：参数基于特定传感器家族（DAVIS240/346）和少量窗口校准，若传感器偏置、镜头、场景变化大，可能需重新校准。论文未测试跨传感器族泛化。
- **下游任务覆盖有限**：仅测试图像重建和光流估计，未包括目标检测、SLAM、姿态估计等其他事件视觉任务。真实应用效果需更多验证。

- **无噪声建模**：当前版本为确定性模型，未包含泊松噪声、热噪声等随机因素，可能影响极端动态范围下的仿真质量。
