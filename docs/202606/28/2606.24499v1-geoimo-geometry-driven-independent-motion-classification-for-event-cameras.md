## 摘要
现有的汽车事件数据集依赖于基于外观的帧流水线标注，使其不适合运动感知的事件处理。我们提出了一种几何驱动、无标注的框架，通过直接从事件流中利用自我运动结构将检测到的对象分类为静态或独立运动。一个带有偏航补偿的焦点扩展模型估计全局背景运动，而当局部运动偏离该预测时（通过尺度不变的残差量化），对象被标记为运动。时间稳定性提高了连续事件窗口的鲁棒性。该方法无需学习、无需手动运动标签，并且适用于任何输入边界框。在MVSEC和Prophesee 1兆像素汽车检测数据集上的实验表明，该方法在不同驾驶场景下具有一致性能，其中偏航补偿在转弯时改善了结果，而简单的平移局部模型在准确性和效率之间提供了良好的权衡。

## Abstract
Existing automotive event datasets rely on appearance-based annotations from frame pipelines, making them poorly suited for motion-aware event perception. We present a geometry-driven, annotation-free framework that classifies detected objects as static or independently moving by exploiting ego-motion structure directly from the event stream. A Focus of Expansion model with yaw compensation estimates global background motion, while objects are labeled as moving when local motion deviates from this prediction, as quantified by a scale-invariant residual. Temporal stabilization improves robustness across consecutive event windows. The method requires no learning, no manual motion labels, and works with any input bounding boxes. Experiments on MVSEC and the Prophesee 1 Megapixel Automotive Detection dataset demonstrate consistent performance across diverse driving scenarios, with yaw compensation improving results during turns and a simple translational local model offering a favorable accuracy-efficiency trade-off.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：自动驾驶系统需要在动态环境中区分静态场景、自我运动（ego-motion）和独立运动物体（IMO）。事件相机具有微秒级时间分辨率、高动态范围等优势，但其发展受限于缺乏标注运动状态的数据集。现有汽车事件数据集（如MVSEC、Prophesee）的边界框标注来源于帧流水线，仅反映外观信息，不区分静态与运动物体，导致“标注鸿沟”（annotation gap），无法支持运动感知任务。
- **核心问题**：如何在无需手动运动标签、无需学习的情况下，利用事件流中内在的几何结构，将检测到的物体分类为静态或独立运动？
- **整体含义**：提出一种几何驱动、无标注的框架，利用焦点扩展模型（FOE）结合偏航补偿估计全局背景运动，通过对比局部运动与全局预测的残差来分类物体，从而弥合外观标注与事件运动感知之间的差距，为后续运动分割、跟踪等任务提供基础。

## 2. 方法论——核心思想、关键技术细节

- **核心思想**：车辆自我运动会引起事件流中全局一致的、可预测的运动模式。通过估计该全局模式，并将其与物体区域内的局部运动进行比较，显著偏离者即为独立运动物体。无需密集光流或学习，仅需参数化几何模型。
- **流程五阶段**：
    1.  **背景事件选择**：排除已被分类为运动物体的框内事件（初始窗口包括所有框内事件），其余作为背景用于估计自运动。
    2.  **全局自我运动估计**：采用包含偏航（yaw）的FOE模型，参数θ = (x_foe, y_foe, s, ω_y)。将事件按估计速度场扭曲到参考时间，通过对比度最大化（contrast maximization）优化参数。对比度C(θ)=C+(θ)+C-(θ)。
    3.  **局部边界框运动估计**：对每个框内事件独立估计运动，提供两种模型：
        - 径向模型（x^b_foe, y^b_foe, s^b）：捕捉扩展/收缩。
        - 均匀平移模型（v_x, v_y）：近似横向运动。
        通过对比度最大化求参，再转化为框中心处的观察速度v_obs。
        对事件数少于阈值（n_b ≥ ⌊100ρ⌋, A_b ≥ ⌊150ρ⌋）的框默认标记为静态。
    4.  **时间稳定化**：对全局参数和局部速度分别进行轻量级卡尔曼滤波。全局参数中扩展系数s可快速变化，FOE坐标尤其是垂直方向更稳定。局部速度在笛卡尔和极坐标下分离，并根据对比度得分加权。
    5.  **运动一致性分类**：计算尺度不变残差 r = ||v_obs - v_ego|| / max(||v_obs||, ||v_ego||, ε)。若 r ≤ τ 标记为静态，否则为运动。τ为固定阈值。
