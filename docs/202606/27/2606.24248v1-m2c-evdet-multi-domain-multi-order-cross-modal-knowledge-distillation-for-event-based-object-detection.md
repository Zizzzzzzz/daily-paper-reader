## 摘要
事件目标检测（EvDet）作为一种生物启发的视觉感知范式，在需要高时间分辨率和宽动态范围的场景中表现出优越性能。然而，事件数据固有的稀疏表示和不足的视觉语义导致EvDet与基于帧的目标检测之间存在显著的性能差距。以往的工作试图通过知识蒸馏来缓解这种跨模态差异，但它们只关注空间视觉语义或成对关系信息，因此在更复杂场景中的性能受限。为了解决这一挑战，本文提出了M^2C-EvDet，一种用于EvDet的多域多阶跨模态知识蒸馏框架。基于频率学习和超图计算，M^2C-EvDet集成了两个专门模块：自适应频率解耦特征蒸馏（AF^2D^2）和多阶关系蒸馏（MORD）。

## Abstract
Event-based object Detection (EvDet), as a biologically inspired visual perception paradigm, demonstrates superior performance in scenarios demanding high temporal resolution and a wide dynamic range. Nevertheless, the inherent sparse representations and inadequate visual semantics of event data result in a considerable performance disparity between EvDet and frame-based object detection. Previous works attempt to alleviate this cross-modal discrepancy through knowledge distillation, yet they only focus on spatial visual semantics or pair-wise relational information, thus limiting performance in more complex scenarios. To address this challenge, this paper proposes M^2C-EvDet, a Multi-domain and Multi-order Cross-modal knowledge distillation framework for EvDet. Built upon frequency learning and hypergraph computation, M^2C-EvDet integrates two specialized modules: Adaptive Frequency-Decoupled Feature Distillation (AF^2D^2) and Multi-Order Relational Distillation (MORD).

## 1. 论文的核心问题与整体含义
**研究动机与背景：**
- 事件相机（Event Camera）具备高时间分辨率（约1μs）和宽动态范围（约140dB），在高速运动、低光照等极端场景中优于传统RGB帧相机。
- 然而，事件数据本质上是稀疏的异步流，视觉语义信息匮乏，导致事件目标检测（EvDet）的精度远低于基于RGB帧的目标检测。
- 现有跨模态知识蒸馏方法（如COFD、EA-DETR）通常仅关注**单一空间域**的像素级特征蒸馏，或**成对低阶关系**（如自注意力矩阵），忽略了**频域信息**和**多对多高阶关系**，限制了对复杂场景（如密集小目标、运动模糊、低光照）的适应能力。
- 本文核心目标：设计一个**多域、多阶**的跨模态蒸馏框架，充分挖掘RGB模态的丰富视觉与纹理信息，提升事件数据特征表达能力，缩小跨模态差距。

## 2. 论文提出的方法论
**核心思想：**
基于**频率学习**与**超图计算**，将传统空间域特征蒸馏扩展为**频域解耦特征蒸馏**和**多阶关系蒸馏**，实现更全面的知识迁移。

**关键技术细节：**
- **总体框架**：教师-学生架构（训练阶段输入RGB+事件，推理阶段仅用事件）。教师模型为RGB检测器（D-FINE），学生模型为事件检测器。
- **AF²D²（自适应频率解耦特征蒸馏）**：
  - 利用**离散小波变换**将特征图分解为低频（LL）和高频（HL/LH/HH）分量，通过多层分解（T=3层）获取多尺度频率成分。
  - 低频分量包含模态共享的全局语义，高频分量包含模态特有的纹理/轮廓及噪声。
  - 设计**自适应低通/高通滤波器**：对每个分解层生成注意力权重（AFK模块），通过加权融合得到最终的低频和高频特征，适应不同目标尺度和图像特性。
  - 损失函数：低频用L2损失，高频先L2归一化再用L2损失（避免噪声梯度爆炸）。
- **MORD（多阶关系蒸馏）**：
  - **低阶关系（成对）**：采用**空间缩减自注意力**（如PVT中方法），在降采样后的特征上计算自注意力矩阵，传递像素间成对相似性。
  - **高阶关系（多对多）**：引入**超图注意力**。超边特征通过K-means聚类从特征点中生成（16个超边），然后进行“聚合-分发”双向消息传递：顶点→超边（收集→超边特征更新），超边→顶点（分发→顶点特征更新）。利用交叉注意力机制实现多对多高阶关联建模。
  - 损失函数：L2蒸馏教师和学生各自的低阶/高阶关系表示。
- **总体损失**：基础检测损失 + 频域蒸馏损失（λ₁低频+λ₂高频） + 关系蒸馏损失（λ₃低阶+λ₄高阶）。
