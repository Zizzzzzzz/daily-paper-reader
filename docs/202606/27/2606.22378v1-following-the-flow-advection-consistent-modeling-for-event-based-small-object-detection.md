## 摘要
事件相机能够以微秒级延迟实现高频视觉感知，为动态场景提供了优势。然而，由于稀疏的异步测量和易受噪声干扰的弱目标响应，事件相机的小目标检测仍然具有挑战性。有限的空间支持导致小目标信号失去时间连续性，产生碎片化和不稳定的预测。为解决此问题，我们提出了一种物理引导的平流一致建模框架，称为PACT，它将事件演化建模为运动驱动的特征传输过程。PACT不依赖于局部时空聚合，而是沿着估计的速度场传播特征，并通过平流约束强制轨迹级一致性。该设计能随时间保留弱事件响应，并防止其在复杂背景干扰下退化。在技术上，PACT将运动感知特征提取与可微的基于平流的传输算子相结合，实现了连贯的运动表示和时间演化过程中的有效噪声抑制。在基准事件数据集上的大量实验表明，PACT始终优于最先进的方法，在IoU上提升20.72%，准确率提升15.03%，同时保持相当的计算效率。代码已公开发布在https://github.com/fulongcai/PACT。

## Abstract
Event cameras enable high-frequency visual perception with microsecond latency, offering advantages for dynamic scenes. However, event-based small object detection remains challenging due to sparse asynchronous measurements and weak object responses that are easily disrupted by noise. Limited spatial support causes small-object signals to lose temporal continuity, resulting in fragmented and unstable predictions. To address this issue, we propose a physics-guided advection-consistent modeling framework, termed PACT, which formulates event evolution as a motion-driven feature transport process. Instead of relying solely on local spatio-temporal aggregation, PACT propagates features along estimated velocity fields and enforces trajectory-level consistency through advection constraints. This design preserves weak event responses over time and prevents their degradation under complex background interference. Technically, PACT integrates motion-aware feature extraction with a differentiable advection-based transport operator, enabling coherent motion representation and effective noise suppression during temporal evolution. Extensive experiments on benchmark event-based datasets demonstrate that PACT consistently outperforms state-of-the-art methods, achieving improvements of 20.72\% in IoU and 15.03\% in accuracy while maintaining comparable computational efficiency. The code is publicly available at https://github.com/fulongcai/PACT.

## 1. 核心问题与整体含义

- **研究背景**：事件相机以微秒级异步响应捕捉亮度变化，具有高时间分辨率和宽动态范围，适合动态场景。但事件流稀疏、不规则且噪声敏感，小目标引起的弱事件响应空间支持有限，容易在时域上碎片化和不稳定，导致检测性能下降。
- **核心问题**：现有方法（帧聚合、脉冲神经网络等）隐式建模时间连续性，缺乏显式传播规则，无法在强背景干扰下保持弱轨迹的结构完整性。小目标事件响应虽稀疏，但物理运动是连续的；噪声缺乏持续运动源，这是区分二者的关键。
- **整体含义**：本文提出利用**平流一致性约束**（源于物理中的平流方程），显式建模事件响应沿估计速度场的特征传输，使弱信号因满足运动连续性而积累增强，噪声则因不满足一致性而被抑制。这是首次将流体平流概念用于事件小目标检测，解决了时域碎片化问题。

## 2. 方法论

- **核心思想**：将事件流的演化建模为特征场的**平流过程**。在短时间间隔内，特征近似沿局部速度场守恒。平流一致性提供了一个操作准则：能够被一致传输的特征保留并且累积；违反一致性的特征则被逐步抑制。
- **关键公式**：  
  (1) 平流方程：∂u/∂t + v·∇u ≈ 0，特征沿特征曲线 x(t) 满足 du/dt ≈ 0。  
  (2) 离散传输算子：T_v(u)(x,t) = u(x - τv, t - τ)。  
  (3) 平流残差：R_adv(x,t) = ‖u(x,t) - T_v(u)(x,t)‖，作为一致性信号。
- **框架组成（PACT）**：
  - **Trajectory-Guided Feature Extraction (T-FE)**：编码器阶段，通过多分支稀疏卷积聚合时空上下文，并引入轨迹一致性评估器；预测局部2D位移 Δp，计算传输特征 F_adv 与原始特征 F 的一致性门控权重 g，进行保守融合 T_adv = g·F_adv + (1-g)·F。g 作为轨迹一致性分数。
  - **Advection-based Trajectory Consistency (ATC)**：在编码器中估计局部速度场，并施加轨迹一致性速度损失（利用伪速度标签监督）。伪速度通过相邻时间切片前景体素的最近邻匹配获得。
  - **Advection-Consistent Feature Reconstruction (A-FR)**：解码器阶段，沿估计速度场进行传输对齐，考虑K个扰动候选 v_i+δ_k，对每个候选计算传输后的特征 A_k 和置信度 G_k，用一致性加权聚合得到对齐特征 ¯A，再结合底层特征和跳跃连接，最终输出轨迹特征金字塔。
- **损失函数**：主损失 L_seg（二值交叉熵） + 速度正则化 L_vel（Smooth-L1），平衡因子 λ=0.3。

## 7. 优点

- **方法新颖**：首次将流体平流方程引入事件小目标检测，将运动连续性作为显式物理约束，而非隐式假设。
- **物理先验引导**：平流一致性作为弱约束（仅要求运动连续，不依赖外观、形状或强度），与事件相机特性高度契合。
- **端到端可微框架**：T-FE、ATC、A-FR三个模块组成完整编解码器，所有组件可微分，便于联合优化。
- **计算效率高**：仅2.9M参数，58ms推理时间，在资源受限设备上有部署潜力。
- **实验分析深入**：不仅报告最终指标，还通过残差分布、时间连续性、事件稀疏鲁棒性等多角度解释机制，增强了说服力。
- **代码开源**：明确提供GitHub仓库，便于复现和进一步研究。

## 8. 不足与局限

- **数据集单一**：仅在EV-UAV上评估，该数据集虽挑战大，但场景集中（无人机视角、小目标）。缺少在Gen1、1 Mpx、DSEC等通用事件检测数据集上的验证，泛化性存疑。
- **速度场假设局限**：当前假设局部恒定速度（一阶平流），在处理多目标同时大幅变速、加速度或非线性运动时，单次速度场无法对齐所有轨迹，融合效果受限。论文自己指出这一限制并视为未来方向。

- **实验设置细节**：虽提供了若干超参数，但对学习率调度、批量大小等的影响未深入探讨。
