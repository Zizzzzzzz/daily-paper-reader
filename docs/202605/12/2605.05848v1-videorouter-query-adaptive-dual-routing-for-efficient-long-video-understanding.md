## 摘要
视频大多模态模型日益面临可扩展性瓶颈：长视频会产生过长的视觉 Token 序列，从而在推理过程中显著增加内存消耗和延迟。虽然现有的压缩方法在特定场景下有效，但大多数方法要么对查询的感知较弱，要么对所有帧应用固定的压缩策略，当视觉证据在时间上分布不均时，这些方法表现不佳。为了解决这一问题，我们提出了 VideoRouter，这是一个基于 InternVL 构建的查询自适应双路由框架，用于在预算限制下进行证据分配。语义路由器（Semantic Router）预测主导分配策略，在广泛的时间覆盖和自适应高分辨率保留之间进行选择；而图像路由器（Image Router）则利用大语言模型（LLM）的早期层对帧相关性进行评分。这使得模型能够对相关性较低的帧进行激进压缩，同时保留关键证据帧的细节。为了训练这两个路由器，我们构建了用于分配策略监督的 Video-QTR-10K 数据集和用于帧相关性监督的 Video-FLR-200K 数据集。在 VideoMME、MLVU 和 LongVideoBench 上的实验表明，在相当或更低的预算下，VideoRouter 相比 InternVL 基线模型取得了持续的改进，并实现了高达 67.9% 的 Token 削减。

## Abstract
Video large multimodal models increasingly face a scalability bottleneck: long videos produce excessively long visual-token sequences, which sharply increase memory and latency during inference. While existing compression methods are effective in specific settings, most are either weakly query-aware or apply a fixed compression policy across frames, proving suboptimal when visual evidence is unevenly distributed over time. To address this, we present VideoRouter, a query-adaptive dual-router framework built on InternVL for budgeted evidence allocation. The Semantic Router predicts the dominant allocation policy, choosing between broad temporal coverage and adaptive high-resolution preservation, while the Image Router uses early LLM layers to score frame relevance. This enables aggressive compression on less relevant frames while preserving detail on critical evidence frames. To train both routers, we build Video-QTR-10K for allocation-policy supervision and Video-FLR-200K for frame-relevance supervision. Experiments on VideoMME, MLVU, and LongVideoBench show that VideoRouter consistently improves over the InternVL baseline under comparable or lower budgets, achieving up to a 67.9% token reduction.

### 1. 核心问题与整体含义（研究动机和背景）
长视频理解面临的主要瓶颈是**视觉 Token 序列过长**，导致推理时的内存压力和延迟剧增。现有的压缩技术（如 Token 丢弃或均匀池化）存在两个主要缺陷：
*   **查询感知弱**：压缩决策往往在充分理解问题之前就已做出。
*   **策略固定**：对所有视频帧采用统一的压缩率，忽略了长视频中视觉证据分布极不均匀的特性（有些问题需要全局覆盖，有些则依赖局部细节）。
**研究动机**：将长视频压缩建模为一个“预算化的证据分配”问题，即在有限的 Token 预算内，动态决定是“广而浅”地覆盖全片，还是“窄而深”地聚焦关键帧。

### 2. 方法论：核心思想与关键技术
VideoRouter 提出了一个**查询自适应的双路由框架**，其核心组件包括：
*   **双路由架构**：
    *   **语义路由器 (Semantic Router)**：轻量级分类器，分析问题文本以决定分配策略。它将查询分为“全局策略”（Global，侧重全片粗略覆盖）或“片段策略”（Fragment，侧重局部高分辨率保留）。
    *   **图像路由器 (Image Router)**：复用 LLM 的前 4 层（影子栈）作为特征提取器，计算每一帧与问题的相关性得分。
*   **动态预算分配算法**：
    *   根据 LLM 最大上下文长度减去文本长度，动态计算可用的视觉 Token 预算 $B_{img}$。
    *   **优先级池化**：若为片段策略，优先以高保真度（Scale=1）保留相关帧，对无关帧进行激进压缩（Scale=4）；若预算极度受限，则按优先级丢弃低相关帧。
*   **监督数据构建**：
    *   **Video-FLR-200K**：通过反向 QA 生成技术，标注回答特定问题所需的最小关键帧集合。
    *   **Video-QTR-10K**：通过 A/B 测试对比不同策略的性能，为问题类别标注最优分配策略。

### 3. 实验设计
*   **数据集/场景**：在多个主流长视频基准测试上进行评估，包括 **Video-MME**（涵盖短、中、长视频）、**LongVideoBench**、**MLVU**、**LVBench** 和 **EgoSchema**。

*   **训练流程**：采用三阶段课程学习：

### 5. 实验数量与充分性
*   **实验规模**：论文涵盖了 5 个主流数据集的全面测试，并进行了详尽的消融实验（验证双路由的必要性、训练策略的有效性、LLM 提取深度的影响等）。
*   **客观性与公平性**：作者设计了“受控比较”协议，确保所有方法在相同的初始帧数和 Token 预算下竞争，排除了因数据量差异带来的干扰。此外，还进行了跨模型（InternVL 和 Qwen）的验证，证明了方法的普适性。实验设计非常充分且逻辑严密。

### 6. 主要结论与发现
*   **性能提升**：VideoRouter 在减少高达 **67.9%** 的视觉 Token 的情况下，性能依然持平或优于全量 Token 的基线模型。
*   **动态分配的价值**：在预算极度匮乏时，保留关键帧的质量比增加采样帧数更重要；而在预算充足时，增加采样帧数并配合动态分配能达到更高的准确率峰值。
*   **效率优势**：相比密集模型，VideoRouter 显著降低了首字延迟（TTFT）和显存占用。

### 7. 优点与亮点
*   **查询自适应**：打破了固定压缩率的传统模式，实现了真正的“按需分配”。
*   **轻量化设计**：通过复用 LLM 早期层作为路由器特征提取器，避免了引入沉重的额外参数。
*   **高质量数据集**：贡献了两个专门用于路由监督的大规模数据集，填补了该领域的空白。
*   **即插即用**：展示了在不同架构（InternVL, Qwen）上的良好迁移能力。

### 8. 不足与局限
*   **离线假设**：目前仍假设可以离线访问所有采样帧，对于流式长视频处理的适配性有待研究。
*   **监督偏差**：训练数据依赖于强 VLM/LLM 生成的标签，可能存在教师模型的固有偏差。
*   **极端场景**：对于那些同时需要极高空间细节和极长时序覆盖的复杂查询，在极低预算下仍面临权衡难题。
