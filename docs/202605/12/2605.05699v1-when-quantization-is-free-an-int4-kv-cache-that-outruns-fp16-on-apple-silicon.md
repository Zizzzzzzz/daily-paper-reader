## 摘要
KV 缓存量化通常被视为质量与延迟之间的权衡。我们证明在 Apple Silicon 的统一内存架构上，这种关系是“反转”的：一个单一的融合 Metal 核函数（符号随机化 FFT + 逐通道 λ + 逐组绝对最大值 + int4 nibble 打包），作为 HuggingFace Cache 子类公开，在 Gemma-3 1B 的 256 至 4096 token 前缀上（每 token 耗时减少 3% 至 8%）以及 Qwen2.5-1.5B 的短上下文中（1K 以内减少 0.7% 至 2.6%），运行速度均快于 fp16，同时实现了 3 倍的持久内存压缩并保持了模型质量（Qwen 短提示词 ΔPPL = 0.000；Gemma 的 hook ΔPPL 为 +3.6）。该核函数约 25 ns/vec 的开销低于 3 倍压缩带来的带宽节省。该融合核函数还在 182 GFLOPS / D=128 的条件下，显著缓解了 Qwen 的 4-bit 逐 token 性能崩溃（ΔPPL 从 +7975 降至 +638.6，降低了 12.5 倍）。支持性发现包括：SRFT 和 SRHT 在 KV 质量上在统计学上是不可区分的（我们选择 SRFT 以适应混合基数和矩阵乘法对齐）；学习旋转的消融实验揭示了固定随机 SRFT 基底的正则化作用（不使用 SRFT 而学习 R+λ 虽然能将校准 MSE 降低 84.9%，优于 50.3%，但会导致更差的 PPL）；在 d=256 时，具有 k=d/2 反射器的 Householder 旋转实际上是无损的。

## Abstract
KV-cache quantization is framed as a quality--latency trade-off. We show it is \emph{inverted} on Apple Silicon's unified memory: a single fused Metal kernel (sign-randomized FFT $+$ per-channel $λ$ $+$ per-group abs-max $+$ int4 nibble pack), exposed as a HuggingFace \texttt{Cache} subclass, runs \emph{faster than fp16} across $256$--$4096$-token prefixes on Gemma-3 1B ($-3$ to $-8\%$ ms/tok) and at short context on Qwen2.5-1.5B ($-0.7$ to $-2.6\%$ through $1$K), with $3\times$ persistent memory compression and quality preserved ($\dPPL = 0.000$ Qwen short-prompt; $+3.6$ hook $\dPPL$ Gemma). The kernel's $\sim\!25$\,ns/vec overhead is below the bandwidth savings from $3\times$ compression. The fused kernel also closes Qwen's 4-bit per-token catastrophe ($\dPPL = +7975 \to +638.6$, $12.5\times$ reduction) at $182$\,GFLOPS / $D{=}128$. Supporting findings: $\SRFT$ and $\SRHT$ are statistically indistinguishable for KV quality (we pick $\SRFT$ for mixed-radix and matrix-multiply alignment); a learned-rotation ablation surfaces a regularization role for the fixed random SRFT base (learning $R+λ$ without SRFT lowers calibration MSE $84.9\%$ vs $50.3\%$ but yields worse PPL); Householder rotations at $k{=}d/2$ reflectors are effectively lossless at $d{=}256$.

### 1. 核心问题与整体含义
*   **研究动机**：长文本 Transformer 推理受限于 KV 缓存（KV Cache）带来的内存容量和带宽瓶颈。传统的量化方法（如 int4）虽然能减少内存占用，但通常被认为会增加计算延迟（由于解量化开销）并损失模型精度。
*   **核心问题**：在 Apple Silicon 这种统一内存架构（Unified Memory）上，能否实现一种“免费”甚至“负成本”的量化方案，即在压缩内存的同时，让推理速度反而比原始 fp16 更快？

### 2. 方法论
*   **核心思想**：利用统一内存架构中“带宽节省 > 计算开销”的特性。通过将复杂的旋转和量化操作封装进一个单一的、高度优化的 Metal 融合内核，减少内核调度开销。
*   **关键技术细节**：
    *   **SRFT（符号随机化傅里叶变换）**：采用 SRFT 代替常用的 Hadamard 变换（SRHT）。SRFT 能将非高斯分布的激活值“高斯化”，减少量化误差，且对非 2 的幂次维度更友好，更易于对齐矩阵乘法单元（如 AMX）。
    *   **融合 Metal 内核**：在一个 Dispatch 中完成：加载 fp32 -> 符号随机化 -> 基数-2 Stockham FFT 变换 -> 逐通道 $\lambda$ 缩放 -> 逐组（Group Size=32）绝对最大值计算 -> int4 压缩打包。
    *   **HuggingFace 集成**：实现为 `Cache` 子类，通过“解量化前缀缓存”技术，将更新复杂度从 $O(\text{prefix len})$ 降低到 $O(1)$。
    *   **Householder 旋转**：在后训练校准中引入可学习的 Householder 反射器，进一步提升大维度（如 $d=256$）下的精度。

### 3. 实验设计
*   **测试模型**：SmolLM2 (135M, 360M, 1.7B)、Qwen2.5-1.5B、Gemma-3 1B。
*   **数据集/场景**：使用 Cosmopedia 语料库进行困惑度（PPL）测试；在长短不同前缀（256 到 4096 tokens）下进行端到端推理延迟测试。
*   **Benchmark 与对比方法**：
    *   **基准**：原始 fp16 推理。
    *   **对比方法**：Identity（不旋转直接量化）、SRHT（随机 Hadamard 变换）、Eager 模式（PyTorch 原生算子组合）以及不同的缩放策略（逐 token、逐通道、逐组）。

### 4. 资源与算力
*   **硬件平台**：主要在 **Apple M1**（8 核 GPU，16GB 统一内存）上完成。
*   **训练/校准时长**：后训练校准（Learned Rotation）在 M1 上仅需 1-5 分钟（约 200-300 步 Adam 优化）。
*   **算力表现**：Metal 内核在 $D=128$ 时达到 227 GFLOPS，AMX CPU 路径达到 319 GFLOPS（单核峰值的 91%）。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 135M 到 8B 级不同架构的模型，测试了 3-bit 到 8-bit 的多种位宽。
*   **消融实验**：详细对比了 SRFT 与 SRHT 的等效性、有无 SRFT 基底的学习效果、不同旋转参数化（Cayley vs Householder）的差异。
*   **充分性评价**：实验设计非常扎实，不仅有理论分析，还有端到端的 `model.generate` 耗时测量，并提供了位一致性（Bit-exact）验证，客观性较强。

### 6. 主要结论与发现
*   **量化是“免费”的**：在 Apple Silicon 上，int4 KV 缓存的运行速度比 fp16 快 **3% 到 8%**。这是因为 3 倍的内存压缩减少了数据传输量，而优化的内核计算耗时（~25ns）远低于节省的带宽耗时。
*   **SRFT ≡ SRHT**：在 KV 量化质量上，傅里叶变换与 Hadamard 变换在统计上没有区别，但前者硬件适配性更好。
*   **精度保持**：在 Gemma-3 1B ($d=256$) 上，使用 Householder 旋转可以实现 **4-bit 近乎无损**（$\Delta PPL = 0.000$）。
*   **解决崩溃**：通过逐通道 + 逐组量化，成功解决了 Qwen 模型在 4-bit 下因离群值导致的性能崩溃问题。

### 7. 优点
*   **软硬结合**：深入挖掘了 Apple Silicon 统一内存和 AMX 协处理器的硬件特性。
*   **工程落地性强**：直接提供 HuggingFace 兼容的接口，且证明了在移动端/笔记本端推理的实际加速效果。
*   **理论贡献**：发现了校准 MSE 与下游 PPL 之间的分离现象，指出随机旋转基底具有正则化作用。

### 8. 不足与局限
*   **硬件局限性**：该“反转”的贸易关系（量化更快）高度依赖于统一内存架构，在具有独立显存（HBM）和高调度延迟的传统 GPU（如 NVIDIA 桌面卡）上可能无法复现。
*   **模型覆盖**：虽然测试了多个模型，但最高参数量仅到 8B 左右（Llama-3-70B 仅做了内存推算），超大规模模型的表现有待验证。
*   **长文本风险**：在 Qwen 2K 长度测试中出现了因量化噪声导致的提前停止（Early EOS）现象，说明在极长上下文下仍需 fp16 回退机制。
