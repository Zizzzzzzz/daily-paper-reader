## 摘要
当观测者和目标同时运动时，利用机载事件相机进行微小无人机检测具有很大挑战。在这种动对动（motion-on-motion）模式下，自身运动会激活建筑物、植被和地平线结构等背景边缘，而无人机则可能表现为稀疏的事件簇。为了探索这一实际问题，我们提出了 M$^2$E-UAV，这是一个用于机载动对动场景下基于事件的微小无人机检测的基准和分析框架。经过处理的 M$^2$E-UAV 基准包含 87,223 个训练样本和 21,395 个验证样本，涵盖四个场景系列：晴天建筑-森林、晴天农场-村庄、日落建筑-森林以及日落农场-村庄。我们提供了基于点的事件基准模型 M$^2$E-Point，以及其 IMU 条件变体 M$^2$E-Point + IMU，旨在分析惯性线索在机载动对动检测中的作用。M$^2$E-Point 将事件编码为 [x,y,t,p] 点集，利用 EdgeConv 提取局部事件结构，并预测事件级的无人机前景得分，随后通过 DBSCAN 导出边界框。我们的验证阶段分析表明，基于点的事件建模是一个强大的基准，而简单的 IMU 条件约束仅带来了微小的总体增益。在训练/验证集划分下，M$^2$E-Point 达到了 0.9673 的 F1 分数和 0.5501 的 mAP50-95，而 IMU 条件变体达到了 0.5561 的 mAP50-95，仅有微小的总体变化，这为该领域的未来探索提供了初始基准。代码将在 https://github.com/Wickyan/M2E-UAV 发布。

## Abstract
Tiny UAV detection from an onboard event camera is difficult when the observer and target move at the same time. In this motion-on-motion regime, ego-motion activates background edges across buildings, vegetation, and horizon structures, while the UAV may appear as a sparse event cluster. To explore this practical problem, we present M$^2$E-UAV, a benchmark and analysis setup for onboard motion-on-motion event-based tiny UAV detection. The processed M$^2$E-UAV benchmark contains 87,223 training samples and 21,395 validation samples across four scene families: sunny building-forest, sunny farm-village, sunset building-forest, and sunset farm-village. We provide M$^2$E-Point, a point-based event baseline, and M$^2$E-Point + IMU, an IMU-conditioned variant, to analyze the role of inertial cues under onboard motion-on-motion detection. M$^2$E-Point encodes events as $[x,y,t,p]$ point sets, extracts local event structure with EdgeConv, and predicts event-level UAV foreground scores, from which bounding boxes are derived via DBSCAN. Our validation-stage analysis shows that point-based event modeling is a strong baseline, while simple IMU conditioning provides only marginal aggregate gains. Under the train/validation split, M$^2$E-Point achieves 0.9673 F1 and 0.5501 mAP50-95, while the IMU-conditioned variant reaches 0.5561 mAP50-95 with only marginal aggregate changes, serving as an initial baseline for future exploration in this domain. Code will be ready in https://github.com/Wickyan/M2E-UAV.

### 2. 论文提出的方法论
*   **核心思想**：将异步事件流视为**稀疏点云**而非密集图像，利用点云处理网络提取局部几何特征，从而在密集的背景噪声中识别出微小目标的结构。
*   **关键技术细节**：
    1.  **数据表征**：将事件包编码为 $[x, y, t, p]$ 的点集，并进行坐标归一化和时间戳标准化。
    2.  **M^2E-Point 模型**：
        *   **局部特征提取**：采用 **EdgeConv** 块。它通过构建局部图结构并进行卷积，能够捕捉微小无人机在时空中的紧凑几何形态。
        *   **全局聚合**：通过全局最大池化（Global Max Pooling）生成包级特征。
    3.  **IMU 增强（可选）**：提出 **M^2E-Point + IMU** 变体，使用 **FiLM（特征线性调制）** 技术。将同步的 IMU 数据（四元数、角速度、加速度）通过多层感知机（MLP）转换为缩放和偏移参数，对全局事件特征进行调制。
    4.  **检测流程**：模型预测每个事件的前景得分，随后使用 **DBSCAN 聚类算法** 将高分事件点聚类，并导出最终的边界检测框。
*   **损失函数**：结合了 **Focal Loss**（处理极端的类别不平衡）和 **Dice Loss**（优化预测区域与真实标签的重叠度）。

### 6. 主要结论与发现
1.  **表征决定性能**：在动对动场景下，**点云建模（Point-based）** 显著优于基于帧或体素的方法。M^2E-Point 达到了 0.9673 的 F1 分数，远超其他点云网络。
2.  **局部几何的重要性**：消融实验显示，去除 EdgeConv 后性能剧降，证明捕捉局部时空结构是区分目标与背景噪声的关键。
3.  **IMU 的作用有限**：简单的 IMU 全局调制（FiLM）仅带来了微小的性能提升（mAP50-95 从 0.5501 升至 0.5561）。这表明简单的惯性线索不足以完全抵消复杂的自身运动干扰，需要更深层的运动补偿机制。

### 7. 优点
*   **数据集填补空白**：提供了首个 720p、机载动对动、同步 IMU 的微小无人机事件数据集，具有极高的实用价值。
*   **硬件级同步**：使用 STM32 触发同步板，确保了事件流与惯性数据的精确对齐。
*   **基准模型高效**：M^2E-Point 证明了即使不使用复杂的图像骨干网络，直接处理原始事件点也能获得极佳的检测效果。

### 8. 不足与局限
*   **场景多样性风险**：虽然涵盖了 4 种场景，但对于极端天气（雨、雾）、不同飞行高度和更远距离（更小像素占比）的覆盖仍有提升空间。
*   **IMU 融合深度不足**：目前的融合方式较为浅层，未能充分利用 IMU 数据进行显式的运动去噪或自我运动补偿。
*   **实时性探讨缺失**：论文未给出模型在嵌入式计算平台（如 Jetson Orin）上的推理延迟数据，这对于机载应用至关重要。
